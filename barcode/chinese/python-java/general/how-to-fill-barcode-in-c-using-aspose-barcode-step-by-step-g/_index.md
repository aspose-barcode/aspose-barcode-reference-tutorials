# 如何在 C# 中使用 Aspose.BarCode 填充条形码

如果您需要在 .NET 应用程序中 **如何填充条形码**，本教程展示了完整的过程。您将生成带有实心条的邮政 Planet 条形码，然后创建同一条形码的空条版本，只需更改一行代码。

本指南涵盖您需要了解的全部内容：项目设置、X‑dimension 调整、在实心条和空条之间切换，以及如何验证生成的 PNG 文件。无需外部文档——只需复制代码，运行即可看到结果。

## 前置条件

开始之前，请确保您已具备：

* .NET 6.0 SDK 或更高版本  
* 如 Visual Studio 2022 或 VS Code 等开发环境  
* **Aspose.BarCode for .NET** NuGet 包（`Aspose.BarCode`）  

这些项目构成了本教程 **barcode generator c#** 部分的最小基线。

## 如何填充条形码 – 设置项目

1. 创建一个新的控制台项目：

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. 添加 Aspose.BarCode 包：

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. 打开生成的 `Program.cs` 文件，并将其内容替换为本文后面展示的完整示例。

现在项目已包含生成 **postal barcode** 图像所需的全部内容。

## 使用实心条生成邮政条形码

第一步是创建使用实心条的 Planet 条形码。Planet 是许多邮政服务用于分拣的符号系统。

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**这些代码行的重要性**

* `EncodeTypes.Planet` 告诉生成器使用哪种符号系统；Planet 是邮政条形码的标准。  
* `XDimension.Pixels = 4` 增加模块宽度，使条形码更易于扫描，打印时视觉上也更清晰。  
* `Save` 将图像以 PNG 格式写入磁盘，这是一种无损格式，适合后续处理。

运行此代码块会生成 **PostalPlanetFilledBars.png**，该图像使用实心条，符合邮政规范。

## 使用 Planet 符号创建空条条形码

有时邮政系统要求条是空的（未填充），而空白保持实心。只需更改一个属性即可切换到该模式。

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**工作原理**

将 `FilledBars = false` 设置为渲染器指示使用相反的视觉样式：条变为透明（空），背景变为不透明。这正好与前面演示的默认行为相反，使您能够 **创建空条条形码** 图像，而无需更改编码数据。

## 完整、可运行的示例

下面是将上述两个部分合并的完整程序。将其复制到 `Program.cs`，将 `YOUR_DIRECTORY/` 替换为实际文件夹路径，然后运行 `dotnet run`。

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### 预期输出

执行后，您将在指定文件夹中找到两个 PNG 文件：

| 文件名                        | 视觉描述 |
|------------------------------|----------|
| `PostalPlanetFilledBars.png` | 条为黑色实心，背景为白色 |
| `PostalPlanetEmptyBars.png`  | 条为透明（白色），背景为黑色 |

两个图像均编码相同的数字字符串 `"123456"`，并使用相同的 X‑dimension，确保在数据验证层面上可以互换使用。

## 常见问题与边缘情况

**如果输出文件夹不存在会怎样？**  
`Save` 方法会抛出 `DirectoryNotFoundException`。请预先创建文件夹，或在 `try / catch` 块中捕获异常并在必要时创建目录：

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**我可以使用其他图像格式吗？**  
可以。将 `BarCodeImageFormat.Png` 替换为 `BarCodeImageFormat.Jpeg`、`BarCodeImageFormat.Bmp` 或 Aspose.BarCode 支持的任何其他格式。

**X‑dimension 会影响扫描仪的可读性吗？**  
增大像素宽度会使条更宽，从而在低分辨率扫描仪上提升可读性。但数值过大可能超出可打印区域。对于 300 dpi 打印，常见取值在 2 到 6 像素之间。

**`EncodeTypes.Planet` 符号是唯一的邮政选项吗？**  
不是。Aspose.BarCode 还支持 `EncodeTypes.Postnet` 和 `EncodeTypes.USPSIntelligentMail`。`FilledBars` 属性同样适用于这些符号。

现在您已经掌握了使用 Aspose.BarCode 库在 C# 中 **如何填充条形码** 图像、**生成邮政条形码** 变体以及使用 Planet 符号 **创建空条条形码** 的方法。通过调节 X‑dimension 可控制视觉清晰度，而仅通过切换一个属性即可在实心条和空条之间切换，而无需更改编码数据。
