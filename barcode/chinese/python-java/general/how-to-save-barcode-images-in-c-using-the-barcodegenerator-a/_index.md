# 如何在 C# 中使用 BarcodeGenerator API 保存条形码图像

如果您需要从 .NET 应用程序 **保存条形码** 文件，本指南将展示具体步骤。您将看到一个完整的 **条形码生成器示例**，它创建 DataBar Stacked Omnidirectional 条码，调整其宽高比，并保存两个 PNG 文件。

在构建库存系统、销售点终端或自动标签工作流时，保存条形码图像是常见需求。通过本教程，您可以生成条形码 C# 代码，生成可靠的图像，随时用于打印或显示。

## 前提条件

- 已安装 .NET 6.0 SDK 或更高版本  
- Visual Studio 2022（或任何兼容 C# 的 IDE）  
- **Aspose.BarCode for .NET** NuGet 包（代码使用 `Aspose.BarCode.Generation`）  

您可以使用以下命令添加该包：

```bash
dotnet add package Aspose.BarCode
```

## 步骤 1：设置最小的 C# 控制台项目

创建一个新的控制台项目并引用该库：

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

打开 `Program.cs`。该文件将包含 `Main` 方法，我们将在其中放置 **生成条形码 C#** 逻辑。

## 步骤 2：为 DataBar Stacked Omnidirectional 条码初始化 BarcodeGenerator

在任何 **创建 DataBar 条码** 工作流中的第一步是使用正确的 `EncodeType` 实例化 `BarcodeGenerator`。构造函数接受条码符号和数据字符串。

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

`EncodeTypes.DatabarStackedOmniDirectional` 值告诉库生成一种 **创建 DataBar 条码**，可以从任意方向扫描。

## 步骤 3：配置 X 维度（模块宽度）

X 维度控制像素中最小的条宽。将其设置为较低的值可以保持条码紧凑，同时保持可读性。

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## 步骤 4：**如何调整宽高比** – 第一个值 (15)

DataBar 条码提供 `AspectRatio` 属性，影响高度与宽度的比例。更高的比例会产生更高的条码，这可以提升某些打印机上的扫描可靠性。

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## 步骤 5：**如何保存条形码** – 第一个图像（宽高比 15）

现在我们实际 **如何保存条形码** 到文件。`Save` 方法接受文件路径和图像格式。在本例中我们保存为 PNG 文件。

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **提示：** 可执行文件所在的目录是默认写入位置。如果需要特定文件夹，请使用绝对路径。

## 步骤 6：**如何调整宽高比** – 第二个值 (30)

为了演示灵活性，改变宽高比并保存第二个图像。这展示了相同的编码数据可以以不同的视觉比例呈现。

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

运行程序会生成两个 PNG 文件：

- `DatabarAspectRatio15.png` – 高度适中的条码  
- `DatabarAspectRatio30.png` – 在复杂扫描环境下更高的条码  

这两个文件都可以直接加载到 UI 控件、打印到标签或通过 API 传输。

### 预期输出

打开生成的图像时，您应该看到一个 DataBar Stacked Omnidirectional 条码，编码的 GTIN‑14 值为 `12345678901231`。两个文件之间的视觉差异仅在于高度，验证了 **如何调整宽高比** 按预期工作。

## 步骤 7：完整源代码参考

下面是完整的可运行程序。将其复制到 `Program.cs`，构建并运行。

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## 常见问题与边缘情况处理

### 如果目标文件夹不存在怎么办？

`Save` 会抛出 `DirectoryNotFoundException`。请先创建目录：

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### 如何更改图像格式？

根据下游需求，将 `BarCodeImageFormat.Png` 替换为 `BarCodeImageFormat.Jpeg`、`BarCodeImageFormat.Bmp` 或 `BarCodeImageFormat.Tiff`。

### 我可以在循环中生成多个条码吗？

可以。为每个数据字符串实例化新的 `BarcodeGenerator`，或在更新 `CodeText` 属性后复用同一个实例：

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### **如何保存条形码** 在非 Windows 平台上是否可用？

Aspose.BarCode 是跨平台的。只要存在 .NET 运行时，相同的代码即可在 Linux 和 macOS 上运行。
