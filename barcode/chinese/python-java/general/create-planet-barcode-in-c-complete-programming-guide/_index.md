# 在 C# 中创建 Planet 条形码 – 完整编程指南

如果您需要在 C# 中**创建 planet 条形码**，本指南将准确展示如何操作。您还将了解**如何设置条形码尺寸**，以便条码以您所需的精确宽度呈现。

在处理邮政服务或物流系统时，生成 Planet 条形码是常见需求。下面的代码涵盖了默认的实心条版本和可选的空心条样式，并提供了 RM4SCC 格式的快速示例。完成本教程后，您将拥有一个可复用的代码片段，可直接嵌入任何 .NET 项目中。

## 前置条件

* .NET 6.0 或更高版本已安装（该 API 也兼容 .NET Framework 4.6+）
* 已在项目中添加 **Aspose.BarCode for .NET** NuGet 包 (`Aspose.BarCode`)
* 可写入的文件夹路径，用于保存 PNG 文件
* 对 C# 语法和 Visual Studio（或任意 IDE）有基本了解

> **专业提示：** 使用绝对路径或 `Path.Combine(Environment.CurrentDirectory, "output")`，以避免保存图像时的权限问题。

## 第一步 – 初始化 Planet 条形码生成器（实心条）

第一步是为 Planet 符号创建一个 `BarcodeGenerator` 实例。默认情况下，生成器会生成**实心**条。

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

`EncodeTypes.Planet` 枚举指示 Aspose.BarCode 使用 Planet 格式，而 `"123456"` 是将被编码的数据负载。

## 第二步 – 如何设置条形码尺寸以实现一致的大小

要控制每根条的宽度，请调整 **X‑dimension**。这是**设置条形码尺寸**的主要方式，可确保条码适配您的标签尺寸。

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

`Pixels` 属性以屏幕像素定义条的宽度。标准邮件标签常用 2 – 5 像素；如需更大打印，请增大该值。

## 第三步 – 将实心 Planet 条形码保存为 PNG

现在将图像写入磁盘。PNG 能保持清晰的边缘，非常适合扫描。

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

将 `YOUR_DIRECTORY` 替换为您之前准备的路径。运行此代码后，您将看到类似下图的文件。

## 第四步 – 创建空心（未填充）条的 Planet 条形码

如果您的邮政服务要求条码为**空心**，则需在初始化生成器后切换 `FilledBars` 标志。

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

构造函数相同；区别在于后续的配置步骤。

## 第五步 – 如何设置条形码尺寸并使条码为空心

同样，先设置 X‑dimension 以保持视觉一致性，然后禁用实心条。

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

`FilledBars = false` 属性才是真正改变渲染样式的设置。保持相同的 X‑dimension 可确保空心条码与实心版本完美对齐。

## 第六步 – 保存空心 Planet 条形码

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

现在您将拥有两个 PNG 文件：一个实心条，一个空心条，两者尺寸相同。

## 第七步 – （可选）生成 RM4SCC 条形码进行对比

RM4SCC 是另一种邮政符号，同样使用默认的实心条样式。步骤与 Planet 示例相同，展示了**如何设置条形码尺寸**在不同格式下均适用。

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

执行上述三步会生成 `PostalRM4SCCFilledBars.png`，您可以将其与 Planet 的输出并排比较。

## 为什么 X‑dimension 很重要

X‑dimension 决定每根条的**最小可打印宽度**。如果设置过低，条码在低分辨率打印机上可能模糊，导致扫描失败。相反，过大的 X‑dimension 会超出标签尺寸并浪费空间。通过明确**如何设置条形码尺寸**，您可以对最终图像大小进行确定性的控制，这对自动化邮件工作流至关重要。

## 常见陷阱及规避方法

| Issue | Cause | Fix |
|-------|-------|-----|
| 条码出现拉伸 | X‑dimension 使用点而非像素设置 | 始终使用 `Pixels` 属性进行像素级精确控制 |
| 空心条仍显示为实心 | `FilledBars` 在更改 X‑dimension 后未设置为 `false` | 在调整 X‑dimension *后* 设置 `FilledBars = false` |
| 保存的文件为空白 | 输出目录不存在或没有写入权限 | 确保目录存在（`Directory.CreateDirectory`）并且应用拥有足够权限 |
| 打印时图像模糊 | 从高分辨率显示器保存的低 DPI PNG | 使用 `BarCodeImageFormat.Png`（无损），如有需要考虑 `Resolution` 属性 |

## 完整、可运行的示例

将下面的完整代码块复制到新建的控制台项目中（`dotnet new console`），然后运行。程序会在 `output` 文件夹中生成三个 PNG 文件。

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**预期输出：** 三个 PNG 文件——`PostalPlanetFilledBars.png`、`PostalPlanetEmptyBars.png` 和 `PostalRM4SCCFilledBars.png`——每根条宽 4 像素，已准备好打印或进一步处理。
