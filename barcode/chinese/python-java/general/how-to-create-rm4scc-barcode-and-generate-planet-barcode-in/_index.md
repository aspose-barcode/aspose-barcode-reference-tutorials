# 如何在 C# 中创建 RM4SCC 条形码并生成 Planet 条形码

如果您需要为邮政应用 **创建 RM4SCC 条形码**，本指南将向您展示具体步骤。您还将学习如何 **生成 Planet 条形码**，包括自动高度和固定高度两种方式，从而使相同的代码适用于任何邮政符号。

本教程涵盖了生成符合邮政标准的 PNG 图像所需的全部内容。除 Aspose.BarCode for .NET 库外，无需任何外部工具。完成后，您即可以编程方式生成条形码并精确控制其尺寸。

## 前提条件

* .NET 6.0 或更高版本已安装
* Visual Studio 2022（或任何 C# IDE）
* Aspose.BarCode for .NET NuGet 包  
  `Install-Package Aspose.BarCode`
* 对输出目录具有写入权限

这些项目使您能够编译并运行示例代码，而无需额外的配置。

## 步骤 1：为 RM4SCC 初始化条形码生成器

第一步操作创建一个针对 RM4SCC 符号配置的 `BarcodeGenerator` 实例。该对象保存条形码图像的所有设置。

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**为什么这很重要** – `EncodeTypes.RM4SCC` 告诉 Aspose 使用邮政 RM4SCC 格式，而数据字符串 `"123456"` 则代表您想要编码的邮政编码。

## 步骤 2：设置模块宽度（X 维度）

模块宽度决定细条的尺寸。邮政条形码的常用值为 4 像素。

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**解释** – X 维度影响条形码的整体可读性。选择 4 px 符合大多数邮政扫描仪的要求。

## 步骤 3：使用自动条码高度保存

当您省略高度值时，Aspose 会根据符号规则自动计算最佳高度。

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**结果** – 生成的 PNG（`PostalRM4SCCBarHeightNone.png`）包含尺寸正确的 RM4SCC 条形码，可直接用于打印。

## 步骤 4：使用自动高度创建 Planet 条形码

相同的模式同样适用于 Planet 符号。首先使用 `EncodeTypes.Planet` 初始化生成器。

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**为何复用代码** – RM4SCC 与 Planet 共享相同的参数结构，只需更改 `EncodeTypes` 值即可切换符号。

## 步骤 5：为 RM4SCC 定义固定条码高度

某些邮政服务要求特定的条码高度（例如 100 px）。您可以在保存前显式设置此值。

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**提示** – 设置 `BarHeight.Pixels` 会覆盖自动计算，让您完全控制可视尺寸。

## 步骤 6：为 Planet 定义固定条码高度

对 Planet 条形码使用相同的固定高度技术。

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**结果** – `PostalRM4SCCBarHeight100Pixels.png` 与 `PostalPlanetBarHeight100Pixels.png` 均包含高度一致的 100 px 条码，满足严格的邮政规范。

## 完整源代码

下面是完整的可运行程序，涵盖所有四个示例。将其复制到新的控制台项目中，并根据需要调整输出路径。

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**预期输出** – 运行程序后，指定目录中会出现四个 PNG 文件：

* `PostalRM4SCCBarHeightNone.png` – 自动高度的 RM4SCC
* `PostalPlanetBarHeightNone.png` – 自动高度的 Planet
* `PostalRM4SCCBarHeight100Pixels.png` – 高度为 100 px 的 RM4SCC
* `PostalPlanetBarHeight100Pixels.png` – 高度为 100 px 的 Planet

打开任意文件即可验证条纹清晰，模块宽度为 4 px，且高度符合所选设置。

## 常见问题与边缘情况

| Question | Answer |
|----------|--------|
| **我可以使用其他图像格式吗？** | 可以。根据需要将 `BarCodeImageFormat.Png` 替换为 `Jpeg`、`Bmp` 或 `Gif`。 |
| **如果数据字符串更长怎么办？** | 生成器会自动调整条数。请确保数据符合符号的长度限制（RM4SCC ≤ 6 位，Planet ≤ 6 位）。 |
| **如何更改条码颜色？** | 在调用 `Save` 之前设置 `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;`。 |
| **打印时 DPI 重要吗？** | 您可以设置 `rm4sccAuto.Parameters.ImageResolution.DpiX` 和 `DpiY` 以匹配打印机的分辨率。 |
