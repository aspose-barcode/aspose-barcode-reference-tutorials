# 如何使用 Python 创建条形码 PNG – 步骤指南

如果你需要 **创建条形码 PNG** 文件（从任意字符串），本教程提供了一个可直接运行的解决方案。你将看到如何生成 Code 128 条形码、将文本转换为条形码图像，并使用几行 Python 代码将结果保存为 PNG 文件。

本指南涵盖了从安装所需库到为不同使用场景自定义输出的全部内容。完成后，你即可在任何 Python 项目中嵌入条形码生成，而无需查找额外文档。

## 你将学到的内容

* 安装支持 Code 128 的 **barcode generator python** 包。
* 使用 `BarCodeGenerator` **生成 code 128 条形码**（从文本字符串）。
* 使用 `save` 将结果保存为高质量 PNG。
* 调整图像尺寸、前景/背景颜色，并处理常见错误。
* 验证 PNG 是否正确创建。

### 前置条件

| 要求 | 原因 |
|------|------|
| Python 3.8+ | 现代语法和类型提示 |
| 网络访问（用于 `pip install`） | 下载库文件 |
| 对文件夹的写入权限 | 存储生成的 PNG |

不需要外部服务；所有操作均在本地完成。

## 第一步：安装条形码库

在 Python 中 **将文本转换为条形码** 最直接的方式是使用 **Aspose.BarCode for Python via .NET** 包，它开箱即支持 Code 128。

```bash
pip install aspose-barcode
```

> **小贴士：** 如果你在虚拟环境中工作，请在运行命令前激活环境，以保持依赖隔离。

## 第二步：导入所需类

安装完成后，导入核心类。导入语句简短，使代码易于阅读。

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` 用于创建条形码图像。  
* `EncodeTypes` 提供支持的符号集枚举，包括 `CODE_128`。

## 第三步：定义要编码的文本

选择任意字母数字字符串。Code 128 能表示完整的 ASCII 集合，因此不局限于数字。

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

如果输入包含不支持的字符，生成器会抛出 `ValueError`。如果预期用户提供数据，请在 `try` 块中进行赋值。

## 第四步：为 Code 128 创建条形码生成器

使用所需的符号集和前面定义的文本实例化 `BarCodeGenerator`。这是 **如何在 Python 中生成条形码** 图像的核心步骤。

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

为什么选择 Code 128？它密度高且能编码完整的 ASCII 范围，非常适合库存系统、运输标签和票务等场景。

## 第五步：（可选）自定义外观

在保存之前，你可以对条形码进行微调。以下选项较为常用：

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

这些设置会影响最终 **create barcode png** 的输出，但不会改变已编码的数据。

## 第六步：将条形码保存为 PNG 文件

最后，将图像写入磁盘。`save` 方法会自动检测文件扩展名，传入 `.png` 即会生成 PNG 图像。

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

如果目标目录不存在，Python 会抛出 `FileNotFoundError`。请提前创建目录，或使用 `os.makedirs` 并设置 `exist_ok=True`。

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### 预期输出

运行脚本后，你将在 `output` 文件夹中看到 `extended_barcode.png`。打开该文件即可看到清晰的 Code 128 条形码，编码内容为 `1234567890`。

## 第七步：验证条形码（快速检查）

你可以使用同一库读取 PNG，以确认编码值与原始文本一致。

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

运行此块会输出：

```
Verification succeeded: 1234567890
```

如果断言失败，请检查 `barcode_text` 以及你设置的任何自定义参数。

## 常见变体和边缘情况

| 场景 | 调整方式 |
|------|----------|
| **文本较长（> 20 个字符）** | 增大 `image_width` 以避免截断。 |
| **需要透明背景** | 在保存前将 `back_color = "Transparent"`。 |
| **在循环中生成多个条形码** | 将步骤 3‑6 包裹在 `for` 循环中，每次迭代更改 `barcode_text`。 |
| **保存为 JPEG 而非 PNG** | 将文件扩展名改为 `.jpg`；库会自动处理格式。 |
| **在无头服务器上运行** | 该库不依赖 GUI，适用于 CI 流水线。 |

## 完整脚本，快速复制粘贴

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

将脚本保存为 `generate_barcode.py` 并运行：

```bash
python generate_barcode.py
```

你将看到确认信息，并在 `output` 文件夹中生成新的 PNG 文件。
