# 使用 C# 生成紧凑设置的 PDF417 条码

如果您需要在 .NET 应用程序中 **生成 PDF417 条码**，本指南将展示如何使用 Aspose.Barcode for .NET 实现。我们将逐步演示创建生成器、配置列数、X‑dimension（模块尺寸）以及启用紧凑模式，以便生成的符号尽可能小。

在需要为票据、身份证或运单标签编码大量数据时，生成 PDF417 条码是常见需求。本教程覆盖从安装库到保存最终 PNG 的完整工作流，您可以直接复制代码到自己的项目并立即运行。

## 生成 PDF417 条码的前置条件

在开始之前，请确保您拥有：

* 已安装 .NET 6.0（或更高版本）。  
* Visual Studio 2022 或任何支持 C# 项目的 IDE。  
* **Aspose.Barcode for .NET** 的 NuGet 许可证（免费试用版可用于学习）。  

您可以使用以下命令添加库：

```bash
dotnet add package Aspose.BarCode
```

> **小技巧：** 使用 `--version` 参数固定已知的稳定版本，例如 `dotnet add package Aspose.BarCode --version 23.12`。

## 创建 PDF417 条码生成器

下面的代码块创建了一个预配置为 PDF417 符号的 `BarcodeGenerator` 实例。文本 `"Åspóse.Barcóde©"` 包含 Unicode 字符，用于演示生成器能够直接处理非 ASCII 输入。

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### 为什么这很重要
`EncodeTypes.Pdf417` 告诉 Aspose.Barcode 您想要生成 **PDF417 条码**，这是一种堆叠线性符号，最多可存储 1 850 个字符。使用带文本参数的构造函数可以省去后续调用 `SetCodeText` 的步骤。

## 设置条码 XDimension（模块尺寸）

模块尺寸（也称 X‑dimension）决定每根条的宽度。像素越小图像越密集，像素越大则在低分辨率打印机上可读性更好。

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### 为什么要调整 XDimension
`2` 像素的值在屏幕显示和大多数办公打印机上表现良好。如果需要更高分辨率的打印，可增大该值；如果想要更紧凑的条码（例如类似 QR 的外观），可减小该值——但绝不能低于 `1` 像素，否则图像将无法读取。

## 设置 PDF417 符号的列数

PDF417 允许您选择条码的列数（垂直堆叠数）。列数少时条码更高，列数多时条码更宽。

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### 何时更改列数
三列可生成紧凑、近似正方形的符号，适合标准身份证。若字符串非常长，您可以增加列数以保持高度在合理范围内。

## 启用紧凑模式（截断）

紧凑模式会自动移除符号中未使用的行，从而缩小整体尺寸。当编码的数据未填满完整矩阵时，这一点尤为有用。

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### 紧凑 PDF417 条码的优势
当 `Truncate` 为 `true` 时，生成器会计算存储数据所需的最小行数，减少墨水消耗和扫描时间。由于 PDF417 规范已定义截断算法，这对大多数扫描仪都是安全的。

## 将生成的条码保存为图像

最后，将条码写入 PNG 文件。PNG 保持无损质量，适合后续打印或嵌入 PDF。

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### 预期输出
运行程序后会在指定文件夹生成 `CompactPdf417.png`。该图像包含一个 **紧凑的 PDF417 条码**，编码字符串为 `"Åspóse.Barcóde©"`，使用三列、2 像素 X‑dimension，并已启用截断。您可以使用任何条码扫描应用或 Aspose.Barcode 在线演示进行验证。

## 常见变体和边缘情况

| 情况 | 调整方式 |
|-----------|------------|
| **数据非常长（> 1500 字符）** | 增加 `Columns` 或手动设置 `Rows`（`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`）。 |
| **在低 DPI 打印机上打印** | 将 `XDimension.Pixels` 提高到 3 或 4，以避免像素化。 |
| **需要透明背景** | 使用 `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`。 |
| **嵌入 PDF** | 保存为 `BarCodeImageFormat.Pdf`，或通过 `pdf417Generator.GenerateBarCodeImage()` 获取 `Image` 对象。 |

## 完整可运行示例

下面是可以直接复制到新控制台项目中的完整程序。无需额外文件。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

在项目文件夹中运行 `dotnet run`。执行完毕后，打开 `CompactPdf417.png` 即可看到生成的条码。

现在您已经掌握了在 C# 中 **生成 PDF417 条码** 的方法，并能够完整控制列数、X‑dimension 和紧凑模式。通过调整 `barcode XDimension pixels`、`set PDF417 columns` 以及启用 `compact PDF417 barcode` 截断，您可以生成完全符合应用尺寸约束的条码。

* 将条码与其他 Aspose 组件（如 **Aspose.PDF**）结合，直接将图像嵌入 PDF 报告中。
