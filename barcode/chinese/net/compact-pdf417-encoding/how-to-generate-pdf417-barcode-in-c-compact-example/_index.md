# 如何在 C# 中生成 PDF417 条码 – 紧凑示例

如果您需要在 C# 应用程序中 **生成 PDF417 条码**，本指南将为您提供一个完整、可直接运行的解决方案。我们将创建一个紧凑的 PDF417 条码，调整模块宽度，定义列数，并将结果保存为 PNG 图像——全部使用 Aspose.BarCode .NET 库。

在需要以空间高效的二维格式编码大量数据（例如 URL、联系人卡片或库存 ID）时，生成 PDF417 条码是常见需求。完成本教程后，您将拥有一个可工作的 `BarcodeGenerator` 实例，能够生成紧凑且高可读性的条码，适用于打印或显示。

## 前置条件

- .NET 6.0 或更高（代码同样适用于 .NET Framework 4.8）
- Visual Studio 2022（或任意 C# IDE）
- Aspose.BarCode for .NET NuGet 包（`Install-Package Aspose.BarCode`）
- 对 C# 语法有基本了解

无需额外配置；示例以控制台应用程序形式运行。

## 步骤 1：创建 PDF417 条码生成器

第一步是使用 `EncodeTypes.Pdf417` 枚举实例化 `BarcodeGenerator`，并传入要编码的文本。

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**为什么重要：** `EncodeTypes.Pdf417` 告诉库使用 PDF417 符号集，第二个参数设置数据负载。您可以将 `"Compact example"` 替换为任意不超过 1800 个字符的字符串。

## 步骤 2：以像素设置模块宽度（X‑dimension）

X‑dimension 定义单个条码模块（最小的黑白方块）的宽度。像素值越小，条码越紧凑。

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**为什么重要：** `2` 像素的值在大多数现代扫描仪上能够在不牺牲扫描可靠性的前提下呈现紧凑外观。如果需要为低分辨率打印提供更大的模块，请相应调整该值。

## 步骤 3：指定列数

PDF417 允许您控制列数，这会影响条码的宽高比。

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**为什么重要：** 列数少会使条码变得更高，列数多则会使其更宽。三列在紧凑的纵向布局中表现良好。

## 步骤 4：通过截断条码启用紧凑模式

紧凑模式会移除不必要的填充行，使条码体积更小，同时保持已编码的数据。

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**为什么重要：** 当屏幕空间受限（例如移动应用或小标签）时，截断非常理想。条码仍然可完整读取，因为编码算法会自动调整纠错级别。

## 步骤 5：将条码保存为 PNG 图像

最后，将生成的条码写入文件。PNG 保留无损质量，这对条码扫描仪至关重要。

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

运行程序后，会在可执行文件的工作目录中生成 `CompactPdf417.png`。图像效果如下：

![Generated compact PDF417 barcode](CompactPdf417.png "Generated compact PDF417 barcode")

**预期输出：** 一个宽度为 2 像素、三列的 PDF417 条码，编码文本为 “Compact example”。使用标准条码扫描仪扫描该 PNG 应返回原始字符串。

## 常见变体与边界情况

| 情形 | 如何调整代码 |
|-----------|------------------------|
| **数据较长（> 500 字符）** | 将 `Columns` 增加到 5‑7，以防条码过高。 |
| **高分辨率打印** | 将 `XDimension.Pixels` 设置为 3 或 4，以获得更大的模块。 |
| **不同的图像格式** | 将 `BarCodeImageFormat.Png` 替换为 `Jpeg` 或 `Bmp`（视需求而定）。 |
| **在 PDF 中嵌入条码** | 使用 `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` 代替 PNG。 |

**专业提示：** 始终在目标扫描硬件上测试生成的条码。某些低价扫描仪对极小的 X‑dimension 处理不佳；若出现读取错误，请将像素值提升一步。

## 完整可运行示例

下面是完整的程序代码，您可以直接复制粘贴到新的控制台项目中。无需额外文件。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

使用 .NET CLI（`dotnet run`）编译并运行程序。执行完毕后，打开 `CompactPdf417.png` 以验证视觉效果。

## 结论

现在您已经掌握了 **如何在 C# 中生成 PDF417 条码**，并能够使用紧凑布局、自定义 X‑dimension 与列设置。示例演示了关键步骤：实例化 `BarcodeGenerator`、配置 `XDimension` 与 `Columns`、启用 `Truncate` 以进入紧凑模式，最后保存图像。

接下来，您可以探索错误纠正级别、自定义颜色或直接将条码嵌入 PDF 等高级功能。若需要其他符号（如 QR、Code128），请尝试不同的 `EncodeTypes` 并使用相同的参数配置模式。
