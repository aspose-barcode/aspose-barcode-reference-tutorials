# 如何使用 Aspose.BarCode 在 C# 中生成条形码并添加元数据

如果您需要为物流或库存系统 **在 C# 中生成条形码**，本指南提供了一个完整、可投入生产的解决方案。您将了解如何创建 Macro PDF417 条形码、附加丰富的元数据以及设置精确的时间戳——全部使用 Aspose.BarCode 库。

本教程涵盖了从安装 NuGet 包到保存最终 PNG 图像的全部步骤。完成后，您即可生成携带文件标识、段信息和自定义字段的条形码，供支持 Macro PDF417 的下游扫描器使用。

## 前置条件

* .NET 6.0 SDK 或更高版本（代码同样适用于 .NET Framework 4.7.2+）
* Visual Studio 2022 或您喜欢的任何 C# IDE
* 有效的 Aspose.BarCode 许可证（免费试用可用于开发）
* 对 C# 语法有基本了解

> **小贴士：** 如果您使用 CI/CD 流水线，请在项目文件中添加 Aspose.BarCode 包引用，以确保构建可复现。

## 第一步：安装 Aspose.BarCode

在项目文件夹中打开终端并运行：

```bash
dotnet add package Aspose.BarCode
```

该命令会获取最新的稳定版本（当前为 24.9）。恢复完成后，您即可在源文件中引用该库。

## 第二步：创建新的 C# 控制台项目（可选）

如果您想从头开始，可以创建一个控制台应用程序：

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs` 文件将承载后面展示的条形码生成代码。

## 第三步：设置条形码生成器

该过程的核心是 `BarcodeGenerator` 类。您需要使用期望的 `EncodeTypes` 枚举值以及要编码的文本来实例化它。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### 每行代码的重要性

* **EncodeTypes.MacroPdf417** 告诉 Aspose 生成可拆分为多个段的 PDF417 条形码。这对于超出单个符号容量的大数据负载至关重要。
* **XDimension.Pixels** 控制视觉密度。值为 2 时，可在大多数屏幕和打印机上生成清晰图像且不会增大文件大小。
* **MacroPdf417* 属性** 嵌入下游扫描器读取的元数据，作为独立字段（文件 ID、段 ID 等）。这就是本教程中“如何添加元数据”的部分。
* **MacroPdf417TimeStamp** 示范“如何设置时间戳”。`DateTime` 实例可以是任意 UTC 时间；使用 UTC 可避免条形码跨地区传输时的时区歧义。
* **MacroPdf417Terminator** 定义宏序列的结束方式。`Set` 是最常用的选择，因为它向读取器指示这是最后一个段。
* **Save(..., BarCodeImageFormat.Png)** 写入无损图像，保留可靠扫描所需的细节。

## 第四步：验证生成的条形码

运行程序：

```bash
dotnet run
```

您应该会看到控制台输出：

```
Barcode saved to ExtPDF417Meta.png
```

在任意图像查看器中打开 `ExtPDF417Meta.png`。图片将显示一个紧凑的 PDF417 符号，文本为 **Åspóse.Barcóde©**，并包含嵌入的宏字段。使用兼容 PDF417 的扫描仪（或支持 Macro PDF417 的移动应用）扫描该图像，将返回原始文本以及您设置的元数据值。

### 预期的视觉特征

* 深色、间距均匀的垂直条
* Aspose 自动添加的安静区（边距）
* 无失真，因为 `XDimension` 为 2 像素正好匹配 PNG 的原始分辨率

## 第五步：常见变体和边缘情况

### 5.1 处理特殊字符

示例文本包含 Unicode 字符（`Å`、`ó`、`©`）。Aspose.BarCode 默认使用 UTF‑8 编码它们，因此在条形码中能够正确显示。如果需要其他编码（例如 ISO‑8859‑1），请设置：

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 大文件标识符

`MacroPdf417FileID` 接受 32 位整数。对于大于 `int.MaxValue` 的值，可将标识符拆分到多个字段，或使用以字符串形式存储在 `MacroPdf417FileName` 中的 GUID。

### 5.3 调整列数

增大 `Pdf417.Columns` 会降低条形码的高度，但会使每行变宽。如果条形码需要适配狭窄标签，请降低列数，系统会自动增加行数。

### 5.4 保存为其他格式

Aspose 支持 BMP、JPEG、TIFF 和 SVG。将 `BarCodeImageFormat.Png` 替换为所需的枚举值，例如使用 `BarCodeImageFormat.Svg` 以获得可缩放矢量图形。

## 常见问题

**问：这在 .NET Core 上能工作吗？**  
答：可以。相同的 API 在 .NET Core、.NET 5+ 和 .NET Framework 上均可使用。只需引用相应的 NuGet 包。

**问：如果需要生成非宏的 PDF417，该怎么办？**  
答：使用 `EncodeTypes.Pdf417` 替代 `EncodeTypes.MacroPdf417`。宏特定的属性将被忽略。

**问：我能在内置字段之外添加自定义键/值对吗？**  
答：Aspose.BarCode 不会为 Macro PDF417 暴露任意用户字段。如果需要额外数据，请将其编码到主文本负载中，或改用支持结构化追加的 QR 码。
