## استيراد الحزم

تحدد تعداد `EncodeTypes` الأنواع المدعومة من الباركود، و`BarcodeGenerator` هي الفئة التي تنشئ صور الباركود.

```java
import com.aspose.barcode.EncodeTypes;
import com.aspose.barcode.generation.BarcodeGenerator;
```

## دليل خطوة بخطوة

### الخطوة 1: تعيين دليل الموارد

حدد أين سيتم تخزين ملف PNG المُولد.

```java
String dataDir = "Your Document Directory";
```

استبدل `"Your Document Directory"` بالمسار المطلق على نظامك (مثال: `C:/Barcodes/`). استخدام مسار مطلق يجنب الغموض في المسارات النسبية ويضمن كتابة الملف في المكان المتوقع.

### الخطوة 2: إنشاء كائن BarcodeGenerator

فئة `BarcodeGenerator` تنشئ صور الباركود بناءً على النوع المختار والبيانات. أنشئ الكائن باستخدام نوع أستراليا بوست والبيانات التي تريد ترميزها.

```java
BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.AUSTRALIA_POST, "1234567890");
```

بدّل `"1234567890"` بالرمز البريدي الفعلي، رقم التتبع، أو أي سلسلة تتوافق مع قواعد أستراليا بوست. يتحقق المُولد تلقائيًا من طول الإدخال ومجموعة الأحرف.

### الخطوة 3: حفظ صورة الباركود

اكتب الباركود إلى ملف PNG في الدليل الذي حددته.

```java
generator.save(dataDir + "australiaPostBarcode.png");
```

بعد التنفيذ، ستجد `australiaPostBarcode.png` جاهزًا للطباعة أو الإدراج في ملفات PDF أو رسائل البريد الإلكتروني أو صفحات الويب.

### ملخص الخطوات

1. تعيين دليل الموارد.  
2. إنشاء `BarcodeGenerator` باستخدام `EncodeTypes.AUSTRALIA_POST`.  
3. استدعاء `save()` لكتابة ملف PNG.

يمكنك الآن دمج هذا المقتطف في أي خدمة جافا، تطبيق ويب، أو مهمة دفعية تتطلب إنشاء باركود.
