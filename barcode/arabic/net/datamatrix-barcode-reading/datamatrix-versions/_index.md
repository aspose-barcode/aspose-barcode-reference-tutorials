# كيفية إنشاء رموز DataMatrix الشريطية باستخدام Aspose.BarCode لـ .NET

إذا كنت بحاجة إلى طريقة موثوقة لإدراج رموز قابلة للقراءة آليًا في تطبيقات .NET الخاصة بك، فإن **كيفية إنشاء DataMatrix** الشريطية هي متطلب شائع. تقدم Aspose.BarCode لـ .NET واجهة برمجة تطبيقات مُدارة بالكامل تتعامل مع كل خطوة — من اختيار نسخة DataMatrix المناسبة إلى ضبط مستويات تصحيح الأخطاء — دون الحاجة إلى أدوات خارجية. في هذا البرنامج التعليمي سنستعرض مثالًا كاملاً، نشرح لماذا كل إعداد مهم، ونظهر لك كيفية حفظ النتيجة كصورة PNG أو JPEG.

## إجابات سريعة
- **ما المكتبة التي تُنشئ رموز DataMatrix الشريطية؟** Aspose.BarCode لـ .NET.  
- **كم عدد إصدارات DataMatrix المدعومة؟** جميع الإصدارات الـ 30 القياسية المربعة والمستطيلة (من 10×10 حتى 144×144 وحدة).  
- **ما أنواع ECC التي يمكنني استخدامها؟** ECC200 (الافتراضية) و ECC140.  
- **هل أحتاج إلى ترخيص للتطوير؟** نسخة تجريبية مجانية لمدة 30 يومًا تعمل للاختبار؛ يتطلب الترخيص التجاري للإنتاج.  
- **هل يمكن تشغيل هذا على .NET 6 أو .NET Core أو .NET Framework؟** نعم — تدعم Aspose.BarCode .NET Framework 4.5+، .NET Core 3.1+، و .NET 5/6+.

## ما هو رمز DataMatrix الشريطي؟
رمز DataMatrix هو مصفوفة ثنائية الأبعاد، مربعة أو مستطيلة، من خلايا سوداء وبيضاء يمكنها تخزين ما يصل إلى 2,335 حرفًا أبجديًا رقميًا. يُستخدم على نطاق واسع في التصنيع واللوجستيات والرعاية الصحية لتعليم العناصر الصغيرة لأنه يظل قابلًا للقراءة حتى عند تلفه جزئيًا.

## لماذا تستخدم Aspose.BarCode لـ .NET؟
تدعم Aspose.BarCode **أكثر من 50 تنسيق إخراج** (بما في ذلك PNG و JPEG و TIFF و SVG و PDF) ويمكنها إنشاء **جميع الإصدارات الـ 30 من DataMatrix** دون تحميل الصورة بالكامل في الذاكرة، مما يتيح لك إنشاء رموز شريطية في خدمات عالية الإنتاجية تعالج ملفات أكبر من 100 ميغابايت.

## كيفية إنشاء رموز DataMatrix الشريطية في .NET؟

حمّل `BarcodeGenerator` بنوع `EncodeTypes.DataMatrix`، عيّن النسخة المطلوبة وECC، ثم استدعِ `Save` لكتابة ملف الصورة. يعمل هذا النمط ذو السطر الواحد لأي نسخة تختارها ويتعامل تلقائيًا مع حجم الوحدات، المناطق الهادئة، وعرض الصورة.

## استيراد مساحات الأسماء

`BarcodeGenerator` هو الفئة الأساسية في Aspose.BarCode لإنشاء صور الرموز الشريطية.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

توفر مساحة الأسماء `Aspose.BarCode.Generation` الوصول إلى الفئة `BarcodeGenerator`، وهي الفئة الأساسية المستخدمة لإنشاء صور الرموز الشريطية.

الآن، لنقسم المثال إلى خطوات متعددة.

## الخطوة 1: إعداد مسار الدليل الخاص بك

ابدأ بتعريف مسار الدليل حيث تريد حفظ رموز DataMatrix التي تم إنشاؤها.

```csharp
string path = "Your Directory Path";
```

استبدل `"Your Directory Path"` بالمسار الفعلي حيث تريد حفظ صور الرموز الشريطية.

## الخطوة 2: تهيئة مولد الرمز الشريطي

أنشئ نسخة من الفئة `BarcodeGenerator` وحدد نوع الرمز الشريطي كـ `DataMatrix`. يمكنك أيضًا توفير البيانات التي تريد ترميزها داخل الرمز الشريطي.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` هي الفئة الرئيسية التي تنشئ وتعرض رموز الشريط.

## الخطوة 3: تكوين خصائص الرمز الشريطي

يمكنك تخصيص خصائص مختلفة لرمز DataMatrix، مثل أبعاده ونوع ECC (رمز تصحيح الأخطاء). إليك مثالًا على ضبط البُعد X إلى 4 بكسل واختيار ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` يحدد حجم كل وحدة بالبكسل، و`DataMatrixEcc` يختار مستوى تصحيح الأخطاء.

## الخطوة 4: تحديد نسخة DataMatrix وحفظها

يمكنك تحديد نسخة DataMatrix عن طريق ضبط عدد الصفوف والأعمدة. بعد تكوين النسخة، احفظ صورة الرمز الشريطي.

على سبيل المثال، لإنشاء رمز DataMatrix بـ 22 صفًا و22 عمودًا باستخدام ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

وبالمثل، يمكنك إنشاء رمز شريطي بمعلمات مختلفة عن طريق تغيير النسخة ونوع ECC حسب الحاجة.

## الخطوة 5: التكرار لإصدارات أخرى

يمكنك تكرار الخطوة 4 لإصدارات DataMatrix أخرى. على سبيل المثال، لإنشاء رمز شريطي بـ 12 صفًا و64 عمودًا باستخدام ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## الخطوة 6: تبديل أنواع ECC

إذا رغبت في تغيير نوع ECC إلى Ecc140، يمكنك فعل ذلك بتحديث خاصية ECC:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## الخطوة 7: إنشاء رموز شريطية بإصدارات وأنواع ECC مختلفة

كرر الخطوة 4 لإصدارات DataMatrix أخرى وأنواع ECC مختلفة، واحفظ كل رمز شريطي باسم ملف فريد.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```
