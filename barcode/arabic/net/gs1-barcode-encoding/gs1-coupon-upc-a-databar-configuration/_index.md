# إنشاء صورة باركود – كوبون GS1 UPC‑A Databar

## مقدمة

هل تبحث عن **إنشاء صورة باركود .net** باستخدام تكوين كوبون GS1 UPC‑A Databar في تطبيقات .NET الخاصة بك؟ أنت في المكان الصحيح. Aspose.BarCode for .NET هو رفيقك الموثوق لإنشاء الباركود بسهولة. في هذا الدليل الشامل، سنرشدك خلال خطوات إنشاء باركودات كوبون GS1 UPC‑A Databar، موضحين العملية ومضمنين لك دمج هذه الوظيفة بسلاسة في مشاريعك.

## إجابات سريعة
- **ما المكتبة التي أحتاجها؟** Aspose.BarCode for .NET  
- **كم تستغرق العملية؟** حوالي 5‑10 دقائق لإنشاء باركود أساسي  
- **ما إصدارات .NET المدعومة؟** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6  
- **هل أحتاج إلى ترخيص للاختبار؟** ترخيص تجريبي مجاني متاح  
- **هل يمكن تخصيص البُعد X؟** نعم، عبر `Parameters.Barcode.XDimension`

`Parameters.Barcode.XDimension` يحدد عرض أضيق شريط في الباركود المُولد.

## ما هو كوبون GS1 UPC‑A Databar؟

كوبون GS1 UPC‑A Databar هو تنسيق باركود مدمج وعالي الكثافة صُمم للقسائم والعروض الترويجية. يقوم بترميز بيانات UPC‑A القياسية مع معرفات تطبيقات GS1 (AIs) إضافية مثل قيمة الخصم الخاصة بالقسيمة، مما يجعله مثالياً للمسح الضوئي في التجزئة.

## لماذا إنشاء صورة باركود باستخدام Aspose.BarCode؟

يمكنك إنشاء صور باركود باستخدام Aspose.BarCode لأنه يمنحك تحكمًا برمجيًا كاملاً، يعمل على جميع المنصات الرئيسية، ولا يتطلب مكتبات أصلية خارجية. تدعم المكتبة **أكثر من 50 نوعًا من رموز الباركود** ويمكنها معالجة مستندات مئات الصفحات دون تحميل الملف بالكامل إلى الذاكرة، مما يضمن أن يبقى توليد الباركود عالي الكثافة سريعًا وموثوقًا.

## المتطلبات المسبقة

قبل أن نغوص في عالم تكوين كوبون GS1 UPC‑A Databar مع Aspose.BarCode for .NET، تأكد من توفر ما يلي:

1. **Aspose.BarCode for .NET مثبت** – إذا لم تقم بتثبيته بعد، قم بتنزيله من صفحة [Aspose.BarCode for .NET page](https://releases.aspose.com/barcode/net/).  
2. **معرفة أساسية بـ C#** – الإلمام بإطار عمل .NET وVisual Studio.  

الآن، دعنا نستعرض تنفيذ الخطوة بخطوة.

### استيراد مساحات الأسماء

للوصول إلى وظيفة إنشاء الباركود، تحتاج إلى استيراد مساحات الأسماء ذات الصلة.

#### الخطوة 1: إضافة توجيهات using

افتح مشروعك في Visual Studio وأضف هذه عبارات `using` في أعلى ملف C# الخاص بك:

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;
```

هذه التوجيهات تجعل فئات Aspose.BarCode متاحة في الكود الخاص بك.

#### الخطوة 2: تحديد دليل الإخراج

حدد المكان الذي تريد حفظ ملف PNG المُولد فيه. استبدل `"Your Directory Path"` بمسار فعلي على جهازك:

```csharp
string path = "Your Directory Path";
```

#### الخطوة 3: إنشاء كوبون GS1 UPC‑A Databar

`BarcodeGenerator` هو الفئة الأساسية التي تنشئ صور الباركود من سلاسل البيانات. توفر خصائص للتحكم في الحجم، الدقة، وخيارات الترميز.

`XDimension` يحدد عرض الشريط (بالبكسل) للباركود المُولد.

أنشئ مثيلًا من `BarcodeGenerator`، اضبط البُعد X، واحفظ الصورة:

```csharp
BarcodeGenerator gen = new BarcodeGenerator(EncodeTypes.UpcaGs1DatabarCoupon, "123456789012(8110)ASPOSE");
gen.Parameters.Barcode.XDimension.Pixels = 2;
gen.Save($"{path}Gs1CouponUpcaDatabar.png", BarCodeImageFormat.Png);
```

- **EncodeTypes.UpcaGs1DatabarCoupon** يخبر المكتبة باستخدام تنسيق GS1 Coupon UPC‑A Databar.  
- سلسلة البيانات `"123456789012(8110)ASPOSE"` تحتوي على رقم UPC‑A متبوعًا بالمعرف AI `(8110)` لقيمة القسيمة.  
- `XDimension.Pixels = 2` يتحكم في عرض الشريط، مما يمنحك صورة واضحة قابلة للمسح.  

`gen.Parameters.ImageResolution` يحدد DPI للصورة الناتجة.  
`BarcodeException` يُرمى عندما لا يتطابق البيانات المدخلة مع الصيغة المطلوبة.  
`FileResult` هو نتيجة إجراء ASP.NET MVC تُعيد ملفًا إلى العميل.

بعد تشغيل هذا الكود، ستجد `Gs1CouponUpcADatabar.png` في المجلد الذي حددته.

## المشكلات الشائعة والنصائح

| المشكلة | الحل |
|-------|----------|
| **الصورة غير محفوظة** | تحقق من أن `path` ينتهي بشرطة مائلة عكسية (`\`) أو شرطة مائلة (`/`) وأن التطبيق لديه أذونات كتابة. |
| **الباركود غير واضح** | زيادة قيمة `XDimension` أو حفظ الصورة بدقة DPI أعلى عن طريق ضبط `gen.Parameters.ImageResolution`. |
| **تنسيق البيانات غير صالح** | تأكد من أن سلسلة البيانات تتبع صيغة GS1: `<UPC>(<AI>)<value>`. فقدان الأقواس سيتسبب في `BarcodeException`. |
| **استخدام في ASP.NET** | احفظ الصورة المُولدة في تدفق ذاكرة وأعدها عبر `FileResult` لتجنب الكتابة إلى القرص. |
