# كيفية إنشاء الباركود في C# باستخدام Aspose.BarCode وإضافة البيانات الوصفية

إذا كنت بحاجة إلى **إنشاء باركود في C#** لنظام لوجستي أو مخزون، يوضح لك هذا الدليل حلاً كاملاً وجاهزًا للإنتاج. ستتعرف على كيفية إنشاء باركود Macro PDF417، وإرفاق بيانات وصفية غنية، وتعيين طابع زمني دقيق—كل ذلك باستخدام مكتبة Aspose.BarCode.

يغطي الدرس كل شيء من تثبيت حزمة NuGet إلى حفظ صورة PNG النهائية. في النهاية، ستتمكن من إنشاء باركود يحمل معرفات ملفات، معلومات مقاطع، وحقول مخصصة، جاهزًا للماسحات التي تدعم Macro PDF417.

## المتطلبات المسبقة

قبل أن تبدأ، تأكد من وجود ما يلي:

* .NET 6.0 SDK أو أحدث (الكود يعمل أيضًا مع .NET Framework 4.7.2+)
* Visual Studio 2022 أو أي بيئة تطوير C# تفضلها
* ترخيص Aspose.BarCode فعال (الإصدار التجريبي المجاني يكفي للتطوير)
* إلمام أساسي بصياغة C#

> **نصيحة احترافية:** إذا كنت تستخدم خط أنابيب CI/CD، أضف إشارة حزمة Aspose.BarCode في ملف المشروع حتى تظل عمليات البناء قابلة للتكرار.

## الخطوة 1: تثبيت Aspose.BarCode

افتح طرفية في مجلد المشروع وشغّل الأمر التالي:

```bash
dotnet add package Aspose.BarCode
```

يقوم الأمر بجلب أحدث نسخة مستقرة (حالياً 24.9). بعد انتهاء الاستعادة، يمكنك الإشارة إلى المكتبة في ملفات المصدر الخاصة بك.

## الخطوة 2: إنشاء مشروع C# كونسول جديد (اختياري)

إذا كنت تفضّل بدءًا جديدًا، أنشئ تطبيق كونسول:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

سيستضيف ملف `Program.cs` كود توليد الباركود المعروض لاحقًا.

## الخطوة 3: إعداد مولّد الباركود

جوهر العملية هو الفئة `BarcodeGenerator`. تقوم بإنشائها مع قيمة تعداد `EncodeTypes` المطلوبة والنص الذي تريد ترميزه.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### لماذا كل سطر مهم

* **EncodeTypes.MacroPdf417** يخبر Aspose بإنتاج باركود PDF417 يمكن تقسيمه إلى مقاطع. هذا ضروري للأحمال الكبيرة التي تتجاوز سعة الرمز الواحد.
* **XDimension.Pixels** يتحكم في الكثافة البصرية. قيمة 2 تنتج صورة واضحة على معظم الشاشات والطابعات دون زيادة حجم الملف.
* **خصائص MacroPdf417*** تُدرج البيانات الوصفية التي تقرأها الماسحات اللاحقة كحقول منفصلة (معرف الملف، معرف المقطع، إلخ). هذا هو الجزء المتعلق بـ “كيفية إضافة البيانات الوصفية”.
* **MacroPdf417TimeStamp** يوضح “كيفية تعيين الطابع الزمني”. يمكن أن تكون قيمة `DateTime` أي وقت بتوقيت UTC؛ استخدام UTC يجنب الغموض المتعلق بالمناطق الزمنية عندما ينتقل الباركود عبر المناطق.
* **MacroPdf417Terminator** يحدد كيفية انتهاء تسلسل الماكرو. `Set` هو الخيار الأكثر شيوعًا لأنه يشير إلى المقطع النهائي للقارئ.
* **Save(..., BarCodeImageFormat.Png)** يكتب صورة غير مضغوطة تحافظ على التفاصيل الدقيقة المطلوبة للقراءة الموثوقة.

## الخطوة 4: التحقق من الباركود المُولَّد

شغّل البرنامج:

```bash
dotnet run
```

يجب أن ترى مخرجات الكونسول:

```
Barcode saved to ExtPDF417Meta.png
```

افتح `ExtPDF417Meta.png` في أي عارض صور. ستظهر الصورة رمز PDF417 مضغوط مع النص **Åspóse.Barcóde©** والحقول الماكرو المدمجة. مسح الصورة باستخدام ماسح يدعم PDF417 (أو تطبيق جوال يدعم Macro PDF417) سيعيد النص الأصلي بالإضافة إلى قيم البيانات الوصفية التي ضبطتها.

### الخصائص البصرية المتوقعة

* أشرطة رأسية داكنة ومتساوية المسافات
* منطقة هادئة (هامش) تُضاف تلقائيًا بواسطة Aspose
* لا تشوه، لأن `XDimension` بقيمة 2 بكسل يتطابق مع دقة PNG الأصلية

## الخطوة 5: الاختلافات الشائعة وحالات الحافة

### 5.1 معالجة الأحرف الخاصة

النص النموذجي يحتوي على أحرف يونيكود (`Å`, `ó`, `©`). تقوم Aspose.BarCode بترميزها باستخدام UTF‑8 افتراضيًا، لذا تظهر بشكل صحيح في الباركود. إذا احتجت إلى ترميز مختلف (مثل ISO‑8859‑1)، اضبط:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 معرفات ملفات كبيرة

`MacroPdf417FileID` يقبل عددًا صحيحًا 32‑بت. للقيم التي تتجاوز `int.MaxValue`، قسّم المعرف عبر حقول متعددة أو استخدم GUID مخزن كسلسلة في `MacroPdf417FileName`.

### 5.3 تعديل عدد الأعمدة

زيادة `Pdf417.Columns` تقلل من ارتفاع الباركود لكن توسّع كل صف. إذا كان الباركود يجب أن يتناسب مع ملصق ضيق، قلل عدد الأعمدة وزد عدد الصفوف تلقائيًا.

### 5.4 الحفظ بصيغ أخرى

يدعم Aspose BMP، JPEG، TIFF، و SVG. استبدل `BarCodeImageFormat.Png` بالقيمة المطلوبة من التعداد، مثل `BarCodeImageFormat.Svg` للحصول على رسم متجه قابل للتوسيع.

## الخطوة 6: دمج الباركود في سير عمل أكبر

بعد حصولك على ملف PNG، يمكنك:

* تضمينه في فاتورة PDF باستخدام Aspose.PDF.
* إرفاقه في بريد إلكتروني كدليل على التسليم.
* تخزين بايتات الصورة في قاعدة بيانات لاسترجاعها لاحقًا.

فيما يلي مقتطف سريع يحوّل PNG إلى مصفوفة بايت للتخزين:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## الأسئلة المتكررة

**س: هل يعمل هذا على .NET Core؟**  
ج: نعم. نفس الـ API يعمل على .NET Core، .NET 5+، و .NET Framework. فقط أشر إلى حزمة NuGet المناسبة.

**س: ماذا لو أردت إنشاء PDF417 غير ماكرو؟**  
ج: استخدم `EncodeTypes.Pdf417` بدلاً من `EncodeTypes.MacroPdf417`. سيتم تجاهل الخصائص الخاصة بالماكرو.

**س: هل يمكنني إضافة أزواج مفتاح/قيمة مخصصة بخلاف الحقول المدمجة؟**  
ج: لا تُتيح Aspose.BarCode حقول مستخدم عشوائية لـ Macro PDF417. إذا احتجت إلى بيانات إضافية، قم بترميزها في الحمولة النصية الرئيسية أو انتقل إلى QR code الذي يدعم الإلحاق المنظم.

## الخلاصة

أنت الآن تعرف كيف **تنشئ باركود في C#** باستخدام Aspose.BarCode، وتدمج بيانات وصفية غنية، وتعيّن طابعًا زمنيًا دقيقًا لرمز Macro PDF417. المثال الكامل القابل للتنفيذ يوضح كل خطوة مطلوبة—من تثبيت المكتبة إلى حفظ صورة PNG جاهزة للقراءة.
