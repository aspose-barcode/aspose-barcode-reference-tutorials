# كيفية إنشاء باركود PDF417 في C# – مثال مضغوط

إذا كنت بحاجة إلى **إنشاء باركود PDF417** في تطبيق C#، فإن هذا الدليل يوضح لك حلاً كاملاً وجاهزًا للتنفيذ. سنقوم بإنشاء باركود PDF417 مضغوط، ضبط عرض الوحدة، تحديد عدد الأعمدة، وحفظ النتيجة كصورة PNG — كل ذلك باستخدام مكتبة Aspose.BarCode .NET.

إنشاء باركود PDF417 شائع عندما تريد ترميز كميات كبيرة من البيانات (مثل الروابط، بطاقات الاتصال، أو معرفات المخزون) بصيغة ثنائية الأبعاد موفرة للمساحة. بنهاية هذا الشرح ستحصل على كائن `BarcodeGenerator` يعمل ويُنتج باركودًا مضغوطًا عالي القراءة جاهزًا للطباعة أو العرض.

## المتطلبات المسبقة

- .NET 6.0 أو أحدث (الكود يعمل أيضًا مع .NET Framework 4.8)
- Visual Studio 2022 (أو أي بيئة تطوير C#)
- حزمة NuGet Aspose.BarCode for .NET (`Install-Package Aspose.BarCode`)
- إلمام أساسي بتركيب C#

لا يلزم أي إعداد إضافي؛ المثال يعمل كتطبيق وحدة تحكم.

## الخطوة 1: إنشاء مولد باركود PDF417

الخطوة الأولى هي إنشاء كائن `BarcodeGenerator` باستخدام تعداد `EncodeTypes.Pdf417` والنص الذي تريد ترميزه.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**لماذا هذا مهم:** `EncodeTypes.Pdf417` يخبر المكتبة باستخدام رموز PDF417، بينما المعامل الثاني يحدد محتوى البيانات. يمكنك استبدال `"Compact example"` بأي سلسلة تصل إلى 1 800 حرف.

## الخطوة 2: ضبط عرض الوحدة (X‑dimension) بالبكسل

X‑dimension يحدد عرض وحدة الباركود الواحدة (أصغر مربع أسود أو أبيض). قيمة بكسل أصغر تنتج باركودًا أكثر تماسكًا.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**لماذا هذا مهم:** قيمة `2` بكسل تُعطي مظهرًا مضغوطًا دون التضحية بموثوقية القراءة على معظم القارئات الحديثة. عدّل القيمة إذا احتجت وحدات أكبر للطباعة منخفضة الدقة.

## الخطوة 3: تحديد عدد الأعمدة

PDF417 يتيح لك التحكم في عدد الأعمدة، مما يؤثر على نسبة أبعاد الباركود.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**لماذا هذا مهم:** عدد أقل من الأعمدة يجعل الباركود أطول، بينما عدد أكبر يجعله أوسع. ثلاثة أعمدة تعمل جيدًا لتصميم عمودي مضغوط.

## الخطوة 4: تفعيل وضع الضغط عن طريق تقصير الباركود

وضع الضغط يزيل الصفوف الفارغة غير الضرورية، مما يجعل الباركود أصغر مع الحفاظ على البيانات المشفرة.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**لماذا هذا مهم:** التقصير مثالي عندما تكون مساحة الشاشة محدودة (مثل التطبيقات المحمولة أو الملصقات الصغيرة). يبقى الباركود قابلًا للقراءة بالكامل لأن خوارزمية الترميز تضبط مستويات تصحيح الأخطاء تلقائيًا.

## الخطوة 5: حفظ الباركود كصورة PNG

أخيرًا، احفظ الباركود المُولد في ملف. PNG يحافظ على جودة غير مضغوطة، وهو أمر أساسي لقارئات الباركود.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

تشغيل البرنامج ينشئ `CompactPdf417.png` في دليل العمل الخاص بالتنفيذ. الصورة تبدو هكذا:

![باركود PDF417 مضغوط تم إنشاؤه](CompactPdf417.png "باركود PDF417 مضغوط تم إنشاؤه")

**الناتج المتوقع:** باركود PDF417 بعرض 2 بكسل وثلاثة أعمدة يرمز إلى النص “Compact example”. مسح PNG باستخدام قارئ باركود قياسي يجب أن يُعيد السلسلة الأصلية.

## الاختلافات الشائعة وحالات الحافة

| الحالة | كيفية تعديل الكود |
|-----------|------------------------|
| **بيانات أطول ( > 500 حرف )** | زيادة `Columns` إلى 5‑7 للحفاظ على عدم ارتفاع الباركود كثيرًا. |
| **طباعة عالية الدقة** | ضبط `XDimension.Pixels` إلى 3 أو 4 للحصول على وحدات أكبر. |
| **تنسيق صورة مختلف** | استبدال `BarCodeImageFormat.Png` بـ `Jpeg` أو `Bmp` حسب الحاجة. |
| **إدراج الباركود في PDF** | استخدام `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` بدلاً من PNG. |

**نصيحة احترافية:** اختبر دائمًا الباركود المُولد على جهاز القارئ المستهدف. بعض القارئات منخفضة التكلفة تواجه صعوبة مع أبعاد X‑dimension صغيرة جدًا؛ إذا واجهت أخطاء قراءة، زد قيمة البكسل خطوة واحدة.

## مثال كامل قابل للتنفيذ

فيما يلي البرنامج الكامل الذي يمكنك نسخه ولصقه في مشروع وحدة تحكم جديد. لا تحتاج إلى ملفات إضافية.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

قم بتجميع البرنامج وتشغيله (`dotnet run` إذا استخدمت .NET CLI). بعد التنفيذ، افتح `CompactPdf417.png` للتحقق من النتيجة البصرية.

## الخلاصة

أنت الآن تعرف **كيفية إنشاء باركود PDF417** في C# بتصميم مضغوط، X‑dimension مخصص، وإعدادات الأعمدة. يوضح المثال الخطوات الأساسية: إنشاء `BarcodeGenerator`، ضبط `XDimension` و `Columns`، تفعيل `Truncate` للوضع المضغوط، وأخيرًا حفظ الصورة.

من هنا يمكنك استكشاف ميزات إضافية مثل مستوى تصحيح الأخطاء، الألوان المخصصة، أو إدراج الباركود مباشرةً في ملفات PDF. جرّب `EncodeTypes` مختلفة إذا احتجت رموزًا أخرى (مثل QR أو Code128) وطبق نفس نمط تكوين المعلمات.

برمجة سعيدة، ولتُمسح باركوداتك دائمًا من المحاولة الأولى!
