# إنشاء شيفرة PDF417 مع إعدادات مدمجة في C#

إذا كنت بحاجة إلى **إنشاء شيفرة PDF417** في تطبيق .NET، يوضح لك هذا الدليل كيفية القيام بذلك باستخدام Aspose.Barcode for .NET. سنستعرض إنشاء المُولّد، ضبط الأعمدة، البُعد X، وتفعيل الوضع المدمج بحيث يكون الرمز الناتج أصغر ما يمكن.

إنشاء شيفرة PDF417 شائع عندما تحتاج إلى ترميز كميات كبيرة من البيانات لتذاكر، بطاقات هوية، أو ملصقات شحن. يغطي هذا البرنامج التعليمي سير العمل بالكامل—من تثبيت المكتبة إلى حفظ ملف PNG النهائي—حتى تتمكن من نسخ‑لصق الشيفرة في مشروعك وتشغيلها فورًا.

## المتطلبات المسبقة لإنشاء شيفرة PDF417

* .NET 6.0 (أو أحدث) مثبت.  
* Visual Studio 2022 أو أي بيئة تطوير تدعم مشاريع C#.  
* ترخيص NuGet لـ **Aspose.Barcode for .NET** (الإصدار التجريبي المجاني يكفي للتعلم).  

يمكنك إضافة المكتبة بالأمر التالي:

```bash
dotnet add package Aspose.BarCode
```

> **نصيحة احترافية:** استخدم العلامة `--version` لتثبيت نسخة مستقرة معروفة، مثال: `dotnet add package Aspose.BarCode --version 23.12`.

## إنشاء مولّد شيفرة PDF417

الكتلة البرمجية الأولى تُنشئ كائن `BarcodeGenerator` مُعد مسبقًا للرمز PDF417. النص `"Åspóse.Barcóde©"` يحتوي على أحرف Unicode لتوضيح أن المُولّد يتعامل مع المدخلات غير ASCII مباشرة.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### لماذا هذا مهم
`EncodeTypes.Pdf417` يخبر Aspose.Barcode أنك تريد **شيفرة PDF417**، وهي رموز خطية مكدسة قادرة على تخزين ما يصل إلى 1 850 حرفًا. استخدام المُنشئ مع معامل النص يوفر عليك استدعاء لاحق لـ `SetCodeText`.

## ضبط XDimension للشيفرة (حجم الوحدة)

حجم الوحدة، المعروف أيضًا بالبُعد X، يحدد عرض كل شريط فردي. البكسلات الأصغر تنتج صورة أكثر كثافة، بينما البكسلات الأكبر تحسن القراءة على الطابعات منخفضة الدقة.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### لماذا يجب تعديل XDimension
القيمة `2` بكسل تعمل جيدًا للعرض على الشاشة ومعظم طابعات المكاتب. إذا كنت تحتاج طباعة بدقة أعلى، زد القيمة؛ إذا أردت شيفرة أكثر ضيقًا (مثل مظهر QR)، قللها—لكن لا تقل عن بكسل واحد، وإلا ستصبح الصورة غير قابلة للقراءة.

## ضبط عدد الأعمدة لرمز PDF417

يتيح لك PDF417 اختيار عدد الأعمدة (المجموعات العمودية) التي سيحتويها الرمز. الأعمدة الأقل تجعل الشيفرة أطول؛ الأعمدة الأكثر تجعلها أوسع.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### متى يجب تغيير عدد الأعمدة
ثلاثة أعمدة تُنتج رمزًا مدمجًا شبه مربع يناسب بطاقات الهوية القياسية. إذا كان لديك نص طويل جدًا، قد تحتاج لزيادة عدد الأعمدة للحفاظ على ارتفاع معقول.

## تفعيل الوضع المدمج (الاقتطاع)

الوضع المدمج يزيل تلقائيًا الصفوف غير المستخدمة من الرمز، مما يقلص حجمه الكلي. يكون هذا مفيدًا خاصة عندما لا تملأ البيانات المشفرة المصفوفة بالكامل.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### فوائد شيفرة PDF417 المدمجة
عند ضبط `Truncate` إلى `true`، يحسب المُولّد الحد الأدنى لعدد الصفوف المطلوبة لتخزين بياناتك، مما يقلل استهلاك الحبر ووقت المسح. هذا آمن لمعظم القارئات لأن مواصفة PDF417 تحدد خوارزمية الاقتطاع.

## حفظ الشيفرة المولدة كصورة

أخيرًا، اكتب الشيفرة إلى ملف PNG. يحافظ PNG على جودة غير مضغوطة، مما يجعله مثاليًا للطباعة لاحقًا أو الإدراج في ملفات PDF.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### النتيجة المتوقعة
تشغيل البرنامج ينشئ ملف `CompactPdf417.png` في المجلد المحدد. تحتوي الصورة على **شيفرة PDF417 مدمجة** ترمز السلسلة `"Åspóse.Barcóde©"` مع ثلاثة أعمدة، بُعد X بمقدار 2 بكسل، وتطبيق الاقتطاع. يمكنك التحقق من النتيجة باستخدام أي تطبيق ماسح شيفرات أو العرض التجريبي المجاني لـ Aspose.Barcode على الإنترنت.

## الاختلافات الشائعة والحالات الطرفية

| الحالة | التعديل |
|-----------|------------|
| **بيانات طويلة جدًا (> 1500 حرف)** | زيادة `Columns` أو ضبط `Rows` يدويًا (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **الطباعة على طابعة منخفضة الدقة (dpi)** | رفع `XDimension.Pixels` إلى 3 أو 4 لتجنب التشويش. |
| **الحاجة إلى خلفية شفافة** | استخدم `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **الإدراج في PDF** | احفظ كـ `BarCodeImageFormat.Pdf` أو احصل على كائن `Image` عبر `pdf417Generator.GenerateBarCodeImage()`. |

## مثال كامل قابل للتنفيذ

فيما يلي البرنامج الكامل الذي يمكنك نسخه إلى مشروع وحدة تحكم جديد. لا تحتاج إلى ملفات إضافية.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

شغّل `dotnet run` من مجلد المشروع. بعد التنفيذ، افتح `CompactPdf417.png` لرؤية الشيفرة المولدة.

## الخلاصة

أنت الآن تعرف كيف **تنشئ شيفرة PDF417** في C# مع تحكم كامل في الأعمدة، البُعد X، والوضع المدمج. من خلال تعديل `barcode XDimension pixels`، `set PDF417 columns`، وتفعيل اقتطاع `compact PDF417 barcode`، يمكنك إنتاج شيفرة تناسب تمامًا قيود الحجم لتطبيقك.

الخطوات التالية التي قد تستكشفها:

* ترميز مجموعات بيانات أكبر وتجربة معامل `Rows`.  
* تحويل صيغة الإخراج إلى `BarCodeImageFormat.Svg` للحصول على رسومات ويب قابلة للتوسع.  
* دمج الشيفرة مع مكونات Aspose أخرى، مثل **Aspose.PDF**، لإدراج الصورة مباشرةً في تقرير PDF.

برمجة سعيدة، ولا تتردد في تعديل الإعدادات لتتناسب مع بيئة المسح الخاصة بك!
