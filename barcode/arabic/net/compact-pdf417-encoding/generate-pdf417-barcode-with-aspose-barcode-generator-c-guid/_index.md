# إنشاء رمز شريطي PDF417 باستخدام مولد Aspose Barcode – دليل C# 

إذا كنت بحاجة إلى **إنشاء رمز شريطي PDF417** في مشروع .NET، فإن هذا الدليل يوضح لك بالضبط كيفية القيام بذلك باستخدام **Aspose Barcode Generator**. سترى مثالًا كاملاً قابلًا للتنفيذ ينشئ رمز PDF417 مضغوطًا، يخصص حجمه، ويحفظ النتيجة كملف PNG.

إنشاء رمز شريطي PDF417 شائع عندما تحتاج إلى ترميز كميات كبيرة من البيانات—مثل عناوين URL، معلومات الاتصال، أو سجلات المخزون—في صورة واحدة قابلة للمسح. يغطي هذا الدليل كل شيء من تثبيت المكتبة إلى تعديل خيارات **how to set PDF417** للحصول على مخرجات مضغوطة.

## ما ستتعلمه

* تثبيت وإضافة مرجع لمكتبة Aspose.BarCode في مشروع C#.  
* استخدام **aspose barcode generator** لإنشاء رمز PDF417 من نص عشوائي.  
* تطبيق معلمات **how to set PDF417** — حجم الوحدة، عدد الأعمدة، ووضع الضغط.  
* حفظ الرمز الشريطي كصورة PNG والتحقق من النتيجة.  

**المتطلبات المسبقة**

* .NET 6.0 SDK أو أحدث (الكود يعمل أيضًا مع .NET Core 3.1 و .NET Framework 4.7+).  
* إلمام أساسي بتطبيقات C# console.  
* رخصة Aspose.BarCode صالحة (التقييم المجاني يعمل للتطوير).

## الخطوة 1: إنشاء رمز PDF417 — إنشاء المولد

المهمة الأولى هي إنشاء نسخة من المولد مع النص المطلوب ورمزية PDF417. هذه الخطوة تجيب مباشرة على سؤال **how to generate pdf417**.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Create a BarcodeGenerator for PDF417 with the data you want to encode.
            // The EncodeTypes enum selects the symbology; Pdf417 is the target type.
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");
```

**لماذا هذا مهم:**  
`EncodeTypes.Pdf417` يخبر المكتبة باستخدام خوارزمية PDF417، التي تدعم حتى 1,850 حرفًا. المُنشئ يقبل أيضًا سلسلة البيانات الخام؛ أي أحرف Unicode (بما في ذلك الأحرف المشددة) يتم التعامل معها تلقائيًا.

## الخطوة 2: كيفية ضبط معلمات PDF417 — تخصيص الحجم والتخطيط

يمكن عرض رمز PDF417 بأشكال متعددة. تعديل خيارات **how to set pdf417** يتيح لك إنشاء رمز مضغوط يناسب ملصقًا صغيرًا أو شاشة هاتف.

```csharp
            // -----------------------------------------------------------------
            // Step 2: Set visual parameters for the barcode
            // -----------------------------------------------------------------

            // Module size – each tiny square (pixel) of the barcode.
            // Smaller values produce a tighter image; 2 pixels is a good default.
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Number of columns – controls the width of the barcode.
            // Fewer columns make the symbol taller; 3 columns yields a compact shape.
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode – removes unnecessary quiet zones and reduces height.
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;
```

**شرح كل إعداد**

| المعامل | التأثير | متى تستخدم |
|-----------|--------|-------------|
| `XDimension.Pixels` | يتحكم في عرض وحدة واحدة. القيم الأقل تصغر الرمز الشريطي ولكن قد تؤثر على قابلية القراءة للماسح على الأجهزة منخفضة الدقة. | استخدم `2`–`4` للعرض على الشاشة؛ زد القيمة للملصقات المطبوعة. |
| `Pdf417.Columns` | يحدد عدد الأعمدة البيانات التي يحتويها الرمز. الأعمدة الأقل تنتج رمزًا أطول وأضيق. | اختر `3`–`5` لتصاميم مضغوطة؛ قيم أعلى للرموز الأعرض. |
| `Pdf417.Truncate` | يفعل “وضع الضغط” الذي يزيل المنطقة الهادئة الخارجية ويقلل الارتفاع الكلي. | مثالي لعناصر واجهة المستخدم حيث المساحة محدودة. |

هذه الإعدادات الثلاثة معًا تجيب على جزء **how to set pdf417** من المهمة، وتمنحك تحكمًا دقيقًا في الصورة النهائية.

## الخطوة 3: حفظ صورة الرمز الشريطي — تصدير كـ PNG

بعد ضبط المولد، تحتاج إلى كتابة الرمز الشريطي إلى ملف. طريقة `Save` تدعم صيغًا متعددة؛ PNG يحافظ على جودة غير مضغوطة ويعمل جيدًا لكل من سيناريوهات الويب وسطح المكتب.

```csharp
            // -----------------------------------------------------------------
            // Step 3: Save the generated barcode as a PNG image
            // -----------------------------------------------------------------

            // Replace YOUR_DIRECTORY with an actual folder on your machine.
            string outputPath = @"C:\Barcodes\CompactPdf417.png";

            // BarCodeImageFormat.Png tells Aspose to write a PNG file.
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            // Inform the user that the process succeeded.
            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**ما يجب أن تراه**  
تشغيل البرنامج ينشئ `CompactPdf417.png` في المجلد المحدد. الصورة تحتوي على رمز PDF417 كثيف يشفّر السلسلة `Åspóse.Barcóde©`. معظم ماسحات الرموز الشريطية وتطبيقات الهواتف المحمولة (مثل ZXing، Scandit) يمكنها قراءة هذه الصورة دون إعداد إضافي.

## الكود الكامل — ملف واحد جاهز للنسخ واللصق

فيما يلي البرنامج الكامل، بما في ذلك توجيهات `using` وطريقة `Main`. يمكنك نسخ هذا إلى مشروع console جديد وتشغيله فورًا.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Step 1: Create the generator (how to generate pdf417)
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");

            // Step 2: Set PDF417 options (how to set pdf417)
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;   // module size
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;    // number of columns
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact mode

            // Step 3: Save as PNG
            string outputPath = @"C:\Barcodes\CompactPdf417.png";
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**تشغيل الكود**

1. افتح طرفية وأنشئ مشروع console جديد:  
   `dotnet new console -n Pdf417Demo`  
2. أضف حزمة NuGet الخاصة بـ Aspose.BarCode:  
   `dotnet add package Aspose.BarCode`  
3. استبدل ملف `Program.cs` المُولد بالكود أعلاه.  
4. ابنِ وشغّل:  
   `dotnet run`  

يجب أن ترى رسالة التأكيد وتجد ملف PNG في الموقع الذي حددته.

## المشكلات الشائعة ونصائح الممارسات الأفضل

* **انتهاء صلاحية الترخيص** – نسخة التقييم تضيف علامة مائية بعد 30 يومًا. سجّل ترخيصًا مبكرًا لتجنب المفاجآت.  
* **أذونات الدليل** – تأكد من وجود المجلد الهدف وأن العملية لديها صلاحية كتابة؛ وإلا ستطرح `Save` استثناء `UnauthorizedAccessException`.  
* **توافق الماسح** – إذا فشل الماسح في قراءة الرمز المضغوط، زد `XDimension.Pixels` إلى `4` أو عيّن `Truncate = false`.  
* **معالجة Unicode** – Aspose.BarCode يدعم UTF‑8 بالكامل؛ يمكنك ترميز أي سلسلة Unicode دون خطوات إضافية.  
* **الأداء** – توليد العديد من الرموز الشريطية داخل حلقة يستفيد من إعادة استخدام كائن `BarcodeGenerator` واحد وتحديث `CodeText` فقط بين التكرارات.
