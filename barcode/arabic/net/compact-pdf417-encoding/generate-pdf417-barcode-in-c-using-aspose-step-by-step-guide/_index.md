# إنشاء باركود PDF417 في C# باستخدام Aspose – دليل خطوة بخطوة

إذا كنت بحاجة إلى **إنشاء باركود PDF417** في تطبيق .NET، يوضح لك هذا الدليل بالضبط كيفية ذلك. سترى مثالًا كاملاً جاهزًا للتنفيذ يُنشئ باركودات PDF417 الأساسية، المدمجة، Micro، GS1‑Micro، وMacro باستخدام Aspose.BarCode for .NET.

إنشاء باركود PDF417 هو طلب شائع لملصقات الشحن، وثائق النقل، وأنظمة المخزون. بحلول نهاية هذا البرنامج التعليمي ستتمكن من **إنشاء صور باركود PDF417**، وفهم المعلمات الرئيسية، وتكييف الكود لحمولات البيانات الخاصة بك.

## المتطلبات المسبقة

- .NET 6.0 SDK أو أحدث (الكود يعمل أيضًا مع .NET Framework 4.7+)
- Visual Studio 2022 أو أي بيئة تطوير C#
- حزمة NuGet الخاصة بـ Aspose.BarCode for .NET (`Aspose.BarCode`) مُثبتة
- إلمام أساسي بصياغة C#

> **نصيحة احترافية:** استخدم ترخيص التقييم المجاني من Aspose لتجنب قيود وقت التشغيل أثناء الاختبار.

## الخطوة 1: إعداد المشروع واستيراد المساحات الاسمية

أنشئ مشروع وحدة تحكم جديد وأضف حزمة Aspose.BarCode:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

ثم افتح `Program.cs` وأضف توجيهات `using` المطلوبة:

```csharp
using System;
using Aspose.BarCode.Generation;
```

هذه المساحات الاسمية تمنحك الوصول إلى فئة `BarcodeGenerator` وتعداد `EncodeTypes` اللازمين **لإنشاء باركود باستخدام C#**.

## الخطوة 2: إنشاء باركود PDF417 أساسي

أبسط باركود PDF417 يستخدم الإعدادات الافتراضية باستثناء بُعد X (عرض الوحدة) وعدد الأعمدة. تعديل هاتين القيمتين يتحكم في الحجم الكلي وقابلية القراءة.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**سبب عمله:**  
- `EncodeTypes.Pdf417` يخبر Aspose باستخدام رموز PDF417.  
- `XDimension.Pixels` يحدد أصغر عرض للخط؛ قيمة 2 تحافظ على صغر الصورة دون التضحية بقدرة المسح.  
- `Pdf417.Columns` يحدد عدد أعمدة البيانات في الباركود؛ ثلاثة أعمدة تعطي نسبة أبعاد متوازنة.

## الخطوة 3: إنشاء باركود PDF417 مدمج (مقتطع)

الوضع المدمج يزيل نمط الإيقاف ويقلل الارتفاع الكلي، وهو مفيد للملصقات ذات المساحة المحدودة.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**سبب عمله:**  
تعيين `Pdf417.Truncate = true` يُفعّل وضع الاختصار، الذي يحذف نمط الإيقاف الأيمن ويقلل ارتفاع الباركود مع الحفاظ على سلامة البيانات.

## الخطوة 4: إنشاء باركود Micro PDF417

Micro PDF417 هو نسخة أصغر تدعم من 1 إلى 4 أعمدة. إنه مثالي للتطبيقات التي تكون فيها المساحة شحيحة، مثل بطاقات المنتجات الصغيرة.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**سبب عمله:**  
- `EncodeTypes.MicroPdf417` يختار النسخة المصغرة من الرموز.  
- عدد الأعمدة يمكن أن يكون بين 1 و 4؛ اختيار 4 ينتج أكثر التخطيطات كثافة مع بقاء القابلية للمسح.

## الخطوة 5: إنشاء باركود GS1‑Micro PDF417 متوافق مع GS1

تضيف بادئات GS1 معرفات موحدة (مثل GTIN، رقم الدفعة) إلى بيانات الباركود. يتيح لك Aspose تضمينها مباشرة.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**سبب عمله:**  
معرفات تطبيق GS1 (AIs) توضع بين أقواس. يقوم Aspose بتحليلها وإضافة التنسيق المناسب المطلوب من قِبل ماسحات GS1.

## الخطوة 6: إنشاء باركود Macro PDF417 مع بيانات وصفية كاملة

Macro PDF417 يتيح لك تقسيم حمولة بيانات كبيرة عبر عدة باركودات مرتبطة. يمكنك تضمين بيانات وصفية على مستوى الملف مثل معرف الملف، عدد القطع، الطوابع الزمنية، وسلاسل مخصصة.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**سبب عمله:**  
كل خاصية `MacroPdf417*` تُطابق جزءًا محددًا من مواصفات الباركود الماكرو. ضبط هذه القيم يضمن أن الماسح يستطيع إعادة بناء الملف الأصلي من عدة صور باركود.
