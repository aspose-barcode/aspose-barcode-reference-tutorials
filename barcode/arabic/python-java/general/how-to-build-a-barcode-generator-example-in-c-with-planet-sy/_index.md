# مثال مولد الباركود في C# – إنشاء باركود Planet وإنشاء صورة باركود

إذا كنت تحتاج إلى **مثال مولد باركود** بلغة C#، يوضح لك هذا الدليل بالضبط كيفية إنشاء باركود Planet وإنشاء صورة باركود c# في بضع أسطر من الشيفرة فقط. سترى حلاً كاملاً جاهزًا للتنفيذ يمكنك إدراجه في أي مشروع .NET.

يُستخدم باركود Planet من قبل خدمات البريد لتشفير معلومات التوجيه. بنهاية هذا الشرح ستفهم لماذا تقوم المكتبة بتحديد ارتفاع الباركود تلقائيًا، وكيفية التحكم في بُعد X، وكيفية حفظ النتيجة كملف PNG. لا تحتاج إلى أدوات خارجية—فقط حزمة Aspose.BarCode for .NET وبيئة تطوير .NET.

## المتطلبات المسبقة

قبل أن تبدأ، تأكد من وجود ما يلي:

* .NET 6.0 SDK أو أحدث مثبت  
* Visual Studio 2022 (أو أي بيئة تطوير تدعم .NET)  
* حزمة **Aspose.BarCode for .NET** من NuGet (`Aspose.BarCode`)  

يمكنك تثبيت الحزمة من سطر الأوامر:

```bash
dotnet add package Aspose.BarCode
```

## الخطوة 1: تهيئة مولد الباركود لتشفير Planet

الخطوة الأولى في أي **مثال مولد باركود** هي إنشاء كائن `BarcodeGenerator` وتحديد نوع الترميز. لباركود Planet تستخدم `EncodeTypes.Planet` وتمرّر سلسلة البيانات التي تريد ترميزها.

```csharp
using Aspose.BarCode.Generation;

// Create a Planet barcode generator with the data to encode
BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

**لماذا هذا مهم:** تعداد `EncodeTypes.Planet` يخبر المكتبة باستخدام رموز Planet، التي لها نمط وحدة ثابت مطلوب وفقًا لمعايير البريد. تمرير البيانات (`"123456"` في هذه الحالة) يضمن أن يحتوي الباركود على رمز التوجيه الرقمي الصحيح.

## الخطوة 2: ضبط بُعد X (عرض الوحدة) بالبكسل

بُعد X يتحكم في عرض كل وحدة فردية (أصغر شريط). تعديل هذا البُعد يغيّر الحجم الكلي للباركود دون التأثير على قابلية القراءة.

```csharp
// Set the X dimension (module width) to 4 pixels
generator.Parameters.Barcode.XDimension.Pixels = 4;
```

**لماذا هذا مهم:** بُعد X أكبر ينتج باركودًا أكبر، وهو مفيد عند الطباعة على أظرف كبيرة. تقوم المكتبة تلقائيًا بتعديل الارتفاع للحفاظ على نسبة الأبعاد الصحيحة لباركودات Planet.

## الخطوة 3: حفظ صورة الباركود على القرص

أخيرًا، تقوم بحفظ الصورة المولدة. تحدد المكتبة الارتفاع الأمثل، لذا عليك فقط تحديد مسار الإخراج والصيغة.

```csharp
using Aspose.BarCode;

// Define the output file path
string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";

// Save the barcode as a PNG image
generator.Save(outputFile, BarCodeImageFormat.Png);
```

**لماذا هذا مهم:** حفظ الصورة بصيغة PNG يحافظ على حواف الباركود الحادة، وهو أمر أساسي للمسح الضوئي الموثوق. طريقة `Save` تدعم أيضًا صيغًا أخرى (JPEG, BMP, TIFF) إذا احتجت إلى إخراج مختلف.

### النتيجة المتوقعة

بعد تشغيل الشيفرة، ستجد ملفًا باسم **PlanetAutoHeight.png** في `C:\Barcodes`. ستبدو الصورة مشابهة للرسمة أدناه (نص بديل: *مثال مولد باركود يُظهر باركود Planet*).

![Planet barcode generated by the C# example](/images/planet-barcode-example.png){alt="مثال مولد باركود يُظهر باركود Planet"}

## الخطوة 4: اختياري – تخصيص ألوان المقدمة والخلفية

إذا كان تطبيقك يتطلب نمطًا بصريًا مختلفًا، يمكنك تغيير ألوان الباركود قبل الحفظ.

```csharp
// Set foreground (bars) to dark blue and background to light gray
generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

// Save the customized image
generator.Save(@"C:\Barcodes\PlanetCustomColors.png", BarCodeImageFormat.Png);
```

**نصيحة:** اختبر دائمًا الباركود المخصص باستخدام ماسح حقيقي للتأكد من أن تغيّر الألوان لا يؤثر على قابلية القراءة.

## الخطوة 5: معالجة الأخطاء والتحقق من الصحة

تطرح مكتبة Aspose.BarCode استثناء `ArgumentException` إذا لم تتوافق البيانات مع متطلبات رموز Planet (مثل وجود أحرف غير رقمية). احطّ كود الإنشاء بكتلة try‑catch لتقديم ملاحظات واضحة.

```csharp
try
{
    BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "ABC123");
    generator.Save(@"C:\Barcodes\InvalidPlanet.png", BarCodeImageFormat.Png);
}
catch (ArgumentException ex)
{
    Console.WriteLine($"Invalid data for Planet barcode: {ex.Message}");
}
```

**لماذا هذا مهم:** تقبل باركودات Planet بيانات رقمية فقط بطول محدد. التحقق الصحيح يمنع فشل التنفيذ ويوفر الوقت أثناء اختبار التكامل.

## مثال كامل قابل للتنفيذ

جمع جميع الخطوات معًا يمنحك برنامجًا مستقلاً يمكنك نسخه ولصقه وتشغيله.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;
using Aspose.BarCode;

class Program
{
    static void Main()
    {
        // Step 1: Initialize the generator with Planet encoding
        BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");

        // Step 2: Set the X dimension (module width) to 4 pixels
        generator.Parameters.Barcode.XDimension.Pixels = 4;

        // Optional: customize colors (comment out if not needed)
        // generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
        // generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

        // Step 3: Save the barcode image
        string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";
        generator.Save(outputFile, BarCodeImageFormat.Png);

        Console.WriteLine($"Planet barcode saved to {outputFile}");
    }
}
```

قم بتجميع البرنامج وتشغيله:

```bash
dotnet run
```

ستظهر رسالة في وحدة التحكم تؤكد موقع الملف، وستحتوي ملف PNG على باركود Planet المولّد.

## الاختلافات الشائعة والحالات الطرفية

| الاختلاف | طريقة التنفيذ | متى يُستَخدم |
|-----------|------------------|------------|
| **طول بيانات مختلف** | غيّر الوسيط الثاني في `new BarcodeGenerator(EncodeTypes.Planet, "987654321")` | خدمات البريد التي تتطلب أرقام توجيه أطول |
| **دقة أعلى** | عيّن `generator.Parameters.ImageResolution = 300;` قبل `Save` | الطباعة على طابعات عالية الدقة (dpi) |
| **صيغة صورة مختلفة** | استخدم `BarCodeImageFormat.Jpeg` أو `BarCodeImageFormat.Tiff` | عندما لا تكون PNG مناسبة لسير عملك |
| **اسم ملف ديناميكي** | `string outputFile = Path.Combine(folder, $"Planet_{DateTime.Now:yyyyMMdd_HHmmss}.png");` | معالجة دفعات متعددة من الباركودات |

## نصائح احترافية لمثال مولد باركود قوي

* **أعد استخدام كائن المولد** عند إنشاء العديد من الباركودات بنفس الإعدادات؛ غير فقط `EncodeTypes` أو سلسلة البيانات لتحسين الأداء.  
* **تحقق من صحة المدخلات** قبل تمريرها إلى `BarcodeGenerator`. تعبير regex بسيط مثل `^\d{6,9}$` يضمن توافق البيانات مع متطلبات Planet.  
* **حرّر الموارد** إذا كنت تولّد آلاف الصور في خدمة طويلة التشغيل. `BarcodeGenerator` يطبق `IDisposable`، لذا احطّه بكتلة `using` عند الحاجة.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, data))
{
    // configure and save...
}
```
