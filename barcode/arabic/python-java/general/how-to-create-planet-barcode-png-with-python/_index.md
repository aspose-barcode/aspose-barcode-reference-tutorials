# كيفية إنشاء رمز شريطي كوكبي PNG باستخدام Python

إذا كنت بحاجة إلى **إنشاء رمز شريطي كوكبي PNG**، فإن هذا الدليل يشرح لك العملية بالكامل باستخدام Python. ستتعلم أيضًا **كيفية توليد رمز شريطي كوكبي** خطوة بخطوة، وتكوين مظهره، وحفظ النتيجة كصورة PNG عالية الجودة.

يُستخدم توليد رمز شريطي كوكبي بشكل شائع في أتمتة البريد، وتتبع المخزون، وأنظمة اللوجستيات. بنهاية هذا الدليل ستحصل على سكريبت مستقل ينتج ملف PNG جاهز للاستخدام، وستفهم كيفية تعديل الكود لأحجام مختلفة أو صيغ صور أخرى.

## المتطلبات المسبقة

قبل أن تبدأ، تأكد من وجود ما يلي:

* Python 3.8 أو أحدث مثبت.
* إمكانية الوصول إلى حزمة `aspose-barcode` (أو أي مكتبة متوافقة توفر الفئات `BarcodeGenerator`، `EncodeTypes`، و `BarCodeImageFormat`).
* صلاحية كتابة في الدليل الذي تريد تخزين ملف PNG فيه.

يمكنك تثبيت المكتبة المطلوبة باستخدام pip:

```bash
pip install aspose-barcode
```

> **نصيحة احترافية:** استخدم بيئة افتراضية لعزل الاعتمادات عن المشاريع الأخرى.

## إنشاء رمز شريطي كوكبي PNG – استعراض كامل للكود

السكريبت التالي يوضح كل خطوة مطلوبة لتوليد رمز شريطي كوكبي PNG بأشرطة فارغة (غير مملوءة). انسخ الكود إلى ملف باسم `planet_barcode.py` وشغّله باستخدام `python planet_barcode.py`.

```python
# planet_barcode.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Initialize a Planet barcode generator with the data to encode
# The data "123456" is a typical numeric payload for postal services.
generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

# Step 2: Set the width of each bar (X dimension) to 4 pixels.
# Adjusting the X dimension changes the overall size and readability.
generator.parameters.barcode.x_dimension.pixels = 4

# Step 3: Configure the barcode to use empty (unfilled) bars.
# When `filled_bars` is False, the dark bars become transparent,
# which is useful for overlaying the barcode on colored backgrounds.
generator.parameters.barcode.filled_bars = False

# Step 4: Save the generated barcode as a PNG image.
# The output path can be absolute or relative; ensure the folder exists.
output_path = "output/PostalPlanetEmptyBars.png"
generator.save(output_path, BarCodeImageFormat.PNG)

print(f"Planet barcode PNG saved to: {output_path}")
```

### ما يفعله كل سطر

| السطر | الشرح |
|------|-------|
| `from aspose.barcode import ...` | يستورد الفئات اللازمة لإنشاء وتكوين الرمز الشريطي. |
| `BarcodeGenerator(EncodeTypes.Planet, "123456")` | ينشئ مولدًا للرمز الشريطي **Planet** باستخدام السلسلة الرقمية `"123456"`. |
| `x_dimension.pixels = 4` | يحدد عرض الشريط إلى 4 بكسل؛ القيم الأكبر تنتج رمزًا أكبر، بينما القيم الأصغر تقلل حجم الملف. |
| `filled_bars = False` | يبدّل الرمز لاستخدام **أشرطة فارغة**، مما يجعل الوحدات الداكنة شفافة. |
| `save(..., BarCodeImageFormat.PNG)` | يحفظ الرمز الشريطي كملف PNG، محافظًا على الجودة غير الضائعة. |
| `print(...)` | يؤكد نجاح الإنشاء في وحدة التحكم. |

## كيفية توليد رمز شريطي كوكبي بإعدادات مخصصة

بينما يغطي السكريبت الأساسي معظم الحالات، قد تحتاج إلى تعديل الرمز وفقًا لمتطلبات معينة:

1. **طول بيانات مختلف** – يدعم رمز شريطي كوكبي حتى 12 حرفًا رقميًا. غيّر `"123456"` إلى أي سلسلة رقمية صالحة ضمن هذا النطاق.
2. **صيغ صور بديلة** – استبدل `BarCodeImageFormat.PNG` بـ `BarCodeImageFormat.JPEG` أو `BarCodeImageFormat.BMP` لتناسب خطوط المعالجة اللاحقة.
3. **تغيير بُعد X** – القيم الأكبر (مثلاً `8`) تُنتج رمزًا بدقة أعلى، وهو مفيد للطباعة على ملصقات كبيرة.
4. **ألوان الخلفية** – إذا رغبت في خلفية ملونة، عيّن `generator.parameters.barcode.back_color` قبل عملية الحفظ.

مثال مع خلفية مخصصة:

```python
from aspose.barcode import Color

generator.parameters.barcode.back_color = Color.get_yellow()
generator.save("output/PlanetYellowBackground.png", BarCodeImageFormat.PNG)
```

## المشكلات الشائعة وكيفية تجنّبها

| المشكلة | السبب | الحل |
|---------|-------|------|
| **FileNotFoundError** عند الحفظ | الدليل المستهدف غير موجود. | أنشئ الدليل مسبقًا (`os.makedirs("output", exist_ok=True)`). |
| **Invalid data length** | رمز شريطي كوكبي يقبل بيانات رقمية بحد أقصى 12 حرفًا. | تحقق من صحة السلسلة قبل إنشاء المولد. |
| **Transparent bars not visible** | بعض عارضات الصور تتجاهل الشفافية على خلفية بيضاء. | ضع الرمز الشريطي على خلفية غير بيضاء أو صدّر كـ PNG مع قناة ألفا. |

## التحقق من النتيجة

بعد تشغيل السكريبت، افتح `PostalPlanetEmptyBars.png` بأي عارض صور. يجب أن ترى مجموعة من الأشرطة العمودية حيث تكون الوحدات الداكنة شفافة، تاركة فقط حدود الرمز الشريطي. لتأكيد إمكانية مسح الرمز، استخدم تطبيق مسح رموز شريطية على الهاتف يدعم رموز Planet.

إذا ظهرت الصورة فارغة، تحقق من التالي:

* علم `filled_bars` مضبوط على `False`.
* بُعد X غير مُعيّن إلى صفر.
* مسار الإخراج يشير إلى مجلد موجود.
