# إنشاء صورة PNG للباركود في بايثون – دليل كامل

هل احتجت يومًا إلى **إنشاء صورة PNG للباركود** لكنك لم تكن متأكدًا من المكتبة أو الإعدادات التي يجب استخدامها؟ لست وحدك. في العديد من أنظمة المخزون أو نقاط البيع، الخطوة الأولى هي تحويل البيانات الخام إلى صورة PNG واضحة يحبها الماسحات الضوئية.  

في هذا الدرس سنستعرض **كيفية إنشاء databar**، وكيفية **ضبط ارتفاع الباركود**، وحتى الحيلة لتغيير معلمات **الباركود** أثناء التشغيل — كل ذلك باستخدام **باركود مع بيانات عينة** يمكنك نسخها ولصقها مباشرةً في مشروعك.  

## ما ستتعلمه

- إعداد مكتبة Aspose.BarCode (أو مكتبة مشابهة) في بايثون.  
- **إنشاء صورة PNG للباركود** بارتفاعات مختلفة في بضع أسطر من الشيفرة فقط.  
- **كيفية تغيير الباركود** من حيث خصائص مثل حجم الوحدة وارتفاع الشريط.  
- استخدام قيمة GTIN‑14 واقعية كـ **باركود مع بيانات عينة**.  
- نصائح لاستكشاف الأخطاء الشائعة مثل الصور الضبابية أو الترميز غير الصحيح.

لا تحتاج إلى أي خبرة سابقة في إنشاء الباركود — فقط مفسّر بايثون أساسي والقدرة على تثبيت حزمة pip.

## المتطلبات المسبقة

- تثبيت Python 3.8+ على جهازك.  
- اتصال بالإنترنت لتثبيت حزمة `aspose-barcode` (أو أي مكتبة متوافقة).  
- مجلد قابل للكتابة حيث سيتم حفظ ملفات PNG (استبدل `YOUR_DIRECTORY` في السكريبت).  

إذا كان لديك هذه المتطلبات، ممتاز—لنبدأ.

## إنشاء صورة PNG للباركود – إعداد المُولِّد

أولًا وقبل كل شيء: نحتاج إلى كائن مولّد يعرف أننا نتعامل مع باركود **DataBar Omnidirectional**. الشيفرة أدناه تستورد الفئات اللازمة، تنشئ المولد باستخدام **باركود مع بيانات عينة**، وتحدد حجم وحدة معتدل.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**لماذا هذا مهم:** يحدد `EncodeTypes.DATABAR_OMNIDIRECTIONAL` للمحرك إنتاج **DataBar** يمكن قراءته من أي اتجاه، وهو مثالي لأرفف التجزئة. ضبط `x_dimension` يحافظ على حدة الخطوط، بينما يتحكم `bar_height` في الحجم البصري للرمز.

## كيفية إنشاء Databar باستخدام بيانات عينة

الآن بعد أن أصبح المولد جاهزًا، سنقوم **بإنشاء ملفات PNG للباركود**. الحفظ الأول يستخدم ارتفاع 30 بكسل، وهو غالبًا ما يكون كافيًا للمعاينات على الشاشة.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

تشغيل السكريبت حتى هذه النقطة سيولد ملف PNG يبدو كباركود مدمج وعالي التباين. افتحه بأي عارض صور للتحقق من أن الخطوط واضحة وأن بيانات GTIN‑14 مشفرة.

## ضبط ارتفاع الباركود (كيفية تغيير الباركود)

أحيانًا تحتاج إلى باركود أطول للملصقات الكبيرة أو للطباعة بدقة أعلى. هنا يأتي دور **ضبط ارتفاع الباركود**. تغيير الارتفاع بسيط كإجراء تحديث لخاصية `BarHeight` وإعادة الحفظ.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**كيف يعمل:** يعيد المولد استخدام نفس البيانات وحجم الوحدة؛ فقط البُعد العمودي يتغير. هذا يتجنب إعادة إنشاء الكائن بالكامل ويظهر **كيفية تغيير الباركود** ديناميكيًا.

## السكريبت الكامل – حل شامل

فيما يلي السكريبت الكامل القابل للتنفيذ الذي يجمع جميع الخطوات. انسخه، الصقه، وشغّله — يجب أن يعمل مباشرةً بعد تثبيت الحزمة.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### النتيجة المتوقعة

تشغيل السكريبت سيولد ملفين:

- `DatabarOmni30.png` – باركود DataBar Omnidirectional بارتفاع 30 بكسل.  
- `DatabarOmni60.png` – نسخة بارتفاع 60 بكسل من نفس الباركود.

كلا الصورتين بصيغة PNG، غير مضغوطة، وجاهزة للتضمين في ملفات PDF، صفحات HTML، أو الطباعة مباشرةً على الملصقات.

## الأخطاء الشائعة والنصائح الاحترافية

- **Pixel vs. DPI:** ملفات PNG تعتمد على البكسل. إذا كنت تحتاج إلى حجم طباعة محدد، احسب `BarHeight` بناءً على DPI (مثلاً، 300 dpi → 30 px ≈ 0.1 in).  
- **Incorrect encoding:** تأكد من أن سلسلة البيانات تتبع تنسيق معرف التطبيق GS1 (`(01)` لـ GTIN‑14). فقدان الأقواس قد يجعل المكتبة تعود إلى باركود رقمي بسيط.  
- **File paths:** استخدم سلاسل خام (`r"..."`) أو شرطات مائلة مزدوجة في Windows لتجنب مشاكل أحرف الهروب.  
- **Performance:** إذا كنت تولد آلاف الباركودات، أنشئ المولد مرة واحدة وعدّل فقط `BarHeight` أو سلسلة البيانات بين عمليات الحفظ. هذا يقلل من استهلاك الذاكرة.  

## الخطوات التالية

الآن بعد أن عرفت كيفية **إنشاء صورة PNG للباركود**، قد ترغب في استكشاف:

- **كيفية تغيير الباركود** اللون أو إضافة منطقة صمت (`generator.parameters.barcode.quiet_zone`).  
- التصدير إلى صيغ أخرى مثل SVG أو PDF للطباعة القابلة للتوسيع.  
- دمج السكريبت في نقطة نهاية Flask أو Django لتقديم الباركود عند الطلب.  

كل من هذه المواضيع يبني على الأساس الذي غطيناه، لذا لا تتردد في التجربة ودع الشيفرة تتطور وفقًا لاحتياجات مشروعك.
