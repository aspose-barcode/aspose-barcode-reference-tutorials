# كيفية حفظ صور الباركود في C# باستخدام واجهة برمجة تطبيقات BarcodeGenerator API

إذا كنت بحاجة إلى **how to save barcode** ملفات من تطبيق .NET، يوضح هذا الدليل الخطوات الدقيقة. سترى مثالًا كاملاً على **barcode generator example** ينشئ باركود DataBar Stacked Omnidirectional، يضبط نسبة الأبعاد، ويحفظ ملفين PNG.

حفظ صور الباركود هو متطلب شائع عند بناء أنظمة الجرد، أو محطات نقاط البيع، أو تدفقات عمل وضع العلامات الآلية. بنهاية هذا الدرس يمكنك توليد كود barcode C# ينتج صورًا موثوقة جاهزة للطباعة أو العرض.

## المتطلبات المسبقة

- .NET 6.0 SDK أو أحدث مثبت  
- Visual Studio 2022 (أو أي بيئة تطوير متوافقة مع C#)  
- حزمة **Aspose.BarCode for .NET** من NuGet (الكود يستخدم `Aspose.BarCode.Generation`)  

يمكنك إضافة الحزمة بالأمر التالي:

```bash
dotnet add package Aspose.BarCode
```

## الخطوة 1: إعداد مشروع وحدة تحكم C# بسيط

أنشئ مشروع وحدة تحكم جديد وأشر إلى المكتبة:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

افتح `Program.cs`. سيحتوي الملف على طريقة `Main` حيث سنضع منطق **generate barcode C#**.

## الخطوة 2: تهيئة BarcodeGenerator لباركود DataBar Stacked Omnidirectional

المهمة الأولى في أي سير عمل **create databar barcode** هي إنشاء كائن `BarcodeGenerator` باستخدام `EncodeType` الصحيح. يتلقى المُنشئ نوع الباركود وسلسلة البيانات.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

القيمة `EncodeTypes.DatabarStackedOmniDirectional` تخبر المكتبة بإنتاج **create databar barcode** يمكن مسحه من أي اتجاه.

## الخطوة 3: ضبط بُعد X (عرض الوحدة)

بُعد X يتحكم في أصغر عرض للخط في البكسل. ضبطه على قيمة منخفضة يحافظ على صغر حجم الباركود مع الحفاظ على قابلية القراءة.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## الخطوة 4: **How to adjust aspect ratio** – القيمة الأولى (15)

باركودات DataBar تعرض خاصية `AspectRatio` التي تؤثر على علاقة الارتفاع إلى العرض. نسبة أعلى تنتج باركودًا أطول، مما قد يحسن موثوقية المسح على بعض الطابعات.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## الخطوة 5: **How to save barcode** – الصورة الأولى (نسبة الأبعاد 15)

الآن نقوم فعليًا بـ **how to save barcode** إلى ملف. طريقة `Save` تأخذ مسار الملف وتنسيق الصورة. في هذا المثال نحفظ ملف PNG.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **نصيحة:** دليل الملف التنفيذي هو الموقع الافتراضي للكتابة. استخدم مسارًا مطلقًا إذا كنت تحتاج إلى مجلد محدد.

## الخطوة 6: **How to adjust aspect ratio** – القيمة الثانية (30)

لإظهار المرونة، غيّر نسبة الأبعاد واحفظ صورة ثانية. هذا يوضح كيف يمكن تمثيل نفس البيانات المشفرة بنسب بصرية مختلفة.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

تشغيل البرنامج ينتج ملفين PNG:

- `DatabarAspectRatio15.png` – باركود بارتفاع متوسط  
- `DatabarAspectRatio30.png` – باركود بارتفاع أعلى لبيئات المسح الصعبة  

كلا الملفين جاهزان للتحميل في عناصر واجهة المستخدم، أو للطباعة على الملصقات، أو للإرسال عبر API.

### النتيجة المتوقعة

عند فتح الصور المولدة، يجب أن ترى باركود DataBar Stacked Omnidirectional يشفّر قيمة GTIN‑14 `12345678901231`. الاختلاف البصري بين الملفين هو الارتفاع فقط، مما يؤكد أن **how to adjust aspect ratio** يعمل كما هو مقصود.

## الخطوة 7: الكود الكامل للمراجعة

فيما يلي البرنامج الكامل القابل للتنفيذ. انسخه إلى `Program.cs`، ثم ابنِه وشغّله.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## الأسئلة الشائعة ومعالجة الحالات الخاصة

### ماذا لو لم يكن المجلد الهدف موجودًا؟

`Save` يطرح استثناء `DirectoryNotFoundException`. أنشئ المجلد أولاً:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### كيف تغير تنسيق الصورة؟

استبدل `BarCodeImageFormat.Png` بـ `BarCodeImageFormat.Jpeg` أو `BarCodeImageFormat.Bmp` أو `BarCodeImageFormat.Tiff` حسب متطلبات المرحلة التالية.

### هل يمكنني توليد باركودات متعددة في حلقة؟

نعم. أنشئ كائن `BarcodeGenerator` جديد لكل سلسلة بيانات أو أعد استخدام نفس الكائن بعد تحديث خاصية `CodeText`:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### هل **how to save barcode** يعمل على منصات غير Windows؟

Aspose.BarCode متعدد المنصات. نفس الكود يعمل على Linux و macOS طالما أن بيئة تشغيل .NET موجودة.
