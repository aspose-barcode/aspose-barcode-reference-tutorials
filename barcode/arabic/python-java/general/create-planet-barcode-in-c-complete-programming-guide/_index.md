# إنشاء باركود كوكب في C# – دليل برمجة كامل

إذا كنت بحاجة إلى **إنشاء باركود كوكب** في C#، فإن هذا الدليل يوضح لك بالضبط كيفية القيام بذلك. ستكتشف أيضًا **كيفية ضبط أبعاد الباركود** بحيث تظهر الأشرطة بالعرض الدقيق الذي تحتاجه.

يُعد إنشاء باركودات كوكب أمرًا شائعًا عند العمل مع خدمات البريد أو أنظمة اللوجستيات. يغطي الكود أدناه كلًا من النسخة المملوءة بالأشرطة (filled‑bar) والنسخة الاختيارية ذات الأشرطة الفارغة (empty‑bar)، بالإضافة إلى مثال سريع لتنسيق RM4SCC. بنهاية هذا الدرس ستحصل على مقتطف قابل لإعادة الاستخدام يمكنك إدراجه في أي مشروع .NET.

## المتطلبات المسبقة

قبل أن تبدأ، تأكد من وجود ما يلي:

* .NET 6.0 أو أحدث مثبت (تعمل الواجهة البرمجية أيضًا مع .NET Framework 4.6+)
* حزمة NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`) مضافة إلى مشروعك
* مسار مجلد قابل للكتابة حيث سيتم حفظ ملفات PNG
* إلمام أساسي بصياغة C# وVisual Studio (أو أي بيئة تطوير متكاملة)

> **نصيحة احترافية:** استخدم مسارًا مطلقًا أو `Path.Combine(Environment.CurrentDirectory, "output")` لتجنب مشاكل الأذونات عند حفظ الصور.

## الخطوة 1 – تهيئة مولّد باركود كوكب (أشرطة مملوءة)

الخطوة الأولى هي إنشاء كائن `BarcodeGenerator` لرمز كوكب. بشكل افتراضي ينتج المولّد أشرطة **مملوءة**.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

تُخبر قيمة التعداد `EncodeTypes.Planet` Aspose.BarCode باستخدام تنسيق كوكب، بينما `"123456"` هو البيانات التي سيتم ترميزها.

## الخطوة 2 – كيفية ضبط أبعاد الباركود لتوحيد الحجم

للتحكم في عرض كل شريط، اضبط **X‑dimension**. هذه هي الطريقة الأساسية **لضبط أبعاد الباركود** وتضمن أن الباركود يتناسب مع حجم الملصق الخاص بك.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

خاصية `Pixels` تحدد عرض الشريط بوحدات بكسل الشاشة. القيم الشائعة هي 2 – 5 بكسل للملصقات البريدية القياسية؛ زد القيمة للطباعة بأحجام أكبر.

## الخطوة 3 – حفظ باركود كوكب المملوء كملف PNG

الآن احفظ الصورة على القرص. PNG يحافظ على الحواف الحادة، وهو مثالي للمسح الضوئي.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

استبدل `YOUR_DIRECTORY` بالمسار الذي أعددته مسبقًا. بعد تشغيل هذا الكود سترى ملفًا مشابهًا للصورة أدناه.

## الخطوة 4 – إنشاء باركود كوكب بأشرطة فارغة (غير مملوءة)

إذا كان مزود البريد يتطلب أن تكون الأشرطة **فارغة**، عليك تبديل علم `FilledBars` بعد تهيئة المولّد.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

المُنشئ هو نفسه؛ الاختلاف يكمن في خطوة التكوين التالية.

## الخطوة 5 – كيفية ضبط أبعاد الباركود وجعل الأشرطة فارغة

مرة أخرى، اضبط X‑dimension لتوحيد المظهر، ثم عطل الأشرطة المملوءة.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

خاصية `FilledBars = false` هي ما يغيّر نمط العرض فعليًا. الحفاظ على نفس X‑dimension يضمن أن باركود الأشرطة الفارغة يتطابق تمامًا مع النسخة المملوءة.

## الخطوة 6 – حفظ باركود كوكب الفارغ

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

ستحصل الآن على ملفي PNG: أحدهما بأشرطة صلبة والآخر بأشرطة مجوفة، كلاهما يشارك نفس الأبعاد.

## الخطوة 7 – (اختياري) إنشاء باركود RM4SCC للمقارنة

RM4SCC هو رمز بريدي آخر يستخدم نمط الأشرطة المملوءة الافتراضي. الخطوات مماثلة لمثال كوكب، مما يوضح أن **كيفية ضبط أبعاد الباركود** تعمل عبر الصيغ المختلفة.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

تشغيل هذه الخطوات الثلاث ينتج الملف `PostalRM4SCCFilledBars.png`، والذي يمكنك مقارنته جنبًا إلى جنب مع مخرجات كوكب.

## لماذا تُعد X‑dimension مهمة؟

تحدد X‑dimension **العرض القابل للطباعة الأدنى** لكل شريط. إذا ضبطتها منخفضًا جدًا، قد يصبح الباركود غير واضح على الطابعات منخفضة الدقة، مما يسبب فشل المسح. وعلى العكس، قد يتجاوز X‑dimension الكبير أبعاد الملصق ويهدر مساحة. من خلال توضيح **كيفية ضبط أبعاد الباركود**، تحصل على تحكم حتمي في حجم الصورة النهائي، وهو أمر أساسي لسير عمل البريد الآلي.

## الأخطاء الشائعة وكيفية تجنّبها

| المشكلة | السبب | الحل |
|-------|-------|-----|
| يظهر الباركود مشوهًا | تم ضبط X‑dimension بالنقاط بدلاً من البكسل | استخدم دائمًا خاصية `Pixels` للتحكم بدقة البكسل |
| الأشرطة الفارغة لا تزال تبدو مملوءة | لم يتم تعيين `FilledBars` إلى `false` بعد تغيير X‑dimension | عيّن `FilledBars = false` *بعد* ضبط X‑dimension |
| الملف المحفوظ فارغ | دليل الإخراج غير موجود أو لا يملك صلاحية كتابة | تأكد من وجود الدليل (`Directory.CreateDirectory`) وأن التطبيق يعمل بصلاحيات كافية |
| الصورة غير واضحة عند الطباعة | تم حفظ PNG بدقة DPI منخفضة من شاشة عالية الدقة | استخدم `BarCodeImageFormat.Png` (بدون فقد) وفكّر في خاصية `Resolution` إذا لزم الأمر |

## مثال كامل قابل للتنفيذ

انسخ الكتلة الكاملة أدناه إلى مشروع وحدة تحكم جديد (`dotnet new console`) وشغّله. البرنامج ينشئ ثلاثة ملفات PNG في مجلد `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**الناتج المتوقع:** ثلاثة ملفات PNG—`PostalPlanetFilledBars.png`، `PostalPlanetEmptyBars.png`، و`PostalRM4SCCFilledBars.png`—كلها بأشرطة عرضها 4 بكسل، جاهزة للطباعة أو المعالجة الإضافية.

## الخلاصة

أنت الآن تعرف **كيفية إنشاء باركود كوكب** في C# وكيفية **ضبط أبعاد الباركود** بدقة لكل من أنماط الأشرطة المملوءة والفارغة. النمط نفسه ينطبق على رموز أخرى مثل RM4SCC، مما يمنحك أساسًا مرنًا لأي متطلبات باركود بريدي.

الخطوات التالية التي قد تستكشفها:

* إضافة نص قابل للقراءة للإنسان أسفل الباركود (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* تغيير ألوان الأشرطة باستخدام `Parameters.Barcode.BarColor`
* إنشاء باركودات بصيغ متجهة (SVG, EPS) للطباعة القابلة للتوسيع

لا تتردد في تجربة قيم X‑dimension مختلفة، سلاسل البيانات، وصيغ الإخراج لتتناسب مع سير عملك الخاص. برمجة سعيدة!
