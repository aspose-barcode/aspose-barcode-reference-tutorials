# كيفية إنشاء صورة باركود في C# باستخدام DataBar Stacked Omni‑Directional

إذا كنت بحاجة إلى **كيفية إنشاء صورة باركود** في تطبيق .NET، فإن هذا الدرس يوضح الخطوات الدقيقة. ستتعرف على كيفية إنشاء باركود DataBar Stacked Omni‑Directional، وضبط نسبة الأبعاد الخاصة به، وتصدير النتيجة كملفات PNG.

إنشاء الباركودات هو مطلب شائع لأنظمة الجرد، ونقاط البيع في التجزئة، وتتبع اللوجستيات. في الأقسام التالية سنغطي كل ما تحتاجه — من حزمة NuGet المطلوبة إلى التحقق النهائي من الصورة — حتى تتمكن من دمج إنشاء الباركود في أي مشروع C# اليوم.

## المتطلبات المسبقة

* .NET 6.0 أو أحدث (الكود يعمل مع .NET Core و .NET Framework)
* Visual Studio 2022 أو أي بيئة تطوير C# تفضلها
* حزمة NuGet **Aspose.BarCode for .NET** (قم بالتثبيت باستخدام `dotnet add package Aspose.BarCode`)
* إذن كتابة إلى المجلد حيث سيتم حفظ ملفات PNG فيه

تضمن هذه المتطلبات أن يعمل المثال دون أي إعدادات إضافية.

## الخطوة 1: إعداد مجلد الإخراج

أول شيء تحتاجه هو دليل حيث سيتم كتابة ملفات PNG المُولدة. استخدام مسار مطلق أو نسبي يعمل، لكن تأكد من وجود المجلد قبل استدعاء `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

إنشاء المجلد برمجياً يمنع حدوث *FileNotFoundException* عندما تحاول طريقة `Save` كتابة الصورة.

## الخطوة 2: إنشاء مولد باركود DataBar Stacked Omni‑Directional

الفئة **BarcodeGenerator** هي نقطة الدخول لجميع أنواع الباركود. هنا نحدد `EncodeTypes.DatabarStackedOmniDirectional` وسلسلة البيانات التي نريد ترميزها.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*لماذا هذا مهم*: يحدد تعداد `EncodeTypes` للمكتبة أي رموز سيمبولوجيا يجب عرضها. استخدام النسخة Omni‑Directional يضمن إمكانية مسح الباركود من أي اتجاه — وهو مطلب للعديد من ماسحات المستودعات.

## الخطوة 3: تكوين معلمات الباركود العامة

يحتاج الباركود القابل للقراءة إلى بُعد X معقول (عرض أصغر شريط). ضبط `Pixels` إلى 2 يمنح توازناً جيداً بين الحجم والوضوح لمعظم دقات الشاشات.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

يمكنك تعديل `Pixels` لاحقاً إذا كنت بحاجة إلى صورة أكبر أو أصغر؛ المكتبة تقوم تلقائياً بتوسيع باقي الباركود.

## الخطوة 4: إنشاء الصورة الأولى بنسبة أبعاد 15

نسبة **الأبعاد** تتحكم في علاقة الارتفاع إلى العرض لباركود DataBar. نسبة أبعاد 15 هي القيمة الافتراضية الشائعة للملصقات التجزئة.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

بعد هذا الاستدعاء، ستجد `DatabarAspectRatio15.png` في مجلد الإخراج. الصورة هي PNG غير مضغوطة، مناسبة للمعالجة الإضافية أو الطباعة.

## الخطوة 5: تغيير نسبة الأبعاد إلى 30 وتصدير صورة ثانية

أحياناً يلزم باركود أطول — على سبيل المثال، عندما يكون ارتفاع الملصق محدوداً. تغيير نسبة الأبعاد إلى 30 ينتج مظهراً أكثر تكثيفاً مع الحفاظ على سلامة البيانات.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

الآن لديك ملفا PNG يوضحان كيف تبدو نفس البيانات بنسب أبعاد مختلفة. هذه المقارنة جنباً إلى جنب تساعدك على اختيار النسخة الأنسب لتصميم الملصق الخاص بك.

## مثال كامل قابل للتنفيذ

فيما يلي البرنامج الكامل الذي يمكنك نسخه، لصقه، وتشغيله. يتضمن جميع توجيهات `using`، ومعالجة الأخطاء، وتعليقات تشرح كل جزء من العملية.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**الناتج المتوقع** (الطرفية):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

افتح ملفي PNG في أي عارض صور. سترى نفس رمز GTIN مشفر، لكن الصورة الثانية أطول بسبب نسبة الأبعاد الأعلى.

## نصائح احترافية ومشكلات شائعة

| الحالة | التوصية |
|-----------|----------------|
| **شاشات منخفضة الدقة** | قم بزيادة `XDimension.Pixels` إلى 3 أو 4 للحفاظ على حدة الخطوط. |
| **الطباعة على الورق الحراري** | استخدم `BarCodeImageFormat.Tiff` للحصول على دقة أعلى واضبط `Resolution.DpiX/DpiY` إلى 300. |
| **بيانات ديناميكية** | أعد استخدام نفس كائن `BarcodeGenerator` وقم فقط بتحديث `generator.CodeText` قبل كل عملية `Save`. هذا يتجنب تخصيص كائنات غير ضرورية. |
| **GTIN غير صالح** | المكتبة ترمي `ArgumentException` إذا لم تتطابق البيانات مع معايير GS1. تحقق من صحة بياناتك قبل تمريرها إلى المولد. |

## الخلاصة

أنت الآن تعرف **كيفية إنشاء صورة باركود** في C# باستخدام Aspose.BarCode، وكيفية التحكم في نسبة أبعاد DataBar Stacked Omni‑Directional، وكيفية تصدير النتيجة كملفات PNG. يغطي هذا المثال الشامل التثبيت، والتكوين، ومعالجة الأخطاء، مما يمنحك أساساً قوياً لأي ميزة متعلقة بالباركود.

بعد ذلك، قد ترغب في استكشاف:

* **معالجة دفعات** لعدة سلاسل بيانات وحفظها في ملف PDF متعدد الصفحات واحد.

لا تتردد في تجربة `EncodeTypes` مختلفة، وصيغ الصور، وإعدادات الدقة لتتناسب مع متطلبات مشروعك الدقيقة. برمجة سعيدة!
