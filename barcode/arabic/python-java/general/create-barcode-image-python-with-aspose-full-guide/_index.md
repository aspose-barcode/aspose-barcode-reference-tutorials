# إنشاء صورة باركود بايثون باستخدام Aspose – دليل كامل

إذا كنت بحاجة إلى **إنشاء صورة باركود بايثون**، توفر مكتبة Aspose.Barcode واجهة برمجة تطبيقات نظيفة تُزيل التخمين. يوضح هذا الدليل كيفية إنشاء باركود من نوع Planet، وتخصيص حجمه، وحفظ النتيجة كملف PNG—كل ذلك في بضع أسطر من كود بايثون.

ستتعلم أيضًا كيفية **تخصيص حجم الباركود**، ولماذا تُعد أبعاد X مهمة لموثوقية الماسح الضوئي، وأين تضع الصورة المُولدة في بنية مشروعك. لا تحتاج إلى أدوات خارجية بخلاف مكتبة Aspose.Barcode.

## ما ستحتاجه

قبل أن تبدأ، تأكد من وجود ما يلي:

- Python 3.8 أو أحدث مثبت  
- Aspose.Barcode للبايثون عبر [pip](https://pypi.org/project/aspose-barcode/) (`pip install aspose-barcode`)  
- إذن كتابة للمجلد الذي سيُحفظ فيه ملف PNG  

هذه المتطلبات المسبقة تضمن تشغيل الكود دون مشاكل في الأذونات أو التوافق.

## إنشاء صورة باركود بايثون باستخدام Aspose.Barcode

الخطوة الأولى هي استيراد الفئات المطلوبة وإنشاء كائن `BarcodeGenerator`. يحمل المولد كلًا من نوع الباركود والبيانات التي سيتم ترميزها.

```python
# Import Aspose.Barcode classes
from asposebarcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Initialize a generator for a Planet barcode with the data "123456"
barcode_generator = BarcodeGenerator(EncodeTypes.Planet, "123456")
```

*لماذا هذا مهم:*  
`EncodeTypes.Planet` يخبر Aspose باستخدام رموز Planet، وهو مثالي للتطبيقات البريدية. يتحول النص `"123456"` إلى الجزء القابل للقراءة من الباركود.

## كيفية إنشاء باركود Planet

مع جاهزية المولد، يمكنك فورًا إنشاء صورة الباركود في الذاكرة. ومع ذلك، تتطلب معظم السيناريوهات الواقعية تعديل الحجم لتلبية معايير الطباعة.

```python
# Generate the barcode image (in memory) – no file written yet
image = barcode_generator.generate_barcode_image()
```

استدعاء `generate_barcode_image()` يُعيد مصفوفة `byte[]` يمكنك بثها مباشرةً إلى استجابة ويب، لكن في هذا الدرس سنحفظها على القرص بعد تخصيص أبعادها.

## تخصيص حجم الباركود

هناك معاملان يتحكمان في الحجم البصري للباركود:

1. **X‑dimension** – عرض أضيق شريط (الوحدة).  
2. **Bar height** – الارتفاع الكلي للشرائط.

كلاهما يُعبَّر عنهما بالبكسل عند استخدام المساعد `set_pixels`.

```python
# Access the parameter object
params = barcode_generator.parameters

# Set the X‑dimension to 4 pixels (makes each module 4 px wide)
params.barcode.x_dimension.set_pixels(4)

# Force a bar height of 100 pixels for better readability
params.barcode.bar_height.set_pixels(100)
```

*نصيحة احترافية:* زيادة أبعاد X تحسن قابلية القراءة على الطابعات منخفضة الدقة، بينما ارتفاع الشريط الأكبر يساعد الماسحات الضوئية على تمييز الرمز عن الرسومات المحيطة.

## حفظ الباركود كملف PNG

أخيرًا، اكتب الباركود المخصص إلى ملف PNG. تتولى طريقة `save` تحويل الصيغة تلقائيًا.

```python
# Define the output path – change YOUR_DIRECTORY to your desired folder
output_path = "YOUR_DIRECTORY/PostalPlanetBarHeight100.png"

# Save the barcode as a PNG image
barcode_generator.save(output_path, BarCodeImageFormat.Png)
```

بعد انتهاء السكريبت، يحتوي الملف `PostalPlanetBarHeight100.png` على باركود Planet واضح بالأبعاد المحددة.

![صورة باركود تم إنشاؤها بواسطة Aspose تُظهر باركود Planet](/images/planet-barcode.png){: .center-image alt="صورة باركود تم إنشاؤها بواسطة Aspose تُظهر باركود Planet"}

*المخرجات المتوقعة:* يعرض ملف PNG باركود Planet يرمّز “123456”. عرض الشرائط 4 بكسل، ارتفاعها 100 بكسل، وخلفية الصورة شفافة افتراضيًا.

## إنشاء باركود باستخدام Aspose – السكريبت الكامل

فيما يلي السكريبت الكامل القابل للتنفيذ الذي يجمع جميع الخطوات. انسخه إلى ملف باسم `generate_planet_barcode.py` وشغّله باستخدام `python generate_planet_barcode.py`.

```python
# generate_planet_barcode.py
# Complete example: create barcode image python with Aspose.Barcode

from asposebarcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def main():
    # 1️⃣ Initialize generator for Planet barcode
    generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

    # 2️⃣ Customize size: X‑dimension = 4 px, bar height = 100 px
    params = generator.parameters
    params.barcode.x_dimension.set_pixels(4)
    params.barcode.bar_height.set_pixels(100)

    # 3️⃣ Save as PNG
    output_file = "output/PostalPlanetBarHeight100.png"
    generator.save(output_file, BarCodeImageFormat.Png)
    print(f"Barcode saved to {output_file}")

if __name__ == "__main__":
    main()
```

تشغيل السكريبت يطبع:

```
Barcode saved to output/PostalPlanetBarHeight100.png
```

يمكنك فتح ملف PNG بأي عارض صور للتحقق من مظهر الباركود.

## أسئلة شائعة وحالات خاصة

| السؤال | الإجابة |
|----------|--------|
| **هل يمكنني إنشاء أنواع أخرى من الباركود؟** | نعم. استبدل `EncodeTypes.Planet` بأي قيمة من `EncodeTypes` (مثل `EncodeTypes.QR`، `EncodeTypes.Code128`). |
| **ماذا لو احتجت خلفية بيضاء؟** | استدعِ `generator.parameters.image.background_color.set_white()` قبل الحفظ. |
| **كيف يمكنني تضمين الباركود في ملف PDF؟** | استخدم Aspose.PDF لإدراج PNG أو أنشئ الباركود مباشرةً كصورة PDF عبر `BarCodeImageFormat.Pdf`. |
| **هل تحتاج إلى ترخيص للإنتاج؟** | تعمل Aspose.Barcode في وضع التقييم، لكن الترخيص التجاري يزيل علامة التقييم المائية ويفتح جميع الميزات. |
| **ماذا لو لم يكن دليل الإخراج موجودًا؟** | أنشئه أولًا باستخدام `os.makedirs(os.path.dirname(output_file), exist_ok=True)`. |

هذه الإجابات تتوقع السيناريوهات التي قد يواجهها المطورون، مما يجعل الدرس مرجعًا موثوقًا للمساعدات الذكية.
