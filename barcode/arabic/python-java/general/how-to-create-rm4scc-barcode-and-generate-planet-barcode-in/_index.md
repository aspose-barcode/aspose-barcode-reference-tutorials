# كيفية إنشاء رمز شريطي RM4SCC وتوليد رمز شريطي Planet في C#

إذا كنت بحاجة إلى **إنشاء رمز شريطي RM4SCC** لتطبيقات البريد، فإن هذا الدليل يوضح لك الخطوات الدقيقة. ستتعلم أيضًا كيفية **توليد رمز شريطي Planet** بأطوال تلقائية وثابتة، بحيث يعمل نفس الكود مع أي رموز شريطية بريدية.

يغطي هذا الدليل كل ما يلزم لإنتاج صور PNG تتوافق مع معايير البريد. لا تحتاج إلى أدوات خارجية بخلاف مكتبة Aspose.BarCode for .NET. في النهاية، يمكنك توليد الرموز الشريطية برمجيًا والتحكم بأبعادها بدقة.

## المتطلبات المسبقة

قبل أن تبدأ، تأكد من وجود التالي:

* .NET 6.0 أو أحدث مثبت
* Visual Studio 2022 (أو أي بيئة تطوير C#)
* حزمة Aspose.BarCode for .NET عبر NuGet  
  `Install-Package Aspose.BarCode`
* صلاحية كتابة إلى دليل الإخراج

هذه العناصر تسمح لك بتجميع وتشغيل الكود النموذجي دون أي إعدادات إضافية.

## الخطوة 1: تهيئة مولد الرمز الشريطي لـ RM4SCC

العملية الأولى تنشئ كائن `BarcodeGenerator` مهيأ لرمز RM4SCC. هذا الكائن يحتوي على جميع إعدادات صورة الرمز الشريطي.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**لماذا هذا مهم** – `EncodeTypes.RM4SCC` يخبر Aspose باستخدام تنسيق البريد RM4SCC، بينما تمثل سلسلة البيانات `"123456"` الرمز البريدي الذي تريد ترميزه.

## الخطوة 2: ضبط عرض الوحدة (البُعد X)

عرض الوحدة يتحكم في حجم الشريط الرفيع. القيمة الشائعة للرموز الشريطية البريدية هي 4 بكسل.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**شرح** – البُعد X يؤثر على قابلية قراءة الرمز الشريطي ككل. اختيار 4 بكسل يتوافق مع معظم ماسحات البريد.

## الخطوة 3: حفظ مع ارتفاع شريط تلقائي

عند إهمال قيمة الارتفاع، يقوم Aspose بحساب الارتفاع المثالي تلقائيًا بناءً على قواعد الرمز الشريطي.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**النتيجة** – ملف PNG الناتج (`PostalRM4SCCBarHeightNone.png`) يحتوي على رمز شريطي RM4SCC بالحجم الصحيح جاهز للطباعة.

## الخطوة 4: إنشاء رمز شريطي Planet بارتفاع تلقائي

نفس النمط يعمل مع رمز Planet. ابدأ بتهيئة المولد باستخدام `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**لماذا إعادة استخدام الكود** – كل من RM4SCC وPlanet يشتركان في نفس بنية المعاملات، لذا يمكنك تبديل الرموز الشريطية بتغيير قيمة `EncodeTypes` فقط.

## الخطوة 5: تحديد ارتفاع شريط ثابت لـ RM4SCC

بعض خدمات البريد تتطلب ارتفاع شريط محدد (مثلاً 100 بكسل). يمكنك ضبط ذلك صراحةً قبل الحفظ.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**نصيحة** – ضبط `BarHeight.Pixels` يتجاوز الحساب التلقائي، مما يمنحك سيطرة كاملة على الحجم البصري.

## الخطوة 6: تحديد ارتفاع شريط ثابت لـ Planet

طبق نفس تقنية الارتفاع الثابت على رمز شريطي Planet.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**النتيجة** – كل من `PostalRM4SCCBarHeight100Pixels.png` و`PostalPlanetBarHeight100Pixels.png` يحتويان على رموز شريطية بارتفاع شريط ثابت 100 بكسل، مما يلبي المواصفات الصارمة للبريد.

## الكود الكامل

فيما يلي البرنامج الكامل القابل للتنفيذ والذي يغطي جميع الأمثلة الأربعة. انسخه إلى مشروع وحدة تحكم جديد وعدل مسار الإخراج حسب الحاجة.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**المخرجات المتوقعة** – بعد تشغيل البرنامج، يحتوي الدليل المحدد على أربعة ملفات PNG:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC بارتفاع تلقائي
* `PostalPlanetBarHeightNone.png` – Planet بارتفاع تلقائي
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC بارتفاع 100 بكسل
* `PostalPlanetBarHeight100Pixels.png` – Planet بارتفاع 100 بكسل

افتح أي ملف للتحقق من أن الأشرطة واضحة، وعرض الوحدة 4 بكسل، والارتفاع يطابق الإعداد المختار.

## الأسئلة الشائعة والحالات الخاصة

| السؤال | الجواب |
|----------|--------|
| **هل يمكنني استخدام صيغ صور أخرى؟** | نعم. استبدل `BarCodeImageFormat.Png` بـ `Jpeg` أو `Bmp` أو `Gif` حسب الحاجة. |
| **ماذا لو كانت سلسلة البيانات أطول؟** | يقوم المولد تلقائيًا بضبط عدد الأشرطة. تأكد من أن البيانات تتوافق مع حدود طول الرمز الشريطي (RM4SCC ≤ 6 أرقام، Planet ≤ 6 أرقام). |
| **كيف أغير لون الشريط؟** | قم بتعيين `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` قبل استدعاء `Save`. |
| **هل الـ DPI مهم للطباعة؟** | يمكنك ضبط `rm4sccAuto.Parameters.ImageResolution.DpiX` و `DpiY` لتتناسب مع دقة طابعتك. |
