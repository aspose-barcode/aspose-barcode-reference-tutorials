# كيفية إنشاء ملف PNG للباركود باستخدام بايثون – دليل خطوة بخطوة

إذا كنت بحاجة إلى **إنشاء ملفات PNG للباركود** من سلاسل نصية عشوائية، فإن هذا الدليل يقدم لك حلاً جاهزًا للتنفيذ. ستتعرف على كيفية توليد باركود Code 128، وتحويل النص إلى صورة باركود، وتخزين النتيجة كملف PNG—كل ذلك ببضع أسطر من بايثون.

يغطي الدليل كل ما تحتاج معرفته، من تثبيت المكتبة المطلوبة إلى تخصيص المخرجات لحالات الاستخدام المختلفة. في النهاية، ستتمكن من دمج توليد الباركود في أي مشروع بايثون دون الحاجة للبحث عن وثائق إضافية.

## ما ستتعلمه

* تثبيت حزمة **barcode generator python** التي تدعم Code 128.
* استخدام `BarCodeGenerator` لت **إنشاء باركود code 128** من سلسلة نصية.
* حفظ النتيجة كملف PNG عالي الجودة باستخدام `save`.
* ضبط حجم الصورة، ألوان المقدمة/الخلفية، ومعالجة الأخطاء الشائعة.
* التحقق من أن ملف PNG تم إنشاؤه بشكل صحيح.

### المتطلبات المسبقة

| المتطلب | السبب |
|-------------|--------|
| Python 3.8+ | بناء جملة حديث وتلميحات نوع |
| Internet access (for `pip install`) | لتنزيل المكتبة |
| Write permission to a folder | لتخزين ملف PNG المُولد |

لا توجد خدمات خارجية مطلوبة؛ كل شيء يعمل محليًا.

## الخطوة 1: تثبيت مكتبة الباركود

أسهل طريقة **لتحويل النص إلى باركود** في بايثون هي استخدام حزمة **Aspose.BarCode for Python via .NET**، التي تدعم Code 128 مباشرةً.

```bash
pip install aspose-barcode
```

> **نصيحة احترافية:** إذا كنت تعمل في بيئة افتراضية، فعّلها قبل تشغيل الأمر للحفاظ على عزل الاعتمادات.

## الخطوة 2: استيراد الفئات التي تحتاجها

بعد التثبيت، استورد الفئات الأساسية. عبارات الاستيراد قصيرة، مما يجعل الشيفرة سهلة القراءة.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` ينشئ صورة الباركود.
* `EncodeTypes` يوفر تعدادًا للرموز المدعومة، بما في ذلك `CODE_128`.

## الخطوة 3: تعريف النص الذي تريد ترميزه

اختر أي سلسلة أبجدية رقمية. يمكن لـ Code 128 تمثيل مجموعة ASCII الكاملة، لذا لست مقيدًا بالأرقام فقط.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

إذا كان الإدخال يحتوي على أحرف غير مدعومة، سيُطلق المولد استثناءً `ValueError`. غلف عملية الإسناد داخل كتلة `try` إذا كنت تتوقع بيانات مقدمة من المستخدم.

## الخطوة 4: إنشاء مولد الباركود لـ Code 128

قم بإنشاء كائن `BarCodeGenerator` مع الرمز المطلوب والنص الذي عرّفته. هذا هو جوهر **كيفية إنشاء صور باركود** في بايثون.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

لماذا Code 128؟ لأنه يوفر كثافة عالية ويمكنه ترميز نطاق ASCII الكامل، مما يجعله مثاليًا لأنظمة الجرد، ملصقات الشحن، وتذاكر الدخول.

## الخطوة 5: (اختياري) تخصيص المظهر

يمكنك ضبط الباركود بدقة قبل حفظه. الخيارات التالية شائعة:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

هذه الإعدادات تؤثر على مخرجات **create barcode png** النهائية دون تعديل البيانات المشفرة.

## الخطوة 6: حفظ الباركود كملف PNG

أخيرًا، احفظ الصورة على القرص. طريقة `save` تكتشف امتداد الملف تلقائيًا، لذا تمرير `.png` يُنشئ صورة PNG.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

إذا لم يكن الدليل الهدف موجودًا، يرفع بايثون استثناءً `FileNotFoundError`. أنشئ الدليل مسبقًا أو استخدم `os.makedirs` مع `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### النتيجة المتوقعة

بعد تشغيل السكريبت، ستجد `extended_barcode.png` في مجلد `output`. فتح الملف يعرض باركود Code 128 واضح يُشفّر `1234567890`.

![باركود PNG تم إنشاؤه باستخدام بايثون](generated_barcode.png "مثال على إنشاء باركود PNG")

*نص بديل:* **create barcode PNG** تم إنشاؤه بواسطة بايثون باستخدام Aspose.BarCode.

## الخطوة 7: التحقق من الباركود (فحص سريع للمنطقية)

يمكنك قراءة ملف PNG مرة أخرى باستخدام نفس المكتبة لتأكيد أن القيمة المشفرة تطابق النص الأصلي.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

تشغيل هذه الكتلة يطبع:

```
Verification succeeded: 1234567890
```

إذا فشل التحقق، أعد فحص `barcode_text` وأي معلمات مخصصة قمت بتعيينها.

## الاختلافات الشائعة وحالات الحافة

| الحالة | التعديل |
|-----------|------------|
| **نص أطول (> 20 حرفًا)** | زيادة `image_width` لتجنب القطع. |
| **الحاجة إلى خلفية شفافة** | تعيين `back_color = "Transparent"` قبل الحفظ. |
| **إنشاء عدة باركودات في حلقة** | غلف الخطوات 3‑6 داخل حلقة `for`، مع تغيير `barcode_text` في كل تكرار. |
| **حفظ كـ JPEG بدلاً من PNG** | تغيير امتداد الملف إلى `.jpg`؛ المكتبة تتعامل مع الصيغة تلقائيًا. |
| **التشغيل على خادم بدون واجهة** | المكتبة لا تحتاج إلى واجهة رسومية، مما يجعلها آمنة لأنابيب CI. |

## السكريبت الكامل للنسخ السريع

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

احفظ السكريبت باسم `generate_barcode.py` وشغّله:

```bash
python generate_barcode.py
```

سترى رسائل التأكيد وملف PNG جديد في مجلد `output`.
