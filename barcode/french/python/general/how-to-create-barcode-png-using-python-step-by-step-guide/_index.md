# Comment créer un fichier PNG de code‑barres avec Python – guide étape par étape

Si vous devez **créer des fichiers PNG de code‑barres** à partir de chaînes arbitraires, ce tutoriel vous fournit une solution prête à l’emploi. Vous verrez exactement comment générer un code‑barres Code 128, convertir du texte en image de code‑barres et enregistrer le résultat sous forme de fichier PNG — le tout en quelques lignes de Python.

Le guide couvre tout ce que vous devez savoir, de l’installation de la bibliothèque requise à la personnalisation du résultat pour différents cas d’utilisation. À la fin, vous pourrez intégrer la génération de code‑barres dans n’importe quel projet Python sans chercher de documentation supplémentaire.

## Ce que vous allez apprendre

* Installer le package **barcode generator python** qui prend en charge Code 128.
* Utiliser `BarCodeGenerator` pour **générer un code‑barres code 128** à partir d’une chaîne de texte.
* Enregistrer le résultat en PNG de haute qualité avec `save`.
* Ajuster la taille de l’image, les couleurs de premier plan/arrière‑plan, et gérer les erreurs courantes.
* Vérifier que le PNG a été créé correctement.

### Prérequis

| Exigence | Raison |
|----------|--------|
| Python 3.8+ | Syntaxe moderne et annotations de type |
| Accès Internet (pour `pip install`) | Pour télécharger la bibliothèque |
| Permission d’écriture sur un dossier | Pour stocker le PNG généré |

Aucun service externe n’est requis ; tout s’exécute localement.

## Étape 1 : Installer la bibliothèque de code‑barres

La façon la plus simple de **convertir du texte en code‑barres** en Python est d’utiliser le package **Aspose.BarCode for Python via .NET**, qui supporte Code 128 dès le départ.

```bash
pip install aspose-barcode
```

> **Astuce :** Si vous travaillez dans un environnement virtuel, activez‑le avant d’exécuter la commande afin de garder les dépendances isolées.

## Étape 2 : Importer les classes nécessaires

Après l’installation, importez les classes principales. Les instructions d’importation sont courtes, ce qui rend le code facile à lire.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` crée l’image du code‑barres.
* `EncodeTypes` fournit une énumération des symbologies prises en charge, dont `CODE_128`.

## Étape 3 : Définir le texte à encoder

Choisissez n’importe quelle chaîne alphanumérique. Code 128 peut représenter l’ensemble complet ASCII, vous n’êtes donc pas limité aux chiffres.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Si l’entrée contient des caractères non pris en charge, le générateur lève une `ValueError`. Enveloppez l’affectation dans un bloc `try` si vous attendez des données fournies par l’utilisateur.

## Étape 4 : Créer le générateur de code‑barres pour Code 128

Instanciez `BarCodeGenerator` avec la symbologie souhaitée et le texte que vous avez défini. C’est le cœur du **comment générer des images de code‑barres** en Python.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Pourquoi Code 128 ? Il offre une haute densité et peut encoder toute la plage ASCII, ce qui le rend idéal pour les systèmes d’inventaire, les étiquettes d’expédition et la billetterie.

## Étape 5 : (Facultatif) Personnaliser l’apparence

Vous pouvez affiner le code‑barres avant de l’enregistrer. Les options suivantes sont courantes :

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Ces réglages influencent le résultat final du **create barcode png** sans modifier les données encodées.

## Étape 6 : Enregistrer le code‑barres en fichier PNG

Enfin, écrivez l’image sur le disque. La méthode `save` détecte automatiquement l’extension du fichier, donc passer `.png` crée une image PNG.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Si le répertoire cible n’existe pas, Python lève une `FileNotFoundError`. Créez le répertoire au préalable ou utilisez `os.makedirs` avec `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### Résultat attendu

Après l’exécution du script, vous trouverez `extended_barcode.png` dans le dossier `output`. L’ouverture du fichier montre un code‑barres Code 128 net qui encode `1234567890`.

![Generated barcode PNG created with Python](generated_barcode.png "exemple de création de code‑barres png")

## Étape 7 : Vérifier le code‑barres (vérification rapide)

Vous pouvez relire le PNG avec la même bibliothèque pour confirmer que la valeur encodée correspond au texte original.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

L’exécution de ce bloc affiche :

```
Verification succeeded: 1234567890
```

Si l’assertion échoue, revérifiez `barcode_text` et les paramètres personnalisés que vous avez définis.

## Variations courantes et cas limites

| Situation | Ajustement |
|-----------|------------|
| **Texte plus long (> 20 caractères)** | Augmentez `image_width` pour éviter la troncature. |
| **Besoin d’un arrière‑plan transparent** | Définissez `back_color = "Transparent"` avant l’enregistrement. |
| **Générer plusieurs codes‑barres dans une boucle** | Enveloppez les étapes 3‑6 dans une boucle `for`, en changeant `barcode_text` à chaque itération. |
| **Enregistrer en JPEG au lieu de PNG** | Changez l’extension du fichier en `.jpg` ; la bibliothèque gère automatiquement le format. |
| **Exécution sur un serveur sans interface graphique** | La bibliothèque ne nécessite pas d’interface GUI, ce qui la rend sûre pour les pipelines CI. |

## Script complet à copier‑coller

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Enregistrez le script sous le nom `generate_barcode.py` et exécutez :

```bash
python generate_barcode.py
```

Vous verrez les messages de confirmation ainsi qu’un nouveau fichier PNG dans le dossier `output`.

## Conclusion

Vous savez maintenant comment **créer des fichiers PNG de code‑barres** en Python, depuis l’installation du package **barcode generator python** jusqu’à la personnalisation de l’apparence et la vérification du résultat. Le même schéma fonctionne pour n’importe quelle donnée Code 128, vous permettant d’intégrer la création de code‑barres dans des systèmes d’inventaire, des services web ou des générateurs de rapports automatisés.

### Prochaines étapes

* Explorez d’autres symbologies comme le **QR Code** ou **EAN‑13** en modifiant `EncodeTypes`.
* Intégrez le script dans un point de terminaison Flask ou FastAPI pour générer des code‑barres à la demande.
* Combinez le PNG avec des bibliothèques de génération PDF (par ex., `ReportLab`) pour des étiquettes imprimables.

N’hésitez pas à expérimenter avec les schémas de couleurs, les tailles et le traitement par lots — votre nouveau flux de création de code‑barres est prêt pour la production. Bon codage !
