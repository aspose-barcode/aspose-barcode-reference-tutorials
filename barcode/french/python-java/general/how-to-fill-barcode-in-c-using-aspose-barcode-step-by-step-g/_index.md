# Comment remplir un code-barres en C# avec Aspose.BarCode

Si vous avez besoin de **remplir un code-barres** dans une application .NET, ce tutoriel montre le processus complet. Vous générerez un code-barres postal Planet avec des barres pleines, puis créerez une version à barres vides du même code-barres, le tout avec un seul changement de ligne de code.

Le guide couvre tout ce que vous devez savoir : configuration du projet, réglage de la X‑dimension, basculement entre barres pleines et vides, et comment vérifier les fichiers PNG générés. Aucune documentation externe n’est requise — il suffit de copier le code, de l’exécuter, et vous verrez le résultat.

## Prérequis

* SDK .NET 6.0 ou version ultérieure installé  
* Un environnement de développement tel que Visual Studio 2022 ou VS Code  
* Le package NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

Ces éléments constituent la base minimale pour la partie **barcode generator c#** du tutoriel.

## Comment remplir le code-barres – configurer le projet

1. Créez un nouveau projet console :

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Ajoutez le package Aspose.BarCode :

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Ouvrez le fichier `Program.cs` généré et remplacez son contenu par l’exemple complet présenté plus loin dans cet article.

Le projet contient maintenant tout ce qui est nécessaire pour **générer des images de code-barres postal**.

## Générer un code-barres postal avec des barres pleines

La première étape consiste à créer un code-barres Planet qui utilise des barres remplies (solides). Planet est la symbologie utilisée par de nombreux services postaux pour le tri.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Pourquoi ces lignes sont importantes**

* `EncodeTypes.Planet` indique au générateur quelle symbologie utiliser ; Planet est la norme pour les codes-barres postaux.  
* `XDimension.Pixels = 4` augmente la largeur du module, rendant le code-barres plus facile à scanner et visuellement plus clair à l’impression.  
* `Save` écrit l’image sur le disque au format PNG, un format sans perte adapté au traitement ultérieur.

L’exécution de ce bloc produit **PostalPlanetFilledBars.png**, une image avec des barres pleines qui respecte les spécifications postales.

## Créer un code-barres vide en utilisant la symbologie Planet

Parfois, un système postal attend que les barres soient vides (non remplies) tandis que les espaces restent solides. Passer à ce mode ne nécessite qu’un seul changement de propriété.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Pourquoi cela fonctionne**

Définir `FilledBars = false` indique au rendu d’inverser le style visuel : les barres deviennent transparentes (vides) et l’arrière‑plan devient opaque. C’est exactement le contraire du comportement par défaut démontré précédemment, vous permettant de **créer des images de code-barres vide** sans modifier les données encodées.

## Exemple complet et exécutable

Voici le programme complet qui combine les deux sections. Copiez‑le dans `Program.cs`, remplacez `YOUR_DIRECTORY/` par un chemin de dossier réel, et exécutez `dotnet run`.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Résultat attendu

Après l’exécution, vous trouverez deux fichiers PNG dans le dossier spécifié :

| Nom du fichier                     | Description visuelle |
|-----------------------------------|-----------------------|
| `PostalPlanetFilledBars.png`      | Barres noires pleines sur fond blanc |
| `PostalPlanetEmptyBars.png`       | Barres transparentes (blanches) sur fond noir |

Les deux images encodent la même chaîne numérique "123456" et partagent la même X‑dimension, garantissant qu’elles sont interchangeables du point de vue de la validation des données.

## Questions fréquentes et cas particuliers

**Que se passe-t-il si le dossier de sortie n’existe pas ?**  
La méthode `Save` lève une `DirectoryNotFoundException`. Créez le dossier au préalable ou encapsulez les appels dans un bloc `try / catch` qui crée le répertoire si nécessaire :

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Puis‑je utiliser un autre format d’image ?**  
Oui. Remplacez `BarCodeImageFormat.Png` par `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp`, ou tout autre format pris en charge par Aspose.BarCode.

**La X‑dimension affecte‑t‑elle la lisibilité par le scanner ?**  
Augmenter la largeur en pixels rend les barres plus larges, ce qui peut améliorer la lisibilité sur des scanners à faible résolution. Cependant, des valeurs très élevées peuvent dépasser la zone imprimable. Les valeurs typiques varient de 2 à 6 pixels pour une impression à 300 dpi.

**La symbologie `EncodeTypes.Planet` est‑elle la seule option postale ?**  
Non. Aspose.BarCode prend également en charge `EncodeTypes.Postnet` et `EncodeTypes.USPSIntelligentMail`. La même propriété `FilledBars` fonctionne avec ces types également.

Vous savez maintenant comment **remplir des images de code-barres** en C# avec la bibliothèque Aspose.BarCode, comment **générer des variantes de code-barres postal**, et comment **créer des versions de code-barres vide** en utilisant la symbologie Planet. En ajustant la X‑dimension, vous contrôlez la clarté visuelle, et un seul changement de propriété bascule entre barres pleines et vides sans modifier les données encodées.
