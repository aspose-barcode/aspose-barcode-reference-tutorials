# Comment générer une image de code‑barres en C# avec DataBar Stacked Omni‑Directional

Si vous avez besoin de **comment générer une image de code‑barres** dans une application .NET, ce tutoriel montre les étapes exactes. Vous verrez comment créer un code‑barres DataBar Stacked Omni‑Directional, ajuster son ratio d’aspect et exporter le résultat sous forme de fichiers PNG.

La génération de codes‑barres est une exigence courante pour les systèmes d’inventaire, les terminaux de point de vente et le suivi logistique. Dans les sections suivantes, nous couvrirons tout ce dont vous avez besoin — du package NuGet requis à la vérification finale de l’image — afin que vous puissiez intégrer la création de codes‑barres dans n’importe quel projet C# dès aujourd’hui.

## Prérequis

Avant de commencer, assurez‑vous d’avoir :

* .NET 6.0 ou version ultérieure (le code fonctionne avec .NET Core et .NET Framework)
* Visual Studio 2022 ou tout IDE C# de votre choix
* Le package NuGet **Aspose.BarCode for .NET** (installez‑le avec `dotnet add package Aspose.BarCode`)
* Des droits d’écriture sur le dossier où les fichiers PNG seront enregistrés

Ces prérequis garantissent que l’exemple s’exécute sans configuration supplémentaire.

## Étape 1 : Configurer le dossier de sortie

La première chose dont vous avez besoin est un répertoire où les fichiers PNG générés seront écrits. Un chemin absolu ou relatif fonctionne, mais assurez‑vous que le dossier existe avant d’appeler `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Créer le dossier par programme évite le *FileNotFoundException* lorsque la méthode `Save` tente d’écrire l’image.

## Étape 2 : Créer un générateur de code‑barres DataBar Stacked Omni‑Directional

La classe **BarcodeGenerator** est le point d’entrée pour tous les types de codes‑barres. Ici nous spécifions `EncodeTypes.DatabarStackedOmniDirectional` et la chaîne de données que nous voulons encoder.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Pourquoi c’est important* : l’énumération `EncodeTypes` indique à la bibliothèque quelle symbologie rendre. Utiliser la variante Omni‑Directional garantit que le code‑barres peut être scanné sous n’importe quelle orientation — une exigence pour de nombreux scanners d’entrepôt.

## Étape 3 : Configurer les paramètres communs du code‑barres

Un code‑barres lisible nécessite une dimension X raisonnable (la largeur de la plus petite barre). Fixer `Pixels` à 2 offre un bon compromis entre taille et netteté pour la plupart des résolutions d’écran.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Vous pouvez ajuster `Pixels` plus tard si vous avez besoin d’une image plus grande ou plus petite ; la bibliothèque met automatiquement à l’échelle le reste du code‑barres.

## Étape 4 : Générer la première image avec un ratio d’aspect 15

Le **ratio d’aspect** contrôle la relation hauteur‑largeur des codes‑barres DataBar. Un ratio d’aspect de 15 est la valeur par défaut typique pour les étiquettes de détail.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Après cet appel, vous trouverez `DatabarAspectRatio15.png` dans le dossier de sortie. L’image est un PNG sans perte, adaptée à un traitement ultérieur ou à l’impression.

## Étape 5 : Modifier le ratio d’aspect à 30 et exporter une seconde image

Parfois, un code‑barres plus haut est requis — par exemple lorsque la hauteur de l’étiquette est limitée. Passer le ratio d’aspect à 30 produit un rendu plus compact tout en préservant l’intégrité des données.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Vous disposez maintenant de deux fichiers PNG illustrant comment les mêmes données apparaissent avec des ratios d’aspect différents. Cette comparaison côte à côte vous aide à choisir la variante qui convient le mieux à la mise en page de votre étiquette.

## Exemple complet, exécutable

Voici le programme complet que vous pouvez copier, coller et exécuter. Il inclut toutes les directives `using`, la gestion des erreurs et des commentaires expliquant chaque partie du processus.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Sortie attendue** (console) :

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Ouvrez les deux fichiers PNG avec n’importe quel visualiseur d’images. Vous verrez le même GTIN encodé, mais la seconde image est plus haute en raison du ratio d’aspect supérieur.

## Astuces professionnelles et pièges courants

| Situation | Recommandation |
|-----------|----------------|
| **Écrans basse résolution** | Augmentez `XDimension.Pixels` à 3 ou 4 pour garder les barres nettes. |
| **Impression sur papier thermique** | Utilisez `BarCodeImageFormat.Tiff` pour une fidélité supérieure et définissez `Resolution.DpiX/DpiY` à 300. |
| **Données dynamiques** | Réutilisez la même instance `BarcodeGenerator` et ne mettez à jour que `generator.CodeText` avant chaque `Save`. Cela évite des allocations d’objets inutiles. |
| **GTIN invalide** | La bibliothèque lève une `ArgumentException` si les données ne respectent pas les normes GS1. Validez vos données avant de les transmettre au générateur. |
