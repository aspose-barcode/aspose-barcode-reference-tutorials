# Comment créer un code‑barres RM4SCC et générer un code‑barres Planet en C#

Si vous devez **créer un code‑barres RM4SCC** pour des applications postales, ce guide vous montre les étapes exactes. Vous apprendrez également comment **générer un code‑barres Planet** avec des hauteurs automatiques et fixes, de sorte que le même code fonctionne pour n’importe quel symbologie postale.

Le tutoriel couvre tout ce qui est nécessaire pour produire des images PNG conformes aux normes postales. Aucun outil externe n’est requis en dehors de la bibliothèque Aspose.BarCode for .NET. À la fin, vous pourrez générer des codes‑barres programmatiquement et contrôler leurs dimensions avec précision.

## Prérequis

Avant de commencer, assurez‑vous d’avoir :

* .NET 6.0 ou version ultérieure installé
* Visual Studio 2022 (ou tout IDE C#)
* Package NuGet Aspose.BarCode for .NET  
  `Install-Package Aspose.BarCode`
* Permission d’écriture sur le répertoire de sortie

Ces éléments vous permettent de compiler et d’exécuter le code d’exemple sans configuration supplémentaire.

## Étape 1 : Initialiser le générateur de code‑barres pour RM4SCC

La première opération crée une instance de `BarcodeGenerator` configurée pour la symbologie RM4SCC. Cet objet contient tous les paramètres de l’image du code‑barres.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Pourquoi c’est important** – `EncodeTypes.RM4SCC` indique à Aspose d’utiliser le format postal RM4SCC, tandis que la chaîne de données `"123456"` représente le code postal que vous souhaitez encoder.

## Étape 2 : Définir la largeur du module (dimension X)

La largeur du module contrôle la taille de la barre fine. Une valeur courante pour les codes‑barres postaux est de 4 pixels.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Explication** – La dimension X influence la lisibilité globale du code‑barres. Choisir 4 px correspond à la plupart des scanners postaux.

## Étape 3 : Enregistrer avec une hauteur de barre automatique

Lorsque vous omettez une valeur de hauteur, Aspose calcule automatiquement la hauteur optimale en fonction des règles de la symbologie.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Résultat** – Le PNG généré (`PostalRM4SCCBarHeightNone.png`) contient un code‑barres RM4SCC correctement dimensionné, prêt à être imprimé.

## Étape 4 : Créer un code‑barres Planet avec hauteur automatique

Le même schéma fonctionne pour la symbologie Planet. Commencez par initialiser le générateur avec `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Pourquoi réutiliser le code** – RM4SCC et Planet partagent la même structure de paramètres, vous pouvez donc changer de symbologie en modifiant uniquement la valeur de `EncodeTypes`.

## Étape 5 : Définir une hauteur de barre fixe pour RM4SCC

Certaines administrations postales exigent une hauteur de barre spécifique (par ex., 100 px). Vous pouvez la définir explicitement avant l’enregistrement.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Astuce** – Définir `BarHeight.Pixels` remplace le calcul automatique, vous donnant un contrôle total sur la taille visuelle.

## Étape 6 : Définir une hauteur de barre fixe pour Planet

Appliquez la même technique de hauteur fixe à un code‑barres Planet.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Résultat** – Les fichiers `PostalRM4SCCBarHeight100Pixels.png` et `PostalPlanetBarHeight100Pixels.png` contiennent des codes‑barres avec une hauteur de 100 px constante, respectant les spécifications postales strictes.

## Code source complet

Voici le programme complet, exécutable, qui regroupe les quatre exemples. Copiez‑le dans un nouveau projet console et ajustez le chemin de sortie si nécessaire.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Sortie attendue** – Après l’exécution du programme, le répertoire indiqué contient quatre fichiers PNG :

* `PostalRM4SCCBarHeightNone.png` – RM4SCC avec hauteur automatique
* `PostalPlanetBarHeightNone.png` – Planet avec hauteur automatique
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC avec hauteur de 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet avec hauteur de 100 px

Ouvrez n’importe quel fichier pour vérifier que les barres sont nettes, que la largeur du module est de 4 px et que la hauteur correspond au paramètre choisi.

## Questions fréquentes et cas particuliers

| Question | Réponse |
|----------|---------|
| **Puis‑je utiliser d’autres formats d’image ?** | Oui. Remplacez `BarCodeImageFormat.Png` par `Jpeg`, `Bmp` ou `Gif` selon vos besoins. |
| **Que faire si la chaîne de données est plus longue ?** | Le générateur ajuste automatiquement le nombre de barres. Assurez‑vous que les données respectent les limites de longueur de la symbologie (RM4SCC ≤ 6 chiffres, Planet ≤ 6 chiffres). |
| **Comment changer la couleur des barres ?** | Définissez `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` avant d’appeler `Save`. |
| **Le DPI est‑il important pour l’impression ?** | Vous pouvez définir `rm4sccAuto.Parameters.ImageResolution.DpiX` et `DpiY` pour correspondre à la résolution de votre imprimante. |
