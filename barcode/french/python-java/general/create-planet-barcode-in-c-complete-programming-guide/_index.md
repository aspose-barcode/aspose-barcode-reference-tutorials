# Créer un code-barres Planet en C# – guide complet de programmation

Si vous devez **créer un code‑barres planet** en C#, ce guide vous montre exactement comment le faire. Vous découvrirez également **comment définir les dimensions du code‑barres** afin que les barres soient rendues à la largeur exacte dont vous avez besoin.

La génération de codes‑barres Planet est courante lorsque vous travaillez avec les services postaux ou les systèmes logistiques. Le code ci‑dessous couvre à la fois la version à barres pleines par défaut et le style optionnel à barres vides, ainsi qu’un exemple rapide pour le format RM4SCC. À la fin de ce tutoriel, vous disposerez d’un extrait réutilisable que vous pourrez intégrer à n’importe quel projet .NET.

## Prérequis

Avant de commencer, assurez‑vous d’avoir :

* .NET 6.0 ou version ultérieure installé (l’API fonctionne également avec .NET Framework 4.6+)
* Le package NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`) ajouté à votre projet
* Un chemin de dossier accessible en écriture où les fichiers PNG seront enregistrés
* Une connaissance de base de la syntaxe C# et de Visual Studio (ou tout autre IDE)

> **Astuce :** Utilisez un chemin absolu ou `Path.Combine(Environment.CurrentDirectory, "output")` pour éviter les problèmes de permissions lors de l’enregistrement des images.

## Étape 1 – Initialiser un générateur de code‑barres Planet (barres pleines)

La première étape consiste à créer une instance de `BarcodeGenerator` pour la symbologie Planet. Par défaut, le générateur produit des barres **pleines**.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

L’énumération `EncodeTypes.Planet` indique à Aspose.BarCode d’utiliser le format Planet, tandis que `"123456"` représente la charge utile de données qui sera encodée.

## Étape 2 – Comment définir les dimensions du code‑barres pour une taille cohérente

Pour contrôler la largeur de chaque barre, ajustez la **X‑dimension**. C’est le moyen principal de **définir les dimensions du code‑barres** et cela garantit que le code‑barres s’adapte à la taille de votre étiquette.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

La propriété `Pixels` définit la largeur de la barre en pixels d’écran. Les valeurs courantes sont de 2 à 5 pixels pour les étiquettes postales standard ; augmentez la valeur pour des impressions plus grandes.

## Étape 3 – Enregistrer le code‑barres Planet plein au format PNG

Écrivez maintenant l’image sur le disque. Le PNG conserve des bords nets, ce qui est idéal pour la lecture.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Remplacez `YOUR_DIRECTORY` par le chemin que vous avez préparé précédemment. Après l’exécution de ce code, vous verrez un fichier similaire à l’image ci‑dessous.

## Étape 4 – Créer un code‑barres Planet avec des barres vides (non remplies)

Si votre service postal exige que les barres soient **vides**, vous devez basculer le drapeau `FilledBars` après l’initialisation du générateur.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Le constructeur est identique ; la différence réside dans l’étape de configuration suivante.

## Étape 5 – Comment définir les dimensions du code‑barres et rendre les barres vides

Encore une fois, définissez la X‑dimension pour une cohérence visuelle, puis désactivez les barres pleines.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

La propriété `FilledBars = false` est celle qui modifie réellement le style de rendu. Conserver la même X‑dimension garantit que le code‑barres à barres vides s’aligne parfaitement avec la version à barres pleines.

## Étape 6 – Enregistrer le code‑barres Planet vide

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Vous disposerez maintenant de deux fichiers PNG : l’un avec des barres solides et l’autre avec des barres creuses, tous deux partageant les mêmes dimensions.

## Étape 7 – (Optionnel) Générer un code‑barres RM4SCC pour comparaison

RM4SCC est une autre symbologie postale qui utilise le même style par défaut à barres pleines. Les étapes reflètent l’exemple Planet, démontrant que **comment définir les dimensions du code‑barres** fonctionne quel que soit le format.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

L’exécution de ces trois étapes produit `PostalRM4SCCFilledBars.png`, que vous pouvez comparer côte à côte avec les résultats Planet.

## Pourquoi la X‑dimension est importante

La X‑dimension détermine la **largeur imprimable minimale** de chaque barre. Si vous la définissez trop petite, le code‑barres peut devenir flou sur des imprimantes basse résolution, entraînant des échecs de lecture. À l’inverse, une X‑dimension trop grande peut dépasser les dimensions de l’étiquette et gaspiller de l’espace. En maîtrisant explicitement **comment définir les dimensions du code‑barres**, vous obtenez un contrôle déterministe sur la taille finale de l’image, ce qui est essentiel pour les flux de travail d’envoi automatisés.

## Pièges courants et comment les éviter

| Problème | Cause | Solution |
|----------|-------|----------|
| Le code‑barres apparaît étiré | X‑dimension définie en points au lieu de pixels | Utilisez toujours la propriété `Pixels` pour un contrôle pixel‑parfait |
| Les barres vides semblent toujours pleines | `FilledBars` non mis à `false` après le changement de X‑dimension | Définissez `FilledBars = false` *après* avoir ajusté la X‑dimension |
| Le fichier enregistré est vide | Le répertoire de sortie n’existe pas ou manque de droits d’écriture | Assurez‑vous que le répertoire existe (`Directory.CreateDirectory`) et que votre application s’exécute avec les droits suffisants |
| L’image est floue à l’impression | PNG à faible DPI enregistré depuis un écran haute résolution | Utilisez `BarCodeImageFormat.Png` (sans perte) et envisagez la propriété `Resolution` si nécessaire |

## Exemple complet, exécutable

Copiez le bloc entier ci‑dess dessous dans un nouveau projet console (`dotnet new console`) et exécutez‑le. Le programme crée trois fichiers PNG dans le dossier `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Résultat attendu :** trois fichiers PNG — `PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` et `PostalRM4SCCFilledBars.png` — avec des barres de 4 pixels de large, prêts à être imprimés ou traités davantage.

## Conclusion

Vous savez maintenant comment **créer un code‑barres planet** en C# et définir précisément **les dimensions du code‑barres** pour les styles à barres pleines et vides. Le même schéma s’applique à d’autres symbologies comme RM4SCC, vous offrant une base flexible pour toute exigence de code‑barres postal.

Ensuite, vous pourriez explorer :

* Ajouter du texte lisible par l’homme sous le code‑barres (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* Modifier les couleurs des barres avec `Parameters.Barcode.BarColor`
* Générer des codes‑barres en formats vectoriels (SVG, EPS) pour une impression évolutive

N’hésitez pas à expérimenter avec différentes valeurs de X‑dimension, chaînes de données et formats de sortie afin d’adapter le tout à votre flux de travail spécifique. Bon codage !
