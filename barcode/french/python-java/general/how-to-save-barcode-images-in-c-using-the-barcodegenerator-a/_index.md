# Comment enregistrer des images de code-barres en C# à l'aide de l'API BarcodeGenerator

Si vous avez besoin de **how to save barcode** fichiers depuis une application .NET, ce guide montre les étapes exactes. Vous verrez un **barcode generator example** complet qui crée un DataBar Stacked Omnidirectional barcode, ajuste son aspect ratio, et enregistre deux fichiers PNG.

Enregistrer des images de code-barres est une exigence courante lors de la création de systèmes d'inventaire, de terminaux point‑of‑sale ou de flux de travail d'étiquetage automatisés. À la fin de ce tutoriel, vous pourrez générer du code C# de barcode qui produit des images fiables prêtes à être imprimées ou affichées.

## Prérequis

- .NET 6.0 SDK ou version ultérieure installé  
- Visual Studio 2022 (ou tout IDE compatible C#)  
- Le package NuGet **Aspose.BarCode for .NET** (le code utilise `Aspose.BarCode.Generation`)  

Vous pouvez ajouter le package avec la commande suivante :

```bash
dotnet add package Aspose.BarCode
```

## Étape 1 : Configurer un projet console C# minimal

Créez un nouveau projet console et référencez la bibliothèque :

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Ouvrez `Program.cs`. Le fichier contiendra la méthode `Main` où nous placerons la logique **generate barcode C#**.

## Étape 2 : Initialiser le BarcodeGenerator pour un DataBar Stacked Omnidirectional barcode

La première tâche dans tout flux de travail **create databar barcode** consiste à instancier `BarcodeGenerator` avec le bon `EncodeType`. Le constructeur reçoit la symbologie du code-barres et la chaîne de données.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

La valeur `EncodeTypes.DatabarStackedOmniDirectional` indique à la bibliothèque de produire un **create databar barcode** qui peut être scanné depuis n'importe quelle direction.

## Étape 3 : Configurer la X‑dimension (largeur du module)

La X‑dimension contrôle la largeur de la plus petite barre en pixels. La régler à une valeur basse maintient le code-barres compact tout en préservant la lisibilité.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Étape 4 : **How to adjust aspect ratio** – première valeur (15)

Les codes-barres DataBar exposent une propriété `AspectRatio` qui influence la relation hauteur‑largeur. Un ratio plus élevé produit un code-barres plus haut, ce qui peut améliorer la fiabilité du scan sur certaines imprimantes.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Étape 5 : **How to save barcode** – première image (ratio d'aspect 15)

Nous allons maintenant réellement **how to save barcode** dans un fichier. La méthode `Save` prend un chemin de fichier et un format d'image. Dans cet exemple, nous enregistrons un fichier PNG.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Astuce :** Le répertoire de l'exécutable est l'emplacement d'écriture par défaut. Utilisez un chemin absolu si vous avez besoin d'un dossier spécifique.

## Étape 6 : **How to adjust aspect ratio** – deuxième valeur (30)

Pour démontrer la flexibilité, modifiez le ratio d'aspect et enregistrez une seconde image. Cela montre comment les mêmes données encodées peuvent être rendues avec des proportions visuelles différentes.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

L'exécution du programme produit deux fichiers PNG :

- `DatabarAspectRatio15.png` – code-barres avec une hauteur modérée  
- `DatabarAspectRatio30.png` – code-barres avec une hauteur plus élevée pour des environnements de scan difficiles  

Les deux fichiers sont prêts à être chargés dans des contrôles UI, imprimés sur des étiquettes ou transmis via API.

### Résultat attendu

Lorsque vous ouvrez les images générées, vous devez voir un DataBar Stacked Omnidirectional barcode qui encode la valeur GTIN‑14 `12345678901231`. La différence visuelle entre les deux fichiers réside uniquement dans la hauteur, confirmant que **how to adjust aspect ratio** fonctionne comme prévu.

## Étape 7 : Code source complet à titre de référence

Voici le programme complet et exécutable. Copiez-le dans `Program.cs`, compilez et exécutez.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Questions fréquentes et gestion des cas limites

### Que faire si le dossier cible n'existe pas ?

`Save` lève une `DirectoryNotFoundException`. Créez d'abord le répertoire :

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Comment changer le format d'image ?

Remplacez `BarCodeImageFormat.Png` par `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` ou `BarCodeImageFormat.Tiff` selon les exigences en aval.

### Puis-je générer plusieurs codes-barres dans une boucle ?

Oui. Instanciez un nouveau `BarcodeGenerator` pour chaque chaîne de données ou réutilisez la même instance après avoir mis à jour la propriété `CodeText` :

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### **how to save barcode** fonctionne-t-il sur des plateformes non‑Windows ?

Aspose.BarCode est multiplateforme. Le même code s'exécute sous Linux et macOS tant que le runtime .NET est présent.
