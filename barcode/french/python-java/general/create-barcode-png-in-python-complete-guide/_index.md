# Créer un PNG de code-barres en Python – Guide complet

Vous avez déjà eu besoin de **créer un PNG de code-barres** mais vous n'étiez pas sûr de la bibliothèque ou des paramètres à utiliser ? Vous n'êtes pas seul. Dans de nombreux systèmes d'inventaire ou de caisse, la première étape consiste à transformer des données brutes en une image PNG nette que les scanners adorent.  

Dans ce tutoriel, nous parcourrons **comment générer databar**, **ajuster la hauteur du code-barres**, et même l'astuce pour **modifier le code-barres** paramètres à la volée — le tout en utilisant **code-barres avec données d'exemple** que vous pouvez copier‑coller directement dans votre projet.  

## Ce que vous apprendrez

- Configurez la bibliothèque Aspose.BarCode (ou similaire) en Python.  
- **Créer un PNG de code-barres** fichiers avec différentes hauteurs en quelques lignes de code.  
- **Comment modifier le code-barres** propriétés telles que la taille du module et la hauteur des barres.  
- Utilisez une valeur GTIN‑14 réaliste comme **code-barres avec données d'exemple**.  
- Conseils pour résoudre les problèmes courants tels que les images floues ou un encodage incorrect.

## Prérequis

- Python 3.8+ installé sur votre machine.  
- Accès à Internet pour installer le package `aspose-barcode` (ou toute bibliothèque compatible).  
- Un dossier accessible en écriture où les fichiers PNG seront enregistrés (remplacez `YOUR_DIRECTORY` dans le script).  

Si vous avez déjà tout cela, super — plongeons‑nous.

## Créer un PNG de code-barres – Configuration du générateur

Première chose à faire : nous avons besoin d'un objet générateur qui sait que nous travaillons avec un code-barres **DataBar Omnidirectional**. Le code ci‑dessous importe les classes nécessaires, crée le générateur avec un **code-barres avec données d'exemple**, et définit une taille de module modeste.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Pourquoi c'est important :** Le `EncodeTypes.DATABAR_OMNIDIRECTIONAL` indique au moteur de produire un **DataBar** qui peut être lu dans n'importe quelle direction, parfait pour les rayons de vente au détail. Le réglage de `x_dimension` garde les barres nettes, tandis que `bar_height` contrôle la taille visuelle du code.

## Comment générer Databar avec des données d'exemple

Maintenant que le générateur est prêt, nous allons **créer un PNG de code-barres**. La première sauvegarde utilise une hauteur de 30 pixels, ce qui est souvent suffisant pour les aperçus à l'écran.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Exécuter le script jusqu'à ce point produira un fichier PNG qui ressemble à un code-barres compact et à contraste élevé. Ouvrez‑le dans n'importe quel visualiseur d'images pour vérifier que les barres sont nettes et que les données GTIN‑14 sont encodées.

## Ajuster la hauteur du code-barres (Comment modifier le code-barres)

Parfois, vous avez besoin d'un code-barres plus haut pour des étiquettes plus grandes ou une impression à plus haute résolution. C'est là que **ajuster la hauteur du code-barres** entre en jeu. Modifier la hauteur est aussi simple que de mettre à jour la propriété `BarHeight` et de sauvegarder à nouveau.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Comment ça fonctionne :** Le générateur réutilise les mêmes données et la même taille de module ; seule la dimension verticale change. Cela évite de recréer tout l'objet et démontre **comment modifier le code-barres** les paramètres dynamiquement.

## Script complet – Solution tout‑en‑un

Voici le script complet et exécutable qui combine toutes les étapes. Copiez, collez et exécutez — il devrait fonctionner immédiatement après l'installation du package.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Résultat attendu

Exécuter le script générera deux fichiers :

- `DatabarOmni30.png` – code-barres DataBar Omnidirectional de 30 px de hauteur.  
- `DatabarOmni60.png` – version de 60 px de hauteur du même code-barres.

Les deux images sont au format PNG, sans perte, et prêtes à être intégrées dans des PDF, des pages HTML ou imprimées directement sur des étiquettes.

## Pièges courants & Astuces pro

- **Pixel vs. DPI :** Les fichiers PNG sont basés sur les pixels. Si vous avez besoin d'une taille d'impression spécifique, calculez `BarHeight` en fonction du DPI (par ex., 300 dpi → 30 px ≈ 0,1 po).  
- **Encodage incorrect :** Assurez‑vous que la chaîne de données suit le format d'Identifiant d'Application GS1 (`(01)` pour GTIN‑14). Des parenthèses manquantes peuvent amener la bibliothèque à revenir à un code-barres numérique simple.  
- **Chemins de fichiers :** Utilisez des chaînes brutes (`r"..."`) ou des doubles barres obliques inverses sous Windows pour éviter les problèmes de caractères d'échappement.  
- **Performance :** Si vous générez des milliers de codes-barres, instanciez le générateur une seule fois et ne modifiez que le `BarHeight` ou la chaîne de données entre les sauvegardes. Cela réduit la consommation de mémoire.
