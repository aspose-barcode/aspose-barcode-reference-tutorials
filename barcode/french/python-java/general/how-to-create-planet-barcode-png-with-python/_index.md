# Comment créer un code‑barres Planet PNG avec Python

Si vous devez **créer un code‑barres Planet PNG**, ce tutoriel vous guide à travers le processus complet en utilisant Python. Vous apprendrez également **comment générer un code‑barres Planet** étape par étape, configurer son apparence et enregistrer le résultat sous forme d’image PNG de haute qualité.

La génération d’un code‑barres Planet est courante dans l’automatisation postale, le suivi d’inventaire et les systèmes logistiques. À la fin de ce guide, vous disposerez d’un script autonome qui produit un fichier PNG prêt à l’emploi, et vous comprendrez comment adapter le code pour différentes tailles ou formats d’image.

## Prérequis

Avant de commencer, assurez‑vous d’avoir :

* Python 3.8 ou une version plus récente installé.
* Accès au package `aspose-barcode` (ou toute bibliothèque compatible fournissant les classes `BarcodeGenerator`, `EncodeTypes` et `BarCodeImageFormat`).
* Permission d’écriture dans le répertoire où vous souhaitez stocker le fichier PNG.

Vous pouvez installer la bibliothèque requise avec pip :

```bash
pip install aspose-barcode
```

> **Astuce :** Utilisez un environnement virtuel pour garder les dépendances isolées des autres projets.

## Créer un code‑barres Planet PNG – guide complet du code

Le script suivant montre chaque étape nécessaire pour générer un code‑barres Planet PNG avec des barres vides (non remplies). Copiez le code dans un fichier nommé `planet_barcode.py` et exécutez‑le avec `python planet_barcode.py`.

```python
# planet_barcode.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Initialize a Planet barcode generator with the data to encode
# The data "123456" is a typical numeric payload for postal services.
generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

# Step 2: Set the width of each bar (X dimension) to 4 pixels.
# Adjusting the X dimension changes the overall size and readability.
generator.parameters.barcode.x_dimension.pixels = 4

# Step 3: Configure the barcode to use empty (unfilled) bars.
# When `filled_bars` is False, the dark bars become transparent,
# which is useful for overlaying the barcode on colored backgrounds.
generator.parameters.barcode.filled_bars = False

# Step 4: Save the generated barcode as a PNG image.
# The output path can be absolute or relative; ensure the folder exists.
output_path = "output/PostalPlanetEmptyBars.png"
generator.save(output_path, BarCodeImageFormat.PNG)

print(f"Planet barcode PNG saved to: {output_path}")
```

### Ce que fait chaque ligne

| Ligne | Explication |
|------|-------------|
| `from aspose.barcode import ...` | Importe les classes nécessaires pour créer et configurer le code‑barres. |
| `BarcodeGenerator(EncodeTypes.Planet, "123456")` | Instancie un générateur pour la symbologie **Planet** en utilisant la chaîne numérique `"123456"`. |
| `x_dimension.pixels = 4` | Définit la largeur de la barre à 4 px ; des valeurs plus grandes produisent un code‑barres plus gros, tandis que des valeurs plus petites réduisent la taille du fichier. |
| `filled_bars = False` | Bascule le code‑barres pour utiliser des **barres vides**, rendant les modules sombres transparents. |
| `save(..., BarCodeImageFormat.PNG)` | Enregistre le code‑barres dans un fichier PNG, préservant la qualité sans perte. |
| `print(...)` | Confirme la création réussie dans la console. |

## Comment générer un code‑barres Planet avec des paramètres personnalisés

Bien que le script de base couvre la plupart des cas d’utilisation, vous pourriez avoir besoin d’ajuster le code‑barres pour des exigences spécifiques :

1. **Longueurs de données différentes** – Les codes‑barres Planet acceptent jusqu’à 12 caractères numériques. Remplacez `"123456"` par toute chaîne numérique valide dans cette plage.
2. **Formats d’image alternatifs** – Remplacez `BarCodeImageFormat.PNG` par `BarCodeImageFormat.JPEG` ou `BarCodeImageFormat.BMP` pour s’adapter aux pipelines de traitement en aval.
3. **Modification de la dimension X** – Des valeurs plus grandes (par ex., `8`) créent un code‑barres à plus haute résolution, utile pour l’impression sur de grandes étiquettes.
4. **Couleurs d’arrière‑plan** – Si vous souhaitez un arrière‑plan coloré, définissez `generator.parameters.barcode.back_color` avant l’enregistrement.

Exemple avec une couleur d’arrière‑plan personnalisée :

```python
from aspose.barcode import Color

generator.parameters.barcode.back_color = Color.get_yellow()
generator.save("output/PlanetYellowBackground.png", BarCodeImageFormat.PNG)
```

## Pièges courants et comment les éviter

| Problème | Raison | Solution |
|----------|--------|----------|
| **FileNotFoundError** lors de l’enregistrement | Le répertoire cible n’existe pas. | Créez le répertoire au préalable (`os.makedirs("output", exist_ok=True)`). |
| **Longueur de données invalide** | Le code‑barres Planet n’accepte que des données numériques jusqu’à 12 caractères. | Validez la chaîne d’entrée avant de créer le générateur. |
| **Barres transparentes invisibles** | Certains visionneurs ignorent la transparence sur un canevas blanc. | Placez le code‑barres sur un arrière‑plan non blanc ou exportez en PNG avec canal alpha. |

## Vérification du résultat

Après avoir exécuté le script, ouvrez `PostalPlanetEmptyBars.png` avec n’importe quel visualiseur d’image. Vous devriez voir une série de barres verticales où les modules sombres sont transparents, ne laissant que le contour du code‑barres. Pour confirmer que le code‑barres est lisible, utilisez une application de lecture de codes‑barres mobile qui prend en charge la symbologie Planet.

Si l’image apparaît vide, revérifiez :

* Le drapeau `filled_bars` est bien réglé sur `False`.
* La dimension X n’est pas à zéro.
* Le chemin de sortie pointe vers un dossier existant.

## Extension de la solution

Maintenant que vous pouvez **créer un code‑barres Planet PNG**, envisagez les étapes suivantes :

* **Génération par lots** – Parcourez un fichier CSV de codes postaux pour produire un PNG pour chaque entrée.
* **Intégration dans des PDF** – Utilisez une bibliothèque PDF (par ex., `reportlab`) pour placer le PNG généré sur des étiquettes d’expédition.
* **API Web** – Enveloppez le script dans un point de terminaison Flask pour générer des codes‑barres à la demande.

Ces extensions tirent parti de la même logique de base démontrée ici tout en ajoutant des capacités d’automatisation et d’intégration.
