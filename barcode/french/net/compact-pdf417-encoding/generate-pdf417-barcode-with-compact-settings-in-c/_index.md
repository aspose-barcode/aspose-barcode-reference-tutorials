# Générer un code‑barres PDF417 avec des paramètres compacts en C#

Si vous devez **générer un code‑barres PDF417** dans une application .NET, ce guide vous montre comment le faire avec Aspose.Barcode for .NET. Nous parcourrons la création du générateur, la configuration des colonnes, de la dimension X et l’activation du mode compact afin que le symbole résultant soit aussi petit que possible.

Générer un code‑barres PDF417 est fréquent lorsque vous devez encoder de grandes quantités de données pour des billets, des cartes d’identité ou des étiquettes d’expédition. Ce tutoriel couvre l’ensemble du flux de travail — de l’installation de la bibliothèque à l’enregistrement du PNG final — afin que vous puissiez copier‑coller le code dans votre propre projet et l’exécuter immédiatement.

## Prérequis pour générer un code‑barres PDF417

Avant de commencer, assurez‑vous d’avoir :

* .NET 6.0 (ou version ultérieure) installé.  
* Visual Studio 2022 ou tout IDE supportant les projets C#.  
* Une licence NuGet pour **Aspose.Barcode for .NET** (l’essai gratuit suffit pour l’apprentissage).  

Vous pouvez ajouter la bibliothèque avec la commande suivante :

```bash
dotnet add package Aspose.BarCode
```

> **Astuce :** Utilisez le drapeau `--version` pour fixer une version stable connue, par ex., `dotnet add package Aspose.BarCode --version 23.12`.

## Créer un générateur de code‑barres PDF417

Le premier bloc de code crée une instance de `BarcodeGenerator` pré‑configurée pour la symbologie PDF417. Le texte `"Åspóse.Barcóde©"` contient des caractères Unicode afin de démontrer que le générateur gère les entrées non‑ASCII dès le départ.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Pourquoi c’est important
`EncodeTypes.Pdf417` indique à Aspose.Barcode que vous souhaitez un **code‑barres PDF417**, qui est une symbologie linéaire empilée capable de stocker jusqu’à 1 850 caractères. Utiliser le constructeur avec l’argument texte vous évite un appel ultérieur à `SetCodeText`.

## Définir la XDimension du code‑barres (taille du module)

La taille du module, également appelée dimension X, détermine la largeur de chaque barre individuelle. Des pixels plus petits produisent une image plus dense, tandis que des pixels plus grands améliorent la lisibilité sur les imprimantes basse résolution.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### Pourquoi vous devriez ajuster la XDimension
Une valeur de `2` pixels convient bien pour l’affichage à l’écran et la plupart des imprimantes de bureau. Si vous avez besoin d’une impression à plus haute résolution, augmentez la valeur ; si vous avez besoin d’un code‑barres plus compact (par ex., pour un aspect similaire à un QR), réduisez‑la — mais jamais en dessous de `1` pixel, sinon l’image devient illisible.

## Définir le nombre de colonnes pour le symbole PDF417

PDF417 vous permet de choisir le nombre de colonnes (empilements verticaux) que le code‑barres aura. Moins de colonnes rendent le code‑barres plus haut ; plus de colonnes le rendent plus large.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### Quand modifier le nombre de colonnes
Trois colonnes produisent un symbole compact, presque carré, qui s’adapte parfaitement aux cartes d’identité standard. Si vous avez une chaîne très longue, vous pouvez augmenter le nombre de colonnes pour garder une hauteur raisonnable.

## Activer le mode compact (troncature)

Le mode compact supprime automatiquement les rangées inutilisées du symbole, réduisant ainsi sa taille globale. Ceci est particulièrement utile lorsque les données encodées ne remplissent pas toute la matrice.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Avantages du code‑barres PDF417 compact
Lorsque `Truncate` est `true`, le générateur calcule le nombre minimal de rangées nécessaires pour stocker vos données, ce qui réduit la consommation d’encre et le temps de numérisation. C’est sûr pour la plupart des scanners car la spécification PDF417 définit l’algorithme de troncature.

## Enregistrer le code‑barres généré en tant qu’image

Enfin, écrivez le code‑barres dans un fichier PNG. Le PNG conserve une qualité sans perte, ce qui le rend idéal pour une impression ultérieure ou une insertion dans des PDF.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Résultat attendu
L’exécution du programme crée `CompactPdf417.png` dans le dossier spécifié. L’image contient un **code‑barres PDF417 compact** qui encode la chaîne `"Åspóse.Barcóde©"` avec trois colonnes, une dimension X de 2 pixels et la troncature appliquée. Vous pouvez vérifier le résultat avec n’importe quelle application de lecture de code‑barres ou la démo en ligne gratuite d’Aspose.Barcode.

## Variantes courantes et cas limites

| Situation | Ajustement |
|-----------|------------|
| **Données très longues (> 1500 caractères)** | Augmentez `Columns` ou définissez `Rows` manuellement (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Impression sur une imprimante basse résolution** | Augmentez `XDimension.Pixels` à 3 ou 4 pour éviter la pixellisation. |
| **Besoin d’un arrière‑plan transparent** | Utilisez `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **Intégration dans un PDF** | Enregistrez en `BarCodeImageFormat.Pdf` ou récupérez l’objet `Image` via `pdf417Generator.GenerateBarCodeImage()`. |

## Exemple complet et exécutable

Voici le programme complet que vous pouvez copier dans un nouveau projet console. Aucun fichier supplémentaire n’est requis.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Exécutez `dotnet run` depuis le dossier du projet. Après l’exécution, ouvrez `CompactPdf417.png` pour voir le code‑barres généré.

## Conclusion

Vous savez maintenant comment **générer un code‑barres PDF417** en C# avec un contrôle total sur les colonnes, la dimension X et le mode compact. En ajustant les `barcode XDimension pixels`, en `set PDF417 columns` et en activant la troncature du `compact PDF417 barcode`, vous pouvez produire un code‑barres qui répond exactement aux contraintes de taille de votre application.

Prochaines étapes que vous pourriez explorer :

* Encoder des ensembles de données plus volumineux et expérimenter avec le paramètre `Rows`.  
* Passer au format de sortie `BarCodeImageFormat.Svg` pour des graphiques web évolutifs.  
* Combiner le code‑barres avec d’autres composants Aspose, tels que **Aspose.PDF**, pour intégrer directement l’image dans un rapport PDF.

Bonne programmation, et n’hésitez pas à ajuster les paramètres pour les adapter à votre environnement de numérisation spécifique !
