# Comment générer un code-barres PDF417 en C# – exemple compact

Si vous devez **générer un code-barres PDF417** dans une application C#, ce guide vous présente une solution complète, prête à l’emploi. Nous créerons un code-barres PDF417 compact, ajusterons la largeur du module, définirons le nombre de colonnes et enregistrerons le résultat sous forme d’image PNG — le tout avec la bibliothèque Aspose.BarCode .NET.

Générer un code-barres PDF417 est fréquent lorsque vous souhaitez encoder de grandes quantités de données (par ex., des URL, des cartes de contact ou des identifiants d’inventaire) dans un format bidimensionnel optimisé en termes d’espace. À la fin de ce tutoriel, vous disposerez d’une instance fonctionnelle de `BarcodeGenerator` qui produit un code-barres compact, très lisible, prêt à être imprimé ou affiché.

## Prérequis

- .NET 6.0 ou version ultérieure (le code fonctionne également avec .NET Framework 4.8)
- Visual Studio 2022 (ou tout IDE C#)
- Package NuGet Aspose.BarCode for .NET (`Install-Package Aspose.BarCode`)
- Familiarité de base avec la syntaxe C#

Aucune configuration supplémentaire n’est requise ; l’exemple s’exécute en tant qu’application console.

## Étape 1 : Créer un générateur de code-barres PDF417

La première étape consiste à instancier `BarcodeGenerator` avec l’énumération `EncodeTypes.Pdf417` et le texte que vous souhaitez encoder.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Pourquoi c’est important :** `EncodeTypes.Pdf417` indique à la bibliothèque d’utiliser la symbologie PDF417, tandis que le deuxième argument définit la charge utile des données. Vous pouvez remplacer `"Compact example"` par n’importe quelle chaîne jusqu’à 1 800 caractères.

## Étape 2 : Définir la largeur du module (dimension X) en pixels

La dimension X définit la largeur d’un seul module du code-barres (le plus petit carré noir ou blanc). Une valeur en pixels plus petite produit un code-barres plus serré.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Pourquoi c’est important :** Une valeur de `2` pixels crée un aspect compact sans sacrifier la fiabilité de la lecture sur la plupart des scanners modernes. Ajustez la valeur si vous avez besoin de modules plus grands pour une impression basse résolution.

## Étape 3 : Spécifier le nombre de colonnes

PDF417 vous permet de contrôler le nombre de colonnes, ce qui influence le rapport d’aspect du code-barres.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Pourquoi c’est important :** Moins de colonnes rendent le code-barres plus haut, tandis que davantage de colonnes l’aplatissent. Trois colonnes fonctionnent bien pour une disposition compacte en mode portrait.

## Étape 4 : Activer le mode compact en tronquant le code-barres

Le mode compact supprime les rangées de remplissage inutiles, rendant le code-barres plus petit tout en conservant les données encodées.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Pourquoi c’est important :** La troncature est idéale lorsque l’espace d’affichage est limité (par ex., applications mobiles ou petites étiquettes). Le code-barres reste entièrement lisible car l’algorithme d’encodage ajuste automatiquement les niveaux de correction d’erreurs.

## Étape 5 : Enregistrer le code-barres sous forme d’image PNG

Enfin, écrivez le code-barres généré dans un fichier. Le PNG conserve une qualité sans perte, ce qui est essentiel pour les scanners de codes-barres.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

L’exécution du programme crée `CompactPdf417.png` dans le répertoire de travail de l’exécutable. L’image ressemble à ceci :

![Code‑barres PDF417 compact généré](CompactPdf417.png "Code‑barres PDF417 compact généré")

**Résultat attendu :** Un code-barres PDF417 de 2 pixels de large, à trois colonnes, qui encode le texte « Compact example ». Scanner le PNG avec un lecteur de code-barres standard doit renvoyer la chaîne d’origine.

## Variations courantes et cas limites

| Situation | Comment ajuster le code |
|-----------|------------------------|
| **Données plus longues ( > 500 caractères )** | Augmentez `Columns` à 5‑7 pour éviter que le code-barres ne devienne trop haut. |
| **Impression haute résolution** | Définissez `XDimension.Pixels` à 3 ou 4 pour des modules plus grands. |
| **Format d’image différent** | Remplacez `BarCodeImageFormat.Png` par `Jpeg` ou `Bmp` selon les besoins. |
| **Intégration du code-barres dans un PDF** | Utilisez `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` au lieu de PNG. |

**Astuce pro :** Testez toujours le code-barres généré sur le matériel de scanner cible. Certains scanners low‑cost ont du mal avec des dimensions X très petites ; si vous rencontrez des erreurs de lecture, augmentez la valeur en pixels d’un cran.

## Exemple complet et exécutable

Voici le programme complet que vous pouvez copier‑coller dans un nouveau projet console. Aucun fichier supplémentaire n’est requis.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Compilez et exécutez le programme (`dotnet run` si vous utilisez le CLI .NET). Après l’exécution, ouvrez `CompactPdf417.png` pour vérifier le résultat visuel.

## Conclusion

Vous savez maintenant **comment générer un code-barres PDF417** en C# avec une disposition compacte, une dimension X personnalisée et des réglages de colonnes. L’exemple montre les étapes essentielles : instancier `BarcodeGenerator`, configurer `XDimension` et `Columns`, activer `Truncate` pour le mode compact, puis enregistrer l’image.

À partir d’ici, vous pouvez explorer des fonctionnalités supplémentaires telles que le niveau de correction d’erreurs, les couleurs personnalisées ou l’intégration directe du code-barres dans des PDF. Expérimentez avec différents `EncodeTypes` si vous avez besoin d’autres symbologies (par ex., QR, Code128) et appliquez le même schéma de configuration des paramètres.

Bon codage, et que vos codes-barres soient toujours lus du premier coup !
