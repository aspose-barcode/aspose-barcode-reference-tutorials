# Générer un code‑barres PDF417 avec Aspose Barcode Generator – guide C#

Si vous devez **générer un code‑barres PDF417** dans un projet .NET, ce tutoriel vous montre exactement comment le faire avec le **Aspose Barcode Generator**. Vous verrez un exemple complet et exécutable qui crée un symbole PDF417 compact, personnalise sa taille et enregistre le résultat sous forme de fichier PNG.

La génération d’un code‑barres PDF417 est courante lorsque vous devez encoder de grandes quantités de données — telles que des URL, des informations de contact ou des enregistrements d’inventaire — dans une seule image scannable. Ce guide couvre tout, de l’installation de la bibliothèque à l’ajustement des **options de configuration PDF417** pour obtenir une sortie compacte.

## Ce que vous allez apprendre

* Installer et référencer la bibliothèque Aspose.BarCode dans un projet C#.  
* Utiliser le **générateur de code‑barres Aspose** pour créer un symbole PDF417 à partir d’un texte arbitraire.  
* Appliquer les paramètres **de configuration PDF417** — taille du module, nombre de colonnes et mode compact.  
* Enregistrer le code‑barres sous forme d’image PNG et vérifier le résultat.  

**Prérequis**

* SDK .NET 6.0 ou ultérieur (le code fonctionne également avec .NET Core 3.1 et .NET Framework 4.7+).  
* Familiarité de base avec les applications console C#.  
* Une licence valide Aspose.BarCode (l’évaluation gratuite suffit pour le développement).

## Étape 1 : Générer un code‑barres PDF417 – créer le générateur

La première tâche consiste à instancier le générateur avec le texte souhaité et la symbologie PDF417. Cette étape répond directement à la question **comment générer pdf417**.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Create a BarcodeGenerator for PDF417 with the data you want to encode.
            // The EncodeTypes enum selects the symbology; Pdf417 is the target type.
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");
```

**Pourquoi c’est important :**  
`EncodeTypes.Pdf417` indique à la bibliothèque d’utiliser l’algorithme PDF417, qui prend en charge jusqu’à 1 850 caractères. Le constructeur accepte également la chaîne de données brute ; tous les caractères Unicode (y compris les accents) sont gérés automatiquement.

## Étape 2 : Configurer les paramètres PDF417 – personnaliser la taille et la mise en page

Un code‑barres PDF417 peut être rendu sous de nombreuses formes. Ajuster les **options de configuration PDF417** vous permet de créer un symbole compact qui tient sur une petite étiquette ou un écran mobile.

```csharp
            // -----------------------------------------------------------------
            // Step 2: Set visual parameters for the barcode
            // -----------------------------------------------------------------

            // Module size – each tiny square (pixel) of the barcode.
            // Smaller values produce a tighter image; 2 pixels is a good default.
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Number of columns – controls the width of the barcode.
            // Fewer columns make the symbol taller; 3 columns yields a compact shape.
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode – removes unnecessary quiet zones and reduces height.
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Explication de chaque paramètre**

| Paramètre | Effet | Quand l’utiliser |
|-----------|-------|-------------------|
| `XDimension.Pixels` | Contrôle la largeur d’un seul module. Des valeurs plus faibles réduisent le code‑barres mais peuvent affecter la lisibilité sur des appareils à basse résolution. | Utilisez `2`–`4` pour l’affichage à l’écran ; augmentez pour les étiquettes imprimées. |
| `Pdf417.Columns` | Détermine le nombre de colonnes de données du symbole. Moins de colonnes produisent un code‑barres plus haut et plus étroit. | Choisissez `3`–`5` pour des mises en page compactes ; des valeurs plus élevées pour des codes‑barres plus larges. |
| `Pdf417.Truncate` | Active le « mode compact » qui supprime la zone silencieuse extérieure et réduit la hauteur globale. | Idéal pour les éléments d’interface où l’espace est limité. |

Ces trois réglages répondent ensemble à la partie **configuration PDF417** de la tâche, vous offrant un contrôle granulaire sur l’image finale.

## Étape 3 : Enregistrer l’image du code‑barres – exporter en PNG

Après avoir configuré le générateur, il faut écrire le code‑barres dans un fichier. La méthode `Save` prend en charge de nombreux formats ; le PNG conserve une qualité sans perte et fonctionne bien tant pour le web que pour les applications de bureau.

```csharp
            // -----------------------------------------------------------------
            // Step 3: Save the generated barcode as a PNG image
            // -----------------------------------------------------------------

            // Replace YOUR_DIRECTORY with an actual folder on your machine.
            string outputPath = @"C:\Barcodes\CompactPdf417.png";

            // BarCodeImageFormat.Png tells Aspose to write a PNG file.
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            // Inform the user that the process succeeded.
            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**Ce que vous devriez voir**

L’exécution du programme crée `CompactPdf417.png` dans le dossier spécifié. L’image contient un symbole PDF417 dense qui encode la chaîne `Åspóse.Barcóde©`. La plupart des lecteurs de code‑barres et des applications mobiles (par ex., ZXing, Scandit) peuvent lire cette image sans configuration supplémentaire.

## Code source complet – un fichier prêt à copier‑coller

Voici le programme complet, incluant les directives `using` et la méthode `Main`. Vous pouvez le copier dans un nouveau projet console et l’exécuter immédiatement.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Step 1: Create the generator (how to generate pdf417)
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");

            // Step 2: Set PDF417 options (how to set pdf417)
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;   // module size
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;    // number of columns
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact mode

            // Step 3: Save as PNG
            string outputPath = @"C:\Barcodes\CompactPdf417.png";
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**Exécution du code**

1. Ouvrez un terminal et créez un nouveau projet console :  
   `dotnet new console -n Pdf417Demo`  
2. Ajoutez le package NuGet Aspose.BarCode :  
   `dotnet add package Aspose.BarCode`  
3. Remplacez le fichier `Program.cs` généré par le code ci‑dessus.  
4. Compilez et exécutez :  
   `dotnet run`  

Vous devriez voir le message de confirmation et retrouver le fichier PNG à l’emplacement que vous avez indiqué.

## Pièges courants et bonnes pratiques

* **Expiration de la licence** – La version d’évaluation ajoute un filigrane après 30 jours. Enregistrez une licence rapidement pour éviter les surprises.  
* **Permissions du répertoire** – Assurez‑vous que le dossier cible existe et que le processus dispose des droits d’écriture ; sinon `Save` lèvera une `UnauthorizedAccessException`.  
* **Compatibilité du lecteur** – Si un lecteur ne parvient pas à lire le code‑barres compact, augmentez `XDimension.Pixels` à `4` ou désactivez `Truncate`.  
* **Gestion Unicode** – Aspose.BarCode prend en charge pleinement UTF‑8 ; vous pouvez encoder n’importe quelle chaîne Unicode sans étapes supplémentaires.  
* **Performance** – Générer de nombreux codes‑barres dans une boucle bénéficie de la réutilisation d’une seule instance `BarcodeGenerator` en ne mettant à jour que `CodeText` entre les itérations.
