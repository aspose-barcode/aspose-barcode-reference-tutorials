# Comment générer un code-barres en C# avec Aspose.BarCode et ajouter des métadonnées

Si vous devez **générer un code-barres en C#** pour un système logistique ou de gestion d'inventaire, ce guide vous présente une solution complète, prête pour la production. Vous verrez comment créer un code-barres Macro PDF417, y joindre des métadonnées riches, et définir un horodatage précis — le tout avec la bibliothèque Aspose.BarCode.

Le tutoriel couvre tout, de l’installation du package NuGet à l’enregistrement de l’image PNG finale. À la fin, vous pourrez générer un code-barres qui transporte des identifiants de fichier, des informations de segment et des champs personnalisés, prêt pour les lecteurs en aval qui supportent le Macro PDF417.

## Prérequis

* .NET 6.0 SDK ou version ultérieure (le code fonctionne également avec .NET Framework 4.7.2+)
* Visual Studio 2022 ou tout IDE C# de votre choix
* Une licence active Aspose.BarCode (l’essai gratuit suffit pour le développement)
* Une connaissance de base de la syntaxe C#

> **Astuce pro :** Si vous utilisez une chaîne CI/CD, ajoutez la référence au package Aspose.BarCode dans votre fichier projet afin que les builds restent reproductibles.

## Étape 1 : Installer Aspose.BarCode

Ouvrez un terminal dans le dossier de votre projet et exécutez :

```bash
dotnet add package Aspose.BarCode
```

La commande récupère la dernière version stable (actuellement 24.9). Une fois la restauration terminée, vous pouvez référencer la bibliothèque dans vos fichiers source.

## Étape 2 : Créer un nouveau projet console C# (optionnel)

Si vous préférez repartir de zéro, créez une application console :

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Le fichier `Program.cs` hébergera le code de génération du code-barres présenté plus loin.

## Étape 3 : Configurer le générateur de code-barres

Le cœur du processus est la classe `BarcodeGenerator`. Vous l’instanciez avec la valeur d’énumération `EncodeTypes` souhaitée et le texte que vous voulez encoder.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Pourquoi chaque ligne est importante

* **EncodeTypes.MacroPdf417** indique à Aspose de produire un code-barres PDF417 qui peut être découpé en segments. C’est essentiel pour les charges utiles importantes qui dépassent la capacité d’un seul symbole.
* **XDimension.Pixels** contrôle la densité visuelle. Une valeur de 2 produit une image nette sur la plupart des écrans et imprimantes sans gonfler la taille du fichier.
* **MacroPdf417* properties** intègrent les métadonnées que les lecteurs en aval lisent comme champs séparés (ID de fichier, ID de segment, etc.). C’est la partie « comment ajouter des métadonnées » du tutoriel.
* **MacroPdf417TimeStamp** montre « comment définir un horodatage ». L’instance `DateTime` peut être n’importe quelle heure UTC ; l’utilisation d’UTC évite les ambiguïtés de fuseau horaire lorsque le code-barres circule entre régions.
* **MacroPdf417Terminator** définit comment la séquence macro se termine. `Set` est le choix le plus courant car il signale le segment final au lecteur.
* **Save(..., BarCodeImageFormat.Png)** écrit une image sans perte qui préserve les détails fins nécessaires à un scan fiable.

## Étape 4 : Vérifier le code-barres généré

Exécutez le programme :

```bash
dotnet run
```

Vous devriez voir la sortie console :

```
Barcode saved to ExtPDF417Meta.png
```

Ouvrez `ExtPDF417Meta.png` avec n’importe quel visualiseur d’images. L’image affichera un symbole PDF417 compact avec le texte **Åspóse.Barcóde©** et les champs macro intégrés. Scanner l’image avec un lecteur compatible PDF417 (ou une application mobile supportant le Macro PDF417) renverra le texte original ainsi que les valeurs de métadonnées que vous avez définies.

### Caractéristiques visuelles attendues

* Barres verticales sombres et uniformément espacées
* Une zone silencieuse (marge) ajoutée automatiquement par Aspose
* Aucun défaut, car le `XDimension` de 2 pixels correspond à la résolution native du PNG

## Étape 5 : Variations courantes et cas limites

### 5.1 Gestion des caractères spéciaux

Le texte d’exemple contient des caractères Unicode (`Å`, `ó`, `©`). Aspose.BarCode les encode en UTF‑8 par défaut, ils apparaissent donc correctement dans le code-barres. Si vous avez besoin d’un autre encodage (par ex., ISO‑8859‑1), définissez :

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Identifiants de fichiers volumineux

`MacroPdf417FileID` accepte un entier 32 bits. Pour des valeurs supérieures à `int.MaxValue`, divisez l’identifiant sur plusieurs champs ou utilisez un GUID stocké sous forme de chaîne dans `MacroPdf417FileName`.

### 5.3 Ajustement du nombre de colonnes

Augmenter `Pdf417.Columns` réduit la hauteur du code-barres mais élargit chaque rangée. Si le code-barres doit tenir sur une étiquette étroite, diminuez le nombre de colonnes et augmentez automatiquement le nombre de rangées.

### 5.4 Enregistrement dans d’autres formats

Aspose prend en charge BMP, JPEG, TIFF et SVG. Remplacez `BarCodeImageFormat.Png` par la valeur d’énumération souhaitée, par ex., `BarCodeImageFormat.Svg` pour un graphique vectoriel évolutif.

## Étape 6 : Intégrer le code-barres dans un flux de travail plus large

Une fois que vous avez le fichier PNG, vous pouvez :

* L’intégrer dans une facture PDF avec Aspose.PDF.
* Le joindre à un e‑mail comme preuve de livraison.
* Stocker les octets de l’image dans une base de données pour une récupération ultérieure.

Voici un extrait rapide qui convertit le PNG en tableau d’octets pour le stockage :

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Questions fréquentes

**Q : Cela fonctionne-t-il sur .NET Core ?**  
R : Oui. La même API fonctionne sur .NET Core, .NET 5+ et .NET Framework. Il suffit de référencer le package NuGet approprié.

**Q : Et si je dois générer un PDF417 non‑macro ?**  
R : Utilisez `EncodeTypes.Pdf417` à la place de `EncodeTypes.MacroPdf417`. Les propriétés spécifiques au macro seront ignorées.

**Q : Puis‑je ajouter des paires clé/valeur personnalisées au‑delà des champs intégrés ?**  
R : Aspose.BarCode n’expose pas de champs utilisateur arbitraires pour le Macro PDF417. Si vous avez besoin de données supplémentaires, encodez‑les dans la charge utile principale ou passez à un QR code, qui supporte l’appendice structuré.
