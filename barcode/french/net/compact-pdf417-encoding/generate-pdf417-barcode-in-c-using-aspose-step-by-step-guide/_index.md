# Générer un code‑barres PDF417 en C# avec Aspose – guide étape par étape

Si vous devez **générer un code‑barres PDF417** dans une application .NET, ce guide vous montre exactement comment faire. Vous verrez un exemple complet, prêt à l’exécution, qui crée des codes‑barres PDF417 basiques, compacts, Micro, GS1‑Micro et Macro avec Aspose.BarCode pour .NET.

La génération d’un code‑barres PDF417 est une exigence courante pour les étiquettes d’expédition, les documents de transport et les systèmes d’inventaire. À la fin de ce tutoriel, vous serez capable de **générer des images de code‑barres PDF417**, de comprendre les paramètres clés et d’adapter le code à vos propres charges de données.

## Prérequis

- SDK .NET 6.0 ou version ultérieure (le code fonctionne également avec .NET Framework 4.7+)
- Visual Studio 2022 ou tout IDE C#
- Package NuGet Aspose.BarCode pour .NET (`Aspose.BarCode`) installé
- Familiarité de base avec la syntaxe C#

> **Astuce :** Utilisez la licence d’évaluation gratuite d’Aspose pour éviter les restrictions d’exécution pendant les tests.

## Étape 1 : Configurer le projet et importer les espaces de noms

Créez un nouveau projet console et ajoutez le package Aspose.BarCode :

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Puis ouvrez `Program.cs` et ajoutez les directives `using` requises :

```csharp
using System;
using Aspose.BarCode.Generation;
```

Ces espaces de noms vous donnent accès à la classe `BarcodeGenerator` et à l’énumération `EncodeTypes` nécessaires pour **générer un code‑barres avec C#**.

## Étape 2 : Générer un code‑barres PDF417 basique

Le code‑barres PDF417 le plus simple utilise les paramètres par défaut, à l’exception de la dimension X (largeur du module) et du nombre de colonnes. Ajuster ces valeurs contrôle la taille globale et la lisibilité.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Pourquoi cela fonctionne :**  
- `EncodeTypes.Pdf417` indique à Aspose d’utiliser la symbologie PDF417.  
- `XDimension.Pixels` définit la largeur de la plus petite barre ; une valeur de 2 garde l’image petite sans sacrifier la capacité de lecture.  
- `Pdf417.Columns` détermine le nombre de colonnes de données du code‑barres ; trois colonnes offrent un rapport d’aspect équilibré.

## Étape 3 : Générer un code‑barres PDF417 compact (truncaté)

Le mode compact supprime le motif d’arrêt et réduit la hauteur globale, ce qui est utile pour les étiquettes à espace limité.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Pourquoi cela fonctionne :**  
Définir `Pdf417.Truncate = true` active le mode tronqué, qui omet le motif d’arrêt à droite et réduit la hauteur du code‑barres tout en préservant l’intégrité des données.

## Étape 4 : Générer un code‑barres Micro PDF417

Micro PDF417 est une variante plus petite qui prend en charge 1 à 4 colonnes. Elle est idéale pour les applications où l’espace est précieux, comme les petites étiquettes produit.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Pourquoi cela fonctionne :**  
- `EncodeTypes.MicroPdf417` sélectionne la version micro de la symbologie.  
- Le nombre de colonnes peut être compris entre 1 et 4 ; choisir 4 donne la mise en page la plus dense tout en restant lisible.

## Étape 5 : Générer un code‑barres Micro PDF417 conforme à GS1

Les préfixes GS1 ajoutent des identifiants standardisés (par ex., GTIN, numéro de lot) aux données du code‑barres. Aspose vous permet de les intégrer directement.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Pourquoi cela fonctionne :**  
Les Identifiants d’Application GS1 (AI) sont placés entre parenthèses. Aspose les analyse et ajoute le formatage approprié requis par les scanners GS1.

## Étape 6 : Générer un code‑barres Macro PDF417 avec métadonnées complètes

Macro PDF417 vous permet de répartir une grande charge de données sur plusieurs codes‑barres liés. Vous pouvez intégrer des métadonnées au niveau du fichier telles que l’ID du fichier, le nombre de segments, les horodatages et des chaînes personnalisées.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Pourquoi cela fonctionne :**  
Chaque propriété `MacroPdf417*` correspond à un segment spécifique de la spécification du code‑barres macro. Définir ces valeurs garantit qu’un scanner peut reconstruire le fichier original à partir de plusieurs images de code‑barres.
