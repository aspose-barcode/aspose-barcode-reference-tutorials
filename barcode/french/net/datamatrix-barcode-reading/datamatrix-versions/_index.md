# Comment générer des codes‑barres DataMatrix avec Aspose.BarCode pour .NET

Si vous avez besoin d’une méthode fiable pour intégrer des symboles lisibles par machine dans vos applications .NET, **comment générer des codes‑barres DataMatrix** est une exigence courante. Aspose.BarCode pour .NET propose une API entièrement gérée qui prend en charge chaque étape — du choix de la bonne version DataMatrix à l’ajustement fin des niveaux de correction d’erreurs—sans nécessiter d’outils externes. Dans ce tutoriel, nous parcourrons un exemple complet, expliquerons pourquoi chaque paramètre est important et vous montrerons comment enregistrer le résultat au format PNG ou JPEG.

## Réponses rapides
- **Quelle bibliothèque crée des codes‑barres DataMatrix ?** Aspose.BarCode pour .NET.  
- **Combien de versions DataMatrix sont prises en charge ?** Les 30 versions standard carrées et rectangulaires (de 10×10 à 144×144 modules).  
- **Quels types d’ECC puis‑je utiliser ?** ECC200 (par défaut) et ECC140.  
- **Ai‑je besoin d’une licence pour le développement ?** Un essai gratuit de 30 jours suffit pour les tests ; une licence commerciale est requise pour la production.  
- **Puis‑je exécuter cela sur .NET 6, .NET Core ou .NET Framework ?** Oui—Aspose.BarCode prend en charge .NET Framework 4.5+, .NET Core 3.1+ et .NET 5/6+.

## Qu’est‑ce qu’un code‑barres DataMatrix ?
Un code‑barres DataMatrix est une matrice bidimensionnelle, carrée ou rectangulaire, de cellules noires et blanches pouvant stocker jusqu’à 2 335 caractères alphanumériques. Il est largement utilisé dans la fabrication, la logistique et la santé pour marquer de petits objets, car il reste lisible même lorsqu’il est partiellement endommagé.

## Pourquoi utiliser Aspose.BarCode pour .NET ?
Aspose.BarCode prend en charge **plus de 50 formats de sortie** (y compris PNG, JPEG, TIFF, SVG et PDF) et peut générer **toutes les 30 versions DataMatrix** sans charger l’image entière en mémoire, vous permettant de créer des codes‑barres dans des services à haut débit traitant des fichiers de plus de 100 Mo.

## Prérequis
Avant de plonger dans le code, assurez‑vous d’avoir les prérequis suivants :
- Un environnement de développement avec prise en charge .NET (Visual Studio 2022, Rider ou VS Code).  
- Une copie d’Aspose.BarCode pour .NET, que vous pouvez télécharger depuis la **page de téléchargement Aspose.BarCode .NET** : [Aspose.BarCode .NET download page](https://releases.aspose.com/barcode/net/).  
- Des connaissances de base en C# et le framework .NET.

Maintenant, explorons les versions DataMatrix et la façon de les générer avec Aspose.BarCode pour .NET.

## Comment générer des codes‑barres DataMatrix en .NET ?
Chargez le `BarcodeGenerator` avec le type `EncodeTypes.DataMatrix`, définissez la version et l’ECC souhaités, puis appelez `Save` pour écrire le fichier image. Ce modèle d’une seule ligne fonctionne pour n’importe quelle version que vous choisissez et gère automatiquement la taille des modules, les zones calmes et le rendu de l’image.

## Importer les espaces de noms
`BarcodeGenerator` est la classe principale d’Aspose.BarCode pour créer des images de codes‑barres.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

L’espace de noms `Aspose.BarCode.Generation` donne accès à la classe `BarcodeGenerator`, qui est la classe principale utilisée pour générer des images de codes‑barres.

Décomposons maintenant l’exemple en plusieurs étapes.

## Étape 1 : configurer le chemin de votre répertoire
Commencez par définir le chemin du répertoire où vous souhaitez enregistrer les codes‑barres DataMatrix générés.

```csharp
string path = "Your Directory Path";
```

Remplacez `"Your Directory Path"` par le chemin réel où vous voulez sauvegarder les images de codes‑barres.

## Étape 2 : initialiser le générateur de code‑barres
Créez une instance de la classe `BarcodeGenerator` et spécifiez le type de code‑barres comme `DataMatrix`. Vous pouvez également fournir les données que vous souhaitez encoder dans le code‑barres.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` est la classe principale qui crée et rend les symboles de codes‑barres.

## Étape 3 : configurer les propriétés du code‑barres
Vous pouvez personnaliser diverses propriétés du code‑barres DataMatrix, telles que ses dimensions et le type d’ECC (Error Correction Code). Voici un exemple de définition de la dimension X à 4 pixels et du choix d’ECC200 :

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` définit la taille de chaque module en pixels, et `DataMatrixEcc` sélectionne le niveau de correction d’erreurs.

## Étape 4 : définir la version DataMatrix et enregistrer
Vous pouvez spécifier la version DataMatrix en définissant le nombre de lignes et de colonnes. Après avoir configuré la version, enregistrez l’image du code‑barres.

Par exemple, pour créer un code‑barres DataMatrix de 22 lignes et 22 colonnes en utilisant ECC200 :

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

De même, vous pouvez générer un code‑barres avec d’autres paramètres en modifiant la version et le type d’ECC selon vos besoins.

## Étape 5 : répéter pour d'autres versions
Vous pouvez répéter l’Étape 4 pour d’autres versions DataMatrix. Par exemple, pour créer un code‑barres de 12 lignes et 64 colonnes en utilisant ECC200 :

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Étape 6 : changer les types ECC
Si vous souhaitez changer le type ECC en Ecc140, il suffit de mettre à jour la propriété ECC :

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Étape 7 : générer des codes‑barres avec différentes versions et ECC
Répétez l’Étape 4 pour d’autres versions DataMatrix et types ECC, en enregistrant chaque code‑barres avec un nom de fichier unique.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

Maintenant que vous avez appris à générer des codes‑barres DataMatrix avec Aspose.BarCode pour .NET, vous pouvez facilement intégrer cette fonctionnalité dans vos applications .NET.

## Pièges courants et conseils de dépannage
- **Dimensions de version incorrectes** – Les versions DataMatrix ont des paires ligne/colonne fixes. Fournir une paire non correspondante (par ex., 10 × 20) déclenchera une `ArgumentException`. Utilisez toujours l’une des combinaisons prises en charge listées dans la documentation de l’API.  
- **Licence manquante** – En mode essai, les images générées contiennent un filigrane. Appliquez une licence valide avec `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` avant de créer le générateur pour supprimer le filigrane. La classe `License` charge un fichier de licence pour activer le produit.  
- **Taille d’image importante** – Si vous avez besoin d’une sortie haute résolution, augmentez la propriété `XDimension` ; la bibliothèque met à l’échelle l’image proportionnellement sans perdre la lisibilité.
