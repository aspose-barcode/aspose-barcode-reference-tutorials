# How to create barcode PNG using Python – step‑by‑step guide

If you need to **create barcode PNG** files from arbitrary strings, this tutorial gives you a ready‑to‑run solution. You’ll see exactly how to generate a Code 128 barcode, convert text to a barcode image, and store the result as a PNG file—all with a few lines of Python.

The guide covers everything you need to know, from installing the required library to customizing the output for different use cases. By the end, you’ll be able to embed barcode generation into any Python project without searching for additional documentation.

## What you’ll learn

* Install the **barcode generator python** package that supports Code 128.
* Use `BarCodeGenerator` to **generate code 128 barcode** from a text string.
* Save the result as a high‑quality PNG with `save`.
* Adjust image size, foreground/background colors, and handle common errors.
* Verify that the PNG was created correctly.

### Prerequisites

| Requirement | Reason |
|-------------|--------|
| Python 3.8+ | Modern syntax and type hints |
| Internet access (for `pip install`) | To download the library |
| Write permission to a folder | To store the generated PNG |

No external services are required; everything runs locally.

## Step 1: Install the barcode library

The most straightforward way to **convert text to barcode** in Python is to use the **Aspose.BarCode for Python via .NET** package, which supports Code 128 out of the box.

```bash
pip install aspose-barcode
```

> **Pro tip:** If you work in a virtual environment, activate it before running the command to keep dependencies isolated.

## Step 2: Import the classes you need

After installation, import the core classes. The import statements are short, making the code easy to read.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` creates the barcode image.
* `EncodeTypes` provides an enumeration of supported symbologies, including `CODE_128`.

## Step 3: Define the text you want to encode

Choose any alphanumeric string. Code 128 can represent the full ASCII set, so you’re not limited to numbers.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

If the input contains unsupported characters, the generator raises a `ValueError`. Wrap the assignment in a `try` block if you expect user‑supplied data.

## Step 4: Create the barcode generator for Code 128

Instantiate `BarCodeGenerator` with the desired symbology and the text you defined. This is the core of **how to generate barcode** images in Python.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Why Code 128? It offers high density and can encode the full ASCII range, making it ideal for inventory systems, shipping labels, and ticketing.

## Step 5: (Optional) Customize appearance

You can fine‑tune the barcode before saving it. The following options are common:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

These settings affect the final **create barcode png** output without altering the encoded data.

## Step 6: Save the barcode as a PNG file

Finally, write the image to disk. The `save` method automatically detects the file extension, so passing `.png` creates a PNG image.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

If the target directory does not exist, Python raises a `FileNotFoundError`. Create the directory beforehand or use `os.makedirs` with `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### Expected output

After running the script, you’ll find `extended_barcode.png` in the `output` folder. Opening the file shows a crisp Code 128 barcode that encodes `1234567890`.

![Generated barcode PNG created with Python](generated_barcode.png "create barcode png example")

## Step 7: Verify the barcode (quick sanity check)

You can read the PNG back with the same library to confirm that the encoded value matches the original text.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Running this block prints:

```
Verification succeeded: 1234567890
```

If the assertion fails, double‑check the `barcode_text` and any custom parameters you set.

## Common variations and edge cases

| Situation | Adjustment |
|-----------|------------|
| **Longer text (> 20 characters)** | Increase `image_width` to avoid truncation. |
| **Need a transparent background** | Set `back_color = "Transparent"` before saving. |
| **Generate multiple barcodes in a loop** | Wrap steps 3‑6 in a `for` loop, changing `barcode_text` each iteration. |
| **Save as JPEG instead of PNG** | Change the file extension to `.jpg`; the library handles the format automatically. |
| **Running on a headless server** | The library does not require a GUI, making it safe for CI pipelines. |

## Full script for quick copy‑paste

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Save the script as `generate_barcode.py` and run:

```bash
python generate_barcode.py
```

You will see the confirmation messages and a new PNG file in the `output` folder.
