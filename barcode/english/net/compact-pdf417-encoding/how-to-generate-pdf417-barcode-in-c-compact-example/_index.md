# How to generate PDF417 barcode in C# – compact example

If you need to **generate PDF417 barcode** in a C# application, this guide shows you a complete, ready‑to‑run solution. We'll create a compact PDF417 barcode, adjust the module width, define the column count, and save the result as a PNG image—all with the Aspose.BarCode .NET library.

Generating a PDF417 barcode is common when you want to encode large amounts of data (e.g., URLs, contact cards, or inventory IDs) in a space‑efficient two‑dimensional format. By the end of this tutorial you will have a working `BarcodeGenerator` instance that produces a compact, high‑readability barcode ready for printing or display.

## Prerequisites

- .NET 6.0 or later (the code also works with .NET Framework 4.8)
- Visual Studio 2022 (or any C# IDE)
- Aspose.BarCode for .NET NuGet package (`Install-Package Aspose.BarCode`)
- Basic familiarity with C# syntax

No additional configuration is required; the example runs as a console app.

## Step 1: Create a PDF417 barcode generator

The first step is to instantiate `BarcodeGenerator` with the `EncodeTypes.Pdf417` enum and the text you want to encode.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Why this matters:** `EncodeTypes.Pdf417` tells the library to use the PDF417 symbology, while the second argument sets the data payload. You can replace `"Compact example"` with any string up to 1 800 characters.

## Step 2: Set the module width (X‑dimension) in pixels

The X‑dimension defines the width of a single barcode module (the smallest black or white square). A smaller pixel value yields a tighter barcode.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Why this matters:** A value of `2` pixels creates a compact appearance without sacrificing scan reliability on most modern scanners. Adjust the value if you need larger modules for low‑resolution printing.

## Step 3: Specify the number of columns

PDF417 allows you to control the number of columns, which influences the barcode’s aspect ratio.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Why this matters:** Fewer columns make the barcode taller, while more columns flatten it. Three columns work well for a compact, portrait‑oriented layout.

## Step 4: Enable compact mode by truncating the barcode

Compact mode removes unnecessary padding rows, making the barcode smaller while preserving the encoded data.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Why this matters:** Truncation is ideal when screen space is limited (e.g., mobile apps or small labels). The barcode remains fully readable because the encoding algorithm automatically adjusts error‑correction levels.

## Step 5: Save the barcode as a PNG image

Finally, write the generated barcode to a file. PNG preserves loss‑less quality, which is essential for barcode scanners.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Running the program creates `CompactPdf417.png` in the executable’s working directory. The image looks like this:

![Generated compact PDF417 barcode](CompactPdf417.png "Generated compact PDF417 barcode")

**Expected output:** A 2‑pixel‑wide, three‑column PDF417 barcode that encodes the text “Compact example”. Scanning the PNG with a standard barcode scanner should return the original string.

## Common variations and edge cases

| Situation | How to adjust the code |
|-----------|------------------------|
| **Longer data ( > 500 characters )** | Increase `Columns` to 5‑7 to keep the barcode from becoming too tall. |
| **Higher‑resolution printing** | Set `XDimension.Pixels` to 3 or 4 for larger modules. |
| **Different image format** | Replace `BarCodeImageFormat.Png` with `Jpeg` or `Bmp` as needed. |
| **Embedding the barcode in a PDF** | Use `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` instead of PNG. |

**Pro tip:** Always test the generated barcode on the target scanner hardware. Some low‑cost scanners struggle with very small X‑dimensions; if you encounter read errors, increase the pixel value by one step.

## Full, runnable example

Below is the complete program you can copy‑paste into a new console project. No additional files are required.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Compile and run the program (`dotnet run` if you use the .NET CLI). After execution, open `CompactPdf417.png` to verify the visual result.

## Conclusion

You now know **how to generate PDF417 barcode** in C# with a compact layout, custom X‑dimension, and column settings. The example demonstrates the essential steps: instantiate `BarcodeGenerator`, configure `XDimension` and `Columns`, enable `Truncate` for compact mode, and finally save the image. 

From here you can explore additional features such as error‑correction level, custom colors, or embedding the barcode directly into PDFs. Experiment with different `EncodeTypes` if you need other symbologies (e.g., QR, Code128) and integrate the same pattern of parameter configuration.

Happy coding, and may your barcodes always scan on the first try!
