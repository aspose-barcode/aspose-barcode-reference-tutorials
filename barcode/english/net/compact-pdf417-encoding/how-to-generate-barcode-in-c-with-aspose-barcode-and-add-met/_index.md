# How to generate barcode in C# with Aspose.BarCode and add metadata

If you need to **generate barcode in C#** for a logistics or inventory system, this guide shows you a complete, production‑ready solution. You’ll see how to create a Macro PDF417 barcode, attach rich metadata, and set a precise timestamp—all with the Aspose.BarCode library.

The tutorial covers everything from installing the NuGet package to saving the final PNG image. By the end, you can generate a barcode that carries file identifiers, segment information, and custom fields, ready for downstream scanners that support Macro PDF417.

## Prerequisites

Before you start, make sure you have:

* .NET 6.0 SDK or later (the code also works with .NET Framework 4.7.2+)
* Visual Studio 2022 or any C# IDE you prefer
* An active Aspose.BarCode license (the free trial works for development)
* Basic familiarity with C# syntax

> **Pro tip:** If you use a CI/CD pipeline, add the Aspose.BarCode package reference in your project file so builds stay reproducible.

## Step 1: Install Aspose.BarCode

Open a terminal in your project folder and run:

```bash
dotnet add package Aspose.BarCode
```

The command pulls the latest stable version (currently 24.9). After the restore finishes, you can reference the library in your source files.

## Step 2: Create a new C# console project (optional)

If you prefer a fresh start, create a console app:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

The `Program.cs` file will host the barcode generation code shown later.

## Step 3: Set up the barcode generator

The core of the process is the `BarcodeGenerator` class. You instantiate it with the desired `EncodeTypes` enum value and the text you want to encode.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Why each line matters

* **EncodeTypes.MacroPdf417** tells Aspose to produce a PDF417 barcode that can be split into segments. This is essential for large payloads that exceed a single symbol’s capacity.
* **XDimension.Pixels** controls the visual density. A value of 2 produces a clear image on most screens and printers without inflating file size.
* **MacroPdf417* properties** embed the metadata that downstream scanners read as separate fields (file ID, segment ID, etc.). This is the “how to add metadata” part of the tutorial.
* **MacroPdf417TimeStamp** demonstrates “how to set timestamp”. The `DateTime` instance can be any UTC time; using UTC avoids timezone ambiguity when the barcode travels across regions.
* **MacroPdf417Terminator** defines how the macro sequence ends. `Set` is the most common choice because it signals the final segment to the reader.
* **Save(..., BarCodeImageFormat.Png)** writes a lossless image that preserves the fine details required for reliable scanning.

## Step 4: Verify the generated barcode

Run the program:

```bash
dotnet run
```

You should see the console output:

```
Barcode saved to ExtPDF417Meta.png
```

Open `ExtPDF417Meta.png` in any image viewer. The picture will display a compact PDF417 symbol with the text **Åspóse.Barcóde©** and the embedded macro fields. Scanning the image with a PDF417‑compatible scanner (or a mobile app that supports Macro PDF417) will return the original text plus the metadata values you set.

### Expected visual characteristics

* Dark, evenly spaced vertical bars
* A quiet zone (margin) automatically added by Aspose
* No distortion, because the `XDimension` of 2 pixels matches the PNG’s native resolution

## Step 5: Common variations and edge cases

### 5.1 Handling special characters

The sample text contains Unicode characters (`Å`, `ó`, `©`). Aspose.BarCode encodes them using UTF‑8 by default, so they appear correctly in the barcode. If you need a different encoding (e.g., ISO‑8859‑1), set:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Large file identifiers

`MacroPdf417FileID` accepts a 32‑bit integer. For values larger than `int.MaxValue`, split the identifier across multiple fields or use a GUID stored as a string in `MacroPdf417FileName`.

### 5.3 Adjusting the number of columns

Increasing `Pdf417.Columns` reduces the barcode height but widens each row. If the barcode must fit a narrow label, lower the column count and increase the row count automatically.

### 5.4 Saving in other formats

Aspose supports BMP, JPEG, TIFF, and SVG. Replace `BarCodeImageFormat.Png` with the desired enum value, e.g., `BarCodeImageFormat.Svg` for a scalable vector graphic.

## Step 6: Integrate the barcode into a larger workflow

Once you have the PNG file, you can:

* Embed it in a PDF invoice using Aspose.PDF.
* Attach it to an email as a proof of delivery.
* Store the image bytes in a database for later retrieval.

Below is a quick snippet that converts the PNG to a byte array for storage:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Frequently asked questions

**Q: Does this work on .NET Core?**  
A: Yes. The same API works on .NET Core, .NET 5+, and .NET Framework. Just reference the appropriate NuGet package.

**Q: What if I need to generate a non‑macro PDF417?**  
A: Use `EncodeTypes.Pdf417` instead of `EncodeTypes.MacroPdf417`. The macro‑specific properties will be ignored.

**Q: Can I add custom key/value pairs beyond the built‑in fields?**  
A: Aspose.BarCode does not expose arbitrary user fields for Macro PDF417. If you need extra data, encode it in the main text payload or switch to a QR code, which supports structured append.
