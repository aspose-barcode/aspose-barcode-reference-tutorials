# How to generate DataMatrix barcodes with Aspose.BarCode for .NET

If you need a reliable way to embed machine‑readable symbols in your .NET applications, **how to generate DataMatrix** barcodes is a common requirement. Aspose.BarCode for .NET offers a fully managed API that handles every step—from choosing the right DataMatrix version to fine‑tuning error‑correction levels—without requiring external tools. In this tutorial we’ll walk through a complete example, explain why each setting matters, and show you how to save the result as a PNG or JPEG image.

## Quick answers
- **What library creates DataMatrix barcodes?** Aspose.BarCode for .NET.  
- **How many DataMatrix versions are supported?** All 30 standard square and rectangular versions (from 10×10 up to 144×144 modules).  
- **Which ECC types can I use?** ECC200 (default) and ECC140.  
- **Do I need a license for development?** A free 30‑day trial works for testing; a commercial license is required for production.  
- **Can I run this on .NET 6, .NET Core, or .NET Framework?** Yes—Aspose.BarCode supports .NET Framework 4.5+, .NET Core 3.1+, and .NET 5/6+.

## What is a DataMatrix barcode?
A DataMatrix barcode is a two‑dimensional, square or rectangular matrix of black and white cells that can store up to 2,335 alphanumeric characters. It is widely used in manufacturing, logistics, and healthcare for marking small items because it remains readable even when partially damaged.

## Why use Aspose.BarCode for .NET?
Aspose.BarCode supports **50+ output formats** (including PNG, JPEG, TIFF, SVG, and PDF) and can generate **all 30 DataMatrix versions** without loading the entire image into memory, allowing you to create barcodes in high‑throughput services that process files larger than 100 MB.

## How to generate DataMatrix barcodes in .NET?

Load the `BarcodeGenerator` with the `EncodeTypes.DataMatrix` type, set the desired version and ECC, then call `Save` to write the image file. This single‑line pattern works for any version you choose and automatically handles module sizing, quiet zones, and image rendering.

## Import namespaces

`BarcodeGenerator` is Aspose.BarCode's core class for creating barcode images.  
```csharp

```
```csharp

```

The `Aspose.BarCode.Generation` namespace provides access to the `BarcodeGenerator` class, which is the primary class used to generate barcode images.

Now, let's break down the example into multiple steps.

## Step 1: set up your directory path

Begin by defining the directory path where you want to save the generated DataMatrix barcodes.

```csharp
string path = "Your Directory Path";
```

Replace `"Your Directory Path"` with the actual path where you want to save the barcode images.

## Step 2: initialize the barcode generator

Create an instance of the `BarcodeGenerator` class and specify the barcode type as `DataMatrix`. You can also provide the data that you want to encode within the barcode.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` is the main class that creates and renders barcode symbols.

## Step 3: configure barcode properties

You can customize various properties of the DataMatrix barcode, such as its dimensions and ECC (Error Correction Code) type. Here's an example of setting the X‑dimension to 4 pixels and choosing ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` sets the size of each module in pixels, and `DataMatrixEcc` selects the error‑correction level.

## Step 4: set DataMatrix version and save

You can specify the DataMatrix version by setting the number of rows and columns. After configuring the version, save the barcode image.

For example, to create a DataMatrix barcode with 22 rows and 22 columns using ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

Similarly, you can generate a barcode with different parameters by changing the version and ECC type as needed.

## Step 5: repeat for other versions

You can repeat Step 4 for other DataMatrix versions. For example, to create a barcode with 12 rows and 64 columns using ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Step 6: switch ECC types

If you want to change the ECC type to Ecc140, you can do so by updating the ECC property:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Step 7: generate barcodes with different versions and ECC

Repeat Step 4 for other DataMatrix versions and ECC types, saving each barcode with a unique file name.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

## Common pitfalls and troubleshooting tips

- **Incorrect version dimensions** – DataMatrix versions have fixed row/column pairs. Supplying a mismatched pair (e.g., 10 × 20) will raise an `ArgumentException`. Always use one of the supported combinations listed in the API docs.  
- **Missing license** – In trial mode the generated images contain a watermark. Apply a valid license with `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` before creating the generator to remove the watermark. The `License` class loads a license file to activate the product.  
- **Large image size** – If you need high‑resolution output, increase the `XDimension` property; the library scales the image proportionally without losing readability.
