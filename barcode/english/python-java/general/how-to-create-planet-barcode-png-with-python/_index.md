# How to create planet barcode PNG with Python

If you need to **create planet barcode PNG**, this tutorial walks you through the complete process using Python. You’ll also learn **how to generate planet barcode** step by step, configure its appearance, and save the result as a high‑quality PNG image.

Generating a Planet barcode is common in postal automation, inventory tracking, and logistics systems. By the end of this guide you will have a self‑contained script that produces a ready‑to‑use PNG file, and you’ll understand how to adapt the code for different sizes or image formats.

## Prerequisites

Before you start, make sure you have:

* Python 3.8 or newer installed.
* Access to the `aspose-barcode` package (or any compatible library that provides `BarcodeGenerator`, `EncodeTypes`, and `BarCodeImageFormat` classes).
* Write permission to the directory where you want to store the PNG file.

You can install the required library with pip:

```bash
pip install aspose-barcode
```

> **Pro tip:** Use a virtual environment to keep dependencies isolated from other projects.

## Create planet barcode PNG – full code walkthrough

The following script demonstrates every step required to generate a Planet barcode PNG with empty (unfilled) bars. Copy the code into a file named `planet_barcode.py` and run it with `python planet_barcode.py`.

```python
# planet_barcode.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Initialize a Planet barcode generator with the data to encode
# The data "123456" is a typical numeric payload for postal services.
generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

# Step 2: Set the width of each bar (X dimension) to 4 pixels.
# Adjusting the X dimension changes the overall size and readability.
generator.parameters.barcode.x_dimension.pixels = 4

# Step 3: Configure the barcode to use empty (unfilled) bars.
# When `filled_bars` is False, the dark bars become transparent,
# which is useful for overlaying the barcode on colored backgrounds.
generator.parameters.barcode.filled_bars = False

# Step 4: Save the generated barcode as a PNG image.
# The output path can be absolute or relative; ensure the folder exists.
output_path = "output/PostalPlanetEmptyBars.png"
generator.save(output_path, BarCodeImageFormat.PNG)

print(f"Planet barcode PNG saved to: {output_path}")
```

### What each line does

| Line | Explanation |
|------|-------------|
| `from aspose.barcode import ...` | Imports the classes needed to create and configure the barcode. |
| `BarcodeGenerator(EncodeTypes.Planet, "123456")` | Instantiates a generator for the **Planet** symbology using the numeric string `"123456"`. |
| `x_dimension.pixels = 4` | Sets the bar width to 4 px; larger values produce a bigger barcode, while smaller values reduce file size. |
| `filled_bars = False` | Switches the barcode to use **empty bars**, making the dark modules transparent. |
| `save(..., BarCodeImageFormat.PNG)` | Writes the barcode to a PNG file, preserving lossless quality. |
| `print(...)` | Confirms successful creation in the console. |

## How to generate planet barcode with custom settings

While the basic script covers most use‑cases, you may need to adjust the barcode for specific requirements:

1. **Different data lengths** – Planet barcodes support up to 12 numeric characters. Change `"123456"` to any valid numeric string within that range.
2. **Alternative image formats** – Replace `BarCodeImageFormat.PNG` with `BarCodeImageFormat.JPEG` or `BarCodeImageFormat.BMP` to suit downstream processing pipelines.
3. **Changing the X dimension** – Larger values (e.g., `8`) create a higher‑resolution barcode, which is helpful for printing on large labels.
4. **Background colors** – If you want a colored background, set `generator.parameters.barcode.back_color` before saving.

Example with a custom background color:

```python
from aspose.barcode import Color

generator.parameters.barcode.back_color = Color.get_yellow()
generator.save("output/PlanetYellowBackground.png", BarCodeImageFormat.PNG)
```

## Common pitfalls and how to avoid them

| Issue | Reason | Fix |
|-------|--------|-----|
| **FileNotFoundError** when saving | The target directory does not exist. | Create the directory beforehand (`os.makedirs("output", exist_ok=True)`). |
| **Invalid data length** | Planet barcode only accepts numeric data up to 12 characters. | Validate the input string before creating the generator. |
| **Transparent bars not visible** | Some viewers ignore transparency on a white canvas. | Place the barcode on a non‑white background or export as PNG with an alpha channel. |

## Verifying the output

After running the script, open `PostalPlanetEmptyBars.png` with any image viewer. You should see a series of vertical bars where the dark modules are transparent, leaving only the outline of the barcode. To confirm that the barcode is scannable, use a mobile barcode scanner app that supports the Planet symbology.

If the image appears blank, double‑check:

* The `filled_bars` flag is set to `False`.
* The X dimension is not set to zero.
* The output path points to an existing folder.
