# How to save barcode images in C# using the BarcodeGenerator API

If you need to **how to save barcode** files from a .NET application, this guide shows the exact steps. You’ll see a complete **barcode generator example** that creates a DataBar Stacked Omnidirectional barcode, adjusts its aspect ratio, and saves two PNG files.

Saving barcode images is a common requirement when building inventory systems, point‑of‑sale terminals, or automated labeling workflows. By the end of this tutorial you can generate barcode C# code that produces reliable images ready for printing or display.

## Prerequisites

Before you start, make sure you have:

- .NET 6.0 SDK or later installed  
- Visual Studio 2022 (or any C#‑compatible IDE)  
- The **Aspose.BarCode for .NET** NuGet package (the code uses `Aspose.BarCode.Generation`)  

You can add the package with the following command:

```bash
dotnet add package Aspose.BarCode
```

## Step 1: Set up a minimal C# console project

Create a new console project and reference the library:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Open `Program.cs`. The file will contain the `Main` method where we will place the **generate barcode C#** logic.

## Step 2: Initialize the BarcodeGenerator for a DataBar Stacked Omnidirectional barcode

The first task in any **create databar barcode** workflow is to instantiate `BarcodeGenerator` with the correct `EncodeType`. The constructor receives the barcode symbology and the data string.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

The `EncodeTypes.DatabarStackedOmniDirectional` value tells the library to produce a **create databar barcode** that can be scanned from any direction.

## Step 3: Configure the X‑dimension (module width)

The X‑dimension controls the smallest bar width in pixels. Setting it to a low value keeps the barcode compact while preserving readability.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Step 4: **How to adjust aspect ratio** – first value (15)

DataBar barcodes expose an `AspectRatio` property that influences the height‑to‑width relationship. A higher ratio yields a taller barcode, which can improve scanning reliability on certain printers.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Step 5: **How to save barcode** – first image (aspect ratio 15)

Now we actually **how to save barcode** to a file. The `Save` method takes a file path and an image format. In this example we store a PNG file.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Tip:** The directory of the executable is the default write location. Use an absolute path if you need a specific folder.

## Step 6: **How to adjust aspect ratio** – second value (30)

To demonstrate flexibility, change the aspect ratio and save a second image. This shows how the same encoded data can be rendered with different visual proportions.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Running the program produces two PNG files:

- `DatabarAspectRatio15.png` – barcode with a moderate height  
- `DatabarAspectRatio30.png` – barcode with a higher height for challenging scan environments  

Both files are ready to be loaded into UI controls, printed on labels, or transmitted via API.

### Expected output

When you open the generated images, you should see a DataBar Stacked Omnidirectional barcode that encodes the GTIN‑14 value `12345678901231`. The visual difference between the two files is solely the height, confirming that **how to adjust aspect ratio** works as intended.

## Step 7: Full source code for reference

Below is the complete, runnable program. Copy it into `Program.cs`, build, and run.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Common questions and edge‑case handling

### What if the target folder does not exist?

`Save` throws a `DirectoryNotFoundException`. Create the directory first:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### How to change image format?

Replace `BarCodeImageFormat.Png` with `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp`, or `BarCodeImageFormat.Tiff` depending on downstream requirements.

### Can I generate multiple barcodes in a loop?

Yes. Instantiate a new `BarcodeGenerator` for each data string or reuse the same instance after updating the `CodeText` property:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### Does **how to save barcode** work on non‑Windows platforms?

Aspose.BarCode is cross‑platform. The same code runs on Linux and macOS as long as the .NET runtime is present.
