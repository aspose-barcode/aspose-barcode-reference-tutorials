# Barcode generator example in C# – generate Planet barcode and create barcode image

If you need a **barcode generator example** in C#, this guide shows you exactly how to generate a Planet barcode and create a barcode image c# in just a few lines of code. You’ll see a complete, ready‑to‑run solution that you can drop into any .NET project.

A Planet barcode is used by postal services to encode routing information. By the end of this tutorial you will understand why the library automatically determines the barcode height, how to control the X dimension, and how to save the result as a PNG file. No external tools are required—just the Aspose.BarCode for .NET package and a .NET development environment.

## Prerequisites

Before you start, make sure you have:

* .NET 6.0 SDK or later installed  
* Visual Studio 2022 (or any IDE that supports .NET)  
* The **Aspose.BarCode for .NET** NuGet package (`Aspose.BarCode`)  

You can install the package from the command line:

```bash
dotnet add package Aspose.BarCode
```

## Step 1: Initialize the barcode generator for Planet encoding

The first step in any **barcode generator example** is to create a `BarcodeGenerator` instance and specify the encoding type. For a Planet barcode you use `EncodeTypes.Planet` and pass the data string you want to encode.

```csharp
using Aspose.BarCode.Generation;

// Create a Planet barcode generator with the data to encode
BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

**Why this matters:** The `EncodeTypes.Planet` enum tells the library to use the Planet symbology, which has a fixed module pattern required by postal standards. Supplying the data (`"123456"` in this case) ensures the barcode contains the correct numeric routing code.

## Step 2: Configure the X dimension (module width) in pixels

The X dimension controls the width of each individual module (the smallest bar). Adjusting it changes the overall size of the barcode without affecting readability.

```csharp
// Set the X dimension (module width) to 4 pixels
generator.Parameters.Barcode.XDimension.Pixels = 4;
```

**Why this matters:** A larger X dimension produces a larger barcode, which can be useful when printing on large envelopes. The library automatically scales the height to maintain the correct aspect ratio for Planet barcodes.

## Step 3: Save the barcode image to disk

Finally, you save the generated image. The library determines the optimal height, so you only need to specify the output path and format.

```csharp
using Aspose.BarCode;

// Define the output file path
string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";

// Save the barcode as a PNG image
generator.Save(outputFile, BarCodeImageFormat.Png);
```

**Why this matters:** Saving as PNG preserves the crisp edges of the barcode, which is essential for reliable scanning. The `Save` method also supports other formats (JPEG, BMP, TIFF) if you need a different output.

## Step 4: Optional – customize foreground and background colors

If your application requires a different visual style, you can change the barcode colors before saving.

```csharp
// Set foreground (bars) to dark blue and background to light gray
generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

// Save the customized image
generator.Save(@"C:\Barcodes\PlanetCustomColors.png", BarCodeImageFormat.Png);
```

**Tip:** Always test the customized barcode with a real scanner to confirm that color changes do not affect readability.

## Step 5: Handling errors and validation

The Aspose.BarCode library throws `ArgumentException` if the data does not meet the Planet symbology requirements (e.g., non‑numeric characters). Wrap the generation code in a try‑catch block to provide clear feedback.

```csharp
try
{
    BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "ABC123");
    generator.Save(@"C:\Barcodes\InvalidPlanet.png", BarCodeImageFormat.Png);
}
catch (ArgumentException ex)
{
    Console.WriteLine($"Invalid data for Planet barcode: {ex.Message}");
}
```

**Why this matters:** Planet barcodes accept only numeric data of specific lengths. Proper validation prevents runtime failures and saves time during integration testing.

## Full, runnable example

Putting all the steps together gives you a self‑contained program that you can copy, paste, and run.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;
using Aspose.BarCode;

class Program
{
    static void Main()
    {
        // Step 1: Initialize the generator with Planet encoding
        BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");

        // Step 2: Set the X dimension (module width) to 4 pixels
        generator.Parameters.Barcode.XDimension.Pixels = 4;

        // Optional: customize colors (comment out if not needed)
        // generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
        // generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

        // Step 3: Save the barcode image
        string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";
        generator.Save(outputFile, BarCodeImageFormat.Png);

        Console.WriteLine($"Planet barcode saved to {outputFile}");
    }
}
```

Compile and run the program:

```bash
dotnet run
```

You should see the console message confirming the file location, and the PNG file will contain the generated Planet barcode.

## Common variations and edge cases

| Variation | How to implement | When to use |
|-----------|------------------|------------|
| **Different data length** | Change the second argument in `new BarcodeGenerator(EncodeTypes.Planet, "987654321")` | Postal services that require longer routing numbers |
| **Higher resolution** | Set `generator.Parameters.ImageResolution = 300;` before `Save` | Printing on high‑dpi printers |
| **Different image format** | Use `BarCodeImageFormat.Jpeg` or `BarCodeImageFormat.Tiff` | When PNG is not suitable for your workflow |
| **Dynamic file name** | `string outputFile = Path.Combine(folder, $"Planet_{DateTime.Now:yyyyMMdd_HHmmss}.png");` | Batch processing of multiple barcodes |

## Pro tips for a robust barcode generator example

* **Reuse the generator instance** when creating many barcodes with the same settings; only change `EncodeTypes` or the data string to improve performance.  
* **Validate input** before passing it to `BarcodeGenerator`. A simple regex like `^\d{6,9}$` ensures the data conforms to Planet requirements.  
* **Dispose of resources** if you generate thousands of images in a long‑running service. The `BarcodeGenerator` implements `IDisposable`, so wrap it in a `using` block when appropriate.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, data))
{
    // configure and save...
}
```
