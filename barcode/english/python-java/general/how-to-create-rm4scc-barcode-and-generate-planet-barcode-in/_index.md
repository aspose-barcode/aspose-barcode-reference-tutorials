# How to create RM4SCC barcode and generate planet barcode in C#

If you need to **create RM4SCC barcode** for postal applications, this guide shows you the exact steps. You’ll also learn how to **generate planet barcode** with both automatic and fixed heights, so the same code works for any postal symbology.

The tutorial covers everything required to produce PNG images that meet postal standards. No external tools are needed beyond the Aspose.BarCode for .NET library. By the end, you can generate barcodes programmatically and control their dimensions precisely.

## Prerequisites

Before you start, ensure you have:

* .NET 6.0 or later installed
* Visual Studio 2022 (or any C# IDE)
* Aspose.BarCode for .NET NuGet package  
  `Install-Package Aspose.BarCode`
* Write permission to the output directory

These items let you compile and run the sample code without additional configuration.

## Step 1: Initialize the barcode generator for RM4SCC

The first operation creates a `BarcodeGenerator` instance configured for the RM4SCC symbology. This object holds all settings for the barcode image.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Why this matters** – `EncodeTypes.RM4SCC` tells Aspose to use the postal RM4SCC format, while the data string `"123456"` represents the postal code you want to encode.

## Step 2: Set the module width (X‑dimension)

The module width controls the thin bar size. A common value for postal barcodes is 4 pixels.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Explanation** – The X‑dimension influences overall barcode readability. Choosing 4 px matches most postal scanners.

## Step 3: Save with automatic bar height

When you omit a height value, Aspose calculates the optimal height automatically based on the symbology rules.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Result** – The generated PNG (`PostalRM4SCCBarHeightNone.png`) contains a correctly sized RM4SCC barcode ready for printing.

## Step 4: Create a Planet barcode with automatic height

The same pattern works for the Planet symbology. Start by initializing the generator with `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Why reuse the code** – Both RM4SCC and Planet share the same parameter structure, so you can switch symbologies by changing only the `EncodeTypes` value.

## Step 5: Define a fixed bar height for RM4SCC

Some postal services require a specific bar height (e.g., 100 px). You can set this explicitly before saving.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Tip** – Setting `BarHeight.Pixels` overrides the automatic calculation, giving you full control over the visual size.

## Step 6: Define a fixed bar height for Planet

Apply the same fixed‑height technique to a Planet barcode.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Result** – Both `PostalRM4SCCBarHeight100Pixels.png` and `PostalPlanetBarHeight100Pixels.png` contain barcodes with a consistent 100 px bar height, satisfying strict postal specifications.

## Complete source code

Below is the full, runnable program that encompasses all four examples. Copy it into a new console project and adjust the output path as needed.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Expected output** – After running the program, the specified directory contains four PNG files:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC with automatic height
* `PostalPlanetBarHeightNone.png` – Planet with automatic height
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC with 100 px height
* `PostalPlanetBarHeight100Pixels.png` – Planet with 100 px height

Open any file to verify that the bars are crisp, the module width is 4 px, and the height matches the chosen setting.

## Common questions and edge cases

| Question | Answer |
|----------|--------|
| **Can I use other image formats?** | Yes. Replace `BarCodeImageFormat.Png` with `Jpeg`, `Bmp`, or `Gif` as needed. |
| **What if the data string is longer?** | The generator automatically adjusts the number of bars. Ensure the data complies with the symbology’s length limits (RM4SCC ≤ 6 digits, Planet ≤ 6 digits). |
| **How do I change bar color?** | Set `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` before calling `Save`. |
| **Is DPI important for printing?** | You can set `rm4sccAuto.Parameters.ImageResolution.DpiX` and `DpiY` to match your printer’s resolution. |
