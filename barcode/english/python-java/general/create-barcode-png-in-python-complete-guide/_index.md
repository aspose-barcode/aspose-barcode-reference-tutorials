# Create barcode PNG in Python – Complete Guide

Ever needed to **create barcode PNG** but weren’t sure which library or settings to use? You’re not alone. In many inventory or checkout systems the first step is turning raw data into a crisp PNG image that scanners love.  

In this tutorial we’ll walk through **how to generate databar**, how to **adjust barcode height**, and even the trick to **change barcode** parameters on the fly—all while using **barcode with sample data** that you can copy‑paste straight into your project.  

## What You’ll Learn

- Set up the Aspose.BarCode (or similar) library in Python.  
- **Create barcode PNG** files with different heights in just a few lines of code.  
- **How to change barcode** properties such as module size and bar height.  
- Use a realistic GTIN‑14 value as **barcode with sample data**.  
- Tips for troubleshooting common pitfalls like blurry images or incorrect encoding.

No prior experience with barcode generation is required—just a basic Python interpreter and the ability to install a pip package.

## Prerequisites

- Python 3.8+ installed on your machine.  
- Access to the internet to install the `aspose-barcode` package (or any compatible library).  
- A writable folder where the PNG files will be saved (replace `YOUR_DIRECTORY` in the script).  

If you already have these, great—let’s dive in.

## Create barcode PNG – Setting Up the Generator

First thing’s first: we need a generator object that knows we’re dealing with a **DataBar Omnidirectional** barcode. The code below imports the necessary classes, creates the generator with a **barcode with sample data**, and sets a modest module size.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Why this matters:** The `EncodeTypes.DATABAR_OMNIDIRECTIONAL` tells the engine to produce a **DataBar** that can be read from any direction, perfect for retail shelves. Setting `x_dimension` keeps the bars sharp, while `bar_height` controls the visual size of the code.

## How to Generate Databar with Sample Data

Now that the generator is ready, we’ll **create barcode PNG** files. The first save uses a 30‑pixel height, which is often sufficient for on‑screen previews.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Running the script up to this point will produce a PNG file that looks like a compact, high‑contrast barcode. Open it in any image viewer to verify that the bars are crisp and the GTIN‑14 data is encoded.

## Adjust Barcode Height (How to Change Barcode)

Sometimes you need a taller barcode for larger labels or higher‑resolution printing. This is where **adjust barcode height** comes into play. Changing the height is as simple as updating the `BarHeight` property and saving again.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**How it works:** The generator re‑uses the same data and module size; only the vertical dimension changes. This avoids recreating the whole object and demonstrates **how to change barcode** settings dynamically.

## Full Script – One‑Stop Solution

Below is the complete, runnable script that combines all the steps. Copy, paste, and run—it should work out of the box after you install the package.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Expected Output

Running the script will generate two files:

- `DatabarOmni30.png` – 30 px tall DataBar Omnidirectional barcode.  
- `DatabarOmni60.png` – 60 px tall version of the same barcode.

Both images are PNG format, lossless, and ready for embedding in PDFs, HTML pages, or printing directly onto labels.

## Common Pitfalls & Pro Tips

- **Pixel vs. DPI:** PNG files are pixel‑based. If you need a specific print size, calculate `BarHeight` based on DPI (e.g., 300 dpi → 30 px ≈ 0.1 in).  
- **Incorrect encoding:** Make sure the data string follows the GS1 Application Identifier format (`(01)` for GTIN‑14). Missing parentheses can cause the library to fall back to a plain numeric barcode.  
- **File paths:** Use raw strings (`r"..."`) or double backslashes on Windows to avoid escape‑character headaches.  
- **Performance:** If you’re generating thousands of barcodes, instantiate the generator once and only modify the `BarHeight` or data string between saves. This reduces memory churn.
