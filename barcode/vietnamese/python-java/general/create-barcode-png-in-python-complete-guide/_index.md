## Tạo barcode PNG – Cài đặt Trình tạo

Điều đầu tiên cần làm: chúng ta cần một đối tượng generator biết rằng chúng ta đang làm việc với mã **DataBar Omnidirectional**. Đoạn mã dưới đây nhập các lớp cần thiết, tạo generator với **barcode with sample data**, và đặt kích thước module vừa phải.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Tại sao điều này quan trọng:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` cho engine biết tạo một **DataBar** có thể đọc được từ bất kỳ hướng nào, hoàn hảo cho kệ bán lẻ. Cài đặt `x_dimension` giữ cho các thanh sắc nét, trong khi `bar_height` kiểm soát kích thước hiển thị của mã.

## Cách tạo Databar với dữ liệu mẫu

Bây giờ generator đã sẵn sàng, chúng ta sẽ **create barcode PNG** các tệp. Lần lưu đầu tiên sử dụng chiều cao 30 pixel, thường đủ cho việc xem trước trên màn hình.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Chạy script tới bước này sẽ tạo ra một tệp PNG trông như một barcode gọn gàng, độ tương phản cao. Mở nó bằng bất kỳ trình xem ảnh nào để xác nhận các thanh sắc nét và dữ liệu GTIN‑14 đã được mã hoá.

## Điều chỉnh chiều cao barcode (Cách **change barcode**)

Đôi khi bạn cần một barcode cao hơn cho nhãn lớn hơn hoặc in độ phân giải cao hơn. Đây là lúc **adjust barcode height** đóng vai trò. Thay đổi chiều cao chỉ cần cập nhật thuộc tính `BarHeight` và lưu lại.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Cách hoạt động:** Generator tái sử dụng cùng dữ liệu và kích thước module; chỉ thay đổi chiều dọc. Điều này tránh việc tạo lại toàn bộ đối tượng và minh họa cách **change barcode** các cài đặt một cách động.

## Script đầy đủ – Giải pháp một cửa

Dưới đây là script đầy đủ, có thể chạy được, kết hợp tất cả các bước. Sao chép, dán và chạy — nó sẽ hoạt động ngay sau khi bạn cài đặt gói.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Kết quả mong đợi

Chạy script sẽ tạo ra hai tệp:

- `DatabarOmni30.png` – barcode DataBar Omnidirectional cao 30 px.  
- `DatabarOmni60.png` – phiên bản cao 60 px của cùng một barcode.

Cả hai hình ảnh đều ở định dạng PNG, không mất dữ liệu, và sẵn sàng để nhúng vào PDF, trang HTML, hoặc in trực tiếp lên nhãn.

## Những lỗi thường gặp & Mẹo chuyên nghiệp

- **Pixel vs. DPI:** Tệp PNG dựa trên pixel. Nếu bạn cần kích thước in cụ thể, tính `BarHeight` dựa trên DPI (ví dụ, 300 dpi → 30 px ≈ 0.1 in).  
- **Incorrect encoding:** Đảm bảo chuỗi dữ liệu tuân theo định dạng GS1 Application Identifier (`(01)` cho GTIN‑14). Thiếu dấu ngoặc có thể khiến thư viện quay lại barcode số thuần.  
- **File paths:** Sử dụng raw strings (`r"..."`) hoặc dấu gạch chéo ngược đôi trên Windows để tránh lỗi ký tự escape.  
- **Performance:** Nếu bạn tạo hàng ngàn barcode, hãy khởi tạo generator một lần và chỉ sửa đổi `BarHeight` hoặc chuỗi dữ liệu giữa các lần lưu. Điều này giảm tải bộ nhớ.
