# Tạo mã vạch Planet trong C# – hướng dẫn lập trình đầy đủ

Nếu bạn cần **tạo mã vạch planet** trong C#, hướng dẫn này sẽ chỉ cho bạn cách thực hiện chi tiết. Bạn cũng sẽ khám phá **cách đặt kích thước mã vạch** để các thanh hiển thị đúng chiều rộng bạn yêu cầu.

Việc tạo mã vạch Planet thường gặp khi làm việc với các dịch vụ bưu chính hoặc hệ thống logistics. Đoạn mã dưới đây bao gồm cả phiên bản thanh đầy (filled‑bar) mặc định và kiểu thanh rỗng (empty‑bar) tùy chọn, cùng một ví dụ nhanh cho định dạng RM4SCC. Khi kết thúc tutorial, bạn sẽ có một đoạn mã có thể tái sử dụng và chèn vào bất kỳ dự án .NET nào.

## Yêu cầu trước

Trước khi bắt đầu, hãy chắc chắn rằng bạn có:

* .NET 6.0 hoặc phiên bản mới hơn đã được cài đặt (API cũng hoạt động với .NET Framework 4.6+)
* Gói NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`) đã được thêm vào dự án
* Một đường dẫn thư mục có quyền ghi để lưu các file PNG
* Kiến thức cơ bản về cú pháp C# và Visual Studio (hoặc bất kỳ IDE nào)

> **Mẹo chuyên nghiệp:** Sử dụng đường dẫn tuyệt đối hoặc `Path.Combine(Environment.CurrentDirectory, "output")` để tránh các vấn đề quyền khi lưu ảnh.

## Bước 1 – Khởi tạo trình tạo mã vạch Planet (thanh đầy)

Bước đầu tiên là tạo một thể hiện `BarcodeGenerator` cho ký hiệu Planet. Mặc định, trình tạo sẽ tạo các **thanh đầy**.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Enum `EncodeTypes.Planet` thông báo cho Aspose.BarCode sử dụng định dạng Planet, trong khi `"123456"` là dữ liệu sẽ được mã hoá.

## Bước 2 – Cách đặt kích thước mã vạch để đồng nhất

Để kiểm soát chiều rộng của mỗi thanh, điều chỉnh **X‑dimension**. Đây là cách chính để **đặt kích thước mã vạch** và đảm bảo mã vạch phù hợp với kích thước nhãn của bạn.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

Thuộc tính `Pixels` xác định độ rộng thanh tính bằng pixel trên màn hình. Giá trị thường dùng là 2 – 5 pixel cho các nhãn thư tiêu chuẩn; tăng giá trị lên nếu cần in lớn hơn.

## Bước 3 – Lưu mã vạch Planet đầy dưới dạng PNG

Bây giờ ghi ảnh ra đĩa. PNG giữ được các cạnh sắc nét, rất thích hợp cho việc quét.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Thay `YOUR_DIRECTORY` bằng đường dẫn bạn đã chuẩn bị ở trên. Sau khi chạy đoạn mã, bạn sẽ thấy một file tương tự như hình dưới.

## Bước 4 – Tạo mã vạch Planet với các thanh rỗng (không đầy)

Nếu dịch vụ bưu chính của bạn yêu cầu các thanh **rỗng**, bạn cần bật cờ `FilledBars` sau khi khởi tạo trình tạo.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Constructor vẫn giống nhau; sự khác biệt nằm ở bước cấu hình tiếp theo.

## Bước 5 – Cách đặt kích thước mã vạch và làm thanh rỗng

Một lần nữa, đặt X‑dimension để đồng nhất về mặt hình ảnh, sau đó tắt thanh đầy.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

Thuộc tính `FilledBars = false` chính là yếu tố thay đổi kiểu hiển thị. Giữ nguyên X‑dimension giúp mã vạch thanh rỗng căn chỉnh hoàn hảo với phiên bản thanh đầy.

## Bước 6 – Lưu mã vạch Planet rỗng

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Bây giờ bạn sẽ có hai file PNG: một với thanh đặc và một với thanh rỗng, cả hai cùng kích thước.

## Bước 7 – (Tùy chọn) Tạo mã vạch RM4SCC để so sánh

RM4SCC là một ký hiệu bưu chính khác sử dụng cùng kiểu thanh đầy mặc định. Các bước tương tự như ví dụ Planet, chứng minh rằng **cách đặt kích thước mã vạch** hoạt động trên nhiều định dạng.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Chạy ba bước này sẽ tạo ra file `PostalRM4SCCFilledBars.png`, bạn có thể so sánh nó bên cạnh các output của Planet.

## Tại sao X‑dimension lại quan trọng

X‑dimension quyết định **chiều rộng tối thiểu có thể in** của mỗi thanh. Nếu đặt quá thấp, mã vạch có thể bị mờ trên máy in độ phân giải thấp, gây lỗi quét. Ngược lại, X‑dimension quá lớn có thể vượt quá kích thước nhãn và lãng phí không gian. Bằng cách **cách đặt kích thước mã vạch** một cách rõ ràng, bạn có được kiểm soát quyết định về kích thước ảnh cuối cùng, điều này rất quan trọng cho quy trình gửi thư tự động.

## Những lỗi thường gặp và cách tránh

| Vấn đề | Nguyên nhân | Giải pháp |
|-------|------------|-----------|
| Mã vạch bị kéo dài | X‑dimension được đặt bằng điểm thay vì pixel | Luôn dùng thuộc tính `Pixels` để kiểm soát pixel chính xác |
| Thanh rỗng vẫn hiện đầy | `FilledBars` chưa được đặt thành `false` sau khi thay đổi X‑dimension | Đặt `FilledBars = false` *sau* khi điều chỉnh X‑dimension |
| File lưu trống | Thư mục đầu ra không tồn tại hoặc thiếu quyền ghi | Đảm bảo thư mục tồn tại (`Directory.CreateDirectory`) và ứng dụng có đủ quyền |
| Ảnh in mờ | PNG DPI thấp được lưu từ màn hình độ phân giải cao | Sử dụng `BarCodeImageFormat.Png` (không mất dữ liệu) và cân nhắc thuộc tính `Resolution` nếu cần |

## Ví dụ đầy đủ, có thể chạy ngay

Sao chép toàn bộ khối dưới đây vào một dự án console mới (`dotnet new console`) và chạy. Chương trình sẽ tạo ba file PNG trong thư mục `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Kết quả mong đợi:** ba file PNG—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png`, và `PostalRM4SCCFilledBars.png`—có thanh rộng 4 pixel, sẵn sàng để in hoặc xử lý tiếp.

## Kết luận

Bây giờ bạn đã biết cách **tạo mã vạch planet** trong C# và cách **đặt kích thước mã vạch** một cách chính xác cho cả kiểu thanh đầy và thanh rỗng. Mẫu này cũng áp dụng cho các ký hiệu khác như RM4SCC, cung cấp nền tảng linh hoạt cho bất kỳ yêu cầu mã vạch bưu chính nào.

Tiếp theo, bạn có thể khám phá:

* Thêm văn bản có thể đọc được dưới mã vạch (`BarcodeGenerator.Parameters.Barcode.CodeText`)

Hãy tự do thử nghiệm với các giá trị X‑dimension khác nhau, chuỗi dữ liệu và định dạng xuất để phù hợp với quy trình làm việc của bạn. Chúc bạn lập trình vui vẻ!
