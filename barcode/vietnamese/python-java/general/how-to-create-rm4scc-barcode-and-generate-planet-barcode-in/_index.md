# Cách tạo mã vạch RM4SCC và tạo mã vạch planet trong C#

Nếu bạn cần **tạo mã vạch RM4SCC** cho các ứng dụng bưu chính, hướng dẫn này sẽ chỉ cho bạn các bước chính xác. Bạn cũng sẽ học cách **tạo mã vạch planet** với cả chiều cao tự động và cố định, vì vậy cùng một đoạn mã có thể hoạt động cho bất kỳ ký hiệu bưu chính nào.

Bài hướng dẫn bao gồm mọi thứ cần thiết để tạo ra các hình ảnh PNG đáp ứng tiêu chuẩn bưu chính. Không cần công cụ bên ngoài nào ngoài thư viện Aspose.BarCode cho .NET. Khi hoàn thành, bạn có thể tạo mã vạch một cách lập trình và kiểm soát kích thước của chúng một cách chính xác.

## Yêu cầu trước

Trước khi bắt đầu, hãy đảm bảo bạn có:

* .NET 6.0 hoặc phiên bản mới hơn đã được cài đặt
* Visual Studio 2022 (hoặc bất kỳ IDE C# nào)
* Gói NuGet Aspose.BarCode cho .NET  
  `Install-Package Aspose.BarCode`
* Quyền ghi vào thư mục đầu ra

Những mục này cho phép bạn biên dịch và chạy mã mẫu mà không cần cấu hình bổ sung.

## Bước 1: Khởi tạo trình tạo mã vạch cho RM4SCC

Hoạt động đầu tiên tạo một thể hiện `BarcodeGenerator` được cấu hình cho ký hiệu RM4SCC. Đối tượng này chứa tất cả các thiết lập cho hình ảnh mã vạch.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Tại sao điều này quan trọng** – `EncodeTypes.RM4SCC` cho Aspose biết sử dụng định dạng RM4SCC cho bưu chính, trong khi chuỗi dữ liệu `"123456"` đại diện cho mã bưu điện bạn muốn mã hoá.

## Bước 2: Đặt độ rộng mô-đun (X‑dimension)

Độ rộng mô-đun kiểm soát kích thước thanh mỏng. Giá trị phổ biến cho mã vạch bưu chính là 4 pixel.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Giải thích** – Kích thước X‑dimension ảnh hưởng đến khả năng đọc tổng thể của mã vạch. Chọn 4 px phù hợp với hầu hết các máy quét bưu chính.

## Bước 3: Lưu với chiều cao thanh tự động

Khi bạn bỏ qua giá trị chiều cao, Aspose sẽ tự động tính toán chiều cao tối ưu dựa trên quy tắc của ký hiệu.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Kết quả** – PNG được tạo (`PostalRM4SCCBarHeightNone.png`) chứa một mã vạch RM4SCC có kích thước đúng chuẩn, sẵn sàng để in.

## Bước 4: Tạo mã vạch Planet với chiều cao tự động

Mẫu tương tự cũng áp dụng cho ký hiệu Planet. Bắt đầu bằng cách khởi tạo trình tạo với `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Tại sao tái sử dụng mã** – Cả RM4SCC và Planet đều chia sẻ cùng một cấu trúc tham số, vì vậy bạn chỉ cần thay đổi giá trị `EncodeTypes` để chuyển đổi ký hiệu.

## Bước 5: Định nghĩa chiều cao thanh cố định cho RM4SCC

Một số dịch vụ bưu chính yêu cầu chiều cao thanh cụ thể (ví dụ: 100 px). Bạn có thể đặt giá trị này một cách rõ ràng trước khi lưu.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Mẹo** – Đặt `BarHeight.Pixels` sẽ ghi đè tính toán tự động, cho phép bạn kiểm soát hoàn toàn kích thước hiển thị.

## Bước 6: Định nghĩa chiều cao thanh cố định cho Planet

Áp dụng kỹ thuật chiều cao cố định tương tự cho mã vạch Planet.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Kết quả** – Cả `PostalRM4SCCBarHeight100Pixels.png` và `PostalPlanetBarHeight100Pixels.png` đều chứa mã vạch với chiều cao thanh 100 px đồng nhất, đáp ứng các yêu cầu nghiêm ngặt của bưu chính.

## Mã nguồn hoàn chỉnh

Dưới đây là chương trình đầy đủ, có thể chạy được, bao gồm cả bốn ví dụ. Sao chép vào một dự án console mới và điều chỉnh đường dẫn đầu ra nếu cần.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Kết quả mong đợi** – Sau khi chạy chương trình, thư mục đã chỉ định sẽ chứa bốn tệp PNG:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC với chiều cao tự động
* `PostalPlanetBarHeightNone.png` – Planet với chiều cao tự động
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC với chiều cao 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet với chiều cao 100 px

Mở bất kỳ tệp nào để xác minh rằng các thanh vạch sắc nét, độ rộng mô-đun là 4 px, và chiều cao khớp với thiết lập đã chọn.

## Các câu hỏi thường gặp và trường hợp đặc biệt

| Câu hỏi | Trả lời |
|----------|--------|
| **Tôi có thể dùng định dạng ảnh khác không?** | Có. Thay `BarCodeImageFormat.Png` bằng `Jpeg`, `Bmp` hoặc `Gif` tùy nhu cầu. |
| **Nếu chuỗi dữ liệu dài hơn thì sao?** | Trình tạo sẽ tự động điều chỉnh số lượng thanh. Đảm bảo dữ liệu tuân thủ giới hạn độ dài của ký hiệu (RM4SCC ≤ 6 chữ số, Planet ≤ 6 chữ số). |
| **Làm sao thay đổi màu thanh?** | Đặt `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` trước khi gọi `Save`. |
| **DPI có quan trọng đối với việc in không?** | Bạn có thể đặt `rm4sccAuto.Parameters.ImageResolution.DpiX` và `DpiY` để phù hợp với độ phân giải của máy in. |
