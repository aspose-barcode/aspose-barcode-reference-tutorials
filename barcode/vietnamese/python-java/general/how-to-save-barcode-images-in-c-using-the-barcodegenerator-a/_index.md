# Cách lưu ảnh mã vạch trong C# bằng API BarcodeGenerator

Nếu bạn cần **cách lưu mã vạch** từ một ứng dụng .NET, hướng dẫn này sẽ chỉ ra các bước chính xác. Bạn sẽ thấy một **ví dụ tạo mã vạch** hoàn chỉnh tạo mã DataBar Stacked Omnidirectional, điều chỉnh tỷ lệ khung hình và lưu hai tệp PNG.

Lưu ảnh mã vạch là yêu cầu phổ biến khi xây dựng hệ thống quản lý tồn kho, máy POS, hoặc quy trình dán nhãn tự động. Khi kết thúc tutorial này, bạn có thể tạo mã C# cho barcode tạo ra các ảnh đáng tin cậy, sẵn sàng để in hoặc hiển thị.

## Các điều kiện tiên quyết

Trước khi bắt đầu, hãy chắc chắn rằng bạn đã có:

- .NET 6.0 SDK hoặc phiên bản mới hơn được cài đặt  
- Visual Studio 2022 (hoặc bất kỳ IDE nào hỗ trợ C#)  
- Gói NuGet **Aspose.BarCode for .NET** (mã sử dụng `Aspose.BarCode.Generation`)  

Bạn có thể thêm gói bằng lệnh sau:

```bash
dotnet add package Aspose.BarCode
```

## Bước 1: Thiết lập dự án console C# tối thiểu

Tạo một dự án console mới và tham chiếu thư viện:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Mở `Program.cs`. Tệp sẽ chứa phương thức `Main` nơi chúng ta sẽ đặt logic **generate barcode C#**.

## Bước 2: Khởi tạo BarcodeGenerator cho mã DataBar Stacked Omnidirectional

Nhiệm vụ đầu tiên trong bất kỳ quy trình **create databar barcode** nào là khởi tạo `BarcodeGenerator` với `EncodeType` phù hợp. Hàm khởi tạo nhận loại symbology và chuỗi dữ liệu.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

Giá trị `EncodeTypes.DatabarStackedOmniDirectional` thông báo cho thư viện tạo **create databar barcode** có thể quét được từ mọi hướng.

## Bước 3: Cấu hình X‑dimension (độ rộng mô-đun)

X‑dimension kiểm soát độ rộng thanh nhỏ nhất tính bằng pixel. Đặt giá trị thấp giúp mã vạch gọn gàng trong khi vẫn duy trì khả năng đọc.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Bước 4: **Cách điều chỉnh tỷ lệ khung hình** – giá trị đầu tiên (15)

Mã DataBar cung cấp thuộc tính `AspectRatio` ảnh hưởng đến mối quan hệ chiều cao‑chiều rộng. Tỷ lệ cao hơn tạo ra mã vạch cao hơn, có thể cải thiện độ tin cậy khi quét trên một số máy in.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Bước 5: **Cách lưu mã vạch** – ảnh đầu tiên (tỷ lệ 15)

Bây giờ chúng ta thực sự **cách lưu mã vạch** vào tệp. Phương thức `Save` nhận đường dẫn tệp và định dạng ảnh. Trong ví dụ này chúng ta lưu dưới dạng PNG.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Mẹo:** Thư mục chứa file thực thi là vị trí ghi mặc định. Sử dụng đường dẫn tuyệt đối nếu bạn cần lưu vào thư mục cụ thể.

## Bước 6: **Cách điều chỉnh tỷ lệ khung hình** – giá trị thứ hai (30)

Để minh họa tính linh hoạt, thay đổi tỷ lệ khung hình và lưu ảnh thứ hai. Điều này cho thấy cùng một dữ liệu đã mã hoá có thể được hiển thị với các tỉ lệ hình ảnh khác nhau.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Chạy chương trình sẽ tạo ra hai tệp PNG:

- `DatabarAspectRatio15.png` – mã vạch với chiều cao trung bình  
- `DatabarAspectRatio30.png` – mã vạch cao hơn, thích hợp cho môi trường quét khó khăn  

Cả hai tệp đều sẵn sàng để tải vào các control UI, in lên nhãn, hoặc truyền qua API.

### Kết quả mong đợi

Khi mở các ảnh đã tạo, bạn sẽ thấy một mã DataBar Stacked Omnidirectional mã hoá giá trị GTIN‑14 `12345678901231`. Sự khác biệt duy nhất giữa hai tệp là chiều cao, xác nhận **cách điều chỉnh tỷ lệ khung hình** hoạt động đúng như mong đợi.

## Bước 7: Mã nguồn đầy đủ để tham khảo

Dưới đây là chương trình hoàn chỉnh, có thể biên dịch và chạy. Sao chép vào `Program.cs`, biên dịch và thực thi.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Các câu hỏi thường gặp và xử lý trường hợp đặc biệt

### Nếu thư mục đích không tồn tại thì sao?

`Save` sẽ ném `DirectoryNotFoundException`. Hãy tạo thư mục trước:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Cách thay đổi định dạng ảnh?

Thay `BarCodeImageFormat.Png` bằng `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp`, hoặc `BarCodeImageFormat.Tiff` tùy theo yêu cầu downstream.

### Có thể tạo nhiều mã vạch trong vòng lặp không?

Có. Khởi tạo một `BarcodeGenerator` mới cho mỗi chuỗi dữ liệu hoặc tái sử dụng cùng một instance sau khi cập nhật thuộc tính `CodeText`:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### **Cách lưu mã vạch** có hoạt động trên nền tảng không phải Windows không?

Aspose.BarCode hỗ trợ đa nền tảng. Mã giống nhau chạy trên Linux và macOS miễn là runtime .NET có sẵn.
