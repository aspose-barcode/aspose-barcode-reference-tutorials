# Ví dụ tạo mã vạch trong C# – tạo mã Planet và tạo ảnh mã vạch

Nếu bạn cần một **ví dụ tạo mã vạch** trong C#, hướng dẫn này sẽ cho bạn thấy cách tạo mã Planet và tạo ảnh mã vạch c# chỉ trong vài dòng code. Bạn sẽ thấy một giải pháp hoàn chỉnh, sẵn sàng chạy mà có thể đưa vào bất kỳ dự án .NET nào.

Mã Planet được các dịch vụ bưu chính sử dụng để mã hoá thông tin định tuyến. Khi hoàn thành tutorial này, bạn sẽ hiểu tại sao thư viện tự động xác định chiều cao mã vạch, cách kiểm soát kích thước X, và cách lưu kết quả dưới dạng file PNG. Không cần công cụ bên ngoài—chỉ cần gói Aspose.BarCode for .NET và môi trường phát triển .NET.

## Các yêu cầu trước

Trước khi bắt đầu, hãy chắc chắn bạn đã có:

* .NET 6.0 SDK hoặc phiên bản mới hơn được cài đặt  
* Visual Studio 2022 (hoặc bất kỳ IDE nào hỗ trợ .NET)  
* Gói **Aspose.BarCode for .NET** NuGet (`Aspose.BarCode`)  

Bạn có thể cài đặt gói này từ dòng lệnh:

```bash
dotnet add package Aspose.BarCode
```

## Bước 1: Khởi tạo trình tạo mã vạch cho mã Planet

Bước đầu tiên trong bất kỳ **ví dụ tạo mã vạch** nào là tạo một thể hiện `BarcodeGenerator` và chỉ định loại mã hoá. Đối với mã Planet, bạn dùng `EncodeTypes.Planet` và truyền chuỗi dữ liệu bạn muốn mã hoá.

```csharp
using Aspose.BarCode.Generation;

// Create a Planet barcode generator with the data to encode
BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

**Tại sao lại quan trọng:** Enum `EncodeTypes.Planet` thông báo cho thư viện sử dụng ký hiệu Planet, có mẫu mô-đun cố định theo tiêu chuẩn bưu chính. Cung cấp dữ liệu (`"123456"` trong trường hợp này) đảm bảo mã vạch chứa đúng mã định tuyến số.

## Bước 2: Cấu hình kích thước X (độ rộng mô-đun) tính bằng pixel

Kích thước X kiểm soát độ rộng của mỗi mô-đun riêng lẻ (vạch nhỏ nhất). Điều chỉnh nó sẽ thay đổi kích thước tổng thể của mã vạch mà không ảnh hưởng tới khả năng đọc.

```csharp
// Set the X dimension (module width) to 4 pixels
generator.Parameters.Barcode.XDimension.Pixels = 4;
```

**Tại sao lại quan trọng:** Kích thước X lớn hơn tạo ra mã vạch lớn hơn, hữu ích khi in trên phong bì lớn. Thư viện tự động mở rộng chiều cao để duy trì tỷ lệ đúng cho mã Planet.

## Bước 3: Lưu ảnh mã vạch vào đĩa

Cuối cùng, bạn lưu ảnh đã tạo. Thư viện xác định chiều cao tối ưu, vì vậy bạn chỉ cần chỉ định đường dẫn và định dạng xuất.

```csharp
using Aspose.BarCode;

// Define the output file path
string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";

// Save the barcode as a PNG image
generator.Save(outputFile, BarCodeImageFormat.Png);
```

**Tại sao lại quan trọng:** Lưu dưới dạng PNG giữ nguyên các cạnh sắc nét của mã vạch, điều này rất quan trọng để quét chính xác. Phương thức `Save` cũng hỗ trợ các định dạng khác (JPEG, BMP, TIFF) nếu bạn cần đầu ra khác.

### Kết quả mong đợi

Sau khi chạy code, bạn sẽ tìm thấy một file có tên **PlanetAutoHeight.png** trong `C:\Barcodes`. Ảnh sẽ trông tương tự như minh họa dưới đây (alt text: *ví dụ tạo mã vạch hiển thị mã Planet*).

## Bước 4: Tùy chọn – tùy chỉnh màu nền và màu foreground

Nếu ứng dụng của bạn yêu cầu phong cách hiển thị khác, bạn có thể thay đổi màu của mã vạch trước khi lưu.

```csharp
// Set foreground (bars) to dark blue and background to light gray
generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

// Save the customized image
generator.Save(@"C:\Barcodes\PlanetCustomColors.png", BarCodeImageFormat.Png);
```

**Mẹo:** Luôn kiểm tra mã vạch đã tùy chỉnh bằng máy quét thực tế để xác nhận rằng việc thay đổi màu không ảnh hưởng tới khả năng đọc.

## Bước 5: Xử lý lỗi và xác thực

Thư viện Aspose.BarCode ném `ArgumentException` nếu dữ liệu không đáp ứng yêu cầu ký hiệu Planet (ví dụ: ký tự không phải số). Bao bọc code tạo trong khối try‑catch để cung cấp phản hồi rõ ràng.

```csharp
try
{
    BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "ABC123");
    generator.Save(@"C:\Barcodes\InvalidPlanet.png", BarCodeImageFormat.Png);
}
catch (ArgumentException ex)
{
    Console.WriteLine($"Invalid data for Planet barcode: {ex.Message}");
}
```

**Tại sao lại quan trọng:** Mã Planet chỉ chấp nhận dữ liệu số với độ dài nhất định. Xác thực đúng cách ngăn ngừa lỗi thời gian chạy và tiết kiệm thời gian trong quá trình kiểm thử tích hợp.

## Ví dụ đầy đủ, có thể chạy ngay

Kết hợp tất cả các bước lại với nhau sẽ cho bạn một chương trình tự chứa mà bạn có thể sao chép, dán và chạy.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;
using Aspose.BarCode;

class Program
{
    static void Main()
    {
        // Step 1: Initialize the generator with Planet encoding
        BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");

        // Step 2: Set the X dimension (module width) to 4 pixels
        generator.Parameters.Barcode.XDimension.Pixels = 4;

        // Optional: customize colors (comment out if not needed)
        // generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
        // generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

        // Step 3: Save the barcode image
        string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";
        generator.Save(outputFile, BarCodeImageFormat.Png);

        Console.WriteLine($"Planet barcode saved to {outputFile}");
    }
}
```

Biên dịch và chạy chương trình:

```bash
dotnet run
```

Bạn sẽ thấy thông báo trên console xác nhận vị trí file, và file PNG sẽ chứa mã Planet đã được tạo.

## Các biến thể phổ biến và trường hợp đặc biệt

| Biến thể | Cách thực hiện | Khi nào sử dụng |
|-----------|------------------|------------|
| **Độ dài dữ liệu khác** | Thay đổi đối số thứ hai trong `new BarcodeGenerator(EncodeTypes.Planet, "987654321")` | Dịch vụ bưu chính yêu cầu số định tuyến dài hơn |
| **Độ phân giải cao hơn** | Đặt `generator.Parameters.ImageResolution = 300;` trước `Save` | In trên máy in DPI cao |
| **Định dạng ảnh khác** | Dùng `BarCodeImageFormat.Jpeg` hoặc `BarCodeImageFormat.Tiff` | Khi PNG không phù hợp với quy trình làm việc của bạn |
| **Tên file động** | `string outputFile = Path.Combine(folder, $"Planet_{DateTime.Now:yyyyMMdd_HHmmss}.png");` | Xử lý hàng loạt nhiều mã vạch |

## Mẹo chuyên nghiệp cho một ví dụ tạo mã vạch mạnh mẽ

* **Tái sử dụng thể hiện generator** khi tạo nhiều mã vạch với cùng cài đặt; chỉ thay đổi `EncodeTypes` hoặc chuỗi dữ liệu để cải thiện hiệu năng.  
* **Xác thực đầu vào** trước khi truyền vào `BarcodeGenerator`. Một regex đơn giản như `^\d{6,9}$` đảm bảo dữ liệu tuân thủ yêu cầu của Planet.  
* **Giải phóng tài nguyên** nếu bạn tạo hàng ngàn ảnh trong một dịch vụ chạy lâu. `BarcodeGenerator` triển khai `IDisposable`, vì vậy hãy bọc nó trong khối `using` khi cần.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, data))
{
    // configure and save...
}
```
