# Cách tạo barcode PNG bằng Python – hướng dẫn từng bước

Nếu bạn cần **tạo file barcode PNG** từ các chuỗi tùy ý, hướng dẫn này cung cấp cho bạn một giải pháp sẵn sàng chạy. Bạn sẽ thấy chính xác cách tạo barcode Code 128, chuyển văn bản thành hình ảnh barcode, và lưu kết quả dưới dạng file PNG—tất cả chỉ với vài dòng Python.

Hướng dẫn bao gồm mọi thứ bạn cần biết, từ việc cài đặt thư viện cần thiết đến tùy chỉnh đầu ra cho các trường hợp sử dụng khác nhau. Khi hoàn thành, bạn sẽ có thể nhúng việc tạo barcode vào bất kỳ dự án Python nào mà không cần tìm kiếm tài liệu bổ sung.

## Những gì bạn sẽ học

* Cài đặt gói **barcode generator python** hỗ trợ Code 128.
* Sử dụng `BarCodeGenerator` để **tạo barcode code 128** từ một chuỗi văn bản.
* Lưu kết quả dưới dạng PNG chất lượng cao bằng `save`.
* Điều chỉnh kích thước ảnh, màu nền/màu tiền cảnh, và xử lý các lỗi thường gặp.
* Xác minh rằng PNG đã được tạo đúng cách.

### Yêu cầu trước

| Yêu cầu | Lý do |
|-------------|--------|
| Python 3.8+ | Cú pháp hiện đại và gợi ý kiểu |
| Internet access (for `pip install`) | Để tải thư viện |
| Write permission to a folder | Để lưu PNG đã tạo |

Không cần dịch vụ bên ngoài; mọi thứ chạy cục bộ.

## Bước 1: Cài đặt thư viện barcode

Cách đơn giản nhất để **chuyển văn bản thành barcode** trong Python là sử dụng gói **Aspose.BarCode for Python via .NET**, hỗ trợ Code 128 ngay từ đầu.

```bash
pip install aspose-barcode
```

> **Mẹo chuyên nghiệp:** Nếu bạn làm việc trong môi trường ảo, hãy kích hoạt nó trước khi chạy lệnh để giữ các phụ thuộc được cô lập.

## Bước 2: Nhập các lớp cần thiết

Sau khi cài đặt, nhập các lớp lõi. Các câu lệnh import ngắn gọn, giúp mã dễ đọc.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` tạo hình ảnh barcode.
* `EncodeTypes` cung cấp một enumeration các symbology được hỗ trợ, bao gồm `CODE_128`.

## Bước 3: Xác định văn bản bạn muốn mã hoá

Chọn bất kỳ chuỗi alphanumeric nào. Code 128 có thể đại diện cho toàn bộ bộ ASCII, vì vậy bạn không bị giới hạn chỉ số.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Nếu đầu vào chứa ký tự không được hỗ trợ, trình tạo sẽ ném ra `ValueError`. Bao quanh việc gán trong một khối `try` nếu bạn dự đoán dữ liệu do người dùng cung cấp.

## Bước 4: Tạo trình tạo barcode cho Code 128

Khởi tạo `BarCodeGenerator` với symbology mong muốn và văn bản bạn đã định nghĩa. Đây là phần cốt lõi của **cách tạo barcode** trong Python.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Tại sao lại là Code 128? Nó cung cấp mật độ cao và có thể mã hoá toàn bộ dải ASCII, rất thích hợp cho hệ thống tồn kho, nhãn vận chuyển và vé.

## Bước 5: (Tùy chọn) Tùy chỉnh giao diện

Bạn có thể tinh chỉnh barcode trước khi lưu. Các tùy chọn sau đây là phổ biến:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Các cài đặt này ảnh hưởng đến đầu ra **create barcode png** cuối cùng mà không thay đổi dữ liệu đã mã hoá.

## Bước 6: Lưu barcode dưới dạng file PNG

Cuối cùng, ghi ảnh ra đĩa. Phương thức `save` tự động phát hiện phần mở rộng file, vì vậy truyền `.png` sẽ tạo một ảnh PNG.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Nếu thư mục đích không tồn tại, Python sẽ ném ra `FileNotFoundError`. Hãy tạo thư mục trước hoặc sử dụng `os.makedirs` với `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

## Bước 7: Xác minh barcode (kiểm tra nhanh tính hợp lý)

Bạn có thể đọc lại PNG bằng cùng thư viện để xác nhận giá trị đã mã hoá khớp với văn bản gốc.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Chạy khối này sẽ in ra:

```
Verification succeeded: 1234567890
```

Nếu phép kiểm tra (assertion) thất bại, hãy kiểm tra lại `barcode_text` và bất kỳ tham số tùy chỉnh nào bạn đã đặt.

## Các biến thể phổ biến và trường hợp đặc biệt

| Tình huống | Điều chỉnh |
|-----------|------------|
| **Văn bản dài hơn (> 20 ký tự)** | Tăng `image_width` để tránh cắt bớt. |
| **Cần nền trong suốt** | Đặt `back_color = "Transparent"` trước khi lưu. |
| **Tạo nhiều barcode trong vòng lặp** | Bao bọc các bước 3‑6 trong một vòng `for`, thay đổi `barcode_text` mỗi lần lặp. |
| **Lưu dưới dạng JPEG thay vì PNG** | Thay đổi phần mở rộng file thành `.jpg`; thư viện tự động xử lý định dạng. |
| **Chạy trên máy chủ không có giao diện** | Thư viện không yêu cầu GUI, nên an toàn cho các pipeline CI. |

## Script đầy đủ để sao chép nhanh

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Lưu script dưới tên `generate_barcode.py` và chạy:

```bash
python generate_barcode.py
```

Bạn sẽ thấy các thông báo xác nhận và một file PNG mới trong thư mục `output`.
