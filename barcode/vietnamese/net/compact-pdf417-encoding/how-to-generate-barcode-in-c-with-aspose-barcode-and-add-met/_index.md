# Cách tạo mã vạch trong C# với Aspose.BarCode và thêm siêu dữ liệu

Nếu bạn cần **generate barcode in C#** cho hệ thống logistics hoặc quản lý tồn kho, hướng dẫn này sẽ cho bạn một giải pháp hoàn chỉnh, sẵn sàng cho môi trường sản xuất. Bạn sẽ thấy cách tạo một mã Macro PDF417, đính kèm siêu dữ liệu phong phú, và đặt một dấu thời gian chính xác — tất cả đều sử dụng thư viện Aspose.BarCode.

Bài hướng dẫn bao gồm mọi thứ từ cài đặt gói NuGet đến lưu ảnh PNG cuối cùng. Khi hoàn thành, bạn có thể tạo mã vạch mang các định danh tệp, thông tin đoạn, và các trường tùy chỉnh, sẵn sàng cho các máy quét downstream hỗ trợ Macro PDF417.

## Yêu cầu trước

* .NET 6.0 SDK hoặc phiên bản mới hơn (mã cũng hoạt động với .NET Framework 4.7.2+)
* Visual Studio 2022 hoặc bất kỳ IDE C# nào bạn thích
* Giấy phép Aspose.BarCode đang hoạt động (bản dùng thử miễn phí hoạt động cho phát triển)
* Kiến thức cơ bản về cú pháp C#

> **Mẹo chuyên nghiệp:** Nếu bạn sử dụng pipeline CI/CD, hãy thêm tham chiếu gói Aspose.BarCode vào file dự án của bạn để các bản build luôn có thể tái tạo.

## Bước 1: Cài đặt Aspose.BarCode

Mở terminal trong thư mục dự án của bạn và chạy:

```bash
dotnet add package Aspose.BarCode
```

Lệnh này sẽ tải phiên bản ổn định mới nhất (hiện tại là 24.9). Sau khi khôi phục hoàn tất, bạn có thể tham chiếu thư viện trong các file nguồn của mình.

## Bước 2: Tạo dự án console C# mới (tùy chọn)

Nếu bạn muốn bắt đầu từ đầu, tạo một ứng dụng console:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

File `Program.cs` sẽ chứa mã tạo mã vạch được trình bày sau.

## Bước 3: Thiết lập trình tạo mã vạch

Cốt lõi của quá trình là lớp `BarcodeGenerator`. Bạn khởi tạo nó với giá trị enum `EncodeTypes` mong muốn và văn bản bạn muốn mã hoá.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Tại sao mỗi dòng lại quan trọng

* **EncodeTypes.MacroPdf417** cho Aspose tạo mã PDF417 có thể chia thành các đoạn. Điều này cần thiết cho các payload lớn vượt quá khả năng của một ký hiệu duy nhất.
* **XDimension.Pixels** kiểm soát mật độ hình ảnh. Giá trị 2 tạo ra hình ảnh rõ nét trên hầu hết màn hình và máy in mà không làm tăng kích thước file.
* **MacroPdf417* properties** nhúng siêu dữ liệu mà các máy quét downstream đọc dưới dạng các trường riêng biệt (file ID, segment ID, v.v.). Đây là phần “cách thêm siêu dữ liệu” của hướng dẫn.
* **MacroPdf417TimeStamp** minh họa “cách đặt dấu thời gian”. Đối tượng `DateTime` có thể là bất kỳ thời gian UTC nào; sử dụng UTC tránh sự mơ hồ về múi giờ khi mã vạch di chuyển qua các khu vực.
* **MacroPdf417Terminator** xác định cách chuỗi macro kết thúc. `Set` là lựa chọn phổ biến nhất vì nó báo hiệu đoạn cuối cho máy đọc.
* **Save(..., BarCodeImageFormat.Png)** ghi một ảnh không mất dữ liệu, bảo toàn các chi tiết cần thiết cho việc quét đáng tin cậy.

## Bước 4: Xác minh mã vạch đã tạo

Chạy chương trình:

```bash
dotnet run
```

Bạn sẽ thấy đầu ra trên console:

```
Barcode saved to ExtPDF417Meta.png
```

Mở `ExtPDF417Meta.png` bằng bất kỳ trình xem ảnh nào. Hình ảnh sẽ hiển thị một ký hiệu PDF417 gọn gàng với văn bản **Åspóse.Barcóde©** và các trường macro được nhúng. Quét ảnh bằng máy quét hỗ trợ PDF417 (hoặc ứng dụng di động hỗ trợ Macro PDF417) sẽ trả về văn bản gốc cùng các giá trị siêu dữ liệu bạn đã thiết lập.

### Đặc điểm hình ảnh mong đợi

* Các thanh dọc màu đen, cách đều nhau
* Vùng yên tĩnh (lề) được Aspose tự động thêm
* Không bị biến dạng, vì `XDimension` 2 pixel khớp với độ phân giải gốc của PNG

## Bước 5: Các biến thể phổ biến và trường hợp góc cạnh

### 5.1 Xử lý ký tự đặc biệt

Văn bản mẫu chứa các ký tự Unicode (`Å`, `ó`, `©`). Aspose.BarCode mã hoá chúng bằng UTF‑8 theo mặc định, vì vậy chúng hiển thị đúng trong mã vạch. Nếu bạn cần một bộ mã hoá khác (ví dụ, ISO‑8859‑1), đặt:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Định danh tệp lớn

`MacroPdf417FileID` chấp nhận một số nguyên 32‑bit. Đối với giá trị lớn hơn `int.MaxValue`, hãy chia định danh thành nhiều trường hoặc sử dụng GUID lưu dưới dạng chuỗi trong `MacroPdf417FileName`.

### 5.3 Điều chỉnh số cột

Tăng `Pdf417.Columns` sẽ giảm chiều cao mã vạch nhưng làm rộng mỗi hàng. Nếu mã vạch phải vừa vào nhãn hẹp, giảm số cột và tăng số hàng tự động.

### 5.4 Lưu ở các định dạng khác

Aspose hỗ trợ BMP, JPEG, TIFF và SVG. Thay `BarCodeImageFormat.Png` bằng giá trị enum mong muốn, ví dụ `BarCodeImageFormat.Svg` cho đồ họa vector có thể mở rộng.

## Bước 6: Tích hợp mã vạch vào quy trình làm việc lớn hơn

Khi bạn đã có file PNG, bạn có thể:

* Nhúng nó vào hóa đơn PDF bằng Aspose.PDF.
* Đính kèm nó vào email như bằng chứng giao hàng.
* Lưu trữ byte ảnh trong cơ sở dữ liệu để truy xuất sau.

Dưới đây là một đoạn mã nhanh chuyển PNG thành mảng byte để lưu trữ:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Câu hỏi thường gặp

**Q: Điều này có hoạt động trên .NET Core không?**  
A: Có. Cùng một API hoạt động trên .NET Core, .NET 5+ và .NET Framework. Chỉ cần tham chiếu gói NuGet phù hợp.

**Q: Nếu tôi cần tạo PDF417 không phải macro thì sao?**  
A: Sử dụng `EncodeTypes.Pdf417` thay vì `EncodeTypes.MacroPdf417`. Các thuộc tính đặc thù của macro sẽ bị bỏ qua.

**Q: Tôi có thể thêm các cặp key/value tùy chỉnh ngoài các trường tích hợp sẵn không?**  
A: Aspose.BarCode không cung cấp các trường người dùng tùy ý cho Macro PDF417. Nếu bạn cần dữ liệu bổ sung, hãy mã hoá nó trong payload văn bản chính hoặc chuyển sang QR code, loại hỗ trợ structured append.
