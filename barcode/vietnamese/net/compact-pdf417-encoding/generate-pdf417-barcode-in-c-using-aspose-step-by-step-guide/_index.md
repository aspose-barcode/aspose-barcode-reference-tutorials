# Tạo mã vạch PDF417 trong C# bằng Aspose – hướng dẫn từng bước

Nếu bạn cần **tạo mã vạch PDF417** trong một ứng dụng .NET, hướng dẫn này sẽ chỉ cho bạn cách thực hiện. Bạn sẽ thấy một ví dụ hoàn chỉnh, sẵn sàng chạy, tạo các mã vạch PDF417 cơ bản, gọn, Micro, GS1‑Micro và Macro bằng Aspose.BarCode cho .NET.

Việc tạo mã vạch PDF417 là một yêu cầu phổ biến cho nhãn vận chuyển, tài liệu vận tải và hệ thống tồn kho. Khi kết thúc tutorial này, bạn sẽ có thể **tạo hình ảnh mã vạch PDF417**, hiểu các tham số chính, và điều chỉnh mã cho dữ liệu của riêng bạn.

## Prerequisites

- .NET 6.0 SDK hoặc phiên bản mới hơn (mã cũng hoạt động với .NET Framework 4.7+)
- Visual Studio 2022 hoặc bất kỳ IDE C# nào
- Gói NuGet Aspose.BarCode cho .NET (`Aspose.BarCode`) đã được cài đặt
- Hiểu biết cơ bản về cú pháp C#

> **Pro tip:** Sử dụng giấy phép đánh giá miễn phí từ Aspose để tránh các hạn chế thời gian chạy khi thử nghiệm.

## Bước 1: Thiết lập dự án và nhập không gian tên

Create a new console project and add the Aspose.BarCode package:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Then open `Program.cs` and add the required `using` directives:

```csharp
using System;
using Aspose.BarCode.Generation;
```

These namespaces give you access to the `BarcodeGenerator` class and the `EncodeTypes` enumeration needed to **generate barcode using C#**.

## Bước 2: Tạo mã vạch PDF417 cơ bản

The simplest PDF417 barcode uses default settings except for the X‑dimension (module width) and the number of columns. Adjusting these values controls the overall size and readability.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Tại sao nó hoạt động:**  
- `EncodeTypes.Pdf417` cho Aspose biết sử dụng ký hiệu PDF417.  
- `XDimension.Pixels` xác định độ rộng thanh nhỏ nhất; giá trị 2 giữ hình ảnh nhỏ mà không làm giảm khả năng quét.  
- `Pdf417.Columns` xác định số cột dữ liệu trong mã vạch; ba cột cho tỷ lệ cân bằng.

## Bước 3: Tạo mã vạch PDF417 gọn (được cắt ngắn)

Compact mode removes the stop pattern and reduces the overall height, which is useful for limited‑space labels.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Tại sao nó hoạt động:**  
Setting `Pdf417.Truncate = true` activates truncated mode, which omits the right‑hand stop pattern and reduces the barcode height while preserving data integrity.

## Bước 4: Tạo mã vạch Micro PDF417

Micro PDF417 is a smaller variant that supports 1‑4 columns. It is ideal for applications where space is at a premium, such as small product tags.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Tại sao nó hoạt động:**  
- `EncodeTypes.MicroPdf417` chọn phiên bản micro của ký hiệu.  
- Số cột có thể từ 1 đến 4; chọn 4 cho bố cục dày đặc nhất trong khi vẫn có thể quét được.

## Bước 5: Tạo mã vạch Micro PDF417 tuân thủ GS1

GS1 prefixes add standardized identifiers (e.g., GTIN, batch number) to the barcode data. Aspose lets you embed these directly.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Tại sao nó hoạt động:**  
GS1 Application Identifiers (AIs) are placed in parentheses. Aspose parses them and adds the appropriate formatting required by GS1 scanners.

## Bước 6: Tạo mã vạch Macro PDF417 với đầy đủ siêu dữ liệu

Macro PDF417 allows you to split a large data payload across multiple linked barcodes. You can embed file‑level metadata such as file ID, segment count, timestamps, and custom strings.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Tại sao nó hoạt động:**  
Each `MacroPdf417*` property maps to a specific segment of the macro barcode specification. Setting these values ensures that a scanner can reconstruct the original file from multiple barcode images.
