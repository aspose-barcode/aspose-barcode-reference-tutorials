# C#'ta BarcodeGenerator API kullanarak barkod görüntülerini kaydetme

Bir .NET uygulamasından **how to save barcode** dosyalarına ihtiyacınız varsa, bu kılavuz tam adımları gösterir. **barcode generator example** içeren bir örnek göreceksiniz; bu örnek bir DataBar Stacked Omnidirectional barkod oluşturur, en‑boy oranını ayarlar ve iki PNG dosyası kaydeder.

Barkod görüntülerini kaydetmek, envanter sistemleri, satış noktası terminalleri veya otomatik etiketleme iş akışları oluştururken yaygın bir gereksinimdir. Bu öğreticinin sonunda, baskı veya gösterim için hazır güvenilir görüntüler üreten barkod C# kodu oluşturabilirsiniz.

## Önkoşullar

- .NET 6.0 SDK veya daha yeni bir sürüm yüklü  
- Visual Studio 2022 (veya herhangi bir C#‑uyumlu IDE)  
- **Aspose.BarCode for .NET** NuGet paketi (kod `Aspose.BarCode.Generation` kullanır)  

Paketi aşağıdaki komutla ekleyebilirsiniz:

```bash
dotnet add package Aspose.BarCode
```

## Adım 1: Minimal bir C# konsol projesi kurun

Yeni bir konsol projesi oluşturun ve kütüphaneyi referans gösterin:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs` dosyasını açın. Bu dosya, **generate barcode C#** mantığını yerleştireceğimiz `Main` metodunu içerecek.

## Adım 2: DataBar Stacked Omnidirectional barkod için BarcodeGenerator'ı başlatın

Herhangi bir **create databar barcode** iş akışındaki ilk görev, doğru `EncodeType` ile `BarcodeGenerator` örneği oluşturmaktır. Yapıcı, barkod sembolojisini ve veri dizesini alır.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

`EncodeTypes.DatabarStackedOmniDirectional` değeri, kütüphaneye herhangi bir yönden taranabilen bir **create databar barcode** üretmesini söyler.

## Adım 3: X‑boyutunu (modül genişliği) yapılandırın

X‑boyutu, piksellerdeki en küçük çubuk genişliğini kontrol eder. Düşük bir değere ayarlamak, barkodu okunabilirliği korurken kompakt tutar.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Adım 4: **How to adjust aspect ratio** – ilk değer (15)

DataBar barkodları, yükseklik‑genişlik ilişkisini etkileyen bir `AspectRatio` özelliği sunar. Daha yüksek bir oran, daha uzun bir barkod üretir ve bu, belirli yazıcılarda tarama güvenilirliğini artırabilir.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Adım 5: **How to save barcode** – ilk görüntü (en‑boy oranı 15)

Şimdi gerçekten **how to save barcode** bir dosyaya kaydediyoruz. `Save` metodu bir dosya yolu ve görüntü formatı alır. Bu örnekte bir PNG dosyası saklıyoruz.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **İpucu:** Çalıştırılabilir dosyanın dizini varsayılan yazma konumudur. Belirli bir klasöre ihtiyacınız varsa mutlak bir yol kullanın.

## Adım 6: **How to adjust aspect ratio** – ikinci değer (30)

Esnekliği göstermek için, en‑boy oranını değiştirin ve ikinci bir görüntü kaydedin. Bu, aynı kodlanmış verinin farklı görsel oranlarla nasıl oluşturulabileceğini gösterir.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Programı çalıştırmak iki PNG dosyası üretir:

- `DatabarAspectRatio15.png` – orta yükseklikte barkod  
- `DatabarAspectRatio30.png` – zorlu tarama ortamları için daha yüksek bir barkod  

Her iki dosya da UI kontrollerine yüklenmeye, etiketlere basılmaya veya API aracılığıyla iletilmeye hazırdır.

### Beklenen çıktı

Oluşturulan görüntüleri açtığınızda, GTIN‑14 değeri `12345678901231` kodlayan bir DataBar Stacked Omnidirectional barkod görmelisiniz. İki dosya arasındaki görsel fark sadece yüksekliktir; bu, **how to adjust aspect ratio**'un amaçlandığı gibi çalıştığını doğrular.

## Adım 7: Referans için tam kaynak kodu

Aşağıda tam ve çalıştırılabilir program yer almaktadır. `Program.cs` içine kopyalayın, derleyin ve çalıştırın.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Yaygın sorular ve kenar‑durumları ele alma

### Hedef klasör mevcut değilse ne olur?

`Save` bir `DirectoryNotFoundException` fırlatır. Önce klasörü oluşturun:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Görüntü formatı nasıl değiştirilir?

`BarCodeImageFormat.Png` yerine, sonraki gereksinimlere bağlı olarak `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` veya `BarCodeImageFormat.Tiff` kullanın.

### Bir döngüde birden fazla barkod üretebilir miyim?

Evet. Her veri dizesi için yeni bir `BarcodeGenerator` örneği oluşturabilir veya `CodeText` özelliğini güncelledikten sonra aynı örneği yeniden kullanabilirsiniz:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```
