# Python’da barcode PNG oluşturma – Tam Kılavuz

Hiç **barcode PNG** oluşturmanız gerektiğinde hangi kütüphaneyi ya da ayarları kullanacağınızdan emin olmadınız mı? Yalnız değilsiniz. Birçok envanter ya da ödeme sisteminde ilk adım, ham veriyi tarayıcıların sevdiği net bir PNG görüntüsüne dönüştürmektir.  

Bu öğreticide **databar nasıl üretilir**, **barcode yüksekliği nasıl ayarlanır** ve hatta **barcode** parametrelerini anında nasıl değiştirirsiniz gibi konuları adım adım inceleyeceğiz—hepsi **barcode with sample data** kullanarak, doğrudan projenize kopyalayıp yapıştırabileceğiniz örneklerle.  

## Öğrenecekleriniz

- Python’da Aspose.BarCode (veya benzeri) kütüphanesini kurma.  
- Sadece birkaç satır kodla farklı yüksekliklerde **barcode PNG** dosyaları oluşturma.  
- Modül boyutu ve bar yüksekliği gibi **barcode** özelliklerini değiştirme.  
- Gerçekçi bir GTIN‑14 değeriyle **barcode with sample data** kullanma.  
- Bulanık görüntüler ya da hatalı kodlama gibi yaygın sorunların nasıl giderileceğine dair ipuçları.

Barcode üretimi konusunda önceden deneyim gerekmez—sadece temel bir Python yorumlayıcısı ve bir pip paketi kurabilme yeteneği yeterlidir.

## Ön Koşullar

- Makinenizde Python 3.8+ yüklü olmalı.  
- `aspose-barcode` paketini (veya uyumlu bir kütüphaneyi) kurmak için internete erişiminiz olmalı.  
- PNG dosyalarının kaydedileceği yazılabilir bir klasör (skriptteki `YOUR_DIRECTORY` ifadesini değiştirin).  

Bu koşullara sahipseniz, harika—hadi başlayalım.

## Barcode PNG Oluşturma – Üreteci Kurma

İlk iş: **DataBar Omnidirectional** barcode’ı üretecek bir nesneye ihtiyacımız var. Aşağıdaki kod gerekli sınıfları içe aktarır, **barcode with sample data** ile bir üreteç oluşturur ve makul bir modül boyutu ayarlar.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Neden önemli:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` motorun, perakende rafları için ideal olan, her yönden okunabilen bir **DataBar** üretmesini sağlar. `x_dimension` çubukların keskin kalmasını sağlarken, `bar_height` kodun görsel boyutunu kontrol eder.

## Sample Data ile Databar Nasıl Üretilir

Üreteç hazır olduğuna göre, **barcode PNG** dosyaları oluşturacağız. İlk kaydetme 30 piksel yüksekliğinde bir dosya üretir; bu, ekran önizlemeleri için genellikle yeterlidir.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Bu noktaya kadar scripti çalıştırdığınızda, kompakt ve yüksek kontrastlı bir barcode gibi görünen bir PNG dosyası elde edersiniz. Çubukların net olduğunu ve GTIN‑14 verisinin kodlandığını doğrulamak için herhangi bir görüntüleyicide açın.

## Barcode Yüksekliğini Ayarlama (How to Change Barcode)

Daha büyük etiketler ya da yüksek çözünürlüklü baskılar için daha uzun bir barcode’a ihtiyaç duyabilirsiniz. İşte **adjust barcode height** burada devreye girer. Yüksekliği değiştirmek sadece `BarHeight` özelliğini güncelleyip tekrar kaydetmek kadar basittir.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Nasıl çalışır:** Üreteç aynı veri ve modül boyutunu yeniden kullanır; sadece dikey boyut değişir. Bu, nesneyi yeniden oluşturmayı önler ve **how to change barcode** ayarlarını dinamik olarak göstermenin bir yoludur.

## Tam Script – Tek Çözüm

Aşağıda tüm adımları birleştiren, çalıştırılabilir tam script yer alıyor. Kopyalayıp yapıştırın; paketi kurduktan sonra sorunsuz çalışacaktır.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Beklenen Çıktı

Scripti çalıştırdığınızda iki dosya üretilecektir:

- `DatabarOmni30.png` – 30 px yüksekliğinde DataBar Omnidirectional barcode.  
- `DatabarOmni60.png` – aynı barcode’ın 60 px yüksekliğindeki versiyonu.

Her iki görüntü de PNG formatında, kayıpsızdır ve PDF, HTML sayfaları ya da doğrudan etiketlere baskı için hazırdır.

## Yaygın Tuzaklar & Pro İpuçları

- **Pixel vs. DPI:** PNG dosyaları piksel tabanlıdır. Belirli bir baskı boyutu gerekiyorsa, `BarHeight` değerini DPI’ye göre hesaplayın (ör. 300 dpi → 30 px ≈ 0.1 in).  
- **Yanlış kodlama:** Veri dizesinin GS1 Uygulama Tanımlayıcısı formatına (`(01)` GTIN‑14 için) uygun olduğundan emin olun. Parantez eksikliği, kütüphanenin düz bir sayısal barcode üretmesine yol açabilir.  
- **Dosya yolları:** Windows’ta kaçış karakteri sorunlarından kaçınmak için ham stringler (`r"..."`) ya da çift ters eğik çizgi kullanın.  
- **Performans:** Binlerce barcode üretmeniz gerekiyorsa, üreteci bir kez oluşturup sadece `BarHeight` ya da veri dizesini kaydetmeler arasında değiştirin. Bu, bellek tüketimini azaltır.
