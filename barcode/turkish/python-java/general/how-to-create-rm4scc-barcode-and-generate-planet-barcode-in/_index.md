# C#'ta RM4SCC barkod oluşturma ve planet barkodu üretme

Posta uygulamaları için **RM4SCC barkod oluşturmanız** gerektiğinde, bu rehber tam adımları gösterir. Ayrıca **planet barkodu üretmeyi** hem otomatik hem de sabit yüksekliklerle nasıl yapacağınızı öğrenecek ve aynı kodun tüm posta sembolleri için çalıştığını göreceksiniz.

Bu öğretici, posta standartlarına uygun PNG görüntüler üretmek için gereken her şeyi kapsar. Aspose.BarCode for .NET kütüphanesi dışındaki hiçbir dış araç gerekmez. Sonunda barkodları programlı olarak oluşturabilir ve boyutlarını tam olarak kontrol edebilirsiniz.

## Gereksinimler

Başlamadan önce aşağıdakilerin kurulu olduğundan emin olun:

* .NET 6.0 veya daha yeni bir sürüm
* Visual Studio 2022 (veya herhangi bir C# IDE)
* Aspose.BarCode for .NET NuGet paketi  
  `Install-Package Aspose.BarCode`
* Çıktı dizinine yazma izni

Bu öğeler, ek bir yapılandırma yapmadan örnek kodu derlemenizi ve çalıştırmanızı sağlar.

## Adım 1: RM4SCC için barkod oluşturucusunu başlatma

İlk işlem, RM4SCC sembolü için yapılandırılmış bir `BarcodeGenerator` örneği oluşturur. Bu nesne barkod görüntüsü için tüm ayarları tutar.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Neden önemli** – `EncodeTypes.RM4SCC` Aspose'a posta RM4SCC formatını kullanmasını söyler, veri dizesi `"123456"` ise kodlamak istediğiniz posta kodunu temsil eder.

## Adım 2: Modül genişliğini (X‑dimension) ayarlama

Modül genişliği ince çubuk boyutunu kontrol eder. Posta barkodları için yaygın bir değer 4 pikseldir.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Açıklama** – X‑dimension, barkodun genel okunabilirliğini etkiler. 4 px seçmek, çoğu posta tarayıcısıyla uyumludur.

## Adım 3: Otomatik çubuk yüksekliğiyle kaydetme

Yükseklik değeri vermediğinizde, Aspose sembol kurallarına göre optimal yüksekliği otomatik olarak hesaplar.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Sonuç** – Oluşturulan PNG (`PostalRM4SCCBarHeightNone.png`) doğru boyutta bir RM4SCC barkodu içerir ve yazdırmaya hazırdır.

## Adım 4: Otomatik yükseklikle Planet barkodu oluşturma

Aynı desen Planet sembolü için de çalışır. `EncodeTypes.Planet` ile oluşturucuyu başlatın.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Kodun yeniden kullanılmasının nedeni** – RM4SCC ve Planet aynı parametre yapısını paylaşır, bu yüzden sadece `EncodeTypes` değerini değiştirerek sembolü değiştirebilirsiniz.

## Adım 5: RM4SCC için sabit çubuk yüksekliği tanımlama

Bazı posta hizmetleri belirli bir çubuk yüksekliği (ör. 100 px) ister. Kaydetmeden önce bunu açıkça ayarlayabilirsiniz.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**İpucu** – `BarHeight.Pixels` ayarı, otomatik hesabı geçersiz kılar ve görsel boyut üzerinde tam kontrol sağlar.

## Adım 6: Planet için sabit çubuk yüksekliği tanımlama

Aynı sabit‑yükseklik tekniğini bir Planet barkoduna da uygulayın.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Sonuç** – `PostalRM4SCCBarHeight100Pixels.png` ve `PostalPlanetBarHeight100Pixels.png` dosyaları, tutarlı 100 px çubuk yüksekliğine sahip barkodlar içerir ve katı posta spesifikasyonlarını karşılar.

## Tam kaynak kodu

Aşağıda dört örneği kapsayan tam, çalıştırılabilir program yer alıyor. Yeni bir konsol projesine kopyalayın ve çıktı yolunu ihtiyacınıza göre ayarlayın.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Beklenen çıktı** – Programı çalıştırdıktan sonra belirtilen dizinde dört PNG dosyası bulunur:

* `PostalRM4SCCBarHeightNone.png` – otomatik yükseklikli RM4SCC
* `PostalPlanetBarHeightNone.png` – otomatik yükseklikli Planet
* `PostalRM4SCCBarHeight100Pixels.png` – 100 px yüksekliğinde RM4SCC
* `PostalPlanetBarHeight100Pixels.png` – 100 px yüksekliğinde Planet

Herhangi bir dosyayı açarak çubukların net, modül genişliğinin 4 px ve yüksekliğin seçilen ayara uygun olduğunu doğrulayabilirsiniz.

## Yaygın sorular ve kenar durumları

| Soru | Cevap |
|----------|--------|
| **Başka görüntü formatları kullanabilir miyim?** | Evet. `BarCodeImageFormat.Png` yerine ihtiyacınıza göre `Jpeg`, `Bmp` veya `Gif` kullanabilirsiniz. |
| **Veri dizesi daha uzun olursa ne olur?** | Oluşturucu otomatik olarak çubuk sayısını ayarlar. Verinin sembolün uzunluk limitlerine (RM4SCC ≤ 6 rakam, Planet ≤ 6 rakam) uygun olduğundan emin olun. |
| **Çubuk rengini nasıl değiştiririm?** | `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` satırını `Save` çağrısından önce ekleyin. |
| **Baskı için DPI önemli mi?** | `rm4sccAuto.Parameters.ImageResolution.DpiX` ve `DpiY` değerlerini yazıcınızın çözünürlüğüne göre ayarlayabilirsiniz. |
