# C#'ta Planet barkodu oluşturma – tam programlama rehberi

C#'ta **planet barkodu oluşturmanız** gerekiyorsa, bu rehber tam olarak nasıl yapılacağını gösterir. Ayrıca **barkod boyutlarını nasıl ayarlayacağınızı** keşfedecek ve çubukların istediğiniz tam genişlikte görüntülenmesini sağlayacaksınız.

Planet barkodları oluşturmak, posta hizmetleri veya lojistik sistemleriyle çalışırken yaygındır. Aşağıdaki kod, varsayılan dolu‑çubuk sürümünü ve isteğe bağlı boş‑çubuk stilini kapsar, ayrıca RM4SCC formatı için hızlı bir örnek içerir. Bu öğreticinin sonunda, herhangi bir .NET projesine ekleyebileceğiniz yeniden kullanılabilir bir kod parçacığına sahip olacaksınız.

## Önkoşullar

* .NET 6.0 veya daha yeni bir sürüm yüklü olmalı (API, .NET Framework 4.6+ ile de çalışır)
* **Aspose.BarCode for .NET** NuGet paketi (`Aspose.BarCode`) projenize eklenmiş olmalı
* PNG dosyalarının kaydedileceği yazılabilir bir klasör yolu
* C# sözdizimi ve Visual Studio (veya herhangi bir IDE) hakkında temel bilgi

> **Pro ipucu:** Görüntüleri kaydederken izin sorunlarından kaçınmak için mutlak bir yol veya `Path.Combine(Environment.CurrentDirectory, "output")` kullanın.

## 1. Adım – Planet barkodu oluşturucusunu başlatma (dolu çubuklar)

İlk adım, Planet sembolü için bir `BarcodeGenerator` örneği oluşturmaktır. Varsayılan olarak oluşturucu **dolu** çubuklar üretir.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

`EncodeTypes.Planet` enum'u, Aspose.BarCode'e Planet formatını kullanmasını söyler, `"123456"` ise kodlanacak veri yüküdür.

## 2. Adım – Tutarlı boyutlandırma için barkod boyutlarını nasıl ayarlarsınız

Her bir çubuğun genişliğini kontrol etmek için **X‑dimension** ayarlanır. Bu, **barkod boyutlarını ayarlamanın** birincil yoludur ve barkodun etiket boyutunuza uymasını sağlar.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

`Pixels` özelliği, çubuk genişliğini ekran pikseli cinsinden tanımlar. Standart posta etiketleri için yaygın değerler 2 – 5 piksel arasındadır; daha büyük baskılar için değeri artırın.

## 3. Adım – Dolu Planet barkodunu PNG olarak kaydetme

Şimdi görüntüyü diske yazın. PNG, net kenarları korur ve tarama için idealdir.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

`YOUR_DIRECTORY` ifadesini önceden hazırladığınız yol ile değiştirin. Bu kodu çalıştırdıktan sonra aşağıdaki görüntüye benzer bir dosya göreceksiniz.

![Dolu çubuklu Planet barkodu](planet_filled.png "Dolu çubuklu Planet barkodu – C# kodu ile oluşturuldu")

*Alt metin:* **C# kodu ile oluşturulmuş dolu çubuklu Planet barkodu** (matches `og_image_alt`).

## 4. Adım – Boş (dolgusuz) çubuklu Planet barkodu oluşturma

Posta hizmetiniz çubukların **boş** olmasını gerektiriyorsa, oluşturucuyu başlattıktan sonra `FilledBars` bayrağını değiştirmeniz gerekir.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Yapıcı aynı; fark bir sonraki yapılandırma adımında ortaya çıkar.

## 5. Adım – Barkod boyutlarını ayarlama ve çubukları boş yapma

Yine, görsel tutarlılık için X‑dimension'ı ayarlayın, ardından dolu çubukları devre dışı bırakın.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

`FilledBars = false` özelliği, render stilini gerçekten değiştirir. Aynı X‑dimension'ı korumak, boş‑çubuk barkodunun dolu sürümle mükemmel hizalanmasını sağlar.

## 6. Adım – Boş Planet barkodunu kaydetme

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Artık iki PNG dosyanız olacak: biri katı çubuklu, diğeri boş çubuklu, ikisi de aynı boyutları paylaşacak.

## 7. Adım – (İsteğe Bağlı) Karşılaştırma için RM4SCC barkodu oluşturma

RM4SCC, aynı varsayılan dolu‑çubuk stilini kullanan başka bir posta sembolüdür. Adımlar, Planet örneğini yansıtır ve **barkod boyutlarını nasıl ayarlayacağınız**'ın formatlar arasında çalıştığını gösterir.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Bu üç adımı çalıştırdığınızda `PostalRM4SCCFilledBars.png` oluşturulur; bunu Planet çıktılarıyla yan yana karşılaştırabilirsiniz.

## X‑dimension'ın önemi

X‑dimension, her bir çubuğun **minimum yazdırılabilir genişliğini** belirler. Çok düşük ayarlarsanız, barkod düşük çözünürlüklü yazıcılarda bulanıklaşabilir ve tarama hatalarına yol açar. Aksine, çok büyük bir X‑dimension etiket boyutlarını aşabilir ve alan kaybına neden olur. **Barkod boyutlarını nasıl ayarlayacağınızı** açıkça belirleyerek, son görüntü boyutu üzerinde kesin kontrol elde edersiniz; bu, otomatik posta iş akışları için çok önemlidir.

## Yaygın tuzaklar ve nasıl önlenir

| Sorun | Neden | Çözüm |
|-------|-------|-----|
| Barkod uzatılmış görünüyor | X‑dimension noktalar yerine piksellerle ayarlandığında | `Pixels` özelliğini her zaman piksel‑tam kontrol için kullanın |
| Boş çubuklar hâlâ dolu görünüyor | `FilledBars`, X‑dimension değiştirildikten sonra `false` olarak ayarlanmamış | `FilledBars = false`'ı X‑dimension'ı ayarladıktan *sonra* ayarlayın |
| Kaydedilen dosya boş | Çıktı dizini mevcut değil veya yazma izni yok | Dizinin var olduğundan emin olun (`Directory.CreateDirectory`) ve uygulamanızın yeterli izinle çalıştığını kontrol edin |
| Görüntü baskıda bulanık | Yüksek çözünürlüklü ekrandan düşük DPI PNG kaydedildi | `BarCodeImageFormat.Png` (kayıpsız) kullanın ve gerekirse `Resolution` özelliğini düşünün |

## Tam, çalıştırılabilir örnek

Aşağıdaki tüm bloğu yeni bir konsol projesine (`dotnet new console`) kopyalayın ve çalıştırın. Program, `output` klasöründe üç PNG dosyası oluşturur.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Beklenen çıktı:** üç PNG dosyası—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` ve `PostalRM4SCCFilledBars.png`—her biri 4 piksel genişliğinde çubuklar içerir, baskı veya sonraki işlem için hazır.

## Sonuç

Artık C#'ta **planet barkodu oluşturmayı** ve dolu ve boş çubuk stilleri için **barkod boyutlarını nasıl ayarlayacağınızı** kesin olarak biliyorsunuz. Aynı desen, RM4SCC gibi diğer sembollere de uygulanır ve herhangi bir posta‑barkodu ihtiyacı için esnek bir temel sağlar.

Sonra, şunları keşfedebilirsiniz:

* Barkodun altına insan tarafından okunabilir metin ekleme (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* `Parameters.Barcode.BarColor` ile çubuk renklerini değiştirme
* Ölçeklenebilir baskı için vektör formatlarında (SVG, EPS) barkod oluşturma

Farklı X‑dimension değerleri, veri dizileri ve çıktı formatlarıyla denemeler yapmaktan çekinmeyin; böylece belirli iş akışınıza uyarlayabilirsiniz. Kodlamanın tadını çıkarın!
