# C# ile DataBar Stacked Omni‑Directional barkod görüntüsü oluşturma

Bir .NET uygulamasında **barkod görüntüsü oluşturma** ihtiyacınız varsa, bu öğretici tam adımları gösterir. DataBar Stacked Omni‑Directional barkodu nasıl oluşturacağınızı, en‑boy oranını nasıl ayarlayacağınızı ve sonucu PNG dosyaları olarak nasıl dışa aktaracağınızı göreceksiniz.

Barkod oluşturma, envanter sistemleri, perakende satış noktası terminalleri ve lojistik takibi için yaygın bir gereksinimdir. Aşağıdaki bölümlerde, gerekli NuGet paketinden son görüntü doğrulamasına kadar ihtiyacınız olan her şeyi ele alacağız; böylece barkod oluşturmayı bugün herhangi bir C# projesine entegre edebilirsiniz.

## Önkoşullar

Başlamadan önce şunların yüklü olduğundan emin olun:

* .NET 6.0 veya üzeri (kod .NET Core ve .NET Framework ile çalışır)
* Visual Studio 2022 veya tercih ettiğiniz herhangi bir C# IDE
* **Aspose.BarCode for .NET** NuGet paketi (kurulum: `dotnet add package Aspose.BarCode`)
* PNG dosyalarının kaydedileceği klasöre yazma izni

Bu önkoşullar, örnek kodun ek yapılandırma gerektirmeden çalışmasını garanti eder.

## Adım 1: Çıktı klasörünü ayarlama

İlk olarak, oluşturulan PNG dosyalarının yazılacağı bir dizine ihtiyacınız var. Mutlak ya da göreli bir yol kullanabilirsiniz, ancak `Save` metodunu çağırmadan önce klasörün var olduğundan emin olun.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Klasörü programmatically oluşturmak, `Save` yöntemi görüntüyü yazmaya çalıştığında *FileNotFoundException* oluşmasını önler.

## Adım 2: DataBar Stacked Omni‑Directional barkod oluşturucu oluşturma

**BarcodeGenerator** sınıfı, tüm barkod tipleri için giriş noktasıdır. Burada `EncodeTypes.DatabarStackedOmniDirectional` ve kodlamak istediğimiz veri dizesini belirtiyoruz.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Bu neden önemlidir*: `EncodeTypes` enum’u, kütüphaneye hangi sembolojiyi render edeceğini söyler. Omni‑Directional varyantını kullanmak, barkodun herhangi bir yönelimden taranabilmesini sağlar – bu, birçok depo tarayıcısı için bir gereksinimdir.

## Adım 3: Ortak barkod parametrelerini yapılandırma

Okunabilir bir barkod, mantıklı bir X‑dimension (en küçük çubuğun genişliği) gerektirir. `Pixels` değerini 2 olarak ayarlamak, çoğu ekran çözünürlüğü için boyut ve netlik arasında iyi bir denge sağlar.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Daha büyük ya da daha küçük bir görüntüye ihtiyacınız olursa `Pixels` değerini daha sonra ayarlayabilirsiniz; kütüphane barkodun geri kalanını otomatik olarak ölçekler.

## Adım 4: En‑boy oranı 15 ile ilk görüntüyü oluşturma

**Aspect ratio**, DataBar barkodlarının yükseklik‑genişlik ilişkisini kontrol eder. En‑boy oranı 15, perakende etiketleri için tipik bir varsayılan değerdir.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Bu çağrıdan sonra, çıktı klasöründe `DatabarAspectRatio15.png` dosyasını bulacaksınız. Görüntü kayıpsız bir PNG olup, ek işleme veya baskı için uygundur.

## Adım 5: En‑boy oranını 30’a değiştirip ikinci görüntüyü dışa aktarma

Bazen daha uzun bir barkod gerekir – örneğin etiket yüksekliği sınırlı olduğunda. En‑boy oranını 30’a değiştirmek, veri bütünlüğünü korurken daha kompakt bir görünüm üretir.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Artık aynı verinin farklı en‑boy oranlarıyla nasıl göründüğünü gösteren iki PNG dosyanız var. Bu yan‑yana karşılaştırma, hangi varyantın etiket düzeninize en iyi uyduğunu belirlemenize yardımcı olur.

## Tam, çalıştırılabilir örnek

Aşağıda kopyalayıp yapıştırıp çalıştırabileceğiniz tam program yer almaktadır. Tüm `using` yönergeleri, hata yönetimi ve sürecin her adımını açıklayan yorumlar dahildir.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Beklenen çıktı** (konsol):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

İki PNG dosyasını herhangi bir görüntü görüntüleyicide açın. Aynı GTIN kodlandığını göreceksiniz, ancak ikinci görüntü daha yüksek en‑boy oranı nedeniyle daha uzundur.

## Uzman ipuçları ve yaygın tuzaklar

| Durum | Öneri |
|-----------|----------------|
| **Düşük çözünürlüklü ekranlar** | Çubukların keskin kalması için `XDimension.Pixels` değerini 3 veya 4’e yükseltin. |
| **Termal kağıda baskı** | Daha yüksek doğruluk için `BarCodeImageFormat.Tiff` kullanın ve `Resolution.DpiX/DpiY` değerini 300’e ayarlayın. |
| **Dinamik veri** | Aynı `BarcodeGenerator` örneğini yeniden kullanın ve her `Save` öncesinde yalnızca `generator.CodeText` değerini güncelleyin. Bu, gereksiz nesne tahsisinin önüne geçer. |
| **Geçersiz GTIN** | Veri GS1 standartlarına uymuyorsa kütüphane `ArgumentException` fırlatır. Verinizi jeneratöre göndermeden önce doğrulayın. |
