## Paketleri İçe Aktarma

`EncodeTypes` enum'u desteklenen barkod sembollerini tanımlar ve `BarcodeGenerator` barkod görüntülerini oluşturan sınıftır.

```java
import com.aspose.barcode.EncodeTypes;
import com.aspose.barcode.generation.BarcodeGenerator;
```

## Adım‑Adım Kılavuz

### Adım 1: Kaynak Dizinini Ayarla

Oluşturulan PNG'nin nerede saklanacağını tanımlayın.

```java
String dataDir = "Your Document Directory";
```

`"Your Document Directory"` ifadesini sisteminizdeki mutlak yol ile değiştirin (ör. `C:/Barcodes/`). Mutlak yol kullanmak, göreli‑yol belirsizliklerini önler ve dosyanın beklediğiniz yerde yazılmasını sağlar.

### Adım 2: BarcodeGenerator Örneğini Oluştur

`BarcodeGenerator` sınıfı, seçilen sembol ve veri temelinde barkod görüntüleri oluşturur. Üreteci Australia Post sembolü ve kodlamak istediğiniz veri ile örnekleyin.

```java
BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.AUSTRALIA_POST, "1234567890");
```

`"1234567890"` ifadesini gerçek posta kodu, takip numarası veya Australia Post kurallarına uyan herhangi bir dize ile değiştirin. Üreteç, giriş uzunluğunu ve karakter kümesini otomatik olarak doğrular.

### Adım 3: Barkod Görüntüsünü Kaydet

Barkodu, belirttiğiniz dizinde bir PNG dosyasına yazın.

```java
generator.save(dataDir + "australiaPostBarcode.png");
```

Çalıştırdıktan sonra, `australiaPostBarcode.png` dosyasını bulacaksınız; bu dosya yazdırma veya PDF, e-posta, web sayfalarına gömme için hazırdır.

### Adımların Özeti

1. Kaynak dizini ayarla.  
2. `EncodeTypes.AUSTRALIA_POST` ile bir `BarcodeGenerator` oluştur.  
3. PNG dosyasını yazmak için `save()` metodunu çağır.

Artık bu kod parçacığını barkod oluşturma gerektiren herhangi bir Java servisi, web uygulaması veya toplu iş içine entegre edebilirsiniz.
