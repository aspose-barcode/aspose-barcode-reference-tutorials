# C#'ta kompakt ayarlarla PDF417 barkod oluşturma

Eğer bir .NET uygulamasında **PDF417 barkod oluşturmanız** gerekiyorsa, bu kılavuz Aspose.Barcode for .NET ile bunu nasıl yapacağınızı gösterir. Oluşturucuyu oluşturma, sütunları, X‑boyutunu yapılandırma ve kompakt modu etkinleştirerek ortaya çıkan sembolün mümkün olduğunca küçük olmasını sağlayacağız.

PDF417 barkod oluşturma, biletler, kimlik kartları veya gönderi etiketleri gibi büyük miktarda veriyi kodlamanız gerektiğinde yaygındır. Bu öğretici, kütüphanenin kurulumu aşamasından son PNG'nin kaydedilmesine kadar tüm iş akışını kapsar—kodları kendi projenize kopyalayıp hemen çalıştırabilirsiniz.

## PDF417 barkod oluşturmak için önkoşullar

* .NET 6.0 (veya daha yeni) yüklü olmalı.  
* Visual Studio 2022 veya C# projelerini destekleyen herhangi bir IDE.  
* **Aspose.Barcode for .NET** için bir NuGet lisansı (ücretsiz deneme sürümü öğrenme amaçlı kullanılabilir).  

Kütüphaneyi aşağıdaki komutla ekleyebilirsiniz:

```bash
dotnet add package Aspose.BarCode
```

> **Pro ipucu:** Bilinen stabil bir sürümü sabitlemek için `--version` bayrağını kullanın, örn., `dotnet add package Aspose.BarCode --version 23.12`.

## PDF417 barkod oluşturucu oluşturma

İlk kod bloğu, PDF417 sembolü için ön‑yapılandırılmış bir `BarcodeGenerator` örneği oluşturur. `"Åspóse.Barcóde©"` metni, oluşturucunun kutu dışı (non‑ASCII) girişleri sorunsuz bir şekilde işlediğini göstermek için Unicode karakterler içerir.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Bunun önemi
`EncodeTypes.Pdf417` Aspose.Barcode'a **PDF417 barkodu** istediğinizi söyler; bu, 1 850 karaktere kadar veri depolayabilen yığılmış bir lineer sembolojidir. Metin argümanıyla yapıcıyı kullanmak, daha sonra `SetCodeText` çağrısı yapmanız ihtiyacını ortadan kaldırır.

## Barkod XDimension (modül boyutu) ayarlama

Modül boyutu, aynı zamanda X‑boyutu olarak da bilinir, her bir çubuğun ne kadar geniş olacağını belirler. Daha küçük pikseller daha yoğun bir görüntü üretirken, daha büyük pikseller düşük çözünürlüklü yazıcılarda okunabilirliği artırır.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### XDimension'ı neden ayarlamalısınız
`2` piksel değeri ekran görüntüsü ve çoğu ofis yazıcısı için iyidir. Daha yüksek çözünürlüklü bir baskıya ihtiyacınız varsa değeri artırın; daha sıkı bir barkod (örneğin QR‑benzeri bir görünüm) istiyorsanız azaltın—ancak asla `1` pikselin altına düşürmeyin, aksi takdirde görüntü okunamaz hâle gelir.

## PDF417 sembolü için sütun sayısını ayarlama

PDF417, barkodun kaç sütun (dikey yığın) olacağını seçmenize izin verir. Daha az sütun barkodu daha uzun yapar; daha çok sütun ise daha geniş yapar.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### Sütun sayısını ne zaman değiştirmelisiniz
Üç sütun, standart kimlik kartlarına rahatça sığan kompakt, neredeyse kare bir sembol üretir. Çok uzun bir dizeye sahipseniz, yüksekliği makul tutmak için sütun sayısını artırabilirsiniz.

## Kompakt modu (kırpma) etkinleştirme

Kompakt mod, sembolden kullanılmayan satırları otomatik olarak kaldırarak genel boyutunu küçültür. Bu, kodlanan verinin tam matrisi doldurmadığı durumlarda özellikle faydalıdır.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Kompakt PDF417 barkodunun faydaları
`Truncate` **true** olduğunda, oluşturucu verinizi depolamak için gereken minimum satır sayısını hesaplar; bu da mürekkep tüketimini ve tarama süresini azaltır. PDF417 spesifikasyonu kırpma algoritmasını tanımladığından, çoğu tarayıcı için güvenlidir.

## Oluşturulan barkodu görüntü olarak kaydetme

Son olarak barkodu bir PNG dosyasına yazın. PNG kayıpsız kaliteyi korur ve daha sonraki baskı ya da PDF'lere gömme için idealdir.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Beklenen çıktı
Program çalıştırıldığında belirtilen klasörde `CompactPdf417.png` oluşturulur. Görüntü, `"Åspóse.Barcóde©"` dizesini üç sütun, 2‑piksel X‑boyutu ve kırpma uygulanmış **kompakt PDF417 barkodu** olarak kodlar. Sonucu herhangi bir barkod tarayıcı uygulaması ya da ücretsiz Aspose.Barcode çevrimiçi demosu ile doğrulayabilirsiniz.

## Yaygın varyasyonlar ve uç durumlar

| Durum | Ayar |
|-----------|------------|
| **Çok uzun veri (> 1500 karakter)** | `Columns` değerini artırın veya `Rows` değerini manuel olarak ayarlayın (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Düşük‑dpi yazıcıda baskı** | Pikselleşmeyi önlemek için `XDimension.Pixels` değerini 3 veya 4'e yükseltin. |
| **Şeffaf arka plan ihtiyacı** | `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })` kullanın. |
| **PDF içine gömme** | `BarCodeImageFormat.Pdf` olarak kaydedin veya `pdf417Generator.GenerateBarCodeImage()` ile `Image` nesnesini alın. |

## Tam, çalıştırılabilir örnek

Aşağıda yeni bir konsol projesine kopyalayabileceğiniz tam program yer almaktadır. Ek bir dosyaya ihtiyaç yoktur.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Proje klasöründen `dotnet run` komutunu çalıştırın. Çalıştırmanın ardından `CompactPdf417.png` dosyasını açarak oluşturulan barkodu görebilirsiniz.
