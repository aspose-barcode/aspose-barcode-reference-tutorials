# C# ile Aspose.BarCode kullanarak barkod oluşturma ve meta veri ekleme

Eğer bir lojistik veya envanter sistemi için **C# ile barkod oluşturmanız** gerekiyorsa, bu kılavuz size eksiksiz, üretim‑hazır bir çözüm gösterir. Macro PDF417 barkodu nasıl oluşturacağınızı, zengin meta verileri nasıl ekleyeceğinizi ve kesin bir zaman damgasını nasıl ayarlayacağınızı — tüm bunları Aspose.BarCode kütüphanesiyle göreceksiniz.

Bu öğretici, NuGet paketinin kurulmasından son PNG görüntüsünün kaydedilmesine kadar her şeyi kapsar. Sonunda, dosya kimlikleri, segment bilgileri ve özel alanlar taşıyan bir barkod oluşturabilir, Macro PDF417’yı destekleyen alıcı tarayıcılar için hazır hale getirebilirsiniz.

## Önkoşullar

Başlamadan önce aşağıdakilere sahip olduğunuzdan emin olun:

* .NET 6.0 SDK veya daha yeni bir sürüm (kod .NET Framework 4.7.2+ ile de çalışır)
* Visual Studio 2022 veya tercih ettiğiniz herhangi bir C# IDE
* Aktif bir Aspose.BarCode lisansı (ücretsiz deneme sürümü geliştirme için yeterlidir)
* C# sözdizimi hakkında temel bilgi

> **Pro ipucu:** Bir CI/CD boru hattı kullanıyorsanız, proje dosyanıza Aspose.BarCode paket referansını ekleyin; böylece derlemeler yeniden üretilebilir olur.

## Adım 1: Aspose.BarCode’u Kurun

Proje klasörünüzde bir terminal açın ve şu komutu çalıştırın:

```bash
dotnet add package Aspose.BarCode
```

Komut, en son kararlı sürümü (şu anda 24.9) indirir. Geri yükleme tamamlandıktan sonra kütüphaneyi kaynak dosyalarınızda referans alabilirsiniz.

## Adım 2: Yeni bir C# konsol projesi oluşturun (isteğe bağlı)

Temiz bir başlangıç istiyorsanız, bir konsol uygulaması oluşturun:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs` dosyası, daha sonra gösterilecek barkod oluşturma kodunu barındıracak.

## Adım 3: Barkod üreteciyi ayarlayın

İşlemin çekirdeği `BarcodeGenerator` sınıfıdır. İstediğiniz `EncodeTypes` enum değerini ve kodlamak istediğiniz metni belirterek bir örnek oluşturursunuz.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Her satırın önemi

* **EncodeTypes.MacroPdf417** Aspose’a, segmentlere ayrılabilen bir PDF417 barkodu üretmesini söyler. Bu, tek bir sembolün kapasitesini aşan büyük veri yükleri için gereklidir.
* **XDimension.Pixels** görsel yoğunluğu kontrol eder. 2 değeri, çoğu ekran ve yazıcıda dosya boyutunu şişirmeden net bir görüntü üretir.
* **MacroPdf417* özellikleri** alt tarayıcıların ayrı alanlar (dosya ID’si, segment ID’si vb.) olarak okuduğu meta verileri gömer. Bu, öğreticideki “meta veri ekleme” kısmıdır.
* **MacroPdf417TimeStamp** “zaman damgası ayarlama” örneğidir. `DateTime` örneği herhangi bir UTC zamanı olabilir; UTC kullanmak, barkod farklı bölgeler arasında taşındığında saat dilimi belirsizliğini önler.
* **MacroPdf417Terminator** makro dizisinin nasıl sonlandırılacağını tanımlar. `Set` en yaygın seçimdir çünkü okuyucuya son segmenti işaret eder.
* **Save(..., BarCodeImageFormat.Png)** kayıpsız bir görüntü yazar; bu, güvenilir tarama için gereken ince detayları korur.

## Adım 4: Oluşturulan barkodu doğrulayın

Programı çalıştırın:

```bash
dotnet run
```

Aşağıdaki konsol çıktısını görmelisiniz:

```
Barcode saved to ExtPDF417Meta.png
```

`ExtPDF417Meta.png` dosyasını herhangi bir görüntü görüntüleyicide açın. Resim, **Åspóse.Barcóde©** metni ve gömülü makro alanlarıyla kompakt bir PDF417 sembolü gösterecek. PDF417‑uyumlu bir tarayıcı (veya Macro PDF417’yı destekleyen bir mobil uygulama) ile resmi taradığınızda, orijinal metnin yanı sıra ayarladığınız meta veri değerlerini de alacaksınız.

### Beklenen görsel özellikler

* Koyu, eşit aralıklı dikey çubuklar
* Aspose tarafından otomatik olarak eklenen bir sessiz bölge (kenar boşluğu)
* Bozulma yok, çünkü `XDimension` değeri 2 piksel PNG’nin yerel çözünürlüğüyle eşleşiyor

## Adım 5: Yaygın varyasyonlar ve kenar durumları

### 5.1 Özel karakterlerin işlenmesi

Örnek metin Unicode karakterleri (`Å`, `ó`, `©`) içeriyor. Aspose.BarCode, varsayılan olarak UTF‑8 kullanarak bunları kodlar; bu yüzden barkodda doğru görünürler. Farklı bir kodlama (ör. ISO‑8859‑1) gerekiyorsa şu ayarı yapın:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Büyük dosya kimlikleri

`MacroPdf417FileID` 32‑bit bir tamsayı kabul eder. `int.MaxValue`’dan büyük değerler için kimliği birden fazla alana bölün veya `MacroPdf417FileName` içinde dize olarak bir GUID kullanın.

### 5.3 Sütun sayısının ayarlanması

`Pdf417.Columns` değerini artırmak barkod yüksekliğini azaltır ancak her satırı genişletir. Barkod dar bir etikete sığacaksa sütun sayısını düşürün; satır sayısı otomatik olarak artar.

### 5.4 Diğer formatlarda kaydetme

Aspose BMP, JPEG, TIFF ve SVG formatlarını da destekler. `BarCodeImageFormat.Png` yerine istediğiniz enum değerini koyun; örneğin ölçeklenebilir bir vektör grafik için `BarCodeImageFormat.Svg`.

## Adım 6: Barkodu daha büyük bir iş akışına entegre edin

PNG dosyasını elde ettikten sonra şunları yapabilirsiniz:

* Aspose.PDF kullanarak bir PDF faturaya gömün.
* Teslimat kanıtı olarak bir e‑posta ekleyin.
* Görüntü baytlarını daha sonra erişim için bir veritabanında saklayın.

Aşağıda, PNG’yi depolama için bir bayt dizisine dönüştüren hızlı bir kod parçacığı bulunuyor:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Sıkça Sorulan Sorular

**S: Bu .NET Core’da çalışır mı?**  
C: Evet. Aynı API .NET Core, .NET 5+ ve .NET Framework üzerinde çalışır. Uygun NuGet paketini referans almanız yeterlidir.

**S: Macro olmayan bir PDF417 üretmem gerekirse ne yapmalıyım?**  
C: `EncodeTypes.Pdf417` kullanın, `EncodeTypes.MacroPdf417` yerine. Macro‑özel özellikler göz ardı edilir.

**S: Yerleşik alanların dışına özel anahtar/değer çiftleri ekleyebilir miyim?**  
C: Aspose.BarCode, Macro PDF417 için rastgele kullanıcı alanlarını açmaz. Ek veri gerekiyorsa, ana metin yüküne kodlayın veya yapılandırılmış eklemeyi destekleyen QR koduna geçin.
