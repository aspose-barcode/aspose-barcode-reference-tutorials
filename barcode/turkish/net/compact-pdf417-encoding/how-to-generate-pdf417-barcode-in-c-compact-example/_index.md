# C#'ta PDF417 barkod nasıl oluşturulur – kompakt örnek

Eğer bir C# uygulamasında **PDF417 barkod oluşturmanız** gerekiyorsa, bu kılavuz size eksiksiz, çalıştırmaya hazır bir çözüm gösterir. Kompakt bir PDF417 barkod oluşturacağız, modül genişliğini ayarlayacağız, sütun sayısını tanımlayacağız ve sonucu PNG görüntüsü olarak kaydedeceğiz—tüm bunlar Aspose.BarCode .NET kütüphanesi ile.

PDF417 barkod oluşturmak, büyük miktarda veriyi (ör. URL'ler, iletişim kartları veya envanter kimlikleri) alan‑verimli iki boyutlu bir formatta kodlamak istediğinizde yaygındır. Bu öğreticinin sonunda, baskı veya ekranda gösterime hazır, kompakt ve yüksek okunabilirlikte bir barkod üreten çalışan bir `BarcodeGenerator` örneğine sahip olacaksınız.

## Prerequisites

- .NET 6.0 veya üzeri (kod .NET Framework 4.8 ile de çalışır)
- Visual Studio 2022 (veya herhangi bir C# IDE)
- Aspose.BarCode for .NET NuGet paketi (`Install-Package Aspose.BarCode`)
- C# sözdizimine temel aşinalık

Ek bir yapılandırma gerekmez; örnek bir konsol uygulaması olarak çalışır.

## Step 1: Create a PDF417 barcode generator

İlk adım, `EncodeTypes.Pdf417` enum’u ve kodlamak istediğiniz metinle `BarcodeGenerator` örneği oluşturmaktır.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Neden önemli:** `EncodeTypes.Pdf417` kütüphaneye PDF417 sembolojisini kullanmasını söyler, ikinci argüman ise veri yükünü ayarlar. `"Compact example"` ifadesini 1 800 karaktere kadar herhangi bir dizeyle değiştirebilirsiniz.

## Step 2: Set the module width (X‑dimension) in pixels

X‑dimension, tek bir barkod modülünün (en küçük siyah veya beyaz kare) genişliğini tanımlar. Daha küçük piksel değeri daha sıkı bir barkod üretir.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Neden önemli:** `2` piksel değeri, çoğu modern tarayıcıda tarama güvenilirliğinden ödün vermeden kompakt bir görünüm oluşturur. Düşük çözünürlüklü baskı için daha büyük modüllere ihtiyacınız varsa değeri ayarlayın.

## Step 3: Specify the number of columns

PDF417, barkodun en‑boy oranını etkileyen sütun sayısını kontrol etmenize izin verir.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Neden önemli:** Daha az sütun barkodu daha uzun yapar, daha çok sütun ise düzleştirir. Üç sütun, kompakt ve dikey (portrait) düzen için iyi çalışır.

## Step 4: Enable compact mode by truncating the barcode

Kompakt mod, gereksiz doldurma satırlarını kaldırarak barkodu daha küçük hâle getirir, aynı zamanda kodlanan veriyi korur.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Neden önemli:** Trunkasyon, ekran alanının sınırlı olduğu durumlarda (ör. mobil uygulamalar veya küçük etiketler) idealdir. Kodlama algoritması hata‑düzeltme seviyelerini otomatik olarak ayarladığından barkod tamamen okunabilir kalır.

## Step 5: Save the barcode as a PNG image

Son olarak, oluşturulan barkodu bir dosyaya yazalım. PNG, kayıpsız kalite koruduğu için barkod tarayıcıları için kritiktir.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Programı çalıştırdığınızda yürütülebilir dosyanın çalışma dizininde `CompactPdf417.png` oluşturulur. Görüntü aşağıdaki gibidir:

![Kompakt PDF417 barkodu oluşturuldu](CompactPdf417.png "Kompakt PDF417 barkodu oluşturuldu")

**Beklenen çıktı:** 2 piksel genişliğinde, üç sütunlu bir PDF417 barkodu ve “Compact example” metnini kodlar. Standart bir barkod tarayıcısıyla PNG'yi taradığınızda orijinal dize geri dönmelidir.

## Common variations and edge cases

| Durum | Kodu nasıl ayarlamalısınız |
|-----------|------------------------|
| **Daha uzun veri ( > 500 karakter )** | Barkodun çok uzun olmasını önlemek için `Columns` değerini 5‑7 aralığına çıkarın. |
| **Yüksek çözünürlüklü baskı** | Daha büyük modüller için `XDimension.Pixels` değerini 3 veya 4 yapın. |
| **Farklı görüntü formatı** | `BarCodeImageFormat.Png` yerine ihtiyacınıza göre `Jpeg` veya `Bmp` kullanın. |
| **Barkodu bir PDF'e gömmek** | PNG yerine `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` kullanın. |

**İpucu:** Oluşturulan barkodu hedef tarayıcı donanımında mutlaka test edin. Bazı düşük maliyetli tarayıcılar çok küçük X‑dimension değerlerinde zorlanabilir; okuma hataları alırsanız piksel değerini bir adım artırın.

## Full, runnable example

Aşağıda yeni bir konsol projesine kopyalayıp yapıştırabileceğiniz tam program yer almaktadır. Ek bir dosyaya ihtiyaç yoktur.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Programı derleyip çalıştırın (`dotnet run` .NET CLI kullanıyorsanız). Çalıştırdıktan sonra görsel sonucu doğrulamak için `CompactPdf417.png` dosyasını açın.

## Conclusion

Artık **C#'ta PDF417 barkod nasıl oluşturulur** konusunda kompakt bir düzen, özel X‑dimension ve sütun ayarlarıyla bilgi sahibisiniz. Örnek, temel adımları gösterir: `BarcodeGenerator` örneği oluşturma, `XDimension` ve `Columns` ayarlama, kompakt mod için `Truncate` etkinleştirme ve son olarak görüntüyü kaydetme.

Buradan, hata‑düzeltme seviyesi, özel renkler veya barkodu doğrudan PDF'lere gömme gibi ek özellikleri keşfedebilirsiniz. Başka sembolojilere (ör. QR, Code128) ihtiyaç duyarsanız farklı `EncodeTypes` deneyin ve aynı parametre yapılandırma desenini uygulayın.

İyi kodlamalar, ve barkodlarınızın ilk denemede taranmasını dileriz!
