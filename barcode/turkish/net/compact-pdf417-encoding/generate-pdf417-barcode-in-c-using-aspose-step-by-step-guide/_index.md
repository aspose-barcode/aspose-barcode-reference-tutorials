# C# kullanarak Aspose ile PDF417 barkod oluşturma – adım adım rehber

Bir .NET uygulamasında **PDF417 barkod oluşturmanız** gerekiyorsa, bu rehber tam olarak nasıl yapılacağını gösterir. Aspose.BarCode for .NET ile temel, kompakt, Micro, GS1‑Micro ve Macro PDF417 barkodları oluşturan eksiksiz, çalıştırmaya hazır bir örnek göreceksiniz.

PDF417 barkod oluşturma, nakliye etiketleri, taşıma belgeleri ve envanter sistemleri için yaygın bir gereksinimdir. Bu öğreticinin sonunda **PDF417 barkod** görüntüleri oluşturabilecek, temel parametreleri anlayacak ve kodu kendi veri yükleriniz için uyarlayabileceksiniz.

## Önkoşullar

- .NET 6.0 SDK veya daha yeni bir sürüm (kod .NET Framework 4.7+ ile de çalışır)
- Visual Studio 2022 veya herhangi bir C# IDE
- Aspose.BarCode for .NET NuGet paketi (`Aspose.BarCode`) yüklü
- C# sözdizimi hakkında temel bilgi

> **Pro ipucu:** Test ederken çalışma zamanı kısıtlamalarından kaçınmak için Aspose'un ücretsiz değerlendirme lisansını kullanın.

## Adım 1: Projeyi kurun ve ad alanlarını içe aktarın

Yeni bir konsol projesi oluşturun ve Aspose.BarCode paketini ekleyin:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Ardından `Program.cs` dosyasını açın ve gerekli `using` yönergelerini ekleyin:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Bu ad alanları, **C# kullanarak barkod oluşturmak** için gereken `BarcodeGenerator` sınıfına ve `EncodeTypes` enumarasyonuna erişim sağlar.

## Adım 2: Temel bir PDF417 barkod oluşturun

En basit PDF417 barkod, X‑dimension (modül genişliği) ve sütun sayısı dışındaki varsayılan ayarları kullanır. Bu değerleri ayarlamak, barkodun genel boyutunu ve okunabilirliğini kontrol eder.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Neden çalışıyor:**  
- `EncodeTypes.Pdf417` Aspose'a PDF417 sembolojisini kullanmasını söyler.  
- `XDimension.Pixels` en küçük çubuk genişliğini tanımlar; 2 değeri, taranabilirliği kaybetmeden görüntüyü küçük tutar.  
- `Pdf417.Columns` barkodun kaç veri sütunu içereceğini belirler; üç sütun dengeli bir en-boy oranı verir.

## Adım 3: Kompakt (kısaltılmış) PDF417 barkod oluşturun

Kompakt mod, durdurma desenini kaldırır ve toplam yüksekliği azaltır; bu, sınırlı alanlı etiketler için faydalıdır.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Neden çalışıyor:**  
`Pdf417.Truncate = true` ayarı, sağ taraftaki durdurma desenini atar ve barkod yüksekliğini azaltırken veri bütünlüğünü korur.

## Adım 4: Micro PDF417 barkod oluşturun

Micro PDF417, 1‑4 sütunu destekleyen daha küçük bir varyanttır. Küçük ürün etiketleri gibi alanın kritik olduğu uygulamalar için idealdir.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Neden çalışıyor:**  
- `EncodeTypes.MicroPdf417` sembolojinin mikro sürümünü seçer.  
- Sütun sayısı 1 ile 4 arasında olabilir; 4 seçildiğinde en yoğun düzen elde edilir ve hâlâ taranabilir kalır.

## Adım 5: GS1‑uyumlu Micro PDF417 barkod oluşturun

GS1 ön ekleri, barkod verisine standartlaştırılmış tanımlayıcılar (ör. GTIN, parti numarası) ekler. Aspose bu bilgileri doğrudan gömmenize olanak tanır.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Neden çalışıyor:**  
GS1 Uygulama Tanımlayıcıları (AI'lar) parantez içinde yer alır. Aspose bunları ayrıştırır ve GS1 tarayıcıları için gerekli biçimlendirmeyi ekler.

## Adım 6: Tam meta veri ile Macro PDF417 barkod oluşturun

Macro PDF417, büyük bir veri yükünü birden fazla bağlantılı barkod arasında bölmenizi sağlar. Dosya kimliği, segment sayısı, zaman damgaları ve özel dizeler gibi dosya‑seviyesi meta verileri gömebilirsiniz.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Neden çalışıyor:**  
Her `MacroPdf417*` özelliği, makro barkod spesifikasyonunun belirli bir segmentine karşılık gelir. Bu değerleri ayarlamak, bir tarayıcının birden fazla barkod görüntüsünden orijinal dosyayı yeniden oluşturmasını sağlar.
