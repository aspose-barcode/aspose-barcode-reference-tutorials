# Aspose.BarCode for .NET ile DataMatrix barkodları nasıl oluşturulur

.NET uygulamalarınıza makine tarafından okunabilir semboller eklemenin güvenilir bir yoluna ihtiyacınız varsa, **DataMatrix barkodları nasıl oluşturulur** yaygın bir gereksinimdir. Aspose.BarCode for .NET, doğru DataMatrix sürümünü seçmekten hata düzeltme seviyelerini ince ayarlamaya kadar her adımı dış araçlar gerektirmeden yöneten tam yönetilen bir API sunar. Bu öğreticide, eksiksiz bir örnek üzerinden ilerleyecek, her ayarın neden önemli olduğunu açıklayacak ve sonucu PNG veya JPEG görüntüsü olarak nasıl kaydedeceğinizi göstereceğiz.

## Hızlı cevaplar
- **DataMatrix barkodlarını hangi kütüphane oluşturur?** Aspose.BarCode for .NET.  
- **Kaç DataMatrix sürümü destekleniyor?** All 30 standard square and rectangular versions (from 10×10 up to 144×144 modules).  
- **Hangi ECC türlerini kullanabilirim?** ECC200 (default) and ECC140.  
- **Geliştirme için lisansa ihtiyacım var mı?** A free 30‑day trial works for testing; a commercial license is required for production.  
- **Bunu .NET 6, .NET Core veya .NET Framework üzerinde çalıştırabilir miyim?** Yes—Aspose.BarCode supports .NET Framework 4.5+, .NET Core 3.1+, and .NET 5/6+.

## DataMatrix barkodu nedir?
DataMatrix barkodu, iki boyutlu, kare veya dikdörtgen bir matris olup, siyah ve beyaz hücrelerden oluşur ve 2.335 alfanümerik karaktere kadar depolayabilir. Üretim, lojistik ve sağlık sektörlerinde küçük öğeleri işaretlemek için yaygın olarak kullanılır çünkü kısmen hasar görse bile okunabilirliğini korur.

## Neden Aspose.BarCode for .NET kullanmalı?
Aspose.BarCode **50+ çıktı formatını** (PNG, JPEG, TIFF, SVG ve PDF dahil) destekler ve tüm 30 DataMatrix sürümünü, görüntüyü belleğe tamamen yüklemeden oluşturabilir, bu sayede 100 MB'den büyük dosyaları işleyen yüksek verimli hizmetlerde barkodlar oluşturabilirsiniz.

## .NET'te DataMatrix barkodları nasıl oluşturulur?

`BarcodeGenerator`'ı `EncodeTypes.DataMatrix` türüyle yükleyin, istediğiniz sürüm ve ECC'yi ayarlayın, ardından görüntü dosyasını yazmak için `Save`'i çağırın. Bu tek satır desen, seçtiğiniz herhangi bir sürüm için çalışır ve modül boyutlandırma, sessiz bölgeler ve görüntü işleme işlemlerini otomatik olarak yönetir.

## Ad alanlarını içe aktar

`BarcodeGenerator`, barkod görüntüleri oluşturmak için Aspose.BarCode'un temel sınıfıdır.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

`Aspose.BarCode.Generation` ad alanı, barkod görüntüleri oluşturmak için kullanılan birincil sınıf olan `BarcodeGenerator` sınıfına erişim sağlar.

Şimdi, örneği birden fazla adıma ayıralım.

## Adım 1: dizin yolunuzu ayarlayın

Oluşturulan DataMatrix barkodlarını kaydetmek istediğiniz dizin yolunu tanımlayarak başlayın.

```csharp
string path = "Your Directory Path";
```

`"Your Directory Path"` ifadesini barkod görüntülerini kaydetmek istediğiniz gerçek yol ile değiştirin.

## Adım 2: barkod oluşturucuyu başlatın

`BarcodeGenerator` sınıfının bir örneğini oluşturun ve barkod türünü `DataMatrix` olarak belirtin. Ayrıca barkod içinde kodlamak istediğiniz veriyi de sağlayabilirsiniz.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator`, barkod sembollerini oluşturup render eden ana sınıftır.

## Adım 3: barkod özelliklerini yapılandırın

DataMatrix barkodunun boyutları ve ECC (Error Correction Code) türü gibi çeşitli özelliklerini özelleştirebilirsiniz. İşte X‑dimension'ı 4 piksel olarak ayarlayıp ECC200'ü seçen bir örnek:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension`, her modülün piksel cinsinden boyutunu ayarlar ve `DataMatrixEcc`, hata düzeltme seviyesini seçer.

## Adım 4: DataMatrix sürümünü ayarlayın ve kaydedin

Satır ve sütun sayısını ayarlayarak DataMatrix sürümünü belirtebilirsiniz. Sürümü yapılandırdıktan sonra barkod görüntüsünü kaydedin.

Örneğin, ECC200 kullanarak 22 satır ve 22 sütunlu bir DataMatrix barkodu oluşturmak için:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

Benzer şekilde, sürümü ve ECC türünü değiştirerek farklı parametrelerle barkod oluşturabilirsiniz.

## Adım 5: diğer sürümler için tekrarlayın

Adım 4'ü diğer DataMatrix sürümleri için tekrarlayabilirsiniz. Örneğin, ECC200 kullanarak 12 satır ve 64 sütunlu bir barkod oluşturmak için:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Adım 6: ECC türlerini değiştirin

ECC türünü Ecc140 olarak değiştirmek isterseniz, ECC özelliğini güncelleyerek bunu yapabilirsiniz:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Adım 7: farklı sürüm ve ECC'lerle barkodlar oluşturun

Diğer DataMatrix sürümleri ve ECC türleri için Adım 4'ü tekrarlayın, her barkodu benzersiz bir dosya adıyla kaydedin.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

Artık Aspose.BarCode for .NET kullanarak DataMatrix barkodları nasıl oluşturulacağını öğrendiğinize göre, bu işlevi .NET uygulamalarınıza kolayca entegre edebilirsiniz.

## Yaygın tuzaklar ve sorun giderme ipuçları
- **Incorrect version dimensions** – DataMatrix sürümleri sabit satır/sütun çiftlerine sahiptir. Uyumsuz bir çift (ör. 10 × 20) sağlamak `ArgumentException` hatası verir. API belgelerinde listelenen desteklenen kombinasyonlardan birini her zaman kullanın.  
- **Missing license** – Deneme modunda oluşturulan görüntüler bir filigran içerir. Filigranı kaldırmak için jeneratörü oluşturmadan önce `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` kodu ile geçerli bir lisans uygulayın. `License` sınıfı, ürünü etkinleştirmek için bir lisans dosyası yükler.  
- **Large image size** – Yüksek çözünürlüklü çıktı gerekiyorsa, `XDimension` özelliğini artırın; kütüphane görüntüyü okunabilirliği kaybetmeden orantılı olarak ölçeklendirir.
