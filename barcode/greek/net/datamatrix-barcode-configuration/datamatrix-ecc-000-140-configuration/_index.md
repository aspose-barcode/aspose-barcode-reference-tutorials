## Τι είναι το DataMatrix ECC 000‑140;
DataMatrix είναι ένας δισδιάστατος barcode που αποθηκεύει μεγάλους όγκους δεδομένων σε ένα συμπαγές τετράγωνο. Το επίπεδο διόρθωσης σφαλμάτων **ECC 000‑140** μπορεί να ανακτήσει έως και 140 % των κατεστραμμένων codewords, καθιστώντας το ιδανικό για σκληρά περιβάλλοντα αποθήκης όπου οι ετικέτες μπορεί να γρατσουνιστούν ή να λεκιαστούν.

## Γιατί να επιλέξετε Aspose.BarCode for .NET;
Aspose.BarCode for .NET παρέχει ένα ολοκληρωμένο, υψηλής απόδοσης API που απλοποιεί τη δημιουργία barcode σε πολλές συμβολές, προσφέροντας ενσωματωμένη διόρθωση σφαλμάτων, αυτόματο μέγεθος και εκτενή υποστήριξη πλατφόρμας, καθιστώντας το ιδανικό για επιχειρησιακές λύσεις διαχείρισης αποθεμάτων και σήμανσης.

- **Robust API:** Διαχειρίζεται 30+ συμβολές barcode και εφαρμόζει αυτόματα τους κανόνες κωδικοποίησης.  
- **Cross‑platform:** Εκτελείται σε Windows, macOS και Linux χωρίς εγγενείς εξαρτήσεις.  
- **High performance:** Δημιουργεί ένα DataMatrix 200 × 200 pixel σε λιγότερο από 50 ms σε τυπική CPU 2.5 GHz, επιτρέποντας γραμμές σήμανσης υψηλής απόδοσης.

## Πώς να δημιουργήσετε datamatrix barcode aspose σε C#
Φορτώστε τα δεδομένα, διαμορφώστε τη γεννήτρια και αποθηκεύστε την εικόνα – όλα σε τρία σύντομα βήματα. Η `BarcodeGenerator` επιλέγει αυτόματα το βέλτιστο μέγεθος μονάδας και εφαρμόζει το επίπεδο διόρθωσης ECC 140, ώστε να μην χρειάζεται να υπολογίζετε εσείς τις τιμές ελέγχου, γρήγορα και αποδοτικά.

### Βήμα 1: ορίστε τον φάκελο εξόδου
Επιλέξτε έναν φάκελο όπου θα γραφτεί το αρχείο PNG. Η διαδρομή πρέπει να υπάρχει πριν καλέσετε `Save`.

```csharp
string path = "Your Directory Path";
```

### Βήμα 2: δημιουργήστε τον barcode generator
Δημιουργήστε ένα αντικείμενο `BarcodeGenerator`, ορίστε τη συμβολή σε DataMatrix, παρέχετε το payload και επιλέξτε το υψηλότερο επίπεδο διόρθωσης σφαλμάτων.

```csharp
using (BarcodeGenerator gen = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Set the XDimension in Pixels
    gen.Parameters.Barcode.XDimension.Pixels = 4;
    
    // Set DataMatrix ECC to 140
    gen.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;

    // Save the generated barcode image
    gen.Save($"{path}DataMatrixEcc000140.png", BarCodeImageFormat.Png);
}
```

Σε αυτό το απόσπασμα:

* Επιλέξτε **DataMatrix** ως τύπο barcode.  
* Παρέχετε μια τιμή δείγματος (`"Åspóse.Barcóde©"`).  
* Ορίστε **XDimension** για να ελέγξετε το μέγεθος μονάδας (4 pixel εδώ).  
* Επιλέξτε το υψηλότερο επίπεδο διόρθωσης σφαλμάτων (**ECC 140**).  
* Αποθηκεύστε το αποτέλεσμα ως αρχείο PNG.  

## Κοινά προβλήματα και λύσεις

| **Invalid path** | Βεβαιωθείτε ότι το `path` τελειώνει με διαχωριστικό καταλόγου (`\` ή `/`) και ότι ο φάκελος υπάρχει. |
| **Unsupported characters** | Το DataMatrix υποστηρίζει UTF‑8· αποφύγετε χαρακτήρες ελέγχου και χρησιμοποιήστε τη σωστή κωδικοποίηση. |
| **License not applied** | Η κλάση `Aspose.BarCode.License` εφαρμόζει εμπορική άδεια για πλήρη λειτουργικότητα. Καλέστε την πριν δημιουργήσετε οποιοδήποτε barcode. |

## Συχνές ερωτήσεις

**Q: Μπορώ να χρησιμοποιήσω Aspose.BarCode for .NET σε διακομιστές Linux;**  
A: Ναι. Η βιβλιοθήκη είναι πλήρως cross‑platform και εκτελείται σε .NET 5+, .NET 6+ και .NET Core σε Linux χωρίς πρόσθετες εξαρτήσεις.

**Q: Πώς διαχειρίζεται η βιβλιοθήκη μεγάλες παρτίδες barcode;**  
A: Μπορείτε να επαναχρησιμοποιήσετε ένα μόνο αντικείμενο `BarcodeGenerator` σε βρόχο· κάθε κλήση στο `Save` επαναδημιουργεί την εικόνα σε περίπου 40‑60 ms, καθιστώντας το κατάλληλο για δημιουργία χιλιάδων ετικετών ανά λεπτό.

**Q: Χρειάζεται να κωδικοποιήσω τα δεδομένα χειροκίνητα για ECC 140;**  
A: Όχι. Ορίζοντας `generator.Parameters.Barcode.DataMatrix.EccMode = DataMatrixEccMode.Ecc140` εφαρμόζει αυτόματα τον σωστό αλγόριθμο διόρθωσης σφαλμάτων.

**Q: Είναι η δοκιμαστική έκδοση επαρκής για ανάπτυξη;**  
A: Η δωρεάν δοκιμή παρέχει πλήρη πρόσβαση σε όλες τις λειτουργίες, συμπεριλαμβανομένου του ECC 140, αλλά προσθέτει υδατογράφημα στις παραγόμενες εικόνες. Εφαρμόστε άδεια για παραγωγή ώστε να αφαιρεθεί το υδατογράφημα.

**Q: Μπορώ να προσαρμόσω τα χρώματα του barcode;**  
A: Απόλυτα. Χρησιμοποιήστε `generator.Parameters.Barcode.Color` και `generator.Parameters.Barcode.BackColor` για να ταιριάξετε με την εταιρική σας ταυτότητα.
