# Πώς να δημιουργήσετε γραμμωτό κώδικα PDF417 σε C# – συμπαγές παράδειγμα

Αν χρειάζεστε **δημιουργία γραμμωτού κώδικα PDF417** σε εφαρμογή C#, αυτός ο οδηγός σας δείχνει μια πλήρη, έτοιμη‑για‑εκτέλεση λύση. Θα δημιουργήσουμε έναν συμπαγή γραμμωτό κώδικα PDF417, θα ρυθμίσουμε το πλάτος του μονάδας, θα ορίσουμε τον αριθμό των στηλών και θα αποθηκεύσουμε το αποτέλεσμα ως εικόνα PNG—όλα με τη βιβλιοθήκη Aspose.BarCode .NET.

Η δημιουργία γραμμωτού κώδικα PDF417 είναι συνηθισμένη όταν θέλετε να κωδικοποιήσετε μεγάλες ποσότητες δεδομένων (π.χ. URLs, επαφές ή αναγνωριστικά αποθέματος) σε μορφή δύο διαστάσεων με αποδοτική χρήση χώρου. Στο τέλος αυτού του tutorial θα έχετε ένα λειτουργικό αντικείμενο `BarcodeGenerator` που παράγει έναν συμπαγή, υψηλής αναγνωσιμότητας γραμμωτό κώδικα, έτοιμο για εκτύπωση ή εμφάνιση.

## Προαπαιτούμενα

- .NET 6.0 ή νεότερο (ο κώδικας λειτουργεί επίσης με .NET Framework 4.8)
- Visual Studio 2022 (ή οποιοδήποτε IDE για C#)
- Πακέτο NuGet Aspose.BarCode for .NET (`Install-Package Aspose.BarCode`)
- Βασική εξοικείωση με τη σύνταξη της C#

Δεν απαιτείται πρόσθετη διαμόρφωση· το παράδειγμα εκτελείται ως εφαρμογή κονσόλας.

## Βήμα 1: Δημιουργία γεννήτριας PDF417 barcode

Το πρώτο βήμα είναι η δημιουργία ενός αντικειμένου `BarcodeGenerator` με την απαρίθμηση `EncodeTypes.Pdf417` και το κείμενο που θέλετε να κωδικοποιήσετε.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Γιατί είναι σημαντικό:** Η `EncodeTypes.Pdf417` λέει στη βιβλιοθήκη να χρησιμοποιήσει τη συμβολική PDF417, ενώ το δεύτερο όρισμα ορίζει το φορτίο δεδομένων. Μπορείτε να αντικαταστήσετε το `"Compact example"` με οποιαδήποτε συμβολοσειρά έως 1 800 χαρακτήρες.

## Βήμα 2: Ορισμός πλάτους μονάδας (διάσταση X) σε pixel

Η διάσταση X ορίζει το πλάτος μιας μοναδικής μονάδας του γραμμωτού κώδικα (το μικρότερο μαύρο ή λευκό τετράγωνο). Μικρότερη τιμή pixel δίνει πιο πυκνό κώδικα.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Γιατί είναι σημαντικό:** Μια τιμή `2` pixel δημιουργεί συμπαγή εμφάνιση χωρίς να θυσιάζει την αξιοπιστία σάρωσης στα περισσότερα σύγχρονα scanners. Ρυθμίστε την τιμή αν χρειάζεστε μεγαλύτερες μονάδες για εκτύπωση χαμηλής ανάλυσης.

## Βήμα 3: Καθορισμός αριθμού στηλών

Η PDF417 επιτρέπει τον έλεγχο του αριθμού των στηλών, κάτι που επηρεάζει την αναλογία διαστάσεων του κώδικα.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Γιατί είναι σημαντικό:** Λιγότερες στήλες κάνουν τον κώδικα πιο ψηλό, ενώ περισσότερες στήλες τον κάνουν πιο επίπεδο. Τρεις στήλες λειτουργούν καλά για μια συμπαγή διάταξη πορτραίτου.

## Βήμα 4: Ενεργοποίηση συμπαγούς λειτουργίας με περικοπή του κώδικα

Η συμπαγής λειτουργία αφαιρεί περιττές σειρές padding, καθιστώντας τον κώδικα μικρότερο ενώ διατηρεί τα κωδικοποιημένα δεδομένα.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Γιατί είναι σημαντικό:** Η περικοπή είναι ιδανική όταν ο διαθέσιμος χώρος στην οθόνη είναι περιορισμένος (π.χ. κινητές εφαρμογές ή μικρές ετικέτες). Ο κώδικας παραμένει πλήρως αναγνώσιμος επειδή ο αλγόριθμος κωδικοποίησης προσαρμόζει αυτόματα τα επίπεδα διόρθωσης σφαλμάτων.

## Βήμα 5: Αποθήκευση του κώδικα ως εικόνα PNG

Τέλος, γράψτε τον παραγόμενο κώδικα σε αρχείο. Το PNG διατηρεί την απώλεια‑απαγόρευση ποιότητας, κάτι που είναι κρίσιμο για τους scanners.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Η εκτέλεση του προγράμματος δημιουργεί το `CompactPdf417.png` στον φάκελο εργασίας του εκτελέσιμου. Η εικόνα φαίνεται ως εξής:

![Δημιουργημένος συμπαγής γραμμωτός κώδικας PDF417](CompactPdf417.png "Δημιουργημένος συμπαγής γραμμωτός κώδικας PDF417")

**Αναμενόμενο αποτέλεσμα:** Ένας PDF417 κώδικας δύο pixel πλάτους, τριών στηλών, που κωδικοποιεί το κείμενο “Compact example”. Η σάρωση του PNG με έναν τυπικό scanner θα πρέπει να επιστρέψει την αρχική συμβολοσειρά.

## Συνηθισμένες παραλλαγές και ειδικές περιπτώσεις

| Κατάσταση | Πώς να προσαρμόσετε τον κώδικα |
|-----------|-------------------------------|
| **Μεγαλύτερα δεδομένα ( > 500 χαρακτήρες )** | Αυξήστε το `Columns` σε 5‑7 για να αποφύγετε υπερβολικό ύψος του κώδικα. |
| **Εκτύπωση υψηλής ανάλυσης** | Ορίστε `XDimension.Pixels` σε 3 ή 4 για μεγαλύτερες μονάδες. |
| **Διαφορετική μορφή εικόνας** | Αντικαταστήστε το `BarCodeImageFormat.Png` με `Jpeg` ή `Bmp` ανάλογα με τις ανάγκες. |
| **Ενσωμάτωση του κώδικα σε PDF** | Χρησιμοποιήστε `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` αντί για PNG. |

**Συμβουλή:** Πάντα δοκιμάζετε τον παραγόμενο κώδικα στον τελικό scanner. Μερικοί φθηνοί scanners δυσκολεύονται με πολύ μικρές διαστάσεις X· αν αντιμετωπίσετε σφάλματα ανάγνωσης, αυξήστε την τιμή pixel κατά ένα βήμα.

## Πλήρες, εκτελέσιμο παράδειγμα

Ακολουθεί το πλήρες πρόγραμμα που μπορείτε να αντιγράψετε‑και‑επικολλήσετε σε ένα νέο project κονσόλας. Δεν απαιτούνται επιπλέον αρχεία.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Συγκεντρώστε και εκτελέστε το πρόγραμμα (`dotnet run` αν χρησιμοποιείτε το .NET CLI). Μετά την εκτέλεση, ανοίξτε το `CompactPdf417.png` για να επαληθεύσετε το οπτικό αποτέλεσμα.

Το παράδειγμα δείχνει τα βασικά βήματα: δημιουργία του `BarcodeGenerator`, ρύθμιση του `XDimension` και των `Columns`, ενεργοποίηση του `Truncate` για συμπαγή λειτουργία και, τέλος, αποθήκευση της εικόνας.
