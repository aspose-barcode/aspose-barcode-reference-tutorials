# Δημιουργία PDF417 barcode σε C# χρησιμοποιώντας το Aspose – βήμα‑βήμα οδηγός

Αν χρειάζεστε **να δημιουργήσετε PDF417 barcode** σε μια εφαρμογή .NET, αυτός ο οδηγός σας δείχνει ακριβώς πώς. Θα δείτε ένα πλήρες, έτοιμο‑για‑εκτέλεση παράδειγμα που δημιουργεί βασικά, compact, Micro, GS1‑Micro και Macro PDF417 barcodes με Aspose.BarCode for .NET.

Η δημιουργία ενός PDF417 barcode είναι κοινή απαίτηση για ετικέτες αποστολής, έγγραφα μεταφοράς και συστήματα απογραφής. Στο τέλος αυτού του tutorial θα μπορείτε να **δημιουργήσετε εικόνες PDF417 barcode**, να κατανοήσετε τις βασικές παραμέτρους και να προσαρμόσετε τον κώδικα για τα δικά σας δεδομένα.

## Προαπαιτούμενα

- .NET 6.0 SDK ή νεότερο (ο κώδικας λειτουργεί επίσης με .NET Framework 4.7+)
- Visual Studio 2022 ή οποιοδήποτε IDE C#
- Πακέτο NuGet Aspose.BarCode for .NET (`Aspose.BarCode`) εγκατεστημένο
- Βασική εξοικείωση με τη σύνταξη C#

> **Συμβουλή:** Χρησιμοποιήστε την δωρεάν άδεια αξιολόγησης από την Aspose για να αποφύγετε περιορισμούς χρόνου εκτέλεσης κατά τη δοκιμή.

## Βήμα 1: Ρύθμιση του έργου και εισαγωγή namespaces

Δημιουργήστε ένα νέο έργο console και προσθέστε το πακέτο Aspose.BarCode:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Στη συνέχεια ανοίξτε το `Program.cs` και προσθέστε τις απαιτούμενες δηλώσεις `using`:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Αυτά τα namespaces σας δίνουν πρόσβαση στην κλάση `BarcodeGenerator` και στην απαρίθμηση `EncodeTypes` που απαιτούνται για **δημιουργία barcode χρησιμοποιώντας C#**.

## Βήμα 2: Δημιουργία βασικού PDF417 barcode

Το πιο απλό PDF417 barcode χρησιμοποιεί τις προεπιλεγμένες ρυθμίσεις εκτός από τη διάσταση X (πλάτος μονάδας) και τον αριθμό των στηλών. Η προσαρμογή αυτών των τιμών ελέγχει το συνολικό μέγεθος και την αναγνωσιμότητα.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Γιατί λειτουργεί:**  
- `EncodeTypes.Pdf417` λέει στην Aspose να χρησιμοποιήσει τη συμβολική PDF417.  
- `XDimension.Pixels` ορίζει το μικρότερο πλάτος μπάρας· μια τιμή 2 διατηρεί την εικόνα μικρή χωρίς να θυσιάζει την δυνατότητα σάρωσης.  
- `Pdf417.Columns` καθορίζει πόσες στήλες δεδομένων περιέχει το barcode· τρεις στήλες δίνουν ισορροπημένη αναλογία.

## Βήμα 3: Δημιουργία compact (truncated) PDF417 barcode

Η λειτουργία compact αφαιρεί το πρότυπο διακοπής και μειώνει το συνολικό ύψος, κάτι που είναι χρήσιμο για ετικέτες με περιορισμένο χώρο.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Γιατί λειτουργεί:**  
Η ρύθμιση `Pdf417.Truncate = true` ενεργοποιεί τη λειτουργία truncated, η οποία παραλείπει το δεξιό πρότυπο διακοπής και μειώνει το ύψος του barcode διατηρώντας την ακεραιότητα των δεδομένων.

## Βήμα 4: Δημιουργία Micro PDF417 barcode

Το Micro PDF417 είναι μια μικρότερη παραλλαγή που υποστηρίζει 1‑4 στήλες. Είναι ιδανικό για εφαρμογές όπου ο χώρος είναι περιορισμένος, όπως μικρές ετικέτες προϊόντων.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Γιατί λειτουργεί:**  
- `EncodeTypes.MicroPdf417` επιλέγει τη μικρο‑έκδοση της συμβολικής.  
- Ο αριθμός στηλών μπορεί να είναι μεταξύ 1 και 4· η επιλογή 4 δίνει την πιο πυκνή διάταξη ενώ παραμένει αναγνώσιμη.

## Βήμα 5: Δημιουργία GS1‑συμβατού Micro PDF417 barcode

Τα πρόθεμα GS1 προσθέτουν τυποποιημένα αναγνωριστικά (π.χ., GTIN, αριθμός παρτίδας) στα δεδομένα του barcode. Η Aspose σας επιτρέπει να τα ενσωματώσετε απευθείας.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Γιατί λειτουργεί:**  
Οι Αναγνωριστές Εφαρμογών GS1 (AIs) τοποθετούνται σε παρενθέσεις. Η Aspose τους αναλύει και προσθέτει τη σωστή μορφοποίηση που απαιτείται από τους σαρωτές GS1.

## Βήμα 6: Δημιουργία Macro PDF417 barcode με πλήρη μεταδεδομένα

Το Macro PDF417 σας επιτρέπει να χωρίσετε ένα μεγάλο payload δεδομένων σε πολλαπλά συνδεδεμένα barcodes. Μπορείτε να ενσωματώσετε μεταδεδομένα επιπέδου αρχείου όπως ID αρχείου, αριθμός τμημάτων, χρονικές σφραγίδες και προσαρμοσμένες συμβολοσειρές.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Γιατί λειτουργεί:**  
Κάθε ιδιότητα `MacroPdf417*` αντιστοιχεί σε συγκεκριμένο τμήμα της προδιαγραφής macro barcode. Η ρύθμιση αυτών των τιμών διασφαλίζει ότι ένας σαρωτής μπορεί να ανασυνθέσει το αρχικό αρχείο από πολλαπλές εικόνες barcode.
