# Πώς να δημιουργήσετε γραμμωτό κώδικα PDF417 σε C# – πλήρης οδηγός βήμα‑βήμα

Ποτέ χρειάστηκε να **δημιουργήσετε γραμμωτό κώδικα PDF417** αλλά δεν ήσασταν σίγουροι ποιες ρυθμίσεις να προσαρμόσετε; Δεν είστε οι μόνοι—πολλοί προγραμματιστές αντιμετωπίζουν το ίδιο πρόβλημα όταν αρχίζουν να πειραματίζονται με γραμμωτούς κώδικες 2‑Δ. Τα καλά νέα; Με μερικές γραμμές C# μπορείτε να μετατρέψετε οποιαδήποτε συμβολοσειρά σε μια σαρωτική εικόνα PDF417, να ελέγξετε το ακριβές μέγεθός της και ακόμη να ορίσετε μια προσαρμοσμένη διάταξη στήλης‑γραμμής.

Σε αυτό το μάθημα θα περάσουμε από το **πώς να δημιουργήσετε γραμμωτό κώδικα από κείμενο**, να προσαρμόσουμε το μέγεθος του κώδικα και να ορίσουμε προσαρμοσμένες διαστάσεις — όλα χρησιμοποιώντας τη δημοφιλή βιβλιοθήκη Aspose.BarCode. Στο τέλος θα έχετε ένα έτοιμο δείγμα που μπορείτε να ενσωματώσετε σε οποιοδήποτε έργο .NET.

## Πώς να δημιουργήσετε γραμμωτό κώδικα PDF417 σε C#;

Φορτώστε το κείμενό σας, διαμορφώστε τον γεννήτορα και αποθηκεύστε την εικόνα σε τρία απλά βήματα. Αυτή η άμεση απάντηση σας δίνει τη πλήρη ροή εργασίας πριν από τυχόν επιπλέον εξηγήσεις. Πρώτα, δημιουργήστε ένα αντικείμενο `BarcodeGenerator` με τη συμβολική PDF417 και τα δεδομένα σας. Στη συνέχεια, προσαρμόστε τις οπτικές παραμέτρους όπως η διάσταση X, οι στήλες και οι σειρές. Τέλος, καλέστε `Save` για να γράψετε την εικόνα στο δίσκο στη μορφή που επιθυμείτε.

### Βήμα 1 – δημιουργία γραμμωτού κώδικα PDF417 με δεδομένα κειμένου

Η κλάση `BarcodeGenerator` δημιουργεί εικόνες γραμμωτών κωδίκων βάσει της καθορισμένης συμβολικής και των δεδομένων.  
Το πρώτο που χρειαζόμαστε είναι μια παρουσία του `BarcodeGenerator` που γνωρίζει ότι δουλεύουμε με συμβολική PDF417 και το ακριβές κείμενο που θέλουμε να κωδικοποιήσουμε.

```csharp
using Aspose.BarCode.Generation;
using Aspose.BarCode;

// Step 1: Initialize the barcode generator with PDF417 symbology and the data to encode
BarcodeGenerator barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Åspóse.Barcóde©");
```

> **Γιατί αυτό είναι σημαντικό:**  
> `EncodeTypes.Pdf417` λέει στη βιβλιοθήκη να χρησιμοποιήσει τη μορφή PDF417 2‑Δ, ενώ το δεύτερο όρισμα είναι το φορτίο **δημιουργίας γραμμωτού κώδικα από κείμενο**. Οτιδήποτε περάσετε εδώ γίνεται τα δεδομένα που αποθηκεύονται στο πλέγμα του κώδικα.

### Βήμα 2 – προσαρμογή μεγέθους γραμμωτού κώδικα (διάσταση X)

Η ιδιότητα `XDimension` ορίζει το πλάτος σε εικονοστοιχεία ενός μεμονωμένου μονάδας (το μικρότερο μαύρο ή λευκό τετράγωνο) στην εικόνα του γραμμωτού κώδικα.

`XDimension` ελέγχει το πλάτος μιας μονάδας (το μικρότερο μαύρο ή λευκό τετράγωνο) σε εικονοστοιχεία.

```csharp
// Step 2: Set the module (X) dimension in pixels to control barcode size
barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2; // 2 px per module
```

> **Συμβουλή:**  
> Μια τιμή 2 px λειτουργεί καλά για τις περισσότερες περιπτώσεις προβολής σε οθόνη. Για εκτυπώσεις υψηλής ανάλυσης μπορείτε να την αυξήσετε σε 3 ή 4 px. Θυμηθείτε ότι μεγαλύτερες διαστάσεις X αυξάνουν το συνολικό μέγεθος της εικόνας.

### Βήμα 3 – ορισμός προσαρμοσμένων διαστάσεων γραμμωτού κώδικα (στήλες & σειρές)

Το PDF417 σας επιτρέπει να καθορίσετε πόσες στήλες και σειρές θα καταλάβει ο κώδικας. Εδώ έρχονται σε παιχνίδι οι **προσαρμοσμένες διαστάσεις γραμμωτού κώδικα**.

Οι παράμετροι `Pdf417` σας επιτρέπουν να ορίσετε το ακριβές πλέγμα στήλης‑γραμμής για τον κώδικα.

```csharp
// Step 3: Define the layout of the PDF417 barcode: number of columns and rows
barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 4; // 4 columns
barcodeGenerator.Parameters.Barcode.Pdf417.Rows    = 9; // 9 rows
```

> **Τι συμβαίνει στο παρασκήνιο;**  
> Η βιβλιοθήκη αναδιανέμει τα κωδικοποιημένα δεδομένα στο καθορισμένο πλέγμα. Λιγότερες στήλες σημαίνουν πιο ψηλούς κώδικες· περισσότερες σειρές τους κάνουν πιο σύντομους. Παίξτε με τις τιμές μέχρι να βρείτε την οπτική ισορροπία που ταιριάζει στην εφαρμογή σας.

### Βήμα 4 – αποθήκευση εικόνας γραμμωτού κώδικα

Τώρα που έχουμε ρυθμίσει τα πάντα, ζητάμε απλώς από τον γεννήτορα να γράψει ένα αρχείο PNG. Το PNG είναι χωρίς απώλειες, έτσι η ευκρίνεια των μονάδων παραμένει αμετάβλητη.  
Η μέθοδος `Save` γράφει τον παραγόμενο γραμμωτό κώδικα σε αρχείο στη μορφή εικόνας που επιλέξατε.

```csharp
// Step 4: Save the generated barcode as a PNG image
barcodeGenerator.Save(@"C:\Barcodes\CustomLayout.png", BarCodeImageFormat.Png);
```

Όταν εκτελέσετε το πρόγραμμα, θα δείτε ένα αρχείο στο `C:\Barcodes\CustomLayout.png` που μοιάζει με το στιγμιότυπο παραπάνω. Η σάρωση του με οποιονδήποτε αναγνώστη PDF417 θα επιστρέψει την αρχική συμβολοσειρά `Åspóse.Barcóde©`.

## Πλήρες λειτουργικό παράδειγμα

Παρακάτω είναι το πλήρες πρόγραμμα που μπορείτε να αντιγράψετε‑και‑επικολλήσετε σε μια εφαρμογή κονσόλας. Περιλαμβάνει όλες τις οδηγίες `using` και τη διαχείριση σφαλμάτων που θα περιμένατε σε κώδικα παραγωγής.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Initialize generator with PDF417 symbology and text
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // 2️⃣ Adjust X‑dimension to control overall size
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 3️⃣ Apply custom layout: 4 columns × 9 rows
            generator.Parameters.Barcode.Pdf417.Columns = 4;
            generator.Parameters.Barcode.Pdf417.Rows    = 9;

            // 4️⃣ Save as PNG
            string outPath = @"C:\Barcodes\CustomLayout.png";
            generator.Save(outPath, BarCodeImageFormat.Png);

            Console.WriteLine($"✅ Barcode generated successfully → {outPath}");
        }
        catch (Exception ex)
        {
            Console.WriteLine($"❌ Error: {ex.Message}");
        }
    }
}
```

### Αναμενόμενο αποτέλεσμα

Η εκτέλεση του κώδικα εκτυπώνει:

```
✅ Barcode generated successfully → C:\Barcodes\CustomLayout.png
```

…και δημιουργεί ένα PNG που μπορεί να ανοιχθεί σε οποιονδήποτε προβολέα εικόνων. Αν το σαρώσετε με μια εφαρμογή κινητού (π.χ., “Barcode Scanner” σε iOS/Android), το αποκωδικοποιημένο κείμενο θα είναι ακριβώς **Åspóse.Barcóde©**.

## Συχνές ερωτήσεις & ειδικές περιπτώσεις

| Ερώτηση | Απάντηση |
|----------|--------|
| **Μπορώ να χρησιμοποιήσω διαφορετική μορφή εικόνας;** | Ναι—`BarCodeImageFormat.Jpeg`, `Bmp`, `Gif` ή `Svg` υποστηρίζονται όλα. Απλώς αλλάξτε το δεύτερο όρισμα της `Save`. |
| **Τι γίνεται αν το κείμενό μου περιέχει χαρακτήρες Unicode;** | Το Aspose.BarCode υποστηρίζει πλήρως UTF‑8, έτσι το παράδειγμα με `Å` και `©` λειτουργεί αμέσως. |
| **Πώς αλλάζω το επίπεδο διόρθωσης σφαλμάτων;** | Χρησιμοποιήστε `generator.Parameters.Barcode.Pdf417.ErrorCorrectionLevel = Pdf417ErrorCorrectionLevel.Level5;` (επίπεδα 0‑8). Τα υψηλότερα επίπεδα αυξάνουν την πλεοναστικότητα αλλά και το μέγεθος. |
| **Χρειάζομαι διαφανές φόντο—μπορώ να το κάνω αυτό;** | Ορίστε `generator.Parameters.Barcode.Image.TransparentBackground = true;` πριν την αποθήκευση. |
| **Υπάρχει τρόπος να ενσωματώσω τον γραμμωτό κώδικα απευθείας σε PDF;** | Απόλυτα. Αντικαταστήστε την κλήση `Save` με `generator.Save("output.pdf", BarCodeImageFormat.Pdf);` και θα έχετε ένα PDF μιας σελίδας που περιέχει τον κώδικα. |

**Ε: Πόσο μεγάλη μπορεί να είναι η παραγόμενη εικόνα;**  
Α: Το API μπορεί να δημιουργήσει εικόνες έως **10 000 × 10 000 pixel**· η κατανάλωση μνήμης εξαρτάται από τη διάσταση X και τις ρυθμίσεις στήλης/γραμμής.

**Ε: Απαιτείται άδεια για χρήση σε παραγωγή;**
