## Πώς να δημιουργήσετε αντικείμενο γραφικών barcode σε Java
Φορτώστε το barcode απευθείας σε μια επιφάνεια γραφικών σε δύο απλά βήματα. **First, instantiate a `BarcodeGenerator` with the desired symbology and data. Then, call `save` to a `ByteArrayOutputStream` and draw the resulting image with `Graphics.drawImage`.** Αυτή η προσέγγιση εξαλείφει την ανάγκη για προσωρινά αρχεία και διατηρεί το pipeline απόδοσης πλήρως στη μνήμη.

Η κλάση `BarcodeGenerator` δημιουργεί εικόνες barcode βάσει της καθορισμένης συμβολισμού και δεδομένων.  
Η μέθοδος `Graphics.drawImage` σχεδιάζει μια εικόνα στο γραφικό περιβάλλον.

### Βήμα 1: ρύθμιση του παραθύρου και εκκίνηση του καμβά
Η κλάση `RenderBarcodeToGraphicsObject` ρυθμίζει ένα παράθυρο και έναν καμβά για την εμφάνιση του barcode.

### Βήμα 2: υλοποίηση απόδοσης barcode στον καμβά
Η κλάση `MyBarCode` επεκτείνει το `Canvas` και παρακάμπτει τη μέθοδο `paint` για να αποδώσει την εικόνα του barcode.

```java
class MyBarCode extends java.awt.Canvas {
    public void paint(Graphics g) {
        // The path to the resource directory.
        String dataDir = "Your Document Directory";
        String fileName = dataDir + "barcode.png";

        BarcodeGenerator bb = new BarcodeGenerator(com.aspose.barcode.EncodeTypes.CODE_128, "12345678");
        try {
            bb.save(fileName);
        } catch (IOException e1) {
            e1.printStackTrace();
        }

        // Load and Draw the image on applet
        MediaTracker tr = new MediaTracker(this);

        File sourceimage = new File(fileName);
        Image image;
        try {
            image = ImageIO.read(sourceimage);
            tr.addImage(image, 0);
            g.drawImage(image, 0, 0, this);
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    public Dimension getPreferredSize() {
        return new Dimension(300, 300);
    }
}
```

## Δημιουργία εικόνας barcode java – τι συμβαίνει στο παρασκήνιο;
Όταν καλείτε `bb.save(fileName)`, η βιβλιοθήκη δημιουργεί μια bitmap αναπαράσταση του barcode και την γράφει στη συγκεκριμένη διαδρομή. Εσωτερικά, **`BarcodeGenerator`** (η κλάση που δημιουργεί τα δεδομένα barcode) **κωδικοποιεί τη συμβολοσειρά εισόδου σύμφωνα με την επιλεγμένη συμβολισμού, υπολογίζει το μοτίβο μονάδων και αποδίδει το μοτίβο σε ένα buffer εικόνας**. Η εικόνα στη συνέχεια παραδίδεται στο `ImageIO.read`, το οποίο τη φορτώνει σε ένα `BufferedImage` που το `Graphics.drawImage` μπορεί να εμφανίσει στον καμβά.

| Το Barcode δεν είναι ορατό στον καμβά | Καλέστε `repaint()` μετά την αποθήκευση της εικόνας ή ελέγξτε αν οι διαστάσεις της εικόνας ταιριάζουν με το μέγεθος του καμβά. |
