# Πώς να δημιουργήσετε barcode PNG με Python – οδηγός βήμα‑βήμα

Αν χρειάζεστε **να δημιουργήσετε αρχεία barcode PNG** από αυθαίρετες συμβολοσειρές, αυτό το tutorial σας παρέχει μια έτοιμη λύση. Θα δείτε ακριβώς πώς να δημιουργήσετε ένα barcode Code 128, να μετατρέψετε κείμενο σε εικόνα barcode και να αποθηκεύσετε το αποτέλεσμα ως αρχείο PNG—όλα με λίγες γραμμές Python.

Ο οδηγός καλύπτει όλα όσα χρειάζεστε, από την εγκατάσταση της απαιτούμενης βιβλιοθήκης μέχρι την προσαρμογή της εξόδου για διαφορετικές περιπτώσεις χρήσης. Στο τέλος, θα μπορείτε να ενσωματώσετε τη δημιουργία barcode σε οποιοδήποτε έργο Python χωρίς να ψάχνετε επιπλέον τεκμηρίωση.

## Τι θα μάθετε

* Εγκατάσταση του πακέτου **barcode generator python** που υποστηρίζει Code 128.
* Χρήση του `BarCodeGenerator` για **δημιουργία barcode code 128** από μια συμβολοσειρά κειμένου.
* Αποθήκευση του αποτελέσματος ως υψηλής ποιότητας PNG με τη μέθοδο `save`.
* Προσαρμογή μεγέθους εικόνας, χρωμάτων προσκηνίου/παρασκηνίου και διαχείριση κοινών σφαλμάτων.
* Επαλήθευση ότι το PNG δημιουργήθηκε σωστά.

### Προαπαιτούμενα

| Απαίτηση | Αιτία |
|-------------|--------|
| Python 3.8+ | Σύγχρονη σύνταξη και υποδείξεις τύπου |
| Πρόσβαση στο διαδίκτυο (για `pip install`) | Για λήψη της βιβλιοθήκης |
| Δικαίωμα εγγραφής σε φάκελο | Για αποθήκευση του παραγόμενου PNG |

Δεν απαιτούνται εξωτερικές υπηρεσίες· όλα εκτελούνται τοπικά.

## Βήμα 1: Εγκατάσταση της βιβλιοθήκης barcode

Ο πιο απλός τρόπος για **μετατροπή κειμένου σε barcode** σε Python είναι η χρήση του πακέτου **Aspose.BarCode for Python via .NET**, το οποίο υποστηρίζει Code 128 αμέσως.

```bash
pip install aspose-barcode
```

> **Συμβουλή:** Αν εργάζεστε σε εικονικό περιβάλλον, ενεργοποιήστε το πριν τρέξετε την εντολή ώστε να διατηρήσετε τις εξαρτήσεις απομονωμένες.

## Βήμα 2: Εισαγωγή των κλάσεων που χρειάζεστε

Μετά την εγκατάσταση, εισάγετε τις βασικές κλάσεις. Οι δηλώσεις εισαγωγής είναι σύντομες, καθιστώντας τον κώδικα εύκολο στην ανάγνωση.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` δημιουργεί την εικόνα barcode.
* `EncodeTypes` παρέχει μια απαρίθμηση των υποστηριζόμενων συμβολοσειρών, συμπεριλαμβανομένου του `CODE_128`.

## Βήμα 3: Ορισμός του κειμένου που θέλετε να κωδικοποιήσετε

Επιλέξτε οποιαδήποτε αλφαριθμητική συμβολοσειρά. Το Code 128 μπορεί να αναπαραστήσει ολόκληρο το σύνολο ASCII, οπότε δεν περιορίζεστε μόνο σε αριθμούς.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Αν η είσοδος περιέχει μη υποστηριζόμενους χαρακτήρες, ο δημιουργός θα ρίξει `ValueError`. Τυλίξτε την ανάθεση σε μπλοκ `try` αν περιμένετε δεδομένα από χρήστη.

## Βήμα 4: Δημιουργία του barcode generator για Code 128

Δημιουργήστε ένα αντικείμενο `BarCodeGenerator` με την επιθυμητή συμβολοσειρά και το κείμενο που ορίσατε. Αυτό αποτελεί τον πυρήνα του **πώς να δημιουργήσετε barcode** εικόνες σε Python.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Γιατί Code 128; Προσφέρει υψηλή πυκνότητα και μπορεί να κωδικοποιήσει ολόκληρο το εύρος ASCII, καθιστώντας το ιδανικό για συστήματα αποθεμάτων, ετικέτες αποστολής και εισιτήρια.

## Βήμα 5: (Προαιρετικό) Προσαρμογή εμφάνισης

Μπορείτε να ρυθμίσετε λεπτομερώς το barcode πριν το αποθηκεύσετε. Οι παρακάτω επιλογές είναι συνηθισμένες:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Αυτές οι ρυθμίσεις επηρεάζουν την τελική **δημιουργία barcode png** έξοδο χωρίς να αλλάζουν τα κωδικοποιημένα δεδομένα.

## Βήμα 6: Αποθήκευση του barcode ως αρχείο PNG

Τέλος, γράψτε την εικόνα στο δίσκο. Η μέθοδος `save` ανιχνεύει αυτόματα την επέκταση του αρχείου, οπότε περνώντας `.png` δημιουργείται εικόνα PNG.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Αν ο προορισμός δεν υπάρχει, η Python ρίχνει `FileNotFoundError`. Δημιουργήστε τον φάκελο εκ των προτέρων ή χρησιμοποιήστε `os.makedirs` με `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

Μετά την εκτέλεση του script, θα βρείτε το `extended_barcode.png` στον φάκελο `output`. Ανοίγοντας το αρχείο θα δείτε ένα καθαρό barcode Code 128 που κωδικοποιεί το `1234567890`.

## Βήμα 7: Επαλήθευση του barcode (γρήγορος έλεγχος)

Μπορείτε να διαβάσετε το PNG ξανά με την ίδια βιβλιοθήκη για να επιβεβαιώσετε ότι η κωδικοποιημένη τιμή ταιριάζει με το αρχικό κείμενο.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Η εκτέλεση αυτού του μπλοκ εκτυπώνει:

```
Verification succeeded: 1234567890
```

Αν η επαλήθευση αποτύχει, ελέγξτε ξανά το `barcode_text` και τυχόν προσαρμοσμένες παραμέτρους που ορίσατε.

## Κοινές παραλλαγές και ειδικές περιπτώσεις

| Κατάσταση | Προσαρμογή |

| **Αποθήκευση ως JPEG αντί για PNG** | Αλλάξτε την επέκταση αρχείου σε `.jpg`; η βιβλιοθήκη διαχειρίζεται αυτόματα τη μορφή. |
| **Εκτέλεση σε server χωρίς GUI** | Η βιβλιοθήκη δεν απαιτεί GUI, καθιστώντας την ασφαλή για CI pipelines. |

## Πλήρες script για γρήγορη αντιγραφή‑επικόλληση

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Αποθηκεύστε το script ως `generate_barcode.py` και τρέξτε:

```bash
python generate_barcode.py
```

Θα δείτε τα μηνύματα επιβεβαίωσης και ένα νέο αρχείο PNG στον φάκελο `output`.
