# Δημιουργία barcode PNG σε Python – Πλήρης Οδηγός

Κάποτε χρειάστηκε να **δημιουργήσετε barcode PNG** αλλά δεν ήσασταν σίγουροι ποια βιβλιοθήκη ή ρυθμίσεις να χρησιμοποιήσετε; Δεν είστε μόνοι. Σε πολλά συστήματα αποθεμάτων ή ταμείων, το πρώτο βήμα είναι η μετατροπή των ακατέργαστων δεδομένων σε μια καθαρή εικόνα PNG που αγαπούν οι σαρωτές.  

Σε αυτόν τον οδηγό θα περάσουμε από **πώς να δημιουργήσουμε databar**, πώς να **ρυθμίσουμε το ύψος του barcode**, και ακόμη το κόλπο για **αλλαγή παραμέτρων barcode** εν κινήσει—όλα ενώ χρησιμοποιούμε **barcode with sample data** που μπορείτε να αντιγράψετε‑επικολλήσετε κατευθείαν στο έργο σας.  

## Τι Θα Μάθετε

- Ρύθμιση της βιβλιοθήκης Aspose.BarCode (ή παρόμοιας) σε Python.  
- **Δημιουργία barcode PNG** αρχείων με διαφορετικά ύψη σε λίγες μόνο γραμμές κώδικα.  
- **Πώς να αλλάξετε barcode** ιδιότητες όπως το μέγεθος μονάδας και το ύψος μπάρας.  
- Χρήση μιας ρεαλιστικής τιμής GTIN‑14 ως **barcode with sample data**.  
- Συμβουλές για αντιμετώπιση κοινών προβλημάτων όπως θολές εικόνες ή λανθασμένη κωδικοποίηση.

Δεν απαιτείται προηγούμενη εμπειρία στη δημιουργία barcode—απλώς ένας βασικός διερμηνέας Python και η δυνατότητα εγκατάστασης ενός πακέτου pip.

## Προαπαιτούμενα

- Python 3.8+ εγκατεστημένο στο σύστημά σας.  
- Πρόσβαση στο διαδίκτυο για την εγκατάσταση του πακέτου `aspose-barcode` (ή οποιασδήποτε συμβατής βιβλιοθήκης).  
- Ένας φάκελος με δικαιώματα εγγραφής όπου θα αποθηκευτούν τα αρχεία PNG (αντικαταστήστε το `YOUR_DIRECTORY` στο script).  

Αν έχετε ήδη όλα αυτά, τέλεια—ας ξεκινήσουμε.

## Δημιουργία barcode PNG – Ρύθμιση του Γεννήτριας

Πρώτα απ' όλα: χρειαζόμαστε ένα αντικείμενο γεννήτριας που να γνωρίζει ότι δουλεύουμε με ένα **DataBar Omnidirectional** barcode. Ο κώδικας παρακάτω εισάγει τις απαραίτητες κλάσεις, δημιουργεί τη γεννήτρια με ένα **barcode with sample data**, και ορίζει ένα μέτριο μέγεθος μονάδας.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Γιατί είναι σημαντικό:** Το `EncodeTypes.DATABAR_OMNIDIRECTIONAL` λέει στη μηχανή να παραγάγει ένα **DataBar** που μπορεί να διαβαστεί από οποιαδήποτε κατεύθυνση, ιδανικό για ράφια λιανικής. Η ρύθμιση του `x_dimension` κρατά τις μπαρές οξείς, ενώ το `bar_height` ελέγχει το οπτικό μέγεθος του κώδικα.

## Πώς να Δημιουργήσετε Databar με Δεδομένα Δείγματος

Τώρα που η γεννήτρια είναι έτοιμη, θα **δημιουργήσουμε barcode PNG** αρχεία. Η πρώτη αποθήκευση χρησιμοποιεί ύψος 30 pixel, που συχνά αρκεί για προεπισκοπήσεις στην οθόνη.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Η εκτέλεση του script μέχρι αυτό το σημείο θα παραγάγει ένα αρχείο PNG που μοιάζει με ένα συμπαγές, υψηλής αντίθεσης barcode. Ανοίξτε το σε οποιονδήποτε προβολέα εικόνων για να επαληθεύσετε ότι οι μπαρές είναι καθαρές και τα δεδομένα GTIN‑14 είναι κωδικοποιημένα.

## Ρύθμιση Ύψους Barcode (Πώς να Αλλάξετε Barcode)

Μερικές φορές χρειάζεται ένα πιο ψηλό barcode για μεγαλύτερες ετικέτες ή εκτύπωση υψηλότερης ανάλυσης. Εδώ έρχεται η **ρύθμιση ύψους barcode**. Η αλλαγή του ύψους είναι τόσο απλή όσο η ενημέρωση της ιδιότητας `BarHeight` και η αποθήκευση ξανά.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Πώς λειτουργεί:** Η γεννήτρια επαναχρησιμοποιεί τα ίδια δεδομένα και το ίδιο μέγεθος μονάδας· μόνο η κάθετη διάσταση αλλάζει. Αυτό αποφεύγει την επαναδημιουργία ολόκληρου του αντικειμένου και δείχνει **πώς να αλλάξετε barcode** ρυθμίσεις δυναμικά.

## Πλήρες Script – Ολοκληρωμένη Λύση

Παρακάτω είναι το πλήρες, εκτελέσιμο script που συνδυάζει όλα τα βήματα. Αντιγράψτε, επικολλήστε και τρέξτε—θα λειτουργήσει αμέσως μετά την εγκατάσταση του πακέτου.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Αναμενόμενο Αποτέλεσμα

Η εκτέλεση του script θα δημιουργήσει δύο αρχεία:

- `DatabarOmni30.png` – Barcode DataBar Omnidirectional ύψους 30 px.  
- `DatabarOmni60.png` – Έκδοση 60 px του ίδιου barcode.

Και οι δύο εικόνες είναι σε μορφή PNG, χωρίς απώλειες, και έτοιμες για ενσωμάτωση σε PDF, HTML σελίδες ή άμεση εκτύπωση σε ετικέτες.

## Συνηθισμένα Προβλήματα & Επαγγελματικές Συμβουλές

- **Pixel vs. DPI:** Τα αρχεία PNG βασίζονται σε pixel. Αν χρειάζεστε συγκεκριμένο μέγεθος εκτύπωσης, υπολογίστε το `BarHeight` βάσει DPI (π.χ., 300 dpi → 30 px ≈ 0.1 in).  
- **Λανθασμένη κωδικοποίηση:** Βεβαιωθείτε ότι η συμβολοσειρά δεδομένων ακολουθεί τη μορφή GS1 Application Identifier (`(01)` για GTIN‑14). Η έλλειψη παρενθέσεων μπορεί να κάνει τη βιβλιοθήκη να επιστρέψει ένα απλό αριθμητικό barcode.  
- **Διαδρομές αρχείων:** Χρησιμοποιήστε raw strings (`r"..."`) ή διπλές ανάστροφες κάθετες (`\\`) στα Windows για να αποφύγετε προβλήματα με χαρακτήρες διαφυγής.  
- **Απόδοση:** Αν δημιουργείτε χιλιάδες barcodes, δημιουργήστε τη γεννήτρια μία φορά και τροποποιήστε μόνο το `BarHeight` ή τη συμβολοσειρά δεδομένων μεταξύ των αποθηκεύσεων. Αυτό μειώνει την κατανάλωση μνήμης.  

## Επόμενα Βήματα

- Εξαγωγή σε άλλες μορφές όπως SVG ή PDF για κλιμακούμενη εκτύπωση.
