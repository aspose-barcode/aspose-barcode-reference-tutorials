# Πώς να δημιουργήσετε PNG κωδικού Planet με Python

Αν χρειάζεστε **να δημιουργήσετε PNG κωδικού Planet**, αυτό το tutorial σας καθοδηγεί βήμα‑βήμα στη διαδικασία χρησιμοποιώντας Python. Θα μάθετε επίσης **πώς να δημιουργήσετε κωδικό Planet** βήμα‑βήμα, να ρυθμίσετε την εμφάνισή του και να αποθηκεύσετε το αποτέλεσμα ως εικόνα PNG υψηλής ποιότητας.

Η δημιουργία κωδικού Planet είναι συνηθισμένη στην αυτοματοποίηση ταχυδρομικών υπηρεσιών, στην παρακολούθηση αποθεμάτων και στα συστήματα logistics. Στο τέλος αυτού του οδηγού θα έχετε ένα αυτόνομο script που παράγει ένα έτοιμο PNG αρχείο, και θα κατανοήσετε πώς να προσαρμόσετε τον κώδικα για διαφορετικά μεγέθη ή μορφές εικόνας.

## Προαπαιτήσεις

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

* Python 3.8 ή νεότερη έκδοση εγκατεστημένη.
* Πρόσβαση στο πακέτο `aspose-barcode` (ή σε οποιαδήποτε συμβατή βιβλιοθήκη που παρέχει τις κλάσεις `BarcodeGenerator`, `EncodeTypes` και `BarCodeImageFormat`).
* Δικαιώματα εγγραφής στον φάκελο όπου θέλετε να αποθηκεύσετε το αρχείο PNG.

Μπορείτε να εγκαταστήσετε τη απαιτούμενη βιβλιοθήκη με pip:

```bash
pip install aspose-barcode
```

> **Pro tip:** Χρησιμοποιήστε ένα εικονικό περιβάλλον (virtual environment) για να διατηρήσετε τις εξαρτήσεις απομονωμένες από άλλα έργα.

## Δημιουργία PNG κωδικού Planet – πλήρης walkthrough κώδικα

Το παρακάτω script δείχνει κάθε βήμα που απαιτείται για τη δημιουργία PNG κωδικού Planet με κενά (μη γεμισμένα) μπαρ. Αντιγράψτε τον κώδικα σε ένα αρχείο με όνομα `planet_barcode.py` και τρέξτε το με `python planet_barcode.py`.

```python
# planet_barcode.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Initialize a Planet barcode generator with the data to encode
# The data "123456" is a typical numeric payload for postal services.
generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

# Step 2: Set the width of each bar (X dimension) to 4 pixels.
# Adjusting the X dimension changes the overall size and readability.
generator.parameters.barcode.x_dimension.pixels = 4

# Step 3: Configure the barcode to use empty (unfilled) bars.
# When `filled_bars` is False, the dark bars become transparent,
# which is useful for overlaying the barcode on colored backgrounds.
generator.parameters.barcode.filled_bars = False

# Step 4: Save the generated barcode as a PNG image.
# The output path can be absolute or relative; ensure the folder exists.
output_path = "output/PostalPlanetEmptyBars.png"
generator.save(output_path, BarCodeImageFormat.PNG)

print(f"Planet barcode PNG saved to: {output_path}")
```

### Τι κάνει κάθε γραμμή

| Γραμμή | Εξήγηση |
|------|-------------|
| `from aspose.barcode import ...` | Εισάγει τις κλάσεις που χρειάζονται για τη δημιουργία και ρύθμιση του κωδικού. |
| `BarcodeGenerator(EncodeTypes.Planet, "123456")` | Δημιουργεί έναν γεννήτρια για τη συμβολική **Planet** χρησιμοποιώντας τη αριθμητική συμβολοσειρά `"123456"`. |
| `x_dimension.pixels = 4` | Ορίζει το πλάτος της μπάρας σε 4 px· μεγαλύτερες τιμές δημιουργούν μεγαλύτερο κωδικό, ενώ μικρότερες μειώνουν το μέγεθος του αρχείου. |
| `filled_bars = False` | Αλλάζει τον κωδικό ώστε να χρησιμοποιεί **κενές μπαρ**, κάνοντας τα σκοτεινά τμήματα διαφανή. |
| `save(..., BarCodeImageFormat.PNG)` | Αποθηκεύει τον κωδικό σε αρχείο PNG, διατηρώντας την απώλεια‑ποιότητας ποιότητα. |
| `print(...)` | Επιβεβαιώνει την επιτυχή δημιουργία στην κονσόλα. |

## Πώς να δημιουργήσετε κωδικό Planet με προσαρμοσμένες ρυθμίσεις

Αν και το βασικό script καλύπτει τις περισσότερες περιπτώσεις, ίσως χρειαστεί να προσαρμόσετε τον κωδικό για συγκεκριμένες απαιτήσεις:

1. **Διαφορετικά μήκη δεδομένων** – Οι κωδικοί Planet υποστηρίζουν έως 12 αριθμητικούς χαρακτήρες. Αλλάξτε το `"123456"` σε οποιαδήποτε έγκυρη αριθμητική συμβολοσειρά εντός αυτού του εύρους.
2. **Εναλλακτικές μορφές εικόνας** – Αντικαταστήστε το `BarCodeImageFormat.PNG` με `BarCodeImageFormat.JPEG` ή `BarCodeImageFormat.BMP` για να ταιριάζει σε downstream pipelines.
3. **Αλλαγή της διάστασης X** – Μεγαλύτερες τιμές (π.χ., `8`) δημιουργούν κωδικό υψηλότερης ανάλυσης, χρήσιμο για εκτύπωση σε μεγάλα ετικέτες.
4. **Χρώματα φόντου** – Αν θέλετε χρωματιστό φόντο, ορίστε `generator.parameters.barcode.back_color` πριν την αποθήκευση.

Παράδειγμα με προσαρμοσμένο χρώμα φόντου:

```python
from aspose.barcode import Color

generator.parameters.barcode.back_color = Color.get_yellow()
generator.save("output/PlanetYellowBackground.png", BarCodeImageFormat.PNG)
```

## Συνηθισμένα προβλήματα και πώς να τα αποφύγετε

| Πρόβλημα | Αιτία | Διόρθωση |
|-------|--------|-----|
| **FileNotFoundError** κατά την αποθήκευση | Ο φάκελος προορισμού δεν υπάρχει. | Δημιουργήστε τον φάκελο εκ των προτέρων (`os.makedirs("output", exist_ok=True)`). |
| **Invalid data length** | Ο κωδικός Planet δέχεται μόνο αριθμητικά δεδομένα έως 12 χαρακτήρες. | Επικυρώστε τη συμβολοσειρά εισόδου πριν δημιουργήσετε τον γεννήτρια. |
| **Transparent bars not visible** | Κάποιοι προβολείς αγνοούν τη διαφάνεια σε λευκό καμβά. | Τοποθετήστε τον κωδικό σε μη‑λευκό φόντο ή εξάγετε ως PNG με κανάλι άλφα. |
