# Πώς να δημιουργήσετε εικόνα barcode σε C# με DataBar Stacked Omni‑Directional

Αν χρειάζεστε **πώς να δημιουργήσετε εικόνα barcode** σε μια εφαρμογή .NET, αυτό το tutorial δείχνει τα ακριβή βήματα. Θα δείτε πώς να δημιουργήσετε ένα barcode DataBar Stacked Omni‑Directional, να ρυθμίσετε την αναλογία διαστάσεων του και να εξάγετε το αποτέλεσμα ως αρχεία PNG.

Η δημιουργία barcode είναι συχνή απαίτηση για συστήματα αποθεμάτων, τερματικά λιανικής πώλησης και παρακολούθηση logistics. Στις επόμενες ενότητες θα καλύψουμε τα πάντα που χρειάζεστε — από το απαιτούμενο πακέτο NuGet μέχρι την τελική επαλήθευση της εικόνας — ώστε να ενσωματώσετε τη δημιουργία barcode σε οποιοδήποτε έργο C# σήμερα.

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

* .NET 6.0 ή νεότερο (ο κώδικας λειτουργεί με .NET Core και .NET Framework)
* Visual Studio 2022 ή οποιοδήποτε IDE C# προτιμάτε
* Το **Aspose.BarCode for .NET** πακέτο NuGet (εγκαταστήστε το με `dotnet add package Aspose.BarCode`)
* Δικαιώματα εγγραφής στον φάκελο όπου θα αποθηκευτούν τα αρχεία PNG

Αυτές οι προϋποθέσεις εγγυώνται ότι το παράδειγμα εκτελείται χωρίς πρόσθετη διαμόρφωση.

## Βήμα 1: Ρύθμιση του φακέλου εξόδου

Το πρώτο που χρειάζεστε είναι ένας φάκελος όπου θα γραφτούν τα παραγόμενα αρχεία PNG. Η χρήση απόλυτης ή σχετικής διαδρομής λειτουργεί, αλλά βεβαιωθείτε ότι ο φάκελος υπάρχει πριν καλέσετε το `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Η δημιουργία του φακέλου προγραμματιστικά αποτρέπει το *FileNotFoundException* όταν η μέθοδος `Save` προσπαθεί να γράψει την εικόνα.

## Βήμα 2: Δημιουργία γεννήτριας DataBar Stacked Omni‑Directional barcode

Η κλάση **BarcodeGenerator** είναι το σημείο εισόδου για όλους τους τύπους barcode. Εδώ καθορίζουμε το `EncodeTypes.DatabarStackedOmniDirectional` και τη συμβολοσειρά δεδομένων που θέλουμε να κωδικοποιήσουμε.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Γιατί είναι σημαντικό*: Η απαρίθμηση `EncodeTypes` λέει στη βιβλιοθήκη ποια συμβολική γραφή (symbology) να αποδώσει. Η χρήση της παραλλαγής Omni‑Directional εξασφαλίζει ότι το barcode μπορεί να διαβαστεί από οποιονδήποτε προσανατολισμό — απαίτηση για πολλούς σαρωτές αποθήκης.

## Βήμα 3: Διαμόρφωση κοινών παραμέτρων barcode

Ένα αναγνώσιμο barcode χρειάζεται μια λογική διάσταση X (το πλάτος της μικρότερης γραμμής). Ορίζοντας το `Pixels` σε 2 προσφέρει καλή ισορροπία μεταξύ μεγέθους και καθαρότητας για τις περισσότερες αναλύσεις οθόνης.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Μπορείτε να προσαρμόσετε το `Pixels` αργότερα αν χρειάζεστε μεγαλύτερη ή μικρότερη εικόνα· η βιβλιοθήκη κλιμακώνει αυτόματα το υπόλοιπο του barcode.

## Βήμα 4: Δημιουργία της πρώτης εικόνας με αναλογία διαστάσεων 15

Η **αναλογία διαστάσεων** ελέγχει τη σχέση ύψους‑πλάτους των DataBar barcode. Μια αναλογία 15 είναι η τυπική προεπιλογή για ετικέτες λιανικής.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Μετά από αυτή την κλήση, θα βρείτε το `DatabarAspectRatio15.png` στον φάκελο εξόδου. Η εικόνα είναι PNG χωρίς απώλειες, κατάλληλη για περαιτέρω επεξεργασία ή εκτύπωση.

## Βήμα 5: Αλλαγή της αναλογίας διαστάσεων σε 30 και εξαγωγή δεύτερης εικόνας

Μερικές φορές απαιτείται ένα πιο ψηλό barcode — για παράδειγμα, όταν το ύψος της ετικέτας είναι περιορισμένο. Η αλλαγή της αναλογίας σε 30 παράγει μια πιο συμπαγή εμφάνιση ενώ διατηρεί την ακεραιότητα των δεδομένων.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Τώρα έχετε δύο αρχεία PNG που δείχνουν πώς τα ίδια δεδομένα εμφανίζονται με διαφορετικές αναλογίες διαστάσεων. Αυτή η σύγκριση πλάι‑πλάι σας βοηθά να αποφασίσετε ποια παραλλαγή ταιριάζει καλύτερα στο layout της ετικέτας σας.

## Πλήρες, εκτελέσιμο παράδειγμα

Παρακάτω βρίσκεται το πλήρες πρόγραμμα που μπορείτε να αντιγράψετε, να επικολλήσετε και να τρέξετε. Περιλαμβάνει όλες τις οδηγίες `using`, διαχείριση σφαλμάτων και σχόλια που εξηγούν κάθε μέρος της διαδικασίας.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Αναμενόμενη έξοδος** (κονσόλα):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Ανοίξτε τα δύο αρχεία PNG σε οποιονδήποτε προβολέα εικόνων. Θα δείτε το ίδιο GTIN κωδικοποιημένο, αλλά η δεύτερη εικόνα είναι πιο ψηλή λόγω της υψηλότερης αναλογίας διαστάσεων.

## Συμβουλές επαγγελματιών και κοινές παγίδες

| Κατάσταση | Σύσταση |
|-----------|----------|
| **Οθόνες χαμηλής ανάλυσης** | Αυξήστε το `XDimension.Pixels` σε 3 ή 4 για να διατηρήσετε τις γραμμές καθαρές. |
| **Εκτύπωση σε θερμικό χαρτί** | Χρησιμοποιήστε `BarCodeImageFormat.Tiff` για μεγαλύτερη πιστότητα και ορίστε `Resolution.DpiX/DpiY` σε 300. |
| **Δυναμικά δεδομένα** | Επαναχρησιμοποιήστε το ίδιο αντικείμενο `BarcodeGenerator` και ενημερώστε μόνο το `generator.CodeText` πριν από κάθε `Save`. Αυτό αποφεύγει περιττές δημιουργίες αντικειμένων. |
| **Μη έγκυρο GTIN** | Η βιβλιοθήκη ρίχνει `ArgumentException` εάν τα δεδομένα δεν συμμορφώνονται με τα πρότυπα GS1. Επικυρώστε τα δεδομένα σας πριν τα περάσετε στη γεννήτρια. |
