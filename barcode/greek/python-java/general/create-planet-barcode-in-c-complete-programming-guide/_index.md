# Δημιουργία κωδικού planet σε C# – πλήρης οδηγός προγραμματισμού

Αν χρειάζεστε **να δημιουργήσετε κωδικό planet** σε C#, αυτός ο οδηγός σας δείχνει ακριβώς πώς να το κάνετε. Θα ανακαλύψετε επίσης **πώς να ορίσετε τις διαστάσεις του κωδικού** ώστε οι γραμμές να αποδίδονται στο ακριβές πλάτος που απαιτείτε.

Η δημιουργία κωδικών Planet είναι συνηθισμένη όταν εργάζεστε με ταχυδρομικές υπηρεσίες ή συστήματα logistics. Ο παρακάτω κώδικας καλύπτει τόσο την προεπιλεγμένη έκδοση με γεμιστές γραμμές όσο και το προαιρετικό στυλ με κενές γραμμές, καθώς και ένα γρήγορο παράδειγμα για τη μορφή RM4SCC. Στο τέλος αυτού του οδηγού θα έχετε ένα επαναχρησιμοποιήσιμο απόσπασμα που μπορείτε να ενσωματώσετε σε οποιοδήποτε έργο .NET.

## Προαπαιτούμενα

* .NET 6.0 ή νεότερο εγκατεστημένο (το API λειτουργεί επίσης με .NET Framework 4.6+)
* Το πακέτο NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`) προστιθέμενο στο έργο σας
* Μια διαδρομή φακέλου με δικαιώματα εγγραφής όπου θα αποθηκευτούν τα αρχεία PNG
* Βασική εξοικείωση με τη σύνταξη C# και το Visual Studio (ή οποιοδήποτε IDE)

> **Συμβουλή επαγγελματία:** Χρησιμοποιήστε απόλυτη διαδρομή ή `Path.Combine(Environment.CurrentDirectory, "output")` για να αποφύγετε προβλήματα δικαιωμάτων κατά την αποθήκευση των εικόνων.

## Βήμα 1 – Αρχικοποίηση γεννήτριας κωδικού Planet (γεμιστές γραμμές)

Το πρώτο βήμα είναι να δημιουργήσετε μια παρουσία `BarcodeGenerator` για τη συμβολική γραφή Planet. Από προεπιλογή η γεννήτρια παράγει **γεμιστές** γραμμές.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Το enum `EncodeTypes.Planet` ενημερώνει το Aspose.BarCode να χρησιμοποιήσει τη μορφή Planet, ενώ το `"123456"` είναι το δεδομένο που θα κωδικοποιηθεί.

## Βήμα 2 – Πώς να ορίσετε τις διαστάσεις του κωδικού για συνεπή μεγέθυνση

Για να ελέγξετε το πλάτος κάθε γραμμής, προσαρμόστε την **διάσταση X**. Αυτή είναι η κύρια μέθοδος για **ορισμό διαστάσεων κωδικού** και εξασφαλίζει ότι ο κωδικός ταιριάζει στο μέγεθος της ετικέτας σας.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

Η ιδιότητα `Pixels` ορίζει το πλάτος της γραμμής σε εικονοστοιχεία οθόνης. Συνηθισμένες τιμές είναι 2 – 5 pixel για τυπικές ετικέτες αλληλογραφίας· αυξήστε την τιμή για μεγαλύτερες εκτυπώσεις.

## Βήμα 3 – Αποθήκευση του γεμιστού κωδικού Planet ως PNG

Τώρα γράψτε την εικόνα στο δίσκο. Το PNG διατηρεί καθαρά άκρα, κάτι που είναι ιδανικό για σάρωση.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Αντικαταστήστε το `YOUR_DIRECTORY` με τη διαδρομή που προετοιμάσατε νωρίτερα. Μετά την εκτέλεση αυτού του κώδικα θα δείτε ένα αρχείο παρόμοιο με την παρακάτω εικόνα.

## Βήμα 4 – Δημιουργία κωδικού Planet με κενές (μη γεμιστές) γραμμές

Αν η ταχυδρομική σας υπηρεσία απαιτεί οι γραμμές να είναι **κενές**, πρέπει να αλλάξετε τη σημαία `FilledBars` μετά την αρχικοποίηση της γεννήτριας.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Ο κατασκευαστής είναι ίδιος· η διαφορά βρίσκεται στο επόμενο βήμα διαμόρφωσης.

## Βήμα 5 – Πώς να ορίσετε τις διαστάσεις του κωδικού και να κάνετε τις γραμμές κενές

Ξανά, ορίστε τη διάσταση X για οπτική συνέπεια, στη συνέχεια απενεργοποιήστε τις γεμιστές γραμμές.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

Η ιδιότητα `FilledBars = false` είναι αυτή που πραγματικά αλλάζει το στυλ απόδοσης. Η διατήρηση της ίδιας διάστασης X εξασφαλίζει ότι ο κωδικός με κενές γραμμές ευθυγραμμίζεται τέλεια με την γεμιστή έκδοση.

## Βήμα 6 – Αποθήκευση του κενό κωδικού Planet

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Τώρα θα έχετε δύο αρχεία PNG: ένα με συμπαγείς γραμμές και ένα με κενές γραμμές, και τα δύο μοιράζονται τις ίδιες διαστάσεις.

## Βήμα 7 – (Προαιρετικό) Δημιουργία κωδικού RM4SCC για σύγκριση

Το RM4SCC είναι μια άλλη ταχυδρομική συμβολική γραφή που χρησιμοποιεί το ίδιο προεπιλεγμένο στυλ γεμιστών γραμμών. Τα βήματα αντικατοπτρίζουν το παράδειγμα Planet, δείχνοντας ότι **ο ορισμός διαστάσεων κωδικού** λειτουργεί σε διαφορετικές μορφές.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Η εκτέλεση αυτών των τριών βημάτων παράγει το `PostalRM4SCCFilledBars.png`, το οποίο μπορείτε να συγκρίνετε πλάι‑πλάι με τα αποτελέσματα Planet.

## Γιατί η διάσταση X είναι σημαντική

Η διάσταση X καθορίζει το **ελάχιστο εκτυπώσιμο πλάτος** κάθε γραμμής. Αν τη ρυθμίσετε πολύ χαμηλά, ο κωδικός μπορεί να θολώσει σε εκτυπωτές χαμηλής ανάλυσης, προκαλώντας αποτυχίες σάρωσης. Αντίστροφα, μια πολύ μεγάλη διάσταση X μπορεί να υπερβεί τις διαστάσεις της ετικέτας και να σπαταλήσει χώρο. Με το σαφές **πώς να ορίσετε τις διαστάσεις του κωδικού**, αποκτάτε καθοριστικό έλεγχο του τελικού μεγέθους της εικόνας, κάτι που είναι ουσιώδες για αυτοματοποιημένες διαδικασίες ταχυδρομικής αποστολής.

## Συνηθισμένα προβλήματα και πώς να τα αποφύγετε

| Issue | Cause | Fix |
|-------|-------|-----|
| Barcode appears stretched | X‑dimension set in points instead of pixels | Always use `Pixels` property for pixel‑perfect control |
| Empty bars still look filled | `FilledBars` not set to `false` after X‑dimension change | Set `FilledBars = false` *after* adjusting X‑dimension |
| Saved file is blank | Output directory does not exist or lacks write permission | Ensure the directory exists (`Directory.CreateDirectory`) and your app runs with sufficient rights |
| Image is blurry on print | Low DPI PNG saved from a high‑resolution monitor | Use `BarCodeImageFormat.Png` (lossless) and consider `Resolution` property if needed |

*Με ελληνική μετάφραση:*

| Πρόβλημα | Αιτία | Διόρθωση |
|----------|-------|----------|
| Ο κωδικός εμφανίζεται τεντωμένος | Η διάσταση X ορίστηκε σε σημεία αντί για pixel | Πάντα χρησιμοποιήστε την ιδιότητα `Pixels` για έλεγχο σε pixel |
| Οι κενές γραμμές φαίνονται ακόμη γεμιστές | `FilledBars` δεν έχει οριστεί σε `false` μετά την αλλαγή της διάστασης X | Ορίστε `FilledBars = false` *μετά* την προσαρμογή της διάστασης X |
| Το αποθηκευμένο αρχείο είναι κενό | Ο φάκελος εξόδου δεν υπάρχει ή δεν έχει δικαιώματα εγγραφής | Βεβαιωθείτε ότι ο φάκελος υπάρχει (`Directory.CreateDirectory`) και η εφαρμογή σας εκτελείται με επαρκή δικαιώματα |
| Η εικόνα είναι θολή στην εκτύπωση | PNG χαμηλής DPI αποθηκευμένο από οθόνη υψηλής ανάλυσης | Χρησιμοποιήστε `BarCodeImageFormat.Png` (χωρίς απώλειες) και εξετάστε την ιδιότητα `Resolution` αν χρειάζεται |

## Πλήρες, εκτελέσιμο παράδειγμα

Αντιγράψτε ολόκληρο το παρακάτω τμήμα σε ένα νέο έργο κονσόλας (`dotnet new console`) και εκτελέστε το. Το πρόγραμμα δημιουργεί τρία αρχεία PNG στο φάκελο `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Αναμενόμενο αποτέλεσμα:** τρία αρχεία PNG—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` και `PostalRM4SCCFilledBars.png`—με γραμμές πλάτους 4 pixel, έτοιμα για εκτύπωση ή περαιτέρω επεξεργασία.
