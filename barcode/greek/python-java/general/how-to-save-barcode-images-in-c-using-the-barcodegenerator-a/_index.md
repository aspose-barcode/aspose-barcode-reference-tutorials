# Πώς να αποθηκεύσετε εικόνες barcode σε C# χρησιμοποιώντας το BarcodeGenerator API

Αν χρειάζεστε **how to save barcode** αρχεία από μια εφαρμογή .NET, αυτός ο οδηγός δείχνει τα ακριβή βήματα. Θα δείτε ένα πλήρες **barcode generator example** που δημιουργεί ένα DataBar Stacked Omnidirectional barcode, ρυθμίζει την αναλογία διαστάσεων και αποθηκεύει δύο αρχεία PNG.

Η αποθήκευση εικόνων barcode είναι συχνή απαίτηση όταν δημιουργείτε συστήματα αποθεμάτων, τερματικά σημείου πώλησης ή αυτοματοποιημένες ροές ετικετών. Στο τέλος αυτού του tutorial θα μπορείτε να δημιουργήσετε κώδικα C# που παράγει αξιόπιστες εικόνες έτοιμες για εκτύπωση ή εμφάνιση.

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

- .NET 6.0 SDK ή νεότερη έκδοση εγκατεστημένη  
- Visual Studio 2022 (ή οποιοδήποτε IDE συμβατό με C#)  
- Το πακέτο **Aspose.BarCode for .NET** από το NuGet (ο κώδικας χρησιμοποιεί `Aspose.BarCode.Generation`)  

Μπορείτε να προσθέσετε το πακέτο με την ακόλουθη εντολή:

```bash
dotnet add package Aspose.BarCode
```

## Βήμα 1: Ρύθμιση ελάχιστου έργου κονσόλας C#

Δημιουργήστε ένα νέο έργο κονσόλας και προσθέστε την βιβλιοθήκη:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Ανοίξτε το `Program.cs`. Το αρχείο θα περιέχει τη μέθοδο `Main` όπου θα τοποθετήσουμε τη λογική **generate barcode C#**.

## Βήμα 2: Αρχικοποίηση του BarcodeGenerator για barcode DataBar Stacked Omnidirectional

Η πρώτη εργασία σε οποιοδήποτε **create databar barcode** workflow είναι η δημιουργία ενός αντικειμένου `BarcodeGenerator` με το σωστό `EncodeType`. Ο κατασκευαστής δέχεται τη συμβολική μορφή του barcode και τη συμβολοσειρά δεδομένων.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

Η τιμή `EncodeTypes.DatabarStackedOmniDirectional` λέει στη βιβλιοθήκη να παράγει ένα **create databar barcode** που μπορεί να σαρωθεί από οποιαδήποτε κατεύθυνση.

## Βήμα 3: Διαμόρφωση της διάστασης X (πλάτος μονάδας)

Η διάσταση X ελέγχει το μικρότερο πλάτος μπάρας σε εικονοστοιχεία. Ορίζοντάς το σε χαμηλή τιμή διατηρεί το barcode συμπαγές ενώ διατηρεί την αναγνωσιμότητα.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Βήμα 4: **How to adjust aspect ratio** – πρώτη τιμή (15)

Τα DataBar barcodes εκθέτουν μια ιδιότητα `AspectRatio` που επηρεάζει τη σχέση ύψους‑πλάτους. Μεγαλύτερη αναλογία δίνει ένα ψηλότερο barcode, κάτι που μπορεί να βελτιώσει την αξιοπιστία σάρωσης σε ορισμένους εκτυπωτές.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Βήμα 5: **How to save barcode** – πρώτη εικόνα (αναλογία 15)

Τώρα αποθηκεύουμε πραγματικά **how to save barcode** σε αρχείο. Η μέθοδος `Save` δέχεται μια διαδρομή αρχείου και μια μορφή εικόνας. Σε αυτό το παράδειγμα αποθηκεύουμε ένα αρχείο PNG.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Συμβουλή:** Ο φάκελος του εκτελέσιμου είναι η προεπιλεγμένη θέση εγγραφής. Χρησιμοποιήστε απόλυτη διαδρομή αν χρειάζεστε συγκεκριμένο φάκελο.

## Βήμα 6: **How to adjust aspect ratio** – δεύτερη τιμή (30)

Για να δείξουμε την ευελιξία, αλλάζουμε την αναλογία διαστάσεων και αποθηκεύουμε μια δεύτερη εικόνα. Αυτό δείχνει πώς τα ίδια κωδικοποιημένα δεδομένα μπορούν να αποδοθούν με διαφορετικές οπτικές αναλογίες.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Η εκτέλεση του προγράμματος παράγει δύο αρχεία PNG:

- `DatabarAspectRatio15.png` – barcode με μέτριο ύψος  
- `DatabarAspectRatio30.png` – barcode με μεγαλύτερο ύψος για απαιτητικά περιβάλλοντα σάρωσης  

Και τα δύο αρχεία είναι έτοιμα να φορτωθούν σε UI controls, να εκτυπωθούν σε ετικέτες ή να μεταδοθούν μέσω API.

### Αναμενόμενο αποτέλεσμα

Όταν ανοίξετε τις παραγόμενες εικόνες, θα πρέπει να δείτε ένα DataBar Stacked Omnidirectional barcode που κωδικοποιεί την τιμή GTIN‑14 `12345678901231`. Η οπτική διαφορά μεταξύ των δύο αρχείων είναι μόνο το ύψος, επιβεβαιώνοντας ότι η **how to adjust aspect ratio** λειτουργεί όπως προβλέπεται.

## Βήμα 7: Πλήρης κώδικας πηγής για αναφορά

Ακολουθεί το πλήρες, εκτελέσιμο πρόγραμμα. Αντιγράψτε το στο `Program.cs`, κάντε build και τρέξτε.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Συχνές ερωτήσεις και διαχείριση ειδικών περιπτώσεων

### Τι γίνεται αν ο φάκελος προορισμού δεν υπάρχει;

Η μέθοδος `Save` ρίχνει `DirectoryNotFoundException`. Δημιουργήστε πρώτα τον φάκελο:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Πώς να αλλάξετε μορφή εικόνας;

Αντικαταστήστε το `BarCodeImageFormat.Png` με `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` ή `BarCodeImageFormat.Tiff` ανάλογα με τις απαιτήσεις downstream.

### Μπορώ να δημιουργήσω πολλαπλά barcode σε βρόχο;

Ναι. Δημιουργήστε ένα νέο `BarcodeGenerator` για κάθε συμβολοσειρά δεδομένων ή επαναχρησιμοποιήστε το ίδιο αντικείμενο αφού ενημερώσετε την ιδιότητα `CodeText`:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### Λειτουργεί η **how to save barcode** σε πλατφόρμες εκτός Windows;

Το Aspose.BarCode είναι cross‑platform. Ο ίδιος κώδικας εκτελείται σε Linux και macOS εφόσον υπάρχει το .NET runtime.
