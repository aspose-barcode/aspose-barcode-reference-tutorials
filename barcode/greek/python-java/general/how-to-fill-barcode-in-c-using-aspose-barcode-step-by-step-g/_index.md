# Πώς να γεμίσετε barcode σε C# χρησιμοποιώντας Aspose.BarCode

Αν χρειάζεστε **πώς να γεμίσετε barcode** σε μια εφαρμογή .NET, αυτό το tutorial δείχνει τη πλήρη διαδικασία. Θα δημιουργήσετε ένα postal Planet barcode με συμπαγείς γραμμές, στη συνέχεια θα δημιουργήσετε μια έκδοση με κενές γραμμές του ίδιου barcode, όλα με μια αλλαγή μιας γραμμής κώδικα.

Ο οδηγός καλύπτει όλα όσα χρειάζεστε: ρύθμιση έργου, ρύθμιση X‑dimension, εναλλαγή μεταξύ γεμιστών και κενών γραμμών, και πώς να επαληθεύσετε τα παραγόμενα αρχεία PNG. Δεν απαιτείται εξωτερική τεκμηρίωση — απλώς αντιγράψτε τον κώδικα, εκτελέστε τον και θα δείτε το αποτέλεσμα.

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

* .NET 6.0 SDK ή νεότερη έκδοση εγκατεστημένη  
* Περιβάλλον ανάπτυξης όπως Visual Studio 2022 ή VS Code  
* Το **Aspose.BarCode for .NET** πακέτο NuGet (`Aspose.BarCode`)  

Αυτά αποτελούν το ελάχιστο υπόβαθρο για το τμήμα **barcode generator c#** του tutorial.

## Πώς να γεμίσετε barcode – ρύθμιση του έργου

1. Δημιουργήστε ένα νέο console project:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Προσθέστε το πακέτο Aspose.BarCode:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Ανοίξτε το παραγόμενο αρχείο `Program.cs` και αντικαταστήστε το περιεχόμενό του με το πλήρες παράδειγμα που εμφανίζεται αργότερα σε αυτό το άρθρο.

Το έργο τώρα περιέχει όλα όσα απαιτούνται για **να δημιουργήσετε εικόνες postal barcode**.

## Δημιουργία postal barcode με συμπαγείς γραμμές

Το πρώτο βήμα είναι η δημιουργία ενός Planet barcode που χρησιμοποιεί γεμιστές (συμπαγείς) γραμμές. Το Planet είναι η συμβολική κωδικοποίηση που χρησιμοποιείται από πολλές ταχυδρομικές υπηρεσίες για ταξινόμηση.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Γιατί αυτές οι γραμμές είναι σημαντικές**

* `EncodeTypes.Planet` λέει στον δημιουργό ποια συμβολική κωδικοποίηση να χρησιμοποιήσει· το Planet είναι το πρότυπο για postal barcodes.  
* `XDimension.Pixels = 4` αυξάνει το πλάτος του μονάδας, καθιστώντας το barcode πιο εύκολο στην ανάγνωση και οπτικά πιο καθαρό όταν εκτυπώνεται.  
* `Save` γράφει την εικόνα στο δίσκο σε μορφή PNG, μια μορφή χωρίς απώλειες κατάλληλη για περαιτέρω επεξεργασία.

Η εκτέλεση αυτού του τμήματος παράγει το **PostalPlanetFilledBars.png**, μια εικόνα με συμπαγείς γραμμές που συμμορφώνεται με τις προδιαγραφές των ταχυδρομείων.

## Δημιουργία κενών barcode χρησιμοποιώντας τη συμβολική κωδικοποίηση Planet

Μερικές φορές ένα ταχυδρομικό σύστημα αναμένει οι γραμμές να είναι κενές (απλήρωτες) ενώ τα κενά παραμένουν συμπαγή. Η εναλλαγή σε αυτή τη λειτουργία απαιτεί μόνο μια αλλαγή ιδιότητας.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Γιατί αυτό λειτουργεί**

Η ρύθμιση `FilledBars = false` λέει στον renderer να αντιστρέψει το οπτικό στυλ: οι γραμμές γίνονται διαφανείς (κενές) και το φόντο γίνεται αδιαφανές. Αυτό είναι ακριβώς το αντίστροφο της προεπιλεγμένης συμπεριφοράς που παρουσιάστηκε νωρίτερα, επιτρέποντάς σας να **δημιουργήσετε κενά barcode** χωρίς να αλλάξετε τα κωδικοποιημένα δεδομένα.

## Πλήρες, εκτελέσιμο παράδειγμα

Παρακάτω βρίσκεται το πλήρες πρόγραμμα που συνδυάζει τα δύο τμήματα. Αντιγράψτε το στο `Program.cs`, αντικαταστήστε το `YOUR_DIRECTORY/` με μια πραγματική διαδρομή φακέλου, και εκτελέστε `dotnet run`.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Αναμενόμενο αποτέλεσμα

Μετά την εκτέλεση θα βρείτε δύο αρχεία PNG στον καθορισμένο φάκελο:

| Όνομα αρχείου                     | Περιγραφή |
|-----------------------------------|-----------|
| `PostalPlanetFilledBars.png`      | Οι γραμμές είναι συμπαγές μαύρο σε λευκό φόντο |
| `PostalPlanetEmptyBars.png`       | Οι γραμμές είναι διαφανείς (λευκές) σε μαύρο φόντο |

Και οι δύο εικόνες κωδικοποιούν την ίδια αριθμητική ακολουθία `"123456"` και μοιράζονται το ίδιο X‑dimension, εξασφαλίζοντας ότι είναι εναλλάξιμες από άποψη επικύρωσης δεδομένων.

## Συχνές ερωτήσεις και ειδικές περιπτώσεις

**Τι γίνεται αν ο φάκελος εξόδου δεν υπάρχει;**  
Η μέθοδος `Save` ρίχνει `DirectoryNotFoundException`. Δημιουργήστε τον φάκελο εκ των προτέρων ή τυλίξτε τις κλήσεις σε ένα μπλοκ `try / catch` που δημιουργεί τον φάκελο εάν είναι απαραίτητο:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Μπορώ να χρησιμοποιήσω διαφορετική μορφή εικόνας;**  
Ναι. Αντικαταστήστε το `BarCodeImageFormat.Png` με `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp`, ή οποιαδήποτε μορφή υποστηρίζεται από το Aspose.BarCode.

**Επηρεάζει το X‑dimension την αναγνώσιμότητα από το scanner;**  
Η αύξηση του πλάτους σε pixel κάνει τις γραμμές πιο φαρδιές, κάτι που μπορεί να βελτιώσει την αναγνώσιμότητα σε scanners χαμηλής ανάλυσης. Ωστόσο, πολύ μεγάλες τιμές μπορεί να υπερβούν την εκτυπώσιμη περιοχή. Τυπικές τιμές κυμαίνονται από 2 έως 6 pixel για εκτύπωση 300 dpi.

**Είναι η συμβολική κωδικοποίηση `EncodeTypes.Planet` η μοναδική επιλογή για ταχυδρομικά barcode;**  
Όχι. Το Aspose.BarCode υποστηρίζει επίσης `EncodeTypes.Postnet` και `EncodeTypes.USPSIntelligentMail`. Η ίδια ιδιότητα `FilledBars` λειτουργεί και με αυτούς τους τύπους.
