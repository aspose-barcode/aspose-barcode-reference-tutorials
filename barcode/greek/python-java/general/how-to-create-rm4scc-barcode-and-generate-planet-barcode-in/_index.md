# Πώς να δημιουργήσετε γραμμωτό κώδικα RM4SCC και να δημιουργήσετε γραμμωτό κώδικα planet σε C#

Αν χρειάζεστε **create RM4SCC barcode** για ταχυδρομικές εφαρμογές, αυτός ο οδηγός σας δείχνει τα ακριβή βήματα. Θα μάθετε επίσης πώς να **generate planet barcode** με αυτόματο και σταθερό ύψος, ώστε ο ίδιος κώδικας να λειτουργεί για οποιαδήποτε postal symbology.

Ο οδηγός καλύπτει όλα όσα απαιτούνται για την παραγωγή εικόνων PNG που πληρούν τα ταχυδρομικά πρότυπα. Δεν απαιτούνται εξωτερικά εργαλεία πέρα από τη βιβλιοθήκη Aspose.BarCode for .NET. Στο τέλος, μπορείτε να generate barcodes προγραμματιστικά και να ελέγχετε τις διαστάσεις τους με ακρίβεια.

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

* .NET 6.0 ή νεότερο εγκατεστημένο
* Visual Studio 2022 (ή οποιοδήποτε C# IDE)
* Πακέτο NuGet Aspose.BarCode for .NET  
  `Install-Package Aspose.BarCode`
* Δικαιώματα εγγραφής στον φάκελο εξόδου

Αυτά τα στοιχεία σας επιτρέπουν να μεταγλωττίσετε και να εκτελέσετε τον κώδικα παραδείγματος χωρίς πρόσθετη ρύθμιση.

## Βήμα 1: Αρχικοποίηση του δημιουργού γραμμωτού κώδικα για RM4SCC

Η πρώτη ενέργεια δημιουργεί ένα αντικείμενο `BarcodeGenerator` ρυθμισμένο για τη συμβολή RM4SCC. Αυτό το αντικείμενο περιέχει όλες τις ρυθμίσεις για την εικόνα του γραμμωτού κώδικα.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Γιατί είναι σημαντικό** – `EncodeTypes.RM4SCC` λέει στο Aspose να χρησιμοποιήσει τη μορφή postal RM4SCC, ενώ η συμβολοσειρά δεδομένων `"123456"` αντιπροσωπεύει τον ταχυδρομικό κώδικα που θέλετε να κωδικοποιήσετε.

## Βήμα 2: Ορισμός του πλάτους μονάδας (διάσταση X)

Το πλάτος μονάδας ελέγχει το μέγεθος της λεπτής γραμμής. Μια κοινή τιμή για ταχυδρομικούς γραμμωτούς κώδικες είναι 4 pixel.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Εξήγηση** – Η διάσταση X επηρεάζει τη συνολική αναγνωσιμότητα του γραμμωτού κώδικα. Η επιλογή 4 px ταιριάζει με τους περισσότερους ταχυδρομικούς σαρωτές.

## Βήμα 3: Αποθήκευση με αυτόματο ύψος γραμμής

Όταν παραλείψετε την τιμή ύψους, το Aspose υπολογίζει αυτόματα το βέλτιστο ύψος βάσει των κανόνων της συμβολής.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Αποτέλεσμα** – Το παραγόμενο PNG (`PostalRM4SCCBarHeightNone.png`) περιέχει έναν σωστά διαστασιοποιημένο γραμμωτό κώδικα RM4SCC έτοιμο για εκτύπωση.

## Βήμα 4: Δημιουργία γραμμωτού κώδικα Planet με αυτόματο ύψος

Το ίδιο μοτίβο λειτουργεί για τη συμβολή Planet. Ξεκινήστε αρχικοποιώντας το γεννήτρια με `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Γιατί να επαναχρησιμοποιήσετε τον κώδικα** – Και τα RM4SCC και Planet μοιράζονται την ίδια δομή παραμέτρων, έτσι μπορείτε να αλλάξετε τη συμβολή αλλάζοντας μόνο την τιμή `EncodeTypes`.

## Βήμα 5: Ορισμός σταθερού ύψους γραμμής για RM4SCC

Ορισμένες ταχυδρομικές υπηρεσίες απαιτούν συγκεκριμένο ύψος γραμμής (π.χ., 100 px). Μπορείτε να το ορίσετε ρητά πριν την αποθήκευση.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Συμβουλή** – Ο ορισμός του `BarHeight.Pixels` παρακάμπτει τον αυτόματο υπολογισμό, δίνοντάς σας πλήρη έλεγχο του οπτικού μεγέθους.

## Βήμα 6: Ορισμός σταθερού ύψους γραμμής για Planet

Εφαρμόστε την ίδια τεχνική σταθερού ύψους σε έναν γραμμωτό κώδικα Planet.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Αποτέλεσμα** – Και τα `PostalRM4SCCBarHeight100Pixels.png` και `PostalPlanetBarHeight100Pixels.png` περιέχουν γραμμωτούς κώδικες με συνεπές ύψος γραμμής 100 px, ικανοποιώντας τις αυστηρές ταχυδρομικές προδιαγραφές.

## Πλήρης πηγαίος κώδικας

Παρακάτω βρίσκεται το πλήρες, εκτελέσιμο πρόγραμμα που περιλαμβάνει όλα τα τέσσερα παραδείγματα. Αντιγράψτε το σε ένα νέο έργο console και προσαρμόστε τη διαδρομή εξόδου όπως χρειάζεται.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Αναμενόμενη έξοδος** – Μετά την εκτέλεση του προγράμματος, ο καθορισμένος φάκελος περιέχει τέσσερα αρχεία PNG:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC με αυτόματο ύψος
* `PostalPlanetBarHeightNone.png` – Planet με αυτόματο ύψος
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC με ύψος 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet με ύψος 100 px

Ανοίξτε οποιοδήποτε αρχείο για να επαληθεύσετε ότι οι γραμμές είναι καθαρές, το πλάτος μονάδας είναι 4 px και το ύψος ταιριάζει με την επιλεγμένη ρύθμιση.
