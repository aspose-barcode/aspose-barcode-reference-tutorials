# Jak generovat DataMatrix čárové kódy pomocí Aspose.BarCode pro .NET

Pokud potřebujete spolehlivý způsob, jak vložit strojově čitelné symboly do svých .NET aplikací, **jak generovat DataMatrix** čárové kódy je běžná požadavek. Aspose.BarCode pro .NET nabízí plně spravované API, které zvládne každý krok — od výběru správné verze DataMatrix až po jemné ladění úrovní opravy chyb — bez nutnosti externích nástrojů. V tomto tutoriálu projdeme kompletním příkladem, vysvětlíme, proč je každé nastavení důležité, a ukážeme vám, jak výsledek uložit jako PNG nebo JPEG obrázek.

## Rychlé odpovědi
- **Jaká knihovna vytváří DataMatrix čárové kódy?** Aspose.BarCode for .NET.  
- **Kolik verzí DataMatrix je podporováno?** Všechny 30 standardních čtvercových a obdélníkových verzí (od 10×10 až po 144×144 modulů).  
- **Jaké typy ECC mohu použít?** ECC200 (výchozí) a ECC140.  
- **Potřebuji licenci pro vývoj?** Bezplatná 30‑denní zkušební verze funguje pro testování; pro produkci je vyžadována komerční licence.  
- **Mohu to spustit na .NET 6, .NET Core nebo .NET Framework?** Ano — Aspose.BarCode podporuje .NET Framework 4.5+, .NET Core 3.1+ a .NET 5/6+.

## Co je DataMatrix čárový kód?
DataMatrix čárový kód je dvourozměrná, čtvercová nebo obdélníková matice černých a bílých buněk, která může uložit až 2 335 alfanumerických znaků. Je široce používán ve výrobě, logistice a zdravotnictví pro označování malých předmětů, protože zůstává čitelný i při částečném poškození.

## Proč používat Aspose.BarCode pro .NET?
Aspose.BarCode podporuje **více než 50 výstupních formátů** (včetně PNG, JPEG, TIFF, SVG a PDF) a může generovat **všechny 30 verzí DataMatrix** bez načítání celého obrázku do paměti, což vám umožní vytvářet čárové kódy ve vysoce výkonných službách, které zpracovávají soubory větší než 100 MB.

## Jak generovat DataMatrix čárové kódy v .NET?

Načtěte `BarcodeGenerator` s typem `EncodeTypes.DataMatrix`, nastavte požadovanou verzi a ECC, a poté zavolejte `Save` pro zápis souboru obrázku. Tento jednorázový vzor funguje pro libovolnou verzi, kterou vyberete, a automaticky zpracovává velikost modulů, tiché zóny a vykreslování obrázku.

## Importovat jmenné prostory

`BarcodeGenerator` je hlavní třída Aspose.BarCode pro vytváření obrázků čárových kódů.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

Jmenný prostor `Aspose.BarCode.Generation` poskytuje přístup ke třídě `BarcodeGenerator`, která je hlavní třídou používanou k generování obrázků čárových kódů.

Nyní rozdělíme příklad do několika kroků.

## Krok 1: nastavení cesty ke složce

Začněte definováním cesty ke složce, kam chcete ukládat vygenerované DataMatrix čárové kódy.

```csharp
string path = "Your Directory Path";
```

Nahraďte `"Your Directory Path"` skutečnou cestou, kam chcete ukládat obrázky čárových kódů.

## Krok 2: inicializace generátoru čárových kódů

Vytvořte instanci třídy `BarcodeGenerator` a specifikujte typ čárového kódu jako `DataMatrix`. Můžete také poskytnout data, která chcete zakódovat do čárového kódu.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` je hlavní třída, která vytváří a vykresluje symboly čárových kódů.

## Krok 3: konfigurace vlastností čárového kódu

Můžete přizpůsobit různé vlastnosti DataMatrix čárového kódu, jako jsou jeho rozměry a typ ECC (Error Correction Code). Zde je příklad nastavení X‑dimenze na 4 pixely a výběru ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` nastavuje velikost každého modulu v pixelech a `DataMatrixEcc` vybírá úroveň opravy chyb.

## Krok 4: nastavení verze DataMatrix a uložení

Můžete specifikovat verzi DataMatrix nastavením počtu řádků a sloupců. Po nakonfigurování verze uložte obrázek čárového kódu.

Například pro vytvoření DataMatrix čárového kódu se 22 řádky a 22 sloupci pomocí ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

Podobně můžete vygenerovat čárový kód s různými parametry změnou verze a typu ECC podle potřeby.

## Krok 5: opakování pro další verze

Můžete opakovat Krok 4 pro další verze DataMatrix. Například pro vytvoření čárového kódu se 12 řádky a 64 sloupci pomocí ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Krok 6: přepnutí typů ECC

Pokud chcete změnit typ ECC na Ecc140, můžete tak učinit aktualizací vlastnosti ECC:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Krok 7: generování čárových kódů s různými verzemi a ECC

Opakujte Krok 4 pro další verze DataMatrix a typy ECC, přičemž každý čárový kód uložte pod jedinečným názvem souboru.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

Nyní, když jste se naučili, jak generovat DataMatrix čárové kódy pomocí Aspose.BarCode pro .NET, můžete tuto funkci snadno integrovat do svých .NET aplikací.

## Časté úskalí a tipy na odstraňování problémů

- **Nesprávné rozměry verze** – Verze DataMatrix mají pevně dané páry řádků/sloupců. Zadání neodpovídajícího páru (např. 10 × 20) vyvolá `ArgumentException`. Vždy použijte jednu z podporovaných kombinací uvedených v dokumentaci API.  
- **Chybějící licence** – V režimu zkušební verze obsahují vygenerované obrázky vodoznak. Použijte platnou licenci pomocí `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` před vytvořením generátoru, aby se vodoznak odstranil. Třída `License` načte licenční soubor pro aktivaci produktu.  
- **Velká velikost obrázku** – Pokud potřebujete výstup ve vysokém rozlišení, zvyšte vlastnost `XDimension`; knihovna škáluje obrázek proporcionálně bez ztráty čitelnosti.
