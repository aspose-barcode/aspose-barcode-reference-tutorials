# Generování čárového kódu PDF417 v C# pomocí Aspose – krok za krokem

Pokud potřebujete **vytvořit čárový kód PDF417** v .NET aplikaci, tento návod vám přesně ukáže, jak na to. Uvidíte kompletní, připravený příklad, který vytváří základní, kompaktní, Micro, GS1‑Micro a Macro PDF417 čárové kódy pomocí Aspose.BarCode pro .NET.

Generování čárového kódu PDF417 je běžnou požadavkem pro přepravní štítky, dopravní dokumenty a inventární systémy. Na konci tohoto tutoriálu budete schopni **vytvořit PDF417 čárový kód** jako obrázky, pochopit klíčové parametry a přizpůsobit kód pro vlastní datové náklady.

## Požadavky

- .NET 6.0 SDK nebo novější (kód také funguje s .NET Framework 4.7+)
- Visual Studio 2022 nebo jakékoli C# IDE
- NuGet balíček Aspose.BarCode pro .NET (`Aspose.BarCode`) nainstalován
- Základní znalost syntaxe C#

> **Tip:** Použijte bezplatnou evaluační licenci od Aspose, abyste během testování předešli omezením za běhu.

## Krok 1: Nastavení projektu a import jmenných prostorů

Vytvořte nový konzolový projekt a přidejte balíček Aspose.BarCode:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Poté otevřete `Program.cs` a přidejte požadované `using` direktivy:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Tyto jmenné prostory vám poskytují přístup ke třídě `BarcodeGenerator` a výčtu `EncodeTypes`, které jsou potřebné k **vytvoření čárového kódu pomocí C#**.

## Krok 2: Vytvoření základního PDF417 čárového kódu

Nejjednodušší PDF417 čárový kód používá výchozí nastavení kromě X‑dimenze (šířka modulu) a počtu sloupců. Úpravou těchto hodnot řídíte celkovou velikost a čitelnost.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Proč to funguje:**  
- `EncodeTypes.Pdf417` říká Aspose, aby použil symbologii PDF417.  
- `XDimension.Pixels` určuje nejmenší šířku čáry; hodnota 2 udržuje obrázek malý, aniž by se snížila skenovatelnost.  
- `Pdf417.Columns` určuje, kolik datových sloupců čárový kód obsahuje; tři sloupce poskytují vyvážený poměr stran.

## Krok 3: Vytvoření kompaktního (zkráceného) PDF417 čárového kódu

Kompaktní režim odstraňuje stopovací vzor a snižuje celkovou výšku, což je užitečné pro štítky s omezeným prostorem.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Proč to funguje:**  
Nastavení `Pdf417.Truncate = true` aktivuje zkrácený režim, který vynechává pravý stopovací vzor a snižuje výšku čárového kódu při zachování integrity dat.

## Krok 4: Vytvoření Micro PDF417 čárového kódu

Micro PDF417 je menší varianta, která podporuje 1‑4 sloupce. Je ideální pro aplikace, kde je prostor omezený, například malé produktové štítky.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Proč to funguje:**  
- `EncodeTypes.MicroPdf417` vybírá mikro verzi symbologie.  
- Počet sloupců může být mezi 1 a 4; výběrem 4 získáte nejhustší rozložení, které je stále skenovatelné.

## Krok 5: Vytvoření GS1‑kompatibilního Micro PDF417 čárového kódu

GS1 prefixy přidávají standardizované identifikátory (např. GTIN, číslo šarže) k datům čárového kódu. Aspose vám umožňuje je vložit přímo.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Proč to funguje:**  
GS1 identifikátory aplikací (AI) jsou umístěny v závorkách. Aspose je parsuje a přidává požadované formátování potřebné pro GS1 skenery.

## Krok 6: Vytvoření Macro PDF417 čárového kódu s kompletními metadaty

Macro PDF417 vám umožňuje rozdělit velký datový payload do několika propojených čárových kódů. Můžete vložit metadata na úrovni souboru, jako je ID souboru, počet segmentů, časová razítka a vlastní řetězce.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Proč to funguje:**  
Každá vlastnost `MacroPdf417*` mapuje na konkrétní segment specifikace makro čárového kódu. Nastavením těchto hodnot zajistíte, že skener dokáže z několika obrázků čárových kódů rekonstruovat původní soubor.
