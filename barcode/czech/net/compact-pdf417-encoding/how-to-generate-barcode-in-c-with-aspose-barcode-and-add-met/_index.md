# Jak generovat čárový kód v C# s Aspose.BarCode a přidat metadata

Pokud potřebujete **generovat čárový kód v C#** pro logistický nebo inventární systém, tento průvodce vám ukáže kompletní, připravené řešení pro produkci. Uvidíte, jak vytvořit Macro PDF417 čárový kód, připojit bohatá metadata a nastavit přesný časový razítko – vše pomocí knihovny Aspose.BarCode.

Tutoriál pokrývá vše od instalace NuGet balíčku až po uložení finálního PNG obrázku. Na konci budete schopni vygenerovat čárový kód, který nese identifikátory souborů, informace o segmentech a vlastní pole, připravený pro downstream skenery podporující Macro PDF417.

## Požadavky

Než začnete, ujistěte se, že máte:

* .NET 6.0 SDK nebo novější (kód funguje také s .NET Framework 4.7.2+)
* Visual Studio 2022 nebo jakékoli C# IDE, které preferujete
* Aktivní licenci Aspose.BarCode (bezplatná zkušební verze funguje pro vývoj)
* Základní znalosti syntaxe C#

> **Pro tip:** Pokud používáte CI/CD pipeline, přidejte odkaz na balíček Aspose.BarCode ve vašem projektovém souboru, aby byly sestavení reprodukovatelné.

## Krok 1: Instalace Aspose.BarCode

Otevřete terminál ve složce projektu a spusťte:

```bash
dotnet add package Aspose.BarCode
```

Příkaz stáhne nejnovější stabilní verzi (aktuálně 24.9). Po dokončení obnovení můžete knihovnu odkazovat ve svých zdrojových souborech.

## Krok 2: Vytvoření nového C# konzolového projektu (volitelné)

Pokud chcete čistý start, vytvořte konzolovou aplikaci:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Soubor `Program.cs` bude hostovat kód pro generování čárového kódu, který bude uveden později.

## Krok 3: Nastavení generátoru čárových kódů

Jádrem procesu je třída `BarcodeGenerator`. Instancujete ji s požadovanou hodnotou výčtu `EncodeTypes` a textem, který chcete zakódovat.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Proč je každý řádek důležitý

* **EncodeTypes.MacroPdf417** říká Aspose, aby vytvořil PDF417 čárový kód, který lze rozdělit do segmentů. To je nezbytné pro velké payloady, které přesahují kapacitu jednoho symbolu.
* **XDimension.Pixels** řídí vizuální hustotu. Hodnota 2 produkuje čistý obrázek na většině obrazovek a tiskáren, aniž by nafouklá velikost souboru.
* **MacroPdf417* properties** vkládají metadata, která downstream skenery čtou jako samostatná pole (file ID, segment ID, atd.). Toto je část „jak přidat metadata“ v tutoriálu.
* **MacroPdf417TimeStamp** demonstruje „jak nastavit časové razítko“. Instance `DateTime` může být libovolný UTC čas; použití UTC eliminuje nejasnosti časových pásem, když čárový kód cestuje napříč regiony.
* **MacroPdf417Terminator** definuje, jak sekvence makra končí. `Set` je nejčastější volba, protože signalizuje poslední segment čtečce.
* **Save(..., BarCodeImageFormat.Png)** zapisuje bezztrátový obrázek, který zachovává jemné detaily potřebné pro spolehlivé skenování.

## Krok 4: Ověření vygenerovaného čárového kódu

Spusťte program:

```bash
dotnet run
```

Měli byste vidět výstup v konzoli:

```
Barcode saved to ExtPDF417Meta.png
```

Otevřete `ExtPDF417Meta.png` v libovolném prohlížeči obrázků. Obrázek zobrazí kompaktní PDF417 symbol s textem **Åspóse.Barcóde©** a vloženými makro poli. Skenování obrázku pomocí PDF417‑kompatibilního skeneru (nebo mobilní aplikace podporující Macro PDF417) vrátí původní text plus hodnoty metadat, které jste nastavili.

### Očekávané vizuální charakteristiky

* Tmavé, rovnoměrně rozestoupené vertikální pruhy
* Klidová zóna (margin) automaticky přidána Aspose
* Žádná deformace, protože `XDimension` 2 pixelů odpovídá nativnímu rozlišení PNG

## Krok 5: Běžné varianty a okrajové případy

### 5.1 Zpracování speciálních znaků

Ukázkový text obsahuje Unicode znaky (`Å`, `ó`, `©`). Aspose.BarCode je kóduje pomocí UTF‑8 ve výchozím nastavení, takže se v čárovém kódu zobrazí správně. Pokud potřebujete jiné kódování (např. ISO‑8859‑1), nastavte:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Velké identifikátory souborů

`MacroPdf417FileID` přijímá 32‑bitové celé číslo. Pro hodnoty větší než `int.MaxValue` rozdělte identifikátor do více polí nebo použijte GUID uložený jako řetězec v `MacroPdf417FileName`.

### 5.3 Úprava počtu sloupců

Zvýšení `Pdf417.Columns` snižuje výšku čárového kódu, ale rozšiřuje každou řadu. Pokud musí čárový kód zapadnout na úzký štítek, snižte počet sloupců a automaticky zvýšte počet řádků.

### 5.4 Ukládání v jiných formátech

Aspose podporuje BMP, JPEG, TIFF a SVG. Nahraďte `BarCodeImageFormat.Png` požadovanou hodnotou výčtu, např. `BarCodeImageFormat.Svg` pro škálovatelný vektorový grafický formát.

## Často kladené otázky

**Q: Funguje to na .NET Core?**  
A: Ano. Stejné API funguje na .NET Core, .NET 5+ i .NET Framework. Stačí odkazovat na příslušný NuGet balíček.

**Q: Co když potřebuji vygenerovat ne‑macro PDF417?**  
A: Použijte `EncodeTypes.Pdf417` místo `EncodeTypes.MacroPdf417`. Makro‑specifické vlastnosti budou ignorovány.

**Q: Můžu přidat vlastní páry klíč/hodnota nad rámec vestavěných polí?**  
A: Aspose.BarCode neumožňuje exponovat libovolná uživatelská pole pro Macro PDF417. Pokud potřebujete další data, zakódujte je do hlavního textového payloadu nebo přejděte na QR kód, který podporuje strukturovaný append.
