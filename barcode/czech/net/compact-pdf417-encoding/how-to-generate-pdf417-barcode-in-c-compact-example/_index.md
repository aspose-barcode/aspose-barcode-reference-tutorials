# Jak generovat PDF417 čárový kód v C# – kompaktní příklad

Pokud potřebujete **generovat PDF417 čárový kód** v aplikaci C#, tento návod vám ukáže kompletní, připravené řešení. Vytvoříme kompaktní PDF417 čárový kód, upravíme šířku modulu, definujeme počet sloupců a výsledek uložíme jako PNG obrázek – vše pomocí knihovny Aspose.BarCode .NET.

Generování PDF417 čárového kódu je běžné, když chcete zakódovat velké množství dat (např. URL, vizitky nebo identifikátory zásob) v úsporném dvourozměrném formátu. Na konci tohoto tutoriálu budete mít funkční instanci `BarcodeGenerator`, která vytváří kompaktní, dobře čitelný čárový kód připravený k tisku nebo zobrazení.

## Požadavky

- .NET 6.0 nebo novější (kód také funguje s .NET Framework 4.8)
- Visual Studio 2022 (nebo jakékoli C# IDE)
- NuGet balíček Aspose.BarCode pro .NET (`Install-Package Aspose.BarCode`)
- Základní znalost syntaxe C#

Žádná další konfigurace není vyžadována; příklad běží jako konzolová aplikace.

## Krok 1: Vytvořte generátor PDF417 čárového kódu

Prvním krokem je vytvořit instanci `BarcodeGenerator` s výčtem `EncodeTypes.Pdf417` a textem, který chcete zakódovat.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Proč je to důležité:** `EncodeTypes.Pdf417` říká knihovně, aby použila symbologii PDF417, zatímco druhý argument nastavuje datový payload. Můžete nahradit `"Compact example"` libovolným řetězcem až do 1 800 znaků.

## Krok 2: Nastavte šířku modulu (X‑dimenzi) v pixelech

X‑dimenze určuje šířku jednoho modulu čárového kódu (nejmenší černý nebo bílý čtvereček). Menší hodnota pixelů vede k těsnějšímu čárovému kódu.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Proč je to důležité:** Hodnota `2` pixely vytváří kompaktní vzhled, aniž by se snížila spolehlivost skenování na většině moderních skenerů. Upravit hodnotu, pokud potřebujete větší moduly pro tisk s nízkým rozlišením.

## Krok 3: Zadejte počet sloupců

PDF417 vám umožňuje řídit počet sloupců, což ovlivňuje poměr stran čárového kódu.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Proč je to důležité:** Méně sloupců dělá čárový kód vyšší, zatímco více sloupců jej zploští. Tři sloupce fungují dobře pro kompaktní, na výšku orientovaný layout.

## Krok 4: Aktivujte kompaktní režim oříznutím čárového kódu

Kompaktní režim odstraňuje zbytečné řádky výplně, čímž zmenšuje čárový kód a zachovává zakódovaná data.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Proč je to důležité:** Oříznutí je ideální, když je omezený prostor na obrazovce (např. mobilní aplikace nebo malé štítky). Čárový kód zůstává plně čitelný, protože algoritmus kódování automaticky upravuje úrovně korekce chyb.

## Krok 5: Uložte čárový kód jako PNG obrázek

Nakonec zapíšeme vygenerovaný čárový kód do souboru. PNG zachovává bezztrátovou kvalitu, což je pro čtečky čárových kódů zásadní.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Spuštěním programu se vytvoří `CompactPdf417.png` v pracovním adresáři spustitelného souboru. Obrázek vypadá takto:

![Vygenerovaný kompaktní PDF417 čárový kód](CompactPdf417.png "Vygenerovaný kompaktní PDF417 čárový kód")

**Očekávaný výstup:** 2‑pixelová, třísloupcová PDF417 čárová značka, která kóduje text „Compact example“. Skenování PNG standardní čtečkou čárových kódů by mělo vrátit původní řetězec.

## Běžné varianty a okrajové případy

| Situace | Jak upravit kód |
|-----------|------------------------|
| **Delší data ( > 500 znaků )** | Zvyšte `Columns` na 5‑7, aby čárový kód nebyl příliš vysoký. |
| **Tisk s vyšším rozlišením** | Nastavte `XDimension.Pixels` na 3 nebo 4 pro větší moduly. |
| **Jiný formát obrázku** | Nahraďte `BarCodeImageFormat.Png` za `Jpeg` nebo `Bmp` podle potřeby. |
| **Vložení čárového kódu do PDF** | Použijte `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` místo PNG. |

**Pro tip:** Vždy testujte vygenerovaný čárový kód na cílovém skeneru. Některé levné skenery mají problémy s velmi malými X‑dimenzemi; pokud narazíte na chyby čtení, zvyšte hodnotu pixelů o jeden krok.

## Kompletní, spustitelný příklad

Níže je celý program, který můžete zkopírovat a vložit do nového konzolového projektu. Žádné další soubory nejsou potřeba.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Zkompilujte a spusťte program (`dotnet run`, pokud používáte .NET CLI). Po dokončení otevřete `CompactPdf417.png` a ověřte vizuální výsledek.

## Závěr

Nyní víte **jak generovat PDF417 čárový kód** v C# s kompaktním rozvržením, vlastní X‑dimenzí a nastavením sloupců. Příklad ukazuje základní kroky: vytvořit `BarcodeGenerator`, nakonfigurovat `XDimension` a `Columns`, povolit `Truncate` pro kompaktní režim a nakonec uložit obrázek.

Odtud můžete zkoumat další funkce, jako je úroveň korekce chyb, vlastní barvy nebo vložení čárového kódu přímo do PDF. Experimentujte s různými `EncodeTypes`, pokud potřebujete jiné symbologie (např. QR, Code128) a použijte stejný vzor konfigurace parametrů.

Šťastné programování a ať se vaše čárové kódy vždy načtou na první pokus!
