# Generování PDF417 čárového kódu s kompaktním nastavením v C#

Pokud potřebujete **generovat PDF417 čárový kód** v .NET aplikaci, tento průvodce vám ukáže, jak to provést pomocí Aspose.Barcode pro .NET. Provedeme vás vytvořením generátoru, nastavením sloupců, X‑dimenzí a povolením kompaktního režimu, aby výsledný symbol byl co nejmenší.

Generování PDF417 čárového kódu je běžné, když musíte zakódovat velké množství dat pro vstupenky, ID karty nebo přepravní štítky. Tento tutoriál pokrývá celý pracovní postup – od instalace knihovny až po uložení finálního PNG – takže můžete kód zkopírovat do svého projektu a spustit ho okamžitě.

## Požadavky pro generování PDF417 čárového kódu

Než začnete, ujistěte se, že máte:

* .NET 6.0 (nebo novější) nainstalováno.  
* Visual Studio 2022 nebo jakékoli IDE podporující C# projekty.  
* Licenci NuGet pro **Aspose.Barcode for .NET** (bezplatná zkušební verze funguje pro výuku).  

Knihovnu můžete přidat pomocí následujícího příkazu:

```bash
dotnet add package Aspose.BarCode
```

> **Tip:** Použijte příznak `--version` k připnutí známé stabilní verze, např. `dotnet add package Aspose.BarCode --version 23.12`.

## Vytvoření generátoru PDF417 čárového kódu

První blok kódu vytváří instanci `BarcodeGenerator`, která je předkonfigurovaná pro symbologii PDF417. Text `"Åspóse.Barcóde©"` obsahuje Unicode znaky, aby ukázal, že generátor zvládá vstup mimo ASCII bez dalších úprav.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Proč je to důležité
`EncodeTypes.Pdf417` říká Aspose.Barcode, že chcete **PDF417 čárový kód**, což je vrstvená lineární symbologie schopná uložit až 1 850 znaků. Použití konstruktoru s argumentem textu vám ušetří pozdější volání `SetCodeText`.

## Nastavení XDimension (velikost modulu) čárového kódu

Velikost modulu, také známá jako X‑dimenze, určuje, jak široký je každý jednotlivý pruh. Menší pixely vytvářejí hustší obrázek, zatímco větší pixely zlepšují čitelnost na tiskárnách s nízkým rozlišením.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### Proč byste měli upravit XDimension
Hodnota `2` pixely funguje dobře pro zobrazení na obrazovce a většinu kancelářských tiskáren. Pokud potřebujete tisk s vyšším rozlišením, hodnotu zvyšte; pokud chcete kompaktnější čárový kód (např. s vzhledem podobným QR), hodnotu snižte – ale nikdy pod `1` pixel, jinak se obrázek stane nečitelným.

## Nastavení počtu sloupců pro symbol PDF417

PDF417 vám umožňuje zvolit, kolik sloupců (vertikálních zásob) bude čárový kód mít. Méně sloupců vede k vyššímu čárovému kódu; více sloupců ho rozšiřuje do šířky.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### Kdy změnit počet sloupců
Tři sloupce vytvářejí kompaktní, téměř čtvercový symbol, který se dobře vejde na standardní ID karty. Pokud máte velmi dlouhý řetězec, můžete zvýšit počet sloupců, aby výška zůstala přiměřená.

## Povolení kompaktního režimu (zkrácení)

Kompaktní režim automaticky odstraňuje nevyužité řádky ze symbolu, čímž zmenšuje jeho celkovou velikost. To je zvláště užitečné, když zakódovaná data nevyplní celou mřížku.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Výhody kompaktního PDF417 čárového kódu
Když je `Truncate` nastaveno na `true`, generátor vypočítá minimální počet řádků potřebných k uložení vašich dat, což snižuje spotřebu inkoustu a dobu skenování. Je to bezpečné pro většinu skenerů, protože specifikace PDF417 definuje algoritmus zkrácení.

## Uložení vygenerovaného čárového kódu jako obrázku

Nakonec zapíšeme čárový kód do souboru PNG. PNG zachovává bezztrátovou kvalitu, což je ideální pro pozdější tisk nebo vkládání do PDF.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Očekávaný výstup
Spuštěním programu se ve zvoleném adresáři vytvoří soubor `CompactPdf417.png`. Obrázek obsahuje **kompaktní PDF417 čárový kód**, který kóduje řetězec `"Åspóse.Barcóde©"` se třemi sloupci, 2‑pixelovou X‑dimenzí a aplikovaným zkrácením. Výsledek můžete ověřit pomocí libovolné aplikace pro skenování čárových kódů nebo pomocí bezplatné online demonstrace Aspose.Barcode.

## Běžné varianty a okrajové případy

| Situace | Úprava |
|-----------|------------|
| **Velmi dlouhá data (> 1500 znaků)** | Zvyšte `Columns` nebo nastavte `Rows` ručně (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Tisk na tiskárně s nízkým DPI** | Zvyšte `XDimension.Pixels` na 3 nebo 4, aby nedošlo k pixelaci. |
| **Potřeba průhledného pozadí** | Použijte `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **Vkládání do PDF** | Uložte jako `BarCodeImageFormat.Pdf` nebo získejte objekt `Image` pomocí `pdf417Generator.GenerateBarCodeImage()`. |

## Kompletní, spustitelný příklad

Níže je kompletní program, který můžete zkopírovat do nového konzolového projektu. Žádné další soubory nejsou potřeba.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Spusťte `dotnet run` z adresáře projektu. Po dokončení otevřete `CompactPdf417.png` a podívejte se na vygenerovaný čárový kód.
