# Vytvořte planet barcode v C# – kompletní programovací průvodce

Pokud potřebujete **vytvořit planet barcode** v C#, tento průvodce vám ukáže přesně, jak na to. Také se dozvíte **jak nastavit rozměry čárového kódu**, aby pruhy měly přesně požadovanou šířku.

Generování planet barcode je běžné při práci s poštovními službami nebo logistickými systémy. Níže uvedený kód pokrývá jak výchozí verzi s vyplněnými pruhy, tak volitelný styl s prázdnými pruhy, plus rychlý příklad pro formát RM4SCC. Na konci tohoto tutoriálu budete mít znovupoužitelný úryvek, který můžete vložit do libovolného .NET projektu.

## Požadavky

Než začnete, ujistěte se, že máte:

* .NET 6.0 nebo novější nainstalovaný (API funguje také s .NET Framework 4.6+)
* NuGet balíček **Aspose.BarCode for .NET** (`Aspose.BarCode`) přidaný do vašeho projektu
* Zapisovatelnou složku, kam budou ukládány PNG soubory
* Základní znalosti syntaxe C# a Visual Studio (nebo jiného IDE)

> **Tip:** Použijte absolutní cestu nebo `Path.Combine(Environment.CurrentDirectory, "output")`, abyste předešli problémům s oprávněními při ukládání obrázků.

## Krok 1 – Inicializace generátoru Planet barcode (vyplněné pruhy)

Prvním krokem je vytvořit instanci `BarcodeGenerator` pro symbologii Planet. Ve výchozím nastavení generátor vytváří **vyplněné** pruhy.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Výčtový typ `EncodeTypes.Planet` říká Aspose.BarCode, aby použil formát Planet, zatímco `"123456"` je datová část, která bude zakódována.

## Krok 2 – Jak nastavit rozměry čárového kódu pro konzistentní velikost

Pro kontrolu šířky každého pruhu upravte **X‑dimenzi**. Toto je hlavní způsob, jak **nastavit rozměry čárového kódu**, a zajišťuje, že čárový kód zapadne do velikosti vašeho štítku.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

Vlastnost `Pixels` určuje šířku pruhu v pixelech obrazovky. Běžné hodnoty jsou 2 – 5 pixelů pro standardní poštovní štítky; zvýšte hodnotu pro větší výtisky.

## Krok 3 – Uložení vyplněného Planet barcode jako PNG

Nyní zapište obrázek na disk. PNG zachovává ostré hrany, což je ideální pro skenování.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Nahraďte `YOUR_DIRECTORY` cestou, kterou jste připravili dříve. Po spuštění tohoto kódu uvidíte soubor podobný obrázku níže.

## Krok 4 – Vytvoření Planet barcode s prázdnými (nevyplněnými) pruhy

Pokud vaše poštovní služba vyžaduje, aby pruhy byly **prázdné**, musíte po inicializaci generátoru přepnout příznak `FilledBars`.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Konstruktor je stejný; rozdíl spočívá v následujícím konfiguračním kroku.

## Krok 5 – Jak nastavit rozměry čárového kódu a udělat pruhy prázdné

Opět nastavte X‑dimenzi pro vizuální konzistenci a poté zakázat vyplněné pruhy.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

Vlastnost `FilledBars = false` je tím, co skutečně mění styl vykreslování. Zachování stejné X‑dimenze zajišťuje, že čárový kód s prázdnými pruhy se přesně zarovná s verzí s vyplněnými pruhy.

## Krok 6 – Uložení prázdného Planet barcode

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Nyní budete mít dva PNG soubory: jeden s plnými pruhy a jeden s dutými pruhy, oba se stejnými rozměry.

## Krok 7 – (Volitelné) Vygenerování RM4SCC barcode pro srovnání

RM4SCC je další poštovní symbologie, která používá stejný výchozí styl s vyplněnými pruhy. Kroky jsou obdobné jako u Planet příkladu, což ukazuje, že **jak nastavit rozměry čárového kódu** funguje napříč formáty.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Po spuštění těchto tří kroků vznikne soubor `PostalRM4SCCFilledBars.png`, který můžete porovnat vedle výstupů Planet.

## Proč je X‑dimenze důležitá

X‑dimenze určuje **minimální tisknutelnou šířku** každého pruhu. Pokud ji nastavíte příliš nízko, čárový kód může na nízkokvalitních tiskárnách rozmazat, což vede k selhání skenování. Naopak příliš velká X‑dimenze může překročit rozměry štítku a plýtvat prostorem. Tím, že explicitně **jak nastavit rozměry čárového kódu**, získáte deterministickou kontrolu nad konečnou velikostí obrázku, což je nezbytné pro automatizované poštovní workflow.

## Časté problémy a jak se jim vyhnout

| Problém | Příčina | Řešení |
|-------|-------|-----|
| Čárový kód vypadá roztaženě | X‑dimenze nastavena v bodech místo pixelů | Vždy používejte vlastnost `Pixels` pro pixel‑perfektní kontrolu |
| Prázdné pruhy stále vypadají vyplněně | `FilledBars` nebylo nastaveno na `false` po změně X‑dimenze | Nastavte `FilledBars = false` *po* úpravě X‑dimenze |
| Uložený soubor je prázdný | Výstupní adresář neexistuje nebo nemá oprávnění k zápisu | Zajistěte, aby adresář existoval (`Directory.CreateDirectory`) a aplikace měla dostatečná práva |
| Obrázek je na tisku rozmazaný | PNG s nízkým DPI uložený z monitoru s vysokým rozlišením | Použijte `BarCodeImageFormat.Png` (bezztrátový) a případně zvažte vlastnost `Resolution` |

## Kompletní, spustitelný příklad

Zkopírujte celý blok níže do nového konzolového projektu (`dotnet new console`) a spusťte jej. Program vytvoří tři PNG soubory ve složce `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Očekávaný výstup:** tři PNG soubory – `PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` a `PostalRM4SCCFilledBars.png` – každý s 4‑pixelovými širokými pruhy, připravený k tisku nebo dalšímu zpracování.

## Závěr

Nyní víte, jak **vytvořit planet barcode** v C# a přesně **jak nastavit rozměry čárového kódu** pro oba styly – vyplněné i prázdné pruhy. Stejný vzor platí i pro jiné symbologie, jako je RM4SCC, což vám poskytuje flexibilní základ pro jakýkoli požadavek na poštovní čárové kódy.

Dále můžete zkusit:

* Přidání lidsky čitelného textu pod čárový kód (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* Změnu barvy pruhů pomocí `Parameters.Barcode.BarColor`
* Generování čárových kódů ve vektorových formátech (SVG, EPS) pro škálovatelný tisk

Nebojte se experimentovat s různými hodnotami X‑dimenze, datovými řetězci a výstupními formáty, aby vyhovovaly vašemu konkrétnímu workflow. Šťastné programování!
