# Vytvoření barcode PNG v Pythonu – Kompletní průvodce

Už jste někdy potřebovali **create barcode PNG**, ale nebyli jste si jisti, kterou knihovnu nebo nastavení použít? Nejste v tom sami. V mnoha inventárních nebo pokladních systémech je první krok převést surová data na ostrý PNG obrázek, který skenery milují.  

V tomto tutoriálu si projdeme **how to generate databar**, jak **adjust barcode height**, a dokonce trik, jak **change barcode** parametry za běhu — vše při použití **barcode with sample data**, které můžete zkopírovat a vložit přímo do svého projektu.  

## Co se naučíte

## Create barcode PNG – Nastavení generátoru

Nejprve potřebujeme objekt generátoru, který ví, že pracujeme s čárovým kódem **DataBar Omnidirectional**. Níže uvedený kód importuje potřebné třídy, vytvoří generátor s **barcode with sample data** a nastaví skromnou velikost modulu.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Proč je to důležité:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` říká motoru, aby vytvořil **DataBar**, který lze číst z jakéhokoli směru, ideální pro regály v maloobchodu. Nastavení `x_dimension` udržuje čáry ostré, zatímco `bar_height` řídí vizuální velikost kódu.

## Jak generovat Databar s ukázkovými daty

Nyní, když je generátor připraven, **create barcode PNG** soubory. První uložení používá výšku 30 pixelů, což je často dostačující pro náhledy na obrazovce.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Spuštěním skriptu až k tomuto bodu získáte PNG soubor, který vypadá jako kompaktní, vysoce kontrastní čárový kód. Otevřete jej v libovolném prohlížeči obrázků a ověřte, že čáry jsou ostré a data GTIN‑14 jsou zakódována.

## Úprava výšky čárového kódu (How to Change Barcode)

Někdy potřebujete vyšší čárový kód pro větší štítky nebo tisk s vyšším rozlišením. Zde vstupuje do hry **adjust barcode height**. Změna výšky je tak jednoduchá jako aktualizace vlastnosti `BarHeight` a opětovné uložení.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Jak to funguje:** Generátor znovu použije stejná data a velikost modulu; mění se pouze vertikální rozměr. Tím se vyhnete znovuvytvoření celého objektu a ukazuje to **how to change barcode** nastavení dynamicky.

## Kompletní skript – Jedno‑stop řešení

Níže je kompletní spustitelný skript, který kombinuje všechny kroky. Zkopírujte, vložte a spusťte — měl by fungovat hned po instalaci balíčku.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Očekávaný výstup

Spuštěním skriptu se vygenerují dva soubory:

- `DatabarOmni30.png` – DataBar Omnidirectional čárový kód vysoký 30 px.  
- `DatabarOmni60.png` – verze stejného čárového kódu vysoká 60 px.

Obě obrázky jsou ve formátu PNG, bezztrátové, a připravené k vložení do PDF, HTML stránek nebo k přímému tisku na štítky.

## Časté problémy a profesionální tipy

- **Pixel vs. DPI:** PNG soubory jsou založeny na pixelech. Pokud potřebujete konkrétní velikost tisku, vypočítejte `BarHeight` na základě DPI (např. 300 dpi → 30 px ≈ 0,1 in).  
- **Incorrect encoding:** Ujistěte se, že řetězec dat odpovídá formátu GS1 Application Identifier (`(01)` pro GTIN‑14). Chybějící závorky mohou způsobit, že knihovna přejde na čistě číselný čárový kód.  
- **File paths:** Používejte raw řetězce (`r"..."`) nebo dvojité zpětné lomítka ve Windows, abyste se vyhnuli problémům s únikovými znaky.  
- **Performance:** Pokud generujete tisíce čárových kódů, vytvořte generátor jednou a mezi ukládáními pouze upravujte `BarHeight` nebo datový řetězec. Tím se sníží zatížení paměti.
