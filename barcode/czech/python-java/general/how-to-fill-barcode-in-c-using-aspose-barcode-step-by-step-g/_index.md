# Jak vyplnit čárový kód v C# pomocí Aspose.BarCode

Pokud potřebujete **jak vyplnit čárový kód** v .NET aplikaci, tento tutoriál ukazuje kompletní proces. Vygenerujete poštovní Planet čárový kód s plnými pruhy a poté vytvoříte verzi se prázdnými pruhy ze stejného kódu, vše s jednou změnou řádku kódu. Průvodce pokrývá vše, co potřebujete vědět: nastavení projektu, ladění X‑dimenze, přepínání mezi plnými a prázdnými pruhy a jak ověřit vygenerované PNG soubory. Není potřeba žádná externí dokumentace – stačí zkopírovat kód, spustit jej a uvidíte výsledek.

## Požadavky

* .NET 6.0 SDK nebo novější nainstalováno  
* Vývojové prostředí jako Visual Studio 2022 nebo VS Code  
* NuGet balíček **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

Tyto položky tvoří minimální základ pro část tutoriálu **barcode generator c#**.

## Jak vyplnit čárový kód – nastavení projektu

1. Vytvořte nový konzolový projekt:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Přidejte balíček Aspose.BarCode:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Otevřete vygenerovaný soubor `Program.cs` a nahraďte jeho obsah úplným příkladem uvedeným později v tomto článku.

Projekt nyní obsahuje vše potřebné k **generování poštovních čárových kódů** obrázků.

## Vygenerujte poštovní čárový kód s plnými pruhy

Prvním krokem je vytvořit Planet čárový kód, který používá vyplněné (plné) pruhy. Planet je symbolika používaná mnoha poštovními službami pro třídění.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Proč jsou tyto řádky důležité**

* `EncodeTypes.Planet` určuje generátoru, kterou symboliku použít; Planet je standard pro poštovní čárové kódy.  
* `XDimension.Pixels = 4` zvyšuje šířku modulu, což usnadňuje skenování čárového kódu a vizuálně jej činí jasnějším při tisku.  
* `Save` zapíše obrázek na disk ve formátu PNG, bezztrátovém formátu vhodném pro další zpracování.  

Spuštěním tohoto bloku se vytvoří **PostalPlanetFilledBars.png**, obrázek s plnými pruhy, který splňuje poštovní specifikace.

## Vytvořte prázdný čárový kód pomocí symboliky Planet

Někdy poštovní systém očekává, že pruhy budou prázdné (nevyplněné), zatímco mezery zůstanou plné. Přepnutí do tohoto režimu vyžaduje pouze změnu jedné vlastnosti.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Proč to funguje**

Nastavení `FilledBars = false` říká vykreslovacímu enginu, aby invertoval vizuální styl: pruhy se stanou průhlednými (prázdnými) a pozadí neprůhledným. To je přesný opak výchozího chování ukázaného dříve, což vám umožní **vytvořit prázdný čárový kód** obrázky bez změny kódovaných dat.

## Kompletní, spustitelný příklad

Níže je kompletní program, který kombinuje obě sekce. Zkopírujte jej do `Program.cs`, nahraďte `YOUR_DIRECTORY/` skutečnou cestou ke složce a spusťte `dotnet run`.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Očekávaný výstup

Po spuštění najdete ve zvoleném adresáři dva PNG soubory:

| Název souboru                     | Popis vizuálu |
|-----------------------------------|----------------|
| `PostalPlanetFilledBars.png`  | Pruhy jsou černé a plné na bílém pozadí |
| `PostalPlanetEmptyBars.png`   | Pruhy jsou průhledné (bílé) na černém pozadí |

Oba obrázky kódují stejný číselný řetězec "123456" a mají stejnou X‑dimenzi, což zajišťuje, že jsou zaměnitelné z hlediska validace dat.

## Časté otázky a okrajové případy

**Co když výstupní složka neexistuje?**  
Metoda `Save` vyvolá `DirectoryNotFoundException`. Vytvořte složku předem nebo obalte volání do bloku `try / catch`, který složku vytvoří, pokud je potřeba:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Mohu použít jiný formát obrázku?**  
Ano. Nahraďte `BarCodeImageFormat.Png` za `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` nebo jakýkoli formát podporovaný knihovnou Aspose.BarCode.

**Ovlivňuje X‑dimenze čitelnost skenerem?**  
Zvětšení šířky pixelu rozšiřuje pruhy, což může zlepšit čitelnost na skenerech s nízkým rozlišením. Nicméně velmi velké hodnoty mohou překročit tisknutelnou oblast. Typické hodnoty se pohybují od 2 do 6 pixelů pro tisk při 300 dpi.

**Je symbolika `EncodeTypes.Planet` jedinou poštovní možností?**  
Ne. Aspose.BarCode také podporuje `EncodeTypes.Postnet` a `EncodeTypes.USPSIntelligentMail`. Stejná vlastnost `FilledBars` funguje i s těmito typy.

## Závěr

Nyní víte, **jak vyplnit čárový kód** obrázky v C# pomocí knihovny Aspose.BarCode, **jak generovat poštovní čárové kódy** varianty a **jak vytvořit prázdný čárový kód** verze pomocí symboliky Planet. Úpravou X‑dimenze řídíte vizuální jasnost a jediná změna vlastnosti přepíná mezi plnými a prázdnými pruhy bez změny kódovaných dat. Odtud můžete zkoumat další funkce, jako je přidání lidsky čitelného textu, změna barev nebo vložení čárového kódu do PDF dokumentů. Všechny tyto rozšíření staví na stejných základech **barcode generator c#**, které jsou v tomto průvodci demonstrovány.
