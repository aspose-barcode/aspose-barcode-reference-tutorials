# Jak uložit obrázky čárových kódů v C# pomocí API BarcodeGenerator

Pokud potřebujete **how to save barcode** soubory z .NET aplikace, tento průvodce ukazuje přesné kroky. Uvidíte kompletní **barcode generator example**, který vytváří DataBar Stacked Omnidirectional čárový kód, upravuje jeho poměr stran a uloží dva PNG soubory.

Ukládání obrázků čárových kódů je běžnou požadavkem při tvorbě inventárních systémů, pokladních terminálů nebo automatizovaných štítkovacích workflow. Na konci tohoto tutoriálu budete schopni vygenerovat barcode C# kód, který vytváří spolehlivé obrázky připravené k tisku nebo zobrazení.

## Požadavky

- .NET 6.0 SDK nebo novější nainstalováno  
- Visual Studio 2022 (nebo jakékoli C#‑kompatibilní IDE)  
- NuGet balíček **Aspose.BarCode for .NET** (kód používá `Aspose.BarCode.Generation`)  

Můžete přidat balíček pomocí následujícího příkazu:

```bash
dotnet add package Aspose.BarCode
```

## Krok 1: Nastavte minimální C# konzolový projekt

Vytvořte nový konzolový projekt a odkažte knihovnu:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Otevřete `Program.cs`. Soubor bude obsahovat metodu `Main`, kde umístíme logiku **generate barcode C#**.

## Krok 2: Inicializujte BarcodeGenerator pro DataBar Stacked Omnidirectional čárový kód

Prvním úkolem v jakémkoli workflow **create databar barcode** je vytvořit instanci `BarcodeGenerator` s správným `EncodeType`. Konstruktor přijímá symbologii čárového kódu a datový řetězec.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

Hodnota `EncodeTypes.DatabarStackedOmniDirectional` říká knihovně, aby vytvořila **create databar barcode**, který lze skenovat z libovolného směru.

## Krok 3: Nastavte X‑dimenzi (šířka modulu)

X‑dimenze ovládá nejmenší šířku čáry v pixelech. Nastavením nízké hodnoty zůstane čárový kód kompaktní a zároveň zachová čitelnost.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Krok 4: **How to adjust aspect ratio** – první hodnota (15)

DataBar čárové kódy mají vlastnost `AspectRatio`, která ovlivňuje poměr výšky k šířce. Vyšší poměr vytváří vyšší čárový kód, což může zlepšit spolehlivost skenování na některých tiskárnách.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Krok 5: **How to save barcode** – první obrázek (poměr stran 15)

Nyní skutečně **how to save barcode** do souboru. Metoda `Save` přijímá cestu k souboru a formát obrázku. V tomto příkladu ukládáme PNG soubor.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Tip:** Adresář spustitelného souboru je výchozí místo zápisu. Použijte absolutní cestu, pokud potřebujete konkrétní složku.

## Krok 6: **How to adjust aspect ratio** – druhá hodnota (30)

Pro demonstraci flexibility změňte poměr stran a uložte druhý obrázek. To ukazuje, jak lze stejná zakódovaná data vykreslit s různými vizuálními proporcemi.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Spuštěním programu vzniknou dva PNG soubory:

- `DatabarAspectRatio15.png` – čárový kód se střední výškou  
- `DatabarAspectRatio30.png` – čárový kód s vyšší výškou pro náročné skenovací prostředí  

Oba soubory jsou připraveny k načtení do UI komponent, tisku na štítky nebo přenosu přes API.

### Očekávaný výstup

Když otevřete vygenerované obrázky, měli byste vidět DataBar Stacked Omnidirectional čárový kód, který kóduje hodnotu GTIN‑14 `12345678901231`. Vizuální rozdíl mezi dvěma soubory je výhradně výška, což potvrzuje, že **how to adjust aspect ratio** funguje podle očekávání.

## Krok 7: Kompletní zdrojový kód pro referenci

Níže je kompletní spustitelný program. Zkopírujte jej do `Program.cs`, sestavte a spusťte.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Časté otázky a řešení okrajových případů

### Co když cílová složka neexistuje?

`Save` vyvolá `DirectoryNotFoundException`. Vytvořte složku nejprve:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Jak změnit formát obrázku?

Nahraďte `BarCodeImageFormat.Png` za `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` nebo `BarCodeImageFormat.Tiff` podle požadavků downstream.

### Mohu generovat více čárových kódů ve smyčce?

Ano. Vytvořte novou instanci `BarcodeGenerator` pro každý datový řetězec nebo znovu použijte stejnou instanci po aktualizaci vlastnosti `CodeText`:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### Funguje **how to save barcode** na ne‑Windows platformách?

Aspose.BarCode je multiplatformní. Stejný kód běží na Linuxu a macOS, pokud je přítomen .NET runtime.
