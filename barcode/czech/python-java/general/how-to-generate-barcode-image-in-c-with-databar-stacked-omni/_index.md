# Jak vygenerovat obrázek čárového kódu v C# s DataBar Stacked Omni‑Directional

Pokud potřebujete **jak vygenerovat obrázek čárového kódu** v aplikaci .NET, tento tutoriál ukazuje přesné kroky. Uvidíte, jak vytvořit DataBar Stacked Omni‑Directional čárový kód, upravit jeho poměr stran a exportovat výsledek jako PNG soubory.

Generování čárových kódů je běžná potřeba pro inventární systémy, maloobchodní pokladny a logistické sledování. V následujících sekcích pokryjeme vše, co potřebujete – od požadovaného NuGet balíčku až po finální ověření obrázku – abyste mohli dnes integrovat tvorbu čárových kódů do libovolného C# projektu.

## Požadavky

Než začnete, ujistěte se, že máte:

* .NET 6.0 nebo novější (kód funguje s .NET Core i .NET Framework)
* Visual Studio 2022 nebo jakékoli C# IDE, které preferujete
* NuGet balíček **Aspose.BarCode for .NET** (nainstalujte pomocí `dotnet add package Aspose.BarCode`)
* Oprávnění k zápisu do složky, kam budou PNG soubory uloženy

Tyto předpoklady zaručují, že ukázka poběží bez další konfigurace.

## Krok 1: Nastavte výstupní složku

Prvním krokem je adresář, kam budou generované PNG soubory zapsány. Lze použít absolutní i relativní cestu, ale ujistěte se, že složka existuje před voláním `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Vytvoření složky programově zabraňuje výjimce *FileNotFoundException*, když metoda `Save` zkouší obrázek zapsat.

## Krok 2: Vytvořte generátor DataBar Stacked Omni‑Directional čárového kódu

Třída **BarcodeGenerator** je vstupním bodem pro všechny typy čárových kódů. Zde specifikujeme `EncodeTypes.DatabarStackedOmniDirectional` a datový řetězec, který chceme zakódovat.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Proč je to důležité*: Výčtový typ `EncodeTypes` říká knihovně, kterou symbologii má vykreslit. Použití varianty Omni‑Directional zajišťuje, že čárový kód lze skenovat z libovolné orientace – požadavek mnoha skladových skenerů.

## Krok 3: Nakonfigurujte společné parametry čárového kódu

Čitelný čárový kód potřebuje rozumnou X‑dimenzi (šířku nejmenšího pruhu). Nastavení `Pixels` na 2 poskytuje dobrý poměr mezi velikostí a ostrostí pro většinu rozlišení obrazovky.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

`Pixels` můžete později upravit, pokud potřebujete větší nebo menší obrázek; knihovna automaticky škáluje zbytek čárového kódu.

## Krok 4: Vygenerujte první obrázek s poměrem stran 15

**Poměr stran** řídí vztah výšky k šířce DataBar čárových kódů. Poměr 15 je typické výchozí nastavení pro maloobchodní štítky.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Po tomto volání najdete soubor `DatabarAspectRatio15.png` ve výstupní složce. Obrázek je bezztrátový PNG, vhodný pro další zpracování nebo tisk.

## Krok 5: Změňte poměr stran na 30 a exportujte druhý obrázek

Někdy je potřeba vyšší čárový kód – například když je výška štítku omezená. Změna poměru stran na 30 vytvoří kompaktnější vizuál při zachování integrity dat.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Nyní máte dva PNG soubory, které ukazují, jak stejná data vypadají s různými poměry stran. Toto vedle‑vedle srovnání vám pomůže rozhodnout, která varianta nejlépe zapadá do rozvržení vašeho štítku.

## Kompletní, spustitelný příklad

Níže je celý program, který můžete zkopírovat, vložit a spustit. Obsahuje všechny `using` direktivy, ošetření chyb a komentáře vysvětlující jednotlivé části procesu.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Očekávaný výstup** (konzole):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Otevřete oba PNG soubory v libovolném prohlížeči obrázků. Uvidíte stejný zakódovaný GTIN, ale druhý obrázek je vyšší kvůli vyššímu poměru stran.

## Tipy a časté úskalí

| Situace | Doporučení |
|-----------|----------------|
| **Nízké rozlišení displeje** | Zvyšte `XDimension.Pixels` na 3 nebo 4, aby pruhy zůstaly ostré. |
| **Tisk na termopapír** | Použijte `BarCodeImageFormat.Tiff` pro vyšší věrnost a nastavte `Resolution.DpiX/DpiY` na 300. |
| **Dynamická data** | Znovu použijte stejnou instanci `BarcodeGenerator` a před každým `Save` pouze aktualizujte `generator.CodeText`. Tím se vyhnete zbytečnému alokování objektů. |
| **Neplatný GTIN** | Knihovna vyhodí `ArgumentException`, pokud data nevyhovují standardům GS1. Ověřte svá data před předáním generátoru. |
