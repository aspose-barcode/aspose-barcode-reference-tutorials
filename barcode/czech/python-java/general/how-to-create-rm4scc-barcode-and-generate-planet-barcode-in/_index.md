# Jak vytvořit čárový kód RM4SCC a vygenerovat planet čárový kód v C#

Pokud potřebujete **vytvořit čárový kód RM4SCC** pro poštovní aplikace, tento návod vám ukáže přesné kroky. Také se naučíte, jak **vygenerovat planet čárový kód** s automatickou i pevnou výškou, takže stejný kód funguje pro jakoukoli poštovní symbologii.

Návod pokrývá vše potřebné k vytvoření PNG obrázků, které splňují poštovní standardy. Kromě knihovny Aspose.BarCode pro .NET nejsou potřeba žádné externí nástroje. Na konci budete schopni generovat čárové kódy programově a přesně řídit jejich rozměry.

## Požadavky

* .NET 6.0 nebo novější nainstalovaný
* Visual Studio 2022 (nebo jakékoli C# IDE)
* NuGet balíček Aspose.BarCode pro .NET `Install-Package Aspose.BarCode`
* Oprávnění k zápisu do výstupního adresáře

Tyto položky vám umožní zkompilovat a spustit ukázkový kód bez další konfigurace.

## Krok 1: Inicializace generátoru čárových kódů pro RM4SCC

První operace vytvoří instanci `BarcodeGenerator` nakonfigurovanou pro symbologii RM4SCC. Tento objekt obsahuje všechna nastavení pro obrázek čárového kódu.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Proč je to důležité** – `EncodeTypes.RM4SCC` říká Aspose, aby použil poštovní formát RM4SCC, zatímco datový řetězec `"123456"` představuje poštovní kód, který chcete zakódovat.

## Krok 2: Nastavení šířky modulu (X‑dimenze)

Šířka modulu řídí velikost tenké čáry. Běžná hodnota pro poštovní čárové kódy je 4 pixely.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Vysvětlení** – X‑dimenze ovlivňuje celkovou čitelnost čárového kódu. Volba 4 px odpovídá většině poštovních skenerů.

## Krok 3: Uložení s automatickou výškou čáry

Když vynecháte hodnotu výšky, Aspose automaticky vypočítá optimální výšku na základě pravidel symbologie.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Výsledek** – Vygenerovaný PNG (`PostalRM4SCCBarHeightNone.png`) obsahuje správně dimenzovaný čárový kód RM4SCC připravený k tisku.

## Krok 4: Vytvoření Planet čárového kódu s automatickou výškou

Stejný vzor funguje pro symbologii Planet. Začněte inicializací generátoru s `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Proč znovu použít kód** – RM4SCC i Planet sdílejí stejnou strukturu parametrů, takže můžete přepnout symbologie změnou pouze hodnoty `EncodeTypes`.

## Krok 5: Definování pevné výšky čáry pro RM4SCC

Některé poštovní služby vyžadují konkrétní výšku čáry (např. 100 px). Můžete ji nastavit explicitně před uložením.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Tip** – Nastavení `BarHeight.Pixels` přepíše automatický výpočet a poskytne vám plnou kontrolu nad vizuální velikostí.

## Krok 6: Definování pevné výšky čáry pro Planet

Použijte stejnou techniku pevné výšky na Planet čárový kód.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Výsledek** – Oba soubory `PostalRM4SCCBarHeight100Pixels.png` a `PostalPlanetBarHeight100Pixels.png` obsahují čárové kódy s konzistentní výškou 100 px, což splňuje přísné poštovní specifikace.

## Kompletní zdrojový kód

Níže je kompletní spustitelný program, který zahrnuje všechny čtyři příklady. Zkopírujte jej do nového konzolového projektu a podle potřeby upravte výstupní cestu.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Očekávaný výstup** – Po spuštění programu se v určeném adresáři nacházejí čtyři PNG soubory:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC s automatickou výškou
* `PostalPlanetBarHeightNone.png` – Planet s automatickou výškou
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC s výškou 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet s výškou 100 px

Otevřete libovolný soubor a ověřte, že čáry jsou ostré, šířka modulu je 4 px a výška odpovídá zvolenému nastavení.

## Časté otázky a okrajové případy

| Otázka | Odpověď |
|----------|--------|
| **Mohu použít jiné formáty obrázků?** | Ano. Nahraďte `BarCodeImageFormat.Png` za `Jpeg`, `Bmp` nebo `Gif` podle potřeby. |
| **Co když je datový řetězec delší?** | Generátor automaticky upraví počet čar. Ujistěte se, že data splňují délkové limity symbologie (RM4SCC ≤ 6 číslic, Planet ≤ 6 číslic). |
| **Jak změním barvu čáry?** | Nastavte `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` před voláním `Save`. |
| **Je DPI důležité pro tisk?** | Můžete nastavit `rm4sccAuto.Parameters.ImageResolution.DpiX` a `DpiY` tak, aby odpovídaly rozlišení vašeho tiskárny. |
