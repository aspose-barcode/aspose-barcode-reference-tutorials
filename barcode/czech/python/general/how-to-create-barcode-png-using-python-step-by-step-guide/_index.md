# Jak vytvořit barcode PNG pomocí Pythonu – krok‑za‑krokem průvodce

Pokud potřebujete **vytvořit barcode PNG** soubory z libovolných řetězců, tento tutoriál vám poskytne připravené řešení ke spuštění. Uvidíte přesně, jak vygenerovat čárový kód Code 128, převést text na obrázek čárového kódu a uložit výsledek jako PNG soubor – vše pomocí několika řádků Pythonu.

Průvodce pokrývá vše, co potřebujete vědět, od instalace požadované knihovny až po přizpůsobení výstupu pro různé případy použití. Na konci budete schopni vložit generování čárových kódů do libovolného Python projektu, aniž byste museli hledat další dokumentaci.

## Co se naučíte

* Nainstalovat balíček **barcode generator python**, který podporuje Code 128.  
* Použít `BarCodeGenerator` k **vytvoření code 128 barcode** z textového řetězce.  
* Uložit výsledek jako vysoce kvalitní PNG pomocí `save`.  
* Upravit velikost obrázku, barvy popředí/pozadí a řešit běžné chyby.  
* Ověřit, že PNG byl vytvořen správně.

### Předpoklady

| Požadavek | Důvod |
|-----------|-------|
| Python 3.8+ | Moderní syntaxe a typové nápovědy |
| Přístup k internetu (pro `pip install`) | Ke stažení knihovny |
| Oprávnění k zápisu do složky | K uložení vygenerovaného PNG |

Žádné externí služby nejsou vyžadovány; vše běží lokálně.

## Krok 1: Instalace knihovny pro čárový kód

Nejjednodušší způsob, jak **převést text na čárový kód** v Pythonu, je použít balíček **Aspose.BarCode for Python via .NET**, který podporuje Code 128 bez další konfigurace.

```bash
pip install aspose-barcode
```

> **Pro tip:** Pokud pracujete ve virtuálním prostředí, aktivujte jej před spuštěním příkazu, aby byly závislosti izolovány.

## Krok 2: Importujte potřebné třídy

Po instalaci importujte základní třídy. Importní příkazy jsou krátké, což usnadňuje čitelnost kódu.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` vytváří obrázek čárového kódu.  
* `EncodeTypes` poskytuje výčet podporovaných symbologií, včetně `CODE_128`.

## Krok 3: Definujte text, který chcete zakódovat

Zvolte libovolný alfanumerický řetězec. Code 128 dokáže reprezentovat celý ASCII soubor, takže nejste omezeni jen na čísla.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Pokud vstup obsahuje nepodporované znaky, generátor vyvolá `ValueError`. Zabalte přiřazení do bloku `try`, pokud očekáváte data od uživatele.

## Krok 4: Vytvořte generátor čárového kódu pro Code 128

Instancujte `BarCodeGenerator` s požadovanou symbologií a textem, který jste definovali. Toto je jádro **jak generovat čárový kód** obrázky v Pythonu.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Proč Code 128? Nabízí vysokou hustotu a může kódovat celý ASCII rozsah, což ho činí ideálním pro inventární systémy, přepravní štítky a vstupenky.

## Krok 5: (Volitelné) Přizpůsobení vzhledu

Můžete jemně doladit čárový kód před jeho uložením. Následující možnosti jsou běžné:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Tato nastavení ovlivňují finální **create barcode png** výstup, aniž by měnily zakódovaná data.

## Krok 6: Uložení čárového kódu jako PNG soubor

Nakonec zapíšete obrázek na disk. Metoda `save` automaticky detekuje příponu souboru, takže zadání `.png` vytvoří PNG obrázek.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Pokud cílový adresář neexistuje, Python vyvolá `FileNotFoundError`. Vytvořte adresář předem nebo použijte `os.makedirs` s `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### Očekávaný výstup

Po spuštění skriptu najdete `extended_barcode.png` ve složce `output`. Otevření souboru zobrazí ostrý Code 128 čárový kód, který kóduje `1234567890`.

![Generated barcode PNG created with Python](generated_barcode.png "create barcode png example")

## Krok 7: Ověření čárového kódu (rychlá kontrola)

Můžete načíst PNG zpět pomocí stejné knihovny a potvrdit, že zakódovaná hodnota odpovídá původnímu textu.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Spuštěním tohoto bloku se vypíše:

```
Verification succeeded: 1234567890
```

Pokud aserce selže, zkontrolujte `barcode_text` a jakékoli vlastní parametry, které jste nastavili.

## Běžné varianty a okrajové případy

| Situace | Úprava |
|---------|--------|
| **Delší text (> 20 znaků)** | Zvyšte `image_width`, aby nedošlo k oříznutí. |
| **Potřeba průhledného pozadí** | Nastavte `back_color = "Transparent"` před uložením. |
| **Generování více čárových kódů ve smyčce** | Zabalte kroky 3‑6 do `for` smyčky a měňte `barcode_text` v každé iteraci. |
| **Uložit jako JPEG místo PNG** | Změňte příponu souboru na `.jpg`; knihovna formát automaticky zpracuje. |
| **Běh na serveru bez grafického rozhraní** | Knihovna nevyžaduje GUI, takže je bezpečná pro CI pipeline. |

## Kompletní skript pro rychlé zkopírování

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Uložte skript jako `generate_barcode.py` a spusťte:

```bash
python generate_barcode.py
```

Uvidíte potvrzovací zprávy a nový PNG soubor ve složce `output`.
