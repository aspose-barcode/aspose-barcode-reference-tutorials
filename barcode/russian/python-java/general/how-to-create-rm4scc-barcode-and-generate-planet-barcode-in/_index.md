# Как создать штрих‑код RM4SCC и сгенерировать штрих‑код Planet в C#

Если вам нужно **создать штрих‑код RM4SCC** для почтовых приложений, это руководство покажет точные шаги. Вы также узнаете, как **сгенерировать штрих‑код Planet** с автоматической и фиксированной высотой, чтобы один и тот же код работал с любой почтовой символьной системой.

В этом руководстве рассматривается всё, что необходимо для создания PNG‑изображений, соответствующих почтовым стандартам. Не требуются внешние инструменты, кроме библиотеки Aspose.BarCode for .NET. По завершении вы сможете программно генерировать штрих‑коды и точно контролировать их размеры.

## Предварительные требования

* .NET 6.0 или новее установлен
* Visual Studio 2022 (или любой IDE для C#)
* Пакет NuGet Aspose.BarCode for .NET  
  `Install-Package Aspose.BarCode`
* Разрешение на запись в каталог вывода

Эти элементы позволяют компилировать и запускать пример кода без дополнительной конфигурации.

## Шаг 1: Инициализация генератора штрих‑кода для RM4SCC

Первая операция создаёт экземпляр `BarcodeGenerator`, настроенный для символьной системы RM4SCC. Этот объект хранит все параметры изображения штрих‑кода.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Почему это важно** – `EncodeTypes.RM4SCC` указывает Aspose использовать почтовый формат RM4SCC, а строка данных `"123456"` представляет почтовый индекс, который вы хотите закодировать.

## Шаг 2: Установить ширину модуля (X‑размер)

Ширина модуля определяет размер тонкой полосы. Обычное значение для почтовых штрих‑кодов — 4 пикселя.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Объяснение** – X‑размер влияет на общую читаемость штрих‑кода. Выбор 4 px соответствует большинству почтовых сканеров.

## Шаг 3: Сохранить с автоматической высотой полосы

Если не указывать значение высоты, Aspose автоматически рассчитывает оптимальную высоту в соответствии с правилами символьной системы.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Результат** – Сгенерированный PNG (`PostalRM4SCCBarHeightNone.png`) содержит правильно размеренный штрих‑код RM4SCC, готовый к печати.

## Шаг 4: Создать штрих‑код Planet с автоматической высотой

Тот же шаблон работает для символьной системы Planet. Начните с инициализации генератора с `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Почему повторно использовать код** – И RM4SCC, и Planet используют одинаковую структуру параметров, поэтому можно переключать символьные системы, изменив лишь значение `EncodeTypes`.

## Шаг 5: Задать фиксированную высоту полосы для RM4SCC

Некоторые почтовые службы требуют конкретную высоту полосы (например, 100 px). Вы можете задать её явно перед сохранением.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Совет** – Установка `BarHeight.Pixels` переопределяет автоматический расчёт, предоставляя полный контроль над визуальным размером.

## Шаг 6: Задать фиксированную высоту полосы для Planet

Примените ту же технику фиксированной высоты к штрих‑коду Planet.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Результат** – Оба файла `PostalRM4SCCBarHeight100Pixels.png` и `PostalPlanetBarHeight100Pixels.png` содержат штрих‑коды с одинаковой высотой полосы 100 px, соответствующей строгим почтовым требованиям.

## Полный исходный код

Ниже представлен полный, исполняемый пример программы, охватывающий все четыре примера. Скопируйте его в новый консольный проект и при необходимости измените путь вывода.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Ожидаемый результат** – После запуска программы указанный каталог содержит четыре PNG‑файла:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC с автоматической высотой
* `PostalPlanetBarHeightNone.png` – Planet с автоматической высотой
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC с высотой 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet с высотой 100 px

Откройте любой файл, чтобы убедиться, что полосы чёткие, ширина модуля 4 px, а высота соответствует выбранной настройке.

## Часто задаваемые вопросы и особые случаи

| Вопрос | Ответ |
|----------|--------|
| **Можно ли использовать другие форматы изображений?** | Да. Замените `BarCodeImageFormat.Png` на `Jpeg`, `Bmp` или `Gif` при необходимости. |
| **Что делать, если строка данных длиннее?** | Генератор автоматически корректирует количество полос. Убедитесь, что данные соответствуют ограничениям длины символьной системы (RM4SCC ≤ 6 цифр, Planet ≤ 6 цифр). |
| **Как изменить цвет полос?** | Установите `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` перед вызовом `Save`. |
| **Важен ли DPI при печати?** | Вы можете задать `rm4sccAuto.Parameters.ImageResolution.DpiX` и `DpiY`, чтобы соответствовать разрешению вашего принтера. |
