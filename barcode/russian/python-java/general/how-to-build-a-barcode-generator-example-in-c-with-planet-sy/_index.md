# Пример генератора штрихкодов на C# – создание штрихкода Planet и изображения штрихкода

Если вам нужен **пример генератора штрихкодов** на C#, это руководство покажет, как именно сгенерировать штрихкод Planet и создать изображение штрихкода c# всего в несколько строк кода. Вы увидите полностью готовое решение, которое можно вставить в любой проект .NET.

Штрихкод Planet используется почтовыми службами для кодирования информации о маршруте. К концу этого руководства вы поймёте, почему библиотека автоматически определяет высоту штрихкода, как управлять размером X и как сохранить результат в файл PNG. Внешние инструменты не требуются — только пакет Aspose.BarCode for .NET и среда разработки .NET.

## Требования

Прежде чем начать, убедитесь, что у вас есть:

* .NET 6.0 SDK или более поздняя версия  
* Visual Studio 2022 (или любая IDE, поддерживающая .NET)  
* NuGet‑пакет **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

Пакет можно установить из командной строки:

```bash
dotnet add package Aspose.BarCode
```

## Шаг 1: Инициализация генератора штрихкода для кодировки Planet

Первый шаг в любом **примере генератора штрихкодов** — создать экземпляр `BarcodeGenerator` и указать тип кодировки. Для штрихкода Planet используется `EncodeTypes.Planet` и передаётся строка данных, которую нужно закодировать.

```csharp
using Aspose.BarCode.Generation;

// Create a Planet barcode generator with the data to encode
BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

**Почему это важно:** Перечисление `EncodeTypes.Planet` сообщает библиотеке использовать символьную систему Planet, имеющую фиксированный шаблон модулей, требуемый почтовыми стандартами. Передача данных (`"123456"` в данном случае) гарантирует, что штрихкод содержит правильный числовой код маршрута.

## Шаг 2: Настройка измерения X (ширина модуля) в пикселях

Измерение X управляет шириной каждого отдельного модуля (самой маленькой полоски). Его изменение меняет общий размер штрихкода, не влияя на читаемость.

```csharp
// Set the X dimension (module width) to 4 pixels
generator.Parameters.Barcode.XDimension.Pixels = 4;
```

**Почему это важно:** Большое измерение X даёт более крупный штрихкод, что может быть полезно при печати на больших конвертах. Библиотека автоматически масштабирует высоту, чтобы сохранить правильное соотношение сторон для штрихкодов Planet.

## Шаг 3: Сохранение изображения штрихкода на диск

Наконец, сохраняем сгенерированное изображение. Библиотека определяет оптимальную высоту, поэтому вам нужно указать только путь к файлу и формат.

```csharp
using Aspose.BarCode;

// Define the output file path
string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";

// Save the barcode as a PNG image
generator.Save(outputFile, BarCodeImageFormat.Png);
```

**Почему это важно:** Сохранение в PNG сохраняет чёткие края штрихкода, что критично для надёжного сканирования. Метод `Save` также поддерживает другие форматы (JPEG, BMP, TIFF), если нужен иной тип вывода.

## Шаг 4: Необязательно – настройка цветов переднего и заднего плана

Если вашему приложению нужен иной визуальный стиль, вы можете изменить цвета штрихкода перед сохранением.

```csharp
// Set foreground (bars) to dark blue and background to light gray
generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

// Save the customized image
generator.Save(@"C:\Barcodes\PlanetCustomColors.png", BarCodeImageFormat.Png);
```

**Совет:** Всегда проверяйте настроенный штрихкод реальным сканером, чтобы убедиться, что изменение цвета не влияет на читаемость.

## Шаг 5: Обработка ошибок и проверка валидности

Библиотека Aspose.BarCode бросает `ArgumentException`, если данные не соответствуют требованиям символьной системы Planet (например, содержат нечисловые символы). Оберните код генерации в блок try‑catch, чтобы предоставить понятную обратную связь.

```csharp
try
{
    BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "ABC123");
    generator.Save(@"C:\Barcodes\InvalidPlanet.png", BarCodeImageFormat.Png);
}
catch (ArgumentException ex)
{
    Console.WriteLine($"Invalid data for Planet barcode: {ex.Message}");
}
```

**Почему это важно:** Штрихкоды Planet принимают только числовые данные определённой длины. Правильная проверка предотвращает ошибки во время выполнения и экономит время при интеграционном тестировании.

## Полный, готовый к запуску пример

Объединив все шаги, получаем автономную программу, которую можно скопировать, вставить и запустить.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;
using Aspose.BarCode;

class Program
{
    static void Main()
    {
        // Step 1: Initialize the generator with Planet encoding
        BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");

        // Step 2: Set the X dimension (module width) to 4 pixels
        generator.Parameters.Barcode.XDimension.Pixels = 4;

        // Optional: customize colors (comment out if not needed)
        // generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
        // generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

        // Step 3: Save the barcode image
        string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";
        generator.Save(outputFile, BarCodeImageFormat.Png);

        Console.WriteLine($"Planet barcode saved to {outputFile}");
    }
}
```

Скомпилируйте и запустите программу:

```bash
dotnet run
```

Вы увидите сообщение в консоли, подтверждающее путь к файлу, а PNG‑файл будет содержать сгенерированный штрихкод Planet.

## Распространённые варианты и граничные случаи

| Вариант | Как реализовать | Когда использовать |
|-----------|------------------|------------|
| **Другая длина данных** | Изменить второй аргумент в `new BarcodeGenerator(EncodeTypes.Planet, "987654321")` | Почтовые службы, требующие более длинных номеров маршрутов |
| **Более высокое разрешение** | Установить `generator.Parameters.ImageResolution = 300;` перед `Save` | Печать на принтерах с высоким DPI |
| **Другой формат изображения** | Использовать `BarCodeImageFormat.Jpeg` или `BarCodeImageFormat.Tiff` | Когда PNG не подходит для вашего рабочего процесса |
| **Динамическое имя файла** | `string outputFile = Path.Combine(folder, $"Planet_{DateTime.Now:yyyyMMdd_HHmmss}.png");` | Пакетная обработка множества штрихкодов |

## Профессиональные советы для надёжного примера генератора штрихкодов

* **Повторно используйте экземпляр генератора** при создании множества штрихкодов с одинаковыми настройками; меняйте только `EncodeTypes` или строку данных для повышения производительности.  
* **Проверяйте входные данные** перед передачей их в `BarcodeGenerator`. Простое регулярное выражение `^\d{6,9}$` гарантирует соответствие требованиям Planet.  
* **Освобождайте ресурсы**, если генерируете тысячи изображений в длительно работающем сервисе. `BarcodeGenerator` реализует `IDisposable`, поэтому оборачивайте его в `using`, когда это уместно.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, data))
{
    // configure and save...
}
```
