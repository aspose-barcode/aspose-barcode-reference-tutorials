# Как заполнить штрих‑код в C# с помощью Aspose.BarCode

Если вам нужно **заполнить штрих‑код** в приложении .NET, этот учебник покажет полный процесс. Вы сгенерируете почтовый штрих‑код Planet со сплошными полосами, а затем создадите версию того же штрих‑кода с пустыми полосами, изменив лишь одну строку кода.

В руководстве рассматривается всё, что необходимо знать: настройка проекта, регулировка X‑размера, переключение между заполненными и пустыми полосами и проверка полученных PNG‑файлов. Внешняя документация не требуется — просто скопируйте код, запустите его и увидите результат.

## Предварительные требования

Прежде чем начать, убедитесь, что у вас есть:

* .NET 6.0 SDK или более поздняя версия  
* Среда разработки, например Visual Studio 2022 или VS Code  
* NuGet‑пакет **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

Эти элементы составляют минимальный набор для части учебника, посвящённой **генератору штрих‑кодов c#**.

## Как заполнить штрих‑код – настройка проекта

1. Создайте новый консольный проект:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Добавьте пакет Aspose.BarCode:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Откройте сгенерированный файл `Program.cs` и замените его содержимое полным примером, показанным ниже в этой статье.

Теперь проект содержит всё необходимое для **генерации почтовых штрих‑кодов**.

## Генерация почтового штрих‑кода со сплошными полосами

Первый шаг — создать штрих‑код Planet, использующий заполненные (сплошные) полосы. Planet — это символьный набор, применяемый многими почтовыми службами для сортировки.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Почему эти строки важны**

* `EncodeTypes.Planet` указывает генератору, какой символьный набор использовать; Planet — стандарт для почтовых штрих‑кодов.  
* `XDimension.Pixels = 4` увеличивает ширину модуля, делая штрих‑код легче считываемым и визуально более чётким при печати.  
* `Save` сохраняет изображение на диск в формате PNG, который является без потерь и подходит для дальнейшей обработки.

Выполнение этого блока создаёт **PostalPlanetFilledBars.png** — изображение со сплошными полосами, соответствующее почтовым требованиям.

## Создание пустого штрих‑кода с использованием символьного набора Planet

Иногда почтовая система ожидает, что полосы будут пустыми (не заполненными), а пробелы — сплошными. Переключиться в этот режим можно, изменив лишь одно свойство.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Почему это работает**

Установка `FilledBars = false` сообщает рендереру инвертировать визуальный стиль: полосы становятся прозрачными (пустыми), а фон — непрозрачным. Это точный противоположный вариант поведения по умолчанию, продемонстрированного ранее, позволяющий **создавать пустые штрих‑коды** без изменения закодированных данных.

## Полный, готовый к запуску пример

Ниже представлен полный код программы, объединяющий оба раздела. Скопируйте его в `Program.cs`, замените `YOUR_DIRECTORY/` реальным путём к папке и выполните `dotnet run`.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Ожидаемый результат

После выполнения вы найдёте два PNG‑файла в указанной папке:

| Имя файла                     | Описание визуального вида |
|-------------------------------|---------------------------|
| `PostalPlanetFilledBars.png`  | Полосы чёрные сплошные на белом фоне |
| `PostalPlanetEmptyBars.png`   | Полосы прозрачные (белые) на чёрном фоне |

Оба изображения кодируют одну и ту же числовую строку `"123456"` и используют одинаковый X‑размер, что гарантирует их взаимозаменяемость с точки зрения проверки данных.

## Часто задаваемые вопросы и особые случаи

**Что делать, если папка назначения не существует?**  
Метод `Save` бросает `DirectoryNotFoundException`. Создайте папку заранее или оберните вызовы в блок `try / catch`, который при необходимости создаст каталог:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Можно ли использовать другой формат изображения?**  
Да. Замените `BarCodeImageFormat.Png` на `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` или любой другой формат, поддерживаемый Aspose.BarCode.

**Влияет ли X‑размер на читаемость сканером?**  
Увеличение ширины в пикселях делает полосы шире, что может улучшить читаемость на сканерах с низким разрешением. Однако слишком большие значения могут выйти за пределы печатной области. Обычные значения находятся в диапазоне от 2 до 6 пикселей при печати 300 dpi.

**Является ли символьный набор `EncodeTypes.Planet` единственным почтовым вариантом?**  
Нет. Aspose.BarCode также поддерживает `EncodeTypes.Postnet` и `EncodeTypes.USPSIntelligentMail`. Свойство `FilledBars` работает и с этими типами.

Регулируя X‑размер, вы контролируете визуальную чёткость, а переключение одного свойства меняет стиль полос без изменения закодированных данных.
