# Как сгенерировать изображение штрихкода в C# с DataBar Stacked Omni‑Directional

Если вам нужно **как сгенерировать изображение штрихкода** в .NET‑приложении, этот учебник покажет точные шаги. Вы увидите, как создать штрихкод DataBar Stacked Omni‑Directional, настроить его соотношение сторон и экспортировать результат в виде PNG‑файлов.

Генерация штрихкодов — распространённая задача для систем учёта, кассовых терминалов розничной торговли и отслеживания логистики. В следующих разделах мы рассмотрим всё необходимое — от требуемого NuGet‑пакета до финальной проверки изображения — чтобы вы могли интегрировать создание штрихкодов в любой C#‑проект уже сегодня.

## Предварительные требования

Прежде чем начать, убедитесь, что у вас есть:

* .NET 6.0 или новее (код работает с .NET Core и .NET Framework)
* Visual Studio 2022 или любая другая IDE для C#
* NuGet‑пакет **Aspose.BarCode for .NET** (установить с помощью `dotnet add package Aspose.BarCode`)
* Права записи в папку, куда будут сохраняться PNG‑файлы

Эти требования гарантируют, что пример запустится без дополнительной настройки.

## Шаг 1: Создать папку вывода

Первое, что нужно — это каталог, в который будут записываться сгенерированные PNG‑файлы. Подойдёт как абсолютный, так и относительный путь, но убедитесь, что папка существует до вызова `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Создание папки программно предотвращает *FileNotFoundException*, когда метод `Save` пытается записать изображение.

## Шаг 2: Создать генератор штрихкода DataBar Stacked Omni‑Directional

Класс **BarcodeGenerator** является точкой входа для всех типов штрихкодов. Здесь мы указываем `EncodeTypes.DatabarStackedOmniDirectional` и строку данных, которую хотим закодировать.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Почему это важно*: Перечисление `EncodeTypes` сообщает библиотеке, какой символьный набор отрисовать. Вариант Omni‑Directional гарантирует, что штрихкод можно сканировать в любой ориентации — требование многих складских сканеров.

## Шаг 3: Настроить общие параметры штрихкода

Читаемый штрихкод требует разумного X‑размера (ширины самой маленькой полоски). Установка `Pixels` в 2 обеспечивает хороший баланс между размером и чёткостью для большинства экранов.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

При необходимости вы можете изменить `Pixels` позже, если нужен более крупный или более мелкий образ; библиотека автоматически масштабирует остальные элементы штрихкода.

## Шаг 4: Сгенерировать первое изображение с соотношением сторон 15

**Соотношение сторон** управляет отношением высоты к ширине штрихкодов DataBar. Значение 15 — типичный дефолт для розничных этикеток.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

После выполнения этого вызова в папке вывода появится файл `DatabarAspectRatio15.png`. Изображение сохраняется в безупречном PNG‑формате, пригодном для дальнейшей обработки или печати.

## Шаг 5: Изменить соотношение сторон на 30 и экспортировать второе изображение

Иногда требуется более высокий штрихкод — например, когда высота этикетки ограничена. Установка соотношения сторон в 30 даёт более компактный визуальный вид при сохранении целостности данных.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Теперь у вас есть два PNG‑файла, показывающих, как одни и те же данные выглядят при разных соотношениях сторон. Такое сравнение помогает выбрать вариант, лучше всего подходящий под ваш макет этикетки.

## Полный, готовый к запуску пример

Ниже приведена полная программа, которую можно скопировать, вставить и запустить. В ней включены все директивы `using`, обработка ошибок и комментарии, поясняющие каждый шаг процесса.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Ожидаемый вывод** (консоль):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Откройте оба PNG‑файла в любом просмотрщике изображений. Вы увидите один и тот же закодированный GTIN, но второе изображение будет выше из‑за большего соотношения сторон.

## Полезные советы и типичные подводные камни

| Ситуация | Рекомендация |
|-----------|----------------|
| **Низкоразрешающие дисплеи** | Увеличьте `XDimension.Pixels` до 3 или 4, чтобы линии оставались чёткими. |
| **Печать на термобумаге** | Используйте `BarCodeImageFormat.Tiff` для более высокого качества и задайте `Resolution.DpiX/DpiY` = 300. |
| **Динамические данные** | Переиспользуйте один экземпляр `BarcodeGenerator` и меняйте только `generator.CodeText` перед каждым `Save`. Это избавит от лишних аллокаций объектов. |
| **Недействительный GTIN** | Библиотека бросает `ArgumentException`, если данные не соответствуют стандартам GS1. Проверьте данные перед передачей их генератору. |
