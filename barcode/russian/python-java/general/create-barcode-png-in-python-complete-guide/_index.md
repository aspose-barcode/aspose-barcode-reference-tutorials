# Create barcode PNG в Python – Полное руководство

Когда‑нибудь вам нужно было **create barcode PNG**, но вы не знали, какую библиотеку или настройки использовать? Вы не одиноки. Во многих системах учёта или касс первый шаг — превратить сырые данные в чёткое PNG‑изображение, которое любят сканеры.  

В этом руководстве мы пройдёмся по **how to generate databar**, как **adjust barcode height**, и даже покажем трюк, как **change barcode** параметры «на лету» — всё это с использованием **barcode with sample data**, который вы можете скопировать‑вставить прямо в свой проект.  

## Что вы узнаете

- Установить библиотеку Aspose.BarCode (или аналогичную) для Python.  
- **Create barcode PNG** файлы с разными высотами всего в несколько строк кода.  
- **How to change barcode** свойства, такие как размер модуля и высота штрих‑кода.  
- Использовать реалистичное значение GTIN‑14 в качестве **barcode with sample data**.  
- Советы по устранению распространённых проблем, таких как размытые изображения или некорректное кодирование.

Предыдущий опыт генерации штрихкодов не требуется — достаточно базового интерпретатора Python и возможности установить pip‑пакет.

## Необходимые условия

- Python 3.8+ установлен на вашем компьютере.  
- Доступ к интернету для установки пакета `aspose-barcode` (или любой совместимой библиотеки).  
- Папка с правом записи, куда будут сохраняться PNG‑файлы (замените `YOUR_DIRECTORY` в скрипте).  

Если у вас уже всё есть, отлично — давайте приступим.

## Create barcode PNG – Настройка генератора

Во‑первых, нам нужен объект‑генератор, который понимает, что мы работаем с штрих‑кодом **DataBar Omnidirectional**. Приведённый ниже код импортирует необходимые классы, создаёт генератор с **barcode with sample data** и задаёт скромный размер модуля.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Почему это важно:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` указывает движку создавать **DataBar**, который можно считывать из любого направления, что идеально подходит для полок в розничной торговле. Установка `x_dimension` сохраняет чёткость линий, а `bar_height` контролирует визуальный размер кода.

## Как сгенерировать Databar с образцовыми данными

Теперь, когда генератор готов, мы **create barcode PNG** файлы. Первая сохранённая версия использует высоту 30 пикселей, что часто достаточно для предварительного просмотра на экране.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Запуск скрипта до этого момента создаст PNG‑файл, выглядящий как компактный, высококонтрастный штрих‑код. Откройте его в любом просмотрщике изображений, чтобы убедиться, что линии чёткие и данные GTIN‑14 закодированы.

## Регулировка высоты штрих‑кода (How to Change Barcode)

Иногда требуется более высокий штрих‑код для больших этикеток или печати с более высоким разрешением. Здесь в дело вступает **adjust barcode height**. Изменить высоту так же просто, как обновить свойство `BarHeight` и снова сохранить.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Как это работает:** Генератор повторно использует те же данные и размер модуля; меняется только вертикальное измерение. Это позволяет избежать повторного создания объекта и демонстрирует **how to change barcode** параметры динамически.

## Полный скрипт — универсальное решение

Ниже представлен полный, исполняемый скрипт, объединяющий все шаги. Скопируйте, вставьте и запустите — он должен работать сразу после установки пакета.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Ожидаемый результат

Запуск скрипта создаст два файла:

- `DatabarOmni30.png` — DataBar Omnidirectional штрих‑код высотой 30 px.  
- `DatabarOmni60.png` — версия того же штрих‑кода высотой 60 px.

Оба изображения в формате PNG, без потерь, и готовы к встраиванию в PDF, HTML‑страницы или прямой печати на этикетках.

## Распространённые ошибки и профессиональные советы

- **Pixel vs. DPI:** PNG‑файлы основаны на пикселях. Если нужен конкретный размер печати, вычислите `BarHeight` исходя из DPI (например, 300 dpi → 30 px ≈ 0.1 in).  
- **Incorrect encoding:** Убедитесь, что строка данных соответствует формату идентификатора приложения GS1 (`(01)` для GTIN‑14). Отсутствие скобок может привести к тому, что библиотека вернёт обычный числовой штрих‑код.  
- **File paths:** Используйте raw‑строки (`r"..."`) или двойные обратные слэши в Windows, чтобы избежать проблем с экранированием.  
- **Performance:** При генерации тысяч штрих‑кодов создавайте объект‑генератор один раз и меняйте только `BarHeight` или строку данных между сохранениями. Это снижает нагрузку на память.
