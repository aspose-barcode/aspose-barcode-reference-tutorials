# Как сохранять изображения штрихкодов в C# с помощью API BarcodeGenerator

Если вам нужно **how to save barcode** файлы из .NET‑приложения, это руководство покажет точные шаги. Вы увидите полный **barcode generator example**, который создает штрихкод DataBar Stacked Omnidirectional, регулирует его соотношение сторон и сохраняет два PNG‑файла.

Сохранение изображений штрихкодов — распространённое требование при создании систем учёта, точек продаж или автоматизированных процессов маркировки. К концу этого руководства вы сможете генерировать barcode C# код, который создаёт надёжные изображения, готовые к печати или отображению.

## Требования

- .NET 6.0 SDK или более поздняя версия, установленная  
- Visual Studio 2022 (или любая IDE, совместимая с C#)  
- Пакет NuGet **Aspose.BarCode for .NET** (в коде используется `Aspose.BarCode.Generation`)  

Вы можете добавить пакет следующей командой:

```bash
dotnet add package Aspose.BarCode
```

## Шаг 1: Создать минимальный консольный проект C#

Создайте новый консольный проект и подключите библиотеку:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Откройте `Program.cs`. Файл будет содержать метод `Main`, где мы разместим логику **generate barcode C#**.

## Шаг 2: Инициализировать BarcodeGenerator для штрихкода DataBar Stacked Omnidirectional

Первая задача в любом процессе **create databar barcode** — создать экземпляр `BarcodeGenerator` с правильным `EncodeType`. Конструктор принимает тип символьного набора штрихкода и строку данных.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

Значение `EncodeTypes.DatabarStackedOmniDirectional` указывает библиотеке создавать **create databar barcode**, который можно сканировать из любого направления.

## Шаг 3: Настроить X‑dimension (ширина модуля)

X‑dimension управляет минимальной шириной полосы в пикселях. Установка небольшого значения сохраняет штрихкод компактным, не ухудшая читаемость.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Шаг 4: **How to adjust aspect ratio** – первое значение (15)

Штрихкоды DataBar предоставляют свойство `AspectRatio`, которое влияет на соотношение высоты к ширине. Более высокое значение дает более высокий штрихкод, что может улучшить надёжность сканирования на некоторых принтерах.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Шаг 5: **How to save barcode** – первое изображение (соотношение сторон 15)

Теперь мы действительно **how to save barcode** в файл. Метод `Save` принимает путь к файлу и формат изображения. В этом примере мы сохраняем PNG‑файл.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Подсказка:** Каталог исполняемого файла является расположением по умолчанию для записи. Используйте абсолютный путь, если нужен конкретный каталог.

## Шаг 6: **How to adjust aspect ratio** – второе значение (30)

Чтобы продемонстрировать гибкость, измените соотношение сторон и сохраните второе изображение. Это показывает, как одни и те же закодированные данные могут отображаться с разными визуальными пропорциями.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Запуск программы создаёт два PNG‑файла:

- `DatabarAspectRatio15.png` – штрихкод со средней высотой  
- `DatabarAspectRatio30.png` – штрихкод с большей высотой для сложных условий сканирования  

Оба файла готовы к загрузке в элементы управления UI, печати на этикетках или передачи через API.

### Ожидаемый результат

При открытии сгенерированных изображений вы должны увидеть штрихкод DataBar Stacked Omnidirectional, кодирующий значение GTIN‑14 `12345678901231`. Визуальная разница между двумя файлами заключается только в высоте, подтверждая, что **how to adjust aspect ratio** работает как задумано.

## Шаг 7: Полный исходный код для справки

Ниже приведена полная, готовая к запуску программа. Скопируйте её в `Program.cs`, соберите и запустите.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Часто задаваемые вопросы и обработка граничных случаев

### Что делать, если целевая папка не существует?

`Save` генерирует `DirectoryNotFoundException`. Сначала создайте каталог:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Как изменить формат изображения?

Замените `BarCodeImageFormat.Png` на `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` или `BarCodeImageFormat.Tiff` в зависимости от требований downstream.

### Могу ли я генерировать несколько штрихкодов в цикле?

Да. Создайте новый `BarcodeGenerator` для каждой строки данных или переиспользуйте тот же экземпляр, обновив свойство `CodeText`:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### Работает ли **how to save barcode** на платформах, отличных от Windows?

Aspose.BarCode кросс‑платформенный. Один и тот же код работает на Linux и macOS, при условии наличия .NET runtime.
