# Создание штрих‑кода Planet в C# – полное руководство по программированию

Если вам нужно **создать штрих‑код planet** в C#, это руководство покажет, как это сделать. Вы также узнаете, **как задать размеры штрих‑кода**, чтобы полосы имели точную требуемую ширину.

Генерация штрих‑кодов Planet часто требуется при работе с почтовыми службами или логистическими системами. Приведённый ниже код охватывает как стандартный вариант с заполненными полосами, так и опциональный стиль с пустыми полосами, а также быстрый пример для формата RM4SCC. К концу этого урока у вас будет переиспользуемый фрагмент, который можно вставить в любой проект .NET.

## Требования

Прежде чем начать, убедитесь, что у вас есть:

* .NET 6.0 или новее (API также работает с .NET Framework 4.6+)
* NuGet‑пакет **Aspose.BarCode for .NET** (`Aspose.BarCode`) добавлен в ваш проект
* Папка, в которую можно записывать файлы PNG
* Базовые знания синтаксиса C# и Visual Studio (или любой другой IDE)

> **Полезный совет:** используйте абсолютный путь или `Path.Combine(Environment.CurrentDirectory, "output")`, чтобы избежать проблем с правами доступа при сохранении изображений.

## Шаг 1 – Инициализация генератора штрих‑кода Planet (заполненные полосы)

Первый шаг – создать экземпляр `BarcodeGenerator` для символьного набора Planet. По умолчанию генератор создаёт **заполненные** полосы.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Перечисление `EncodeTypes.Planet` указывает Aspose.BarCode использовать формат Planet, а `"123456"` – это данные, которые будут закодированы.

## Шаг 2 – Как задать размеры штрих‑кода для единообразия

Чтобы контролировать ширину каждой полосы, настройте **X‑dimension**. Это основной способ **задать размеры штрих‑кода** и гарантировать, что он впишется в размер вашей этикетки.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

Свойство `Pixels` определяет ширину полосы в пикселях экрана. Обычные значения – 2 – 5 пикселей для стандартных почтовых этикеток; увеличьте значение для более крупных печатных материалов.

## Шаг 3 – Сохранение заполненного штрих‑кода Planet в PNG

Теперь запишем изображение на диск. PNG сохраняет чёткие границы, что идеально для сканирования.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Замените `YOUR_DIRECTORY` на путь, который вы подготовили ранее. После выполнения кода вы увидите файл, похожий на изображение ниже.

## Шаг 4 – Создание штрих‑кода Planet с пустыми (не заполненными) полосами

Если ваша почтовая служба требует **пустые** полосы, нужно переключить флаг `FilledBars` после инициализации генератора.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Конструктор остаётся тем же; различие проявляется в следующем шаге настройки.

## Шаг 5 – Как задать размеры штрих‑кода и сделать полосы пустыми

Снова задаём X‑dimension для визуального соответствия, затем отключаем заполненные полосы.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

Свойство `FilledBars = false` именно меняет стиль отрисовки. Сохраняя ту же X‑dimension, вы гарантируете, что штрих‑код с пустыми полосами будет точно совпадать по размеру с заполненным вариантом.

## Шаг 6 – Сохранение пустого штрих‑кода Planet

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

В результате у вас будет два PNG‑файла: один с сплошными полосами, другой с полыми, оба с одинаковыми размерами.

## Шаг 7 – (Опционально) Генерация штрих‑кода RM4SCC для сравнения

RM4SCC – ещё один почтовый символьный набор, использующий тот же стиль заполненных полос по умолчанию. Шаги повторяют пример с Planet, демонстрируя, что **как задать размеры штрих‑кода** работает и для других форматов.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Выполнение этих трёх шагов создаст `PostalRM4SCCFilledBars.png`, который можно сравнить бок о бок с результатами Planet.

## Почему X‑dimension важна

X‑dimension определяет **минимальную печатную ширину** каждой полосы. Если задать её слишком маленькой, штрих‑код может размыться на принтерах низкого разрешения, что приведёт к ошибкам сканирования. Слишком большая X‑dimension может превысить размеры этикетки и занять лишнее пространство. Явно задавая **как задать размеры штрих‑кода**, вы получаете детерминированный контроль над конечным размером изображения, что критично для автоматизированных почтовых процессов.

## Распространённые ошибки и способы их избежать

| Проблема | Причина | Решение |
|----------|---------|---------|
| Штрих‑код выглядит растянутым | X‑dimension задан в пунктах вместо пикселей | Всегда используйте свойство `Pixels` для пиксель‑точного контроля |
| Пустые полосы выглядят заполненными | `FilledBars` не установлен в `false` после изменения X‑dimension | Установите `FilledBars = false` *после* настройки X‑dimension |
| Сохранённый файл пустой | Папка вывода не существует или нет прав на запись | Убедитесь, что папка существует (`Directory.CreateDirectory`) и приложение имеет достаточные права |
| Изображение размыто при печати | PNG сохранён с низким DPI с монитора высокого разрешения | Используйте `BarCodeImageFormat.Png` (без потерь) и при необходимости задайте свойство `Resolution` |

## Полный, готовый к запуску пример

Скопируйте весь блок ниже в новый консольный проект (`dotnet new console`) и запустите его. Программа создаст три PNG‑файла в папке `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Ожидаемый результат:** три PNG‑файла — `PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` и `PostalRM4SCCFilledBars.png` — каждая полоса шириной 4 пикселя, готовые к печати или дальнейшей обработке.
