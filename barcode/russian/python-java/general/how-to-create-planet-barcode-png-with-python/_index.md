# Как создать PNG штрих‑кода Planet с помощью Python

Если вам нужно **создать PNG штрих‑кода Planet**, этот учебник проведёт вас через весь процесс с использованием Python. Вы также узнаете **как пошагово генерировать штрих‑код Planet**, настроить его внешний вид и сохранить результат в виде PNG‑изображения высокого качества.

Генерация штрих‑кода Planet часто используется в почтовой автоматизации, учёте запасов и логистических системах. К концу руководства у вас будет автономный скрипт, который создаёт готовый к использованию PNG‑файл, а также понимание того, как адаптировать код под разные размеры или форматы изображений.

## Предварительные требования

Прежде чем начать, убедитесь, что у вас есть:

* Python 3.8 или новее.
* Доступ к пакету `aspose-barcode` (или любой совместимой библиотеке, предоставляющей классы `BarcodeGenerator`, `EncodeTypes` и `BarCodeImageFormat`).
* Права записи в каталог, где вы планируете сохранять PNG‑файл.

Установить необходимую библиотеку можно с помощью pip:

```bash
pip install aspose-barcode
```

> **Pro tip:** Используйте виртуальное окружение, чтобы изолировать зависимости от других проектов.

## Полный разбор кода для создания PNG штрих‑кода Planet

Следующий скрипт демонстрирует каждый шаг, необходимый для генерации PNG штрих‑кода Planet с пустыми (не заполненными) полосами. Скопируйте код в файл с именем `planet_barcode.py` и запустите его командой `python planet_barcode.py`.

```python
# planet_barcode.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Initialize a Planet barcode generator with the data to encode
# The data "123456" is a typical numeric payload for postal services.
generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

# Step 2: Set the width of each bar (X dimension) to 4 pixels.
# Adjusting the X dimension changes the overall size and readability.
generator.parameters.barcode.x_dimension.pixels = 4

# Step 3: Configure the barcode to use empty (unfilled) bars.
# When `filled_bars` is False, the dark bars become transparent,
# which is useful for overlaying the barcode on colored backgrounds.
generator.parameters.barcode.filled_bars = False

# Step 4: Save the generated barcode as a PNG image.
# The output path can be absolute or relative; ensure the folder exists.
output_path = "output/PostalPlanetEmptyBars.png"
generator.save(output_path, BarCodeImageFormat.PNG)

print(f"Planet barcode PNG saved to: {output_path}")
```

### Что делает каждая строка

| Строка | Пояснение |
|------|-------------|
| `from aspose.barcode import ...` | Импортирует классы, необходимые для создания и настройки штрих‑кода. |
| `BarcodeGenerator(EncodeTypes.Planet, "123456")` | Создаёт генератор для символьного набора **Planet**, используя числовую строку `"123456"`. |
| `x_dimension.pixels = 4` | Устанавливает ширину полосы в 4 px; большие значения дают более крупный штрих‑код, а меньшие уменьшают размер файла. |
| `filled_bars = False` | Переключает штрих‑код на **пустые полосы**, делая тёмные модули прозрачными. |
| `save(..., BarCodeImageFormat.PNG)` | Сохраняет штрих‑код в PNG‑файл, сохраняя без потерь. |
| `print(...)` | Подтверждает успешное создание в консоли. |

## Как генерировать штрих‑код Planet с пользовательскими настройками

Хотя базовый скрипт покрывает большинство сценариев, вам может потребоваться адаптировать штрих‑код под конкретные требования:

1. **Разные длины данных** – Штрих‑коды Planet поддерживают до 12 числовых символов. Замените `"123456"` любой допустимой числовой строкой в этом диапазоне.
2. **Альтернативные форматы изображений** – Замените `BarCodeImageFormat.PNG` на `BarCodeImageFormat.JPEG` или `BarCodeImageFormat.BMP` в зависимости от последующей обработки.
3. **Изменение X‑размера** – Большие значения (например, `8`) создают штрих‑код более высокого разрешения, что полезно при печати больших этикеток.
4. **Цвета фона** – Если нужен цветной фон, задайте `generator.parameters.barcode.back_color` перед сохранением.

Пример с пользовательским цветом фона:

```python
from aspose.barcode import Color

generator.parameters.barcode.back_color = Color.get_yellow()
generator.save("output/PlanetYellowBackground.png", BarCodeImageFormat.PNG)
```

## Частые ошибки и как их избежать

| Проблема | Причина | Решение |
|-------|--------|-----|
| **FileNotFoundError** при сохранении | Целевой каталог не существует. | Создайте каталог заранее (`os.makedirs("output", exist_ok=True)`). |
| **Invalid data length** | Штрих‑код Planet принимает только числовые данные длиной до 12 символов. | Проверьте строку ввода перед созданием генератора. |
| **Transparent bars not visible** | Некоторые просмотрщики игнорируют прозрачность на белом холсте. | Разместите штрих‑код на фоне, отличном от белого, или экспортируйте PNG с альфа‑каналом. |

## Проверка результата

После выполнения скрипта откройте `PostalPlanetEmptyBars.png` в любом просмотрщике изображений. Вы должны увидеть серию вертикальных полос, где тёмные модули прозрачны, оставляя лишь контур штрих‑кода. Чтобы убедиться, что штрих‑код сканируем, используйте мобильное приложение‑сканер, поддерживающее символьный набор Planet.

Если изображение выглядит пустым, проверьте:

* Флаг `filled_bars` установлен в `False`.
* X‑размер не равен нулю.
* Путь вывода указывает на существующую папку.
