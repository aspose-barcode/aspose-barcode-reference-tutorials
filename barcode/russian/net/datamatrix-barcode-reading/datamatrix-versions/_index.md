# Как генерировать штрихкоды DataMatrix с помощью Aspose.BarCode для .NET

Если вам нужен надёжный способ внедрять машинно‑читаемые символы в ваши .NET‑приложения, **как генерировать DataMatrix** штрихкоды является распространённым требованием. Aspose.BarCode для .NET предлагает полностью управляемый API, который обрабатывает каждый шаг — от выбора правильной версии DataMatrix до тонкой настройки уровней коррекции ошибок — без необходимости внешних инструментов. В этом руководстве мы пройдём полный пример, объясним, почему каждый параметр важен, и покажем, как сохранить результат в виде изображения PNG или JPEG.

## Быстрые ответы
- **Какая библиотека создаёт штрихкоды DataMatrix?** Aspose.BarCode for .NET.  
- **Сколько версий DataMatrix поддерживается?** Все 30 стандартных квадратных и прямоугольных версий (от 10×10 до 144×144 модулей).  
- **Какие типы ECC я могу использовать?** ECC200 (по умолчанию) и ECC140.  
- **Нужна ли лицензия для разработки?** Бесплатная 30‑дневная trial‑версия подходит для тестирования; коммерческая лицензия требуется для продакшна.  
- **Можно ли запускать это на .NET 6, .NET Core или .NET Framework?** Да — Aspose.BarCode поддерживает .NET Framework 4.5+, .NET Core 3.1+ и .NET 5/6+.

## Что такое штрихкод DataMatrix?
Штрихкод DataMatrix — это двумерная квадратная или прямоугольная матрица черных и белых ячеек, способная хранить до 2 335 буквенно-цифровых символов. Он широко используется в производстве, логистике и здравоохранении для маркировки небольших предметов, поскольку остаётся читаемым даже при частичном повреждении.

## Почему использовать Aspose.BarCode для .NET?
Aspose.BarCode поддерживает **более 50 форматов вывода** (включая PNG, JPEG, TIFF, SVG и PDF) и может генерировать **все 30 версий DataMatrix** без загрузки полного изображения в память, позволяя создавать штрихкоды в высокопроизводительных сервисах, обрабатывающих файлы размером более 100 МБ.

Теперь давайте изучим версии DataMatrix и то, как их генерировать с помощью Aspose.BarCode для .NET.

## Как генерировать штрихкоды DataMatrix в .NET?

Загрузите `BarcodeGenerator` с типом `EncodeTypes.DataMatrix`, задайте нужную версию и ECC, затем вызовите `Save` для записи файла изображения. Этот однострочный шаблон работает для любой выбранной версии и автоматически обрабатывает размер модулей, зоны тишины и рендеринг изображения.

## Импорт пространств имён

`BarcodeGenerator` — основной класс Aspose.BarCode для создания изображений штрихкодов.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

Пространство имён `Aspose.BarCode.Generation` предоставляет доступ к классу `BarcodeGenerator`, который является основным классом для генерации изображений штрихкодов.

Теперь разберём пример на несколько шагов.

## Шаг 1: настройте путь к каталогу

Begin by defining the directory path where you want to save the generated DataMatrix barcodes.

```csharp
string path = "Your Directory Path";
```

Замените `"Your Directory Path"` на фактический путь, где вы хотите сохранять изображения штрихкодов.

## Шаг 2: инициализировать генератор штрихкодов

Create an instance of the `BarcodeGenerator` class and specify the barcode type as `DataMatrix`. You can also provide the data that you want to encode within the barcode.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` — основной класс, создающий и визуализирующий символы штрихкодов.

## Шаг 3: настроить свойства штрихкода

Вы можете настраивать различные свойства штрихкода DataMatrix, такие как его размеры и тип ECC (Error Correction Code). Ниже пример установки X‑dimension в 4 пикселя и выбора ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` задаёт размер каждого модуля в пикселях, а `DataMatrixEcc` выбирает уровень коррекции ошибок.

## Шаг 4: задать версию DataMatrix и сохранить

Вы можете указать версию DataMatrix, задав количество строк и столбцов. После настройки версии сохраните изображение штрихкода.

Например, чтобы создать штрихкод DataMatrix с 22 строками и 22 столбцами, используя ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

Аналогично, вы можете генерировать штрихкод с другими параметрами, изменяя версию и тип ECC по необходимости.

## Шаг 5: повторить для других версий

Вы можете повторить Шаг 4 для других версий DataMatrix. Например, создать штрихкод с 12 строками и 64 столбцами, используя ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Шаг 6: переключить типы ECC

Если вы хотите изменить тип ECC на Ecc140, сделайте это, обновив свойство ECC:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Шаг 7: генерировать штрихкоды с разными версиями и ECC

Повторите Шаг 4 для других версий DataMatrix и типов ECC, сохраняя каждый штрихкод под уникальным именем файла.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

## Распространённые подводные камни и советы по устранению неполадок
- **Неправильные размеры версии** — версии DataMatrix имеют фиксированные пары строк/столбцов. Указание несовпадающей пары (например, 10 × 20) вызовет `ArgumentException`. Всегда используйте одну из поддерживаемых комбинаций, перечисленных в документации API.  
- **Отсутствующая лицензия** — в trial‑режиме сгенерированные изображения содержат водяной знак. Примените действующую лицензию с помощью `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` перед созданием генератора, чтобы удалить водяной знак. Класс `License` загружает файл лицензии для активации продукта.  
- **Большой размер изображения** — если требуется вывод высокого разрешения, увеличьте свойство `XDimension`; библиотека масштабирует изображение пропорционально без потери читаемости.
