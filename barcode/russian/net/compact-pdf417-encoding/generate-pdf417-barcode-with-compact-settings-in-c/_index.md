# Генерация штрих‑кода PDF417 с компактными настройками в C#

Если вам нужно **создать штрих‑код PDF417** в приложении .NET, это руководство покажет, как сделать это с помощью Aspose.Barcode for .NET. Мы пройдемся по созданию генератора, настройке колонок, X‑размера и включению компактного режима, чтобы полученный символ был как можно меньше.

Создание штрих‑кода PDF417 часто требуется, когда нужно закодировать большие объёмы данных для билетов, удостоверений или транспортных этикеток. В этом учебнике рассматривается весь процесс — от установки библиотеки до сохранения конечного PNG‑файла — чтобы вы могли скопировать‑вставить код в свой проект и сразу запустить его.

## Предварительные требования для генерации штрих‑кода PDF417

Прежде чем начать, убедитесь, что у вас есть:

* .NET 6.0 (или новее) установлен.  
* Visual Studio 2022 или любая IDE, поддерживающая проекты C#.  
* Лицензия NuGet для **Aspose.Barcode for .NET** (бесплатная пробная версия подходит для обучения).  

Библиотеку можно добавить следующей командой:

```bash
dotnet add package Aspose.BarCode
```

> **Pro tip:** Используйте флаг `--version`, чтобы зафиксировать известную стабильную версию, например, `dotnet add package Aspose.BarCode --version 23.12`.

## Создание генератора штрих‑кода PDF417

Первый блок кода создает экземпляр `BarcodeGenerator`, предварительно настроенный для символьного набора PDF417. Текст `"Åspóse.Barcóde©"` содержит Unicode‑символы, чтобы продемонстрировать, что генератор обрабатывает ввод не‑ASCII «из коробки».

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Почему это важно
`EncodeTypes.Pdf417` сообщает Aspose.Barcode, что вы хотите **штрих‑код PDF417**, который представляет собой многослойный линейный символьный набор, способный хранить до 1 850 символов. Использование конструктора с аргументом текста экономит последующий вызов `SetCodeText`.

## Установка XDimension (размера модуля) штрих‑кода

Размер модуля, также известный как X‑размер, определяет ширину каждой отдельной полосы. Меньшие пиксели дают более плотное изображение, а большие — повышают читаемость на принтерах с низким разрешением.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### Почему стоит регулировать XDimension
Значение `2` пикселя хорошо подходит для отображения на экране и большинства офисных принтеров. Если нужен печатный вывод более высокого разрешения, увеличьте значение; если нужен более компактный штрих‑код (например, похожий на QR‑код), уменьшите его — но никогда не ниже `1` пикселя, иначе изображение станет нечитаемым.

## Установка количества колонок для символа PDF417

PDF417 позволяет выбрать, сколько колонок (вертикальных стеков) будет у штрих‑кода. Меньшее количество колонок делает штрих‑код выше; больше колонок — шире.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### Когда менять количество колонок
Три колонки дают компактный, почти квадратный символ, который удобно размещать на стандартных удостоверениях. Если у вас очень длинная строка, можно увеличить количество колонок, чтобы высота оставалась приемлемой.

## Включение компактного режима (усечение)

Компактный режим автоматически удаляет неиспользуемые строки из символа, уменьшая его общий размер. Это особенно полезно, когда закодированные данные не заполняют всю матрицу.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Преимущества компактного штрих‑кода PDF417
Когда `Truncate` установлен в `true`, генератор вычисляет минимальное количество строк, необходимое для хранения ваших данных, что снижает расход чернил и время сканирования. Это безопасно для большинства сканеров, поскольку спецификация PDF417 определяет алгоритм усечения.

## Сохранение сгенерированного штрих‑кода как изображения

Наконец, записываем штрих‑код в PNG‑файл. PNG сохраняет без потерь, что делает его идеальным для последующей печати или встраивания в PDF.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Ожидаемый результат
Запуск программы создаст `CompactPdf417.png` в указанной папке. На изображении будет **компактный штрих‑код PDF417**, кодирующий строку `"Åspóse.Barcóde©"` с тремя колонками, X‑размером 2 пикселя и включённым усечением. Вы можете проверить результат любой программой‑сканером штрих‑кодов или бесплатной онлайн‑демо‑версией Aspose.Barcode.

## Общие варианты и граничные случаи

| Ситуация | Корректировка |
|-----------|------------|
| **Очень длинные данные (> 1500 символов)** | Увеличьте `Columns` или задайте `Rows` вручную (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Печать на принтере с низким DPI** | Повышайте `XDimension.Pixels` до 3 или 4, чтобы избежать пикселизации. |
| **Необходим прозрачный фон** | Используйте `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **Встраивание в PDF** | Сохраните как `BarCodeImageFormat.Pdf` или получите объект `Image` через `pdf417Generator.GenerateBarCodeImage()`. |

## Полный, готовый к запуску пример

Ниже представлена полная программа, которую можно скопировать в новый консольный проект. Дополнительные файлы не требуются.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Запустите `dotnet run` из папки проекта. После выполнения откройте `CompactPdf417.png`, чтобы увидеть сгенерированный штрих‑код.
