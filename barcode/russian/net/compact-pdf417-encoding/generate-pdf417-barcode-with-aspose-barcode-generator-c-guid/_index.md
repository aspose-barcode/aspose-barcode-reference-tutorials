# Создание штрих‑кода PDF417 с помощью Aspose Barcode Generator – руководство на C# 

Если вам нужно **создать штрих‑код PDF417** в проекте .NET, этот учебник покажет, как сделать это с помощью **Aspose Barcode Generator**. Вы увидите полностью готовый пример, который создает компактный символ PDF417, настраивает его размер и сохраняет результат в файл PNG.  

Создание штрих‑кода PDF417 часто требуется, когда нужно закодировать большие объёмы данных — такие как URL‑адреса, контактную информацию или записи инвентаря — в одно сканируемое изображение. В этом руководстве рассматривается всё: от установки библиотеки до настройки параметров **how to set PDF417** для компактного вывода.  

## Что вы узнаете

* Установить и подключить библиотеку Aspose.BarCode в проект C#.  
* Использовать **aspose barcode generator** для создания символа PDF417 из произвольного текста.  
* Применить параметры **how to set PDF417** — размер модуля, количество столбцов и компактный режим.  
* Сохранить штрих‑код как изображение PNG и проверить результат.  

**Требования**

* .NET 6.0 SDK или новее (код также работает с .NET Core 3.1 и .NET Framework 4.7+).  
* Базовое знакомство с консольными приложениями C#.  
* Действительная лицензия Aspose.BarCode (бесплатная оценочная версия подходит для разработки).

## Шаг 1: Создание штрих‑кода PDF417 – создание генератора

Первая задача — создать экземпляр генератора с нужным текстом и символьным набором PDF417. Этот шаг напрямую отвечает на вопрос **how to generate pdf417**.  

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Create a BarcodeGenerator for PDF417 with the data you want to encode.
            // The EncodeTypes enum selects the symbology; Pdf417 is the target type.
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");
```

**Почему это важно:**  

`EncodeTypes.Pdf417` указывает библиотеке использовать алгоритм PDF417, который поддерживает до 1 850 символов. Конструктор также принимает строку исходных данных; любые символы Unicode (включая акценты) обрабатываются автоматически.  

## Шаг 2: Как задать параметры PDF417 – настройка размера и макета

Штрих‑код PDF417 может быть отрисован в разных формах. Настройка параметров **how to set pdf417** позволяет создать компактный символ, который помещается на небольшую этикетку или экран мобильного устройства.  

```csharp
            // -----------------------------------------------------------------
            // Step 2: Set visual parameters for the barcode
            // -----------------------------------------------------------------

            // Module size – each tiny square (pixel) of the barcode.
            // Smaller values produce a tighter image; 2 pixels is a good default.
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Number of columns – controls the width of the barcode.
            // Fewer columns make the symbol taller; 3 columns yields a compact shape.
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode – removes unnecessary quiet zones and reduces height.
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Объяснение каждой настройки**

| Параметр | Эффект | Когда использовать |
|-----------|--------|---------------------|
| `XDimension.Pixels` | Управляет шириной одного модуля. Меньшие значения уменьшают штрих‑код, но могут ухудшить читаемость сканером на устройствах с низким разрешением. | Используйте `2`–`4` для отображения на экране; увеличьте для печатных этикеток. |
| `Pdf417.Columns` | Определяет количество столбцов данных в символе. Меньшее количество столбцов дает более высокий и узкий штрих‑код. | Выбирайте `3`–`5` для компактных макетов; большие значения — для более широких штрих‑кодов. |
| `Pdf417.Truncate` | Включает «компактный режим», который удаляет внешнюю тихую зону и уменьшает общую высоту. | Идеально для элементов UI, где пространство ограничено. |

Эти три настройки вместе отвечают на часть задачи **how to set pdf417**, предоставляя тонкий контроль над конечным изображением.  

## Шаг 3: Сохранить изображение штрих‑кода – экспорт в PNG

После настройки генератора необходимо записать штрих‑код в файл. Метод `Save` поддерживает множество форматов; PNG сохраняет качество без потерь и хорошо подходит как для веб‑, так и для настольных сценариев.  

```csharp
            // -----------------------------------------------------------------
            // Step 3: Save the generated barcode as a PNG image
            // -----------------------------------------------------------------

            // Replace YOUR_DIRECTORY with an actual folder on your machine.
            string outputPath = @"C:\Barcodes\CompactPdf417.png";

            // BarCodeImageFormat.Png tells Aspose to write a PNG file.
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            // Inform the user that the process succeeded.
            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**Что вы должны увидеть**  

Запуск программы создаёт `CompactPdf417.png` в указанной папке. Изображение содержит плотный символ PDF417, кодирующий строку `Åspóse.Barcóde©`. Большинство сканеров штрих‑кодов и мобильных приложений (например, ZXing, Scandit) могут прочитать это изображение без дополнительной настройки.  

## Полный исходный код – один файл, готовый к копированию

Ниже приведена полная программа, включая директивы `using` и метод `Main`. Вы можете скопировать её в новый консольный проект и сразу запустить.  

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Step 1: Create the generator (how to generate pdf417)
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");

            // Step 2: Set PDF417 options (how to set pdf417)
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;   // module size
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;    // number of columns
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact mode

            // Step 3: Save as PNG
            string outputPath = @"C:\Barcodes\CompactPdf417.png";
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**Запуск кода**

1. Откройте терминал и создайте новый консольный проект:  
   `dotnet new console -n Pdf417Demo`  
2. Добавьте пакет NuGet Aspose.BarCode:  
   `dotnet add package Aspose.BarCode`  
3. Замените сгенерированный `Program.cs` кодом выше.  
4. Соберите и запустите:  
   `dotnet run`  

Вы должны увидеть сообщение подтверждения и найти файл PNG в указанном месте.  

## Распространённые подводные камни и рекомендации по лучшим практикам

* **Срок действия лицензии** – Оценочная версия добавляет водяной знак через 30 дней. Зарегистрируйте лицензию заранее, чтобы избежать сюрпризов.  
* **Разрешения каталога** – Убедитесь, что целевая папка существует и процесс имеет права на запись; иначе `Save` бросит `UnauthorizedAccessException`.  
* **Совместимость сканера** – Если сканер не может прочитать компактный штрих‑код, увеличьте `XDimension.Pixels` до `4` или установите `Truncate = false`.  
* **Обработка Unicode** – Aspose.BarCode полностью поддерживает UTF‑8; вы можете кодировать любую строку Unicode без дополнительных шагов.  
* **Производительность** – При генерации множества штрих‑кодов в цикле выгодно переиспользовать один экземпляр `BarcodeGenerator` и лишь обновлять `CodeText` между итерациями.
