# Как создать штрих‑код PDF417 с помощью Aspose – Полное пошаговое руководство

Вы когда‑нибудь задумывались **как создать PDF417** штрих‑код с помощью Aspose, не просеивая разбросанную документацию? Вы не одиноки. Многие разработчики сталкиваются с проблемой, когда нужно вложить обширные метаданные в символ Macro PDF417 и в итоге пишут код методом проб и ошибок, который никогда не работает должным образом.

Дело в том, что Aspose.BarCode for .NET упрощает весь процесс, как только вы знаете, какие свойства установить. В этом руководстве мы пройдём полностью рабочий пример на C#, который создаёт штрих‑код Macro PDF417, заполняет все необязательные поля метаданных и сохраняет результат в виде PNG‑изображения. К концу вы получите чёткое представление о **как создать PDF417** штрих‑коды, содержащие идентификатор файла, количество сегментов, метки времени и даже пользовательские строки отправителя/получателя.

## Требования – Что понадобится

- **.NET 6.0** или новее (API работает одинаково на .NET Framework 4.8, но мы будем использовать .NET 6 для актуальности).  
- **Aspose.BarCode for .NET** пакет NuGet – установить с помощью `dotnet add package Aspose.BarCode`.  
- Базовая среда разработки C# (Visual Studio 2022, Rider или VS Code).  
- Папка на диске, куда будет записан PNG – убедитесь, что приложение имеет права на запись.

Вот и всё. Никаких внешних сервисов, никаких дополнительных DLL, кроме Aspose.BarCode.

## Шаг 1: Инициализация генератора штрих‑кода

Первое, что нужно сделать, — создать экземпляр `BarcodeGenerator`, указав Aspose, какую символьную систему вы хотите (Macro PDF417) и какие данные кодировать. Строка данных может содержать символы Unicode — Aspose выполнит конвертацию за вас.

```csharp
using Aspose.BarCode.Generation;
using Aspose.BarCode;
using System;

// Step 1 – create the generator for Macro PDF417
using (BarcodeGenerator generator = new BarcodeGenerator(
           EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
{
    // All further configuration lives inside this using block
```

> **Почему это важно:** Оператор `using` гарантирует автоматическое освобождение неуправляемых ресурсов (буфера изображения), предотвращая утечки памяти в длительно работающих сервисах.

## Шаг 2: Установка базовых параметров внешнего вида

Прежде чем перейти к специфичным для макроса метаданным, нам нужен читаемый размер штрих‑кода. `XDimension` управляет шириной самого маленького модуля, а `Columns` определяет количество столбцов данных, которые использует PDF417.

```csharp
    // Step 2 – basic visual settings
    generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
    generator.Parameters.Barcode.Pdf417.Columns = 5;     // compact layout
```

> **Совет:** Большой `XDimension` упрощает сканирование штрих‑кода на принтерах с низким разрешением, но также увеличивает размер изображения. Экспериментируйте со значениями от 2‑4 пикселей для большинства сценариев.

## Шаг 3: Заполнение метаданных Macro PDF417

Macro PDF417 — это специальный режим, позволяющий разбить большой полезный груз на несколько символов и добавить информацию уровня файла. Aspose предоставляет каждое поле через `Parameters.Barcode.Pdf417`. Ниже мы задаём все необязательные свойства, которые могут понадобиться.

```csharp
    // Step 3 – macro‑PDF417 specific fields
    generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;               // 4‑byte file identifier
    generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;                // this is segment #12
    generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;           // total segments in the file
    generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";           // optional filename
    generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234;              // CCITT‑16 example checksum
    generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;           // size in bytes
    generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = 
        new DateTime(2019, 11, 1);                                                // creation timestamp
    generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";          // recipient info
    generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";            // sender identifier
    generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
        Pdf417MacroTerminator.Set;                                                // marks the last segment
```

### Зачем существует каждое свойство

| Property | Purpose | Typical Use |
|----------|---------|-------------|
| **MacroPdf417FileID** | Уникальный идентификатор всего файла | Связывает несколько сканирований штрих‑кода с одним документом |
| **MacroPdf417SegmentID** | Индекс текущего сегмента | Воссоздаёт оригинальный полезный груз в правильном порядке |
| **MacroPdf417SegmentsCount** | Общее ожидаемое количество сегментов | Проверка полноты перед обработкой |
| **MacroPdf417FileName** | Читаемое человеком имя (опционально) | Отображает имя файла на устройстве сканирования |
| **MacroPdf417Checksum** | Код обнаружения ошибок (CCITT‑16) | Быстрая проверка целостности на стороне сканера |
| **MacroPdf417FileSize** | Исходный размер в байтах | Полезно для индикаторов прогресса или проверок хранилища |
| **MacroPdf417TimeStamp** | Время создания | Аудит, версионирование или логика истечения срока |
| **MacroPdf417Addressee / Sender** | Пользовательские строки для логистики | Кодирует отправителя/получателя в сценариях цепочки поставок |
| **MacroPdf417Terminator** | Флаг, указывающий, что это последний сегмент | Сканеры знают, когда последовательность заканчивается |

> **Особый случай:** Если опустить `MacroPdf417Terminator`, сканер будет рассматривать штрих‑код как не финальный сегмент, что может привести к бесконечному ожиданию дополнительных символов. Всегда устанавливайте его в последнем фрагменте.

## Шаг 4: Сохранение изображения штрих‑кода

После установки всех свойств попросите Aspose отрисовать символ и записать его на диск. Метод `Save` принимает путь к файлу и перечисление формата изображения.

```csharp
    // Step 4 – write the PNG file
    string outputPath = Path.Combine(
        Environment.CurrentDirectory, "ExtPDF417Meta.png");
    generator.Save(outputPath, BarCodeImageFormat.Png);
}
```

> **Что вы увидите:** Чёткий PNG‑файл с именем `ExtPDF417Meta.png`, находящийся в папке проекта. Откройте его в любом просмотрщике изображений — штрих‑код должен показывать плотный прямоугольный узор с закодированным текстом “Åspóse.Barcóde©”, встроенным вместе с макро‑метаданными.

## Проверка результата

Быстрая проверка — декодировать изображение с помощью той же библиотеки Aspose (или любого приложения‑сканера) и просмотреть извлечённые метаданные:

```csharp
using Aspose.BarCode.BarCodeRecognition;

// Load the PNG we just saved
using (BarCodeReader reader = new BarCodeReader(outputPath, DecodeType.Pdf417))
{
    foreach (BarCodeResult result in reader.ReadBarCodes())
    {
        Console.WriteLine("Decoded Text: " + result.CodeText);
        // Macro fields are available via result.Extended
        Console.WriteLine("File ID: " + result.Extended.MacroPdf417FileID);
        Console.WriteLine("Segment #: " + result.Extended.MacroPdf417SegmentID);
        // ... print other fields as needed
    }
}
```

Если консоль выводит значения, которые вы задали ранее, поздравляем — вы успешно **создали PDF417 штрих‑код с Aspose** и проверили каждый элемент метаданных.

## Распространённые подводные камни и как их избежать

| Symptom | Likely Cause | Fix |
|---------|--------------|-----|
| Штрих‑код выглядит размытым или нечитаемым | `XDimension` слишком низкое для выбранного DPI принтера | Увеличьте `XDimension` до 3‑4 пикселей |
| Сканер сообщает «отсутствует сегмент» | `MacroPdf417SegmentsCount` не совпадает с фактическим количеством символов | Убедитесь, что количество равно общему числу сегментов, которые вы будете генерировать |
| Проверка контрольной суммы не проходит | Неправильное значение контрольной суммы или переполнение | Используйте `generator.Parameters.Barcode.Pdf417.CalculateMacroPdf417Checksum()`, если хотите, чтобы Aspose вычислял её |
| Символы Unicode искажены | Неправильная кодировка текста | Aspose автоматически использует UTF‑8; просто передайте `string` — избегайте ручных преобразований байтов |

## Полный рабочий пример (готовый к копированию)

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;
using Aspose.BarCode.BarCodeRecognition;

class Program
{
    static void Main()
    {
        // Initialise generator for Macro PDF417
        using (BarcodeGenerator generator = new BarcodeGenerator(
               EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Visual settings
            generator.Parameters.Barcode.XDimension.Pixels = 2;
            generator.Parameters.Barcode.Pdf417.Columns = 5;

            // Macro PDF417 metadata
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

            // Save PNG
            string outPath = Path.Combine(Environment.CurrentDirectory, "ExtPDF417Meta.png");
            generator.Save(outPath, BarCodeImageFormat.Png);
            Console.WriteLine($"Barcode saved to {outPath}");
        }

        // Optional: decode to verify
        using (BarCodeReader reader = new BarCodeReader("ExtPDF417Meta.png", DecodeType.Pdf417))
        {
            foreach (BarCodeResult result in reader.ReadBarCodes())
            {
                Console.WriteLine($"Decoded: {result.CodeText}");
                Console.WriteLine($"FileID: {result.Extended.MacroPdf417FileID}");
                Console.WriteLine($"Segment: {result.Extended.MacroPdf417SegmentID}");
                // Add more fields as desired
            }
        }
    }
}
```

Запустите эту программу (`dotnet run`), и вы увидите, как PNG‑файл появится рядом с выводом консоли, подтверждающим декодированные значения.
