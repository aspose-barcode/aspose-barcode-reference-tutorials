# Как создать изображение штрихкода PDF417 в C# – полное руководство

Если вам нужно **создать изображение штрихкода PDF417** в приложении .NET, вы попали по адресу. Независимо от того, печатаете ли вы бирки посадочных талонов, кодируете данные инвентаря или создаёте систему мобильных билетов, PDF417 обеспечивает высокую ёмкость, двумерные штрихкоды. Это руководство покажет, как сгенерировать изображение с помощью Aspose.BarCode и как задать количество столбцов, чтобы штрихкод был как можно более компактным.

## Быстрые ответы
- **Какая библиотека создаёт штрихкоды PDF417?** Aspose.BarCode for .NET.
- **Сколько строк кода требуется?** About 10 lines in a console app.
- **Могу ли я контролировать ширину штрихкода?** Yes, by setting the `Columns` property.
- **Какой формат изображения рекомендуется?** PNG for loss‑less quality.
- **Поддерживается ли .NET 6?** Fully – the library works with .NET 6, .NET 7 and later.

## Что такое изображение штрихкода PDF417?
Изображение штрихкода PDF417 — это двумерная матрица, которая хранит до 1 700 символов в строке, используя строки и столбцы для плотного размещения данных. Aspose.BarCode преобразует эту матрицу в стандартные форматы изображений, такие как PNG, JPEG или BMP. Оно может сохраняться в различных форматах и подходит для печати на этикетках, билетах или экранах мобильных устройств.

## Зачем задавать количество столбцов для компактного изображения штрихкода PDF417?
Задание количества столбцов позволяет уменьшить ширину штрихкода, что важно для узких этикеток или элементов интерфейса с ограниченным пространством. Aspose.BarCode поддерживает от 1 до 30 столбцов, и выбор меньшего количества уменьшает общую ширину изображения до 40 % при сохранении целостности данных. Эта настройка помогает разместить штрихкоды на небольших бирках без потери читаемости.

## Как создать изображение штрихкода PDF417 в C#?
Загрузите библиотеку `Aspose.BarCode`, настройте `BarcodeGenerator` с `EncodeTypes.Pdf417`, задайте `Columns` и `Truncate`, затем сохраните результат в PNG. Весь процесс занимает два вызова методов и создаёт готовый к использованию файл изображения. Вы также можете настроить размеры, цвета и добавить читаемый человеком текст в соответствии с потребностями вашего приложения.

### Требования
- .NET 6+ SDK (или новее)
- Visual Studio 2022 или любой редактор C#
- Пакет NuGet `Aspose.BarCode`

### Пошаговая реализация

## Шаг 1: Установите пакет NuGet Aspose.BarCode
`Aspose.BarCode` — это .NET библиотека для генерации и чтения различных символьных наборов штрихкодов.

```bash
dotnet add package Aspose.BarCode
```

Эта единственная строка подтягивает все необходимые типы, включая `BarcodeGenerator`, `EncodeTypes` и перечисление `BarCodeImageFormat`.

> **Совет:** Если вы нацелены на .NET Framework вместо .NET 6, используйте классическую команду PowerShell `Install-Package Aspose.BarCode` в консоли диспетчера пакетов.

## Шаг 2: Создайте минимальное консольное приложение
`BarcodeGenerator` создаёт изображения штрихкодов на основе указанных настроек. `EncodeTypes` перечисляет поддерживаемые символьные наборы штрихкодов. `BarCodeImageFormat` перечисляет форматы изображений.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // 1️⃣ Define the data you want to encode.
            string data = "SampleBarcode©";

            // 2️⃣ Instantiate the generator for PDF417.
            BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Pdf417, data);

            // 3️⃣ Set the size of a single barcode module (pixel dimension).
            //    This is the “X‑Dimension” – smaller values yield a finer image.
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ **How to set columns** – configure the matrix layout.
            //    Fewer columns = taller barcode; more columns = wider barcode.
            generator.Parameters.Barcode.Pdf417.Columns = 3;   // 👈 primary levers
            generator.Parameters.Barcode.Pdf417.Truncate = true; // compact mode

            // 5️⃣ Choose where the PNG will be saved.
            string outputPath = @"./CompactPdf417.png";

            // 6️⃣ Save the generated barcode as a PNG image.
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"✅ Barcode saved to {outputPath}");
        }
    }
}
```

**Почему это важно:**  
- `EncodeTypes.Pdf417` указывает библиотеке, что нужен штрихкод PDF417, а не QR или Code128.  
- `XDimension.Pixels` контролирует разрешение каждого маленького чёрного или белого модуля.  
- Блок **как задать столбцы** напрямую влияет на форму **изображения штрихкода PDF417**.  
- `Truncate = true` удаляет все ненужные пустые строки, давая вам «компактный» вид, который любят многие сканеры.

## Шаг 3: Углублённое изучение — понимание столбцов и усечения

### Как задать столбцы
PDF417 размещает данные в матрице *строк* × *столбцов*. По умолчанию библиотека использует 5 столбцов, что подходит для большинства случаев. Однако вам может потребоваться более узкий штрихкод для этикетки или более широкий для повышения надёжности сканирования. Свойство:

```csharp
generator.Parameters.Barcode.Pdf417.Columns = <desiredColumnCount>;
```

принимает значения от **1** до **30** (точный предел зависит от длины данных). Вот быстрый справочник:

| Столбцы | Примерная ширина (мм) | Когда использовать |
|---------|-------------------|----------------------|
| 1‑3     | Очень узкий       | Маленькая этикетка, ограниченное пространство |
| 4‑6     | Стандартный       | Большинство чеков, билетов |
| 7‑10    | Шире              | Данные высокой плотности, лучшая читаемость |

### Усечение (компактный режим)
Установка `Truncate = true` указывает кодировщику отрезать все ненужные пустые строки внизу. Результатом является **компактное изображение штрихкода PDF417**, занимающее минимальную возможную площадь, при этом содержащие все данные. Если вы получаете ошибку «штрихкод слишком велик для этикетки», переключите этот флаг.

## Шаг 5: Распространённые подводные камни и способы их исправления

| Симптом | Вероятная причина | Быстрое решение |
|---------|-------------------|-----------------|
| Штрихкод выглядит размытым | `XDimension.Pixels` слишком низкое (например, 1) | Увеличьте до 2‑3 пикселей для более чёткого изображения. |
| Сканер не может прочитать | Слишком много столбцов для данных | Уменьшите `Columns` или включите `Truncate`. |
| Неправильный формат файла | Сохранено с `BarCodeImageFormat.Jpeg` по ошибке | Используйте `BarCodeImageFormat.Png` для без потерь. |
| Исключение `ArgumentOutOfRangeException` | Количество столбцов превышает допустимый диапазон | Держите столбцы в диапазоне 1‑30 и убедитесь, что данные помещаются. |

## Шаг 6: Дальше — настройка цветов и добавление текста

Если вы хотите, чтобы штрихкод соответствовал фирменной палитре, вы можете изменить цвета переднего плана и фона:

```csharp
generator.Parameters.Barcode.BarcodeColor = System.Drawing.Color.DarkBlue;
generator.Parameters.Barcode.BackColor = System.Drawing.Color.White;
```

Или наложить читаемый человеком текст под штрихкодом:

```csharp
generator.Parameters.Barcode.CodeText = data; // shows the raw string
generator.Parameters.Barcode.CodeLocation = CodeLocation.Below;
```

Эти дополнения необязательны, но они показывают, насколько гибким может быть процесс **создания штрихкода PDF417**.

## Часто задаваемые вопросы

**В: Можно ли использовать сгенерированный PNG на веб‑странице без дополнительного преобразования?**  
**О:** Да, PNG поддерживается всеми современными браузерами, поэтому вы можете вставлять файл напрямую с помощью тега `<img>`.

**В: Сколько символов может содержать штрихкод PDF417?**  
**О:** До 1 700 символов в строке и до 30 строк, что теоретически даёт максимум около 51 000 символов, хотя практические ограничения зависят от возможностей сканера.

**В: Требуется ли лицензия Aspose.BarCode для разработки?**  
**О:** Доступна бесплатная оценочная лицензия для тестирования; коммерческая лицензия необходима для продакшн‑развёртываний.

**В: Можно ли генерировать штрихкоды PDF417 в фоновом сервисе?**  
**О:** Конечно. Библиотека потокобезопасна для операций только чтения, поэтому вы можете генерировать штрихкоды в ASP.NET Core или Windows‑службах без взаимодействия с UI.

**В: Какие форматы изображений, кроме PNG, поддерживаются?**  
**О:** BMP, JPEG, GIF, TIFF и SVG поддерживаются через перечисление `BarCodeImageFormat`.
