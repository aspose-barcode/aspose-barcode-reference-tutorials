# Как сгенерировать штрих‑код в C# с помощью Aspose.BarCode и добавить метаданные

Если вам нужно **сгенерировать штрих‑код в C#** для логистической или складской системы, это руководство покажет полностью готовое к продакшену решение. Вы увидите, как создать Macro PDF417 штрих‑код, прикрепить богатые метаданные и задать точную метку времени — все с использованием библиотеки Aspose.BarCode.

В руководстве рассматривается всё: от установки пакета NuGet до сохранения конечного PNG‑изображения. К концу вы сможете генерировать штрих‑код, содержащий идентификаторы файлов, информацию о сегментах и пользовательские поля, готовый к считыванию сканерами, поддерживающими Macro PDF417.

## Требования

Прежде чем начать, убедитесь, что у вас есть:

* .NET 6.0 SDK или новее (код также работает с .NET Framework 4.7.2+)
* Visual Studio 2022 или любой другой предпочитаемый IDE для C#
* Действующая лицензия Aspose.BarCode (бесплатная trial‑версия подходит для разработки)
* Базовое знакомство с синтаксисом C#

> **Pro tip:** Если вы используете CI/CD‑конвейер, добавьте ссылку на пакет Aspose.BarCode в файл проекта, чтобы сборки оставались воспроизводимыми.

## Шаг 1: Установить Aspose.BarCode

Откройте терминал в папке проекта и выполните:

```bash
dotnet add package Aspose.BarCode
```

Команда загрузит последнюю стабильную версию (в данный момент 24.9). После завершения восстановления вы сможете подключать библиотеку в своих исходных файлах.

## Шаг 2: Создать новый консольный проект C# (по желанию)

Если хотите начать с чистого листа, создайте консольное приложение:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Файл `Program.cs` будет содержать код генерации штрих‑кода, показанный далее.

## Шаг 3: Настроить генератор штрих‑кода

Ядром процесса является класс `BarcodeGenerator`. Вы создаёте его, указывая нужное значение перечисления `EncodeTypes` и текст, который требуется закодировать.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Почему важна каждая строка

* **EncodeTypes.MacroPdf417** сообщает Aspose, что нужно создать PDF417‑штрих‑код, который может быть разбит на сегменты. Это необходимо для больших полезных нагрузок, превышающих ёмкость одного символа.
* **XDimension.Pixels** управляет визуальной плотностью. Значение 2 даёт чёткое изображение на большинстве экранов и принтеров без увеличения размера файла.
* **MacroPdf417* свойства** встраивают метаданные, которые считыватели воспринимают как отдельные поля (ID файла, ID сегмента и т.д.). Это часть руководства «как добавить метаданные».
* **MacroPdf417TimeStamp** демонстрирует «как задать метку времени». Экземпляр `DateTime` может быть любой UTC‑временем; использование UTC избавляет от неоднозначности часовых поясов при перемещении штрих‑кода между регионами.
* **MacroPdf417Terminator** определяет, как заканчивается макросеквенция. `Set` — самый распространённый выбор, так как он сигнализирует последнему сегменту считывателю.
* **Save(..., BarCodeImageFormat.Png)** сохраняет без потерь изображение, сохраняющее тонкие детали, необходимые для надёжного сканирования.

## Шаг 4: Проверить сгенерированный штрих‑код

Запустите программу:

```bash
dotnet run
```

В консоли вы увидите вывод:

```
Barcode saved to ExtPDF417Meta.png
```

Откройте `ExtPDF417Meta.png` в любом просмотрщике изображений. На картинке будет отображён компактный PDF417‑символ с текстом **Åspóse.Barcóde©** и встроенными макрополями. Сканирование изображения сканером, поддерживающим PDF417 (или мобильным приложением с поддержкой Macro PDF417), вернёт исходный текст плюс значения метаданных, которые вы задали.

### Ожидаемые визуальные характеристики

* Тёмные, равномерно распределённые вертикальные полосы
* Тихая зона (поле) автоматически добавляется Aspose
* Нет искажений, поскольку `XDimension` = 2 пикселя соответствует нативному разрешению PNG

## Шаг 5: Распространённые варианты и граничные случаи

### 5.1 Обработка специальных символов

В примере текста присутствуют Unicode‑символы (`Å`, `ó`, `©`). Aspose.BarCode по умолчанию кодирует их в UTF‑8, поэтому они корректно отображаются в штрих‑коде. Если нужен иной набор символов (например, ISO‑8859‑1), задайте:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Большие идентификаторы файлов

`MacroPdf417FileID` принимает 32‑битное целое число. Для значений, превышающих `int.MaxValue`, разбейте идентификатор на несколько полей или используйте GUID, сохранённый как строка в `MacroPdf417FileName`.

### 5.3 Регулировка количества столбцов

Увеличение `Pdf417.Columns` уменьшает высоту штрих‑кода, но делает каждую строку шире. Если штрих‑код должен помещаться на узкой этикетке, уменьшите количество столбцов и автоматически увеличьте количество строк.

### 5.4 Сохранение в других форматах

Aspose поддерживает BMP, JPEG, TIFF и SVG. Замените `BarCodeImageFormat.Png` нужным значением перечисления, например `BarCodeImageFormat.Svg` для масштабируемой векторной графики.

## Шаг 6: Интеграция штрих‑кода в более крупный рабочий процесс

После получения PNG‑файла вы можете:

* Встроить его в PDF‑счёт с помощью Aspose.PDF.
* Прикрепить к письму как подтверждение доставки.
* Сохранить байты изображения в базе данных для последующего извлечения.

Ниже короткий фрагмент, который преобразует PNG в массив байтов для хранения:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Часто задаваемые вопросы

**Q: Работает ли это на .NET Core?**  
A: Да. Тот же API работает на .NET Core, .NET 5+ и .NET Framework. Просто подключите соответствующий пакет NuGet.

**Q: Что если мне нужен не‑macro PDF417?**  
A: Используйте `EncodeTypes.Pdf417` вместо `EncodeTypes.MacroPdf417`. Свойства, специфичные для макроса, будут игнорироваться.

**Q: Могу ли я добавить пользовательские пары ключ/значение сверх встроенных полей?**  
A: Aspose.BarCode не предоставляет произвольные пользовательские поля для Macro PDF417. Если нужны дополнительные данные, закодируйте их в основном текстовом полезном нагрузке или переключитесь на QR‑код, который поддерживает структурированное добавление.
