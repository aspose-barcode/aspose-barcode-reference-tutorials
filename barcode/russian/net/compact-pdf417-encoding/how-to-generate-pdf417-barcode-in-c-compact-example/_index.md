# Как сгенерировать штрих‑код PDF417 в C# – компактный пример

Если вам нужно **сгенерировать штрих‑код PDF417** в приложении на C#, это руководство покажет вам полное, готовое к запуску решение. Мы создадим компактный штрих‑код PDF417, настроим ширину модуля, зададим количество столбцов и сохраним результат в виде PNG‑изображения — всё с помощью библиотеки Aspose.BarCode .NET.

Генерация штрих‑кода PDF417 часто используется, когда необходимо закодировать большие объёмы данных (например, URL‑адреса, визитные карточки или идентификаторы инвентаря) в пространственно‑экономичном двумерном формате. К концу этого руководства у вас будет рабочий экземпляр `BarcodeGenerator`, который создаёт компактный, легко читаемый штрих‑код, готовый к печати или отображению.

## Требования

- .NET 6.0 или новее (код также работает с .NET Framework 4.8)
- Visual Studio 2022 (или любой IDE для C#)
- NuGet‑пакет Aspose.BarCode for .NET (`Install-Package Aspose.BarCode`)
- Базовое знакомство с синтаксисом C#

Дополнительная конфигурация не требуется; пример работает как консольное приложение.

## Шаг 1: Создание генератора штрих‑кода PDF417

Первый шаг — создать экземпляр `BarcodeGenerator`, передав перечисление `EncodeTypes.Pdf417` и текст, который нужно закодировать.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Почему это важно:** `EncodeTypes.Pdf417` указывает библиотеке использовать символьную схему PDF417, а второй аргумент задаёт полезные данные. Вы можете заменить `"Compact example"` любой строкой длиной до 1 800 символов.

## Шаг 2: Установка ширины модуля (X‑dimension) в пикселях

X‑dimension определяет ширину одного модуля штрих‑кода (самого маленького чёрного или белого квадрата). Меньшее значение в пикселях делает штрих‑код более плотным.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Почему это важно:** Значение `2` пикселя создаёт компактный вид без потери надёжности сканирования на большинстве современных сканеров. При необходимости увеличьте значение, если нужны более крупные модули для печати с низким разрешением.

## Шаг 3: Указание количества столбцов

PDF417 позволяет управлять количеством столбцов, что влияет на соотношение сторон штрих‑кода.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Почему это важно:** Меньшее количество столбцов делает штрих‑код выше, а большее — шире. Три столбца хорошо подходят для компактного портретного расположения.

## Шаг 4: Включение компактного режима путём усечения штрих‑кода

Компактный режим удаляет лишние строки отступов, делая штрих‑код меньше, при этом сохраняет закодированные данные.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Почему это важно:** Усечение идеально, когда экранное пространство ограничено (например, мобильные приложения или небольшие этикетки). Штрих‑код остаётся полностью читаемым, поскольку алгоритм кодирования автоматически корректирует уровни коррекции ошибок.

## Шаг 5: Сохранение штрих‑кода как PNG‑изображения

Наконец, запишите сгенерированный штрих‑код в файл. PNG сохраняет без потерь, что важно для сканеров штрих‑кодов.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Запуск программы создаёт `CompactPdf417.png` в рабочем каталоге исполняемого файла. Изображение выглядит так:

![Сгенерированный компактный штрих‑код PDF417](CompactPdf417.png "Сгенерированный компактный штрих‑код PDF417")

**Ожидаемый результат:** PDF417 штрих‑код шириной 2 пикселя, с тремя столбцами, который кодирует текст “Compact example”. Сканирование PNG стандартным сканером штрих‑кодов должно вернуть исходную строку.

## Распространённые варианты и граничные случаи

| Ситуация | Как изменить код |
|-----------|------------------------|
| **Более длинные данные ( > 500 символов )** | Увеличьте `Columns` до 5‑7, чтобы штрих‑код не стал слишком высоким. |
| **Печать с высоким разрешением** | Установите `XDimension.Pixels` в 3 или 4 для более крупных модулей. |
| **Другой формат изображения** | Замените `BarCodeImageFormat.Png` на `Jpeg` или `Bmp` при необходимости. |
| **Встраивание штрих‑кода в PDF** | Используйте `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` вместо PNG. |

**Совет:** Всегда тестируйте сгенерированный штрих‑код на целевом сканере. Некоторые недорогие сканеры плохо работают с очень маленькими X‑dimension; если возникают ошибки чтения, увеличьте значение пикселей на один шаг.

## Полный, исполняемый пример

Ниже приведена полная программа, которую можно скопировать и вставить в новый консольный проект. Дополнительные файлы не требуются.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Скомпилируйте и запустите программу (`dotnet run`, если используете .NET CLI). После выполнения откройте `CompactPdf417.png`, чтобы проверить визуальный результат.

## Заключение

Теперь вы знаете **как сгенерировать штрих‑код PDF417** в C# с компактным макетом, пользовательской X‑dimension и настройками столбцов. Пример демонстрирует основные шаги: создать `BarcodeGenerator`, настроить `XDimension` и `Columns`, включить `Truncate` для компактного режима и, наконец, сохранить изображение.

Отсюда вы можете изучать дополнительные возможности, такие как уровень коррекции ошибок, пользовательские цвета или встраивание штрих‑кода непосредственно в PDF. Поэкспериментируйте с различными `EncodeTypes`, если нужны другие символьные схемы (например, QR, Code128) и применяйте тот же шаблон настройки параметров.

Удачной разработки, и пусть ваши штрих‑коды всегда сканируются с первой попытки!
