# Создание штрих‑кода PDF417 в C# с использованием Aspose – пошаговое руководство

Если вам нужно **создать штрих‑код PDF417** в приложении .NET, это руководство покажет вам, как это сделать. Вы увидите полностью готовый пример, который создает базовые, компактные, Micro, GS1‑Micro и Macro PDF417 штрих‑коды с помощью Aspose.BarCode для .NET.

Создание штрих‑кода PDF417 является распространенной задачей для транспортных этикеток, транспортных документов и систем инвентаризации. К концу этого руководства вы сможете **создавать изображения штрих‑кода PDF417**, понять ключевые параметры и адаптировать код под свои данные.

## Необходимые условия

- .NET 6.0 SDK или новее (код также работает с .NET Framework 4.7+)
- Visual Studio 2022 или любой C# IDE
- NuGet‑пакет Aspose.BarCode for .NET (`Aspose.BarCode`) установлен
- Базовое знакомство с синтаксисом C#

> **Совет:** Используйте бесплатную оценочную лицензию от Aspose, чтобы избежать ограничений во время выполнения при тестировании.

## Шаг 1: Настройка проекта и импорт пространств имён

Создайте новый консольный проект и добавьте пакет Aspose.BarCode:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Затем откройте `Program.cs` и добавьте необходимые директивы `using`:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Эти пространства имён предоставляют доступ к классу `BarcodeGenerator` и перечислению `EncodeTypes`, необходимым для **создания штрих‑кода с помощью C#**.

## Шаг 2: Создание базового штрих‑кода PDF417

Самый простой штрих‑код PDF417 использует настройки по умолчанию, за исключением X‑dimension (ширина модуля) и количества колонок. Настройка этих значений управляет общим размером и читаемостью.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Почему это работает:**  
- `EncodeTypes.Pdf417` указывает Aspose использовать символьность PDF417.  
- `XDimension.Pixels` задаёт минимальную ширину полосы; значение 2 сохраняет изображение небольшим без потери сканируемости.  
- `Pdf417.Columns` определяет количество колонок данных в штрих‑коде; три колонки дают сбалансированное соотношение сторон.

## Шаг 3: Создание компактного (усечённого) штрих‑кода PDF417

Компактный режим удаляет стоп‑шаблон и уменьшает общую высоту, что полезно для этикеток с ограниченным пространством.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Почему это работает:**  
Установка `Pdf417.Truncate = true` активирует усечённый режим, который опускает правый стоп‑шаблон и уменьшает высоту штрих‑кода, сохраняя целостность данных.

## Шаг 4: Создание Micro PDF417 штрих‑кода

Micro PDF417 — это уменьшенный вариант, поддерживающий 1‑4 колонки. Он идеален для приложений, где пространство ограничено, например, небольшие бирки продуктов.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Почему это работает:**  
- `EncodeTypes.MicroPdf417` выбирает микровариант символьности.  
- Количество колонок может быть от 1 до 4; выбор 4 даёт самое плотное расположение при сохранении сканируемости.

## Шаг 5: Создание Micro PDF417 штрих‑кода, совместимого с GS1

Префиксы GS1 добавляют стандартизированные идентификаторы (например, GTIN, номер партии) к данным штрих‑кода. Aspose позволяет внедрять их напрямую.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Почему это работает:**  
Идентификаторы приложений GS1 (AI) помещаются в скобки. Aspose разбирает их и добавляет необходимое форматирование, требуемое сканерами GS1.

## Шаг 6: Создание Macro PDF417 штрих‑кода с полной метаданными

Macro PDF417 позволяет разбить большой объём данных на несколько связанных штрих‑кодов. Вы можете внедрить метаданные уровня файла, такие как ID файла, количество сегментов, временные метки и пользовательские строки.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Почему это работает:**  
Каждое свойство `MacroPdf417*` соответствует определённому сегменту спецификации макро‑штрих‑кода. Установка этих значений гарантирует, что сканер сможет восстановить оригинальный файл из нескольких изображений штрих‑кода.
