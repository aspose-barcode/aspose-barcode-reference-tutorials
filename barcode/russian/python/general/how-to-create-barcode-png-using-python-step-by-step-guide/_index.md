# Как создать PNG‑изображение штрихкода с помощью Python – пошаговое руководство

Если вам нужно **создать PNG‑файлы штрихкода** из произвольных строк, это руководство предоставляет готовое решение. Вы увидите, как сгенерировать штрихкод Code 128, преобразовать текст в изображение штрихкода и сохранить результат в виде PNG‑файла — всё это с помощью нескольких строк кода на Python.

В руководстве покрыты все необходимые шаги: от установки требуемой библиотеки до настройки вывода под разные сценарии использования. К концу вы сможете встроить генерацию штрихкодов в любой Python‑проект без поиска дополнительной документации.

## Что вы узнаете

* Установите пакет **barcode generator python**, поддерживающий Code 128.  
* Используйте `BarCodeGenerator` для **генерации штрихкода code 128** из текстовой строки.  
* Сохраните результат как PNG высокого качества с помощью `save`.  
* Настройте размер изображения, цвета переднего/фонового плана и обработайте типичные ошибки.  
* Проверьте, что PNG‑файл создан корректно.

### Предварительные требования

| Требование | Причина |
|------------|---------|
| Python 3.8+ | Современный синтаксис и подсказки типов |
| Доступ в Интернет (для `pip install`) | Для загрузки библиотеки |
| Права записи в папку | Для сохранения сгенерированного PNG |

Внешние сервисы не требуются; всё работает локально.

## Шаг 1: Установите библиотеку для штрихкодов

Самый простой способ **преобразовать текст в штрихкод** в Python — использовать пакет **Aspose.BarCode for Python via .NET**, который поддерживает Code 128 «из коробки».

```bash
pip install aspose-barcode
```

> **Совет:** Если вы работаете в виртуальном окружении, активируйте его перед выполнением команды, чтобы изолировать зависимости.

## Шаг 2: Импортируйте необходимые классы

После установки импортируйте основные классы. Импорт короткий, поэтому код легко читается.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` создаёт изображение штрихкода.  
* `EncodeTypes` предоставляет перечисление поддерживаемых символьных систем, включая `CODE_128`.

## Шаг 3: Определите текст для кодирования

Выберите любую буквенно‑цифровую строку. Code 128 может представлять полный набор ASCII, так что вы не ограничены только цифрами.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Если входные данные содержат неподдерживаемые символы, генератор бросит `ValueError`. Оберните присваивание в блок `try`, если ожидаете пользовательский ввод.

## Шаг 4: Создайте генератор штрихкода для Code 128

Создайте экземпляр `BarCodeGenerator`, указав нужную символьную систему и ранее определённый текст. Это ядро **как генерировать изображения штрихкода** в Python.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Почему Code 128? Он обеспечивает высокую плотность и может кодировать весь диапазон ASCII, что делает его идеальным для систем учёта, транспортных этикеток и билетов.

## Шаг 5: (Опционально) Настройте внешний вид

Перед сохранением можно тонко настроить штрихкод. Ниже перечислены часто используемые параметры:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Эти настройки влияют на конечный **create barcode png**‑вывод, не меняя закодированные данные.

## Шаг 6: Сохраните штрихкод в PNG‑файл

Наконец, запишите изображение на диск. Метод `save` автоматически определяет расширение файла, поэтому указание `.png` создаст PNG‑изображение.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Если целевая директория не существует, Python бросит `FileNotFoundError`. Создайте каталог заранее или используйте `os.makedirs` с параметром `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### Ожидаемый результат

После выполнения скрипта вы найдёте `extended_barcode.png` в папке `output`. Открытие файла покажет чёткий штрихкод Code 128, кодирующий `1234567890`.

## Шаг 7: Проверьте штрихкод (быстрая проверка)

Можно считать PNG‑файл тем же библиотекой, чтобы убедиться, что закодированное значение совпадает с исходным текстом.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Выполнение этого блока выводит:

```
Verification succeeded: 1234567890
```

Если проверка не проходит, перепроверьте `barcode_text` и любые пользовательские параметры.

## Распространённые варианты и граничные случаи

| Ситуация | Корректировка |
|----------|---------------|
| **Более длинный текст (> 20 символов)** | Увеличьте `image_width`, чтобы избежать обрезки. |
| **Необходим прозрачный фон** | Установите `back_color = "Transparent"` перед сохранением. |
| **Генерация нескольких штрихкодов в цикле** | Оберните шаги 3‑6 в `for`‑цикл, меняя `barcode_text` на каждой итерации. |
| **Сохранить как JPEG вместо PNG** | Измените расширение файла на `.jpg`; библиотека автоматически обработает формат. |
| **Запуск на сервере без графического интерфейса** | Библиотека не требует GUI, что делает её безопасной для CI‑конвейеров. |

## Полный скрипт для быстрого копирования

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Сохраните скрипт как `generate_barcode.py` и запустите:

```bash
python generate_barcode.py
```

Вы увидите сообщения‑подтверждения и новый PNG‑файл в папке `output`.

Та же схема работает для любых данных Code 128, позволяя интегрировать создание штрихкодов в системы учёта, веб‑службы или автоматические генераторы отчётов.
