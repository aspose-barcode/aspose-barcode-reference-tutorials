# Come generare un codice a barre in C# con Aspose.BarCode e aggiungere metadati

Se hai bisogno di **generare un codice a barre in C#** per un sistema di logistica o inventario, questa guida ti mostra una soluzione completa, pronta per la produzione. Vedrai come creare un codice a barre Macro PDF417, allegare metadati ricchi e impostare un timestamp preciso—tutto con la libreria Aspose.BarCode.

Il tutorial copre tutto, dall'installazione del pacchetto NuGet al salvataggio dell'immagine PNG finale. Alla fine, sarai in grado di generare un codice a barre che contiene identificatori di file, informazioni di segmento e campi personalizzati, pronto per gli scanner a valle che supportano Macro PDF417.

## Prerequisiti

* .NET 6.0 SDK o versioni successive (il codice funziona anche con .NET Framework 4.7.2+)
* Visual Studio 2022 o qualsiasi IDE C# tu preferisca
* Una licenza attiva di Aspose.BarCode (la versione di prova gratuita funziona per lo sviluppo)
* Familiarità di base con la sintassi C#

> **Consiglio professionale:** Se utilizzi una pipeline CI/CD, aggiungi il riferimento al pacchetto Aspose.BarCode nel file di progetto in modo che le build rimangano riproducibili.

## Passo 1: Installa Aspose.BarCode

Apri un terminale nella cartella del tuo progetto ed esegui:

```bash
dotnet add package Aspose.BarCode
```

Il comando scarica l'ultima versione stabile (attualmente 24.9). Dopo che il ripristino è terminato, puoi fare riferimento alla libreria nei tuoi file sorgente.

## Passo 2: Crea un nuovo progetto console C# (opzionale)

Se preferisci un nuovo inizio, crea un'app console:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Il file `Program.cs` conterrà il codice di generazione del codice a barre mostrato più avanti.

## Passo 3: Configura il generatore di codici a barre

Il cuore del processo è la classe `BarcodeGenerator`. La istanzi con il valore enum `EncodeTypes` desiderato e il testo che vuoi codificare.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Perché ogni riga è importante

* **EncodeTypes.MacroPdf417** indica ad Aspose di produrre un codice a barre PDF417 che può essere suddiviso in segmenti. È essenziale per payload di grandi dimensioni che superano la capacità di un singolo simbolo.
* **XDimension.Pixels** controlla la densità visiva. Un valore di 2 produce un'immagine chiara sulla maggior parte degli schermi e delle stampanti senza aumentare le dimensioni del file.
* **MacroPdf417*** proprietà** incorporano i metadati che gli scanner a valle leggono come campi separati (ID file, ID segmento, ecc.). Questa è la parte del tutorial su “come aggiungere metadati”.
* **MacroPdf417TimeStamp** dimostra “come impostare il timestamp”. L'istanza `DateTime` può essere qualsiasi ora UTC; usare UTC evita ambiguità di fuso orario quando il codice a barre viaggia tra regioni.
* **MacroPdf417Terminator** definisce come termina la sequenza macro. `Set` è la scelta più comune perché segnala il segmento finale al lettore.
* **Save(..., BarCodeImageFormat.Png)** scrive un'immagine lossless che preserva i dettagli fini necessari per una scansione affidabile.

## Passo 4: Verifica il codice a barre generato

Esegui il programma:

```bash
dotnet run
```

Dovresti vedere l'output della console:

```
Barcode saved to ExtPDF417Meta.png
```

Apri `ExtPDF417Meta.png` in qualsiasi visualizzatore di immagini. L'immagine mostrerà un simbolo PDF417 compatto con il testo **Åspóse.Barcóde©** e i campi macro incorporati. Scansionare l'immagine con uno scanner compatibile PDF417 (o un'app mobile che supporta Macro PDF417) restituirà il testo originale più i valori dei metadati che hai impostato.

### Caratteristiche visive attese

* Barre verticali scure, uniformemente distanziate
* Una zona silenziosa (margine) aggiunta automaticamente da Aspose
* Nessuna distorsione, poiché l'`XDimension` di 2 pixel corrisponde alla risoluzione nativa del PNG

## Passo 5: Varianti comuni e casi limite

### 5.1 Gestione dei caratteri speciali

Il testo di esempio contiene caratteri Unicode (`Å`, `ó`, `©`). Aspose.BarCode li codifica usando UTF‑8 per impostazione predefinita, quindi appaiono correttamente nel codice a barre. Se ti serve una codifica diversa (ad esempio ISO‑8859‑1), imposta:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Identificatori di file di grandi dimensioni

`MacroPdf417FileID` accetta un intero a 32 bit. Per valori superiori a `int.MaxValue`, suddividi l'identificatore in più campi o usa un GUID memorizzato come stringa in `MacroPdf417FileName`.

### 5.3 Regolazione del numero di colonne

Aumentare `Pdf417.Columns` riduce l'altezza del codice a barre ma allarga ogni riga. Se il codice a barre deve adattarsi a un'etichetta stretta, diminuisci il numero di colonne e aumenta automaticamente il conteggio delle righe.

### 5.4 Salvataggio in altri formati

Aspose supporta BMP, JPEG, TIFF e SVG. Sostituisci `BarCodeImageFormat.Png` con il valore enum desiderato, ad esempio `BarCodeImageFormat.Svg` per una grafica vettoriale scalabile.

## Passo 6: Integra il codice a barre in un flusso di lavoro più ampio

Una volta ottenuto il file PNG, puoi:

* Incorporarlo in una fattura PDF usando Aspose.PDF.
* Allegarlo a un'email come prova di consegna.
* Memorizzare i byte dell'immagine in un database per un successivo recupero.

Di seguito trovi un breve snippet che converte il PNG in un array di byte per la memorizzazione:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Domande frequenti

**Q: Funziona su .NET Core?**  
A: Sì. La stessa API funziona su .NET Core, .NET 5+ e .NET Framework. Basta fare riferimento al pacchetto NuGet appropriato.

**Q: E se devo generare un PDF417 non‑macro?**  
A: Usa `EncodeTypes.Pdf417` invece di `EncodeTypes.MacroPdf417`. Le proprietà specifiche della macro saranno ignorate.

**Q: Posso aggiungere coppie chiave/valore personalizzate oltre ai campi predefiniti?**  
A: Aspose.BarCode non espone campi utente arbitrari per Macro PDF417. Se ti servono dati aggiuntivi, codificali nel payload di testo principale o passa a un codice QR, che supporta l'append strutturato.
