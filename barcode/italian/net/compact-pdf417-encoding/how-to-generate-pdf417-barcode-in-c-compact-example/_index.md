# Come generare un codice a barre PDF417 in C# – esempio compatto

Se hai bisogno di **generare un codice a barre PDF417** in un'applicazione C#, questa guida ti mostra una soluzione completa, pronta all'uso. Creeremo un codice a barre PDF417 compatto, regoleremo la larghezza del modulo, definiremo il numero di colonne e salveremo il risultato come immagine PNG — il tutto con la libreria Aspose.BarCode .NET.

Generare un codice a barre PDF417 è comune quando si desidera codificare grandi quantità di dati (ad es., URL, biglietti da visita o ID di inventario) in un formato bidimensionale efficiente in termini di spazio. Alla fine di questo tutorial avrai un'istanza funzionante di `BarcodeGenerator` che produce un codice a barre compatto, ad alta leggibilità, pronto per la stampa o la visualizzazione.

## Prerequisiti

- .NET 6.0 o successivo (il codice funziona anche con .NET Framework 4.8)
- Visual Studio 2022 (o qualsiasi IDE per C#)
- Pacchetto NuGet Aspose.BarCode per .NET (`Install-Package Aspose.BarCode`)
- Familiarità di base con la sintassi C#

Non è necessaria alcuna configurazione aggiuntiva; l'esempio funziona come un'app console.

## Passo 1: Creare un generatore di codice a barre PDF417

Il primo passo è istanziare `BarcodeGenerator` con l'enumerazione `EncodeTypes.Pdf417` e il testo che vuoi codificare.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Perché è importante:** `EncodeTypes.Pdf417` indica alla libreria di utilizzare la simbologia PDF417, mentre il secondo argomento imposta il payload dei dati. Puoi sostituire `"Compact example"` con qualsiasi stringa fino a 1 800 caratteri.

## Passo 2: Impostare la larghezza del modulo (dimensione X) in pixel

La dimensione X definisce la larghezza di un singolo modulo del codice a barre (il più piccolo quadrato nero o bianco). Un valore pixel più piccolo genera un codice a barre più stretto.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Perché è importante:** Un valore di `2` pixel crea un aspetto compatto senza sacrificare l'affidabilità della scansione sulla maggior parte degli scanner moderni. Regola il valore se ti servono moduli più grandi per stampe a bassa risoluzione.

## Passo 3: Specificare il numero di colonne

PDF417 consente di controllare il numero di colonne, il che influisce sul rapporto d'aspetto del codice a barre.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Perché è importante:** Meno colonne rendono il codice a barre più alto, mentre più colonne lo appiattiscono. Tre colonne funzionano bene per un layout compatto in orientamento verticale.

## Passo 4: Abilitare la modalità compatta troncando il codice a barre

La modalità compatta rimuove le righe di riempimento non necessarie, rendendo il codice a barre più piccolo pur mantenendo i dati codificati.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Perché è importante:** Il troncamento è ideale quando lo spazio sullo schermo è limitato (ad es., app mobili o etichette piccole). Il codice a barre rimane pienamente leggibile perché l'algoritmo di codifica regola automaticamente i livelli di correzione degli errori.

## Passo 5: Salvare il codice a barre come immagine PNG

Infine, scrivi il codice a barre generato su un file. PNG conserva la qualità loss‑less, fondamentale per gli scanner di codici a barre.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

L'esecuzione del programma crea `CompactPdf417.png` nella directory di lavoro dell'eseguibile. L'immagine appare così:

![Codice a barre PDF417 compatto generato](CompactPdf417.png "Generated compact PDF417 barcode")

**Output previsto:** Un codice a barre PDF417 di tre colonne, larghezza di 2 pixel, che codifica il testo “Compact example”. La scansione del PNG con uno scanner standard dovrebbe restituire la stringa originale.

## Variazioni comuni e casi limite

| Situazione | Come modificare il codice |
|-----------|---------------------------|
| **Dati più lunghi ( > 500 caratteri )** | Aumenta `Columns` a 5‑7 per evitare che il codice a barre diventi troppo alto. |
| **Stampa ad alta risoluzione** | Imposta `XDimension.Pixels` a 3 o 4 per moduli più grandi. |
| **Formato immagine diverso** | Sostituisci `BarCodeImageFormat.Png` con `Jpeg` o `Bmp` secondo necessità. |
| **Incorporare il codice a barre in un PDF** | Usa `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` al posto di PNG. |

**Suggerimento:** Testa sempre il codice a barre generato sull'hardware scanner di destinazione. Alcuni scanner economici hanno difficoltà con dimensioni X molto piccole; se riscontri errori di lettura, aumenta il valore dei pixel di un passo.

## Esempio completo, eseguibile

Di seguito trovi il programma completo che puoi copiare‑incollare in un nuovo progetto console. Non sono richiesti file aggiuntivi.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Compila ed esegui il programma (`dotnet run` se usi la CLI .NET). Dopo l'esecuzione, apri `CompactPdf417.png` per verificare il risultato visivo.

## Conclusione

Ora sai **come generare un codice a barre PDF417** in C# con layout compatto, dimensione X personalizzata e impostazioni di colonna. L'esempio dimostra i passaggi essenziali: istanziare `BarcodeGenerator`, configurare `XDimension` e `Columns`, abilitare `Truncate` per la modalità compatta e, infine, salvare l'immagine.

Da qui puoi esplorare funzionalità aggiuntive come il livello di correzione degli errori, colori personalizzati o l'incorporamento diretto del codice a barre in PDF. Sperimenta con diversi `EncodeTypes` se ti servono altre simbologie (ad es., QR, Code128) e integra lo stesso schema di configurazione dei parametri.

Buona programmazione, e che i tuoi codici a barre vengano sempre letti al primo tentativo!
