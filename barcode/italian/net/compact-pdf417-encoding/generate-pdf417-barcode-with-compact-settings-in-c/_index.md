# Genera codice a barre PDF417 con impostazioni compatte in C#

Se devi **generare un codice a barre PDF417** in un'applicazione .NET, questa guida ti mostra come farlo con Aspose.Barcode per .NET. Vedremo come creare il generatore, configurare le colonne, la dimensione X e abilitare la modalità compatta in modo che il simbolo risultante sia il più piccolo possibile.

Generare un codice a barre PDF417 è comune quando è necessario codificare grandi quantità di dati per biglietti, ID o etichette di spedizione. Questo tutorial copre l'intero flusso di lavoro—dall'installazione della libreria al salvataggio del PNG finale—così potrai copiare‑incollare il codice nel tuo progetto e farlo funzionare subito.

## Prerequisiti per generare un codice a barre PDF417

Prima di iniziare, assicurati di avere:

* .NET 6.0 (o successivo) installato.  
* Visual Studio 2022 o qualsiasi IDE che supporti progetti C#.  
* Una licenza NuGet per **Aspose.Barcode for .NET** (la versione di prova gratuita è sufficiente per imparare).  

Puoi aggiungere la libreria con il seguente comando:

```bash
dotnet add package Aspose.BarCode
```

> **Suggerimento:** Usa il flag `--version` per fissare una versione stabile nota, ad esempio `dotnet add package Aspose.BarCode --version 23.12`.

## Crea un generatore di codice a barre PDF417

Il primo blocco di codice crea un'istanza di `BarcodeGenerator` pre‑configurata per la simbologia PDF417. Il testo `"Åspóse.Barcóde©"` contiene caratteri Unicode per dimostrare che il generatore gestisce input non‑ASCII fin da subito.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Perché è importante
`EncodeTypes.Pdf417` indica ad Aspose.Barcode che desideri un **codice a barre PDF417**, una simbologia lineare impilata capace di memorizzare fino a 1 850 caratteri. Utilizzare il costruttore con l'argomento testo ti evita una chiamata successiva a `SetCodeText`.

## Imposta la XDimension del codice a barre (dimensione del modulo)

La dimensione del modulo, nota anche come X‑dimension, determina quanto è larga ogni singola barra. Pixel più piccoli producono un'immagine più densa, mentre pixel più grandi migliorano la leggibilità su stampanti a bassa risoluzione.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### Perché dovresti regolare la XDimension
Un valore di `2` pixel funziona bene per la visualizzazione su schermo e per la maggior parte delle stampanti da ufficio. Se ti serve una stampa ad alta risoluzione, aumenta il valore; se desideri un codice a barre più stretto (ad esempio, per un aspetto simile a un QR), riducilo—ma mai al di sotto di `1` pixel, altrimenti l'immagine diventa illeggibile.

## Imposta il numero di colonne per il simbolo PDF417

PDF417 ti permette di scegliere quante colonne (stack verticali) avrà il codice a barre. Meno colonne rendono il codice più alto; più colonne lo rendono più largo.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### Quando modificare il conteggio delle colonne
Tre colonne producono un simbolo compatto, quasi quadrato, che si adatta bene alle carte d'identità standard. Se hai una stringa molto lunga, potresti aumentare il numero di colonne per mantenere l'altezza ragionevole.

## Abilita la modalità compatta (troncamento)

La modalità compatta rimuove automaticamente le righe inutilizzate dal simbolo, riducendone le dimensioni complessive. È particolarmente utile quando i dati codificati non riempiono tutta la matrice.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Vantaggi del codice a barre PDF417 compatto
Quando `Truncate` è `true`, il generatore calcola il numero minimo di righe necessario per memorizzare i tuoi dati, riducendo l'uso di inchiostro e il tempo di scansione. È sicuro per la maggior parte degli scanner perché la specifica PDF417 definisce l'algoritmo di troncamento.

## Salva il codice a barre generato come immagine

Infine, scrivi il codice a barre in un file PNG. PNG conserva la qualità lossless, rendendolo ideale per stampe successive o per l'inserimento in PDF.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Output previsto
L'esecuzione del programma crea `CompactPdf417.png` nella cartella specificata. L'immagine contiene un **codice a barre PDF417 compatto** che codifica la stringa `"Åspóse.Barcóde©"` con tre colonne, una X‑dimension di 2 pixel e troncamento applicato. Puoi verificare il risultato con qualsiasi app di lettura codici a barre o con la demo online gratuita di Aspose.Barcode.

## Variazioni comuni e casi limite

| Situazione | Adeguamento |
|-----------|------------|
| **Dati molto lunghi (> 1500 caratteri)** | Aumenta `Columns` o imposta manualmente `Rows` (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Stampa su una stampante a bassa risoluzione** | Incrementa `XDimension.Pixels` a 3 o 4 per evitare la pixelazione. |
| **Necessità di sfondo trasparente** | Usa `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **Incorporamento in un PDF** | Salva come `BarCodeImageFormat.Pdf` o ottieni l'oggetto `Image` tramite `pdf417Generator.GenerateBarCodeImage()`. |

## Esempio completo, eseguibile

Di seguito trovi il programma completo che puoi copiare in un nuovo progetto console. Non sono necessari file aggiuntivi.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Esegui `dotnet run` dalla cartella del progetto. Dopo l'esecuzione, apri `CompactPdf417.png` per vedere il codice a barre generato.

## Conclusione

Ora sai come **generare un codice a barre PDF417** in C# con pieno controllo su colonne, X‑dimension e modalità compatta. Regolando i `barcode XDimension pixels`, `set PDF417 columns` e abilitando il troncamento `compact PDF417 barcode`, puoi produrre un codice a barre che rispetti esattamente i vincoli di dimensione della tua applicazione.

Passi successivi da esplorare:

* Codifica set di dati più grandi e sperimenta con il parametro `Rows`.  
* Cambia il formato di output in `BarCodeImageFormat.Svg` per grafica web scalabile.  
* Combina il codice a barre con altri componenti Aspose, come **Aspose.PDF**, per inserire l'immagine direttamente in un report PDF.

Buon coding, e sentiti libero di modificare le impostazioni per adattarle al tuo specifico ambiente di scansione!
