# Generare codice a barre PDF417 in C# usando Aspose – guida passo‑passo

Se hai bisogno di **generare un codice a barre PDF417** in un'applicazione .NET, questa guida ti mostra esattamente come. Vedrai un esempio completo, pronto‑da‑eseguire, che crea codici a barre PDF417 di base, compatti, Micro, GS1‑Micro e Macro con Aspose.BarCode per .NET.

Generare un codice a barre PDF417 è una necessità comune per etichette di spedizione, documenti di trasporto e sistemi di inventario. Alla fine di questo tutorial sarai in grado di **generare immagini di codice a barre PDF417**, comprendere i parametri chiave e adattare il codice ai tuoi payload di dati.

## Prerequisiti

- .NET 6.0 SDK o successivo (il codice funziona anche con .NET Framework 4.7+)
- Visual Studio 2022 o qualsiasi IDE C#
- Pacchetto NuGet Aspose.BarCode for .NET (`Aspose.BarCode`) installato
- Familiarità di base con la sintassi C#

> **Consiglio professionale:** Usa la licenza di valutazione gratuita di Aspose per evitare restrizioni di runtime durante i test.

## Passo 1: Configura il progetto e importa i namespace

Crea un nuovo progetto console e aggiungi il pacchetto Aspose.BarCode:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Quindi apri `Program.cs` e aggiungi le direttive `using` richieste:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Questi namespace ti danno accesso alla classe `BarcodeGenerator` e all'enumerazione `EncodeTypes` necessarie per **generare un codice a barre usando C#**.

## Passo 2: Genera un codice a barre PDF417 di base

Il codice a barre PDF417 più semplice utilizza le impostazioni predefinite eccetto la X‑dimension (larghezza del modulo) e il numero di colonne. Modificare questi valori controlla la dimensione complessiva e la leggibilità.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Perché funziona:**  
- `EncodeTypes.Pdf417` indica ad Aspose di usare la simbologia PDF417.  
- `XDimension.Pixels` definisce la larghezza minima della barra; un valore di 2 mantiene l'immagine piccola senza sacrificare la scansione.  
- `Pdf417.Columns` determina quante colonne di dati contiene il codice a barre; tre colonne offrono un rapporto d'aspetto equilibrato.

## Passo 3: Genera un codice a barre PDF417 compatto (troncato)

La modalità compatta rimuove il pattern di stop e riduce l'altezza complessiva, utile per etichette con spazio limitato.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Perché funziona:**  
Impostare `Pdf417.Truncate = true` attiva la modalità troncata, che omette il pattern di stop a destra e riduce l'altezza del codice a barre preservando l'integrità dei dati.

## Passo 4: Genera un codice a barre Micro PDF417

Micro PDF417 è una variante più piccola che supporta da 1 a 4 colonne. È ideale per applicazioni in cui lo spazio è limitato, come piccoli tag di prodotto.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Perché funziona:**  
- `EncodeTypes.MicroPdf417` seleziona la versione micro della simbologia.  
- Il conteggio delle colonne può variare da 1 a 4; scegliere 4 produce il layout più denso mantenendo la scansione possibile.

## Passo 5: Genera un codice a barre Micro PDF417 conforme a GS1

I prefissi GS1 aggiungono identificatori standardizzati (ad es., GTIN, numero di lotto) ai dati del codice a barre. Aspose ti consente di incorporarli direttamente.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Perché funziona:**  
Gli Identificatori di Applicazione GS1 (AI) sono inseriti tra parentesi. Aspose li interpreta e aggiunge la formattazione appropriata richiesta dagli scanner GS1.

## Passo 6: Genera un codice a barre Macro PDF417 con metadati completi

Macro PDF417 ti permette di suddividere un grande payload di dati in più codici a barre collegati. Puoi incorporare metadati a livello di file come ID file, conteggio segmenti, timestamp e stringhe personalizzate.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Perché funziona:**  
Ogni proprietà `MacroPdf417*` mappa a uno specifico segmento della specifica del codice a barre macro. Impostare questi valori garantisce che uno scanner possa ricostruire il file originale da più immagini di codice a barre.
