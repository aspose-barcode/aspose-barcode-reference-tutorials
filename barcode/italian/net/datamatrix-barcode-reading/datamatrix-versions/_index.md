# Come generare codici a barre DataMatrix con Aspose.BarCode per .NET

Se hai bisogno di un modo affidabile per incorporare simboli leggibili da macchine nelle tue applicazioni .NET, **come generare DataMatrix** è una necessità comune. Aspose.BarCode per .NET offre un'API completamente gestita che gestisce ogni passaggio—dalla scelta della versione DataMatrix corretta alla messa a punto dei livelli di correzione degli errori—senza richiedere strumenti esterni. In questo tutorial percorreremo un esempio completo, spiegheremo perché ogni impostazione è importante e ti mostreremo come salvare il risultato come immagine PNG o JPEG.

## Risposte rapide
- **Quale libreria crea codici a barre DataMatrix?** Aspose.BarCode for .NET.  
- **Quante versioni DataMatrix sono supportate?** Tutte le 30 versioni standard quadrate e rettangolari (da 10×10 fino a 144×144 moduli).  
- **Quali tipi di ECC posso usare?** ECC200 (predefinito) e ECC140.  
- **È necessaria una licenza per lo sviluppo?** Una prova gratuita di 30 giorni è sufficiente per i test; è necessaria una licenza commerciale per la produzione.  
- **Posso eseguirlo su .NET 6, .NET Core o .NET Framework?** Sì—Aspose.BarCode supporta .NET Framework 4.5+, .NET Core 3.1+ e .NET 5/6+.

## Cos'è un codice a barre DataMatrix?
Un codice a barre DataMatrix è una matrice bidimensionale, quadrata o rettangolare, di celle nere e bianche che può memorizzare fino a 2.335 caratteri alfanumerici. È ampiamente utilizzato nella produzione, nella logistica e nell'assistenza sanitaria per la marcatura di piccoli oggetti perché rimane leggibile anche se parzialmente danneggiato.

## Perché usare Aspose.BarCode per .NET?
Aspose.BarCode supporta **oltre 50 formati di output** (inclusi PNG, JPEG, TIFF, SVG e PDF) e può generare **tutte le 30 versioni DataMatrix** senza caricare l'intera immagine in memoria, consentendoti di creare codici a barre in servizi ad alto rendimento che elaborano file più grandi di 100 MB.

## Prerequisiti
Prima di immergerci nel codice, assicurati di avere i seguenti prerequisiti:
- Un ambiente di sviluppo con supporto .NET (Visual Studio 2022, Rider o VS Code).  
- Una copia di Aspose.BarCode per .NET, che puoi scaricare dalla **pagina di download di Aspose.BarCode .NET**: [Aspose.BarCode .NET download page](https://releases.aspose.com/barcode/net/).  
- Conoscenze di base di C# e del framework .NET.

Ora, esploriamo le versioni DataMatrix e come generarne utilizzando Aspose.BarCode per .NET.

## Come generare codici a barre DataMatrix in .NET?
Carica il `BarcodeGenerator` con il tipo `EncodeTypes.DataMatrix`, imposta la versione e l'ECC desiderati, quindi chiama `Save` per scrivere il file immagine. Questo modello a singola riga funziona per qualsiasi versione tu scelga e gestisce automaticamente la dimensione dei moduli, le zone silenziose e il rendering dell'immagine.

## Importa spazi dei nomi
`BarcodeGenerator` è la classe principale di Aspose.BarCode per creare immagini di codici a barre.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

Lo spazio dei nomi `Aspose.BarCode.Generation` fornisce l'accesso alla classe `BarcodeGenerator`, che è la classe principale utilizzata per generare immagini di codici a barre.

Ora, suddividiamo l'esempio in più passaggi.

## Passo 1: imposta il percorso della directory
Inizia definendo il percorso della directory dove desideri salvare i codici a barre DataMatrix generati.

```csharp
string path = "Your Directory Path";
```

Sostituisci `"Your Directory Path"` con il percorso reale dove vuoi salvare le immagini dei codici a barre.

## Passo 2: inizializza il generatore di codici a barre
Crea un'istanza della classe `BarcodeGenerator` e specifica il tipo di codice a barre come `DataMatrix`. Puoi anche fornire i dati che desideri codificare all'interno del codice a barre.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` è la classe principale che crea e rende i simboli dei codici a barre.

## Passo 3: configura le proprietà del codice a barre
Puoi personalizzare varie proprietà del codice a barre DataMatrix, come le sue dimensioni e il tipo ECC (Error Correction Code). Ecco un esempio di impostazione della X‑dimension a 4 pixel e della scelta di ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` imposta la dimensione di ogni modulo in pixel, e `DataMatrixEcc` seleziona il livello di correzione degli errori.

## Passo 4: imposta la versione DataMatrix e salva
Puoi specificare la versione DataMatrix impostando il numero di righe e colonne. Dopo aver configurato la versione, salva l'immagine del codice a barre.

Ad esempio, per creare un codice a barre DataMatrix con 22 righe e 22 colonne usando ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

Allo stesso modo, puoi generare un codice a barre con parametri diversi modificando la versione e il tipo ECC secondo necessità.

## Passo 5: ripeti per altre versioni
Puoi ripetere il Passo 4 per altre versioni DataMatrix. Ad esempio, per creare un codice a barre con 12 righe e 64 colonne usando ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Passo 6: cambia i tipi ECC
Se desideri cambiare il tipo ECC in Ecc140, puoi farlo aggiornando la proprietà ECC:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Passo 7: genera codici a barre con versioni ed ECC diversi
Ripeti il Passo 4 per altre versioni DataMatrix e tipi ECC, salvando ogni codice a barre con un nome file unico.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

Ora che hai imparato a generare codici a barre DataMatrix usando Aspose.BarCode per .NET, puoi facilmente integrare questa funzionalità nelle tue applicazioni .NET.

## Problemi comuni e consigli per la risoluzione
- **Dimensioni versione errate** – Le versioni DataMatrix hanno coppie fisse di righe/colonne. Fornire una coppia non corrispondente (ad es., 10 × 20) genererà un `ArgumentException`. Usa sempre una delle combinazioni supportate elencate nella documentazione API.  
- **Licenza mancante** – In modalità di prova le immagini generate contengono una filigrana. Applica una licenza valida con `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` prima di creare il generatore per rimuovere la filigrana. La classe `License` carica un file di licenza per attivare il prodotto.  
- **Dimensione immagine grande** – Se hai bisogno di un'output ad alta risoluzione, aumenta la proprietà `XDimension`; la libreria scala l'immagine proporzionalmente senza perdere la leggibilità.
