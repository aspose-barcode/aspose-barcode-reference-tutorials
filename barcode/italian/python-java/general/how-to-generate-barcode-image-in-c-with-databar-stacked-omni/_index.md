# Come generare un'immagine di codice a barre in C# con DataBar Stacked Omni‑Directional

Se hai bisogno di **come generare un'immagine di codice a barre** in un'applicazione .NET, questo tutorial mostra i passaggi esatti. Vedrai come creare un codice a barre DataBar Stacked Omni‑Directional, regolare il suo rapporto d'aspetto e esportare il risultato come file PNG.

Generare codici a barre è una necessità comune per sistemi di inventario, terminali di punto vendita al dettaglio e tracciamento logistico. Nelle sezioni seguenti copriremo tutto ciò di cui hai bisogno—dal pacchetto NuGet richiesto alla verifica finale dell'immagine—così potrai integrare la creazione di codici a barre in qualsiasi progetto C# già da oggi.

## Prerequisiti

Prima di iniziare, assicurati di avere:

* .NET 6.0 o successivo (il codice funziona con .NET Core e .NET Framework)
* Visual Studio 2022 o qualsiasi IDE C# tu preferisca
* Il pacchetto NuGet **Aspose.BarCode for .NET** (installalo con `dotnet add package Aspose.BarCode`)
* Permessi di scrittura sulla cartella in cui verranno salvati i file PNG

Questi prerequisiti garantiscono che il campione venga eseguito senza configurazioni aggiuntive.

## Passo 1: Configurare la cartella di output

La prima cosa di cui hai bisogno è una directory dove verranno scritti i file PNG generati. Funziona sia un percorso assoluto che relativo, ma assicurati che la cartella esista prima di chiamare `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Creare la cartella programmaticamente evita *FileNotFoundException* quando il metodo `Save` tenta di scrivere l'immagine.

## Passo 2: Creare un generatore di codice a barre DataBar Stacked Omni‑Directional

La classe **BarcodeGenerator** è il punto di ingresso per tutti i tipi di codice a barre. Qui specifichiamo `EncodeTypes.DatabarStackedOmniDirectional` e la stringa di dati che vogliamo codificare.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Perché è importante*: l'enumerazione `EncodeTypes` indica alla libreria quale simbologia renderizzare. L'uso della variante Omni‑Directional assicura che il codice a barre possa essere letto da qualsiasi orientamento—un requisito per molti scanner di magazzino.

## Passo 3: Configurare i parametri comuni del codice a barre

Un codice a barre leggibile necessita di una X‑dimension sensata (la larghezza della barra più piccola). Impostare `Pixels` a 2 offre un buon equilibrio tra dimensione e nitidezza per la maggior parte delle risoluzioni schermo.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Puoi modificare `Pixels` in seguito se ti serve un'immagine più grande o più piccola; la libreria scala automaticamente il resto del codice a barre.

## Passo 4: Generare la prima immagine con rapporto d'aspetto 15

Il **rapporto d'aspetto** controlla la relazione altezza‑larghezza dei codici DataBar. Un rapporto d'aspetto di 15 è il valore predefinito tipico per le etichette al dettaglio.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Dopo questa chiamata, troverai `DatabarAspectRatio15.png` nella cartella di output. L'immagine è un PNG lossless, adatto per ulteriori elaborazioni o stampe.

## Passo 5: Cambiare il rapporto d'aspetto a 30 ed esportare una seconda immagine

A volte è necessario un codice a barre più alto—ad esempio quando l'altezza dell'etichetta è limitata. Cambiare il rapporto d'aspetto a 30 produce un'immagine più compatta mantenendo l'integrità dei dati.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Ora hai due file PNG che illustrano come gli stessi dati appaiono con rapporti d'aspetto diversi. Questo confronto affiancato ti aiuta a decidere quale variante si adatta meglio al layout della tua etichetta.

## Esempio completo, eseguibile

Di seguito trovi il programma completo che puoi copiare, incollare ed eseguire. Include tutte le direttive `using`, la gestione degli errori e i commenti che spiegano ogni parte del processo.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Output previsto** (console):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Apri i due file PNG in qualsiasi visualizzatore di immagini. Vedrai lo stesso GTIN codificato, ma la seconda immagine è più alta a causa del rapporto d'aspetto maggiore.

## Consigli professionali e ostacoli comuni

| Situazione | Raccomandazione |
|-----------|----------------|
| **Display a bassa risoluzione** | Aumenta `XDimension.Pixels` a 3 o 4 per mantenere le barre nitide. |
| **Stampa su carta termica** | Usa `BarCodeImageFormat.Tiff` per una fedeltà maggiore e imposta `Resolution.DpiX/DpiY` a 300. |
| **Dati dinamici** | Riutilizza la stessa istanza di `BarcodeGenerator` e aggiorna solo `generator.CodeText` prima di ogni `Save`. Questo evita allocazioni di oggetti non necessarie. |
| **GTIN non valido** | La libreria lancia `ArgumentException` se i dati non rispettano gli standard GS1. Convalida i dati prima di passarli al generatore. |
