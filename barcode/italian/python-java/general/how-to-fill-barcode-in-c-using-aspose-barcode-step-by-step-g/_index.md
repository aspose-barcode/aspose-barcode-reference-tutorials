# Come riempire un codice a barre in C# usando Aspose.BarCode

Se hai bisogno di **come riempire un codice a barre** in un'applicazione .NET, questo tutorial mostra l'intero processo. Genererai un codice a barre postale Planet con barre solide, quindi creerai una versione a barre vuote dello stesso codice a barre, il tutto con una singola modifica di una riga di codice.

La guida copre tutto ciò che devi sapere: configurazione del progetto, regolazione della X‑dimension, passaggio tra barre riempite e vuote, e come verificare i file PNG generati. Non è necessaria alcuna documentazione esterna—basta copiare il codice, eseguirlo e vedrai il risultato.

## Prerequisiti

Prima di iniziare, assicurati di avere:

* .NET 6.0 SDK o versioni successive installate  
* Un ambiente di sviluppo come Visual Studio 2022 o VS Code  
* Il pacchetto NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

Questi elementi costituiscono la base minima per la parte **barcode generator c#** del tutorial.

## Come riempire un codice a barre – configurazione del progetto

1. Crea un nuovo progetto console:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Aggiungi il pacchetto Aspose.BarCode:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Apri il file `Program.cs` generato e sostituisci il suo contenuto con l'esempio completo mostrato più avanti in questo articolo.

Il progetto ora contiene tutto il necessario per **generare immagini di codice a barre postale**.

## Genera un codice a barre postale con barre solide

Il primo passo è creare un codice a barre Planet che utilizzi barre riempite (solide). Planet è la simbologia usata da molti servizi postali per l'ordinamento.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Perché queste righe sono importanti**

* `EncodeTypes.Planet` indica al generatore quale simbologia usare; Planet è lo standard per i codici a barre postali.  
* `XDimension.Pixels = 4` aumenta la larghezza del modulo, rendendo il codice a barre più facile da leggere e visivamente più chiaro quando stampato.  
* `Save` scrive l'immagine su disco in formato PNG, un formato loss‑less adatto per ulteriori elaborazioni.

L'esecuzione di questo blocco produce **PostalPlanetFilledBars.png**, un'immagine con barre solide che rispetta le specifiche postali.

## Crea un codice a barre vuoto usando la simbologia Planet

A volte un sistema postale si aspetta che le barre siano vuote (non riempite) mentre gli spazi rimangono solidi. Passare a quella modalità richiede solo una modifica di proprietà.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Perché funziona**

Impostare `FilledBars = false` indica al renderer di invertire lo stile visivo: le barre diventano trasparenti (vuote) e lo sfondo diventa opaco. Questo è l'esatto opposto del comportamento predefinito mostrato in precedenza, permettendoti di **creare immagini di codice a barre vuoto** senza modificare i dati codificati.

## Esempio completo, eseguibile

Di seguito trovi il programma completo che combina le due sezioni. Copialo in `Program.cs`, sostituisci `YOUR_DIRECTORY/` con un percorso di cartella reale e esegui `dotnet run`.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Output previsto

Dopo l'esecuzione troverai due file PNG nella cartella specificata:

| Nome file                     | Descrizione visiva |
|-------------------------------|--------------------|
| `PostalPlanetFilledBars.png`  | Barre solide nere su sfondo bianco |
| `PostalPlanetEmptyBars.png`   | Barre trasparenti (bianche) su sfondo nero |

Entrambe le immagini codificano la stessa stringa numerica `"123456"` e condividono la stessa X‑dimension, garantendo che siano intercambiabili dal punto di vista della validazione dei dati.

## Domande comuni e casi particolari

**Cosa succede se la cartella di output non esiste?**  
Il metodo `Save` genera una `DirectoryNotFoundException`. Crea la cartella in anticipo o avvolgi le chiamate in un blocco `try / catch` che crea la directory se necessario:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Posso usare un formato immagine diverso?**  
Sì. Sostituisci `BarCodeImageFormat.Png` con `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` o qualsiasi formato supportato da Aspose.BarCode.

**La X‑dimension influisce sulla leggibilità da parte dello scanner?**  
Aumentare la larghezza in pixel rende le barre più larghe, il che può migliorare la leggibilità su scanner a bassa risoluzione. Tuttavia, valori molto grandi possono superare l'area stampabile. I valori tipici variano da 2 a 6 pixel per stampa a 300 dpi.

**La simbologia `EncodeTypes.Planet` è l'unica opzione postale?**  
No. Aspose.BarCode supporta anche `EncodeTypes.Postnet` e `EncodeTypes.USPSIntelligentMail`. La stessa proprietà `FilledBars` funziona anche con questi tipi.

Regolando la X‑dimension controlli la chiarezza visiva, e un singolo cambio di proprietà alterna tra barre riempite e vuote senza alterare i dati codificati.
