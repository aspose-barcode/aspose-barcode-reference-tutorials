# Crea barcode PNG in Python – Guida completa

Ti è mai capitato di dover **creare barcode PNG** ma non eri sicuro di quale libreria o impostazioni usare? Non sei solo. In molti sistemi di inventario o di cassa il primo passo è trasformare i dati grezzi in un'immagine PNG nitida che i lettori amano.  

In questo tutorial vedremo **come generare databar**, come **regolare l'altezza del barcode**, e anche il trucco per **modificare i parametri del barcode** al volo—tutto usando **barcode con dati di esempio** che puoi copiare‑incollare direttamente nel tuo progetto.  

## Cosa imparerai

- Configurare la libreria Aspose.BarCode (o simile) in Python.  
- **Creare barcode PNG** con altezze diverse in poche righe di codice.  
- **Come modificare barcode** proprietà come la dimensione del modulo e l'altezza della barra.  
- Utilizzare un valore GTIN‑14 realistico come **barcode con dati di esempio**.  
- Suggerimenti per risolvere problemi comuni come immagini sfocate o codifica errata.

Non è necessaria alcuna esperienza precedente nella generazione di barcode—basta un interprete Python di base e la possibilità di installare un pacchetto pip.

## Prerequisiti

- Python 3.8+ installato sulla tua macchina.  
- Accesso a internet per installare il pacchetto `aspose-barcode` (o qualsiasi libreria compatibile).  
- Una cartella scrivibile dove verranno salvati i file PNG (sostituisci `YOUR_DIRECTORY` nello script).  

Se li hai già, ottimo—tuffiamoci.

## Crea barcode PNG – Configurazione del generatore

Prima di tutto: abbiamo bisogno di un oggetto generatore che sappia che stiamo trattando un barcode **DataBar Omnidirectional**. Il codice qui sotto importa le classi necessarie, crea il generatore con un **barcode con dati di esempio**, e imposta una dimensione del modulo modesta.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Perché è importante:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` indica al motore di produrre un **DataBar** leggibile da qualsiasi direzione, perfetto per gli scaffali al dettaglio. Impostare `x_dimension` mantiene le barre nitide, mentre `bar_height` controlla la dimensione visiva del codice.

## Come generare Databar con dati di esempio

Ora che il generatore è pronto, **creeremo file barcode PNG**. Il primo salvataggio utilizza un'altezza di 30 pixel, spesso sufficiente per le anteprime a schermo.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Eseguendo lo script fino a questo punto otterrai un file PNG che appare come un barcode compatto e ad alto contrasto. Aprilo in qualsiasi visualizzatore di immagini per verificare che le barre siano nitide e che i dati GTIN‑14 siano codificati.

## Regola l'altezza del barcode (Come modificare barcode)

A volte è necessario un barcode più alto per etichette più grandi o stampe ad alta risoluzione. È qui che entra in gioco **regolare l'altezza del barcode**. Cambiare l'altezza è semplice come aggiornare la proprietà `BarHeight` e salvare nuovamente.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Come funziona:** Il generatore riutilizza gli stessi dati e la stessa dimensione del modulo; solo la dimensione verticale cambia. Questo evita di ricreare l'intero oggetto e dimostra **come modificare barcode** dinamicamente.

## Script completo – Soluzione tutto‑in‑uno

Di seguito trovi lo script completo e eseguibile che combina tutti i passaggi. Copia, incolla ed esegui—dovrebbe funzionare subito dopo aver installato il pacchetto.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Output previsto

Eseguendo lo script verranno generati due file:

- `DatabarOmni30.png` – barcode DataBar Omnidirectional alto 30 px.  
- `DatabarOmni60.png` – versione alta 60 px dello stesso barcode.

Entrambe le immagini sono in formato PNG, senza perdita, e pronte per essere incorporate in PDF, pagine HTML o stampate direttamente su etichette.

## Problemi comuni e consigli professionali

- **Pixel vs. DPI:** I file PNG sono basati sui pixel. Se ti serve una dimensione di stampa specifica, calcola `BarHeight` in base al DPI (es., 300 dpi → 30 px ≈ 0.1 in).  
- **Codifica errata:** Assicurati che la stringa dei dati segua il formato GS1 Application Identifier (`(01)` per GTIN‑14). La mancanza delle parentesi può far ricadere la libreria su un barcode numerico semplice.  
- **Percorsi dei file:** Usa stringhe raw (`r"..."`) o doppi backslash su Windows per evitare problemi con i caratteri di escape.  
- **Prestazioni:** Se generi migliaia di barcode, istanzia il generatore una sola volta e modifica solo `BarHeight` o la stringa dei dati tra i salvataggi. Questo riduce il consumo di memoria.
