# Come salvare le immagini di codici a barre in C# usando l'API BarcodeGenerator

Se hai bisogno di **how to save barcode** file da un'applicazione .NET, questa guida mostra i passaggi esatti. Vedrai un **barcode generator example** completo che crea un DataBar Stacked Omnidirectional barcode, ne regola il rapporto d'aspetto e salva due file PNG.

Salvare le immagini dei codici a barre è una necessità comune quando si costruiscono sistemi di inventario, terminali point‑of‑sale o flussi di lavoro di etichettatura automatizzata. Alla fine di questo tutorial potrai generare codice C# per codici a barre che produce immagini affidabili pronte per la stampa o la visualizzazione.

## Prerequisiti

- .NET 6.0 SDK o versioni successive installato  
- Visual Studio 2022 (o qualsiasi IDE compatibile con C#)  
- Il pacchetto NuGet **Aspose.BarCode for .NET** (il codice utilizza `Aspose.BarCode.Generation`)  

Puoi aggiungere il pacchetto con il seguente comando:

```bash
dotnet add package Aspose.BarCode
```

## Passo 1: Configurare un progetto console C# minimale

Crea un nuovo progetto console e aggiungi il riferimento alla libreria:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Apri `Program.cs`. Il file conterrà il metodo `Main` dove inseriremo la logica **generate barcode C#**.

## Passo 2: Inizializzare il BarcodeGenerator per un codice a barre DataBar Stacked Omnidirectional

Il primo compito in qualsiasi flusso di lavoro **create databar barcode** è istanziare `BarcodeGenerator` con il corretto `EncodeType`. Il costruttore riceve la simbologia del codice a barre e la stringa di dati.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

Il valore `EncodeTypes.DatabarStackedOmniDirectional` indica alla libreria di produrre un **create databar barcode** che può essere scansionato da qualsiasi direzione.

## Passo 3: Configurare la X‑dimension (larghezza del modulo)

La X‑dimension controlla la larghezza minima della barra in pixel. Impostandola a un valore basso il codice a barre rimane compatto mantenendo la leggibilità.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Passo 4: **How to adjust aspect ratio** – primo valore (15)

I codici a barre DataBar espongono una proprietà `AspectRatio` che influenza il rapporto altezza‑larghezza. Un rapporto più alto genera un codice a barre più alto, il che può migliorare l'affidabilità della scansione su alcune stampanti.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Passo 5: **How to save barcode** – prima immagine (rapporto d'aspetto 15)

Ora salviamo effettivamente **how to save barcode** su un file. Il metodo `Save` accetta un percorso file e un formato immagine. In questo esempio salviamo un file PNG.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Suggerimento:** La directory dell'eseguibile è la posizione di scrittura predefinita. Usa un percorso assoluto se ti serve una cartella specifica.

## Passo 6: **How to adjust aspect ratio** – secondo valore (30)

Per dimostrare la flessibilità, cambia il rapporto d'aspetto e salva una seconda immagine. Questo mostra come gli stessi dati codificati possano essere renderizzati con proporzioni visive diverse.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Eseguendo il programma vengono prodotti due file PNG:

- `DatabarAspectRatio15.png` – codice a barre con altezza moderata  
- `DatabarAspectRatio30.png` – codice a barre con altezza maggiore per ambienti di scansione difficili  

Entrambi i file sono pronti per essere caricati nei controlli UI, stampati su etichette o trasmessi tramite API.

### Output previsto

Quando apri le immagini generate, dovresti vedere un DataBar Stacked Omnidirectional barcode che codifica il valore GTIN‑14 `12345678901231`. La differenza visiva tra i due file è solo l'altezza, confermando che **how to adjust aspect ratio** funziona come previsto.

## Passo 7: Codice sorgente completo per riferimento

Di seguito trovi il programma completo e eseguibile. Copialo in `Program.cs`, compila ed esegui.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Domande comuni e gestione dei casi limite

### Cosa succede se la cartella di destinazione non esiste?

`Save` genera una `DirectoryNotFoundException`. Crea prima la cartella:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Come cambiare il formato immagine?

Sostituisci `BarCodeImageFormat.Png` con `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` o `BarCodeImageFormat.Tiff` a seconda dei requisiti successivi.

### Posso generare più codici a barre in un ciclo?

Sì. Istanzia un nuovo `BarcodeGenerator` per ogni stringa di dati o riutilizza la stessa istanza aggiornando la proprietà `CodeText`:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### **how to save barcode** funziona su piattaforme non‑Windows?

Aspose.BarCode è cross‑platform. Lo stesso codice funziona su Linux e macOS purché sia presente il runtime .NET.
