# Come creare un codice a barre RM4SCC e generare il codice a barre planet in C#

Se hai bisogno di **creare un codice a barre RM4SCC** per applicazioni postali, questa guida ti mostra i passaggi esatti. Imparerai anche come **generare un codice a barre planet** con altezze sia automatiche che fisse, così lo stesso codice funziona per qualsiasi simbologia postale.

Il tutorial copre tutto il necessario per produrre immagini PNG che soddisfano gli standard postali. Non sono necessari strumenti esterni oltre alla libreria Aspose.BarCode per .NET. Alla fine, potrai generare codici a barre programmaticamente e controllare le loro dimensioni con precisione.

## Prerequisiti

* .NET 6.0 o versioni successive installate
* Visual Studio 2022 (o qualsiasi IDE C#)
* Pacchetto NuGet Aspose.BarCode per .NET  
  `Install-Package Aspose.BarCode`
* Permessi di scrittura nella directory di output

Questi elementi ti consentono di compilare ed eseguire il codice di esempio senza configurazioni aggiuntive.

## Passo 1: Inizializzare il generatore di codici a barre per RM4SCC

La prima operazione crea un'istanza di `BarcodeGenerator` configurata per la simbologia RM4SCC. Questo oggetto contiene tutte le impostazioni per l'immagine del codice a barre.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Perché è importante** – `EncodeTypes.RM4SCC` indica ad Aspose di utilizzare il formato postale RM4SCC, mentre la stringa di dati `"123456"` rappresenta il codice postale che desideri codificare.

## Passo 2: Impostare la larghezza del modulo (dimensione X)

La larghezza del modulo controlla la dimensione della barra sottile. Un valore comune per i codici a barre postali è 4 pixel.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Spiegazione** – La dimensione X influisce sulla leggibilità complessiva del codice a barre. Scegliere 4 px corrisponde alla maggior parte degli scanner postali.

## Passo 3: Salvare con altezza della barra automatica

Quando ometti un valore di altezza, Aspose calcola automaticamente l'altezza ottimale in base alle regole della simbologia.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Risultato** – Il PNG generato (`PostalRM4SCCBarHeightNone.png`) contiene un codice a barre RM4SCC di dimensioni corrette pronto per la stampa.

## Passo 4: Creare un codice a barre Planet con altezza automatica

Lo stesso schema funziona per la simbologia Planet. Inizia inizializzando il generatore con `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Perché riutilizzare il codice** – Sia RM4SCC che Planet condividono la stessa struttura dei parametri, così puoi cambiare simbologia modificando solo il valore di `EncodeTypes`.

## Passo 5: Definire un'altezza fissa della barra per RM4SCC

Alcuni servizi postali richiedono un'altezza della barra specifica (ad esempio, 100 px). Puoi impostarla esplicitamente prima di salvare.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Suggerimento** – Impostare `BarHeight.Pixels` sovrascrive il calcolo automatico, dandoti il pieno controllo sulla dimensione visiva.

## Passo 6: Definire un'altezza fissa della barra per Planet

Applica la stessa tecnica di altezza fissa a un codice a barre Planet.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Risultato** – Sia `PostalRM4SCCBarHeight100Pixels.png` che `PostalPlanetBarHeight100Pixels.png` contengono codici a barre con un'altezza della barra costante di 100 px, soddisfacendo le rigorose specifiche postali.

## Codice sorgente completo

Di seguito trovi il programma completo e eseguibile che comprende tutti e quattro gli esempi. Copialo in un nuovo progetto console e regola il percorso di output secondo necessità.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Output previsto** – Dopo aver eseguito il programma, la directory specificata contiene quattro file PNG:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC con altezza automatica
* `PostalPlanetBarHeightNone.png` – Planet con altezza automatica
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC con altezza di 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet con altezza di 100 px

Apri qualsiasi file per verificare che le barre siano nitide, la larghezza del modulo sia 4 px e l'altezza corrisponda all'impostazione scelta.

## Domande comuni e casi particolari

| Domanda | Risposta |
|----------|--------|
| **Posso usare altri formati immagine?** | Sì. Sostituisci `BarCodeImageFormat.Png` con `Jpeg`, `Bmp` o `Gif` secondo necessità. |
| **Cosa succede se la stringa di dati è più lunga?** | Il generatore regola automaticamente il numero di barre. Assicurati che i dati rispettino i limiti di lunghezza della simbologia (RM4SCC ≤ 6 cifre, Planet ≤ 6 cifre). |
| **Come cambio il colore della barra?** | Imposta `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` prima di chiamare `Save`. |
| **Il DPI è importante per la stampa?** | Puoi impostare `rm4sccAuto.Parameters.ImageResolution.DpiX` e `DpiY` per corrispondere alla risoluzione della tua stampante. |
