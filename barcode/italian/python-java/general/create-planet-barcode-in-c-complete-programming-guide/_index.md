# Crea barcode Planet in C# – guida completa di programmazione

Se hai bisogno di **creare barcode planet** in C#, questa guida ti mostra esattamente come farlo. Scoprirai anche **come impostare le dimensioni del barcode** in modo che le barre vengano renderizzate con la larghezza esatta che ti serve.

Generare barcode Planet è comune quando si lavora con servizi postali o sistemi logistici. Il codice qui sotto copre sia la versione predefinita a barre piene sia lo stile opzionale a barre vuote, oltre a un rapido esempio per il formato RM4SCC. Alla fine di questo tutorial avrai uno snippet riutilizzabile da inserire in qualsiasi progetto .NET.

## Prerequisiti

Prima di iniziare, assicurati di avere:

* .NET 6.0 o successivo installato (l'API funziona anche con .NET Framework 4.6+)
* Il pacchetto NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`) aggiunto al tuo progetto
* Un percorso di cartella scrivibile dove verranno salvati i file PNG
* Familiarità di base con la sintassi C# e Visual Studio (o qualsiasi IDE)

> **Pro tip:** Usa un percorso assoluto o `Path.Combine(Environment.CurrentDirectory, "output")` per evitare problemi di permessi durante il salvataggio delle immagini.

## Passo 1 – Inizializzare un generatore di barcode Planet (barre piene)

Il primo passo è creare un'istanza di `BarcodeGenerator` per la simbologia Planet. Per impostazione predefinita il generatore produce **barre piene**.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

L'enumerazione `EncodeTypes.Planet` indica ad Aspose.BarCode di utilizzare il formato Planet, mentre `"123456"` è il payload di dati che verrà codificato.

## Passo 2 – Come impostare le dimensioni del barcode per una dimensione coerente

Per controllare la larghezza di ogni barra, regola la **X‑dimension**. Questo è il modo principale per **impostare le dimensioni del barcode** e garantisce che il barcode si adatti alle dimensioni della tua etichetta.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

La proprietà `Pixels` definisce la larghezza della barra in pixel dello schermo. Valori comuni sono 2 – 5 pixel per etichette postali standard; aumenta il valore per stampe più grandi.

## Passo 3 – Salva il barcode Planet pieno come PNG

Ora scrivi l'immagine su disco. PNG conserva bordi nitidi, ideale per la scansione.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Sostituisci `YOUR_DIRECTORY` con il percorso che hai preparato in precedenza. Dopo aver eseguito questo codice vedrai un file simile all'immagine qui sotto.

## Passo 4 – Crea un barcode Planet con barre vuote (non riempite)

Se il tuo servizio postale richiede che le barre siano **vuote**, devi attivare il flag `FilledBars` dopo aver inizializzato il generatore.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Il costruttore è identico; la differenza sta nel passaggio di configurazione successivo.

## Passo 5 – Come impostare le dimensioni del barcode e rendere le barre vuote

Di nuovo, imposta la X‑dimension per coerenza visiva, quindi disabilita le barre piene.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

La proprietà `FilledBars = false` è quella che effettivamente cambia lo stile di rendering. Mantenere la stessa X‑dimension assicura che il barcode a barre vuote si allinei perfettamente con la versione a barre piene.

## Passo 6 – Salva il barcode Planet vuoto

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Ora avrai due file PNG: uno con barre solide e uno con barre vuote, entrambi con le stesse dimensioni.

## Passo 7 – (Facoltativo) Genera un barcode RM4SCC per confronto

RM4SCC è un'altra simbologia postale che utilizza lo stesso stile predefinito a barre piene. I passaggi rispecchiano l'esempio Planet, dimostrando che **come impostare le dimensioni del barcode** funziona su più formati.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Eseguendo questi tre passaggi si produce `PostalRM4SCCFilledBars.png`, che puoi confrontare fianco a fianco con le uscite Planet.

## Perché la X‑dimension è importante

La X‑dimension determina la **larghezza minima stampabile** di ogni barra. Se la imposti troppo bassa, il barcode può sfocare su stampanti a bassa risoluzione, causando errori di scansione. Al contrario, una X‑dimension troppo grande può superare le dimensioni dell'etichetta e sprecare spazio. Specificando esplicitamente **come impostare le dimensioni del barcode**, ottieni un controllo deterministico sulla dimensione finale dell'immagine, fondamentale per flussi di lavoro di spedizione automatizzati.

## Problemi comuni e come evitarli

| Issue | Cause | Fix |
|-------|-------|-----|
| Barcode appears stretched | X‑dimension set in points instead of pixels | Always use `Pixels` property for pixel‑perfect control |
| Empty bars still look filled | `FilledBars` not set to `false` after X‑dimension change | Set `FilledBars = false` *after* adjusting X‑dimension |
| Saved file is blank | Output directory does not exist or lacks write permission | Ensure the directory exists (`Directory.CreateDirectory`) and your app runs with sufficient rights |
| Image is blurry on print | Low DPI PNG saved from a high‑resolution monitor | Use `BarCodeImageFormat.Png` (lossless) and consider `Resolution` property if needed |

## Esempio completo, eseguibile

Copia l'intero blocco qui sotto in un nuovo progetto console (`dotnet new console`) ed eseguilo. Il programma crea tre file PNG nella cartella `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Expected output:** three PNG files—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png`, and `PostalRM4SCCFilledBars.png`—each 4‑pixel wide bars, ready for printing or further processing.

Prossimi passi consigliati:
