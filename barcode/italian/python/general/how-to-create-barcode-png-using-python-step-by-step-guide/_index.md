# Come creare barcode PNG usando Python – guida passo‑passo

Se hai bisogno di **creare barcode PNG** da stringhe arbitrarie, questo tutorial ti offre una soluzione pronta all'uso. Vedrai esattamente come generare un barcode Code 128, convertire del testo in un'immagine barcode e salvare il risultato come file PNG — il tutto con poche righe di Python.

La guida copre tutto ciò che devi sapere, dall'installazione della libreria necessaria alla personalizzazione dell'output per diversi casi d'uso. Alla fine, sarai in grado di incorporare la generazione di barcode in qualsiasi progetto Python senza dover cercare documentazione aggiuntiva.

## Cosa imparerai

* Installa il pacchetto **barcode generator python** che supporta Code 128.
* Usa `BarCodeGenerator` per **generare code 128 barcode** da una stringa di testo.
* Salva il risultato come PNG ad alta qualità con `save`.
* Regola la dimensione dell'immagine, i colori di primo piano/sfondo e gestisci gli errori comuni.
* Verifica che il PNG sia stato creato correttamente.

### Prerequisiti

| Requisito | Motivo |
|-------------|--------|
| Python 3.8+ | Sintassi moderna e type hints |
| Accesso a Internet (per `pip install`) | Per scaricare la libreria |
| Permesso di scrittura su una cartella | Per memorizzare il PNG generato |

Non sono richiesti servizi esterni; tutto viene eseguito localmente.

## Passo 1: Installa la libreria barcode

Il modo più semplice per **convertire testo in barcode** in Python è usare il pacchetto **Aspose.BarCode for Python via .NET**, che supporta Code 128 fin da subito.

```bash
pip install aspose-barcode
```

> **Pro tip:** Se lavori in un ambiente virtuale, attivalo prima di eseguire il comando per mantenere le dipendenze isolate.

## Passo 2: Importa le classi necessarie

Dopo l'installazione, importa le classi principali. Le istruzioni di importazione sono brevi, rendendo il codice facile da leggere.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` crea l'immagine barcode.
* `EncodeTypes` fornisce un'enumerazione delle simbologie supportate, inclusa `CODE_128`.

## Passo 3: Definisci il testo da codificare

Scegli qualsiasi stringa alfanumerica. Code 128 può rappresentare l'intero set ASCII, quindi non sei limitato ai numeri.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Se l'input contiene caratteri non supportati, il generatore solleva un `ValueError`. Avvolgi l'assegnazione in un blocco `try` se ti aspetti dati forniti dall'utente.

## Passo 4: Crea il generatore di barcode per Code 128

Istanzia `BarCodeGenerator` con la simbologia desiderata e il testo che hai definito. Questo è il cuore di **come generare barcode** in Python.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Perché Code 128? Offre alta densità e può codificare l'intero intervallo ASCII, rendendolo ideale per sistemi di inventario, etichette di spedizione e ticketing.

## Passo 5: (Opzionale) Personalizza l'aspetto

Puoi perfezionare il barcode prima di salvarlo. Le seguenti opzioni sono comuni:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Queste impostazioni influenzano l'output finale **create barcode png** senza alterare i dati codificati.

## Passo 6: Salva il barcode come file PNG

Infine, scrivi l'immagine su disco. Il metodo `save` rileva automaticamente l'estensione del file, quindi passando `.png` si crea un'immagine PNG.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Se la directory di destinazione non esiste, Python solleva un `FileNotFoundError`. Crea la directory in anticipo o usa `os.makedirs` con `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### Output previsto

Dopo aver eseguito lo script, troverai `extended_barcode.png` nella cartella `output`. Aprire il file mostra un barcode Code 128 nitido che codifica `1234567890`.

## Passo 7: Verifica il barcode (controllo rapido)

Puoi leggere il PNG con la stessa libreria per confermare che il valore codificato corrisponda al testo originale.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

L'esecuzione di questo blocco stampa:

```
Verification succeeded: 1234567890
```

Se l'asserzione fallisce, ricontrolla `barcode_text` e qualsiasi parametro personalizzato impostato.

## Variazioni comuni e casi limite

| Situazione | Adeguamento |
|-----------|------------|
| **Testo più lungo (> 20 caratteri)** | Aumenta `image_width` per evitare troncamenti. |
| **Necessità di sfondo trasparente** | Imposta `back_color = "Transparent"` prima di salvare. |
| **Genera più barcode in un ciclo** | Avvolgi i passi 3‑6 in un ciclo `for`, modificando `barcode_text` ad ogni iterazione. |
| **Salva come JPEG invece di PNG** | Cambia l'estensione del file in `.jpg`; la libreria gestisce il formato automaticamente. |
| **Esecuzione su server headless** | La libreria non richiede una GUI, rendendola sicura per pipeline CI. |

## Script completo per copia‑incolla veloce

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Salva lo script come `generate_barcode.py` ed esegui:

```bash
python generate_barcode.py
```

Vedrai i messaggi di conferma e un nuovo file PNG nella cartella `output`.
