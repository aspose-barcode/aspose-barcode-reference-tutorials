# Menghasilkan barcode PDF417 dengan Aspose Barcode Generator – Panduan C#

Jika Anda perlu **menghasilkan barcode PDF417** dalam proyek .NET, tutorial ini menunjukkan secara tepat cara melakukannya dengan **Aspose Barcode Generator**. Anda akan melihat contoh lengkap yang dapat dijalankan yang membuat simbol PDF417 yang kompak, menyesuaikan ukurannya, dan menyimpan hasilnya sebagai file PNG.

Membuat barcode PDF417 umum dilakukan ketika Anda harus mengkodekan sejumlah besar data—seperti URL, informasi kontak, atau catatan inventaris—ke dalam satu gambar yang dapat dipindai. Panduan ini mencakup semua hal mulai dari instalasi pustaka hingga penyesuaian **cara mengatur PDF417** untuk output yang kompak.

## Apa yang akan Anda pelajari

* Menginstal dan mereferensikan pustaka Aspose.BarCode dalam proyek C#.  
* Menggunakan **aspose barcode generator** untuk membuat simbol PDF417 dari teks apa pun.  
* Menerapkan parameter **cara mengatur PDF417** — ukuran modul, jumlah kolom, dan mode kompak.  
* Menyimpan barcode sebagai gambar PNG dan memverifikasi hasilnya.  

**Prasyarat**

* .NET 6.0 SDK atau yang lebih baru (kode ini juga berfungsi dengan .NET Core 3.1 dan .NET Framework 4.7+).  
* Familiaritas dasar dengan aplikasi konsol C#.  
* Lisensi Aspose.BarCode yang valid (versi evaluasi gratis dapat digunakan untuk pengembangan).

## Langkah 1: Menghasilkan barcode PDF417 – buat generatornya

Tugas pertama adalah menginstansiasi generator dengan teks yang diinginkan dan simbolologi PDF417. Langkah ini menjawab pertanyaan **cara menghasilkan pdf417** secara langsung.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Create a BarcodeGenerator for PDF417 with the data you want to encode.
            // The EncodeTypes enum selects the symbology; Pdf417 is the target type.
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");
```

**Mengapa ini penting:**  
`EncodeTypes.Pdf417` memberi tahu pustaka untuk menggunakan algoritma PDF417, yang mendukung hingga 1.850 karakter. Konstruktor juga menerima string data mentah; semua karakter Unicode (termasuk aksen) ditangani secara otomatis.

## Langkah 2: Cara mengatur parameter PDF417 – sesuaikan ukuran dan tata letak

Barcode PDF417 dapat dirender dalam banyak bentuk. Menyesuaikan opsi **cara mengatur pdf417** memungkinkan Anda membuat simbol kompak yang muat pada label kecil atau layar seluler.

```csharp
            // -----------------------------------------------------------------
            // Step 2: Set visual parameters for the barcode
            // -----------------------------------------------------------------

            // Module size – each tiny square (pixel) of the barcode.
            // Smaller values produce a tighter image; 2 pixels is a good default.
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Number of columns – controls the width of the barcode.
            // Fewer columns make the symbol taller; 3 columns yields a compact shape.
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode – removes unnecessary quiet zones and reduces height.
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Penjelasan masing‑masing pengaturan**

| Parameter | Efek | Kapan digunakan |
|-----------|------|-----------------|
| `XDimension.Pixels` | Mengontrol lebar satu modul. Nilai yang lebih rendah memperkecil barcode tetapi dapat memengaruhi keterbacaan pemindai pada perangkat beresolusi rendah. | Gunakan `2`–`4` untuk tampilan di layar; tingkatkan untuk label cetak. |
| `Pdf417.Columns` | Menentukan berapa banyak kolom data yang dimiliki simbol. Lebih sedikit kolom menghasilkan barcode yang lebih tinggi dan lebih sempit. | Pilih `3`–`5` untuk tata letak kompak; nilai lebih tinggi untuk barcode yang lebih lebar. |
| `Pdf417.Truncate` | Mengaktifkan “mode kompak” yang menghapus zona tenang di luar dan mengurangi tinggi keseluruhan. | Ideal untuk elemen UI di mana ruang terbatas. |

Ketiga pengaturan ini bersama‑sama menjawab bagian **cara mengatur pdf417** dari tugas, memberi Anda kontrol halus atas gambar akhir.

## Langkah 3: Menyimpan gambar barcode – ekspor sebagai PNG

Setelah mengonfigurasi generator, Anda perlu menulis barcode ke file. Metode `Save` mendukung banyak format; PNG mempertahankan kualitas lossless dan bekerja baik untuk skenario web maupun desktop.

```csharp
            // -----------------------------------------------------------------
            // Step 3: Save the generated barcode as a PNG image
            // -----------------------------------------------------------------

            // Replace YOUR_DIRECTORY with an actual folder on your machine.
            string outputPath = @"C:\Barcodes\CompactPdf417.png";

            // BarCodeImageFormat.Png tells Aspose to write a PNG file.
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            // Inform the user that the process succeeded.
            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**Apa yang akan Anda lihat**

Menjalankan program akan membuat `CompactPdf417.png` di folder yang ditentukan. Gambar tersebut berisi simbol PDF417 yang padat yang mengkodekan string `Åspóse.Barcóde©`. Sebagian besar pemindai barcode dan aplikasi seluler (misalnya ZXing, Scandit) dapat membaca gambar ini tanpa konfigurasi tambahan.

## Kode sumber lengkap – satu file siap salin‑tempel

Berikut adalah program lengkap, termasuk direktif `using` dan metode `Main`. Anda dapat menyalin ini ke proyek konsol baru dan menjalankannya langsung.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Step 1: Create the generator (how to generate pdf417)
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");

            // Step 2: Set PDF417 options (how to set pdf417)
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;   // module size
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;    // number of columns
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact mode

            // Step 3: Save as PNG
            string outputPath = @"C:\Barcodes\CompactPdf417.png";
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**Menjalankan kode**

1. Buka terminal dan buat proyek konsol baru:  
   `dotnet new console -n Pdf417Demo`  
2. Tambahkan paket NuGet Aspose.BarCode:  
   `dotnet add package Aspose.BarCode`  
3. Ganti `Program.cs` yang dihasilkan dengan kode di atas.  
4. Build dan jalankan:  
   `dotnet run`  

Anda akan melihat pesan konfirmasi dan menemukan file PNG di lokasi yang Anda tentukan.

## Kesulitan umum dan tip praktik terbaik

* **Kedaluwarsa lisensi** – Versi evaluasi menambahkan watermark setelah 30 hari. Daftarkan lisensi lebih awal untuk menghindari kejutan.  
* **Izin direktori** – Pastikan folder target ada dan proses memiliki hak tulis; jika tidak `Save` akan melempar `UnauthorizedAccessException`.  
* **Kompatibilitas pemindai** – Jika pemindai gagal membaca barcode kompak, tingkatkan `XDimension.Pixels` menjadi `4` atau setel `Truncate = false`.  
* **Penanganan Unicode** – Aspose.BarCode sepenuhnya mendukung UTF‑8; Anda dapat mengkodekan string Unicode apa pun tanpa langkah tambahan.  
* **Kinerja** – Menghasilkan banyak barcode dalam loop akan lebih efisien jika menggunakan satu instance `BarcodeGenerator` dan hanya memperbarui `CodeText` di antara iterasi.
