# Hasilkan kode batang PDF417 dengan pengaturan kompak di C#

Jika Anda perlu **menghasilkan kode batang PDF417** dalam aplikasi .NET, panduan ini menunjukkan cara melakukannya dengan Aspose.Barcode untuk .NET. Kami akan menjelaskan pembuatan generator, mengonfigurasi kolom, X‑dimension, dan mengaktifkan mode kompak sehingga simbol yang dihasilkan sekecil mungkin.

Membuat kode batang PDF417 umum ketika Anda harus mengkodekan sejumlah besar data untuk tiket, ID, atau label pengiriman. Tutorial ini mencakup seluruh alur kerja—dari menginstal pustaka hingga menyimpan PNG akhir—sehingga Anda dapat menyalin‑tempel kode ke dalam proyek Anda sendiri dan menjalankannya segera.

## Prasyarat untuk menghasilkan kode batang PDF417

* .NET 6.0 (atau yang lebih baru) terinstal.  
* Visual Studio 2022 atau IDE apa pun yang mendukung proyek C#.  
* Lisensi NuGet untuk **Aspose.Barcode for .NET** (versi percobaan gratis cukup untuk belajar).  

Anda dapat menambahkan pustaka dengan perintah berikut:

```bash
dotnet add package Aspose.BarCode
```

> **Tip profesional:** Gunakan flag `--version` untuk mengunci versi stabil yang diketahui, misalnya, `dotnet add package Aspose.BarCode --version 23.12`.

## Buat generator kode batang PDF417

Blok kode pertama membuat instance `BarcodeGenerator` yang telah dikonfigurasi sebelumnya untuk simbol PDF417. Teks `"Åspóse.Barcóde©"` berisi karakter Unicode untuk menunjukkan bahwa generator menangani input non‑ASCII secara langsung.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Mengapa ini penting
`EncodeTypes.Pdf417` memberi tahu Aspose.Barcode bahwa Anda menginginkan **kode batang PDF417**, yang merupakan simbol linear bertumpuk yang dapat menyimpan hingga 1 850 karakter. Menggunakan konstruktor dengan argumen teks menghemat pemanggilan `SetCodeText` nanti.

## Atur XDimension kode batang (ukuran modul)

Ukuran modul, juga dikenal sebagai X‑dimension, menentukan seberapa lebar setiap bar individu. Piksel yang lebih kecil menghasilkan gambar yang lebih padat, sementara piksel yang lebih besar meningkatkan keterbacaan pada printer beresolusi rendah.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### Mengapa Anda harus menyesuaikan XDimension
Nilai `2` piksel bekerja baik untuk tampilan layar dan kebanyakan printer kantor. Jika Anda memerlukan cetakan beresolusi lebih tinggi, tingkatkan nilainya; jika Anda memerlukan kode batang yang lebih rapat (mis., untuk tampilan mirip QR), turunkan nilainya—tetapi jangan pernah di bawah `1` piksel, karena gambar akan menjadi tidak terbaca.

## Atur jumlah kolom untuk simbol PDF417

PDF417 memungkinkan Anda memilih berapa banyak kolom (tumpukan vertikal) yang dimiliki kode batang. Lebih sedikit kolom membuat kode batang lebih tinggi; lebih banyak kolom membuatnya lebih lebar.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### Kapan mengubah jumlah kolom
Tiga kolom menghasilkan simbol kompak, hampir berbentuk persegi yang pas pada kartu ID standar. Jika Anda memiliki string yang sangat panjang, Anda dapat meningkatkan jumlah kolom untuk menjaga tinggi tetap wajar.

## Aktifkan mode kompak (pemotongan)

Mode kompak secara otomatis menghapus baris yang tidak terpakai dari simbol, mengecilkan ukuran keseluruhan. Ini sangat berguna ketika data yang dikodekan tidak mengisi seluruh matriks.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Manfaat kode batang PDF417 kompak
Ketika `Truncate` bernilai `true`, generator menghitung jumlah baris minimal yang diperlukan untuk menyimpan data Anda, yang mengurangi penggunaan tinta dan waktu pemindaian. Ini aman untuk kebanyakan pemindai karena spesifikasi PDF417 mendefinisikan algoritma pemotongan.

## Simpan kode batang yang dihasilkan sebagai gambar

Akhirnya, tulis kode batang ke file PNG. PNG mempertahankan kualitas lossless, menjadikannya ideal untuk pencetakan nanti atau penyematan dalam PDF.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Output yang diharapkan
Menjalankan program akan membuat `CompactPdf417.png` di folder yang ditentukan. Gambar tersebut berisi **kode batang PDF417 kompak** yang mengkodekan string `"Åspóse.Barcóde©"` dengan tiga kolom, X‑dimension 2 piksel, dan pemotongan diterapkan. Anda dapat memverifikasi hasilnya dengan aplikasi pemindai kode batang apa pun atau demo online gratis Aspose.Barcode.

## Variasi umum dan kasus tepi

| Situasi | Penyesuaian |
|-----------|------------|
| **Data sangat panjang (> 1500 karakter)** | Tingkatkan `Columns` atau atur `Rows` secara manual (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Mencetak pada printer low‑dpi** | Naikkan `XDimension.Pixels` menjadi 3 atau 4 untuk menghindari pixelasi. |
| **Membutuhkan latar belakang transparan** | Gunakan `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **Menyematkan dalam PDF** | Simpan sebagai `BarCodeImageFormat.Pdf` atau dapatkan objek `Image` melalui `pdf417Generator.GenerateBarCodeImage()`. |

## Contoh lengkap yang dapat dijalankan

Berikut adalah program lengkap yang dapat Anda salin ke dalam proyek konsol baru. Tidak diperlukan file tambahan.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Jalankan `dotnet run` dari folder proyek. Setelah eksekusi, buka `CompactPdf417.png` untuk melihat kode batang yang dihasilkan.

## Kesimpulan

Anda kini tahu cara **menghasilkan kode batang PDF417** di C# dengan kontrol penuh atas kolom, X‑dimension, dan mode kompak. Dengan menyesuaikan `barcode XDimension pixels`, `set PDF417 columns`, dan mengaktifkan pemotongan `compact PDF417 barcode`, Anda dapat menghasilkan kode batang yang sesuai dengan batas ukuran tepat aplikasi Anda.

Langkah selanjutnya yang dapat Anda jelajahi:

* Mengkodekan set data yang lebih besar dan bereksperimen dengan parameter `Rows`.  
* Mengubah format output menjadi `BarCodeImageFormat.Svg` untuk grafik web yang dapat diskalakan.  
* Menggabungkan kode batang dengan komponen Aspose lainnya, seperti **Aspose.PDF**, untuk menyematkan gambar langsung ke dalam laporan PDF.

Selamat coding, dan silakan sesuaikan pengaturan untuk mencocokkan lingkungan pemindaian spesifik Anda!
