# Cara menghasilkan barcode di C# dengan Aspose.BarCode dan menambahkan metadata

Jika Anda perlu **menghasilkan barcode di C#** untuk sistem logistik atau inventaris, panduan ini menunjukkan solusi lengkap yang siap produksi. Anda akan melihat cara membuat barcode Macro PDF417, melampirkan metadata kaya, dan menetapkan timestamp yang tepat—semua dengan pustaka Aspose.BarCode.

Tutorial ini mencakup semua hal mulai dari menginstal paket NuGet hingga menyimpan gambar PNG akhir. Pada akhir tutorial, Anda dapat menghasilkan barcode yang membawa pengidentifikasi file, informasi segmen, dan bidang khusus, siap untuk pemindai hilir yang mendukung Macro PDF417.

## Prasyarat

* .NET 6.0 SDK atau yang lebih baru (kode juga berfungsi dengan .NET Framework 4.7.2+)
* Visual Studio 2022 atau IDE C# apa pun yang Anda sukai
* Lisensi Aspose.BarCode yang aktif (versi percobaan gratis dapat digunakan untuk pengembangan)
* Familiaritas dasar dengan sintaks C#

> **Tips profesional:** Jika Anda menggunakan pipeline CI/CD, tambahkan referensi paket Aspose.BarCode di file proyek Anda agar build tetap dapat direproduksi.

## Langkah 1: Instal Aspose.BarCode

Buka terminal di folder proyek Anda dan jalankan:

```bash
dotnet add package Aspose.BarCode
```

Perintah ini mengambil versi stabil terbaru (saat ini 24.9). Setelah proses restore selesai, Anda dapat merujuk pustaka tersebut dalam file sumber Anda.

## Langkah 2: Buat proyek konsol C# baru (opsional)

Jika Anda lebih suka memulai dari awal, buat aplikasi konsol:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

File `Program.cs` akan menampung kode pembuatan barcode yang ditunjukkan nanti.

## Langkah 3: Siapkan generator barcode

Inti dari proses ini adalah kelas `BarcodeGenerator`. Anda menginstansiasikannya dengan nilai enum `EncodeTypes` yang diinginkan dan teks yang ingin Anda enkode.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Mengapa setiap baris penting

- **EncodeTypes.MacroPdf417** memberi tahu Aspose untuk menghasilkan barcode PDF417 yang dapat dibagi menjadi segmen. Ini penting untuk payload besar yang melebihi kapasitas satu simbol.
- **XDimension.Pixels** mengontrol kepadatan visual. Nilai 2 menghasilkan gambar yang jelas pada kebanyakan layar dan printer tanpa memperbesar ukuran file.
- **MacroPdf417* properties** menyematkan metadata yang dibaca pemindai hilir sebagai bidang terpisah (file ID, segment ID, dll.). Ini adalah bagian “cara menambahkan metadata” dalam tutorial.
- **MacroPdf417TimeStamp** menunjukkan “cara mengatur timestamp”. Instance `DateTime` dapat berupa waktu UTC apa pun; menggunakan UTC menghindari ambiguitas zona waktu ketika barcode berpindah antar wilayah.
- **MacroPdf417Terminator** menentukan bagaimana urutan makro berakhir. `Set` adalah pilihan paling umum karena menandakan segmen akhir kepada pembaca.
- **Save(..., BarCodeImageFormat.Png)** menulis gambar lossless yang mempertahankan detail halus yang diperlukan untuk pemindaian yang dapat diandalkan.

## Langkah 4: Verifikasi barcode yang dihasilkan

Jalankan program:

```bash
dotnet run
```

Anda akan melihat output konsol:

```
Barcode saved to ExtPDF417Meta.png
```

Buka `ExtPDF417Meta.png` di penampil gambar apa pun. Gambar tersebut akan menampilkan simbol PDF417 yang kompak dengan teks **Åspóse.Barcóde©** dan bidang makro yang disematkan. Memindai gambar dengan pemindai yang kompatibel dengan PDF417 (atau aplikasi seluler yang mendukung Macro PDF417) akan mengembalikan teks asli plus nilai metadata yang Anda tetapkan.

### Karakteristik visual yang diharapkan

- Bar vertikal gelap yang terpisah merata
- Zona tenang (margin) yang secara otomatis ditambahkan oleh Aspose
- Tanpa distorsi, karena `XDimension` sebesar 2 piksel cocok dengan resolusi asli PNG

## Langkah 5: Variasi umum dan kasus tepi

### 5.1 Menangani karakter khusus

Teks contoh berisi karakter Unicode (`Å`, `ó`, `©`). Aspose.BarCode mengenkodenya menggunakan UTF‑8 secara default, sehingga tampil dengan benar di barcode. Jika Anda memerlukan enkoding berbeda (misalnya ISO‑8859‑1), atur:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Pengidentifikasi file besar

`MacroPdf417FileID` menerima integer 32‑bit. Untuk nilai yang lebih besar dari `int.MaxValue`, bagi pengidentifikasi ke beberapa bidang atau gunakan GUID yang disimpan sebagai string di `MacroPdf417FileName`.

### 5.3 Menyesuaikan jumlah kolom

Meningkatkan `Pdf417.Columns` mengurangi tinggi barcode tetapi memperlebar setiap baris. Jika barcode harus muat pada label sempit, turunkan jumlah kolom dan tingkatkan jumlah baris secara otomatis.

### 5.4 Menyimpan dalam format lain

Aspose mendukung BMP, JPEG, TIFF, dan SVG. Ganti `BarCodeImageFormat.Png` dengan nilai enum yang diinginkan, misalnya `BarCodeImageFormat.Svg` untuk grafik vektor yang dapat diskalakan.

## Langkah 6: Integrasikan barcode ke dalam alur kerja yang lebih besar

Setelah Anda memiliki file PNG, Anda dapat:

- Menyematkannya dalam faktur PDF menggunakan Aspose.PDF.
- Melampirkannya ke email sebagai bukti pengiriman.
- Menyimpan byte gambar dalam basis data untuk pengambilan di kemudian hari.

Berikut adalah cuplikan cepat yang mengonversi PNG menjadi array byte untuk penyimpanan:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Pertanyaan yang sering diajukan

**Q: Apakah ini bekerja pada .NET Core?**  
A: Ya. API yang sama bekerja pada .NET Core, .NET 5+, dan .NET Framework. Cukup referensikan paket NuGet yang sesuai.

**Q: Bagaimana jika saya perlu menghasilkan PDF417 non‑macro?**  
A: Gunakan `EncodeTypes.Pdf417` alih-alih `EncodeTypes.MacroPdf417`. Properti khusus macro akan diabaikan.

**Q: Bisakah saya menambahkan pasangan kunci/nilai khusus di luar bidang bawaan?**  
A: Aspose.BarCode tidak menyediakan bidang pengguna arbitrer untuk Macro PDF417. Jika Anda memerlukan data tambahan, enkode dalam payload teks utama atau beralih ke kode QR, yang mendukung structured append.
