# Cara menghasilkan PDF417 barcode di C# – contoh kompak

Jika Anda perlu **menghasilkan PDF417 barcode** dalam aplikasi C#, panduan ini menunjukkan solusi lengkap yang siap dijalankan. Kami akan membuat barcode PDF417 yang kompak, menyesuaikan lebar modul, menentukan jumlah kolom, dan menyimpan hasilnya sebagai gambar PNG—semua dengan library Aspose.BarCode .NET.

Membuat barcode PDF417 umum dilakukan ketika Anda ingin mengkodekan sejumlah besar data (misalnya, URL, kartu kontak, atau ID inventaris) dalam format dua dimensi yang efisien ruang. Pada akhir tutorial ini Anda akan memiliki instance `BarcodeGenerator` yang berfungsi dan menghasilkan barcode kompak dengan tingkat keterbacaan tinggi, siap untuk dicetak atau ditampilkan.

## Prasyarat

- .NET 6.0 atau lebih baru (kode ini juga berfungsi dengan .NET Framework 4.8)
- Visual Studio 2022 (atau IDE C# apa pun)
- Paket NuGet Aspose.BarCode untuk .NET (`Install-Package Aspose.BarCode`)
- Familiaritas dasar dengan sintaks C#

Tidak diperlukan konfigurasi tambahan; contoh ini berjalan sebagai aplikasi konsol.

## Langkah 1: Buat generator barcode PDF417

Langkah pertama adalah menginstansiasi `BarcodeGenerator` dengan enum `EncodeTypes.Pdf417` dan teks yang ingin Anda enkode.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Mengapa ini penting:** `EncodeTypes.Pdf417` memberi tahu library untuk menggunakan simbol PDF417, sementara argumen kedua menentukan payload data. Anda dapat mengganti `"Compact example"` dengan string apa pun hingga 1 800 karakter.

## Langkah 2: Atur lebar modul (dimensi X) dalam piksel

Dimensi X menentukan lebar satu modul barcode (kotak hitam atau putih terkecil). Nilai piksel yang lebih kecil menghasilkan barcode yang lebih rapat.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Mengapa ini penting:** Nilai `2` piksel menghasilkan tampilan kompak tanpa mengorbankan keandalan pemindaian pada kebanyakan pemindai modern. Sesuaikan nilai tersebut jika Anda memerlukan modul yang lebih besar untuk pencetakan beresolusi rendah.

## Langkah 3: Tentukan jumlah kolom

PDF417 memungkinkan Anda mengontrol jumlah kolom, yang memengaruhi rasio aspek barcode.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Mengapa ini penting:** Lebih sedikit kolom membuat barcode lebih tinggi, sementara lebih banyak kolom membuatnya lebih datar. Tiga kolom bekerja baik untuk tata letak kompak dengan orientasi potret.

## Langkah 4: Aktifkan mode kompak dengan memotong barcode

Mode kompak menghapus baris padding yang tidak diperlukan, membuat barcode lebih kecil sambil mempertahankan data yang dienkode.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Mengapa ini penting:** Pemotongan ideal ketika ruang layar terbatas (misalnya, aplikasi seluler atau label kecil). Barcode tetap sepenuhnya dapat dibaca karena algoritma enkoding secara otomatis menyesuaikan tingkat koreksi kesalahan.

## Langkah 5: Simpan barcode sebagai gambar PNG

Akhirnya, tulis barcode yang dihasilkan ke sebuah file. PNG mempertahankan kualitas loss‑less, yang penting untuk pemindai barcode.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Menjalankan program akan membuat `CompactPdf417.png` di direktori kerja executable. Gambar tersebut terlihat seperti ini:

![Barcode PDF417 kompak yang dihasilkan](CompactPdf417.png "Barcode PDF417 kompak yang dihasilkan")

**Output yang diharapkan:** Barcode PDF417 lebar 2 piksel, tiga kolom yang mengenkode teks “Compact example”. Memindai PNG dengan pemindai barcode standar harus mengembalikan string asli.

## Variasi umum dan kasus tepi

| Situasi | Cara menyesuaikan kode |
|-----------|------------------------|
| **Data lebih panjang ( > 500 karakter )** | Tingkatkan `Columns` menjadi 5‑7 untuk mencegah barcode menjadi terlalu tinggi. |
| **Pencetakan resolusi tinggi** | Setel `XDimension.Pixels` ke 3 atau 4 untuk modul yang lebih besar. |
| **Format gambar berbeda** | Ganti `BarCodeImageFormat.Png` dengan `Jpeg` atau `Bmp` sesuai kebutuhan. |
| **Menyematkan barcode dalam PDF** | Gunakan `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` alih-alih PNG. |

**Tips pro:** Selalu uji barcode yang dihasilkan pada perangkat pemindai target. Beberapa pemindai murah kesulitan dengan dimensi X yang sangat kecil; jika Anda menemukan kesalahan pembacaan, tingkatkan nilai piksel satu langkah.

## Contoh lengkap yang dapat dijalankan

Berikut adalah program lengkap yang dapat Anda salin‑tempel ke proyek konsol baru. Tidak diperlukan file tambahan.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Kompilasi dan jalankan program (`dotnet run` jika Anda menggunakan .NET CLI). Setelah eksekusi, buka `CompactPdf417.png` untuk memverifikasi hasil visual.

## Kesimpulan

Anda kini tahu **cara menghasilkan PDF417 barcode** di C# dengan tata letak kompak, X‑dimension khusus, dan pengaturan kolom. Contoh ini menunjukkan langkah-langkah penting: menginstansiasi `BarcodeGenerator`, mengonfigurasi `XDimension` dan `Columns`, mengaktifkan `Truncate` untuk mode kompak, dan akhirnya menyimpan gambar.

Dari sini Anda dapat menjelajahi fitur tambahan seperti tingkat koreksi kesalahan, warna khusus, atau menyematkan barcode langsung ke PDF. Bereksperimenlah dengan `EncodeTypes` yang berbeda jika Anda memerlukan simbol lain (misalnya, QR, Code128) dan integrasikan pola konfigurasi parameter yang sama.

Selamat coding, dan semoga barcode Anda selalu dapat dipindai pada percobaan pertama!
