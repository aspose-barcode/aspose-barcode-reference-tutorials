# Menghasilkan barcode PDF417 di C# menggunakan Aspose – panduan langkah‑demi‑langkah

Jika Anda perlu **menghasilkan barcode PDF417** dalam aplikasi .NET, panduan ini menunjukkan secara tepat caranya. Anda akan melihat contoh lengkap yang siap‑jalan yang membuat barcode PDF417 dasar, kompak, Micro, GS1‑Micro, dan Macro dengan Aspose.BarCode untuk .NET.

Menghasilkan barcode PDF417 adalah kebutuhan umum untuk label pengiriman, dokumen transportasi, dan sistem inventaris. Pada akhir tutorial ini Anda akan dapat **menghasilkan gambar barcode PDF417**, memahami parameter kunci, dan menyesuaikan kode untuk muatan data Anda sendiri.

## Prerequisites

- .NET 6.0 SDK atau yang lebih baru (kode juga berfungsi dengan .NET Framework 4.7+)
- Visual Studio 2022 atau IDE C# apa saja
- Paket NuGet Aspose.BarCode untuk .NET (`Aspose.BarCode`) terpasang
- Familiaritas dasar dengan sintaks C#

> **Pro tip:** Gunakan lisensi evaluasi gratis dari Aspose untuk menghindari pembatasan runtime saat pengujian.

## Langkah 1: Siapkan proyek dan impor namespace

Buat proyek konsol baru dan tambahkan paket Aspose.BarCode:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Kemudian buka `Program.cs` dan tambahkan directive `using` yang diperlukan:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Namespace ini memberi Anda akses ke kelas `BarcodeGenerator` dan enumerasi `EncodeTypes` yang dibutuhkan untuk **menghasilkan barcode menggunakan C#**.

## Langkah 2: Hasilkan barcode PDF417 dasar

Barcode PDF417 paling sederhana menggunakan pengaturan default kecuali dimensi X (lebar modul) dan jumlah kolom. Menyesuaikan nilai‑nilai ini mengontrol ukuran keseluruhan dan keterbacaan.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Mengapa ini berhasil:**  
- `EncodeTypes.Pdf417` memberi tahu Aspose untuk menggunakan simbol PDF417.  
- `XDimension.Pixels` menentukan lebar bar terkecil; nilai 2 menjaga gambar tetap kecil tanpa mengorbankan kemampuan pemindaian.  
- `Pdf417.Columns` menentukan berapa banyak kolom data yang dimiliki barcode; tiga kolom memberikan rasio aspek yang seimbang.

## Langkah 3: Hasilkan barcode PDF417 kompak (dipotong)

Mode kompak menghapus pola berhenti dan mengurangi tinggi keseluruhan, yang berguna untuk label dengan ruang terbatas.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Mengapa ini berhasil:**  
Menetapkan `Pdf417.Truncate = true` mengaktifkan mode terpotong, yang menghilangkan pola berhenti di sisi kanan dan mengurangi tinggi barcode sambil mempertahankan integritas data.

## Langkah 4: Hasilkan barcode Micro PDF417

Micro PDF417 adalah varian yang lebih kecil yang mendukung 1‑4 kolom. Ini ideal untuk aplikasi di mana ruang sangat terbatas, seperti label produk kecil.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Mengapa ini berhasil:**  
- `EncodeTypes.MicroPdf417` memilih versi mikro dari simbol tersebut.  
- Jumlah kolom dapat antara 1 dan 4; memilih 4 menghasilkan tata letak paling padat sambil tetap dapat dipindai.

## Langkah 5: Hasilkan barcode Micro PDF417 yang mematuhi GS1

Prefiks GS1 menambahkan pengenal standar (misalnya GTIN, nomor batch) ke data barcode. Aspose memungkinkan Anda menyematkan ini secara langsung.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Mengapa ini berhasil:**  
Application Identifiers (AIs) GS1 ditempatkan dalam tanda kurung. Aspose mem‑parse‑nya dan menambahkan format yang diperlukan oleh pemindai GS1.

## Langkah 6: Hasilkan barcode Macro PDF417 dengan metadata lengkap

Macro PDF417 memungkinkan Anda membagi muatan data besar ke beberapa barcode yang terhubung. Anda dapat menyematkan metadata tingkat file seperti ID file, jumlah segmen, cap waktu, dan string khusus.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Mengapa ini berhasil:**  
Setiap properti `MacroPdf417*` memetakan ke segmen spesifik dari spesifikasi barcode macro. Menetapkan nilai‑nilai ini memastikan pemindai dapat merekonstruksi file asli dari beberapa gambar barcode.
