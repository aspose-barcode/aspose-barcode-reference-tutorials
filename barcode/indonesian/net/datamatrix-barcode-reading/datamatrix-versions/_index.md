# Cara menghasilkan kode batang DataMatrix dengan Aspose.BarCode untuk .NET

Jika Anda memerlukan cara yang dapat diandalkan untuk menyematkan simbol yang dapat dibaca mesin dalam aplikasi .NET Anda, **cara menghasilkan DataMatrix** adalah kebutuhan yang umum. Aspose.BarCode untuk .NET menawarkan API yang sepenuhnya dikelola yang menangani setiap langkah—dari memilih versi DataMatrix yang tepat hingga menyempurnakan tingkat koreksi kesalahan—tanpa memerlukan alat eksternal. Dalam tutorial ini kami akan membahas contoh lengkap, menjelaskan mengapa setiap pengaturan penting, dan menunjukkan cara menyimpan hasilnya sebagai gambar PNG atau JPEG.

## Jawaban Cepat
- **Perpustakaan apa yang membuat kode batang DataMatrix?** Aspose.BarCode untuk .NET.  
- **Berapa banyak versi DataMatrix yang didukung?** Semua 30 versi standar persegi dan persegi panjang (dari 10×10 hingga 144×144 modul).  
- **Tipe ECC mana yang dapat saya gunakan?** ECC200 (default) dan ECC140.  
- **Apakah saya memerlukan lisensi untuk pengembangan?** Versi percobaan gratis 30 hari cukup untuk pengujian; lisensi komersial diperlukan untuk produksi.  
- **Dapatkah saya menjalankannya di .NET 6, .NET Core, atau .NET Framework?** Ya—Aspose.BarCode mendukung .NET Framework 4.5+, .NET Core 3.1+, dan .NET 5/6+.

## Apa itu kode batang DataMatrix?
Kode batang DataMatrix adalah matriks dua dimensi, persegi atau persegi panjang, yang terdiri dari sel hitam dan putih dan dapat menyimpan hingga 2.335 karakter alfanumerik. Kode ini banyak digunakan dalam manufaktur, logistik, dan perawatan kesehatan untuk menandai barang kecil karena tetap dapat dibaca meskipun sebagian rusak.

## Mengapa menggunakan Aspose.BarCode untuk .NET?
Aspose.BarCode mendukung **lebih dari 50 format output** (termasuk PNG, JPEG, TIFF, SVG, dan PDF) dan dapat menghasilkan **semua 30 versi DataMatrix** tanpa memuat seluruh gambar ke dalam memori, memungkinkan Anda membuat kode batang dalam layanan berkecepatan tinggi yang memproses file lebih besar dari 100 MB.

Sekarang, mari jelajahi versi DataMatrix dan cara menghasilkan mereka menggunakan Aspose.BarCode untuk .NET.

## Cara menghasilkan kode batang DataMatrix di .NET?

Muat `BarcodeGenerator` dengan tipe `EncodeTypes.DataMatrix`, atur versi dan ECC yang diinginkan, lalu panggil `Save` untuk menulis file gambar. Pola satu baris ini bekerja untuk versi apa pun yang Anda pilih dan secara otomatis menangani ukuran modul, zona tenang, serta rendering gambar.

## Impor namespace

`BarcodeGenerator` adalah kelas inti Aspose.BarCode untuk membuat gambar kode batang.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

Namespace `Aspose.BarCode.Generation` menyediakan akses ke kelas `BarcodeGenerator`, yang merupakan kelas utama yang digunakan untuk menghasilkan gambar kode batang.

Sekarang, mari uraikan contoh ini menjadi beberapa langkah.

## Langkah 1: siapkan jalur direktori Anda

Mulailah dengan mendefinisikan jalur direktori tempat Anda ingin menyimpan kode batang DataMatrix yang dihasilkan.

```csharp
string path = "Your Directory Path";
```

Ganti `"Your Directory Path"` dengan jalur sebenarnya tempat Anda ingin menyimpan gambar kode batang.

## Langkah 2: inisialisasi generator kode batang

Buat instance kelas `BarcodeGenerator` dan tentukan tipe kode batang sebagai `DataMatrix`. Anda juga dapat menyediakan data yang ingin Anda enkode dalam kode batang.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` adalah kelas utama yang membuat dan merender simbol kode batang.

## Langkah 3: konfigurasikan properti kode batang

Anda dapat menyesuaikan berbagai properti kode batang DataMatrix, seperti dimensinya dan tipe ECC (Error Correction Code). Berikut contoh pengaturan dimensi X menjadi 4 piksel dan memilih ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` mengatur ukuran setiap modul dalam piksel, dan `DataMatrixEcc` memilih tingkat koreksi kesalahan.

## Langkah 4: atur versi DataMatrix dan simpan

Anda dapat menentukan versi DataMatrix dengan mengatur jumlah baris dan kolom. Setelah mengonfigurasi versi, simpan gambar kode batang.

Sebagai contoh, untuk membuat kode batang DataMatrix dengan 22 baris dan 22 kolom menggunakan ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

Demikian pula, Anda dapat menghasilkan kode batang dengan parameter berbeda dengan mengubah versi dan tipe ECC sesuai kebutuhan.

## Langkah 5: ulangi untuk versi lain

Anda dapat mengulangi Langkah 4 untuk versi DataMatrix lainnya. Misalnya, untuk membuat kode batang dengan 12 baris dan 64 kolom menggunakan ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Langkah 6: ganti tipe ECC

Jika Anda ingin mengubah tipe ECC menjadi Ecc140, Anda dapat melakukannya dengan memperbarui properti ECC:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Langkah 7: hasilkan kode batang dengan versi dan ECC yang berbeda

Ulangi Langkah 4 untuk versi DataMatrix dan tipe ECC lainnya, menyimpan setiap kode batang dengan nama file yang unik.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

Sekarang setelah Anda mempelajari cara menghasilkan kode batang DataMatrix menggunakan Aspose.BarCode untuk .NET, Anda dapat dengan mudah mengintegrasikan fungsionalitas ini ke dalam aplikasi .NET Anda.

## Kesalahan umum dan tips pemecahan masalah

- **Dimensi versi yang tidak tepat** – Versi DataMatrix memiliki pasangan baris/kolom tetap. Menyediakan pasangan yang tidak cocok (misalnya, 10 × 20) akan memicu `ArgumentException`. Selalu gunakan salah satu kombinasi yang didukung yang tercantum dalam dokumentasi API.  
- **Lisensi hilang** – Dalam mode percobaan gambar yang dihasilkan berisi watermark. Terapkan lisensi yang valid dengan `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` sebelum membuat generator untuk menghapus watermark. Kelas `License` memuat file lisensi untuk mengaktifkan produk.  
- **Ukuran gambar besar** – Jika Anda memerlukan output beresolusi tinggi, tingkatkan properti `XDimension`; perpustakaan akan menskalakan gambar secara proporsional tanpa kehilangan keterbacaan.
