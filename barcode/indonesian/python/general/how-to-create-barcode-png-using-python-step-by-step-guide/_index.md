# Cara membuat barcode PNG menggunakan Python – panduan langkah‑demi‑langkah

Jika Anda perlu **membuat file barcode PNG** dari string apa pun, tutorial ini memberikan solusi siap‑jalankan. Anda akan melihat secara tepat cara menghasilkan barcode Code 128, mengonversi teks menjadi gambar barcode, dan menyimpan hasilnya sebagai file PNG—semua dengan beberapa baris Python.

Panduan ini mencakup semua yang perlu Anda ketahui, mulai dari menginstal pustaka yang diperlukan hingga menyesuaikan output untuk berbagai kasus penggunaan. Pada akhir tutorial, Anda akan dapat menyematkan pembuatan barcode ke dalam proyek Python mana pun tanpa harus mencari dokumentasi tambahan.

## Apa yang akan Anda pelajari

* Menginstal paket **barcode generator python** yang mendukung Code 128.
* Menggunakan `BarCodeGenerator` untuk **menghasilkan barcode code 128** dari string teks.
* Menyimpan hasilnya sebagai PNG berkualitas tinggi dengan `save`.
* Menyesuaikan ukuran gambar, warna latar depan/latar belakang, dan menangani kesalahan umum.
* Memverifikasi bahwa PNG telah dibuat dengan benar.

### Prasyarat

| Persyaratan | Alasan |
|-------------|--------|
| Python 3.8+ | Sintaks modern dan tipe hint |
| Akses internet (untuk `pip install`) | Untuk mengunduh pustaka |
| Izin menulis ke folder | Untuk menyimpan PNG yang dihasilkan |

Tidak ada layanan eksternal yang diperlukan; semuanya berjalan secara lokal.

## Langkah 1: Instal pustaka barcode

Cara paling sederhana untuk **mengonversi teks menjadi barcode** di Python adalah menggunakan paket **Aspose.BarCode for Python via .NET**, yang mendukung Code 128 secara langsung.

```bash
pip install aspose-barcode
```

> **Pro tip:** Jika Anda bekerja di lingkungan virtual, aktifkan terlebih dahulu sebelum menjalankan perintah agar dependensi terisolasi.

## Langkah 2: Impor kelas yang diperlukan

Setelah instalasi, impor kelas inti. Pernyataan impor singkat, sehingga kode mudah dibaca.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` membuat gambar barcode.
* `EncodeTypes` menyediakan enumerasi simbolologi yang didukung, termasuk `CODE_128`.

## Langkah 3: Tentukan teks yang ingin Anda enkode

Pilih string alfanumerik apa saja. Code 128 dapat merepresentasikan seluruh set ASCII, jadi Anda tidak terbatas pada angka.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Jika input berisi karakter yang tidak didukung, generator akan mengeluarkan `ValueError`. Bungkus penugasan dalam blok `try` jika Anda mengharapkan data dari pengguna.

## Langkah 4: Buat generator barcode untuk Code 128

Instansiasi `BarCodeGenerator` dengan simbolologi yang diinginkan dan teks yang telah Anda definisikan. Inilah inti **cara menghasilkan gambar barcode** di Python.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Mengapa Code 128? Ia menawarkan kepadatan tinggi dan dapat mengenkode seluruh rentang ASCII, menjadikannya ideal untuk sistem inventaris, label pengiriman, dan tiket.

## Langkah 5: (Opsional) Sesuaikan tampilan

Anda dapat menyetel barcode sebelum menyimpannya. Opsi-opsi berikut umum digunakan:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Pengaturan ini memengaruhi output **create barcode png** akhir tanpa mengubah data yang dienkode.

## Langkah 6: Simpan barcode sebagai file PNG

Akhirnya, tulis gambar ke disk. Metode `save` secara otomatis mendeteksi ekstensi file, sehingga memberikan `.png` akan menghasilkan gambar PNG.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Jika direktori target tidak ada, Python akan mengeluarkan `FileNotFoundError`. Buat direktori terlebih dahulu atau gunakan `os.makedirs` dengan `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### Output yang diharapkan

Setelah menjalankan skrip, Anda akan menemukan `extended_barcode.png` di folder `output`. Membuka file tersebut menampilkan barcode Code 128 yang tajam dan mengenkode `1234567890`.

![Generated barcode PNG created with Python](generated_barcode.png "create barcode png example")

## Langkah 7: Verifikasi barcode (pemeriksaan cepat)

Anda dapat membaca kembali PNG dengan pustaka yang sama untuk memastikan nilai yang dienkode cocok dengan teks asli.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Menjalankan blok ini akan mencetak:

```
Verification succeeded: 1234567890
```

Jika asersi gagal, periksa kembali `barcode_text` dan parameter kustom yang Anda tetapkan.

## Variasi umum dan kasus tepi

| Situasi | Penyesuaian |
|-----------|------------|
| **Teks lebih panjang (> 20 karakter)** | Tingkatkan `image_width` untuk menghindari pemotongan. |
| **Membutuhkan latar belakang transparan** | Setel `back_color = "Transparent"` sebelum menyimpan. |
| **Menghasilkan banyak barcode dalam loop** | Bungkus langkah 3‑6 dalam `for` loop, ubah `barcode_text` tiap iterasi. |
| **Simpan sebagai JPEG alih-alih PNG** | Ubah ekstensi file menjadi `.jpg`; pustaka akan menangani format secara otomatis. |
| **Menjalankan di server tanpa tampilan (headless)** | Pustaka tidak memerlukan GUI, sehingga aman untuk pipeline CI. |

## Skrip lengkap untuk salin‑tempel cepat

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Simpan skrip sebagai `generate_barcode.py` dan jalankan:

```bash
python generate_barcode.py
```

Anda akan melihat pesan konfirmasi serta file PNG baru di folder `output`.
