# Membuat barcode planet di C# – panduan pemrograman lengkap

Jika Anda perlu **membuat barcode planet** di C#, panduan ini menunjukkan secara tepat cara melakukannya. Anda juga akan menemukan **cara mengatur dimensi barcode** sehingga bar menghasilkan lebar yang tepat sesuai kebutuhan Anda.

Membuat barcode Planet umum ketika Anda bekerja dengan layanan pos atau sistem logistik. Kode di bawah mencakup versi bar terisi default dan gaya bar kosong opsional, serta contoh cepat untuk format RM4SCC. Pada akhir tutorial ini Anda akan memiliki potongan kode yang dapat digunakan kembali dan dapat dimasukkan ke proyek .NET mana pun.

## Prasyarat

* .NET 6.0 atau yang lebih baru terpasang (API juga bekerja dengan .NET Framework 4.6+)
* Paket NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`) ditambahkan ke proyek Anda
* Jalur folder yang dapat ditulisi dimana file PNG akan disimpan
* Familiaritas dasar dengan sintaks C# dan Visual Studio (atau IDE apa pun)

> **Pro tip:** Gunakan jalur absolut atau `Path.Combine(Environment.CurrentDirectory, "output")` untuk menghindari masalah izin saat menyimpan gambar.

## Langkah 1 – Inisialisasi generator barcode Planet (bar terisi)

Langkah pertama adalah membuat instance `BarcodeGenerator` untuk simbol Planet. Secara default generator menghasilkan bar **terisi**.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Enum `EncodeTypes.Planet` memberi tahu Aspose.BarCode untuk menggunakan format Planet, sementara `"123456"` adalah data yang akan dienkode.

## Langkah 2 – Cara mengatur dimensi barcode untuk ukuran konsisten

Untuk mengontrol lebar setiap bar, sesuaikan **X‑dimension**. Ini adalah cara utama untuk **mengatur dimensi barcode** dan memastikan barcode cocok dengan ukuran label Anda.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

Properti `Pixels` menentukan lebar bar dalam piksel layar. Nilai umum adalah 2 – 5 piksel untuk label pos standar; tingkatkan nilai tersebut untuk cetakan yang lebih besar.

## Langkah 3 – Simpan barcode Planet terisi sebagai PNG

Sekarang tulis gambar ke disk. PNG mempertahankan tepi yang tajam, yang ideal untuk pemindaian.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Ganti `YOUR_DIRECTORY` dengan jalur yang Anda siapkan sebelumnya. Setelah menjalankan kode ini Anda akan melihat file yang mirip dengan gambar di bawah.

## Langkah 4 – Buat barcode Planet dengan bar kosong (tidak terisi)

Jika layanan pos Anda mengharuskan bar menjadi **kosong**, Anda perlu mengubah flag `FilledBars` setelah menginisialisasi generator.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Konstruktornya identik; perbedaannya terletak pada langkah konfigurasi berikutnya.

## Langkah 5 – Cara mengatur dimensi barcode dan membuat bar kosong

Sekali lagi, atur X‑dimension untuk konsistensi visual, lalu nonaktifkan bar terisi.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

Properti `FilledBars = false` adalah yang sebenarnya mengubah gaya rendering. Menjaga X‑dimension yang sama memastikan barcode bar kosong sejajar sempurna dengan versi terisi.

## Langkah 6 – Simpan barcode Planet kosong

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Sekarang Anda akan memiliki dua file PNG: satu dengan bar solid dan satu dengan bar kosong, keduanya memiliki dimensi yang sama.

## Langkah 7 – (Opsional) Hasilkan barcode RM4SCC untuk perbandingan

RM4SCC adalah simbol pos lain yang menggunakan gaya bar terisi default yang sama. Langkah-langkahnya mirip dengan contoh Planet, menunjukkan bahwa **cara mengatur dimensi barcode** berfungsi di semua format.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Menjalankan tiga langkah ini menghasilkan `PostalRM4SCCFilledBars.png`, yang dapat Anda bandingkan berdampingan dengan output Planet.

## Mengapa X‑dimension penting

X‑dimension menentukan **lebar cetak minimum** setiap bar. Jika Anda mengaturnya terlalu rendah, barcode dapat menjadi blur pada printer beresolusi rendah, menyebabkan kegagalan pemindaian. Sebaliknya, X‑dimension yang terlalu besar dapat melebihi dimensi label dan membuang ruang. Dengan secara eksplisit **cara mengatur dimensi barcode**, Anda memperoleh kontrol deterministik atas ukuran gambar akhir, yang penting untuk alur kerja pengiriman otomatis.

## Kesalahan umum dan cara menghindarinya

| Masalah | Penyebab | Solusi |
|-------|-------|-----|
| Barcode tampak terdistorsi | X‑dimension diatur dalam poin bukan piksel | Selalu gunakan properti `Pixels` untuk kontrol pixel‑perfect |
| Bar kosong masih terlihat terisi | `FilledBars` tidak diatur ke `false` setelah perubahan X‑dimension | Atur `FilledBars = false` *setelah* menyesuaikan X‑dimension |
| File yang disimpan kosong | Direktori output tidak ada atau tidak memiliki izin menulis | Pastikan direktori ada (`Directory.CreateDirectory`) dan aplikasi Anda berjalan dengan hak yang cukup |
| Gambar blur saat dicetak | PNG DPI rendah disimpan dari monitor beresolusi tinggi | Gunakan `BarCodeImageFormat.Png` (lossless) dan pertimbangkan properti `Resolution` jika diperlukan |

## Contoh lengkap yang dapat dijalankan

Salin seluruh blok di bawah ini ke proyek konsol baru (`dotnet new console`) dan jalankan. Program ini membuat tiga file PNG di folder `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Output yang diharapkan:** tiga file PNG—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png`, dan `PostalRM4SCCFilledBars.png`—masing‑masing dengan bar lebar 4 piksel, siap untuk pencetakan atau pemrosesan lebih lanjut.

## Kesimpulan

Anda sekarang tahu cara **membuat barcode planet** di C# dan secara tepat **cara mengatur dimensi barcode** untuk gaya bar terisi maupun kosong. Pola yang sama berlaku untuk simbol lain seperti RM4SCC, memberi Anda dasar yang fleksibel untuk setiap kebutuhan barcode pos.

Selanjutnya, Anda mungkin ingin menjelajahi:

* Menambahkan teks yang dapat dibaca manusia di bawah barcode (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* Mengubah warna bar dengan `Parameters.Barcode.BarColor`
* Menghasilkan barcode dalam format vektor (SVG, EPS) untuk pencetakan skalabel

Silakan bereksperimen dengan nilai X‑dimension yang berbeda, string data, dan format output untuk menyesuaikan alur kerja spesifik Anda. Selamat coding!
