# Membuat gambar barcode python dengan Aspose – panduan lengkap

Jika Anda perlu **membuat gambar barcode python**, Aspose.Barcode menyediakan API yang bersih yang menghilangkan perkiraan. Panduan ini memandu Anda melalui pembuatan barcode Planet, menyesuaikan ukurannya, dan menyimpan hasilnya sebagai file PNG—semua dalam beberapa baris kode Python.

Anda juga akan belajar cara **menyesuaikan ukuran barcode**, mengapa dimensi X penting untuk keandalan pemindai, dan di mana menempatkan gambar yang dihasilkan dalam struktur proyek Anda. Tidak ada alat eksternal yang diperlukan selain pustaka Aspose.Barcode.

## Apa yang Anda butuhkan

Sebelum memulai, pastikan Anda memiliki:

- Python 3.8 atau yang lebih baru terinstal  
- Aspose.Barcode untuk Python via [pip](https://pypi.org/project/aspose-barcode/) (`pip install aspose-barcode`)  
- Izin menulis ke direktori tempat PNG akan disimpan  

Prasyarat ini memastikan kode berjalan tanpa masalah izin atau kompatibilitas.

## Membuat gambar barcode python dengan Aspose.Barcode

Langkah pertama adalah mengimpor kelas yang diperlukan dan membuat instance `BarcodeGenerator`. Generator menyimpan jenis barcode serta data yang akan dienkode.

```python
# Import Aspose.Barcode classes
from asposebarcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Initialize a generator for a Planet barcode with the data "123456"
barcode_generator = BarcodeGenerator(EncodeTypes.Planet, "123456")
```

*Mengapa ini penting:*  
`EncodeTypes.Planet` memberi tahu Aspose untuk menggunakan simbol Planet, yang ideal untuk aplikasi pos. String data `"123456"` menjadi bagian yang dapat dibaca manusia dari barcode.

## Cara menghasilkan barcode Planet

Dengan generator siap, Anda dapat langsung membuat gambar barcode di memori. Namun, sebagian besar skenario dunia nyata memerlukan penyesuaian ukuran untuk memenuhi standar pencetakan.

```python
# Generate the barcode image (in memory) – no file written yet
image = barcode_generator.generate_barcode_image()
```

Memanggil `generate_barcode_image()` mengembalikan `byte[]` yang dapat Anda alirkan langsung ke respons web, tetapi untuk tutorial ini kami akan menyimpannya ke disk setelah menyesuaikan dimensinya.

## Menyesuaikan ukuran barcode

Dua parameter mengontrol ukuran visual barcode:

1. **X‑dimension** – lebar bar paling sempit (modul).  
2. **Bar height** – tinggi keseluruhan bar.

Keduanya dinyatakan dalam piksel saat Anda menggunakan helper `set_pixels`.

```python
# Access the parameter object
params = barcode_generator.parameters

# Set the X‑dimension to 4 pixels (makes each module 4 px wide)
params.barcode.x_dimension.set_pixels(4)

# Force a bar height of 100 pixels for better readability
params.barcode.bar_height.set_pixels(100)
```

*Tips profesional:* Dimensi X yang lebih besar meningkatkan keterbacaan pada printer beresolusi rendah, sementara tinggi bar yang lebih tinggi membantu pemindai membedakan kode dari grafik di sekitarnya.

## Simpan barcode sebagai PNG

Akhirnya, tulis barcode yang telah disesuaikan ke file PNG. Metode `save` menangani konversi format secara otomatis.

```python
# Define the output path – change YOUR_DIRECTORY to your desired folder
output_path = "YOUR_DIRECTORY/PostalPlanetBarHeight100.png"

# Save the barcode as a PNG image
barcode_generator.save(output_path, BarCodeImageFormat.Png)
```

Setelah skrip selesai, `PostalPlanetBarHeight100.png` berisi barcode Planet yang jelas dengan dimensi yang ditentukan.

*Output yang diharapkan:* PNG menampilkan barcode Planet yang mengkodekan “123456”. Bar berukuran 4 px lebar, 100 px tinggi, dan latar belakang gambar transparan secara default.

## Menghasilkan barcode dengan aspose – skrip lengkap

Berikut adalah skrip lengkap yang dapat dijalankan yang menggabungkan semua langkah. Salin ke file bernama `generate_planet_barcode.py` dan jalankan dengan `python generate_planet_barcode.py`.

```python
# generate_planet_barcode.py
# Complete example: create barcode image python with Aspose.Barcode

from asposebarcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def main():
    # 1️⃣ Initialize generator for Planet barcode
    generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

    # 2️⃣ Customize size: X‑dimension = 4 px, bar height = 100 px
    params = generator.parameters
    params.barcode.x_dimension.set_pixels(4)
    params.barcode.bar_height.set_pixels(100)

    # 3️⃣ Save as PNG
    output_file = "output/PostalPlanetBarHeight100.png"
    generator.save(output_file, BarCodeImageFormat.Png)
    print(f"Barcode saved to {output_file}")

if __name__ == "__main__":
    main()
```

Menjalankan skrip akan mencetak:

```
Barcode saved to output/PostalPlanetBarHeight100.png
```

Anda dapat membuka PNG dengan penampil gambar apa pun untuk memverifikasi tampilan barcode.

## Pertanyaan umum dan kasus tepi

| Question | Answer |
|----------|--------|
| **Apakah saya dapat menghasilkan tipe barcode lain?** | Ya. Ganti `EncodeTypes.Planet` dengan nilai apa pun dari `EncodeTypes` (misalnya, `EncodeTypes.QR`, `EncodeTypes.Code128`). |
| **Bagaimana jika saya membutuhkan latar belakang putih?** | Panggil `generator.parameters.image.background_color.set_white()` sebelum menyimpan. |
| **Bagaimana cara menyisipkan barcode ke dalam PDF?** | Gunakan Aspose.PDF untuk menyisipkan PNG atau hasilkan barcode langsung sebagai gambar PDF melalui `BarCodeImageFormat.Pdf`. |
| **Apakah lisensi diperlukan untuk produksi?** | Aspose.Barcode berfungsi dalam mode evaluasi, tetapi lisensi komersial menghapus watermark evaluasi dan membuka semua fitur. |
| **Bagaimana jika direktori output tidak ada?** | Buat dulu dengan `os.makedirs(os.path.dirname(output_file), exist_ok=True)`. |
