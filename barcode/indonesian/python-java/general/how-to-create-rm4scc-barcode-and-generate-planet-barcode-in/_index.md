# Cara membuat kode batang RM4SCC dan menghasilkan kode batang planet dalam C#

Jika Anda perlu **membuat kode batang RM4SCC** untuk aplikasi pos, panduan ini menunjukkan langkah‑langkah tepatnya. Anda juga akan belajar cara **menghasilkan kode batang planet** dengan tinggi otomatis maupun tetap, sehingga kode yang sama dapat bekerja untuk semua simbol pos.

Tutorial ini mencakup semua yang diperlukan untuk menghasilkan gambar PNG yang memenuhi standar pos. Tidak diperlukan alat eksternal selain pustaka Aspose.BarCode untuk .NET. Pada akhir tutorial, Anda dapat menghasilkan kode batang secara programatik dan mengontrol dimensinya dengan tepat.

## Prasyarat

* .NET 6.0 atau yang lebih baru terpasang
* Visual Studio 2022 (atau IDE C# apa pun)
* Paket NuGet Aspose.BarCode untuk .NET  
  `Install-Package Aspose.BarCode`
* Izin menulis ke direktori output

Item-item ini memungkinkan Anda mengompilasi dan menjalankan kode contoh tanpa konfigurasi tambahan.

## Langkah 1: Inisialisasi generator kode batang untuk RM4SCC

Operasi pertama membuat instance `BarcodeGenerator` yang dikonfigurasi untuk simbolologi RM4SCC. Objek ini menyimpan semua pengaturan untuk gambar kode batang.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Mengapa ini penting** – `EncodeTypes.RM4SCC` memberi tahu Aspose untuk menggunakan format RM4SCC pos, sementara string data `"123456"` mewakili kode pos yang ingin Anda enkode.

## Langkah 2: Atur lebar modul (dimensi X‑)

Lebar modul mengontrol ukuran bar tipis. Nilai umum untuk kode batang pos adalah 4 piksel.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Penjelasan** – Dimensi X memengaruhi keterbacaan keseluruhan kode batang. Memilih 4 px cocok dengan sebagian besar pemindai pos.

## Langkah 3: Simpan dengan tinggi bar otomatis

Ketika Anda tidak menyertakan nilai tinggi, Aspose menghitung tinggi optimal secara otomatis berdasarkan aturan simbolologi.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Hasil** – PNG yang dihasilkan (`PostalRM4SCCBarHeightNone.png`) berisi kode batang RM4SCC dengan ukuran yang tepat siap untuk dicetak.

## Langkah 4: Buat kode batang Planet dengan tinggi otomatis

Pola yang sama berlaku untuk simbolologi Planet. Mulailah dengan menginisialisasi generator menggunakan `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Mengapa menggunakan kembali kode** – Baik RM4SCC maupun Planet menggunakan struktur parameter yang sama, sehingga Anda dapat beralih simbolologi hanya dengan mengubah nilai `EncodeTypes`.

## Langkah 5: Tentukan tinggi bar tetap untuk RM4SCC

Beberapa layanan pos memerlukan tinggi bar tertentu (mis., 100 px). Anda dapat mengatur ini secara eksplisit sebelum menyimpan.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Tip** – Menetapkan `BarHeight.Pixels` menggantikan perhitungan otomatis, memberi Anda kontrol penuh atas ukuran visual.

## Langkah 6: Tentukan tinggi bar tetap untuk Planet

Terapkan teknik tinggi tetap yang sama pada kode batang Planet.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Hasil** – Baik `PostalRM4SCCBarHeight100Pixels.png` maupun `PostalPlanetBarHeight100Pixels.png` berisi kode batang dengan tinggi bar konsisten 100 px, memenuhi spesifikasi pos yang ketat.

## Kode sumber lengkap

Berikut adalah program lengkap yang dapat dijalankan yang mencakup keempat contoh. Salin ke dalam proyek konsol baru dan sesuaikan jalur output sesuai kebutuhan.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Output yang diharapkan** – Setelah menjalankan program, direktori yang ditentukan berisi empat file PNG:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC dengan tinggi otomatis
* `PostalPlanetBarHeightNone.png` – Planet dengan tinggi otomatis
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC dengan tinggi 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet dengan tinggi 100 px

Buka file apa pun untuk memverifikasi bahwa bar bersih, lebar modul 4 px, dan tinggi sesuai dengan pengaturan yang dipilih.

## Pertanyaan umum dan kasus tepi

| Question | Answer |
|----------|--------|
| **Apakah saya dapat menggunakan format gambar lain?** | Ya. Ganti `BarCodeImageFormat.Png` dengan `Jpeg`, `Bmp`, atau `Gif` sesuai kebutuhan. |
| **Bagaimana jika string data lebih panjang?** | Generator secara otomatis menyesuaikan jumlah bar. Pastikan data mematuhi batas panjang simbolologi (RM4SCC ≤ 6 digit, Planet ≤ 6 digit). |
| **Bagaimana cara mengubah warna bar?** | Setel `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` sebelum memanggil `Save`. |
| **Apakah DPI penting untuk pencetakan?** | Anda dapat mengatur `rm4sccAuto.Parameters.ImageResolution.DpiX` dan `DpiY` agar sesuai dengan resolusi printer Anda. |
