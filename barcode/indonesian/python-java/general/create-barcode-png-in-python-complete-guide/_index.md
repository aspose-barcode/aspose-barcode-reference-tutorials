# Buat barcode PNG di Python – Panduan Lengkap

Pernah perlu **create barcode PNG** tetapi tidak yakin pustaka atau pengaturan mana yang harus digunakan? Anda tidak sendirian. Dalam banyak sistem inventaris atau checkout, langkah pertama adalah mengubah data mentah menjadi gambar PNG yang tajam dan disukai pemindai.  

Dalam tutorial ini kami akan menjelaskan **how to generate databar**, cara **adjust barcode height**, dan bahkan trik untuk **change barcode** parameter secara langsung—semua sambil menggunakan **barcode with sample data** yang dapat Anda salin‑tempel langsung ke proyek Anda.  

## Apa yang Akan Anda Pelajari

- Siapkan pustaka Aspose.BarCode (atau serupa) di Python.  
- **Create barcode PNG** file dengan tinggi yang berbeda hanya dalam beberapa baris kode.  
- **How to change barcode** properti seperti ukuran modul dan tinggi bar.  
- Gunakan nilai GTIN‑14 yang realistis sebagai **barcode with sample data**.  
- Tips untuk memecahkan masalah umum seperti gambar buram atau enkoding yang salah.

## Prasyarat

- Python 3.8+ terinstal di mesin Anda.  
- Akses internet untuk menginstal paket `aspose-barcode` (atau pustaka kompatibel lainnya).  
- Folder yang dapat ditulisi tempat file PNG akan disimpan (ganti `YOUR_DIRECTORY` dalam skrip).  

Jika Anda sudah memiliki semua ini, bagus—mari kita mulai.

## Buat barcode PNG – Menyiapkan Generator

Hal pertama yang harus dilakukan: kita memerlukan objek generator yang mengetahui bahwa kita sedang menangani barcode **DataBar Omnidirectional**. Kode di bawah mengimpor kelas yang diperlukan, membuat generator dengan **barcode with sample data**, dan mengatur ukuran modul yang wajar.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Mengapa ini penting:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` memberi tahu mesin untuk menghasilkan **DataBar** yang dapat dibaca dari arah mana pun, sempurna untuk rak ritel. Mengatur `x_dimension` menjaga bar tetap tajam, sementara `bar_height` mengontrol ukuran visual kode.

## Cara Menghasilkan Databar dengan Sample Data

Setelah generator siap, kami akan **create barcode PNG** file. Penyimpanan pertama menggunakan tinggi 30‑pixel, yang biasanya cukup untuk pratinjau di layar.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Menjalankan skrip hingga titik ini akan menghasilkan file PNG yang tampak seperti barcode kompak dengan kontras tinggi. Buka di penampil gambar apa pun untuk memverifikasi bahwa bar tajam dan data GTIN‑14 telah terenkode.

## Sesuaikan Tinggi Barcode (How to Change Barcode)

Kadang-kadang Anda memerlukan barcode yang lebih tinggi untuk label yang lebih besar atau pencetakan resolusi tinggi. Di sinilah **adjust barcode height** berperan. Mengubah tinggi semudah memperbarui properti `BarHeight` dan menyimpan kembali.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Cara kerjanya:** Generator menggunakan kembali data dan ukuran modul yang sama; hanya dimensi vertikal yang berubah. Ini menghindari pembuatan ulang seluruh objek dan menunjukkan **how to change barcode** pengaturan secara dinamis.

## Skrip Lengkap – Solusi Satu‑Pintu

Di bawah ini adalah skrip lengkap yang dapat dijalankan yang menggabungkan semua langkah. Salin, tempel, dan jalankan—seharusnya langsung bekerja setelah Anda menginstal paket.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Output yang Diharapkan

Menjalankan skrip akan menghasilkan dua file:

- `DatabarOmni30.png` – barcode DataBar Omnidirectional setinggi 30 px.  
- `DatabarOmni60.png` – versi setinggi 60 px dari barcode yang sama.

Kedua gambar berformat PNG, lossless, dan siap disisipkan dalam PDF, halaman HTML, atau dicetak langsung pada label.

## Kesalahan Umum & Tips Pro

- **Pixel vs. DPI:** File PNG berbasis piksel. Jika Anda memerlukan ukuran cetak tertentu, hitung `BarHeight` berdasarkan DPI (mis., 300 dpi → 30 px ≈ 0.1 in).  
- **Incorrect encoding:** Pastikan string data mengikuti format GS1 Application Identifier (`(01)` untuk GTIN‑14). Kurung yang hilang dapat menyebabkan pustaka kembali ke barcode numerik biasa.  
- **File paths:** Gunakan raw string (`r"..."`) atau double backslashes pada Windows untuk menghindari masalah karakter escape.  
- **Performance:** Jika Anda menghasilkan ribuan barcode, buat instance generator sekali saja dan hanya modifikasi `BarHeight` atau string data antara penyimpanan. Ini mengurangi beban memori.
