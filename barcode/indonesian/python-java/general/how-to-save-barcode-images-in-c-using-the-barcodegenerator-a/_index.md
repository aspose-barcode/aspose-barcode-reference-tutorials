# Cara menyimpan gambar barcode di C# menggunakan API BarcodeGenerator

Jika Anda perlu **cara menyimpan barcode** file dari aplikasi .NET, panduan ini menunjukkan langkah‑langkah tepat. Anda akan melihat contoh **contoh generator barcode** lengkap yang membuat barcode DataBar Stacked Omnidirectional, menyesuaikan rasio aspeknya, dan menyimpan dua file PNG.

Menyimpan gambar barcode adalah kebutuhan umum saat membangun sistem inventaris, terminal point‑of‑sale, atau alur kerja pelabelan otomatis. Pada akhir tutorial ini Anda dapat menghasilkan kode C# barcode yang menghasilkan gambar handal siap untuk dicetak atau ditampilkan.

## Prasyarat

Sebelum Anda memulai, pastikan Anda memiliki:

- .NET 6.0 SDK atau yang lebih baru terpasang  
- Visual Studio 2022 (atau IDE kompatibel C# apa pun)  
- Paket NuGet **Aspose.BarCode for .NET** (kode menggunakan `Aspose.BarCode.Generation`)  

Anda dapat menambahkan paket dengan perintah berikut:

```bash
dotnet add package Aspose.BarCode
```

## Langkah 1: Siapkan proyek konsol C# minimal

Buat proyek konsol baru dan referensikan pustaka:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Buka `Program.cs`. File tersebut akan berisi metode `Main` tempat kita akan menempatkan logika **menghasilkan barcode C#**.

## Langkah 2: Inisialisasi BarcodeGenerator untuk barcode DataBar Stacked Omnidirectional

Tugas pertama dalam setiap alur kerja **create databar barcode** adalah menginstansiasi `BarcodeGenerator` dengan `EncodeType` yang tepat. Konstruktor menerima simbol barcode dan string data.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

Nilai `EncodeTypes.DatabarStackedOmniDirectional` memberi tahu pustaka untuk menghasilkan **create databar barcode** yang dapat dipindai dari arah mana pun.

## Langkah 3: Konfigurasikan dimensi X (lebar modul)

Dimensi X mengontrol lebar bar terkecil dalam piksel. Menetapkannya ke nilai rendah membuat barcode tetap kompak sambil mempertahankan keterbacaan.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Langkah 4: **Cara menyesuaikan rasio aspek** – nilai pertama (15)

Barcode DataBar mengekspos properti `AspectRatio` yang memengaruhi hubungan tinggi‑lebar. Rasio yang lebih tinggi menghasilkan barcode yang lebih tinggi, yang dapat meningkatkan keandalan pemindaian pada printer tertentu.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Langkah 5: **Cara menyimpan barcode** – gambar pertama (rasio aspek 15)

Sekarang kita benar‑benar **cara menyimpan barcode** ke sebuah file. Metode `Save` menerima jalur file dan format gambar. Pada contoh ini kami menyimpan file PNG.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Tip:** Direktori eksekusi adalah lokasi penulisan default. Gunakan jalur absolut jika Anda memerlukan folder tertentu.

## Langkah 6: **Cara menyesuaikan rasio aspek** – nilai kedua (30)

Untuk menunjukkan fleksibilitas, ubah rasio aspek dan simpan gambar kedua. Ini menunjukkan bagaimana data yang sama dapat dirender dengan proporsi visual yang berbeda.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Menjalankan program menghasilkan dua file PNG:

- `DatabarAspectRatio15.png` – barcode dengan tinggi sedang  
- `DatabarAspectRatio30.png` – barcode dengan tinggi lebih tinggi untuk lingkungan pemindaian yang menantang  

Kedua file siap dimuat ke kontrol UI, dicetak pada label, atau ditransmisikan melalui API.

### Output yang Diharapkan

Saat Anda membuka gambar yang dihasilkan, Anda akan melihat barcode DataBar Stacked Omnidirectional yang mengkodekan nilai GTIN‑14 `12345678901231`. Perbedaan visual antara kedua file hanya pada tinggi, mengonfirmasi bahwa **cara menyesuaikan rasio aspek** berfungsi sebagaimana mestinya.

## Langkah 7: Kode sumber lengkap sebagai referensi

Di bawah ini adalah program lengkap yang dapat dijalankan. Salin ke `Program.cs`, bangun, dan jalankan.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Pertanyaan umum dan penanganan kasus tepi

### Bagaimana jika folder target tidak ada?

`Save` melempar `DirectoryNotFoundException`. Buat folder terlebih dahulu:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Cara mengubah format gambar?

Ganti `BarCodeImageFormat.Png` dengan `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp`, atau `BarCodeImageFormat.Tiff` tergantung pada kebutuhan downstream.

### Bisakah saya menghasilkan banyak barcode dalam loop?

Ya. Instansiasikan `BarcodeGenerator` baru untuk setiap string data atau gunakan kembali instance yang sama setelah memperbarui properti `CodeText`:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### Apakah **cara menyimpan barcode** berfungsi di platform non‑Windows?

Aspose.BarCode bersifat lintas‑platform. Kode yang sama berjalan di Linux dan macOS selama runtime .NET tersedia.
