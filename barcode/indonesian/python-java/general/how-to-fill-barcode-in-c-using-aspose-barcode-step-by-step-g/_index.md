# Cara mengisi barcode di C# menggunakan Aspose.BarCode

Jika Anda perlu **mengisi barcode** dalam aplikasi .NET, tutorial ini menunjukkan proses lengkapnya. Anda akan menghasilkan barcode Planet pos dengan bar solid, kemudian membuat versi bar kosong dari barcode yang sama, semuanya dengan satu perubahan satu baris kode.

Panduan ini mencakup semua yang perlu Anda ketahui: penyiapan proyek, penyetelan X‑dimension, beralih antara bar terisi dan kosong, serta cara memverifikasi file PNG yang dihasilkan. Tidak diperlukan dokumentasi eksternal—cukup salin kode, jalankan, dan Anda akan melihat hasilnya.

## Prasyarat

Sebelum memulai, pastikan Anda memiliki:

* .NET 6.0 SDK atau yang lebih baru terpasang  
* Lingkungan pengembangan seperti Visual Studio 2022 atau VS Code  
* Paket NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

Item‑item ini merupakan dasar minimal untuk bagian **barcode generator c#** dalam tutorial.

## Cara mengisi barcode – menyiapkan proyek

1. Buat proyek konsol baru:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Tambahkan paket Aspose.BarCode:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Buka file `Program.cs` yang dihasilkan dan ganti isinya dengan contoh lengkap yang ditunjukkan nanti dalam artikel ini.

Proyek kini berisi semua yang diperlukan untuk **menghasilkan barcode pos** dalam bentuk gambar.

## Hasilkan barcode pos dengan bar solid

Langkah pertama adalah membuat barcode Planet yang menggunakan bar terisi (solid). Planet adalah simbol yang dipakai oleh banyak layanan pos untuk proses penyortiran.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Mengapa baris-baris ini penting**

* `EncodeTypes.Planet` memberi tahu generator simbol apa yang akan dipakai; Planet adalah standar untuk barcode pos.  
* `XDimension.Pixels = 4` memperlebar modul, sehingga barcode lebih mudah dipindai dan tampak lebih jelas saat dicetak.  
* `Save` menulis gambar ke disk dalam format PNG, format loss‑less yang cocok untuk pemrosesan lebih lanjut.

Menjalankan blok ini menghasilkan **PostalPlanetFilledBars.png**, sebuah gambar dengan bar solid yang memenuhi spesifikasi pos.

## Buat barcode kosong menggunakan simbologi Planet

Kadang‑kadang sistem pos mengharapkan bar menjadi kosong (tidak terisi) sementara ruang tetap solid. Beralih ke mode itu hanya memerlukan satu perubahan properti.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Mengapa ini berhasil**

Menetapkan `FilledBars = false` memberi tahu renderer untuk membalikkan gaya visual: bar menjadi transparan (kosong) dan latar belakang menjadi tidak tembus. Ini merupakan kebalikan tepat dari perilaku default yang ditunjukkan sebelumnya, memungkinkan Anda **membuat barcode kosong** tanpa mengubah data yang dienkode.

## Contoh lengkap yang dapat dijalankan

Berikut adalah program lengkap yang menggabungkan dua bagian tersebut. Salin ke dalam `Program.cs`, ganti `YOUR_DIRECTORY/` dengan jalur folder yang sebenarnya, dan jalankan `dotnet run`.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Output yang diharapkan

Setelah eksekusi Anda akan menemukan dua file PNG di folder yang ditentukan:

| Nama file                     | Deskripsi visual |
|-------------------------------|------------------|
| `PostalPlanetFilledBars.png`  | Bar berwarna hitam solid pada latar putih |
| `PostalPlanetEmptyBars.png`   | Bar transparan (putih) pada latar hitam |

Kedua gambar mengenkode string numerik yang sama `"123456"` dan memiliki X‑dimension yang sama, sehingga dapat dipertukarkan dari perspektif validasi data.

## Pertanyaan umum dan kasus tepi

**Bagaimana jika folder output tidak ada?**  
Metode `Save` akan melempar `DirectoryNotFoundException`. Buat folder tersebut terlebih dahulu atau bungkus pemanggilan dalam blok `try / catch` yang membuat direktori bila diperlukan:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Bisakah saya menggunakan format gambar lain?**  
Ya. Ganti `BarCodeImageFormat.Png` dengan `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp`, atau format lain yang didukung oleh Aspose.BarCode.

**Apakah X‑dimension memengaruhi keterbacaan pemindai?**  
Meningkatkan lebar piksel membuat bar lebih lebar, yang dapat meningkatkan keterbacaan pada pemindai beresolusi rendah. Namun, nilai yang terlalu besar dapat melampaui area yang dapat dicetak. Nilai tipikal berkisar antara 2 hingga 6 piksel untuk pencetakan 300 dpi.

**Apakah simbologi `EncodeTypes.Planet` satu‑satunya opsi pos?**  
Tidak. Aspose.BarCode juga mendukung `EncodeTypes.Postnet` dan `EncodeTypes.USPSIntelligentMail`. Properti `FilledBars` yang sama bekerja dengan tipe‑tipe tersebut juga.
