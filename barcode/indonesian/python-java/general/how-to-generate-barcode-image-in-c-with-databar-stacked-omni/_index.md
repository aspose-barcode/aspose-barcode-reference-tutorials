# Cara menghasilkan gambar barcode di C# dengan DataBar Stacked Omni‑Directional

Jika Anda perlu **cara menghasilkan gambar barcode** dalam aplikasi .NET, tutorial ini menunjukkan langkah‑langkah tepatnya. Anda akan melihat cara membuat barcode DataBar Stacked Omni‑Directional, menyesuaikan rasio aspeknya, dan mengekspor hasilnya sebagai file PNG.

Membuat barcode merupakan kebutuhan umum untuk sistem inventaris, terminal point‑of‑sale ritel, dan pelacakan logistik. Pada bagian berikut kami akan membahas semua yang Anda perlukan—mulai dari paket NuGet yang diperlukan hingga verifikasi gambar akhir—sehingga Anda dapat mengintegrasikan pembuatan barcode ke dalam proyek C# apa pun hari ini.

## Prasyarat

* .NET 6.0 atau lebih baru (kode ini bekerja dengan .NET Core dan .NET Framework)
* Visual Studio 2022 atau IDE C# apa pun yang Anda sukai
* Paket NuGet **Aspose.BarCode for .NET** (pasang dengan `dotnet add package Aspose.BarCode`)
* Izin menulis ke folder tempat file PNG akan disimpan

Prasyarat ini menjamin contoh berjalan tanpa konfigurasi tambahan.

## Langkah 1: Siapkan folder output

Hal pertama yang Anda butuhkan adalah direktori tempat file PNG yang dihasilkan akan ditulis. Menggunakan jalur absolut atau relatif dapat, tetapi pastikan folder tersebut ada sebelum Anda memanggil `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Membuat folder secara programatik mencegah *FileNotFoundException* ketika metode `Save` mencoba menulis gambar.

## Langkah 2: Buat generator barcode DataBar Stacked Omni‑Directional

Kelas **BarcodeGenerator** adalah titik masuk untuk semua jenis barcode. Di sini kami menentukan `EncodeTypes.DatabarStackedOmniDirectional` dan string data yang ingin kami enkode.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Mengapa ini penting*: Enum `EncodeTypes` memberi tahu perpustakaan simbol apa yang harus dirender. Menggunakan varian Omni‑Directional memastikan barcode dapat dipindai dari orientasi apa pun—sebuah persyaratan bagi banyak pemindai gudang.

## Langkah 3: Konfigurasikan parameter barcode umum

Barcode yang dapat dibaca membutuhkan X‑dimension yang masuk akal (lebar bar terkecil). Menetapkan `Pixels` ke 2 memberikan keseimbangan yang baik antara ukuran dan kejelasan untuk kebanyakan resolusi layar.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Anda dapat menyesuaikan `Pixels` nanti jika membutuhkan gambar yang lebih besar atau lebih kecil; perpustakaan secara otomatis menskalakan sisa barcode.

## Langkah 4: Hasilkan gambar pertama dengan rasio aspek 15

**Rasio aspek** mengontrol hubungan tinggi‑ke‑lebar barcode DataBar. Rasio aspek 15 adalah nilai default umum untuk label ritel.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Setelah pemanggilan ini, Anda akan menemukan `DatabarAspectRatio15.png` di folder output. Gambar tersebut adalah PNG lossless, cocok untuk pemrosesan lebih lanjut atau pencetakan.

## Langkah 5: Ubah rasio aspek menjadi 30 dan ekspor gambar kedua

Kadang-kadang barcode yang lebih tinggi diperlukan—misalnya, ketika tinggi label terbatas. Mengubah rasio aspek menjadi 30 menghasilkan tampilan yang lebih kompak sambil mempertahankan integritas data.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Sekarang Anda memiliki dua file PNG yang memperlihatkan bagaimana data yang sama terlihat dengan rasio aspek yang berbeda. Perbandingan berdampingan ini membantu Anda memutuskan varian mana yang paling cocok untuk tata letak label Anda.

## Contoh lengkap yang dapat dijalankan

Berikut adalah program lengkap yang dapat Anda salin, tempel, dan jalankan. Program ini mencakup semua direktif `using`, penanganan error, dan komentar yang menjelaskan setiap bagian proses.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Output yang diharapkan** (console):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Buka kedua file PNG dengan penampil gambar apa pun. Anda akan melihat GTIN yang sama terenkode, tetapi gambar kedua lebih tinggi karena rasio aspek yang lebih tinggi.

## Tips profesional dan jebakan umum

| Situasi | Rekomendasi |
|-----------|----------------|
| **Layar resolusi rendah** | Tingkatkan `XDimension.Pixels` menjadi 3 atau 4 untuk menjaga bar tetap tajam. |
| **Mencetak pada kertas termal** | Gunakan `BarCodeImageFormat.Tiff` untuk fidelitas lebih tinggi dan atur `Resolution.DpiX/DpiY` ke 300. |
| **Data dinamis** | Gunakan kembali instance `BarcodeGenerator` yang sama dan hanya perbarui `generator.CodeText` sebelum setiap `Save`. Ini menghindari alokasi objek yang tidak perlu. |
| **GTIN tidak valid** | Perpustakaan akan melempar `ArgumentException` jika data tidak sesuai dengan standar GS1. Validasi data Anda sebelum mengirimkannya ke generator. |
