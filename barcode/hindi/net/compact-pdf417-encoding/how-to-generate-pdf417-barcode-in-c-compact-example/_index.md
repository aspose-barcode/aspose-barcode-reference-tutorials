# C# में PDF417 बारकोड कैसे जेनरेट करें – कॉम्पैक्ट उदाहरण

यदि आपको C# एप्लिकेशन में **PDF417 बारकोड जेनरेट** करना है, तो यह गाइड आपको एक पूर्ण, तैयार‑चलाने योग्य समाधान दिखाता है। हम एक कॉम्पैक्ट PDF417 बारकोड बनाएंगे, मॉड्यूल की चौड़ाई समायोजित करेंगे, कॉलम संख्या निर्धारित करेंगे, और परिणाम को PNG इमेज के रूप में सहेजेंगे—सभी Aspose.BarCode .NET लाइब्रेरी के साथ।

PDF417 बारकोड जेनरेट करना आम है जब आप बड़ी मात्रा में डेटा (जैसे URLs, संपर्क कार्ड, या इन्वेंटरी IDs) को स्थान‑कुशल दो‑आयामी फॉर्मेट में एन्कोड करना चाहते हैं। इस ट्यूटोरियल के अंत तक आपके पास एक कार्यशील `BarcodeGenerator` इंस्टेंस होगा जो एक कॉम्पैक्ट, उच्च‑पठनीयता वाला बारकोड उत्पन्न करता है, जो प्रिंटिंग या डिस्प्ले के लिए तैयार है।

## आवश्यकताएँ

- .NET 6.0 या बाद का संस्करण (कोड .NET Framework 4.8 के साथ भी काम करता है)
- Visual Studio 2022 (या कोई भी C# IDE)
- Aspose.BarCode for .NET NuGet पैकेज (`Install-Package Aspose.BarCode`)
- C# सिंटैक्स की बुनियादी परिचितता

कोई अतिरिक्त कॉन्फ़िगरेशन आवश्यक नहीं है; उदाहरण एक कंसोल ऐप के रूप में चलता है।

## चरण 1: PDF417 बारकोड जेनरेटर बनाएं

पहला कदम `BarcodeGenerator` को `EncodeTypes.Pdf417` एन्‍म और उस टेक्स्ट के साथ इंस्टैंशिएट करना है जिसे आप एन्कोड करना चाहते हैं।

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**क्यों यह महत्वपूर्ण है:** `EncodeTypes.Pdf417` लाइब्रेरी को PDF417 सिम्बोलॉजी उपयोग करने के लिए बताता है, जबकि दूसरा आर्ग्युमेंट डेटा पेलोड सेट करता है। आप `"Compact example"` को 1 800 अक्षरों तक की किसी भी स्ट्रिंग से बदल सकते हैं।

## चरण 2: मॉड्यूल की चौड़ाई (X‑डायमेंशन) पिक्सेल में सेट करें

X‑डायमेंशन एकल बारकोड मॉड्यूल (सबसे छोटा काला या सफ़ेद वर्ग) की चौड़ाई निर्धारित करता है। छोटा पिक्सेल मान एक अधिक सघन बारकोड देता है।

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**क्यों यह महत्वपूर्ण है:** `2` पिक्सेल का मान अधिकांश आधुनिक स्कैनरों पर स्कैन विश्वसनीयता को कम किए बिना एक कॉम्पैक्ट लुक बनाता है। यदि आपको कम‑रिज़ॉल्यूशन प्रिंटिंग के लिए बड़े मॉड्यूल चाहिए तो मान को समायोजित करें।

## चरण 3: कॉलम संख्या निर्दिष्ट करें

PDF417 आपको कॉलम संख्या नियंत्रित करने की अनुमति देता है, जो बारकोड के आस्पेक्ट रेशियो को प्रभावित करता है।

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**क्यों यह महत्वपूर्ण है:** कम कॉलम बारकोड को लंबा बनाते हैं, जबकि अधिक कॉलम इसे चपटा करते हैं। तीन कॉलम एक कॉम्पैक्ट, पोर्ट्रेट‑ओरिएंटेड लेआउट के लिए उपयुक्त होते हैं।

## चरण 4: बारकोड को ट्रंकेट करके कॉम्पैक्ट मोड सक्षम करें

कॉम्पैक्ट मोड अनावश्यक पैडिंग पंक्तियों को हटाता है, जिससे बारकोड छोटा हो जाता है जबकि एन्कोडेड डेटा बरकरार रहता है।

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**क्यों यह महत्वपूर्ण है:** ट्रंकेशन तब आदर्श है जब स्क्रीन स्पेस सीमित हो (जैसे मोबाइल ऐप्स या छोटे लेबल)। बारकोड पूरी तरह पढ़ने योग्य रहता है क्योंकि एन्कोडिंग एल्गोरिद्म स्वचालित रूप से एरर‑करेक्शन लेवल को समायोजित करता है।

## चरण 5: बारकोड को PNG इमेज के रूप में सहेजें

अंत में, उत्पन्न बारकोड को फ़ाइल में लिखें। PNG लॉस‑लेस क्वालिटी को बनाए रखता है, जो बारकोड स्कैनरों के लिए आवश्यक है।

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

प्रोग्राम चलाने से `CompactPdf417.png` निष्पादन योग्य की कार्य निर्देशिका में बनता है। इमेज इस प्रकार दिखती है:

![जनरेट किया गया कॉम्पैक्ट PDF417 बारकोड](CompactPdf417.png "जनरेट किया गया कॉम्पैक्ट PDF417 बारकोड")

**अपेक्षित आउटपुट:** 2‑पिक्सेल‑चौड़ाई, तीन‑कॉलम PDF417 बारकोड जो टेक्स्ट “Compact example” को एन्कोड करता है। PNG को एक मानक बारकोड स्कैनर से स्कैन करने पर मूल स्ट्रिंग वापस मिलनी चाहिए।

## सामान्य विविधताएँ और किनारे के केस

| स्थिति | कोड को कैसे समायोजित करें |
|-----------|------------------------|
| **लंबा डेटा ( > 500 अक्षर )** | `Columns` को 5‑7 तक बढ़ाएँ ताकि बारकोड बहुत ऊँचा न हो। |
| **उच्च‑रिज़ॉल्यूशन प्रिंटिंग** | `XDimension.Pixels` को 3 या 4 सेट करें बड़े मॉड्यूल के लिए। |
| **विभिन्न इमेज फॉर्मेट** | `BarCodeImageFormat.Png` को आवश्यकता अनुसार `Jpeg` या `Bmp` से बदलें। |
| **बारकोड को PDF में एम्बेड करना** | PNG के बजाय `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` का उपयोग करें। |

**प्रो टिप:** हमेशा जनरेट किए गए बारकोड को लक्ष्य स्कैनर हार्डवेयर पर टेस्ट करें। कुछ कम‑कीमत वाले स्कैनर बहुत छोटे X‑डायमेंशन से जूझते हैं; यदि पढ़ने में त्रुटि आती है, तो पिक्सेल मान को एक कदम बढ़ाएँ।

## पूर्ण, चलाने योग्य उदाहरण

नीचे पूर्ण प्रोग्राम दिया गया है जिसे आप नई कंसोल प्रोजेक्ट में कॉपी‑पेस्ट कर सकते हैं। कोई अतिरिक्त फ़ाइलें आवश्यक नहीं हैं।

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

प्रोग्राम को कंपाइल और रन करें (`dotnet run` यदि आप .NET CLI उपयोग करते हैं)। निष्पादन के बाद, दृश्य परिणाम की जाँच के लिए `CompactPdf417.png` खोलें।

## निष्कर्ष

अब आप जानते हैं **C# में PDF417 बारकोड कैसे जेनरेट करें** एक कॉम्पैक्ट लेआउट, कस्टम X‑डायमेंशन, और कॉलम सेटिंग्स के साथ। उदाहरण आवश्यक चरणों को दर्शाता है: `BarcodeGenerator` को इंस्टैंशिएट करना, `XDimension` और `Columns` को कॉन्फ़िगर करना, कॉम्पैक्ट मोड के लिए `Truncate` सक्षम करना, और अंत में इमेज सहेजना।

अब आप अतिरिक्त सुविधाओं जैसे एरर‑करेक्शन लेवल, कस्टम रंग, या बारकोड को सीधे PDF में एम्बेड करना आदि का अन्वेषण कर सकते हैं। यदि आपको अन्य सिम्बोलॉजी (जैसे QR, Code128) चाहिए तो विभिन्न `EncodeTypes` के साथ प्रयोग करें और समान पैरामीटर कॉन्फ़िगरेशन पैटर्न को इंटीग्रेट करें।

कोडिंग का आनंद लें, और आपका बारकोड हमेशा पहली कोशिश में स्कैन हो!
