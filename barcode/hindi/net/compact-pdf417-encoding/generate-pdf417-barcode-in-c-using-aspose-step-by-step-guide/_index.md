# Aspose का उपयोग करके C# में PDF417 बारकोड बनाना – चरण‑दर‑चरण गाइड

यदि आपको **PDF417 बारकोड बनाना** एक .NET एप्लिकेशन में है, तो यह गाइड आपको बिल्कुल दिखाता है कि कैसे। आप एक पूर्ण, तैयार‑चलाने योग्य उदाहरण देखेंगे जो Aspose.BarCode for .NET के साथ बेसिक, कॉम्पैक्ट, माइक्रो, GS1‑माइक्रो, और मैक्रो PDF417 बारकोड बनाता है।

शिपिंग लेबल, ट्रांसपोर्ट दस्तावेज़, और इन्वेंट्री सिस्टम के लिए PDF417 बारकोड बनाना एक सामान्य आवश्यकता है। इस ट्यूटोरियल के अंत तक आप **PDF417 बारकोड** इमेज़ बनाना, प्रमुख पैरामीटर समझना, और अपने डेटा पेलोड के लिए कोड को अनुकूलित करना सीख जाएंगे।

## आवश्यकताएँ

- .NET 6.0 SDK या बाद का (कोड .NET Framework 4.7+ के साथ भी काम करता है)
- Visual Studio 2022 या कोई भी C# IDE
- Aspose.BarCode for .NET NuGet पैकेज (`Aspose.BarCode`) स्थापित
- C# सिंटैक्स की बुनियादी परिचितता

> **Pro tip:** परीक्षण के दौरान रनटाइम प्रतिबंधों से बचने के लिए Aspose का मुफ्त इवैल्यूएशन लाइसेंस उपयोग करें।

## चरण 1: प्रोजेक्ट सेट अप करें और नेमस्पेस इम्पोर्ट करें

एक नया कंसोल प्रोजेक्ट बनाएं और Aspose.BarCode पैकेज जोड़ें:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

फिर `Program.cs` खोलें और आवश्यक `using` निर्देश जोड़ें:

```csharp
using System;
using Aspose.BarCode.Generation;
```

ये नेमस्पेस आपको `BarcodeGenerator` क्लास और `EncodeTypes` एनेमरेशन तक पहुँच देते हैं, जो **C# का उपयोग करके बारकोड बनाना** के लिए आवश्यक हैं।

## चरण 2: बेसिक PDF417 बारकोड बनाएं

सबसे सरल PDF417 बारकोड डिफ़ॉल्ट सेटिंग्स का उपयोग करता है, सिवाय X‑डायमेंशन (मॉड्यूल चौड़ाई) और कॉलम संख्या के। इन मानों को समायोजित करने से कुल आकार और पठनीयता नियंत्रित होती है।

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**क्यों काम करता है:**  
- `EncodeTypes.Pdf417` Aspose को PDF417 सिम्बोलॉजी उपयोग करने के लिए बताता है।  
- `XDimension.Pixels` सबसे छोटी बार चौड़ाई को परिभाषित करता है; मान 2 इमेज को छोटा रखता है बिना स्कैनबिलिटी घटाए।  
- `Pdf417.Columns` निर्धारित करता है कि बारकोड में कितने डेटा कॉलम हैं; तीन कॉलम संतुलित अनुपात देते हैं।

## चरण 3: कॉम्पैक्ट (ट्रंकेटेड) PDF417 बारकोड बनाएं

कॉम्पैक्ट मोड स्टॉप पैटर्न को हटाता है और कुल ऊँचाई को कम करता है, जो सीमित‑स्थान लेबल के लिए उपयोगी है।

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**क्यों काम करता है:**  
`Pdf417.Truncate = true` सेट करने से ट्रंकेटेड मोड सक्रिय होता है, जो दाएँ‑हाथ का स्टॉप पैटर्न हटाता है और बारकोड की ऊँचाई को घटाता है जबकि डेटा इंटेग्रिटी बनाए रखता है।

## चरण 4: माइक्रो PDF417 बारकोड बनाएं

माइक्रो PDF417 एक छोटा संस्करण है जो 1‑4 कॉलम का समर्थन करता है। यह उन अनुप्रयोगों के लिए आदर्श है जहाँ स्थान कम होता है, जैसे छोटे प्रोडक्ट टैग।

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**क्यों काम करता है:**  
- `EncodeTypes.MicroPdf417` सिम्बोलॉजी का माइक्रो संस्करण चुनता है।  
- कॉलम संख्या 1 से 4 के बीच हो सकती है; 4 चुनने से सबसे घना लेआउट मिलता है जबकि स्कैन करने योग्य रहता है।

## चरण 5: GS1‑अनुपालन माइक्रो PDF417 बारकोड बनाएं

GS1 प्रीफ़िक्स बारकोड डेटा में मानकीकृत पहचानकर्ता (जैसे GTIN, बैच नंबर) जोड़ते हैं। Aspose आपको इन्हें सीधे एम्बेड करने देता है।

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**क्यों काम करता है:**  
GS1 एप्लिकेशन आइडेंटिफ़ायर्स (AIs) को कोष्ठकों में रखा जाता है। Aspose उन्हें पार्स करता है और GS1 स्कैनरों द्वारा आवश्यक उचित फ़ॉर्मेटिंग जोड़ता है।

## चरण 6: पूर्ण मेटाडेटा के साथ मैक्रो PDF417 बारकोड बनाएं

मैक्रो PDF417 आपको बड़े डेटा पेलोड को कई जुड़े हुए बारकोड में विभाजित करने की अनुमति देता है। आप फ़ाइल‑स्तर मेटाडेटा जैसे फ़ाइल ID, सेगमेंट काउंट, टाइमस्टैम्प, और कस्टम स्ट्रिंग्स एम्बेड कर सकते हैं।

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**क्यों काम करता है:**  
प्रत्येक `MacroPdf417*` प्रॉपर्टी मैक्रो बारकोड स्पेसिफिकेशन के एक विशिष्ट सेगमेंट से मैप होती है। इन मानों को सेट करने से सुनिश्चित होता है कि स्कैनर कई बारकोड इमेज़ से मूल फ़ाइल को पुनर्निर्मित कर सके।
