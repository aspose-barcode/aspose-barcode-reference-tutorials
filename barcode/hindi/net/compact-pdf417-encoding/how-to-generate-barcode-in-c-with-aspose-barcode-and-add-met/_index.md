# C# में Aspose.BarCode के साथ बारकोड जनरेट करें और मेटाडेटा जोड़ें

यदि आपको लॉजिस्टिक्स या इन्वेंटरी सिस्टम के लिए **C# में बारकोड जनरेट** करना है, तो यह गाइड एक पूर्ण, प्रोडक्शन‑रेडी समाधान दिखाता है। आप देखेंगे कि कैसे मैक्रो PDF417 बारकोड बनाएं, समृद्ध मेटाडेटा संलग्न करें, और सटीक टाइमस्टैम्प सेट करें—सब कुछ Aspose.BarCode लाइब्रेरी के साथ।

यह ट्यूटोरियल इंस्टॉल करने से लेकर अंतिम PNG इमेज सेव करने तक सब कुछ कवर करता है। अंत तक, आप एक ऐसा बारकोड जनरेट कर पाएंगे जिसमें फ़ाइल पहचानकर्ता, सेगमेंट जानकारी, और कस्टम फ़ील्ड्स हों, जो मैक्रो PDF417 को सपोर्ट करने वाले डाउनस्ट्रीम स्कैनर के लिए तैयार हो।

## आवश्यकताएँ

शुरू करने से पहले सुनिश्चित करें कि आपके पास है:

* .NET 6.0 SDK या बाद का संस्करण (कोड .NET Framework 4.7.2+ पर भी काम करता है)
* Visual Studio 2022 या कोई भी पसंदीदा C# IDE
* सक्रिय Aspose.BarCode लाइसेंस (डिवेलपमेंट के लिए फ्री ट्रायल चलती है)
* C# सिंटैक्स की बुनियादी समझ

> **Pro tip:** यदि आप CI/CD पाइपलाइन उपयोग करते हैं, तो अपने प्रोजेक्ट फ़ाइल में Aspose.BarCode पैकेज रेफ़रेंस जोड़ें ताकि बिल्ड्स पुनरुत्पादित रहें।

## चरण 1: Aspose.BarCode स्थापित करें

अपने प्रोजेक्ट फ़ोल्डर में टर्मिनल खोलें और चलाएँ:

```bash
dotnet add package Aspose.BarCode
```

यह कमांड नवीनतम स्थिर संस्करण (वर्तमान में 24.9) को पुल करता है। रिस्टोर समाप्त होने के बाद, आप लाइब्रेरी को अपने सोर्स फ़ाइलों में रेफ़र कर सकते हैं।

## चरण 2: नया C# कंसोल प्रोजेक्ट बनाएं (वैकल्पिक)

यदि आप नई शुरुआत चाहते हैं, तो एक कंसोल ऐप बनाएं:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs` फ़ाइल में बाद में दिखाया गया बारकोड जनरेशन कोड रहेगा।

## चरण 3: बारकोड जेनरेटर सेट अप करें

प्रक्रिया का मुख्य भाग `BarcodeGenerator` क्लास है। आप इसे इच्छित `EncodeTypes` एन्हुम मान और एन्कोड करने वाले टेक्स्ट के साथ इंस्टैंशिएट करते हैं।

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### प्रत्येक पंक्ति क्यों महत्वपूर्ण है

* **EncodeTypes.MacroPdf417** Aspose को ऐसा PDF417 बारकोड बनाने के लिए कहता है जिसे सेगमेंट्स में विभाजित किया जा सके। यह बड़े पेलोड्स के लिए आवश्यक है जो एक सिंगल सिम्बल की क्षमता से अधिक होते हैं।
* **XDimension.Pixels** दृश्य घनत्व को नियंत्रित करता है। मान 2 अधिकांश स्क्रीन और प्रिंटर पर स्पष्ट इमेज देता है और फ़ाइल आकार को बढ़ाए बिना।
* **MacroPdf417* properties** वह मेटाडेटा एम्बेड करती हैं जिसे डाउनस्ट्रीम स्कैनर अलग‑अलग फ़ील्ड्स (फ़ाइल ID, सेगमेंट ID, आदि) के रूप में पढ़ते हैं। यही ट्यूटोरियल का “मेटाडेटा कैसे जोड़ें” भाग है।
* **MacroPdf417TimeStamp** “टाइमस्टैम्प कैसे सेट करें” को दर्शाता है। `DateTime` इंस्टैंस कोई भी UTC समय हो सकता है; UTC उपयोग करने से टाइमज़ोन की अस्पष्टता नहीं रहती जब बारकोड विभिन्न क्षेत्रों में यात्रा करता है।
* **MacroPdf417Terminator** मैक्रो सीक्वेंस के समाप्त होने का तरीका निर्धारित करता है। `Set` सबसे आम विकल्प है क्योंकि यह रीडर को अंतिम सेगमेंट संकेत देता है।
* **Save(..., BarCodeImageFormat.Png)** एक लॉसलेस इमेज लिखता है जो विश्वसनीय स्कैनिंग के लिए आवश्यक बारीक विवरणों को संरक्षित रखता है।

`ExtPDF417Meta.png` को किसी भी इमेज व्यूअर में खोलें। चित्र में एक कॉम्पैक्ट PDF417 सिम्बल दिखेगा जिसमें टेक्स्ट **Åspóse.Barcóde©** और एम्बेडेड मैक्रो फ़ील्ड्स होंगे। इस इमेज को PDF417‑कम्पैटिबल स्कैनर (या मैक्रो PDF417 सपोर्ट करने वाले मोबाइल ऐप) से स्कैन करने पर मूल टेक्स्ट के साथ आपने सेट किए हुए मेटाडेटा वैल्यूज़ मिलेंगे।

### अपेक्षित दृश्य विशेषताएँ

* गहरे, समान रूप से स्पेस्ड वर्टिकल बार
* Aspose द्वारा स्वचालित रूप से जोड़ा गया क्वाइट ज़ोन (मार्जिन)
* कोई विकृति नहीं, क्योंकि `XDimension` 2 पिक्सेल PNG की नेटिव रिज़ॉल्यूशन से मेल खाता है

## चरण 5: सामान्य वैरिएशन्स और एज केस

### 5.1 विशेष अक्षरों का हैंडलिंग

सैंपल टेक्स्ट में यूनिकोड कैरेक्टर्स (`Å`, `ó`, `©`) हैं। Aspose.BarCode डिफ़ॉल्ट रूप से उन्हें UTF‑8 में एन्कोड करता है, इसलिए वे बारकोड में सही दिखते हैं। यदि आपको अलग एन्कोडिंग चाहिए (जैसे ISO‑8859‑1), तो सेट करें:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 बड़े फ़ाइल पहचानकर्ता

`MacroPdf417FileID` 32‑बिट इंटीजर स्वीकार करता है। यदि मान `int.MaxValue` से बड़ा है, तो पहचानकर्ता को कई फ़ील्ड्स में बाँटें या `MacroPdf417FileName` में स्ट्रिंग के रूप में GUID उपयोग करें।

### 5.3 कॉलम की संख्या समायोजित करना

`Pdf417.Columns` बढ़ाने से बारकोड की ऊँचाई घटती है लेकिन प्रत्येक पंक्ति चौड़ी हो जाती है। यदि बारकोड को संकरी लेबल में फिट करना है, तो कॉलम काउंट घटाएँ और रो काउंट स्वचालित रूप से बढ़ाएँ।

### 5.4 अन्य फ़ॉर्मैट में सेव करना

Aspose BMP, JPEG, TIFF, और SVG को सपोर्ट करता है। `BarCodeImageFormat.Png` को इच्छित एन्हुम वैल्यू से बदलें, उदाहरण के लिए स्केलेबल वेक्टर ग्राफ़िक के लिए `BarCodeImageFormat.Svg`।

## चरण 6: बारकोड को बड़े वर्कफ़्लो में इंटीग्रेट करें

PNG फ़ाइल मिलने के बाद आप इसे:

* Aspose.PDF का उपयोग करके PDF इनवॉइस में एम्बेड कर सकते हैं।
* डिलीवरी प्रूफ़ के रूप में ईमेल में अटैच कर सकते हैं।
* बाद में रिट्रीवल के लिए डेटाबेस में इमेज बाइट्स स्टोर कर सकते हैं।

नीचे एक छोटा स्निपेट है जो PNG को बाइट एरे में बदलकर स्टोरेज के लिए तैयार करता है:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## अक्सर पूछे जाने वाले प्रश्न

**प्रश्न: क्या यह .NET Core पर काम करता है?**  
उत्तर: हाँ। वही API .NET Core, .NET 5+ और .NET Framework पर काम करती है। केवल उपयुक्त NuGet पैकेज रेफ़रेंस करें।

**प्रश्न: यदि मुझे नॉन‑मैक्रो PDF417 जनरेट करना हो तो?**  
उत्तर: `EncodeTypes.Pdf417` का उपयोग करें, `EncodeTypes.MacroPdf417` के बजाय। मैक्रो‑स्पेसिफिक प्रॉपर्टीज़ अनदेखी रह जाएँगी।

**प्रश्न: क्या मैं बिल्ट‑इन फ़ील्ड्स के अलावा कस्टम की/वैल्यू पेयर्स जोड़ सकता हूँ?**  
उत्तर: Aspose.BarCode मैक्रो PDF417 के लिए मनमाने यूज़र फ़ील्ड्स प्रदान नहीं करता। यदि अतिरिक्त डेटा चाहिए, तो उसे मुख्य टेक्स्ट पेलोड में एन्कोड करें या QR कोड पर स्विच करें, जो स्ट्रक्चर्ड अपेंड को सपोर्ट करता है।

## निष्कर्ष

अब आप जानते हैं कि **C# में Aspose.BarCode** के साथ बारकोड कैसे जनरेट करें, समृद्ध मेटाडेटा एम्बेड करें, और मैक्रो PDF417 सिम्बल के लिए सटीक टाइमस्टैम्प सेट करें। पूरा, रन‑एबल उदाहरण लाइब्रेरी इंस्टॉल करने से लेकर स्कैनिंग‑रेडी PNG इमेज सेव करने तक हर आवश्यक कदम दर्शाता है।

अगला, **कैसे जनरेट करें pdf417** बिना मैक्रो सेगमेंट्स के, या **create barcode with aspose** जैसे अन्य सिंबोलॉजीज़ (QR, DataMatrix, Code128) के लिए देखें। विभिन्न इमेज फ़ॉर्मैट्स के साथ प्रयोग करें और बारकोड को PDFs, रिपोर्ट्स, या वेब API में इंटीग्रेट करके अपने डॉक्यूमेंट वर्कफ़्लो को ऑटोमेट करें।
