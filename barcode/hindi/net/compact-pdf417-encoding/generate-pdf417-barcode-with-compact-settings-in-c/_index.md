# C# में कॉम्पैक्ट सेटिंग्स के साथ PDF417 बारकोड जनरेट करें

यदि आपको .NET एप्लिकेशन में **PDF417 बारकोड जनरेट** करना है, तो यह गाइड Aspose.Barcode for .NET के साथ इसे कैसे करें दिखाता है। हम जनरेटर बनाने, कॉलम, X‑डायमेंशन को कॉन्फ़िगर करने, और कॉम्पैक्ट मोड को एनेबल करने के चरणों से गुजरेंगे ताकि परिणामी सिम्बल यथासंभव छोटा हो।

PDF417 बारकोड का जनरेशन अक्सर तब आवश्यक होता है जब आपको टिकट, आईडी या शिपिंग लेबल के लिए बड़ी मात्रा में डेटा एन्कोड करना हो। यह ट्यूटोरियल पूरी वर्कफ़्लो को कवर करता है—लाइब्रेरी इंस्टॉल करने से लेकर अंतिम PNG सहेजने तक—ताकि आप कोड को अपने प्रोजेक्ट में कॉपी‑पेस्ट करके तुरंत चला सकें।

## PDF417 बारकोड जनरेट करने के लिए प्रीरेक्विज़िट्स

शुरू करने से पहले सुनिश्चित करें कि आपके पास है:

* .NET 6.0 (या बाद का) इंस्टॉल हो।  
* Visual Studio 2022 या कोई भी IDE जो C# प्रोजेक्ट्स को सपोर्ट करता हो।  
* **Aspose.Barcode for .NET** का NuGet लाइसेंस (फ्री ट्रायल लर्निंग के लिए काम करता है)।  

आप लाइब्रेरी को निम्न कमांड से जोड़ सकते हैं:

```bash
dotnet add package Aspose.BarCode
```

> **Pro tip:** स्थिर संस्करण को पिन करने के लिए `--version` फ़्लैग का उपयोग करें, जैसे `dotnet add package Aspose.BarCode --version 23.12`।

## PDF417 बारकोड जनरेटर बनाएं

पहला कोड ब्लॉक एक `BarcodeGenerator` इंस्टेंस बनाता है जो PDF417 सिम्बोलॉजी के लिए प्री‑कॉन्फ़िगर किया गया है। टेक्स्ट `"Åspóse.Barcóde©"` में यूनिकोड कैरेक्टर्स हैं ताकि यह दिखाया जा सके कि जनरेटर बॉक्स‑आउट‑ऑफ़‑द‑बॉक्स नॉन‑ASCII इनपुट को संभालता है।

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### क्यों महत्वपूर्ण है
`EncodeTypes.Pdf417` Aspose.Barcode को बताता है कि आप **PDF417 बारकोड** चाहते हैं, जो एक स्टैक्ड लीनियर सिम्बोलॉजी है और 1 850 कैरेक्टर्स तक स्टोर कर सकती है। टेक्स्ट आर्ग्यूमेंट के साथ कंस्ट्रक्टर का उपयोग करने से बाद में `SetCodeText` कॉल करने की जरूरत नहीं पड़ती।

## बारकोड XDimension (मॉड्यूल साइज) सेट करें

मॉड्यूल साइज, जिसे X‑डायमेंशन भी कहा जाता है, यह निर्धारित करता है कि प्रत्येक व्यक्तिगत बार कितनी चौड़ी होगी। छोटे पिक्सेल अधिक घना इमेज बनाते हैं, जबकि बड़े पिक्सेल कम‑रिज़ॉल्यूशन प्रिंटरों पर पठनीयता बढ़ाते हैं।

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### XDimension को क्यों एडजस्ट करें
`2` पिक्सेल का मान स्क्रीन डिस्प्ले और अधिकांश ऑफिस प्रिंटरों के लिए उपयुक्त है। यदि आपको हाई‑रेज़ोल्यूशन प्रिंट चाहिए, तो मान बढ़ाएँ; यदि आपको टाइटर बारकोड चाहिए (जैसे QR‑जैसा लुक), तो इसे घटाएँ—परंतु `1` पिक्सेल से नीचे कभी न जाएँ, नहीं तो इमेज पढ़ने योग्य नहीं रहेगी।

## PDF417 सिम्बल के लिए कॉलम की संख्या सेट करें

PDF417 आपको यह चुनने देता है कि बारकोड में कितने कॉलम (वर्टिकल स्टैक्स) होंगे। कम कॉलम होने से बारकोड ऊँचा बनता है; अधिक कॉलम होने से यह चौड़ा हो जाता है।

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### कॉलम काउंट कब बदलें
तीन कॉलम एक कॉम्पैक्ट, लगभग स्क्वायर सिम्बल बनाते हैं जो स्टैंडर्ड आईडी कार्ड पर अच्छी तरह फिट होता है। यदि आपका स्ट्रिंग बहुत लंबा है, तो आप कॉलम काउंट बढ़ा सकते हैं ताकि ऊँचाई को उचित रखा जा सके।

## कॉम्पैक्ट मोड (ट्रंकेशन) एनेबल करें

कॉम्पैक्ट मोड स्वचालित रूप से सिम्बल से अनयूज़्ड रो को हटाता है, जिससे उसका कुल आकार छोटा हो जाता है। यह विशेष रूप से तब उपयोगी होता है जब एन्कोड किया गया डेटा पूरी मैट्रिक्स को भरता नहीं है।

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### कॉम्पैक्ट PDF417 बारकोड के लाभ
जब `Truncate` `true` होता है, तो जनरेटर न्यूनतम आवश्यक रो की गणना करता है, जिससे इंक उपयोग और स्कैनिंग टाइम कम हो जाता है। यह अधिकांश स्कैनरों के लिए सुरक्षित है क्योंकि PDF417 स्पेसिफिकेशन ट्रंकेशन एल्गोरिदम को परिभाषित करता है।

## जनरेटेड बारकोड को इमेज के रूप में सहेजें

अंत में, बारकोड को PNG फ़ाइल में लिखें। PNG लॉसलेस क्वालिटी बनाए रखता है, जिससे यह बाद में प्रिंटिंग या PDF में एम्बेड करने के लिए आदर्श है।

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### अपेक्षित आउटपुट
प्रोग्राम चलाने पर निर्दिष्ट फ़ोल्डर में `CompactPdf417.png` बनता है। इमेज में **कॉम्पैक्ट PDF417 बारकोड** होता है जो स्ट्रिंग `"Åspóse.Barcóde©"` को तीन कॉलम, 2‑पिक्सेल X‑डायमेंशन, और ट्रंकेशन के साथ एन्कोड करता है। आप परिणाम को किसी भी बारकोड स्कैनर ऐप या मुफ्त Aspose.Barcode ऑनलाइन डेमो से वेरिफ़ाई कर सकते हैं।

## सामान्य वैरिएशन और एज केस

| स्थिति | समायोजन |
|-----------|------------|
| **बहुत लंबा डेटा (> 1500 कैरेक्टर्स)** | `Columns` बढ़ाएँ या `Rows` को मैन्युअली सेट करें (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`)। |
| **लो‑DPI प्रिंटर पर प्रिंटिंग** | पिक्सेलेशन से बचने के लिए `XDimension.Pixels` को 3 या 4 करें। |
| **ट्रांसपेरेंट बैकग्राउंड चाहिए** | `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })` का उपयोग करें। |
| **PDF में एम्बेड करना** | `BarCodeImageFormat.Pdf` के रूप में सहेजें या `pdf417Generator.GenerateBarCodeImage()` के जरिए `Image` ऑब्जेक्ट प्राप्त करें। |

## पूरा, रन करने योग्य उदाहरण

नीचे पूरा प्रोग्राम दिया गया है जिसे आप नई कंसोल प्रोजेक्ट में कॉपी कर सकते हैं। अतिरिक्त फ़ाइलों की आवश्यकता नहीं है।

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

प्रोजेक्ट फ़ोल्डर से `dotnet run` चलाएँ। निष्पादन के बाद `CompactPdf417.png` खोलें और जनरेटेड बारकोड देखें।

## निष्कर्ष

अब आप C# में **PDF417 बारकोड जनरेट** करना जानते हैं, साथ ही कॉलम, X‑डायमेंशन, और कॉम्पैक्ट मोड पर पूर्ण नियंत्रण रखते हैं। `barcode XDimension pixels` को एडजस्ट करके, `PDF417 columns` सेट करके, और `compact PDF417 barcode` ट्रंकेशन एनेबल करके आप ऐसा बारकोड बना सकते हैं जो आपके एप्लिकेशन की सटीक साइज कॉन्स्ट्रेंट्स को फिट करता हो।

अगले कदम जिन्हें आप एक्सप्लोर कर सकते हैं:

* बड़े डेटा सेट एन्कोड करें और `Rows` पैरामीटर के साथ प्रयोग करें।  
* आउटपुट फॉर्मेट को `BarCodeImageFormat.Svg` में बदलें ताकि स्केलेबल वेब ग्राफिक्स मिलें।  
* बारकोड को अन्य Aspose कंपोनेंट्स, जैसे **Aspose.PDF**, के साथ मिलाकर इमेज को सीधे PDF रिपोर्ट में एम्बेड करें।

हैप्पी कोडिंग, और अपने स्कैनिंग एनवायरनमेंट के अनुसार सेटिंग्स को ट्यून करने में संकोच न करें!
