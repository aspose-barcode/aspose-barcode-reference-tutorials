# Aspose.BarCode for .NET के साथ DataMatrix बारकोड कैसे जनरेट करें

यदि आपको अपने .NET अनुप्रयोगों में मशीन‑रीडेबल प्रतीकों को एम्बेड करने का एक विश्वसनीय तरीका चाहिए, तो **DataMatrix बारकोड कैसे जनरेट करें** एक सामान्य आवश्यकता है। Aspose.BarCode for .NET एक पूरी तरह से प्रबंधित API प्रदान करता है जो हर चरण को संभालता है—सही DataMatrix संस्करण चुनने से लेकर त्रुटि‑सुधार स्तरों को फाइन‑ट्यून करने तक—बिना किसी बाहरी टूल की आवश्यकता के। इस ट्यूटोरियल में हम एक पूर्ण उदाहरण के माध्यम से चलेंगे, समझाएंगे कि प्रत्येक सेटिंग क्यों महत्वपूर्ण है, और दिखाएंगे कि परिणाम को PNG या JPEG इमेज के रूप में कैसे सहेजें।

## त्वरित उत्तर
- **DataMatrix बारकोड बनाने वाली लाइब्रेरी कौन सी है?** Aspose.BarCode for .NET.  
- **कितनी DataMatrix संस्करण समर्थित हैं?** सभी 30 मानक वर्गीय और आयताकार संस्करण (10×10 से 144×144 मॉड्यूल तक).  
- **मैं कौन से ECC प्रकार उपयोग कर सकता हूँ?** ECC200 (डिफ़ॉल्ट) और ECC140.  
- **क्या विकास के लिए लाइसेंस चाहिए?** परीक्षण के लिए एक मुफ्त 30‑दिन ट्रायल काम करता है; उत्पादन के लिए एक व्यावसायिक लाइसेंस आवश्यक है.  
- **क्या मैं इसे .NET 6, .NET Core, या .NET Framework पर चला सकता हूँ?** हाँ—Aspose.BarCode .NET Framework 4.5+, .NET Core 3.1+, और .NET 5/6+ को सपोर्ट करता है.

## DataMatrix बारकोड क्या है?
DataMatrix बारकोड दो‑आयामी, वर्ग या आयताकार मैट्रिक्स है जिसमें काली और सफ़ेद कोशिकाएँ होती हैं और यह अधिकतम 2,335 अल्फ़ान्यूमेरिक अक्षर संग्रहीत कर सकता है। यह निर्माण, लॉजिस्टिक्स और स्वास्थ्य देखभाल में छोटे वस्तुओं को चिह्नित करने के लिए व्यापक रूप से उपयोग किया जाता है क्योंकि यह आंशिक रूप से क्षतिग्रस्त होने पर भी पढ़ा जा सकता है।

## Aspose.BarCode for .NET का उपयोग क्यों करें?
Aspose.BarCode **50+ आउटपुट फॉर्मेट** (जैसे PNG, JPEG, TIFF, SVG, और PDF) को सपोर्ट करता है और **सभी 30 DataMatrix संस्करण** को बिना पूरी इमेज को मेमोरी में लोड किए जनरेट कर सकता है, जिससे आप 100 MB से बड़े फ़ाइलों को प्रोसेस करने वाली हाई‑थ्रूपुट सेवाओं में बारकोड बना सकते हैं।

## .NET में DataMatrix बारकोड कैसे जनरेट करें?
`BarcodeGenerator` को `EncodeTypes.DataMatrix` प्रकार के साथ लोड करें, इच्छित संस्करण और ECC सेट करें, फिर `Save` को कॉल करके इमेज फ़ाइल लिखें। यह सिंगल‑लाइन पैटर्न आपके द्वारा चुने गए किसी भी संस्करण के लिए काम करता है और स्वचालित रूप से मॉड्यूल साइजिंग, क्वाइट ज़ोन्स, और इमेज रेंडरिंग को संभालता है।

## नेमस्पेस आयात करें
`BarcodeGenerator` Aspose.BarCode की कोर क्लास है जो बारकोड इमेज बनाती है।  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

`Aspose.BarCode.Generation` नेमस्पेस `BarcodeGenerator` क्लास तक पहुँच प्रदान करता है, जो बारकोड इमेज जनरेट करने के लिए मुख्य क्लास है।

अब, चलिए उदाहरण को कई चरणों में विभाजित करते हैं।

## चरण 1: अपनी डायरेक्टरी पाथ सेट करें
सबसे पहले उस डायरेक्टरी पाथ को परिभाषित करें जहाँ आप जनरेट किए गए DataMatrix बारकोड सहेजना चाहते हैं।

```csharp
string path = "Your Directory Path";
```

`"Your Directory Path"` को वास्तविक पाथ से बदलें जहाँ आप बारकोड इमेज सहेजना चाहते हैं।

## चरण 2: बारकोड जेनरेटर को इनिशियलाइज़ करें
`BarcodeGenerator` क्लास का एक इंस्टेंस बनाएं और बारकोड प्रकार को `DataMatrix` निर्दिष्ट करें। आप वह डेटा भी प्रदान कर सकते हैं जिसे आप बारकोड में एन्कोड करना चाहते हैं।

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` वह मुख्य क्लास है जो बारकोड प्रतीकों को बनाता और रेंडर करता है।

## चरण 3: बारकोड प्रॉपर्टीज़ कॉन्फ़िगर करें
आप DataMatrix बारकोड की विभिन्न प्रॉपर्टीज़ को कस्टमाइज़ कर सकते हैं, जैसे इसके आयाम और ECC (Error Correction Code) प्रकार। यहाँ X‑डाइमेंशन को 4 पिक्सेल सेट करने और ECC200 चुनने का एक उदाहरण है:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` प्रत्येक मॉड्यूल का आकार पिक्सेल में सेट करता है, और `DataMatrixEcc` त्रुटि‑सुधार स्तर चुनता है।

## चरण 4: DataMatrix संस्करण सेट करें और सहेजें
आप पंक्तियों और कॉलमों की संख्या सेट करके DataMatrix संस्करण निर्दिष्ट कर सकते हैं। संस्करण को कॉन्फ़िगर करने के बाद, बारकोड इमेज सहेजें।

उदाहरण के लिए, ECC200 का उपयोग करके 22 पंक्तियों और 22 कॉलमों वाला DataMatrix बारकोड बनाने के लिए:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

इसी तरह, आप संस्करण और ECC प्रकार बदलकर विभिन्न पैरामीटरों के साथ बारकोड जनरेट कर सकते हैं।

## चरण 5: अन्य संस्करणों के लिए दोहराएँ
आप अन्य DataMatrix संस्करणों के लिए चरण 4 को दोहरा सकते हैं। उदाहरण के लिए, ECC200 का उपयोग करके 12 पंक्तियों और 64 कॉलमों वाला बारकोड बनाने के लिए:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## चरण 6: ECC प्रकार बदलें
यदि आप ECC प्रकार को Ecc140 में बदलना चाहते हैं, तो आप ECC प्रॉपर्टी को अपडेट करके ऐसा कर सकते हैं:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## चरण 7: विभिन्न संस्करणों और ECC के साथ बारकोड जनरेट करें
अन्य DataMatrix संस्करणों और ECC प्रकारों के लिए चरण 4 को दोहराएँ, प्रत्येक बारकोड को एक अद्वितीय फ़ाइल नाम के साथ सहेजें।

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```
