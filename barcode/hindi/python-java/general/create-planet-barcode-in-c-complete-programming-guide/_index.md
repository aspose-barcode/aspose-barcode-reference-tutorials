# C# में Planet बारकोड बनाएं – पूर्ण प्रोग्रामिंग गाइड

यदि आपको C# में **Planet बारकोड बनाना** है, तो यह गाइड आपको बिल्कुल बताता है कि इसे कैसे करें। आप यह भी जानेंगे **बारकोड के आयाम कैसे सेट करें** ताकि बार्स आपकी आवश्यक सटीक चौड़ाई पर प्रदर्शित हों।

Planet बारकोड बनाना अक्सर तब आवश्यक होता है जब आप डाक सेवाओं या लॉजिस्टिक्स सिस्टम के साथ काम करते हैं। नीचे दिया गया कोड डिफ़ॉल्ट फ़िल्ड‑बार संस्करण और वैकल्पिक खाली‑बार शैली दोनों को कवर करता है, साथ ही RM4SCC फ़ॉर्मेट का एक त्वरित उदाहरण भी देता है। इस ट्यूटोरियल के अंत तक आपके पास एक पुन: उपयोग योग्य स्निपेट होगा जिसे आप किसी भी .NET प्रोजेक्ट में डाल सकते हैं।

## आवश्यकताएँ

शुरू करने से पहले सुनिश्चित करें कि आपके पास निम्नलिखित हों:

* .NET 6.0 या बाद का संस्करण स्थापित हो (API .NET Framework 4.6+ के साथ भी काम करता है)
* **Aspose.BarCode for .NET** NuGet पैकेज (`Aspose.BarCode`) आपके प्रोजेक्ट में जोड़ा गया हो
* वह फ़ोल्डर पाथ जहाँ PNG फ़ाइलें सहेजी जाएँगी, लिखने योग्य हो
* C# सिंटैक्स और Visual Studio (या कोई भी IDE) की बुनियादी जानकारी

> **Pro tip:** इमेज सहेजते समय अनुमति समस्याओं से बचने के लिए एक पूर्ण पाथ या `Path.Combine(Environment.CurrentDirectory, "output")` का उपयोग करें।

## चरण 1 – Planet बारकोड जेनरेटर (फ़िल्ड बार) को इनिशियलाइज़ करें

पहला कदम Planet सिंबोलॉजी के लिए `BarcodeGenerator` इंस्टेंस बनाना है। डिफ़ॉल्ट रूप से जेनरेटर **फ़िल्ड** बार बनाता है।

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

`EncodeTypes.Planet` एनेम Aspose.BarCode को Planet फ़ॉर्मेट उपयोग करने के लिए बताता है, जबकि `"123456"` वह डेटा पेलोड है जिसे एन्कोड किया जाएगा।

## चरण 2 – लगातार आकार के लिए बारकोड आयाम कैसे सेट करें

प्रत्येक बार की चौड़ाई को नियंत्रित करने के लिए **X‑dimension** को समायोजित करें। यह **बारकोड आयाम सेट करने** का मुख्य तरीका है और यह सुनिश्चित करता है कि बारकोड आपके लेबल के आकार में फिट हो।

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

`Pixels` प्रॉपर्टी स्क्रीन पिक्सेल में बार की चौड़ाई निर्धारित करती है। मानक मेलिंग लेबल्स के लिए सामान्य मान 2 – 5 पिक्सेल होते हैं; बड़े प्रिंट के लिए मान बढ़ाएँ।

## चरण 3 – फ़िल्ड Planet बारकोड को PNG के रूप में सहेजें

अब इमेज को डिस्क पर लिखें। PNG तेज किनारे रखता है, जो स्कैनिंग के लिए आदर्श है।

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

`YOUR_DIRECTORY` को उस पाथ से बदलें जो आपने पहले तैयार किया था। इस कोड को चलाने के बाद आपको नीचे दिखाए गए इमेज जैसा फ़ाइल मिलेगा।

## चरण 4 – खाली (अनफ़िल्ड) बार वाला Planet बारकोड बनाएं

यदि आपका डाक सेवा बार को **खाली** चाहती है, तो जेनरेटर को इनिशियलाइज़ करने के बाद `FilledBars` फ़्लैग को टॉगल करें।

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

कंस्ट्रक्टर समान है; अंतर अगले कॉन्फ़िगरेशन चरण में है।

## चरण 5 – बारकोड आयाम सेट करें और बार को खाली बनाएं

फिर से विज़ुअल कंसिस्टेंसी के लिए X‑dimension सेट करें, फिर फ़िल्ड बार को डिसेबल करें।

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

`FilledBars = false` प्रॉपर्टी ही रेंडरिंग स्टाइल को बदलती है। समान X‑dimension रखने से खाली‑बार वाला बारकोड फ़िल्ड संस्करण के साथ पूरी तरह संरेखित रहता है।

## चरण 6 – खाली Planet बारकोड को सहेजें

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

अब आपके पास दो PNG फ़ाइलें होंगी: एक ठोस बार वाली और एक खोखली बार वाली, दोनों के आयाम समान हैं।

## चरण 7 – (वैकल्पिक) तुलना के लिए RM4SCC बारकोड बनाएं

RM4SCC एक अन्य डाक सिंबोलॉजी है जो डिफ़ॉल्ट फ़िल्ड‑बार स्टाइल का उपयोग करता है। चरण Planet उदाहरण के समान हैं, यह दर्शाते हुए कि **बारकोड आयाम कैसे सेट करें** विभिन्न फ़ॉर्मेट में भी काम करता है।

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

इन तीन चरणों को चलाने से `PostalRM4SCCFilledBars.png` बनता है, जिसे आप Planet आउटपुट के साथ साइड‑बाय‑साइड तुलना कर सकते हैं।

## X‑dimension क्यों महत्वपूर्ण है

X‑dimension प्रत्येक बार की **न्यूनतम प्रिंटेबल चौड़ाई** निर्धारित करता है। यदि इसे बहुत कम सेट किया जाए, तो बारकोड कम‑रिज़ॉल्यूशन प्रिंटरों पर धुंधला हो सकता है, जिससे स्कैन विफल हो सकता है। दूसरी ओर, बहुत बड़ा X‑dimension लेबल के आकार से अधिक हो सकता है और जगह बर्बाद कर सकता है। **बारकोड आयाम कैसे सेट करें** को स्पष्ट रूप से समझकर आप अंतिम इमेज आकार पर निर्धारक नियंत्रण प्राप्त करते हैं, जो स्वचालित मेलिंग वर्कफ़्लो के लिए आवश्यक है।

## सामान्य समस्याएँ और उनके समाधान

| Issue | Cause | Fix |
|-------|-------|-----|
| बारकोड खिंचा हुआ दिखता है | X‑dimension को पिक्सेल के बजाय पॉइंट्स में सेट किया गया | पिक्सेल‑परफेक्ट नियंत्रण के लिए हमेशा `Pixels` प्रॉपर्टी का उपयोग करें |
| खाली बार अभी भी भरे हुए दिखते हैं | `FilledBars` को X‑dimension बदलने के बाद `false` नहीं किया गया | `FilledBars = false` को X‑dimension समायोजित करने के बाद सेट करें |
| सहेजी गई फ़ाइल खाली है | आउटपुट डायरेक्टरी मौजूद नहीं है या लिखने की अनुमति नहीं है | डायरेक्टरी मौजूद है (`Directory.CreateDirectory`) यह सुनिश्चित करें और आपका ऐप पर्याप्त अधिकारों के साथ चल रहा हो |
| प्रिंट पर इमेज धुंधली है | उच्च‑रिज़ॉल्यूशन मॉनीटर से कम DPI PNG सहेजा गया | `BarCodeImageFormat.Png` (लॉसलेस) का उपयोग करें और आवश्यकता होने पर `Resolution` प्रॉपर्टी पर विचार करें |

## पूर्ण, चलाने योग्य उदाहरण

नीचे दिया गया पूरा ब्लॉक एक नए कंसोल प्रोजेक्ट (`dotnet new console`) में कॉपी करें और चलाएँ। प्रोग्राम `output` फ़ोल्डर में तीन PNG फ़ाइलें बनाता है।

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**अपेक्षित आउटपुट:** तीन PNG फ़ाइलें—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png`, और `PostalRM4SCCFilledBars.png`—प्रत्येक में 4‑पिक्सेल चौड़े बार, प्रिंट या आगे की प्रोसेसिंग के लिए तैयार।

## निष्कर्ष

अब आप जानते हैं कि C# में **Planet बारकोड कैसे बनाएं** और फ़िल्ड तथा खाली बार स्टाइल दोनों के लिए **बारकोड आयाम कैसे सेट करें**। वही पैटर्न अन्य सिंबोलॉजी जैसे RM4SCC पर भी लागू होता है, जिससे आप किसी भी डाक‑बारकोड आवश्यकता के लिए एक लचीला आधार प्राप्त करते हैं।

अगले कदम में आप यह कर सकते हैं:

* बारकोड के नीचे मानव‑पठनीय टेक्स्ट जोड़ें (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* `Parameters.Barcode.BarColor` से बार का रंग बदलें
* स्केलेबल प्रिंटिंग के लिए वेक्टर फ़ॉर्मेट (SVG, EPS) में बारकोड जनरेट करें

विभिन्न X‑dimension मान, डेटा स्ट्रिंग और आउटपुट फ़ॉर्मेट के साथ प्रयोग करें ताकि आपका वर्कफ़्लो पूरी तरह फिट हो सके। कोडिंग का आनंद लें!
