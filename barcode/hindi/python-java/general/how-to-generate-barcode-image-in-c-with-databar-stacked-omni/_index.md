# C# में DataBar Stacked Omni‑Directional के साथ बारकोड इमेज कैसे जनरेट करें

यदि आपको .NET एप्लिकेशन में **बारकोड इमेज कैसे जनरेट करें** की आवश्यकता है, तो यह ट्यूटोरियल सटीक चरण दिखाता है। आप देखेंगे कि DataBar Stacked Omni‑Directional बारकोड कैसे बनाएं, उसका एस्पेक्ट रेशियो कैसे समायोजित करें, और परिणाम को PNG फ़ाइलों के रूप में एक्सपोर्ट करें।

बारकोड जनरेट करना इन्वेंटरी सिस्टम, रिटेल पॉइंट‑ऑफ़‑सेल टर्मिनल और लॉजिस्टिक्स ट्रैकिंग के लिए सामान्य आवश्यकता है। अगले सेक्शन में हम सभी आवश्यक चीज़ों को कवर करेंगे—आवश्यक NuGet पैकेज से लेकर अंतिम इमेज वेरिफिकेशन तक—ताकि आप आज ही किसी भी C# प्रोजेक्ट में बारकोड निर्माण को इंटीग्रेट कर सकें।

## Prerequisites

शुरू करने से पहले सुनिश्चित करें कि आपके पास है:

* .NET 6.0 या बाद का (कोड .NET Core और .NET Framework के साथ काम करता है)
* Visual Studio 2022 या कोई भी C# IDE जो आप पसंद करते हैं
* **Aspose.BarCode for .NET** NuGet पैकेज (इंस्टॉल करने के लिए `dotnet add package Aspose.BarCode` का उपयोग करें)
* उस फ़ोल्डर में लिखने की अनुमति जहाँ PNG फ़ाइलें सहेजी जाएँगी

ये पूर्वापेक्षाएँ सुनिश्चित करती हैं कि सैंपल अतिरिक्त कॉन्फ़िगरेशन के बिना चल सके।

## Step 1: Set up the output folder

पहला काम वह डायरेक्टरी बनाना है जहाँ जनरेट की गई PNG फ़ाइलें लिखी जाएँगी। एब्सोल्यूट या रिलेटिव पाथ दोनों काम करेंगे, लेकिन `Save` कॉल करने से पहले फ़ोल्डर मौजूद होना चाहिए।

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

फ़ोल्डर को प्रोग्रामेटिकली बनाना *FileNotFoundException* को रोकता है जब `Save` मेथड इमेज लिखने की कोशिश करता है।

## Step 2: Create a DataBar Stacked Omni‑Directional barcode generator

**BarcodeGenerator** क्लास सभी बारकोड प्रकारों के लिए एंट्री पॉइंट है। यहाँ हम `EncodeTypes.DatabarStackedOmniDirectional` और वह डेटा स्ट्रिंग सेट करते हैं जिसे हम एन्कोड करना चाहते हैं।

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*क्यों यह महत्वपूर्ण है*: `EncodeTypes` एनेम लाइब्रेरी को बताता है कि कौन सी सिम्बोलॉजी रेंडर करनी है। Omni‑Directional वेरिएंट का उपयोग करने से बारकोड किसी भी ओरिएंटेशन से स्कैन किया जा सकता है—जो कई वेयरहाउस स्कैनरों की आवश्यकता है।

## Step 3: Configure common barcode parameters

एक पठनीय बारकोड को उचित X‑डायमेंशन (सबसे छोटे बार की चौड़ाई) की जरूरत होती है। `Pixels` को 2 सेट करने से अधिकांश स्क्रीन रेज़ोल्यूशन के लिए आकार और स्पष्टता का अच्छा संतुलन मिलता है।

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

यदि आपको बड़ी या छोटी इमेज चाहिए तो बाद में `Pixels` को समायोजित कर सकते हैं; लाइब्रेरी बाकी बारकोड को स्वचालित रूप से स्केल कर देती है।

## Step 4: Generate the first image with aspect ratio 15

**aspect ratio** DataBar बारकोड की ऊँचाई‑से‑चौड़ाई संबंध को नियंत्रित करता है। 15 का एस्पेक्ट रेशियो रिटेल लेबल्स के लिए सामान्य डिफ़ॉल्ट है।

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

इस कॉल के बाद, आप आउटपुट फ़ोल्डर में `DatabarAspectRatio15.png` पाएँगे। इमेज एक लॉसलेस PNG है, जो आगे की प्रोसेसिंग या प्रिंटिंग के लिए उपयुक्त है।

## Step 5: Change the aspect ratio to 30 and export a second image

कभी‑कभी ऊँचा बारकोड आवश्यक होता है—उदाहरण के लिए जब लेबल की ऊँचाई सीमित हो। एस्पेक्ट रेशियो को 30 करने से अधिक कॉम्पैक्ट विज़ुअल मिलता है जबकि डेटा इंटेग्रिटी बनी रहती है।

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

अब आपके पास दो PNG फ़ाइलें हैं जो दिखाती हैं कि समान डेटा विभिन्न एस्पेक्ट रेशियो के साथ कैसे दिखता है। यह साइड‑बाय‑साइड तुलना आपको तय करने में मदद करेगी कि कौन सा वेरिएंट आपके लेबल लेआउट के लिए बेहतर है।

## Full, runnable example

नीचे पूरा प्रोग्राम दिया गया है जिसे आप कॉपी‑पेस्ट करके चला सकते हैं। इसमें सभी `using` डायरेक्टिव्स, एरर हैंडलिंग, और कमेंट्स शामिल हैं जो प्रक्रिया के प्रत्येक भाग को समझाते हैं।

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**अपेक्षित आउटपुट** (कंसोल):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

दोनों PNG फ़ाइलें किसी भी इमेज व्यूअर में खोलें। आप देखेंगे कि वही GTIN एन्कोड है, लेकिन दूसरा इमेज ऊँचा है क्योंकि एस्पेक्ट रेशियो अधिक है।

## Pro tips and common pitfalls

| Situation | Recommendation |
|-----------|----------------|
| **Low‑resolution displays** | बार्स को स्पष्ट रखने के लिए `XDimension.Pixels` को 3 या 4 तक बढ़ाएँ। |
| **Printing on thermal paper** | उच्च फ़िडेलिटी के लिए `BarCodeImageFormat.Tiff` उपयोग करें और `Resolution.DpiX/DpiY` को 300 सेट करें। |
| **Dynamic data** | वही `BarcodeGenerator` इंस्टेंस पुनः उपयोग करें और प्रत्येक `Save` से पहले केवल `generator.CodeText` अपडेट करें। इससे अनावश्यक ऑब्जेक्ट अलोकेशन से बचा जा सकता है। |
| **Invalid GTIN** | यदि डेटा GS1 मानकों के अनुरूप नहीं है तो लाइब्रेरी `ArgumentException` थ्रो करती है। जनरेटर को पास करने से पहले अपने डेटा को वैलिडेट करें। |

## Conclusion

अब आप **बारकोड इमेज कैसे जनरेट करें** C# में Aspose.BarCode का उपयोग करके, DataBar Stacked Omni‑Directional एस्पेक्ट रेशियो को कैसे नियंत्रित करें, और परिणाम को PNG फ़ाइलों के रूप में कैसे एक्सपोर्ट करें, यह जानते हैं। यह एंड‑टू‑एंड उदाहरण इंस्टॉलेशन, कॉन्फ़िगरेशन और एरर हैंडलिंग को कवर करता है, जिससे आप किसी भी बारकोड‑संबंधित फीचर के लिए ठोस आधार बना सकते हैं।

अगले चरण में आप देख सकते हैं:

* **C# बारकोड जनरेशन** अन्य सिम्बोलॉजी जैसे QR, Code 128, या PDF417 के लिए।
* **PDF दस्तावेज़ों में बारकोड एम्बेड करना** Aspose.PDF का उपयोग करके।
* **बैच प्रोसेसिंग** कई डेटा स्ट्रिंग्स को एक ही मल्टी‑पेज PDF में सहेजना।

विभिन्न `EncodeTypes`, इमेज फ़ॉर्मैट और रेज़ोल्यूशन सेटिंग्स के साथ प्रयोग करने में संकोच न करें ताकि आपके प्रोजेक्ट की सटीक आवश्यकताओं को पूरा किया जा सके। Happy coding!
