# C# में BarcodeGenerator API का उपयोग करके बारकोड इमेज कैसे सहेजें

यदि आपको .NET एप्लिकेशन से **बारकोड कैसे सहेजें** फ़ाइलें सहेजनी हैं, तो यह गाइड सटीक कदम दिखाता है। आप एक पूर्ण **बारकोड जेनरेटर उदाहरण** देखेंगे जो DataBar Stacked Omnidirectional बारकोड बनाता है, उसके aspect ratio को समायोजित करता है, और दो PNG फ़ाइलें सहेजता है।

बारकोड इमेज सहेजना इन्वेंट्री सिस्टम, पॉइंट‑ऑफ़‑सेल टर्मिनल, या ऑटोमेटेड लेबलिंग वर्कफ़्लो बनाते समय एक सामान्य आवश्यकता है। इस ट्यूटोरियल के अंत तक आप C# कोड जनरेट कर सकते हैं जो भरोसेमंद इमेज बनाता है, जिसे प्रिंट या डिस्प्ले के लिए तैयार किया जा सकता है।

## आवश्यकताएँ

- .NET 6.0 SDK या बाद का संस्करण स्थापित हो  
- Visual Studio 2022 (या कोई भी C#‑संगत IDE)  
- **Aspose.BarCode for .NET** NuGet पैकेज (कोड `Aspose.BarCode.Generation` का उपयोग करता है)  

आप पैकेज को निम्न कमांड से जोड़ सकते हैं:

```bash
dotnet add package Aspose.BarCode
```

## चरण 1: न्यूनतम C# कंसोल प्रोजेक्ट सेट अप करें

एक नया कंसोल प्रोजेक्ट बनाएं और लाइब्रेरी को रेफ़रेंस करें:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs` खोलें। फ़ाइल में `Main` मेथड होगा जहाँ हम **बारकोड जेनरेट C#** लॉजिक रखेंगे।

## चरण 2: DataBar Stacked Omnidirectional बारकोड के लिए BarcodeGenerator को इनिशियलाइज़ करें

किसी भी **डेटाबार बारकोड बनाएं** वर्कफ़्लो में पहला कार्य सही `EncodeType` के साथ `BarcodeGenerator` को इंस्टैंशिएट करना है। कंस्ट्रक्टर बारकोड सिम्बोलॉजी और डेटा स्ट्रिंग लेता है।

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

`EncodeTypes.DatabarStackedOmniDirectional` वैल्यू लाइब्रेरी को बताती है कि वह **डेटाबार बारकोड बनाएं** जो किसी भी दिशा से स्कैन किया जा सकता है।

## चरण 3: X‑डायमेंशन (मॉड्यूल चौड़ाई) कॉन्फ़िगर करें

X‑डायमेंशन पिक्सेल में सबसे छोटी बार की चौड़ाई को नियंत्रित करता है। इसे कम मान पर सेट करने से बारकोड कॉम्पैक्ट रहता है जबकि पठनीयता बनी रहती है।

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## चरण 4: **aspect ratio कैसे समायोजित करें** – पहला मान (15)

DataBar बारकोड `AspectRatio` प्रॉपर्टी प्रदान करता है जो ऊँचाई‑से‑चौड़ाई अनुपात को प्रभावित करता है। अधिक अनुपात से बारकोड ऊँचा बनता है, जिससे कुछ प्रिंटरों पर स्कैनिंग विश्वसनीयता बढ़ सकती है।

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## चरण 5: **बारकोड कैसे सहेजें** – पहली इमेज (aspect ratio 15)

अब हम वास्तव में **बारकोड कैसे सहेजें** फ़ाइल में। `Save` मेथड फ़ाइल पाथ और इमेज फ़ॉर्मेट लेता है। इस उदाहरण में हम PNG फ़ाइल सहेजते हैं।

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Tip:** एक्सीक्यूटेबल की डायरेक्टरी डिफ़ॉल्ट लिखने का स्थान है। यदि आपको विशिष्ट फ़ोल्डर चाहिए तो एब्सॉल्यूट पाथ उपयोग करें।

## चरण 6: **aspect ratio कैसे समायोजित करें** – दूसरा मान (30)

लचीलापन दिखाने के लिए, aspect ratio बदलें और दूसरी इमेज सहेजें। यह दर्शाता है कि समान एन्कोडेड डेटा को विभिन्न दृश्य अनुपातों के साथ कैसे रेंडर किया जा सकता है।

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

प्रोग्राम चलाने पर दो PNG फ़ाइलें बनती हैं:

- `DatabarAspectRatio15.png` – मध्यम ऊँचाई वाला बारकोड  
- `DatabarAspectRatio30.png` – चुनौतीपूर्ण स्कैन वातावरण के लिए अधिक ऊँचाई वाला बारकोड  

दोनों फ़ाइलें UI कंट्रोल में लोड करने, लेबल पर प्रिंट करने, या API के माध्यम से ट्रांसमिट करने के लिए तैयार हैं।

### अपेक्षित आउटपुट

जब आप जेनरेट की गई इमेज खोलेंगे, तो आपको DataBar Stacked Omnidirectional बारकोड दिखना चाहिए जो GTIN‑14 वैल्यू `12345678901231` को एन्कोड करता है। दो फ़ाइलों के बीच दृश्य अंतर केवल ऊँचाई का है, जो पुष्टि करता है कि **aspect ratio कैसे समायोजित करें** इच्छित रूप से काम करता है।

## चरण 7: संदर्भ के लिए पूर्ण स्रोत कोड

नीचे पूरा, चलाने योग्य प्रोग्राम दिया गया है। इसे `Program.cs` में कॉपी करें, बिल्ड करें और चलाएँ।

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## सामान्य प्रश्न और एज‑केस हैंडलिंग

### यदि लक्ष्य फ़ोल्डर मौजूद नहीं है तो क्या करें?

`Save` `DirectoryNotFoundException` फेंकता है। पहले डायरेक्टरी बनाएं:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### इमेज फ़ॉर्मेट कैसे बदलें?

`BarCodeImageFormat.Png` को `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp`, या `BarCodeImageFormat.Tiff` से बदलें, यह आपके डाउनस्ट्रीम आवश्यकताओं पर निर्भर करता है।

### क्या मैं लूप में कई बारकोड जेनरेट कर सकता हूँ?

हां। प्रत्येक डेटा स्ट्रिंग के लिए नया `BarcodeGenerator` इंस्टैंशिएट करें या `CodeText` प्रॉपर्टी अपडेट करने के बाद उसी इंस्टेंस को पुनः उपयोग करें:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### क्या **बारकोड कैसे सहेजें** non‑Windows प्लेटफ़ॉर्म पर काम करता है?

Aspose.BarCode क्रॉस‑प्लेटफ़ॉर्म है। वही कोड Linux और macOS पर चलता है, बशर्ते .NET रनटाइम मौजूद हो।

## निष्कर्ष

अब आप **बारकोड कैसे सहेजें** इमेज C# में एक पूर्ण **बारकोड जेनरेटर उदाहरण** का उपयोग करके बना सकते हैं। ट्यूटोरियल ने शामिल किया:

- **डेटाबार बारकोड बनाएं** जेनरेटर को इनिशियलाइज़ करना  
- स्पष्ट मॉड्यूल के लिए X‑डायमेंशन सेट करना  
- दृश्य ट्यूनिंग के लिए **aspect ratio कैसे समायोजित करें**  
- विभिन्न अनुपातों के साथ **बारकोड कैसे सहेजें** को दो बार निष्पादित करना  

अब आप अन्य सिम्बोलॉजी (`EncodeTypes.QR`, `EncodeTypes.Code128`), विभिन्न इमेज फ़ॉर्मेट, या जेनरेटेड PNG को PDF रिपोर्ट में एम्बेड करने के साथ प्रयोग कर सकते हैं। वही पैटर्न—कॉन्फ़िगर, समायोजित, और **बारकोड कैसे सहेजें**—Aspose.BarCode द्वारा समर्थित सभी बारकोड प्रकारों पर लागू होता है।

कोडिंग का आनंद लें, और अपनी एप्लिकेशन को तुरंत स्कैन करने योग्य बारकोड प्रदान करना शुरू करें!
