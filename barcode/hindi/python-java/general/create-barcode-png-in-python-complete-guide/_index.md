# Python में barcode PNG बनाएं – पूर्ण गाइड

क्या आपको कभी **barcode PNG बनाना** पड़ा है लेकिन आप नहीं जानते थे कि कौनसी लाइब्रेरी या सेटिंग्स उपयोग करें? आप अकेले नहीं हैं। कई इन्वेंटरी या चेकआउट सिस्टम में पहला कदम कच्चे डेटा को एक स्पष्ट PNG इमेज में बदलना होता है जिसे स्कैनर पसंद करते हैं।  

इस ट्यूटोरियल में हम **databar कैसे जेनरेट करें**, **barcode की ऊँचाई कैसे समायोजित करें**, और यहां तक कि **barcode** पैरामीटर को तुरंत बदलने की ट्रिक भी देखेंगे—सभी **barcode with sample data** का उपयोग करके जिसे आप सीधे अपने प्रोजेक्ट में कॉपी‑पेस्ट कर सकते हैं।  

## आप क्या सीखेंगे

- Python में Aspose.BarCode (या समान) लाइब्रेरी सेट अप करें।  
- विभिन्न ऊँचाइयों वाली **Create barcode PNG** फ़ाइलें कुछ ही कोड लाइनों में बनाएं।  
- **How to change barcode** गुण जैसे मॉड्यूल आकार और बार ऊँचाई।  
- **barcode with sample data** के रूप में एक वास्तविक GTIN‑14 मान का उपयोग करें।  
- ब्लरी इमेज या गलत एन्कोडिंग जैसी सामान्य समस्याओं को हल करने के लिए टिप्स।

barcode जेनरेशन में कोई पूर्व अनुभव आवश्यक नहीं है—सिर्फ एक बेसिक Python इंटरप्रेटर और pip पैकेज इंस्टॉल करने की क्षमता चाहिए।

## आवश्यकताएँ

- आपके मशीन पर Python 3.8+ स्थापित हो।  
- `aspose-barcode` पैकेज (या कोई संगत लाइब्रेरी) इंस्टॉल करने के लिए इंटरनेट एक्सेस।  
- एक लिखने योग्य फ़ोल्डर जहाँ PNG फ़ाइलें सेव होंगी (`YOUR_DIRECTORY` को स्क्रिप्ट में बदलें)।  

यदि आपके पास ये सब है, तो बढ़िया—आइए शुरू करें।

## barcode PNG बनाना – जेनरेटर सेट अप करना

सबसे पहले: हमें एक जेनरेटर ऑब्जेक्ट चाहिए जो समझे कि हम **DataBar Omnidirectional** barcode के साथ काम कर रहे हैं। नीचे दिया गया कोड आवश्यक क्लासेज़ इम्पोर्ट करता है, **barcode with sample data** के साथ जेनरेटर बनाता है, और एक उचित मॉड्यूल आकार सेट करता है।

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**यह क्यों महत्वपूर्ण है:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` इंजन को बताता है कि वह एक **DataBar** बनाए जो किसी भी दिशा से पढ़ा जा सके, रिटेल शेल्फ़ के लिए परफेक्ट। `x_dimension` सेट करने से बार तेज़ रहते हैं, जबकि `bar_height` कोड के दृश्य आकार को नियंत्रित करता है।

## Sample Data के साथ Databar कैसे जेनरेट करें

अब जेनरेटर तैयार है, हम **create barcode PNG** फ़ाइलें बनाएंगे। पहला सेव 30‑पिक्सेल ऊँचाई का उपयोग करता है, जो अक्सर ऑन‑स्क्रीन प्रीव्यू के लिए पर्याप्त होता है।

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

इस बिंदु तक स्क्रिप्ट चलाने से एक PNG फ़ाइल बनेगी जो एक कॉम्पैक्ट, हाई‑कॉन्ट्रास्ट barcode जैसी दिखेगी। इसे किसी भी इमेज व्यूअर में खोलें ताकि यह पुष्टि हो सके कि बार तेज़ हैं और GTIN‑14 डेटा एन्कोडेड है।

## Barcode की ऊँचाई समायोजित करें (How to Change Barcode)

कभी‑कभी बड़े लेबल या हाई‑रिज़ॉल्यूशन प्रिंटिंग के लिए आपको लंबा barcode चाहिए होता है। यही वह जगह है जहाँ **adjust barcode height** काम आता है। ऊँचाई बदलना इतना सरल है जितना `BarHeight` प्रॉपर्टी को अपडेट करना और फिर से सेव करना।

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**यह कैसे काम करता है:** जेनरेटर वही डेटा और मॉड्यूल आकार फिर से उपयोग करता है; केवल वर्टिकल डाइमेंशन बदलता है। इससे पूरे ऑब्जेक्ट को फिर से बनाने से बचा जा सकता है और यह **how to change barcode** सेटिंग्स को डायनामिक रूप से दिखाता है।

## पूर्ण स्क्रिप्ट – वन‑स्टॉप सॉल्यूशन

नीचे पूरी, चलाने योग्य स्क्रिप्ट है जो सभी चरणों को जोड़ती है। कॉपी, पेस्ट और चलाएँ—पैकेज इंस्टॉल करने के बाद यह तुरंत काम करेगा।

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### अपेक्षित आउटपुट

स्क्रिप्ट चलाने से दो फ़ाइलें बनेंगी:

- `DatabarOmni30.png` – 30 px ऊँचा DataBar Omnidirectional barcode।  
- `DatabarOmni60.png` – उसी barcode का 60 px ऊँचा संस्करण।

दोनों इमेज PNG फ़ॉर्मेट में हैं, लॉसलेस, और PDFs, HTML पेजेज़ में एम्बेड करने या सीधे लेबल पर प्रिंट करने के लिए तैयार हैं।

## सामान्य समस्याएँ एवं प्रो टिप्स

- **पिक्सेल बनाम DPI:** PNG फ़ाइलें पिक्सेल‑आधारित होती हैं। यदि आपको विशिष्ट प्रिंट साइज चाहिए, तो DPI के आधार पर `BarHeight` गणना करें (उदा., 300 dpi → 30 px ≈ 0.1 in)।  
- **गलत एन्कोडिंग:** सुनिश्चित करें कि डेटा स्ट्रिंग GS1 एप्लिकेशन आइडेंटिफ़ायर फ़ॉर्मेट (`(01)` GTIN‑14 के लिए) का पालन करे। कोष्ठक न होने से लाइब्रेरी साधारण न्यूमेरिक barcode पर फ़ॉल्बैक कर सकती है।  
- **फ़ाइल पाथ:** Windows पर एस्केप‑कैरेक्टर समस्याओं से बचने के लिए रॉ स्ट्रिंग (`r"..."`) या डबल बैकस्लैश का उपयोग करें।  
- **परफ़ॉर्मेंस:** यदि आप हजारों barcode जेनरेट कर रहे हैं, तो जेनरेटर को एक बार इंस्टैंशिएट करें और केवल `BarHeight` या डेटा स्ट्रिंग को सेव्स के बीच बदलें। इससे मेमोरी चर्न कम होगा।  

## अगले कदम

अब जब आप जानते हैं कि **create barcode PNG** कैसे करें, तो आप निम्नलिखित का अन्वेषण कर सकते हैं:

- **How to change barcode** रंग या क्वाइट ज़ोन जोड़ना (`generator.parameters.barcode.quiet_zone`)।

- स्क्रिप्ट को Flask या Django एंडपॉइंट में इंटीग्रेट करना ताकि आवश्यकता अनुसार barcode सर्व किया जा सके।  

इनमें से प्रत्येक विषय उस नींव पर आधारित है जो हमने कवर की है, इसलिए प्रयोग करने में संकोच न करें और कोड को अपने प्रोजेक्ट की जरूरतों के अनुसार विकसित होते देखें।
