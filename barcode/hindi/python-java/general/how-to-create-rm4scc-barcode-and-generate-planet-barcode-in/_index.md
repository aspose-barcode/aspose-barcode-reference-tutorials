# C# में RM4SCC बारकोड कैसे बनाएं और प्लैनेट बारकोड जनरेट करें

यदि आपको पोस्टल एप्लिकेशन के लिए **RM4SCC बारकोड बनाना** है, तो यह गाइड आपको सटीक चरण दिखाता है। आप यह भी सीखेंगे कि कैसे **प्लैनेट बारकोड** को स्वचालित और निश्चित ऊँचाई दोनों के साथ जनरेट किया जाए, ताकि एक ही कोड किसी भी पोस्टल सिम्बोलॉजी के लिए काम करे।

यह ट्यूटोरियल उन सभी चीज़ों को कवर करता है जो पोस्टल मानकों के अनुरूप PNG इमेज बनाने के लिए आवश्यक हैं। Aspose.BarCode for .NET लाइब्रेरी के अलावा कोई बाहरी टूल आवश्यक नहीं है। अंत तक, आप प्रोग्रामेटिक रूप से बारकोड जनरेट कर सकते हैं और उनके आयामों को सटीक रूप से नियंत्रित कर सकते हैं।

## आवश्यकताएँ

* .NET 6.0 या बाद का संस्करण स्थापित हो
* Visual Studio 2022 (या कोई भी C# IDE)
* Aspose.BarCode for .NET NuGet पैकेज  
  `Install-Package Aspose.BarCode`
* आउटपुट डायरेक्टरी में लिखने की अनुमति

ये आइटम आपको अतिरिक्त कॉन्फ़िगरेशन के बिना सैंपल कोड को कंपाइल और रन करने में सक्षम बनाते हैं।

## चरण 1: RM4SCC के लिए बारकोड जेनरेटर को इनिशियलाइज़ करें

पहला ऑपरेशन एक `BarcodeGenerator` इंस्टेंस बनाता है जो RM4SCC सिम्बोलॉजी के लिए कॉन्फ़िगर किया गया है। यह ऑब्जेक्ट बारकोड इमेज की सभी सेटिंग्स रखता है।

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**यह क्यों महत्वपूर्ण है** – `EncodeTypes.RM4SCC` Aspose को पोस्टल RM4SCC फॉर्मेट उपयोग करने के लिए बताता है, जबकि डेटा स्ट्रिंग `"123456"` वह पोस्टल कोड दर्शाती है जिसे आप एन्कोड करना चाहते हैं।

## चरण 2: मॉड्यूल चौड़ाई (X‑डायमेंशन) सेट करें

मॉड्यूल चौड़ाई पतली बार के आकार को नियंत्रित करती है। पोस्टल बारकोड के लिए सामान्य मान 4 पिक्सेल है।

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**व्याख्या** – X‑डायमेंशन कुल बारकोड पठनीयता को प्रभावित करता है। 4 px चुनने से अधिकांश पोस्टल स्कैनर के साथ मेल खाता है।

## चरण 3: स्वचालित बार ऊँचाई के साथ सहेजें

जब आप ऊँचाई मान को छोड़ देते हैं, तो Aspose सिम्बोलॉजी नियमों के आधार पर स्वचालित रूप से इष्टतम ऊँचाई की गणना करता है।

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**परिणाम** – जनरेट किया गया PNG (`PostalRM4SCCBarHeightNone.png`) में सही आकार का RM4SCC बारकोड होता है, जो प्रिंटिंग के लिए तैयार है।

## चरण 4: स्वचालित ऊँचाई के साथ प्लैनेट बारकोड बनाएं

इसी पैटर्न को प्लैनेट सिम्बोलॉजी के लिए भी उपयोग किया जा सकता है। `EncodeTypes.Planet` के साथ जेनरेटर को इनिशियलाइज़ करके शुरू करें।

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**कोड को पुन: उपयोग करने का कारण** – RM4SCC और प्लैनेट दोनों समान पैरामीटर संरचना साझा करते हैं, इसलिए आप केवल `EncodeTypes` मान बदलकर सिम्बोलॉजी बदल सकते हैं।

## चरण 5: RM4SCC के लिए निश्चित बार ऊँचाई निर्धारित करें

कुछ पोस्टल सेवाओं को विशिष्ट बार ऊँचाई (जैसे, 100 px) की आवश्यकता होती है। आप इसे सहेजने से पहले स्पष्ट रूप से सेट कर सकते हैं।

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**टिप** – `BarHeight.Pixels` सेट करने से स्वचालित गणना ओवरराइड हो जाती है, जिससे आपको विज़ुअल साइज पर पूर्ण नियंत्रण मिलता है।

## चरण 6: प्लैनेट के लिए निश्चित बार ऊँचाई निर्धारित करें

इसी निश्चित‑ऊँचाई तकनीक को प्लैनेट बारकोड पर लागू करें।

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**परिणाम** – दोनों `PostalRM4SCCBarHeight100Pixels.png` और `PostalPlanetBarHeight100Pixels.png` में 100 px की समान बार ऊँचाई वाला बारकोड होता है, जो कड़े पोस्टल स्पेसिफिकेशन को पूरा करता है।

## पूरा स्रोत कोड

नीचे पूर्ण, चलाने योग्य प्रोग्राम दिया गया है जो सभी चार उदाहरणों को सम्मिलित करता है। इसे एक नए कंसोल प्रोजेक्ट में कॉपी करें और आवश्यकतानुसार आउटपुट पाथ समायोजित करें।

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**अपेक्षित आउटपुट** – प्रोग्राम चलाने के बाद, निर्दिष्ट डायरेक्टरी में चार PNG फ़ाइलें होंगी:

* `PostalRM4SCCBarHeightNone.png` – स्वचालित ऊँचाई वाला RM4SCC
* `PostalPlanetBarHeightNone.png` – स्वचालित ऊँचाई वाला Planet
* `PostalRM4SCCBarHeight100Pixels.png` – 100 px ऊँचाई वाला RM4SCC
* `PostalPlanetBarHeight100Pixels.png` – 100 px ऊँचाई वाला Planet

किसी भी फ़ाइल को खोलें ताकि यह सत्यापित हो सके कि बार स्पष्ट हैं, मॉड्यूल चौड़ाई 4 px है, और ऊँचाई चुनी गई सेटिंग के अनुरूप है।

## आम प्रश्न और किनारे के मामलों

| प्रश्न | उत्तर |
|----------|--------|
| **क्या मैं अन्य इमेज फॉर्मेट उपयोग कर सकता हूँ?** | हाँ। आवश्यकता अनुसार `BarCodeImageFormat.Png` को `Jpeg`, `Bmp`, या `Gif` से बदलें। |
| **यदि डेटा स्ट्रिंग लंबी हो तो क्या होगा?** | जेनरेटर स्वचालित रूप से बार की संख्या को समायोजित करता है। सुनिश्चित करें कि डेटा सिम्बोलॉजी की लंबाई सीमाओं (RM4SCC ≤ 6 अंकों, Planet ≤ 6 अंकों) के अनुरूप हो। |
| **बार का रंग कैसे बदलूँ?** | `Save` कॉल करने से पहले `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` सेट करें। |
| **क्या प्रिंटिंग के लिए DPI महत्वपूर्ण है?** | आप `rm4sccAuto.Parameters.ImageResolution.DpiX` और `DpiY` को अपने प्रिंटर की रिज़ॉल्यूशन के अनुसार सेट कर सकते हैं। |

* उसी पैटर्न का उपयोग करके **POSTNET** या **Intelligent Mail** जैसे अन्य पोस्टल सिम्बोलॉजी के साथ प्रयोग करें।

इस गाइड का पालन करके, अब आप जानते हैं कि कैसे **RM4SCC बारकोड बनाएं** और **प्लैनेट बारकोड जनरेट करें** बार ऊँचाई पर पूर्ण नियंत्रण के साथ। कोड को बैच प्रोसेसिंग के लिए अनुकूलित करने या इसे बड़े मेलिंग सिस्टम में एकीकृत करने में संकोच न करें। कोडिंग का आनंद लें!
