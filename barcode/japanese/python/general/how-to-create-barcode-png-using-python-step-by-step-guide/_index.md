# PythonでバーコードPNGを作成する方法 – ステップバイステップガイド

任意の文字列から **バーコードPNG** ファイルを作成したい場合、このチュートリアルはすぐに実行できるソリューションを提供します。Code 128 バーコードの生成方法、テキストをバーコード画像に変換する手順、そして PNG ファイルとして保存する方法を、数行の Python コードで確認できます。

本ガイドでは、必要なライブラリのインストールから、さまざまなユースケース向けの出力カスタマイズまで、知っておくべきことをすべて網羅しています。最後まで読めば、追加のドキュメントを探すことなく、任意の Python プロジェクトにバーコード生成機能を組み込めるようになります。

## 学べること

* **barcode generator python** パッケージ（Code 128 対応）をインストールする
* `BarCodeGenerator` を使用してテキスト文字列から **code 128 barcode** を生成する
* `save` で高品質な PNG として保存する
* 画像サイズ、前景・背景色を調整し、一般的なエラーに対処する
* PNG が正しく作成されたことを検証する

### 前提条件

| 要件 | 理由 |
|------|------|
| Python 3.8+ | 最新の構文と型ヒントを利用できる |
| インターネット接続（`pip install` 用） | ライブラリをダウンロードするため |
| フォルダーへの書き込み権限 | 生成した PNG を保存するため |

外部サービスは不要です。すべてローカルで実行できます。

## 手順 1: バーコードライブラリをインストール

Python で **テキストをバーコードに変換** する最も簡単な方法は、**Aspose.BarCode for Python via .NET** パッケージを使用することです。このパッケージは Code 128 を標準でサポートしています。

```bash
pip install aspose-barcode
```

> **プロのコツ:** 仮想環境を使用している場合は、コマンド実行前に環境をアクティベートして依存関係を分離しましょう。

## 手順 2: 必要なクラスをインポート

インストールが完了したら、コアクラスをインポートします。インポート文は短く、コードの可読性が高まります。

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` はバーコード画像を生成します。  
* `EncodeTypes` は `CODE_128` を含むサポート対象シンボロジーの列挙体を提供します。

## 手順 3: エンコードしたいテキストを定義

任意の英数字文字列を選びます。Code 128 は ASCII 全体を表現できるため、数字に限定されません。

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

入力にサポート外の文字が含まれると、ジェネレータは `ValueError` をスローします。ユーザー入力を受け取る場合は、`try` ブロックでラップしてください。

## 手順 4: Code 128 用のバーコードジェネレータを作成

`BarCodeGenerator` を目的のシンボロジーと先ほど定義したテキストでインスタンス化します。これが **Python でバーコード画像を生成する方法** の核心です。

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

なぜ Code 128 かというと、高密度で ASCII 全域をエンコードでき、在庫管理システム、出荷ラベル、チケットなどに最適だからです。

## 手順 5: (任意) 外観をカスタマイズ

保存前にバーコードの外観を微調整できます。以下のオプションは一般的に使用されます。

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

これらの設定は、エンコードされたデータを変更せずに **create barcode png** の最終出力に影響を与えます。

## 手順 6: バーコードを PNG ファイルとして保存

最後に画像をディスクに書き出します。`save` メソッドは拡張子を自動判別するため、`.png` を指定すれば PNG 画像が生成されます。

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

対象ディレクトリが存在しない場合、Python は `FileNotFoundError` をスローします。事前にディレクトリを作成するか、`os.makedirs` に `exist_ok=True` を指定して作成してください。

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### 期待される出力

スクリプト実行後、`output` フォルダーに `extended_barcode.png` が生成されます。ファイルを開くと、`1234567890` をエンコードした鮮明な Code 128 バーコードが表示されます。

![Generated barcode PNG created with Python](generated_barcode.png "create barcode png example")

## 手順 7: バーコードを検証（簡易チェック）

同じライブラリで PNG を再度読み込み、エンコードされた値が元のテキストと一致するか確認できます。

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

このブロックを実行すると次が出力されます:

```
Verification succeeded: 1234567890
```

アサーションが失敗した場合は、`barcode_text` とカスタムパラメータを再確認してください。

## よくあるバリエーションとエッジケース

| 状況 | 調整方法 |
|------|----------|
| **テキストが長い（20文字超）** | 切り捨てを防ぐため `image_width` を増やす |
| **背景を透過させたい** | 保存前に `back_color = "Transparent"` を設定 |
| **ループで複数のバーコードを生成** | 手順 3‑6 を `for` ループで囲み、各イテレーションで `barcode_text` を変更 |
| **PNG ではなく JPEG で保存** | 拡張子を `.jpg` に変更すれば、ライブラリが自動でフォーマットを処理 |
| **ヘッドレスサーバーで実行** | GUI が不要なため、CI パイプラインでも安全に使用可能 |

## すぐにコピーできるフルスクリプト

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

スクリプトを `generate_barcode.py` として保存し、実行します:

```bash
python generate_barcode.py
```

実行すると確認メッセージが表示され、`output` フォルダーに新しい PNG ファイルが作成されます。
