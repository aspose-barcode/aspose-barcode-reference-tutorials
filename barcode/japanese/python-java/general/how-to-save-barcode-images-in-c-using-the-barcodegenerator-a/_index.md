# C# で BarcodeGenerator API を使用してバーコード画像を保存する方法

.NET アプリケーションから **how to save barcode** ファイルを保存する必要がある場合、本ガイドでは正確な手順を示します。DataBar Stacked Omnidirectional バーコードを生成し、アスペクト比を調整し、2 つの PNG ファイルとして保存する完全な **barcode generator example** を確認できます。

バーコード画像の保存は、在庫管理システム、POS 端末、または自動ラベリングワークフローを構築する際の一般的な要件です。このチュートリアルを終える頃には、印刷や表示にすぐ使える信頼性の高い画像を生成する C# コードを作成できるようになります。

## Prerequisites

開始する前に、以下がインストールされていることを確認してください。

- .NET 6.0 SDK 以降  
- Visual Studio 2022（または C# 対応の任意の IDE）  
- **Aspose.BarCode for .NET** NuGet パッケージ（コードは `Aspose.BarCode.Generation` を使用）

以下のコマンドでパッケージを追加できます：

```bash
dotnet add package Aspose.BarCode
```

## Step 1: Set up a minimal C# console project

新しいコンソールプロジェクトを作成し、ライブラリへの参照を追加します：

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs` を開きます。このファイルに **generate barcode C#** ロジックを記述する `Main` メソッドが含まれます。

## Step 2: Initialize the BarcodeGenerator for a DataBar Stacked Omnidirectional barcode

任意の **create databar barcode** ワークフローの最初のステップは、正しい `EncodeType` で `BarcodeGenerator` をインスタンス化することです。コンストラクタにはバーコードシンボロジーとデータ文字列を渡します。

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

`EncodeTypes.DatabarStackedOmniDirectional` の値は、任意の方向からスキャン可能な **create databar barcode** を生成するようライブラリに指示します。

## Step 3: Configure the X‑dimension (module width)

X‑dimension はピクセル単位の最小バー幅を制御します。低い値に設定すると、可読性を保ちつつバーコードをコンパクトに保てます。

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Step 4: **How to adjust aspect ratio** – first value (15)

DataBar バーコードは `AspectRatio` プロパティを公開しており、縦横比に影響します。比率を高くするとバーコードが高くなり、特定のプリンターでのスキャン信頼性が向上することがあります。

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Step 5: **How to save barcode** – first image (aspect ratio 15)

いよいよ **how to save barcode** をファイルに保存します。`Save` メソッドはファイルパスと画像フォーマットを受け取ります。この例では PNG ファイルとして保存します。

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Tip:** 実行ファイルのディレクトリがデフォルトの書き込み先です。特定のフォルダーに保存したい場合は絶対パスを使用してください。

## Step 6: **How to adjust aspect ratio** – second value (30)

柔軟性を示すために、アスペクト比を変更して 2 枚目の画像を保存します。これにより、同じエンコードデータが異なる視覚的比率で描画できることが分かります。

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

プログラムを実行すると、次の 2 つの PNG ファイルが生成されます。

- `DatabarAspectRatio15.png` – 高さが程よいバーコード  
- `DatabarAspectRatio30.png` – 高さが大きく、スキャンが難しい環境向け  

どちらのファイルも UI コントロールにロードしたり、ラベルに印刷したり、API 経由で送信したりできます。

### Expected output

生成された画像を開くと、GTIN‑14 値 `12345678901231` をエンコードした DataBar Stacked Omnidirectional バーコードが表示されます。2 ファイルの違いは高さだけで、**how to adjust aspect ratio** が意図通りに機能していることが確認できます。

## Step 7: Full source code for reference

以下に完全な実行可能プログラムを示します。`Program.cs` に貼り付けてビルド・実行してください。

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Common questions and edge‑case handling

### What if the target folder does not exist?

`Save` は `DirectoryNotFoundException` をスローします。事前にディレクトリを作成してください：

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### How to change image format?

`BarCodeImageFormat.Png` を `BarCodeImageFormat.Jpeg`、`BarCodeImageFormat.Bmp`、または `BarCodeImageFormat.Tiff` に置き換えて、下流の要件に合わせた形式に変更できます。

### Can I generate multiple barcodes in a loop?

可能です。各データ文字列ごとに新しい `BarcodeGenerator` をインスタンス化するか、`CodeText` プロパティを更新して同じインスタンスを再利用してください：

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### Does **how to save barcode** work on non‑Windows platforms?

Aspose.BarCode はクロスプラットフォームです。.NET ランタイムがあれば、Linux や macOS 上でも同じコードが動作します。
