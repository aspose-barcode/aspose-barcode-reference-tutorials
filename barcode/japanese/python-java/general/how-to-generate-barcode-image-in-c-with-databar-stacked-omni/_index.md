# C# で DataBar Stacked Omni‑Directional バーコード画像を生成する方法

.NET アプリケーションで **バーコード画像の生成方法** が必要な場合、本チュートリアルでは正確な手順を示します。DataBar Stacked Omni‑Directional バーコードの作成方法、アスペクト比の調整方法、そして結果を PNG ファイルとしてエクスポートする方法が分かります。

バーコードの生成は在庫システム、小売の POS 端末、物流トラッキングなどで一般的な要件です。以下のセクションでは、必要な NuGet パッケージの導入から最終的な画像検証まで、必要なすべてをカバーしますので、今日から任意の C# プロジェクトにバーコード作成機能を統合できます。

## 前提条件

* .NET 6.0 以降（コードは .NET Core と .NET Framework でも動作します）
* Visual Studio 2022 またはお好みの C# IDE
* **Aspose.BarCode for .NET** NuGet パッケージ（`dotnet add package Aspose.BarCode` でインストール）
* PNG ファイルを保存するフォルダーへの書き込み権限

これらの前提条件により、サンプルが追加設定なしで実行できることが保証されます。

## 手順 1: 出力フォルダーの設定

最初に必要なのは、生成された PNG ファイルを書き込むディレクトリです。絶対パスでも相対パスでも構いませんが、`Save` を呼び出す前にフォルダーが存在することを確認してください。

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

フォルダーをプログラムで作成することで、`Save` メソッドが画像を書き込もうとした際の *FileNotFoundException* を防止できます。

## 手順 2: DataBar Stacked Omni‑Directional バーコードジェネレーターの作成

**BarcodeGenerator** クラスはすべてのバーコードタイプのエントリーポイントです。ここでは `EncodeTypes.DatabarStackedOmniDirectional` とエンコードしたいデータ文字列を指定します。

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*重要な理由*: `EncodeTypes` 列挙体はライブラリにどのシンボロジーを描画するかを指示します。Omni‑Directional バリアントを使用することで、バーコードは任意の向きからスキャン可能となり、多くの倉庫スキャナーの要件を満たします。

## 手順 3: 共通バーコードパラメーターの設定

読み取り可能なバーコードには適切な X‑dimension（最小バーの幅）が必要です。`Pixels` を 2 に設定すると、ほとんどの画面解像度でサイズと鮮明さのバランスが取れます。

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

画像を大きくしたり小さくしたりしたい場合は、後から `Pixels` を調整できます。ライブラリは自動的にバーコード全体をスケーリングします。

## 手順 4: アスペクト比 15 で最初の画像を生成

**アスペクト比** は DataBar バーコードの高さと幅の関係を制御します。アスペクト比 15 は小売ラベルの典型的なデフォルトです。

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

この呼び出しの後、出力フォルダーに `DatabarAspectRatio15.png` が作成されます。この画像はロスレス PNG で、さらなる処理や印刷に適しています。

## 手順 5: アスペクト比を 30 に変更し、2 番目の画像をエクスポート

ラベルの高さが制限されている場合など、より高いバーコードが必要になることがあります。アスペクト比を 30 に変更すると、データの完全性を保ちつつ、よりコンパクトな表示が得られます。

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

これで、同じデータが異なるアスペクト比でどのように見えるかを示す 2 つの PNG ファイルが得られます。この並列比較により、どのバリエーションがラベルレイアウトに最適か判断できます。

## 完全な実行可能サンプル

以下に、コピーして貼り付け、実行できる完全なプログラムを示します。すべての `using` ディレクティブ、エラーハンドリング、プロセスの各部分を説明するコメントが含まれています。

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**期待される出力**（コンソール）:

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

任意の画像ビューアで 2 つの PNG ファイルを開いてください。同じ GTIN がエンコードされていますが、2 番目の画像はアスペクト比が高いため、より縦長になっています。

## プロのコツと一般的な落とし穴

| Situation | Recommendation |
|-----------|----------------|
| **低解像度ディスプレイ** | `XDimension.Pixels` を 3 または 4 に増やしてバーを鮮明に保ちます。 |
| **熱紙への印刷** | 高忠実度のために `BarCodeImageFormat.Tiff` を使用し、`Resolution.DpiX/DpiY` を 300 に設定します。 |
| **動的データ** | 同じ `BarcodeGenerator` インスタンスを再利用し、各 `Save` の前に `generator.CodeText` のみを更新します。これにより不要なオブジェクト割り当てを回避できます。 |
| **無効な GTIN** | データが GS1 標準に準拠していない場合、ライブラリは `ArgumentException` をスローします。ジェネレーターに渡す前にデータを検証してください。 |
