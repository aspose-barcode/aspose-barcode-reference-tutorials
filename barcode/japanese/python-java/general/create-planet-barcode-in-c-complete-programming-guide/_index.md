# C# で Planet バーコードを作成する – 完全プログラミングガイド

C# で **Planet バーコードを作成** したい場合は、このガイドが手順をすべて示します。また、**バーコードのサイズを設定** する方法も解説し、必要な幅でバーが描画されるようにします。

Planet バーコードの生成は、郵便サービスや物流システムで一般的です。以下のコードは、デフォルトの塗りつぶしバー バージョンと、オプションの空バー スタイル、さらに RM4SCC 形式の簡単な例を網羅しています。このチュートリアルの最後までに、任意の .NET プロジェクトに組み込める再利用可能なスニペットが手に入ります。

## 前提条件

開始する前に、以下を確認してください。

* .NET 6.0 以降がインストール済み（API は .NET Framework 4.6+ でも動作します）
* プロジェクトに **Aspose.BarCode for .NET** NuGet パッケージ（`Aspose.BarCode`）が追加されていること
* PNG ファイルを保存する書き込み可能なフォルダー パス
* C# の基本構文と Visual Studio（または任意の IDE）に慣れていること

> **プロのコツ:** 画像保存時の権限問題を回避するため、絶対パスまたは `Path.Combine(Environment.CurrentDirectory, "output")` を使用してください。

## 手順 1 – Planet バーコードジェネレータを初期化（塗りつぶしバー）

最初のステップは、Planet シンボル用の `BarcodeGenerator` インスタンスを作成することです。デフォルトではジェネレータは **塗りつぶし** バーを生成します。

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

`EncodeTypes.Planet` 列挙体は Aspose.BarCode に Planet 形式を使用するよう指示し、`"123456"` がエンコードされるデータ ペイロードです。

## 手順 2 – 一貫したサイズ設定のためにバーコード寸法を設定する方法

各バーの幅を制御するには **X‑dimension** を調整します。これが **バーコード寸法を設定** する主な方法で、ラベルサイズに合わせてバーコードを収めることができます。

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

`Pixels` プロパティは画面ピクセル単位でバー幅を定義します。標準的な郵便ラベルでは 2 〜 5 ピクセルが一般的です。大きな印刷物が必要な場合はこの値を上げてください。

## 手順 3 – 塗りつぶし Planet バーコードを PNG として保存

画像をディスクに書き込みます。PNG はエッジが鮮明に保たれるため、スキャンに最適です。

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

`YOUR_DIRECTORY` を事前に用意したパスに置き換えてください。このコードを実行すると、以下の画像に似たファイルが生成されます。

## 手順 4 – 空（未塗りつぶし）バーの Planet バーコードを作成

郵便サービスがバーを **空** にすることを要求する場合は、ジェネレータ初期化後に `FilledBars` フラグを切り替えます。

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

コンストラクタは同一です。違いは次の設定ステップにあります。

## 手順 5 – バーコード寸法を設定し、バーを空にする方法

再び X‑dimension を設定して視覚的な一貫性を保ち、次に塗りつぶしバーを無効にします。

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

`FilledBars = false` プロパティが実際に描画スタイルを変更します。同じ X‑dimension を保つことで、空バーのバーコードが塗りつぶしバーと完全に揃います。

## 手順 6 – 空の Planet バーコードを保存

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

これで、塗りつぶしバーと空バーの 2 つの PNG ファイルが作成され、どちらも同じ寸法を共有します。

## 手順 7 – （オプション）比較用に RM4SCC バーコードを生成

RM4SCC は同じデフォルトの塗りつぶしバー スタイルを使用する別の郵便シンボルです。手順は Planet の例と同様で、**バーコード寸法を設定** する方法がフォーマットを超えて機能することを示します。

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

この 3 つのステップを実行すると `PostalRM4SCCFilledBars.png` が生成され、Planet の出力と並べて比較できます。

## X‑dimension が重要な理由

X‑dimension は各バーの **最小印刷幅** を決定します。設定が低すぎると低解像度プリンタでバーコードがぼやけ、スキャン失敗の原因になります。逆に大きすぎるとラベルサイズを超えてスペースが無駄になります。**バーコード寸法を設定** することで、最終画像サイズを決定的にコントロールでき、郵便自動化ワークフローに不可欠です。

## よくある落とし穴と回避策

| 問題 | 原因 | 対策 |
|------|------|------|
| バーコードが伸びて見える | X‑dimension をポイント単位で設定している | ピクセル単位の `Pixels` プロパティを常に使用してピクセルパーフェクトに制御 |
| 空バーがまだ塗りつぶされて見える | X‑dimension 変更後に `FilledBars` を `false` に設定していない | X‑dimension 調整 **後** に `FilledBars = false` を設定 |
| 保存されたファイルが空白 | 出力ディレクトリが存在しない、または書き込み権限がない | `Directory.CreateDirectory` でディレクトリを作成し、アプリが十分な権限で実行されていることを確認 |
| 印刷時に画像がぼやける | 高解像度モニタから低 DPI の PNG が保存されている | ロスレスの `BarCodeImageFormat.Png` を使用し、必要に応じて `Resolution` プロパティも設定 |

## 完全な実行可能サンプル

以下のブロック全体を新しいコンソール プロジェクト（`dotnet new console`）に貼り付けて実行してください。プログラムは `output` フォルダーに 3 つの PNG ファイルを作成します。

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**期待される出力:** 3 つの PNG ファイル – `PostalPlanetFilledBars.png`、`PostalPlanetEmptyBars.png`、`PostalRM4SCCFilledBars.png` – それぞれバー幅 4 ピクセルで、印刷やさらに処理する準備が整っています。

## 結論

これで C# で **Planet バーコードを作成** し、塗りつぶしバーと空バーの両方で **バーコード寸法を正確に設定** する方法が分かりました。同じパターンは RM4SCC など他のシンボルにも適用でき、あらゆる郵便バーコード要件に柔軟に対応できる基盤が手に入ります。

次に試すこと:

* バーコード下に人が読めるテキストを追加（`BarcodeGenerator.Parameters.Barcode.CodeText`）
* `Parameters.Barcode.BarColor` でバーの色を変更
* ベクタ形式（SVG、EPS）でバーコードを生成し、拡大縮小印刷に対応

さまざまな X‑dimension の値、データ文字列、出力形式を試して、特定のワークフローに最適化してください。コーディングを楽しんでください！
