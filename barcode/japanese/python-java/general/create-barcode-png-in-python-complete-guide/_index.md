# PythonでバーコードPNGを作成 – 完全ガイド

生データをスキャナーが好む鮮明なPNG画像に変換する方法が分からず、**バーコードPNGを作成**したいと思ったことはありませんか？ あなたは一人ではありません。多くの在庫管理やレジシステムでは、最初のステップは生データをスキャナーが好む鮮明なPNG画像に変換することです。  

このチュートリアルでは、**databarの生成方法**、**バーコード高さの調整方法**、そして**バーコードを変更**するテクニックまでを順に解説します。すべて **サンプルデータ付きバーコード** を使用しているので、コードをそのままコピー＆ペーストしてプロジェクトに組み込めます。  

## 学べること

- Pythonで Aspose.BarCode（または類似）ライブラリをセットアップする方法。  
- **バーコードPNG** を異なる高さで数行のコードだけで作成する方法。  
- **バーコードを変更** する際のモジュールサイズやバー高さなどのプロパティ設定方法。  
- 実際的な GTIN‑14 値を **サンプルデータ付きバーコード** として使用する方法。  
- ぼやけた画像やエンコードエラーなど、一般的な落とし穴のトラブルシューティングのコツ。

バーコード生成の経験は不要です。基本的な Python インタプリタと pip パッケージをインストールできる環境があれば始められます。

## 前提条件

- Python 3.8+ がインストールされていること。  
- `aspose-barcode` パッケージ（または互換ライブラリ）をインストールできるインターネット接続があること。  
- PNG ファイルを保存できる書き込み可能なフォルダーがあること（スクリプト内の `YOUR_DIRECTORY` を置き換えてください）。  

これらがすでに整っているなら、さっそく始めましょう。

## バーコードPNGの作成 – ジェネレータの設定

まず最初に、**DataBar Omnidirectional** バーコードを扱うことを認識したジェネレータオブジェクトが必要です。以下のコードは必要なクラスをインポートし、**サンプルデータ付きバーコード** でジェネレータを作成し、適度なモジュールサイズを設定します。

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Why this matters:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` はエンジンに任意の方向から読み取れる **DataBar** を生成させます。小売棚に最適です。`x_dimension` を設定するとバーがシャープに保たれ、`bar_height` がコードの視覚的サイズを制御します。

## サンプルデータでDatabarを生成する方法

ジェネレータの準備ができたので、**バーコードPNG** ファイルを作成します。最初の保存は 30 ピクセルの高さで、画面プレビューには十分です。

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

この時点までスクリプトを実行すると、コンパクトで高コントラストなバーコードの PNG が生成されます。任意の画像ビューアで開き、バーが鮮明で GTIN‑14 データが正しくエンコードされていることを確認してください。

## バーコードの高さを調整する（バーコードを変更する方法）

ラベルが大きい場合や高解像度印刷が必要な場合は、バーコードを高くする必要があります。ここで **バーコード高さの調整** が登場します。高さを変更するのは `BarHeight` プロパティを更新して再保存するだけです。

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**How it works:** ジェネレータは同じデータとモジュールサイズを再利用し、垂直方向の寸法だけが変わります。オブジェクト全体を再作成する必要がなく、**バーコードを変更** する設定を動的に行えることを示しています。

## 完全スクリプト – ワンストップソリューション

以下はすべての手順を組み合わせた、実行可能な完全スクリプトです。コピーして貼り付け、実行すればパッケージをインストールしただけで動作します。

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### 期待される出力

スクリプトを実行すると 2 つのファイルが生成されます。

- `DatabarOmni30.png` – 高さ 30 px の DataBar Omnidirectional バーコード。  
- `DatabarOmni60.png` – 同じバーコードの高さ 60 px バージョン。

どちらも PNG 形式でロスレス、PDF、HTML ページへの埋め込みやラベルへの直接印刷にすぐ使用できます。

## よくある落とし穴とプロのコツ

- **Pixel vs. DPI:** PNG はピクセルベースです。特定の印刷サイズが必要な場合は DPI に基づいて `BarHeight` を計算します（例：300 dpi → 30 px ≈ 0.1 in）。  
- **Incorrect encoding:** データ文字列が GS1 アプリケーション識別子形式（GTIN‑14 の場合は `(01)`）に従っていることを確認してください。括弧が欠けていると、ライブラリはプレーンな数値バーコードにフォールバックします。  
- **File paths:** Windows では生文字列 (`r"..."`) または二重バックスラッシュを使用してエスケープ文字の問題を回避してください。  
- **Performance:** 数千本のバーコードを生成する場合は、ジェネレータを一度だけインスタンス化し、`BarHeight` やデータ文字列だけを変更して保存します。これによりメモリの消費が抑えられます。
