# C# で RM4SCC バーコードを作成し、Planet バーコードを生成する方法

郵便用途で **RM4SCC バーコードを作成** する必要がある場合、本ガイドでは正確な手順を示します。また、**Planet バーコードを自動高さと固定高さの両方で生成** する方法も学べるので、同じコードであらゆる郵便シンボルに対応できます。

このチュートリアルでは、郵便規格に適合した PNG 画像を生成するために必要なすべてをカバーしています。外部ツールは Aspose.BarCode for .NET ライブラリ以外不要です。最後まで実施すれば、プログラムでバーコードを生成し、サイズを正確に制御できるようになります。

## 前提条件

* .NET 6.0 以降がインストールされていること
* Visual Studio 2022（または任意の C# IDE）
* Aspose.BarCode for .NET NuGet パッケージ  
  `Install-Package Aspose.BarCode`
* 出力ディレクトリへの書き込み権限

これらがあれば、追加設定なしでサンプルコードをコンパイル・実行できます。

## 手順 1: RM4SCC 用のバーコードジェネレータを初期化する

最初の操作で、RM4SCC シンボロジー用に設定された `BarcodeGenerator` インスタンスを作成します。このオブジェクトはバーコード画像のすべての設定を保持します。

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**なぜ重要か** – `EncodeTypes.RM4SCC` は Aspose に郵便用 RM4SCC フォーマットを使用させ、データ文字列 `"123456"` はエンコードしたい郵便番号を表します。

## 手順 2: モジュール幅（X‑ディメンション）を設定する

モジュール幅は細いバーのサイズを決定します。郵便バーコードで一般的な値は 4 ピクセルです。

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**解説** – X‑ディメンションはバーコード全体の読み取りやすさに影響します。4 px を選択すると、ほとんどの郵便スキャナに適合します。

## 手順 3: 自動バー高さで保存する

高さの値を省略すると、Aspose はシンボロジーの規則に基づき最適な高さを自動的に計算します。

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**結果** – 生成された PNG（`PostalRM4SCCBarHeightNone.png`）は、印刷準備が整った正しいサイズの RM4SCC バーコードを含みます。

## 手順 4: 自動高さで Planet バーコードを作成する

同じパターンが Planet シンボロジーでも機能します。まず `EncodeTypes.Planet` でジェネレータを初期化します。

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**コード再利用の理由** – RM4SCC と Planet は同じパラメータ構造を共有しているため、`EncodeTypes` の値を変更するだけでシンボロジーを切り替えられます。

## 手順 5: RM4SCC の固定バー高さを設定する

一部の郵便サービスでは特定のバー高さ（例: 100 px）が必要です。保存前に明示的に設定できます。

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**ヒント** – `BarHeight.Pixels` を設定すると自動計算が上書きされ、視覚的サイズを完全に制御できます。

## 手順 6: Planet の固定バー高さを設定する

同じ固定高さの手法を Planet バーコードに適用します。

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**結果** – `PostalRM4SCCBarHeight100Pixels.png` と `PostalPlanetBarHeight100Pixels.png` の両方が、一定の 100 px バー高さを持つバーコードを含み、厳格な郵便仕様を満たします。

## 完全なソースコード

以下は、4 つの例すべてを網羅した完全な実行可能プログラムです。新しいコンソールプロジェクトにコピーし、必要に応じて出力パスを調整してください。

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**期待される出力** – プログラムを実行すると、指定したディレクトリに 4 つの PNG ファイルが作成されます：

* `PostalRM4SCCBarHeightNone.png` – 自動高さの RM4SCC
* `PostalPlanetBarHeightNone.png` – 自動高さの Planet
* `PostalRM4SCCBarHeight100Pixels.png` – 高さ 100 px の RM4SCC
* `PostalPlanetBarHeight100Pixels.png` – 高さ 100 px の Planet

任意のファイルを開き、バーが鮮明でモジュール幅が 4 px、そして高さが設定した通りであることを確認してください。

## よくある質問とエッジケース

| 質問 | 回答 |
|----------|--------|
| **他の画像形式を使用できますか？** | はい。必要に応じて `BarCodeImageFormat.Png` を `Jpeg`、`Bmp`、または `Gif` に置き換えてください。 |
| **データ文字列が長い場合はどうなりますか？** | ジェネレータは自動的にバー数を調整します。データがシンボロジーの長さ制限（RM4SCC ≤ 6 桁、Planet ≤ 6 桁）に合致していることを確認してください。 |
| **バーの色を変更するには？** | `Save` を呼び出す前に `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` を設定します。 |
| **印刷時に DPI は重要ですか？** | `rm4sccAuto.Parameters.ImageResolution.DpiX` と `DpiY` を設定して、プリンターの解像度に合わせることができます。 |
