# C#でAspose.BarCodeを使用してバーコードを塗りつぶす方法

.NET アプリケーションで **バーコードを塗りつぶす方法** が必要な場合、このチュートリアルでは全工程を示します。実線バーの郵便 Planet バーコードを生成し、同じバーコードの空白バー版も、コードを1行変更するだけで作成できます。

このガイドでは、プロジェクトのセットアップ、X‑dimension の調整、塗りつぶしバーと空白バーの切り替え、生成された PNG ファイルの検証方法など、必要なすべてを網羅しています。外部ドキュメントは不要で、コードをコピーして実行するだけで結果が確認できます。

## 前提条件

開始する前に、以下がインストールされていることを確認してください。

* .NET 6.0 SDK 以降がインストール済み  
* Visual Studio 2022 や VS Code などの開発環境  
* **Aspose.BarCode for .NET** NuGet パッケージ (`Aspose.BarCode`)  

これらはチュートリアルの **barcode generator c#** パートに必要な最小限の環境です。

## バーコードを塗りつぶす方法 – プロジェクトのセットアップ

1. 新しいコンソールプロジェクトを作成します：

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Aspose.BarCode パッケージを追加します：

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. 生成された `Program.cs` ファイルを開き、この記事の後半に示す完全なサンプルコードに置き換えます。

このプロジェクトには、**postal barcode を生成** するために必要なすべてが含まれています。

## 実線バーで郵便バーコードを生成

最初のステップは、塗りつぶし（実線）バーを使用した Planet バーコードを作成することです。Planet は多くの郵便サービスで仕分けに使用されるシンボロジーです。

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**このコードが重要な理由**

* `EncodeTypes.Planet` は使用するシンボロジーを指定します。Planet は郵便バーコードの標準です。  
* `XDimension.Pixels = 4` はモジュール幅を広げ、スキャンしやすく印刷時に視認性を向上させます。  
* `Save` は画像を PNG 形式でディスクに書き出します。PNG はロスレス形式で、後続の処理に適しています。

このブロックを実行すると **PostalPlanetFilledBars.png** が生成され、実線バーの画像が郵便規格に準拠した形で出力されます。

## Planet シンボロジーで空白バーを作成

場合によっては、バーは空白（未塗り）で、スペースは実線のままであることが求められます。そのモードへの切り替えはプロパティを1つ変更するだけで可能です。

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**このコードが機能する理由**

`FilledBars = false` を設定すると、レンダラは視覚スタイルを反転させます。バーは透明（空白）になり、背景が不透明になります。これは前述のデフォルト動作とは正反対で、エンコードされたデータを変更せずに **empty barcode を作成** できるようになります。

## 完全な実行可能サンプル

以下は 2 つのセクションを組み合わせた完全なプログラムです。`Program.cs` に貼り付け、`YOUR_DIRECTORY/` を実際のフォルダパスに置き換えてから `dotnet run` を実行してください。

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### 期待される出力

実行後、指定したフォルダに次の 2 つの PNG ファイルが作成されます。

| ファイル名                     | ビジュアル説明 |
|-------------------------------|--------------------|
| `PostalPlanetFilledBars.png`  | 白背景に黒の実線バー |
| `PostalPlanetEmptyBars.png`   | 黒背景に白（透明）バー |

両画像は同じ数値文字列 `"123456"` をエンコードしており、X‑dimension も同一です。そのため、データ検証の観点からは相互に置き換え可能です。

## よくある質問とエッジケース

**出力フォルダが存在しない場合はどうすればよいですか？**  
`Save` メソッドは `DirectoryNotFoundException` をスローします。事前にフォルダを作成するか、必要に応じてディレクトリを作成する `try / catch` ブロックで呼び出しをラップしてください：

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**別の画像形式を使用できますか？**  
はい。`BarCodeImageFormat.Png` を `BarCodeImageFormat.Jpeg`、`BarCodeImageFormat.Bmp`、または Aspose.BarCode がサポートする任意の形式に置き換えてください。

**X‑dimension はスキャナの読み取り易さに影響しますか？**  
ピクセル幅を大きくするとバーが太くなり、低解像度スキャナでの読み取り易さが向上する可能性があります。ただし、値が大きすぎると印刷可能領域を超えることがあります。300 dpi 印刷の場合、一般的な範囲は 2〜6 ピクセルです。

**`EncodeTypes.Planet` シンボロジーは唯一の郵便オプションですか？**  
いいえ。Aspose.BarCode は `EncodeTypes.Postnet` や `EncodeTypes.USPSIntelligentMail` もサポートしています。`FilledBars` プロパティはこれらのタイプでも同様に機能します。
