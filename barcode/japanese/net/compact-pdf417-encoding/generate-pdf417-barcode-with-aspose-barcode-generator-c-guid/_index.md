# Aspose Barcode Generator を使用した PDF417 バーコードの生成 – C# ガイド

.NET プロジェクトで **PDF417 バーコードを生成** する必要がある場合、このチュートリアルでは **Aspose Barcode Generator** を使ってその方法を正確に示します。コンパクトな PDF417 シンボルを作成し、サイズをカスタマイズして、結果を PNG ファイルとして保存する完全な実行可能サンプルが確認できます。

大量のデータ（URL、連絡先情報、在庫記録など）を単一のスキャン可能な画像にエンコードする必要がある場合、PDF417 バーコードの生成は一般的です。このガイドでは、ライブラリのインストールからコンパクトな出力のための **how to set PDF417** オプションの調整まで、すべてをカバーします。

## 学習できること

* C# プロジェクトに Aspose.BarCode ライブラリをインストールして参照する。  
* **aspose barcode generator** を使用して任意のテキストから PDF417 シンボルを作成する。  
* **how to set PDF417** パラメータ（モジュールサイズ、列数、コンパクトモード）を適用する。  
* バーコードを PNG 画像として保存し、結果を検証する。  

**前提条件**

* .NET 6.0 SDK 以降（コードは .NET Core 3.1 および .NET Framework 4.7+ でも動作します）。  
* C# コンソールアプリケーションの基本的な知識。  
* 有効な Aspose.BarCode ライセンス（無料評価版は開発用途で使用可能）。

## ステップ 1: PDF417 バーコードの生成 – ジェネレータの作成

最初のタスクは、目的のテキストと PDF417 シンボロジーでジェネレータをインスタンス化することです。このステップは **how to generate pdf417** の質問に直接答えます。

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Create a BarcodeGenerator for PDF417 with the data you want to encode.
            // The EncodeTypes enum selects the symbology; Pdf417 is the target type.
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");
```

**なぜ重要か:**  
`EncodeTypes.Pdf417` はライブラリに PDF417 アルゴリズムを使用するよう指示し、最大 1,850 文字までサポートします。コンストラクタは生データ文字列も受け取り、アクセントを含むすべての Unicode 文字が自動的に処理されます。

## ステップ 2: PDF417 パラメータの設定 – サイズとレイアウトのカスタマイズ

PDF417 バーコードはさまざまな形状でレンダリングできます。**how to set pdf417** オプションを調整することで、小さなラベルやモバイル画面に収まるコンパクトなシンボルを作成できます。

```csharp
            // -----------------------------------------------------------------
            // Step 2: Set visual parameters for the barcode
            // -----------------------------------------------------------------

            // Module size – each tiny square (pixel) of the barcode.
            // Smaller values produce a tighter image; 2 pixels is a good default.
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Number of columns – controls the width of the barcode.
            // Fewer columns make the symbol taller; 3 columns yields a compact shape.
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode – removes unnecessary quiet zones and reduces height.
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;
```

**各設定の説明**

| パラメータ | 効果 | 使用するタイミング |
|-----------|--------|-------------|
| `XDimension.Pixels` | 単一モジュールの幅を制御します。値を小さくするとバーコードが縮小しますが、低解像度デバイスではスキャナの読み取り性に影響する可能性があります。 | `2`–`4` を画面表示に使用し、印刷ラベルの場合は増やします。 |
| `Pdf417.Columns` | シンボルが含むデータ列の数を決定します。列が少ないほど、バーコードは高く狭くなります。 | `3`–`5` をコンパクトレイアウトに選択し、より広いバーコードにはより大きな値を使用します。 |
| `Pdf417.Truncate` | 「コンパクトモード」を有効にし、外側のクワイエットゾーンを削除して全体の高さを減らします。 | スペースが限られた UI 要素に最適です。 |

これら 3 つの設定を組み合わせることで **how to set pdf417** の課題に答え、最終画像を細かく制御できます。

## ステップ 3: バーコード画像の保存 – PNG としてエクスポート

ジェネレータの設定が完了したら、バーコードをファイルに書き出す必要があります。`Save` メソッドは多数のフォーマットをサポートしており、PNG はロスレス品質を保ち、Web とデスクトップの両シナリオでうまく機能します。

```csharp
            // -----------------------------------------------------------------
            // Step 3: Save the generated barcode as a PNG image
            // -----------------------------------------------------------------

            // Replace YOUR_DIRECTORY with an actual folder on your machine.
            string outputPath = @"C:\Barcodes\CompactPdf417.png";

            // BarCodeImageFormat.Png tells Aspose to write a PNG file.
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            // Inform the user that the process succeeded.
            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**期待される結果**

プログラムを実行すると、指定フォルダーに `CompactPdf417.png` が作成されます。この画像は文字列 `Åspóse.Barcóde©` をエンコードした密な PDF417 シンボルを含みます。ほとんどのバーコードスキャナやモバイルアプリ（例: ZXing、Scandit）は追加設定なしでこの画像を読み取れます。

## 完全なソースコード – コピー＆ペースト可能な単一ファイル

以下に `using` ディレクティブと `Main` メソッドを含む完全なプログラムを示します。これを新しいコンソールプロジェクトにコピーすればすぐに実行できます。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Step 1: Create the generator (how to generate pdf417)
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");

            // Step 2: Set PDF417 options (how to set pdf417)
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;   // module size
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;    // number of columns
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact mode

            // Step 3: Save as PNG
            string outputPath = @"C:\Barcodes\CompactPdf417.png";
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**コードの実行**

1. ターミナルを開き、新しいコンソールプロジェクトを作成します:  
   `dotnet new console -n Pdf417Demo`  
2. Aspose.BarCode NuGet パッケージを追加します:  
   `dotnet add package Aspose.BarCode`  
3. 生成された `Program.cs` を上記のコードに置き換えます。  
4. ビルドして実行します:  
   `dotnet run`  

確認メッセージが表示され、指定した場所に PNG ファイルが作成されているはずです。

## よくある落とし穴とベストプラクティスのヒント

* **ライセンスの有効期限** – 評価版は 30 日後に透かしが追加されます。予期せぬ問題を防ぐために早めにライセンスを登録してください。  
* **ディレクトリの権限** – 対象フォルダーが存在し、プロセスに書き込み権限があることを確認してください。そうでないと `Save` が `UnauthorizedAccessException` をスローします。  
* **スキャナの互換性** – コンパクトバーコードが読み取れない場合は、`XDimension.Pixels` を `4` に増やすか、`Truncate = false` に設定してください。  
* **Unicode の取り扱い** – Aspose.BarCode は UTF‑8 を完全にサポートしており、追加手順なしで任意の Unicode 文字列をエンコードできます。  
* **パフォーマンス** – ループで多数のバーコードを生成する場合、単一の `BarcodeGenerator` インスタンスを再利用し、イテレーション間で `CodeText` のみを更新すると効果的です。
