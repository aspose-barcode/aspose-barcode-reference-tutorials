# C# で Aspose を使用して PDF417 バーコードを生成する – ステップバイステップ ガイド

.NET アプリケーションで **PDF417 バーコードを生成** する必要がある場合、このガイドが具体的な手順を示します。Aspose.BarCode for .NET を使用して、基本、コンパクト、Micro、GS1‑Micro、そして Macro PDF417 バーコードを作成する、完全に実行可能なサンプルをご覧いただけます。

PDF417 バーコードの生成は、出荷ラベル、輸送書類、在庫システムなどで一般的な要件です。このチュートリアルの最後までに、**PDF417 バーコード** 画像を生成し、主要なパラメータを理解し、独自のデータペイロードに合わせてコードを適応できるようになります。

## 前提条件

- .NET 6.0 SDK 以降（コードは .NET Framework 4.7+ でも動作します）
- Visual Studio 2022 または任意の C# IDE
- Aspose.BarCode for .NET NuGet パッケージ（`Aspose.BarCode`）がインストール済み
- C# 文法の基本的な知識

> **プロのコツ:** テスト中に実行時の制限を回避するため、Aspose の無料評価ライセンスを使用してください。

## ステップ 1: プロジェクトのセットアップと名前空間のインポート

新しいコンソールプロジェクトを作成し、Aspose.BarCode パッケージを追加します：

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

次に `Program.cs` を開き、必要な `using` ディレクティブを追加します：

```csharp
using System;
using Aspose.BarCode.Generation;
```

これらの名前空間により、**C# でバーコードを生成する**ために必要な `BarcodeGenerator` クラスと `EncodeTypes` 列挙型にアクセスできます。

## ステップ 2: 基本的な PDF417 バーコードを生成する

最もシンプルな PDF417 バーコードは、X‑dimension（モジュール幅）と列数以外はデフォルト設定を使用します。これらの値を調整することで、全体のサイズと読み取りやすさを制御できます。

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**なぜ機能するのか:**  
- `EncodeTypes.Pdf417` は Aspose に PDF417 シンボルを使用させます。  
- `XDimension.Pixels` は最小のバー幅を定義します。値を 2 にすると、スキャン可能性を損なうことなく画像を小さく保てます。  
- `Pdf417.Columns` はバーコードが持つデータ列数を決定します。3 列にするとバランスの取れたアスペクト比になります。

## ステップ 3: コンパクト（トランケート）PDF417 バーコードを生成する

コンパクトモードはストップパターンを除去し、全体の高さを縮小します。限られたスペースのラベルに有用です。

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**なぜ機能するのか:**  
`Pdf417.Truncate = true` を設定すると、トランケートモードが有効になり、右側のストップパターンが省かれ、データの完全性を保ちつつバーコードの高さが縮小されます。

## ステップ 4: Micro PDF417 バーコードを生成する

Micro PDF417 は 1‑4 列をサポートする小型バリアントです。小さな商品タグなど、スペースが限られる用途に最適です。

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**なぜ機能するのか:**  
- `EncodeTypes.MicroPdf417` はシンボルのマイクロバージョンを選択します。  
- 列数は 1 から 4 の間で指定できます。4 を選ぶと、最も密度の高いレイアウトになり、スキャン可能です。

## ステップ 5: GS1 準拠の Micro PDF417 バーコードを生成する

GS1 プレフィックスは、バーコードデータに標準化された識別子（例: GTIN、ロット番号）を付加します。Aspose はこれらを直接埋め込むことができます。

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**なぜ機能するのか:**  
GS1 アプリケーション識別子（AI）は括弧で囲まれます。Aspose はそれらを解析し、GS1 スキャナが要求する適切なフォーマットを付加します。

## ステップ 6: 完全なメタデータ付き Macro PDF417 バーコードを生成する

Macro PDF417 は、大容量データペイロードを複数のリンクされたバーコードに分割できます。ファイル ID、セグメント数、タイムスタンプ、カスタム文字列などのファイルレベルメタデータを埋め込むことが可能です。

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**なぜ機能するのか:**  
各 `MacroPdf417*` プロパティは、マクロバーコード仕様の特定のセグメントに対応しています。これらの値を設定することで、スキャナは複数のバーコード画像から元のファイルを再構築できるようになります。
