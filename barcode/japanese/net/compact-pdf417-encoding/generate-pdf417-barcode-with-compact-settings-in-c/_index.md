# コンパクト設定でPDF417バーコードをC#で生成する

.NETアプリケーションで**PDF417バーコードを生成**する必要がある場合、本ガイドではAspose.Barcode for .NETを使用した方法を示します。ジェネレータの作成、列数、X‑dimensionの設定、コンパクトモードの有効化を順に解説し、シンボルをできるだけ小さくします。

大量のデータをチケット、ID、または出荷ラベルにエンコードする必要があるときに、PDF417バーコードの生成は一般的です。このチュートリアルでは、ライブラリのインストールから最終的なPNGの保存までの全工程をカバーしているので、コードをコピーして自分のプロジェクトに貼り付け、すぐに実行できます。

## PDF417バーコード生成の前提条件

開始する前に、以下が揃っていることを確認してください。

* .NET 6.0（またはそれ以降）がインストールされていること。  
* Visual Studio 2022 または C# プロジェクトをサポートする任意の IDE。  
* **Aspose.Barcode for .NET** の NuGet ライセンス（学習目的であれば無料トライアルで可）。  

以下のコマンドでライブラリを追加できます。

```bash
dotnet add package Aspose.BarCode
```

> **プロのコツ:** `--version` フラグを使用して既知の安定バージョンを固定してください。例: `dotnet add package Aspose.BarCode --version 23.12`.

## PDF417バーコードジェネレータの作成

最初のコードブロックは、PDF417シンボロジー用に事前設定された `BarcodeGenerator` インスタンスを作成します。テキスト `"Åspóse.Barcóde©"` には Unicode 文字が含まれており、ジェネレータが非ASCII入力をそのまま処理できることを示しています。

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### これが重要な理由
`EncodeTypes.Pdf417` は Aspose.Barcode に **PDF417バーコード** を生成したいことを指示します。PDF417 は最大 1 850 文字を格納できるスタック型リニアシンボロジーです。テキスト引数付きコンストラクタを使用することで、後から `SetCodeText` を呼び出す手間が省けます。

## バーコードの XDimension（モジュールサイズ）を設定する

モジュールサイズ（X‑dimension）は、各バーの幅を決定します。ピクセルが小さいほど画像は密になり、ピクセルが大きいほど低解像度プリンターでの可読性が向上します。

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### XDimension を調整すべき理由
`2` ピクセルは画面表示や一般的なオフィスプリンターに適しています。高解像度印刷が必要な場合は値を上げ、QR のようにコンパクトにしたい場合は下げます。ただし `1` ピクセル未満にすると画像が読めなくなるので注意してください。

## PDF417シンボルの列数を設定する

PDF417 ではバーコードの列数（垂直スタック数）を選択できます。列が少ないとバーコードは高くなり、列が多いと横に広がります。

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### 列数を変更すべきタイミング
3 列はコンパクトでほぼ正方形のシンボルを生成し、標準的な ID カードにうまく収まります。文字列が非常に長い場合は、縦長になりすぎないよう列数を増やすと良いでしょう。

## コンパクトモード（トランケーション）を有効にする

コンパクトモードは未使用の行を自動的に削除し、全体サイズを縮小します。エンコードされたデータがマトリックス全体を埋め尽くさない場合に特に有用です。

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### コンパクトPDF417バーコードの利点
`Truncate` が `true` の場合、ジェネレータはデータを格納するために必要な最小行数を計算し、インク使用量とスキャン時間を削減します。PDF417 仕様でトランケーションアルゴリズムが定義されているため、ほとんどのスキャナーで安全に使用できます。

## 生成したバーコードを画像として保存する

最後に、バーコードを PNG ファイルに書き出します。PNG はロスレス品質を保持するため、後で印刷したり PDF に埋め込んだりするのに最適です。

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### 期待される出力
プログラムを実行すると、指定フォルダーに `CompactPdf417.png` が作成されます。この画像は、文字列 `"Åspóse.Barcóde©"` を 3 列、2 ピクセル X‑dimension、トランケーション適用でエンコードした **コンパクトPDF417バーコード** を含みます。任意のバーコードスキャナーアプリや無料の Aspose.Barcode オンラインデモで結果を確認できます。

## 一般的なバリエーションとエッジケース

| 状況 | 調整 |
|-----------|------------|
| **非常に長いデータ（1500文字超）** | `Columns` を増やすか、`Rows` を手動で設定します（`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`）。 |
| **低DPIプリンターでの印刷** | ピクセル化を防ぐために `XDimension.Pixels` を 3 または 4 に上げます。 |
| **透過背景が必要** | `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })` を使用します。 |
| **PDFへの埋め込み** | `BarCodeImageFormat.Pdf` として保存するか、`pdf417Generator.GenerateBarCodeImage()` で `Image` オブジェクトを取得します。 |

## 完全な実行可能サンプル

以下は新しいコンソールプロジェクトにコピーできる完全なプログラムです。追加のファイルは不要です。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

プロジェクトフォルダーで `dotnet run` を実行してください。実行後、`CompactPdf417.png` を開くと生成されたバーコードが確認できます。

## 結論

これで C# で **PDF417バーコードを生成**し、列数、X‑dimension、コンパクトモードをフルコントロールできるようになりました。`barcode XDimension pixels`、`set PDF417 columns`、`compact PDF417 barcode` のトランケーションを調整することで、アプリケーションのサイズ制約に正確に合致したバーコードを作成できます。

次に検討できるステップ:

* `Rows` パラメータを使って、より大きなデータセットをエンコードし実験する。  
* 出力形式を `BarCodeImageFormat.Svg` に切り替えて、スケーラブルなウェブグラフィックにする。  
* バーコードを他の Aspose コンポーネント（例: **Aspose.PDF**）と組み合わせ、画像を PDF レポートに直接埋め込む。

コーディングを楽しんで、スキャン環境に合わせて設定を自由に調整してください！
