# C# で PDF417 バーコードを生成する方法 – コンパクト例

C# アプリケーションで **PDF417 バーコードを生成** したい場合、このガイドでは完全に実行可能なソリューションを示します。Aspose.BarCode .NET ライブラリを使用して、コンパクトな PDF417 バーコードを作成し、モジュール幅を調整し、列数を定義し、結果を PNG 画像として保存します。

PDF417 バーコードの生成は、URL、連絡先カード、在庫 ID など大量のデータをスペース効率の良い二次元形式でエンコードしたいときに一般的です。このチュートリアルの最後までに、印刷や表示に適したコンパクトで高可読性のバーコードを生成する `BarcodeGenerator` インスタンスが手に入ります。

## 前提条件

- .NET 6.0 以降（コードは .NET Framework 4.8 でも動作します）
- Visual Studio 2022（または任意の C# IDE）
- Aspose.BarCode for .NET NuGet パッケージ（`Install-Package Aspose.BarCode`）
- C# 文法の基本的な知識

追加の設定は不要です。サンプルはコンソール アプリとして実行できます。

## 手順 1: PDF417 バーコード ジェネレータを作成する

最初のステップは、`EncodeTypes.Pdf417` 列挙体とエンコードしたいテキストを指定して `BarcodeGenerator` をインスタンス化することです。

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**ポイント:** `EncodeTypes.Pdf417` はライブラリに PDF417 シンボルを使用させ、2 番目の引数でデータペイロードを設定します。`"Compact example"` は最大 1 800 文字までの任意の文字列に置き換え可能です。

## 手順 2: ピクセル単位でモジュール幅（X‑dimension）を設定する

X‑dimension は単一のバーコードモジュール（最小の黒または白の正方形）の幅を定義します。ピクセル値を小さくすると、バーコードがよりタイトになります。

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**ポイント:** `2` ピクセルの値は、ほとんどの最新スキャナでスキャン信頼性を損なうことなくコンパクトな外観を実現します。低解像度印刷が必要な場合は、値を大きく調整してください。

## 手順 3: 列数を指定する

PDF417 では列数を制御でき、バーコードのアスペクト比に影響します。

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**ポイント:** 列数が少ないほどバーコードは縦長になり、列数が多いほど横長になります。3 列はコンパクトで縦向きレイアウトに適しています。

## 手順 4: トランケーションでコンパクトモードを有効にする

コンパクトモードは不要なパディング行を除去し、エンコードされたデータを保持しながらバーコードを小さくします。

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**ポイント:** トランケーションは画面スペースが限られる場合（例: モバイルアプリや小さなラベル）に最適です。エンコードアルゴリズムが自動的に誤り訂正レベルを調整するため、可読性は維持されます。

## 手順 5: PNG 画像としてバーコードを保存する

最後に、生成したバーコードをファイルに書き出します。PNG はロスレス品質を保持するため、バーコードスキャナにとって重要です。

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

プログラムを実行すると、実行ファイルの作業ディレクトリに `CompactPdf417.png` が作成されます。画像は次のようになります。

![Generated compact PDF417 barcode](CompactPdf417.png "Generated compact PDF417 barcode")

**期待される出力:** 2 ピクセル幅、3 列の PDF417 バーコードで、テキスト “Compact example” をエンコードします。標準的なバーコードスキャナで PNG をスキャンすると、元の文字列が返ります。

## 一般的なバリエーションとエッジケース

| 状況 | コードの調整方法 |
|-----------|------------------------|
| **データが長い（> 500 文字）** | バーコードが高くなりすぎないように `Columns` を 5‑7 に増やす |
| **高解像度印刷** | モジュールを大きくするために `XDimension.Pixels` を 3 または 4 に設定 |
| **画像形式を変更** | 必要に応じて `BarCodeImageFormat.Png` を `Jpeg` や `Bmp` に置き換える |
| **PDF に埋め込む** | PNG の代わりに `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` を使用 |

**プロのコツ:** 常に対象スキャナハードウェアで生成したバーコードをテストしてください。非常に小さな X‑dimension は低価格スキャナで読み取りエラーが発生しやすいので、エラーが出た場合はピクセル値を 1 ステップ上げてみましょう。

## 完全な実行可能サンプル

以下は新しいコンソール プロジェクトにコピー＆ペーストできる完全なプログラムです。追加ファイルは不要です。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

`dotnet run`（.NET CLI 使用時）でコンパイル・実行してください。実行後、`CompactPdf417.png` を開いてビジュアル結果を確認します。

## 結論

これで **C# でコンパクトなレイアウト、カスタム X‑dimension、列設定を持つ PDF417 バーコードを生成** する方法が分かりました。例では、`BarcodeGenerator` のインスタンス化、`XDimension` と `Columns` の設定、コンパクトモードのための `Truncate` 有効化、そして画像保存という基本手順を示しました。

ここからは、誤り訂正レベルやカスタムカラー、PDF への直接埋め込みなどの追加機能を探求できます。別のシンボルが必要な場合は `EncodeTypes` を変更して（例: QR、Code128）同様のパラメータ構成パターンを適用してください。

コーディングを楽しんで、バーコードが常に最初のスキャンで読み取れるようにしましょう！
