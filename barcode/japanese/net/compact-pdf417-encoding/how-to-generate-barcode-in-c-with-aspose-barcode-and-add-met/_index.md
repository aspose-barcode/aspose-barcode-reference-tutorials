# C#でAspose.BarCodeを使用してバーコードを生成し、メタデータを追加する方法

物流や在庫管理システム向けに **C#でバーコードを生成** する必要がある場合、このガイドでは完全な本番環境対応ソリューションを示します。Macro PDF417 バーコードの作成方法、リッチなメタデータの添付方法、正確なタイムスタンプの設定方法を、すべて Aspose.BarCode ライブラリを使用して学べます。

このチュートリアルは、NuGet パッケージのインストールから最終的な PNG 画像の保存までを網羅しています。最後まで実行すれば、ファイル ID、セグメント情報、カスタムフィールドを保持したバーコードを生成でき、Macro PDF417 をサポートする下流のスキャナで使用可能になります。

## 前提条件

開始する前に、以下を用意してください。

* .NET 6.0 SDK 以降（コードは .NET Framework 4.7.2+ でも動作します）
* Visual Studio 2022 またはお好みの C# IDE
* 有効な Aspose.BarCode ライセンス（開発用には無料トライアルで可）
* C# の基本的な構文に慣れていること

> **プロのコツ:** CI/CD パイプラインを使用している場合は、プロジェクト ファイルに Aspose.BarCode のパッケージ参照を追加しておくと、ビルドの再現性が保てます。

## 手順 1: Aspose.BarCode をインストール

プロジェクト フォルダーでターミナルを開き、次のコマンドを実行します。

```bash
dotnet add package Aspose.BarCode
```

このコマンドは最新の安定版（現在は 24.9）を取得します。復元が完了したら、ソース ファイルでライブラリを参照できるようになります。

## 手順 2: 新しい C# コンソール プロジェクトを作成（任意）

新規に始めたい場合は、コンソール アプリを作成します。

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs` ファイルに、後述のバーコード生成コードを配置します。

## 手順 3: バーコード ジェネレータを設定

プロセスの中心となるのは `BarcodeGenerator` クラスです。目的の `EncodeTypes` 列挙値とエンコードしたいテキストを指定してインスタンス化します。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### 各行の重要ポイント

* **EncodeTypes.MacroPdf417** は、セグメントに分割可能な PDF417 バーコードを生成するよう Aspose に指示します。大容量データを単一シンボルの容量を超えて扱う際に必須です。
* **XDimension.Pixels** は視覚的密度を制御します。値を 2 にすると、ほとんどの画面やプリンターでクリアな画像が得られ、ファイルサイズの肥大化を防げます。
* **MacroPdf417* プロパティ** は、下流スキャナが個別フィールドとして読み取るメタデータ（ファイル ID、セグメント ID など）を埋め込みます。これが「メタデータを追加する」部分です。
* **MacroPdf417TimeStamp** は「タイムスタンプを設定する」例です。`DateTime` インスタンスは任意の UTC 時間を指定でき、UTC を使用することで地域間のタイムゾーン曖昧さを回避できます。
* **MacroPdf417Terminator** はマクロ シーケンスの終了方法を定義します。`Set` は最も一般的で、リーダーに最終セグメントであることを通知します。
* **Save(..., BarCodeImageFormat.Png)** は、スキャンの信頼性に必要な微細なディテールを保持したロスレス画像を出力します。

## 手順 4: 生成されたバーコードを確認

プログラムを実行します。

```bash
dotnet run
```

コンソールに次のように表示されます。

```
Barcode saved to ExtPDF417Meta.png
```

任意の画像ビューアで `ExtPDF417Meta.png` を開きます。画像にはテキスト **Åspóse.Barcóde©** と埋め込まれたマクロ フィールドを持つコンパクトな PDF417 シンボルが表示されます。Macro PDF417 対応スキャナ（または同等のモバイル アプリ）でスキャンすると、元のテキストに加えて設定したメタデータが返されます。

### 期待されるビジュアル特性

* 暗く均等に間隔が取られた垂直バー
* Aspose が自動的に追加するクワイエットゾーン（余白）
* `XDimension` が 2 ピクセルで PNG のネイティブ解像度に一致しているため歪みなし

## 手順 5: 一般的なバリエーションとエッジケース

### 5.1 特殊文字の取り扱い

サンプル テキストには Unicode 文字（`Å`, `ó`, `©`）が含まれています。Aspose.BarCode はデフォルトで UTF‑8 にエンコードするため、バーコード内で正しく表現されます。別のエンコーディング（例: ISO‑8859‑1）が必要な場合は、次のように設定します。

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 大きなファイル識別子

`MacroPdf417FileID` は 32 ビット整数を受け取ります。`int.MaxValue` を超える値の場合は、識別子を複数フィールドに分割するか、`MacroPdf417FileName` に文字列として格納した GUID を使用してください。

### 5.3 列数の調整

`Pdf417.Columns` を増やすとバーコードの高さが減少しますが、各行が広くなります。ラベルが狭い場合は列数を減らし、行数が自動的に増えるように調整します。

### 5.4 他形式での保存

Aspose は BMP、JPEG、TIFF、SVG をサポートしています。`BarCodeImageFormat.Png` を目的の列挙値に置き換えるだけです。例: スケーラブルなベクタ画像が必要な場合は `BarCodeImageFormat.Svg` を使用します。

## 手順 6: バーコードを大規模ワークフローに統合

PNG ファイルができたら、次のように活用できます。

* Aspose.PDF を使って PDF 請求書に埋め込む
* 配達証明としてメールに添付する
* 後で取得できるようにデータベースに画像バイト列として保存する

以下は PNG をバイト配列に変換して保存する簡易コードです。

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## よくある質問

**Q: .NET Core でも動作しますか？**  
A: はい。同じ API が .NET Core、.NET 5+、および .NET Framework で動作します。適切な NuGet パッケージを参照してください。

**Q: Macro ではない PDF417 を生成したい場合は？**  
A: `EncodeTypes.Pdf417` を使用し、Macro 固有のプロパティは無視されます。

**Q: ビルトイン フィールド以外にカスタムのキー/バリュー ペアを追加できますか？**  
A: Aspose.BarCode は Macro PDF417 用に任意のユーザー フィールドを公開していません。追加データが必要な場合は、メインテキスト ペイロードにエンコードするか、構造化付加が可能な QR コードに切り替えてください。
