# Aspose.BarCode for .NET を使用した DataMatrix バーコードの生成方法

.NET アプリケーションに機械可読シンボルを埋め込む信頼できる方法が必要な場合、**DataMatrix バーコードの生成** は一般的な要件です。Aspose.BarCode for .NET は、適切な DataMatrix バージョンの選択からエラー訂正レベルの微調整まで、外部ツールを必要とせずにすべての手順を処理する完全にマネージドされた API を提供します。このチュートリアルでは、完全なサンプルを順に解説し、各設定が重要な理由を説明し、結果を PNG または JPEG 画像として保存する方法を示します。

## クイック回答
- **DataMatrix バーコードを生成するライブラリは何ですか？** Aspose.BarCode for .NET。  
- **サポートされている DataMatrix バージョンはいくつですか？** 10×10 から 144×144 モジュールまでの 30 種類の標準正方形および長方形バージョンすべて。  
- **使用できる ECC タイプはどれですか？** ECC200（デフォルト）と ECC140。  
- **開発にライセンスは必要ですか？** テスト用の無料 30 日間トライアルで動作します。商用利用には製品ライセンスが必要です。  
- **.NET 6、.NET Core、.NET Framework のいずれでも実行できますか？** はい。Aspose.BarCode は .NET Framework 4.5 以降、.NET Core 3.1 以降、.NET 5/6 以降をサポートしています。

## DataMatrix バーコードとは？
DataMatrix バーコードは、黒と白のセルで構成された二次元の正方形または長方形のマトリックスで、最大 2,335 文字の英数字を格納できます。製造、物流、医療などで小さなアイテムにマーキングする際に広く使用されており、部分的に損傷しても読み取り可能です。

## Aspose.BarCode for .NET を使用する理由は？
Aspose.BarCode は **50 以上の出力フォーマット**（PNG、JPEG、TIFF、SVG、PDF など）をサポートし、**すべての 30 バージョンの DataMatrix** を画像全体をメモリにロードせずに生成できます。これにより、100 MB を超えるファイルを処理する高スループットサービスでもバーコードを作成できます。

コードに取り掛かる前に、以下の前提条件が整っていることを確認してください。
- .NET に対応した開発環境（Visual Studio 2022、Rider、または VS Code）。  
- Aspose.BarCode for .NET のコピー。**Aspose.BarCode .NET ダウンロードページ** からダウンロードできます: [Aspose.BarCode .NET ダウンロードページ](https://releases.aspose.com/barcode/net/)。  
- C# と .NET フレームワークの基本知識。

それでは、DataMatrix のバージョンと Aspose.BarCode for .NET を使用した生成方法を見ていきましょう。

## .NET で DataMatrix バーコードを生成する方法

`BarcodeGenerator` に `EncodeTypes.DataMatrix` タイプを指定し、目的のバージョンと ECC を設定してから `Save` を呼び出すだけで画像ファイルを書き出せます。このシングルラインパターンは任意のバージョンで機能し、モジュールサイズ、静粛領域、画像レンダリングを自動的に処理します。

## 名前空間のインポート

`BarcodeGenerator` は Aspose.BarCode のコアクラスで、バーコード画像の作成に使用します。  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

`Aspose.BarCode.Generation` 名前空間は `BarcodeGenerator` クラスへのアクセスを提供し、バーコード画像生成の主要クラスです。

それでは、例を複数のステップに分解して説明します。

## 手順 1: ディレクトリ パスの設定

生成した DataMatrix バーコードを保存したいディレクトリ パスを定義します。

```csharp
string path = "Your Directory Path";
```

`"Your Directory Path"` を、バーコード画像を保存したい実際のパスに置き換えてください。

## 手順 2: バーコードジェネレータの初期化

`BarcodeGenerator` クラスのインスタンスを作成し、バーコードタイプを `DataMatrix` に指定します。エンコードしたいデータも同時に指定できます。

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` はシンボルの作成とレンダリングを行うメインクラスです。

## 手順 3: バーコードプロパティの設定

DataMatrix バーコードのサイズや ECC（エラー訂正コード）タイプなど、さまざまなプロパティをカスタマイズできます。以下は X‑dimension を 4 ピクセルに設定し、ECC200 を選択する例です。

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` は各モジュールのピクセルサイズを決定し、`DataMatrixEcc` はエラー訂正レベルを選択します。

## 手順 4: DataMatrix バージョンの設定と保存

行数と列数を設定して DataMatrix バージョンを指定します。バージョンを設定したら、バーコード画像を保存します。

たとえば、ECC200 を使用して 22 行 22 列の DataMatrix バーコードを作成する場合:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

同様に、バージョンや ECC タイプを変更すれば、別のパラメータでバーコードを生成できます。

## 手順 5: 他のバージョンでも繰り返す

手順 4 を他の DataMatrix バージョンでも実行します。例として、ECC200 を使用して 12 行 64 列のバーコードを作成する場合:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## 手順 6: ECC タイプの切り替え

ECC タイプを Ecc140 に変更したい場合は、ECC プロパティを更新します。

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## 手順 7: 異なるバージョンと ECC でバーコードを生成する

手順 4 を他の DataMatrix バージョンと ECC タイプで繰り返し、各バーコードを固有のファイル名で保存します。

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

以上で、Aspose.BarCode for .NET を使用した DataMatrix バーコードの生成方法を習得しました。この機能を .NET アプリケーションに簡単に組み込むことができます。

## よくある落とし穴とトラブルシューティングのヒント

- **バージョン寸法の不一致** – DataMatrix バージョンは固定の行/列ペアを持ちます。組み合わせが合わない（例: 10 × 20）と `ArgumentException` がスローされます。必ず API ドキュメントに記載された組み合わせを使用してください。  
- **ライセンス未設定** – トライアルモードでは生成画像に透かしが入ります。ジェネレータ作成前に有効なライセンスを適用してください: `License license = new License(); license.SetLicense("Aspose.BarCode.lic");`。`License` クラスはライセンス ファイルを読み込み、製品を有効化します。  
- **画像サイズが大きすぎる** – 高解像度が必要な場合は `XDimension` プロパティを増やしてください。ライブラリは画像を比例的に拡大し、可読性を維持します。
