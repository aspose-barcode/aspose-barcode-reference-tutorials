# Hoe barcode te genereren in C# met Aspose.BarCode en metadata toe te voegen

Als je **barcode in C#** moet genereren voor een logistiek of voorraadbeheersysteem, laat deze gids je een complete, productie‑klare oplossing zien. Je ziet hoe je een Macro PDF417 barcode maakt, rijke metadata toevoegt en een nauwkeurige tijdstempel instelt — allemaal met de Aspose.BarCode bibliotheek.

De tutorial behandelt alles, van het installeren van het NuGet‑pakket tot het opslaan van de uiteindelijke PNG‑afbeelding. Aan het einde kun je een barcode genereren die bestands‑ID’s, segmentinformatie en aangepaste velden bevat, klaar voor downstream‑scanners die Macro PDF417 ondersteunen.

## Vereisten

Voordat je begint, zorg dat je het volgende hebt:

* .NET 6.0 SDK of later (de code werkt ook met .NET Framework 4.7.2+)
* Visual Studio 2022 of een andere C#‑IDE naar keuze
* Een actieve Aspose.BarCode‑licentie (de gratis trial werkt voor ontwikkeling)
* Basiskennis van C#‑syntaxis

> **Pro tip:** Als je een CI/CD‑pipeline gebruikt, voeg dan de Aspose.BarCode‑pakketreferentie toe in je project‑bestand zodat builds reproduceerbaar blijven.

## Stap 1: Installeer Aspose.BarCode

Open een terminal in je projectmap en voer uit:

```bash
dotnet add package Aspose.BarCode
```

Het commando haalt de nieuwste stabiele versie op (momenteel 24.9). Nadat het herstel is voltooid, kun je de bibliotheek in je bronbestanden refereren.

## Stap 2: Maak een nieuw C#‑consoleproject (optioneel)

Als je liever met een schone lei begint, maak dan een console‑applicatie:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Het bestand `Program.cs` zal de barcode‑generatiecode bevatten die later wordt getoond.

## Stap 3: Stel de barcode‑generator in

De kern van het proces is de `BarcodeGenerator`‑klasse. Je maakt een instantie aan met de gewenste `EncodeTypes`‑enumwaarde en de tekst die je wilt coderen.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Waarom elke regel belangrijk is

* **EncodeTypes.MacroPdf417** vertelt Aspose een PDF417‑barcode te produceren die in segmenten kan worden opgesplitst. Dit is essentieel voor grote payloads die de capaciteit van één symbool overschrijden.
* **XDimension.Pixels** regelt de visuele dichtheid. Een waarde van 2 levert een duidelijk beeld op de meeste schermen en printers zonder de bestandsgrootte te vergroten.
* **MacroPdf417*‑eigenschappen** embedden de metadata die downstream‑scanners lezen als afzonderlijke velden (file ID, segment ID, enz.). Dit is het “hoe metadata toe te voegen”‑deel van de tutorial.
* **MacroPdf417TimeStamp** toont “hoe een tijdstempel in te stellen”. De `DateTime`‑instantie kan elke UTC‑tijd zijn; UTC gebruiken voorkomt tijdzone‑ambiguïteit wanneer de barcode over regio’s reist.
* **MacroPdf417Terminator** bepaalt hoe de macro‑reeks eindigt. `Set` is de meest voorkomende keuze omdat het het laatste segment aan de lezer signaleert.
* **Save(..., BarCodeImageFormat.Png)** schrijft een lossless‑afbeelding die de fijne details behoudt die nodig zijn voor betrouwbare scanning.

## Stap 4: Verifieer de gegenereerde barcode

Voer het programma uit:

```bash
dotnet run
```

Je zou de console‑output moeten zien:

```
Barcode saved to ExtPDF417Meta.png
```

Open `ExtPDF417Meta.png` in een willekeurige afbeeldingsviewer. De afbeelding toont een compact PDF417‑symbool met de tekst **Åspóse.Barcóde©** en de ingebedde macro‑velden. Het scannen van de afbeelding met een PDF417‑compatibele scanner (of een mobiele app die Macro PDF417 ondersteunt) geeft de oorspronkelijke tekst plus de metadata‑waarden die je hebt ingesteld terug.

### Verwachte visuele kenmerken

* Donkere, gelijkmatig gespreide verticale balken
* Een quiet zone (marge) automatisch toegevoegd door Aspose
* Geen vervorming, omdat de `XDimension` van 2 pixels overeenkomt met de native resolutie van de PNG

## Stap 5: Veelvoorkomende variaties en randgevallen

### 5.1 Omgaan met speciale tekens

De voorbeeldtekst bevat Unicode‑tekens (`Å`, `ó`, `©`). Aspose.BarCode codeert ze standaard met UTF‑8, zodat ze correct in de barcode verschijnen. Als je een andere codering nodig hebt (bijv. ISO‑8859‑1), stel dan in:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Grote bestands‑ID’s

`MacroPdf417FileID` accepteert een 32‑bit integer. Voor waarden groter dan `int.MaxValue` kun je de identifier over meerdere velden verdelen of een GUID als string opslaan in `MacroPdf417FileName`.

### 5.3 Het aantal kolommen aanpassen

Het verhogen van `Pdf417.Columns` verkleint de barcode‑hoogte maar maakt elke rij breder. Als de barcode op een smal label moet passen, verlaag dan het aantal kolommen en laat het aantal rijen automatisch toenemen.

### 5.4 Opslaan in andere formaten

Aspose ondersteunt BMP, JPEG, TIFF en SVG. Vervang `BarCodeImageFormat.Png` door de gewenste enum‑waarde, bijvoorbeeld `BarCodeImageFormat.Svg` voor een schaalbare vectorafbeelding.

## Stap 6: Integreer de barcode in een grotere workflow

Zodra je het PNG‑bestand hebt, kun je:

* Het embedden in een PDF‑factuur met Aspose.PDF.
* Het als bijlage aan een e‑mail toevoegen als bewijs van levering.
* De afbeeldingsbytes opslaan in een database voor later gebruik.

Hieronder een kort fragment dat de PNG converteert naar een byte‑array voor opslag:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Veelgestelde vragen

**Q: Werkt dit op .NET Core?**  
A: Ja. dezelfde API werkt op .NET Core, .NET 5+ en .NET Framework. Verwijs gewoon naar het juiste NuGet‑pakket.

**Q: Wat als ik een niet‑macro PDF417 moet genereren?**  
A: Gebruik `EncodeTypes.Pdf417` in plaats van `EncodeTypes.MacroPdf417`. De macro‑specifieke eigenschappen worden dan genegeerd.

**Q: Kan ik aangepaste sleutel/waarde‑paren toevoegen naast de ingebouwde velden?**  
A: Aspose.BarCode biedt geen willekeurige gebruikersvelden voor Macro PDF417. Als je extra data nodig hebt, codeer die dan in de hoofd‑tekstpayload of schakel over naar een QR‑code, die gestructureerde append ondersteunt.
