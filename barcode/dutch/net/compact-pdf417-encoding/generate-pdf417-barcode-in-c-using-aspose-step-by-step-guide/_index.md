# PDF417 barcode genereren in C# met Aspose – stap‑voor‑stap handleiding

Als je een **PDF417 barcode moet genereren** in een .NET‑applicatie, laat deze gids je precies zien hoe. Je ziet een compleet, kant‑klaar voorbeeld dat basis‑, compacte, Micro-, GS1‑Micro‑ en Macro‑PDF417‑barcodes maakt met Aspose.BarCode voor .NET.

Het genereren van een PDF417 barcode is een veelvoorkomende eis voor verzendetiketten, transportdocumenten en voorraadbeheersystemen. Aan het einde van deze tutorial kun je **PDF417 barcode**‑afbeeldingen genereren, de belangrijkste parameters begrijpen en de code aanpassen voor je eigen gegevenspayloads.

## Vereisten

- .NET 6.0 SDK of later (de code werkt ook met .NET Framework 4.7+)
- Visual Studio 2022 of een andere C#‑IDE
- Aspose.BarCode for .NET NuGet‑pakket (`Aspose.BarCode`) geïnstalleerd
- Basiskennis van C#‑syntaxis

> **Pro tip:** Gebruik de gratis evaluatielicentie van Aspose om runtime‑beperkingen tijdens het testen te vermijden.

## Stap 1: Het project opzetten en namespaces importeren

Maak een nieuw console‑project aan en voeg het Aspose.BarCode‑pakket toe:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Open vervolgens `Program.cs` en voeg de benodigde `using`‑directieven toe:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Deze namespaces geven je toegang tot de `BarcodeGenerator`‑klasse en de `EncodeTypes`‑enumeratie die nodig zijn om **een barcode te genereren met C#**.

## Stap 2: Een basis‑PDF417 barcode genereren

De eenvoudigste PDF417 barcode gebruikt de standaardinstellingen, behalve de X‑dimensie (module‑breedte) en het aantal kolommen. Het aanpassen van deze waarden bepaalt de totale grootte en leesbaarheid.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Waarom het werkt:**  
- `EncodeTypes.Pdf417` vertelt Aspose om de PDF417‑symbologie te gebruiken.  
- `XDimension.Pixels` definieert de kleinste balkbreedte; een waarde van 2 houdt de afbeelding klein zonder de scanbaarheid te verminderen.  
- `Pdf417.Columns` bepaalt hoeveel datakolommen de barcode bevat; drie kolommen geven een evenwichtige beeldverhouding.

## Stap 3: Een compacte (afgekorte) PDF417 barcode genereren

De compacte modus verwijdert het stop‑patroon en verkleint de totale hoogte, wat nuttig is voor etiketten met beperkte ruimte.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Waarom het werkt:**  
Door `Pdf417.Truncate = true` in te stellen, wordt de afgekorte modus geactiveerd, die het rechter‑stop‑patroon weghaalt en de barcode‑hoogte verkleint terwijl de gegevensintegriteit behouden blijft.

## Stap 4: Een Micro PDF417 barcode genereren

Micro PDF417 is een kleinere variant die 1‑4 kolommen ondersteunt. Het is ideaal voor toepassingen waar ruimte schaars is, zoals kleine productetiketten.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Waarom het werkt:**  
- `EncodeTypes.MicroPdf417` selecteert de micro‑versie van de symbologie.  
- Het aantal kolommen kan tussen 1 en 4 liggen; kiezen voor 4 levert de dichtste lay‑out op terwijl deze scanbaar blijft.

## Stap 5: Een GS1‑conforme Micro PDF417 barcode genereren

GS1‑prefixen voegen gestandaardiseerde identifiers (bijv. GTIN, batch‑nummer) toe aan de barcode‑data. Aspose stelt je in staat deze direct in te sluiten.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Waarom het werkt:**  
GS1‑Application Identifiers (AIs) worden tussen haakjes geplaatst. Aspose parseert ze en voegt de juiste opmaak toe die vereist is door GS1‑scanners.

## Stap 6: Een Macro PDF417 barcode met volledige metadata genereren

Macro PDF417 maakt het mogelijk een grote gegevenspayload over meerdere gekoppelde barcodes te verdelen. Je kunt bestands‑metadata insluiten zoals bestand‑ID, segment‑aantal, tijdstempels en aangepaste strings.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Waarom het werkt:**  
Elke `MacroPdf417*`‑eigenschap correspondeert met een specifiek segment van de macro‑barcode‑specificatie. Het instellen van deze waarden zorgt ervoor dat een scanner het oorspronkelijke bestand kan reconstrueren uit meerdere barcode‑afbeeldingen.
