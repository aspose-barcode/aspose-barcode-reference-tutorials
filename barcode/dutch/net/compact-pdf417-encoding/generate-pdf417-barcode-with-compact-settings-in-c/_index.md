# Genereer PDF417 barcode met compacte instellingen in C#

Als je een **PDF417 barcode** moet genereren in een .NET‑applicatie, laat deze gids je zien hoe je dat doet met Aspose.Barcode for .NET. We lopen stap voor stap door het maken van de generator, het configureren van kolommen, X‑dimension, en het inschakelen van compacte modus zodat het resulterende symbool zo klein mogelijk is.

Het genereren van een PDF417 barcode is gebruikelijk wanneer je grote hoeveelheden data moet coderen voor tickets, ID's of verzendlabels. Deze tutorial behandelt de volledige workflow — van het installeren van de bibliotheek tot het opslaan van de uiteindelijke PNG — zodat je de code kunt kopiëren‑plakken in je eigen project en direct kunt uitvoeren.

## Vereisten voor het genereren van PDF417 barcode

* .NET 6.0 (of later) geïnstalleerd.  
* Visual Studio 2022 of een IDE die C#‑projecten ondersteunt.  
* Een NuGet‑licentie voor **Aspose.Barcode for .NET** (de gratis proefversie werkt voor leren).  

Je kunt de bibliotheek toevoegen met het volgende commando:

```bash
dotnet add package Aspose.BarCode
```

> **Pro tip:** Gebruik de `--version`‑vlag om een bekende stabiele versie vast te zetten, bijv. `dotnet add package Aspose.BarCode --version 23.12`.

## Maak een PDF417 barcode‑generator

Het eerste code‑blok maakt een `BarcodeGenerator`‑instance die vooraf geconfigureerd is voor de PDF417‑symbologie. De tekst `"Åspóse.Barcóde©"` bevat Unicode‑tekens om te laten zien dat de generator non‑ASCII invoer direct ondersteunt.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Waarom dit belangrijk is
`EncodeTypes.Pdf417` vertelt Aspose.Barcode dat je een **PDF417 barcode** wilt, wat een gestapelde lineaire symbologie is die tot 1 850 tekens kan opslaan. Het gebruiken van de constructor met het tekstargument bespaart je een latere aanroep van `SetCodeText`.

## Stel de barcode XDimension (modulegrootte) in

De modulegrootte, ook wel X‑dimension genoemd, bepaalt hoe breed elke individuele balk is. Kleinere pixels produceren een dichtere afbeelding, terwijl grotere pixels de leesbaarheid op low‑resolution printers verbeteren.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### Waarom je XDimension moet aanpassen
Een waarde van `2` pixels werkt goed voor weergave op schermen en de meeste kantoorp printers. Als je een hogere resolutie‑print nodig hebt, verhoog dan de waarde; als je een compactere barcode wilt (bijv. voor een QR‑achtige uitstraling), verlaag deze — maar nooit onder `1` pixel, anders wordt de afbeelding onleesbaar.

## Stel het aantal kolommen in voor het PDF417‑symbool

PDF417 laat je kiezen hoeveel kolommen (verticale stapels) de barcode zal hebben. Minder kolommen maken de barcode hoger; meer kolommen maken hem breder.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### Wanneer je het aantal kolommen moet wijzigen
Drie kolommen produceren een compact, bijna vierkant symbool dat goed past op standaard ID‑kaarten. Als je een zeer lange string hebt, kun je het aantal kolommen verhogen om de hoogte redelijk te houden.

## Schakel compacte modus in (truncatie)

Compacte modus verwijdert automatisch ongebruikte rijen uit het symbool, waardoor de totale grootte wordt verkleind. Dit is vooral nuttig wanneer de gecodeerde data niet de volledige matrix vult.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Voordelen van een compacte PDF417 barcode
Wanneer `Truncate` `true` is, berekent de generator het minimale aantal rijen dat nodig is om je data op te slaan, wat het inktverbruik en de scantijd vermindert. Het is veilig voor de meeste scanners omdat de PDF417‑specificatie het truncatie‑algoritme definieert.

## Sla de gegenereerde barcode op als afbeelding

Schrijf tenslotte de barcode naar een PNG‑bestand. PNG behoudt lossless kwaliteit, waardoor het ideaal is voor later afdrukken of inbedden in PDF's.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Verwachte output
Het uitvoeren van het programma maakt `CompactPdf417.png` aan in de opgegeven map. De afbeelding bevat een **compacte PDF417 barcode** die de string `"Åspóse.Barcóde©"` codeert met drie kolommen, een X‑dimension van 2 pixels, en toegepaste truncatie. Je kunt het resultaat verifiëren met elke barcode‑scanner‑app of de gratis Aspose.Barcode online demo.

## Veelvoorkomende variaties en randgevallen

| Situatie | Aanpassing |
|-----------|------------|
| **Zeer lange data (> 1500 tekens)** | Verhoog `Columns` of stel `Rows` handmatig in (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Afdrukken op een low‑dpi printer** | Verhoog `XDimension.Pixels` naar 3 of 4 om pixelatie te voorkomen. |
| **Transparante achtergrond nodig** | Gebruik `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **Inbedden in een PDF** | Sla op als `BarCodeImageFormat.Pdf` of verkrijg het `Image`‑object via `pdf417Generator.GenerateBarCodeImage()`. |

## Volledig, uitvoerbaar voorbeeld

Hieronder staat het volledige programma dat je kunt kopiëren naar een nieuw console‑project. Er zijn geen extra bestanden nodig.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Voer `dotnet run` uit vanuit de projectmap. Na uitvoering, open `CompactPdf417.png` om de gegenereerde barcode te zien.

## Conclusie

Je weet nu hoe je een **PDF417 barcode** kunt **genereren** in C# met volledige controle over kolommen, X‑dimension en compacte modus. Door de `barcode XDimension pixels`, `set PDF417 columns` aan te passen en `compact PDF417 barcode` truncatie in te schakelen, kun je een barcode produceren die precies aan de grootte‑eisen van je applicatie voldoet.

Volgende stappen die je kunt verkennen:

* Encode grotere datasets en experimenteer met de `Rows`‑parameter.  
* Schakel het uitvoerformaat naar `BarCodeImageFormat.Svg` voor schaalbare web‑graphics.  
* Combineer de barcode met andere Aspose‑componenten, zoals **Aspose.PDF**, om de afbeelding direct in een PDF‑rapport in te bedden.

Veel plezier met coderen, en voel je vrij om de instellingen aan te passen aan je specifieke scanomgeving!
