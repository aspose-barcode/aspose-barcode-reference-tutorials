# Hoe PDF417 barcode te genereren in C# – compact voorbeeld

Als je een **PDF417 barcode wilt genereren** in een C#‑applicatie, laat deze gids je een complete, kant‑klaar oplossing zien. We maken een compacte PDF417 barcode, passen de module‑breedte aan, definiëren het aantal kolommen en slaan het resultaat op als een PNG‑afbeelding – alles met de Aspose.BarCode .NET‑bibliotheek.

Het genereren van een PDF417 barcode is gebruikelijk wanneer je grote hoeveelheden data (bijv. URL’s, contactkaarten of voorraad‑ID’s) wilt coderen in een ruimte‑efficiënt tweedimensionaal formaat. Aan het einde van deze tutorial heb je een werkende `BarcodeGenerator`‑instantie die een compacte, goed leesbare barcode produceert, klaar voor afdrukken of weergave.

## Vereisten

- .NET 6.0 of later (de code werkt ook met .NET Framework 4.8)
- Visual Studio 2022 (of een andere C#‑IDE)
- Aspose.BarCode for .NET NuGet‑pakket (`Install-Package Aspose.BarCode`)
- Basiskennis van C#‑syntaxis

Er is geen extra configuratie nodig; het voorbeeld draait als een console‑applicatie.

## Stap 1: Maak een PDF417 barcode‑generator

De eerste stap is om `BarcodeGenerator` te instantieren met de `EncodeTypes.Pdf417`‑enum en de tekst die je wilt coderen.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Waarom dit belangrijk is:** `EncodeTypes.Pdf417` vertelt de bibliotheek om de PDF417‑symbologie te gebruiken, terwijl het tweede argument de gegevenspayload instelt. Je kunt `"Compact example"` vervangen door elke string tot 1 800 tekens.

## Stap 2: Stel de module‑breedte (X‑dimensie) in pixels in

De X‑dimensie bepaalt de breedte van één barcode‑module (het kleinste zwarte of witte vierkant). Een kleinere pixelwaarde levert een strakkere barcode op.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Waarom dit belangrijk is:** Een waarde van `2` pixels creëert een compact uiterlijk zonder de scan‑betrouwbaarheid op de meeste moderne scanners te schaden. Pas de waarde aan als je grotere modules nodig hebt voor low‑resolution afdrukken.

## Stap 3: Geef het aantal kolommen op

PDF417 laat je het aantal kolommen bepalen, wat de beeldverhouding van de barcode beïnvloedt.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Waarom dit belangrijk is:** Minder kolommen maken de barcode hoger, terwijl meer kolommen deze platter maken. Drie kolommen werken goed voor een compact, staand (portrait) ontwerp.

## Stap 4: Schakel compacte modus in door de barcode te trunceren

Compacte modus verwijdert overbodige opvul‑rijen, waardoor de barcode kleiner wordt terwijl de gecodeerde data behouden blijft.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Waarom dit belangrijk is:** Truncatie is ideaal wanneer schermruimte beperkt is (bijv. mobiele apps of kleine labels). De barcode blijft volledig leesbaar omdat het coderingsalgoritme automatisch de fout‑correctieniveaus aanpast.

## Stap 5: Sla de barcode op als PNG‑afbeelding

Schrijf tenslotte de gegenereerde barcode naar een bestand. PNG behoudt lossless kwaliteit, wat essentieel is voor barcodescanners.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Het uitvoeren van het programma maakt `CompactPdf417.png` aan in de werkmap van het uitvoerbare bestand. De afbeelding ziet er als volgt uit:

![Generated compact PDF417 barcode](CompactPdf417.png "Generated compact PDF417 barcode")

**Verwacht resultaat:** Een 2‑pixel‑brede, drie‑koloms PDF417 barcode die de tekst “Compact example” codeert. Het scannen van de PNG met een standaard barcodescanner moet de oorspronkelijke string teruggeven.

## Veelvoorkomende variaties en randgevallen

| Situatie | Hoe de code aan te passen |
|-----------|----------------------------|
| **Langere data ( > 500 tekens )** | Verhoog `Columns` naar 5‑7 om te voorkomen dat de barcode te hoog wordt. |
| **Hogere‑resolutie afdrukken** | Stel `XDimension.Pixels` in op 3 of 4 voor grotere modules. |
| **Ander afbeeldingsformaat** | Vervang `BarCodeImageFormat.Png` door `Jpeg` of `Bmp` naar behoefte. |
| **Barcode in een PDF insluiten** | Gebruik `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` in plaats van PNG. |

**Pro tip:** Test de gegenereerde barcode altijd op de beoogde scannerhardware. Sommige goedkope scanners hebben moeite met zeer kleine X‑dimensies; als je leesfouten tegenkomt, verhoog dan de pixelwaarde met één stap.

## Volledig, uitvoerbaar voorbeeld

Hieronder vind je het volledige programma dat je kunt kopiëren‑plakken in een nieuw console‑project. Er zijn geen extra bestanden nodig.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Compileer en voer het programma uit (`dotnet run` als je de .NET CLI gebruikt). Na uitvoering open je `CompactPdf417.png` om het visuele resultaat te verifiëren.

## Conclusie

Je weet nu **hoe je een PDF417 barcode genereert** in C# met een compact layout, aangepaste X‑dimensie en kolominstellingen. Het voorbeeld toont de essentiële stappen: `BarcodeGenerator` instantieren, `XDimension` en `Columns` configureren, `Truncate` inschakelen voor compacte modus, en tenslotte de afbeelding opslaan.

Vanaf hier kun je extra functies verkennen, zoals fout‑correctieniveau, aangepaste kleuren, of het direct insluiten van de barcode in PDF‑bestanden. Experimenteer met verschillende `EncodeTypes` als je andere symbologieën nodig hebt (bijv. QR, Code128) en pas hetzelfde patroon van parameterconfiguratie toe.

Veel programmeerplezier, en moge je barcodes altijd bij de eerste poging scannen!
