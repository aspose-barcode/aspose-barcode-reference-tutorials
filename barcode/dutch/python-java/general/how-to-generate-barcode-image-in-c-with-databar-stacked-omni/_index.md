# Hoe een barcode‑afbeelding te genereren in C# met DataBar Stacked Omni‑Directional

Als je **hoe een barcode‑afbeelding te genereren** in een .NET‑applicatie nodig hebt, laat deze tutorial de exacte stappen zien. Je ziet hoe je een DataBar Stacked Omni‑Directional barcode maakt, de beeldverhouding aanpast en het resultaat exporteert als PNG‑bestanden.

Het genereren van barcodes is een veelvoorkomende eis voor voorraadsystemen, retail‑kassa’s en logistiek‑tracking. In de volgende secties behandelen we alles wat je nodig hebt – van het vereiste NuGet‑pakket tot de uiteindelijke beeldverificatie – zodat je barcode‑creatie vandaag nog in elk C#‑project kunt integreren.

## Vereisten

* .NET 6.0 of later (de code werkt met .NET Core en .NET Framework)  
* Visual Studio 2022 of een andere C#‑IDE die je verkiest  
* Het **Aspose.BarCode for .NET** NuGet‑pakket (installeren met `dotnet add package Aspose.BarCode`)  
* Schrijfrechten op de map waar de PNG‑bestanden worden opgeslagen  

Deze vereisten garanderen dat het voorbeeld zonder extra configuratie draait.

## Stap 1: Maak de uitvoermap aan

Het eerste wat je nodig hebt is een map waarin de gegenereerde PNG‑bestanden worden weggeschreven. Een absoluut of relatief pad werkt, maar zorg ervoor dat de map bestaat voordat je `Save` aanroept.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Het programmatic maken van de map voorkomt *FileNotFoundException* wanneer de `Save`‑methode probeert het beeld te schrijven.

## Stap 2: Maak een DataBar Stacked Omni‑Directional barcode‑generator

De **BarcodeGenerator**‑klasse is het toegangspunt voor alle barcode‑typen. Hier geven we `EncodeTypes.DatabarStackedOmniDirectional` op en de gegevensreeks die we willen coderen.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Waarom dit belangrijk is*: De `EncodeTypes`‑enum vertelt de bibliotheek welke symbologie moet worden gerenderd. Het gebruik van de Omni‑Directional‑variant zorgt ervoor dat de barcode vanuit elke oriëntatie kan worden gescand – een vereiste voor veel magazijnscanners.

## Stap 3: Configureer algemene barcode‑parameters

Een leesbare barcode heeft een verstandige X‑dimension (de breedte van de kleinste staaf) nodig. Het instellen van `Pixels` op 2 geeft een goede balans tussen grootte en helderheid voor de meeste schermresoluties.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Je kunt `Pixels` later aanpassen als je een groter of kleiner beeld nodig hebt; de bibliotheek schaalt de rest van de barcode automatisch.

## Stap 4: Genereer de eerste afbeelding met beeldverhouding 15

De **aspect ratio** bepaalt de hoogte‑tot‑breedte‑verhouding van DataBar‑barcodes. Een aspect ratio van 15 is een typische standaard voor retail‑labels.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Na deze aanroep vind je `DatabarAspectRatio15.png` in de uitvoermap. De afbeelding is een lossless PNG, geschikt voor verdere verwerking of afdrukken.

## Stap 5: Verander de beeldverhouding naar 30 en exporteer een tweede afbeelding

Soms is een hogere barcode vereist – bijvoorbeeld wanneer de labelhoogte beperkt is. Het wijzigen van de aspect ratio naar 30 levert een compacter beeld op terwijl de gegevensintegriteit behouden blijft.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Nu heb je twee PNG‑bestanden die laten zien hoe dezelfde data eruitziet met verschillende beeldverhoudingen. Deze naast‑elkaar‑vergelijking helpt je te bepalen welke variant het beste bij je label‑layout past.

## Volledig, uitvoerbaar voorbeeld

Hieronder staat het volledige programma dat je kunt kopiëren, plakken en uitvoeren. Het bevat alle `using`‑directives, foutafhandeling en commentaren die elk onderdeel van het proces uitleggen.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Verwachte output** (console):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Open de twee PNG‑bestanden in een willekeurige afbeeldingsviewer. Je ziet dezelfde GTIN gecodeerd, maar de tweede afbeelding is hoger vanwege de grotere aspect ratio.

## Pro‑tips en veelvoorkomende valkuilen

| Situatie | Aanbeveling |
|-----------|----------------|
| **Weergaven met lage resolutie** | Verhoog `XDimension.Pixels` naar 3 of 4 om de staven scherp te houden. |
| **Printen op thermisch papier** | Gebruik `BarCodeImageFormat.Tiff` voor hogere nauwkeurigheid en stel `Resolution.DpiX/DpiY` in op 300. |
| **Dynamische data** | Her‑gebruik dezelfde `BarcodeGenerator`‑instantie en werk alleen `generator.CodeText` bij vóór elke `Save`. Dit voorkomt onnodige objectallocatie. |
| **Ongeldige GTIN** | De bibliotheek gooit een `ArgumentException` als de data niet voldoet aan de GS1‑normen. Valideer je data voordat je deze aan de generator doorgeeft. |
