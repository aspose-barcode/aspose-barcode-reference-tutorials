# Hoe maak je een RM4SCC-barcode en genereer je een planet-barcode in C#

Als je een **RM4SCC-barcode** moet maken voor posttoepassingen, laat deze gids je de exacte stappen zien. Je leert ook hoe je een **planet-barcode** kunt **genereren** met zowel automatische als vaste hoogtes, zodat dezelfde code werkt voor elke post‑symbologie.

De tutorial behandelt alles wat nodig is om PNG‑afbeeldingen te produceren die voldoen aan de postnormen. Er zijn geen externe tools nodig, behalve de Aspose.BarCode for .NET‑bibliotheek. Aan het einde kun je barcodes programmatisch genereren en hun afmetingen nauwkeurig regelen.

## Vereisten

Voordat je begint, zorg ervoor dat je het volgende hebt:

* .NET 6.0 of later geïnstalleerd
* Visual Studio 2022 (of een andere C# IDE)
* Aspose.BarCode for .NET NuGet‑pakket  
  `Install-Package Aspose.BarCode`
* Schrijfrechten voor de uitvoermap

Deze items stellen je in staat om de voorbeeldcode te compileren en uit te voeren zonder extra configuratie.

## Stap 1: Initialiseer de barcodegenerator voor RM4SCC

De eerste bewerking maakt een `BarcodeGenerator`‑instantie aan die is geconfigureerd voor de RM4SCC‑symbologie. Dit object bevat alle instellingen voor de barcode‑afbeelding.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Waarom dit belangrijk is** – `EncodeTypes.RM4SCC` vertelt Aspose om het postale RM4SCC‑formaat te gebruiken, terwijl de gegevensreeks `"123456"` de postcode vertegenwoordigt die je wilt coderen.

## Stap 2: Stel de modulebreedte (X‑dimensie) in

De modulebreedte bepaalt de grootte van de dunne balk. Een veelgebruikte waarde voor post‑barcodes is 4 pixels.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Uitleg** – De X‑dimensie beïnvloedt de algehele leesbaarheid van de barcode. Het kiezen van 4 px komt overeen met de meeste post‑scanners.

## Stap 3: Opslaan met automatische balkhoogte

Wanneer je geen hoogte opgeeft, berekent Aspose de optimale hoogte automatisch op basis van de symbologie‑regels.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Resultaat** – De gegenereerde PNG (`PostalRM4SCCBarHeightNone.png`) bevat een correct geschaalde RM4SCC‑barcode die klaar is om af te drukken.

## Stap 4: Maak een Planet-barcode met automatische hoogte

Hetzelfde patroon werkt voor de Planet‑symbologie. Begin met het initialiseren van de generator met `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Waarom de code hergebruiken** – Zowel RM4SCC als Planet delen dezelfde parameterstructuur, zodat je van symbologie kunt wisselen door alleen de `EncodeTypes`‑waarde te wijzigen.

## Stap 5: Definieer een vaste balkhoogte voor RM4SCC

Sommige postdiensten vereisen een specifieke balkhoogte (bijv. 100 px). Je kunt deze expliciet instellen vóór het opslaan.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Tip** – Het instellen van `BarHeight.Pixels` overschrijft de automatische berekening, waardoor je volledige controle krijgt over de visuele grootte.

## Stap 6: Definieer een vaste balkhoogte voor Planet

Pas dezelfde vaste‑hoogte‑techniek toe op een Planet‑barcode.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Resultaat** – Zowel `PostalRM4SCCBarHeight100Pixels.png` als `PostalPlanetBarHeight100Pixels.png` bevatten barcodes met een consistente balkhoogte van 100 px, wat voldoet aan strikte postspecificaties.

## Volledige broncode

Hieronder staat het volledige, uitvoerbare programma dat alle vier voorbeelden omvat. Kopieer het naar een nieuw console‑project en pas het uitvoerpad naar behoefte aan.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Verwacht resultaat** – Na het uitvoeren van het programma bevat de opgegeven map vier PNG‑bestanden:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC met automatische hoogte
* `PostalPlanetBarHeightNone.png` – Planet met automatische hoogte
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC met 100 px hoogte
* `PostalPlanetBarHeight100Pixels.png` – Planet met 100 px hoogte

Open een bestand om te verifiëren dat de balken scherp zijn, de modulebreedte 4 px is en de hoogte overeenkomt met de gekozen instelling.

## Veelgestelde vragen en randgevallen

| Vraag | Antwoord |
|----------|--------|
| **Kan ik andere afbeeldingsformaten gebruiken?** | Ja. Vervang `BarCodeImageFormat.Png` door `Jpeg`, `Bmp` of `Gif` indien nodig. |
| **Wat als de gegevensreeks langer is?** | De generator past automatisch het aantal balken aan. Zorg ervoor dat de gegevens voldoen aan de lengtebeperkingen van de symbologie (RM4SCC ≤ 6 cijfers, Planet ≤ 6 cijfers). |
| **Hoe wijzig ik de balkkleur?** | Stel `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` in vóór het aanroepen van `Save`. |
| **Is DPI belangrijk voor afdrukken?** | Je kunt `rm4sccAuto.Parameters.ImageResolution.DpiX` en `DpiY` instellen om overeen te komen met de resolutie van je printer. |
