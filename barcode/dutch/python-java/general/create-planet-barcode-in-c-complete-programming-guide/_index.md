# Planet-barcode maken in C# – volledige programmeergids

Als je een **planet-barcode** in C# moet **maken**, laat deze gids je precies zien hoe. Je ontdekt ook **hoe je de afmetingen van de barcode instelt** zodat de strepen exact de gewenste breedte hebben.

Het genereren van Planet-barcodes komt vaak voor bij postdiensten of logistieke systemen. De code hieronder behandelt zowel de standaard versie met gevulde strepen als de optionele versie met lege strepen, plus een snel voorbeeld voor het RM4SCC‑formaat. Aan het einde van deze tutorial heb je een herbruikbaar fragment dat je in elk .NET‑project kunt gebruiken.

## Vereisten

Voordat je begint, zorg dat je het volgende hebt:

* .NET 6.0 of hoger geïnstalleerd (de API werkt ook met .NET Framework 4.6+)
* Het **Aspose.BarCode for .NET** NuGet‑pakket (`Aspose.BarCode`) aan je project toegevoegd
* Een schrijfbare map waar de PNG‑bestanden worden opgeslagen
* Basiskennis van C#‑syntaxis en Visual Studio (of een andere IDE)

> **Pro tip:** Gebruik een absoluut pad of `Path.Combine(Environment.CurrentDirectory, "output")` om machtigingsproblemen bij het opslaan van afbeeldingen te voorkomen.

## Stap 1 – Initialiseer een Planet‑barcodegenerator (gevulde strepen)

De eerste stap is het aanmaken van een `BarcodeGenerator`‑instantie voor de Planet‑symbologie. Standaard genereert de generator **gevulde** strepen.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

De `EncodeTypes.Planet`‑enum vertelt Aspose.BarCode om het Planet‑formaat te gebruiken, terwijl `"123456"` de gegevenspayload is die wordt gecodeerd.

## Stap 2 – Hoe je de afmetingen van de barcode instelt voor consistente grootte

Om de breedte van elke streep te regelen, pas je de **X‑dimensie** aan. Dit is de primaire manier om **de afmetingen van de barcode in te stellen** en zorgt ervoor dat de barcode in je label past.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

De eigenschap `Pixels` bepaalt de streepbreedte in schermpixels. Veelvoorkomende waarden zijn 2 – 5 pixels voor standaard postlabels; verhoog de waarde voor grotere afdrukken.

## Stap 3 – Sla de gevulde Planet‑barcode op als PNG

Schrijf nu de afbeelding naar schijf. PNG behoudt scherpe randen, wat ideaal is voor scannen.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Vervang `YOUR_DIRECTORY` door het pad dat je eerder hebt voorbereid. Na het uitvoeren van deze code zie je een bestand dat lijkt op de afbeelding hieronder.

## Stap 4 – Maak een Planet‑barcode met lege (ongevulde) strepen

Als je postdienst vereist dat de strepen **leeg** zijn, moet je de `FilledBars`‑vlag omzetten na het initialiseren van de generator.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

De constructor is identiek; het verschil zit in de volgende configuratiestap.

## Stap 5 – Hoe je de afmetingen van de barcode instelt en strepen leeg maakt

Stel opnieuw de X‑dimensie in voor visuele consistentie, en schakel vervolgens de gevulde strepen uit.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

De eigenschap `FilledBars = false` is wat daadwerkelijk de weergavestijl wijzigt. Het behouden van dezelfde X‑dimensie zorgt ervoor dat de barcode met lege strepen perfect op één lijn ligt met de versie met gevulde strepen.

## Stap 6 – Sla de lege Planet‑barcode op

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Je hebt nu twee PNG‑bestanden: één met solide strepen en één met holle strepen, beide met dezelfde afmetingen.

## Stap 7 – (Optioneel) Genereer een RM4SCC‑barcode ter vergelijking

RM4SCC is een andere post‑symbologie die dezelfde standaard gevulde‑streep‑stijl gebruikt. De stappen spiegelen het Planet‑voorbeeld, waarmee wordt aangetoond dat **hoe je de afmetingen van de barcode instelt** werkt voor verschillende formaten.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Het uitvoeren van deze drie stappen produceert `PostalRM4SCCFilledBars.png`, die je naast de Planet‑uitvoer kunt vergelijken.

## Waarom X‑dimensie belangrijk is

De X‑dimensie bepaalt de **minimale afdrukbare breedte** van elke streep. Als je deze te laag instelt, kan de barcode vervagen op laag‑resolutieprinters, wat scan‑fouten veroorzaakt. Omgekeerd kan een te grote X‑dimensie de labelafmetingen overschrijden en ruimte verspillen. Door expliciet **hoe je de afmetingen van de barcode instelt** te bepalen, krijg je deterministische controle over de uiteindelijke afbeeldingsgrootte, wat essentieel is voor geautomatiseerde postprocessen.

## Veelvoorkomende valkuilen en hoe ze te vermijden

| Probleem | Oorzaak | Oplossing |
|----------|---------|-----------|
| Barcode lijkt uitgerekt | X‑dimensie ingesteld in points in plaats van pixels | Gebruik altijd de `Pixels`‑eigenschap voor pixel‑perfecte controle |
| Lege strepen zien er toch gevuld uit | `FilledBars` niet op `false` gezet na wijziging van X‑dimensie | Zet `FilledBars = false` *na* het aanpassen van de X‑dimensie |
| Opgeslagen bestand is leeg | Doelmap bestaat niet of heeft geen schrijfrechten | Zorg dat de map bestaat (`Directory.CreateDirectory`) en dat je app voldoende rechten heeft |
| Afbeelding is onscherp bij afdrukken | Lage DPI PNG opgeslagen vanaf een hoge‑resolutie monitor | Gebruik `BarCodeImageFormat.Png` (lossless) en overweeg de `Resolution`‑eigenschap indien nodig |

## Volledig, uitvoerbaar voorbeeld

Kopieer het volledige blok hieronder naar een nieuw console‑project (`dotnet new console`) en voer het uit. Het programma maakt drie PNG‑bestanden aan in de map `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Verwachte output:** drie PNG‑bestanden—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` en `PostalRM4SCCFilledBars.png`—elk met 4‑pixel brede strepen, klaar voor afdrukken of verdere verwerking.

## Conclusie

Je weet nu hoe je een **planet‑barcode** in C# kunt **maken** en precies **hoe je de afmetingen van de barcode instelt** voor zowel gevulde als lege streep‑stijlen. Hetzelfde patroon geldt voor andere symbologieën zoals RM4SCC, waardoor je een flexibele basis hebt voor elke post‑barcode‑vereiste.

Vervolgens kun je verkennen:

* Het toevoegen van menselijk leesbare tekst onder de barcode (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* Het wijzigen van de kleur van de strepen met `Parameters.Barcode.BarColor`
* Het genereren van barcodes in vectorformaten (SVG, EPS) voor schaalbare afdrukken

Voel je vrij om te experimenteren met verschillende X‑dimensie‑waarden, gegevensreeksen en uitvoerformaten om ze aan jouw specifieke workflow aan te passen. Veel programmeerplezier!
