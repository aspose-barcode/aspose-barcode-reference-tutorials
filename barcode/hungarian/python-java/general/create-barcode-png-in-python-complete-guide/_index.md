## Create barcode PNG – Setting Up the Generator

Első lépésként szükségünk van egy generátor objektumra, amely tudja, hogy egy **DataBar Omnidirectional** barkódról van szó. Az alábbi kód importálja a szükséges osztályokat, létrehozza a generátort egy **barcode with sample data**‑val, és beállít egy szerény modulméretet.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Miért fontos:** Az `EncodeTypes.DATABAR_OMNIDIRECTIONAL` azt mondja a motornak, hogy egy **DataBar**‑t állítson elő, amely bármely irányból olvasható, tökéletes a kiskereskedelmi polcokhoz. Az `x_dimension` éles sávokat biztosít, míg a `bar_height` a kód vizuális méretét szabályozza.

## How to Generate Databar with Sample Data

Most, hogy a generátor készen áll, **create barcode PNG** fájlokat hozunk létre. Az első mentés 30 pixel magasságot használ, ami gyakran elegendő a képernyőn megjelenő előnézethez.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

A szkript futtatása eddig egy PNG fájlt eredményez, amely egy kompakt, nagy kontrasztú barkódot mutat. Nyisd meg bármely képnézőben, hogy ellenőrizd, a sávok élesek és a GTIN‑14 adat kódolva van.

## Adjust Barcode Height (How to Change Barcode)

Néha magasabb barkódra van szükség nagyobb címkékhez vagy nagy felbontású nyomtatáshoz. Itt jön képbe a **adjust barcode height**. A magasság módosítása egyszerűen a `BarHeight` tulajdonság frissítésével és újra mentéssel történik.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Hogyan működik:** A generátor újra felhasználja ugyanazt az adatot és modulméretet; csak a függőleges dimenzió változik. Ez elkerüli az objektum teljes újra létrehozását, és bemutatja, hogyan lehet **how to change barcode** beállításokat dinamikusan módosítani.

## Full Script – One‑Stop Solution

Az alábbiakban a teljes, futtatható szkript található, amely összegzi az összes lépést. Másold, illeszd be, és futtasd – a csomag telepítése után azonnal működni fog.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

- `DatabarOmni60.png` – 60 px magas változat ugyanabból a barkódból.

## Common Pitfalls & Pro Tips

- **Pixel vs. DPI:** A PNG fájlok pixel‑alapúak. Ha konkrét nyomtatási méretre van szükséged, számold ki a `BarHeight`‑t DPI alapján (pl. 300 dpi → 30 px ≈ 0,1 in).  
- **Incorrect encoding:** Győződj meg róla, hogy az adatkarakterlánc a GS1 Application Identifier formátumot követi (`(01)` a GTIN‑14‑hez). A zárójelek hiánya miatt a könyvtár egyszerű numerikus barkódra vált.  
- **File paths:** Használj raw stringeket (`r"..."`) vagy dupla backslash‑t Windows alatt, hogy elkerüld a escape‑karakter problémákat.  
- **Performance:** Ha több ezer barkódot generálsz, hozd létre a generátort egyszer, és csak a `BarHeight`‑t vagy az adatkarakterláncot módosítsd a mentések között. Ez csökkenti a memóriahasználatot.
