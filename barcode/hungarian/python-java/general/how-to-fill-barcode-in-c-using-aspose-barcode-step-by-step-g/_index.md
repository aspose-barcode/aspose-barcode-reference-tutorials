# Hogyan töltsünk ki vonalkódot C#-ban az Aspose.BarCode használatával

Ha **hogyan töltsünk ki vonalkódot** kell egy .NET alkalmazásban, ez a bemutató a teljes folyamatot mutatja be. Létrehozhat egy postai Planet vonalkódot szilárd vonalakkal, majd ugyanabból a vonalkódból egy üres‑vonallal rendelkező változatot, mindezt egyetlen kódsor módosításával.

Az útmutató mindent lefed, amit tudni kell: projekt beállítása, X‑dimenzió finomhangolása, a kitöltött és üres vonalak közötti váltás, valamint a generált PNG fájlok ellenőrzése. Külső dokumentáció nem szükséges – csak másolja a kódot, futtassa, és láthatja az eredményt.

## Előfeltételek

* .NET 6.0 SDK vagy újabb telepítve  
* Fejlesztői környezet, például Visual Studio 2022 vagy VS Code  
* A **Aspose.BarCode for .NET** NuGet csomag (`Aspose.BarCode`)  

Ezek az elemek alkotják a **barcode generator c#** rész minimális alapját a bemutatóban.

## Hogyan töltsünk ki vonalkódot – a projekt beállítása

1. Hozzon létre egy új konzolos projektet:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Adja hozzá az Aspose.BarCode csomagot:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Nyissa meg a generált `Program.cs` fájlt, és cserélje ki a tartalmát a később ebben a cikkben bemutatott teljes példával.

A projekt most már mindent tartalmaz, ami a **generate postal barcode** képekhez szükséges.

## Postai vonalkód generálása szilárd vonalakkal

Az első lépés egy Planet vonalkód létrehozása, amely kitöltött (szilárd) vonalakat használ. A Planet a sok postai szolgáltató által a rendezéshez használt szimbólum.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Miért fontosak ezek a sorok**

* `EncodeTypes.Planet` megmondja a generátornak, melyik szimbólumot használja; a Planet a postai vonalkódok szabványa.  
* `XDimension.Pixels = 4` növeli a modul szélességét, így a vonalkód könnyebben beolvasható és nyomtatáskor vizuálisan tisztább.  
* `Save` PNG formátumban írja a képet a lemezre, egy veszteségmentes formátum, amely alkalmas további feldolgozásra.

A blokk futtatása **PostalPlanetFilledBars.png** fájlt hoz létre, egy szilárd vonalakkal rendelkező képet, amely megfelel a postai előírásoknak.

## Üres vonalkód létrehozása a Planet szimbólummal

Néha egy postai rendszer azt várja, hogy a vonalak üresek (nem kitöltöttek) legyenek, míg a szóközök szilárdak maradnak. Ebbe a módba való váltáshoz csak egy tulajdonság módosítása szükséges.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Miért működik ez**

A `FilledBars = false` beállítás azt mondja a renderelőnek, hogy fordítsa meg a vizuális stílust: a vonalak átlátszóvá (üressé) válnak, a háttér pedig átlátszatlanná. Ez pontosan az ellenkezője az előzőleg bemutatott alapértelmezett viselkedésnek, lehetővé téve, hogy **create empty barcode** képeket készítsen a kódolt adatok módosítása nélkül.

## Teljes, futtatható példa

Az alábbiakban a teljes program látható, amely egyesíti a két szekciót. Másolja be a `Program.cs` fájlba, cserélje le a `YOUR_DIRECTORY/`-t egy valós mappára, és futtassa a `dotnet run` parancsot.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Várt kimenet

A futtatás után a megadott mappában két PNG fájlt talál:

| File name                     | Visual description |
|-------------------------------|--------------------|
| `PostalPlanetFilledBars.png`  | A vonalak fekete szilárdak fehér háttéren |
| `PostalPlanetEmptyBars.png`   | A vonalak átlátszóak (fehérek) fekete háttéren |

Mindkét kép ugyanazt a numerikus karakterláncot (`"123456"`) kódolja, és ugyanazt az X‑dimenziót használja, biztosítva, hogy adat‑validációs szempontból cserélhetők legyenek.

## Gyakori kérdések és szélhelyzetek

**Mi van, ha a kimeneti mappa nem létezik?**  
A `Save` metódus `DirectoryNotFoundException`-t dob. Hozza létre a mappát előre, vagy helyezze a hívásokat egy `try / catch` blokkba, amely szükség esetén létrehozza a könyvtárat:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Használhatok másik képformátumot?**  
Igen. Cserélje le a `BarCodeImageFormat.Png`-t `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` vagy bármely, az Aspose.BarCode által támogatott formátumra.

**Hatással van az X‑dimenzió a szkenner olvashatóságára?**  
A pixel szélesség növelése szélesebb vonalakat eredményez, ami javíthatja az olvashatóságot alacsony felbontású szkennereknél. Ugyanakkor nagyon nagy értékek meghaladhatják a nyomtatható területet. A tipikus értékek 2‑6 pixel 300 dpi nyomtatáshoz.

**Csak a `EncodeTypes.Planet` szimbólum a postai egyetlen lehetőség?**  
Nem. Az Aspose.BarCode támogatja a `EncodeTypes.Postnet` és `EncodeTypes.USPSIntelligentMail` szimbólumokat is. A `FilledBars` tulajdonság ugyanúgy működik ezeknél a típusoknál is.
