# Hogyan mentse el a vonalkód képeket C#-ban a BarcodeGenerator API használatával

Ha **how to save barcode** fájlokat kell menteni egy .NET alkalmazásból, ez az útmutató pontos lépéseket mutat. Megtekint egy teljes **barcode generator example**-t, amely DataBar Stacked Omnidirectional vonalkódot hoz létre, beállítja annak képarányát, és két PNG fájlt ment.

A vonalkód képek mentése gyakori követelmény készletkezelő rendszerek, értékesítési pont terminálok vagy automatizált címkézési munkafolyamatok építésekor. A tutorial végére képes lesz barcode C# kódot generálni, amely megbízható képeket hoz létre, készen állva a nyomtatásra vagy megjelenítésre.

## Előfeltételek

- .NET 6.0 SDK vagy újabb telepítve  
- Visual Studio 2022 (vagy bármely C#‑kompatibilis IDE)  
- **Aspose.BarCode for .NET** NuGet csomag (a kód a `Aspose.BarCode.Generation`-t használja)  

A csomagot a következő paranccsal adhatja hozzá:

```bash
dotnet add package Aspose.BarCode
```

## 1. lépés: Minimalista C# konzolprojekt beállítása

Hozzon létre egy új konzolprojektet, és hivatkozzon a könyvtárra:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Nyissa meg a `Program.cs`-t. A fájl tartalmazni fogja a `Main` metódust, ahol elhelyezzük a **generate barcode C#** logikát.

## 2. lépés: A BarcodeGenerator inicializálása DataBar Stacked Omnidirectional vonalkódhoz

Az első feladat bármely **create databar barcode** munkafolyamatban a `BarcodeGenerator` példányosítása a megfelelő `EncodeType`-tal. A konstruktor megkapja a vonalkód szimbólumát és az adatkarakterláncot.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

A `EncodeTypes.DatabarStackedOmniDirectional` érték azt mondja a könyvtárnak, hogy **create databar barcode**-t állítson elő, amely bármely irányból beolvasható.

## 3. lépés: Az X‑dimenzió (modul szélesség) beállítása

Az X‑dimenzió szabályozza a legkisebb vonal szélességét pixelben. Alacsony értékre állítva a vonalkód kompakt marad, miközben megőrzi az olvashatóságot.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## 4. lépés: **How to adjust aspect ratio** – első érték (15)

A DataBar vonalkódok egy `AspectRatio` tulajdonságot biztosítanak, amely befolyásolja a magasság‑szélesség arányt. A magasabb arány magasabb vonalkódot eredményez, ami javíthatja a beolvasási megbízhatóságot bizonyos nyomtatókon.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## 5. lépés: **How to save barcode** – első kép (aspect ratio 15)

Most ténylegesen **how to save barcode** egy fájlba. A `Save` metódus egy fájlútvonalat és egy képformátumot vár. Ebben a példában PNG fájlt tárolunk.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Tip:** A végrehajtható fájl könyvtára az alapértelmezett írási hely. Használjon abszolút útvonalat, ha egy meghatározott mappára van szüksége.

## 6. lépés: **How to adjust aspect ratio** – második érték (30)

A rugalmasság bemutatásához változtassa meg az arányt, és mentse el a második képet. Ez azt mutatja, hogy ugyanaz az kódolt adat különböző vizuális arányokkal jeleníthető meg.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

A program futtatása két PNG fájlt hoz létre:

- `DatabarAspectRatio15.png` – közepes magasságú vonalkód  
- `DatabarAspectRatio30.png` – magasabb magasságú vonalkód nehéz beolvasási környezetekhez  

Mindkét fájl készen áll UI vezérlőkbe betöltésre, címkékre nyomtatásra vagy API-n keresztül történő továbbításra.

### Várható kimenet

Amikor megnyitja a generált képeket, egy DataBar Stacked Omnidirectional vonalkódot kell látnia, amely a `12345678901231` GTIN‑14 értéket kódolja. A két fájl közötti vizuális különbség kizárólag a magasság, ami megerősíti, hogy a **how to adjust aspect ratio** a kívánt módon működik.

## 7. lépés: Teljes forráskód referenciaként

Alább megtalálható a teljes, futtatható program. Másolja be a `Program.cs`-be, építse, és futtassa.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Gyakori kérdések és szélsőséges esetek kezelése

### Mi van, ha a célmappa nem létezik?

`Save` `DirectoryNotFoundException`-t dob. Először hozza létre a könyvtárat:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Hogyan változtassuk meg a képformátumot?

Cserélje le a `BarCodeImageFormat.Png`-t `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` vagy `BarCodeImageFormat.Tiff`-re a downstream követelményeknek megfelelően.

### Generálhatok több vonalkódot egy ciklusban?

Igen. Hozzon létre egy új `BarcodeGenerator`-t minden adatkarakterlánchoz, vagy használja újra ugyanazt a példányt a `CodeText` tulajdonság frissítése után:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```
