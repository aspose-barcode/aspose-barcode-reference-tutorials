# Hogyan generáljunk vonalkód képet C#-ban DataBar Stacked Omni‑Directional használatával

Ha **hogyan generáljunk vonalkód képet** kell egy .NET alkalmazásban, ez a bemutató pontos lépéseket mutat. Megmutatjuk, hogyan hozhat létre DataBar Stacked Omni‑Directional vonalkódot, állíthatja be annak képarányát, és exportálhatja az eredményt PNG fájlokként.

A vonalkódok generálása gyakori igény készletkezelő rendszerekben, kiskereskedelmi értékesítési pontok termináljaiban és logisztikai nyomon követésben. Az alábbi szakaszokban mindent lefedünk, amire szüksége van – a szükséges NuGet csomagtól a végső kép ellenőrzéséig – hogy még ma beépíthesse a vonalkód létrehozását bármely C# projektbe.

## Előfeltételek

Mielőtt elkezdené, győződjön meg róla, hogy rendelkezik a következőkkel:

* .NET 6.0 vagy újabb (a kód működik .NET Core és .NET Framework alatt is)
* Visual Studio 2022 vagy bármely kedvelt C# IDE
* Az **Aspose.BarCode for .NET** NuGet csomag (telepítés: `dotnet add package Aspose.BarCode`)
* Írási jogosultság a mappához, ahová a PNG fájlok mentésre kerülnek

Ezek az előfeltételek biztosítják, hogy a példa további konfiguráció nélkül fusson.

## 1. lépés: A kimeneti mappa beállítása

Az első dolog, amire szüksége van, egy könyvtár, ahová a generált PNG fájlok kerülnek. Használhat abszolút vagy relatív útvonalat, de győződjön meg róla, hogy a mappa létezik, mielőtt a `Save` metódust meghívná.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

A mappa programozott létrehozása megakadályozza a *FileNotFoundException* kivételt, amikor a `Save` metódus megpróbálja a képet írni.

## 2. lépés: DataBar Stacked Omni‑Directional vonalkód generátor létrehozása

A **BarcodeGenerator** osztály a belépési pont minden vonalkódtípushoz. Itt adjuk meg a `EncodeTypes.DatabarStackedOmniDirectional` értéket és a kódolandó adatkarakterláncot.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Miért fontos*: Az `EncodeTypes` enumeráció megmondja a könyvtárnak, melyik szimbólumot kell megjeleníteni. Az Omni‑Directional változat biztosítja, hogy a vonalkód bármilyen orientációból beolvasható legyen – ez sok raktári szkenner esetében elvárás.

## 3. lépés: Általános vonalkód paraméterek konfigurálása

Egy olvasható vonalkódhoz szükséges egy megfelelő X‑dimenzió (a legkisebb vonal szélessége). A `Pixels` érték 2‑re állítása jó egyensúlyt teremt a méret és a tisztaság között a legtöbb képernyőfelbontásnál.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Később módosíthatja a `Pixels` értékét, ha nagyobb vagy kisebb képre van szüksége; a könyvtár automatikusan átméretezi a vonalkód többi részét.

## 4. lépés: Az első kép generálása 15‑ös képaránnyal

A **képarány** szabályozza a DataBar vonalkódok magasság‑szélesség arányát. A 15‑ös képarány tipikus alapértelmezett a kiskereskedelmi címkékhez.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Ez a hívás után a `DatabarAspectRatio15.png` fájlt megtalálja a kimeneti mappában. A kép veszteségmentes PNG, amely alkalmas további feldolgozásra vagy nyomtatásra.

## 5. lépés: A képarány 30‑ra változtatása és a második kép exportálása

Néha magasabb vonalkódra van szükség – például ha a címke magassága korlátozott. A képarány 30‑ra állítása kompaktabb megjelenést eredményez, miközben az adat integritása megmarad.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Most már két PNG fájlja van, amely bemutatja, hogyan néz ki ugyanaz az adat különböző képarányokkal. Ez a párhuzamos összehasonlítás segít eldönteni, melyik változat illik legjobban a címke elrendezéséhez.

## Teljes, futtatható példa

Az alábbiakban a teljes program látható, amelyet egyszerűen másolhat, beilleszthet és futtathat. Tartalmazza az összes `using` direktívát, a hibakezelést és a megjegyzéseket, amelyek minden lépést elmagyaráznak.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Várható kimenet** (konzol):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Nyissa meg a két PNG fájlt bármely képmegjelenítőben. Ugyanazt a GTIN‑t fogja látni, de a második kép magasabb a nagyobb képarány miatt.

## Profi tippek és gyakori buktatók

| Helyzet | Ajánlás |
|-----------|----------------|
| **Alacsony felbontású kijelzők** | Növelje az `XDimension.Pixels` értékét 3‑ra vagy 4‑re, hogy a vonalak élesek maradjanak. |
| **Nyomtatás hőpapírra** | Használja a `BarCodeImageFormat.Tiff` formátumot a nagyobb hűségért, és állítsa a `Resolution.DpiX/DpiY` értékét 300-ra. |
| **Dinamikus adatok** | Használja újra ugyanazt a `BarcodeGenerator` példányt, és csak a `generator.CodeText` értékét módosítsa minden egyes `Save` előtt. Ez elkerüli a felesleges objektum‑létrehozást. |
| **Érvénytelen GTIN** | A könyvtár `ArgumentException`‑t dob, ha az adat nem felel meg a GS1 szabványoknak. Ellenőrizze az adatot, mielőtt a generátornak átadná. |
