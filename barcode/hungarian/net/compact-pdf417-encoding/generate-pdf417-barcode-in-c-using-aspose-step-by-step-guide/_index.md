# PDF417 vonalkód generálása C#-ban az Aspose segítségével – lépésről‑lépésre útmutató

Ha **PDF417 vonalkódot** kell generálnod egy .NET alkalmazásban, ez az útmutató pontosan megmutatja, hogyan. Egy teljes, azonnal futtatható példát láthatsz, amely alap, kompakt, Micro, GS1‑Micro és Macro PDF417 vonalkódokat hoz létre az Aspose.BarCode for .NET segítségével.

A PDF417 vonalkód generálása gyakori igény szállítmánycímkék, szállítási dokumentumok és készletkezelő rendszerek esetén. A tutorial végére képes leszel **PDF417 vonalkód képeket** generálni, megérted a kulcsfontosságú paramétereket, és a kódot a saját adatcsomagjaidhoz tudod igazítani.

## Előkövetelmények

- .NET 6.0 SDK vagy újabb (a kód .NET Framework 4.7+‑vel is működik)
- Visual Studio 2022 vagy bármely C# IDE
- Aspose.BarCode for .NET NuGet csomag (`Aspose.BarCode`) telepítve
- Alapvető C# szintaxis ismeret

> **Pro tipp:** Használd az Aspose ingyenes értékelő licencét, hogy a tesztelés során elkerüld a futásidejű korlátozásokat.

## 1. lépés: A projekt beállítása és névterek importálása

Hozz létre egy új konzolprojektet, és add hozzá az Aspose.BarCode csomagot:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Ezután nyisd meg a `Program.cs` fájlt, és add hozzá a szükséges `using` direktívákat:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Ezek a névterek biztosítják a `BarcodeGenerator` osztályhoz és az `EncodeTypes` felsoroláshoz való hozzáférést, amely a **vonalkód generálásához C#‑ban** szükséges.

## 2. lépés: Alap PDF417 vonalkód generálása

Az egyszerű PDF417 vonalkód az alapértelmezett beállításokat használja, kivéve az X‑dimenziót (modul szélesség) és az oszlopok számát. Ezeknek az értékeknek a módosítása szabályozza a teljes méretet és olvashatóságot.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Miért működik:**  
- `EncodeTypes.Pdf417` azt mondja az Aspose‑nak, hogy a PDF417 szimbólumot használja.  
- `XDimension.Pixels` határozza meg a legkisebb vonal szélességét; a 2 érték kis képet eredményez anélkül, hogy a beolvashatóság csorbulna.  
- `Pdf417.Columns` meghatározza, hány adatoszlopot tartalmaz a vonalkód; három oszlop kiegyensúlyozott arányt ad.

## 3. lépés: Kompakt (rövidített) PDF417 vonalkód generálása

A kompakt mód eltávolítja a stop mintát, és csökkenti a teljes magasságot, ami korlátozott helyű címkéknél hasznos.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Miért működik:**  
A `Pdf417.Truncate = true` beállítás aktiválja a rövidített módot, amely kihagyja a jobb oldali stop mintát, és csökkenti a vonalkód magasságát, miközben az adat integritását megőrzi.

## 4. lépés: Micro PDF417 vonalkód generálása

A Micro PDF417 egy kisebb változat, amely 1‑4 oszlopot támogat. Ideális olyan alkalmazásokhoz, ahol a hely premium, például kis termékcímkéknél.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Miért működik:**  
- `EncodeTypes.MicroPdf417` a szimbólum mikro változatát választja.  
- Az oszlopszám 1 és 4 között lehet; a 4-es választás a legkompaktabb elrendezést adja, miközben beolvasható marad.

## 5. lépés: GS1‑kompatibilis Micro PDF417 vonalkód generálása

A GS1 előtagok szabványos azonosítókat (pl. GTIN, tételszám) adnak a vonalkód adataihoz. Az Aspose lehetővé teszi ezek közvetlen beágyazását.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Miért működik:**  
A GS1 Alkalmazási Azonosítók (AI‑k) zárójelek között szerepelnek. Az Aspose ezeket értelmezi, és hozzáadja a GS1 szkennerek által megkövetelt megfelelő formázást.

## 6. lépés: Macro PDF417 vonalkód generálása teljes metaadatokkal

A Macro PDF417 lehetővé teszi, hogy egy nagy adatcsomagot több összekapcsolt vonalkódra oszd szét. Beágyazhatsz fájlszintű metaadatokat, például fájlazonosítót, szegmensszámot, időbélyegeket és egyedi karakterláncokat.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Miért működik:**  
Minden `MacroPdf417*` tulajdonság a makró vonalkód specifikáció egy adott szegmensére vonatkozik. Ezeknek az értékeknek a beállítása biztosítja, hogy egy szkenner a több vonalkód képből rekonstruálni tudja az eredeti fájlt.
