# Como criar um PNG de código de barras usando Python – guia passo a passo

Se você precisa **criar arquivos PNG de código de barras** a partir de strings arbitrárias, este tutorial oferece uma solução pronta para executar. Você verá exatamente como gerar um código de barras Code 128, converter texto em uma imagem de código de barras e salvar o resultado como um arquivo PNG — tudo com poucas linhas de Python.

O guia cobre tudo o que você precisa saber, desde a instalação da biblioteca necessária até a personalização da saída para diferentes casos de uso. Ao final, você poderá incorporar a geração de códigos de barras em qualquer projeto Python sem precisar buscar documentação adicional.

## O que você aprenderá

* Instalar o pacote **barcode generator python** que suporta Code 128.  
* Usar `BarCodeGenerator` para **gerar código de barras 128** a partir de uma string de texto.  
* Salvar o resultado como um PNG de alta qualidade com `save`.  
* Ajustar tamanho da imagem, cores de primeiro plano/fundo e lidar com erros comuns.  
* Verificar se o PNG foi criado corretamente.

### Pré‑requisitos

| Requisito | Motivo |
|-----------|--------|
| Python 3.8+ | Sintaxe moderna e dicas de tipo |
| Acesso à internet (para `pip install`) | Para baixar a biblioteca |
| Permissão de escrita em uma pasta | Para armazenar o PNG gerado |

Nenhum serviço externo é necessário; tudo é executado localmente.

## Etapa 1: Instalar a biblioteca de código de barras

A maneira mais direta de **converter texto em código de barras** em Python é usar o pacote **Aspose.BarCode for Python via .NET**, que já suporta Code 128.

```bash
pip install aspose-barcode
```

> **Dica profissional:** Se você trabalha em um ambiente virtual, ative‑o antes de executar o comando para manter as dependências isoladas.

## Etapa 2: Importar as classes necessárias

Após a instalação, importe as classes principais. As instruções de importação são curtas, facilitando a leitura do código.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` cria a imagem do código de barras.  
* `EncodeTypes` fornece uma enumeração das simbologias suportadas, incluindo `CODE_128`.

## Etapa 3: Definir o texto que você deseja codificar

Escolha qualquer string alfanumérica. O Code 128 pode representar todo o conjunto ASCII, portanto você não está limitado a números.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Se a entrada contiver caracteres não suportados, o gerador lançará um `ValueError`. Envolva a atribuição em um bloco `try` caso espere dados fornecidos pelo usuário.

## Etapa 4: Criar o gerador de código de barras para Code 128

Instancie `BarCodeGenerator` com a simbologia desejada e o texto que você definiu. Este é o núcleo de **como gerar imagens de código de barras** em Python.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Por que Code 128? Ele oferece alta densidade e pode codificar todo o intervalo ASCII, tornando‑o ideal para sistemas de inventário, etiquetas de envio e bilhetagem.

## Etapa 5: (Opcional) Personalizar a aparência

Você pode ajustar finamente o código de barras antes de salvá‑lo. As opções a seguir são as mais comuns:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Essas configurações afetam a saída final de **criar barcode png** sem alterar os dados codificados.

## Etapa 6: Salvar o código de barras como um arquivo PNG

Finalmente, grave a imagem no disco. O método `save` detecta automaticamente a extensão do arquivo, portanto ao passar `.png` um PNG será criado.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Se o diretório de destino não existir, o Python lançará um `FileNotFoundError`. Crie o diretório previamente ou use `os.makedirs` com `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### Saída esperada

Após executar o script, você encontrará `extended_barcode.png` na pasta `output`. Abrindo o arquivo, verá um código de barras Code 128 nítido que codifica `1234567890`.

![Generated barcode PNG created with Python](generated_barcode.png "create barcode png example")

## Etapa 7: Verificar o código de barras (checagem rápida)

Você pode ler o PNG novamente com a mesma biblioteca para confirmar que o valor codificado corresponde ao texto original.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Executar este bloco imprime:

```
Verification succeeded: 1234567890
```

Se a asserção falhar, verifique novamente o `barcode_text` e quaisquer parâmetros personalizados que você definiu.

## Variações comuns e casos de borda

| Situação | Ajuste |
|----------|--------|
| **Texto mais longo (> 20 caracteres)** | Aumente `image_width` para evitar truncamento. |
| **Necessidade de fundo transparente** | Defina `back_color = "Transparent"` antes de salvar. |
| **Gerar múltiplos códigos de barras em um loop** | Envolva as etapas 3‑6 em um `for` loop, alterando `barcode_text` a cada iteração. |
| **Salvar como JPEG em vez de PNG** | Mude a extensão do arquivo para `.jpg`; a biblioteca lida com o formato automaticamente. |
| **Executar em um servidor sem interface gráfica** | A biblioteca não requer GUI, sendo segura para pipelines de CI. |

## Script completo para copiar‑e‑colar rapidamente

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Salve o script como `generate_barcode.py` e execute:

```bash
python generate_barcode.py
```

Você verá as mensagens de confirmação e um novo arquivo PNG na pasta `output`.
