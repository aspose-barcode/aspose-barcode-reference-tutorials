# Como gerar códigos de barras DataMatrix com Aspose.BarCode para .NET

Se você precisa de uma maneira confiável de incorporar símbolos legíveis por máquina em suas aplicações .NET, **gerar códigos de barras DataMatrix** é um requisito comum. Aspose.BarCode para .NET oferece uma API totalmente gerenciada que cuida de cada etapa — desde a escolha da versão correta do DataMatrix até o ajuste fino dos níveis de correção de erro — sem exigir ferramentas externas. Neste tutorial percorreremos um exemplo completo, explicaremos por que cada configuração é importante e mostraremos como salvar o resultado como imagem PNG ou JPEG.

## Respostas rápidas
- **Qual biblioteca cria códigos de barras DataMatrix?** Aspose.BarCode para .NET.  
- **Quantas versões do DataMatrix são suportadas?** Todas as 30 versões padrão quadradas e retangulares (de 10×10 até 144×144 módulos).  
- **Quais tipos de ECC posso usar?** ECC200 (padrão) e ECC140.  
- **Preciso de licença para desenvolvimento?** Um teste gratuito de 30 dias funciona para testes; uma licença comercial é necessária para produção.  
- **Posso executar isso no .NET 6, .NET Core ou .NET Framework?** Sim—Aspose.BarCode suporta .NET Framework 4.5+, .NET Core 3.1+ e .NET 5/6+.

## O que é um código de barras DataMatrix?
Um código de barras DataMatrix é uma matriz bidimensional, quadrada ou retangular, de células pretas e brancas que pode armazenar até 2.335 caracteres alfanuméricos. É amplamente usado em manufatura, logística e saúde para marcar itens pequenos porque permanece legível mesmo quando parcialmente danificado.

## Por que usar Aspose.BarCode para .NET?
Aspose.BarCode suporta **mais de 50 formatos de saída** (incluindo PNG, JPEG, TIFF, SVG e PDF) e pode gerar **todas as 30 versões do DataMatrix** sem carregar a imagem inteira na memória, permitindo criar códigos de barras em serviços de alta taxa de transferência que processam arquivos maiores que 100 MB.

## Pré‑requisitos

Antes de mergulharmos no código, certifique‑se de que você tem os seguintes pré‑requisitos:
- Um ambiente de desenvolvimento com suporte a .NET (Visual Studio 2022, Rider ou VS Code).  
- Uma cópia do Aspose.BarCode para .NET, que você pode baixar da **Página de download do Aspose.BarCode .NET**: [Página de download do Aspose.BarCode .NET](https://releases.aspose.com/barcode/net/).  
- Conhecimento básico de C# e do framework .NET.

Agora, vamos explorar as versões do DataMatrix e como gerá‑las usando Aspose.BarCode para .NET.

## Como gerar códigos de barras DataMatrix em .NET?

Carregue o `BarcodeGenerator` com o tipo `EncodeTypes.DataMatrix`, defina a versão desejada e o ECC, então chame `Save` para gravar o arquivo de imagem. Esse padrão de uma única linha funciona para qualquer versão que você escolher e lida automaticamente com o dimensionamento dos módulos, zonas silenciosas e renderização da imagem.

## Importar namespaces

`BarcodeGenerator` é a classe central do Aspose.BarCode para criar imagens de códigos de barras.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

O namespace `Aspose.BarCode.Generation` fornece acesso à classe `BarcodeGenerator`, que é a classe principal usada para gerar imagens de códigos de barras.

Agora, vamos dividir o exemplo em várias etapas.

## Etapa 1: configure o caminho do diretório

Comece definindo o caminho do diretório onde você deseja salvar os códigos de barras DataMatrix gerados.

```csharp
string path = "Your Directory Path";
```

Substitua `"Your Directory Path"` pelo caminho real onde você deseja salvar as imagens do código de barras.

## Etapa 2: inicializar o gerador de código de barras

Crie uma instância da classe `BarcodeGenerator` e especifique o tipo de código de barras como `DataMatrix`. Você também pode fornecer os dados que deseja codificar dentro do código de barras.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` é a classe principal que cria e renderiza símbolos de código de barras.

## Etapa 3: configurar propriedades do código de barras

Você pode personalizar várias propriedades do código de barras DataMatrix, como suas dimensões e tipo ECC (Código de Correção de Erro). Aqui está um exemplo de definição da dimensão X para 4 pixels e escolha do ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` define o tamanho de cada módulo em pixels, e `DataMatrixEcc` seleciona o nível de correção de erro.

## Etapa 4: definir a versão do DataMatrix e salvar

Você pode especificar a versão do DataMatrix definindo o número de linhas e colunas. Após configurar a versão, salve a imagem do código de barras.

Por exemplo, para criar um código de barras DataMatrix com 22 linhas e 22 colunas usando ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

Da mesma forma, você pode gerar um código de barras com parâmetros diferentes alterando a versão e o tipo ECC conforme necessário.

## Etapa 5: repetir para outras versões

Você pode repetir a Etapa 4 para outras versões do DataMatrix. Por exemplo, para criar um código de barras com 12 linhas e 64 colunas usando ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Etapa 6: trocar tipos de ECC

Se quiser mudar o tipo de ECC para Ecc140, basta atualizar a propriedade ECC:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Etapa 7: gerar códigos de barras com diferentes versões e ECC

Repita a Etapa 4 para outras versões do DataMatrix e tipos de ECC, salvando cada código de barras com um nome de arquivo exclusivo.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

Agora que você aprendeu a gerar códigos de barras DataMatrix usando Aspose.BarCode para .NET, pode integrar facilmente essa funcionalidade em suas aplicações .NET.

## Armadilhas comuns e dicas de solução de problemas

- **Dimensões de versão incorretas** – As versões do DataMatrix têm pares fixos de linhas/colunas. Fornecer um par incompatível (ex.: 10 × 20) gerará uma `ArgumentException`. Sempre use uma das combinações suportadas listadas na documentação da API.  
- **Licença ausente** – No modo de avaliação, as imagens geradas contêm uma marca d'água. Aplique uma licença válida com `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` antes de criar o gerador para remover a marca d'água. A classe `License` carrega um arquivo de licença para ativar o produto.  
- **Tamanho de imagem grande** – Se precisar de saída em alta resolução, aumente a propriedade `XDimension`; a biblioteca escala a imagem proporcionalmente sem perder a legibilidade.
