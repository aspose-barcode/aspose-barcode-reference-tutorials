# Gerar código de barras PDF417 em C# usando Aspose – guia passo a passo

Se você precisa **gerar código de barras PDF417** em uma aplicação .NET, este guia mostra exatamente como fazer. Você verá um exemplo completo, pronto‑para‑executar, que cria códigos de barras PDF417 básicos, compactos, Micro, GS1‑Micro e Macro com Aspose.BarCode para .NET.

Gerar um código de barras PDF417 é uma necessidade comum para etiquetas de envio, documentos de transporte e sistemas de inventário. Ao final deste tutorial você será capaz de **gerar imagens de código de barras PDF417**, entender os parâmetros principais e adaptar o código para seus próprios dados.

## Prerequisites

- .NET 6.0 SDK ou posterior (o código também funciona com .NET Framework 4.7+)
- Visual Studio 2022 ou qualquer IDE C#
- Pacote NuGet Aspose.BarCode for .NET (`Aspose.BarCode`) instalado
- Familiaridade básica com a sintaxe C#

> **Dica profissional:** Use a licença de avaliação gratuita da Aspose para evitar restrições em tempo de execução durante os testes.

## Etapa 1: Configurar o projeto e importar namespaces

Crie um novo projeto de console e adicione o pacote Aspose.BarCode:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Em seguida, abra `Program.cs` e adicione as diretivas `using` necessárias:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Esses namespaces dão acesso à classe `BarcodeGenerator` e à enumeração `EncodeTypes` necessárias para **gerar código de barras usando C#**.

## Etapa 2: Gerar um código de barras PDF417 básico

O código de barras PDF417 mais simples usa as configurações padrão, exceto a X‑dimension (largura do módulo) e o número de colunas. Ajustar esses valores controla o tamanho geral e a legibilidade.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Por que funciona:**  
- `EncodeTypes.Pdf417` indica ao Aspose para usar a simbologia PDF417.  
- `XDimension.Pixels` define a menor largura de barra; um valor de 2 mantém a imagem pequena sem sacrificar a capacidade de leitura.  
- `Pdf417.Columns` determina quantas colunas de dados o código de barras contém; três colunas fornecem uma proporção equilibrada.

## Etapa 3: Gerar um código de barras PDF417 compacto (truncado)

O modo compacto remove o padrão de parada e reduz a altura total, o que é útil para etiquetas com espaço limitado.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Por que funciona:**  
Definir `Pdf417.Truncate = true` ativa o modo truncado, que omite o padrão de parada à direita e reduz a altura do código de barras enquanto preserva a integridade dos dados.

## Etapa 4: Gerar um código de barras Micro PDF417

Micro PDF417 é uma variante menor que suporta de 1‑4 colunas. É ideal para aplicações onde o espaço é limitado, como etiquetas de produtos pequenos.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Por que funciona:**  
- `EncodeTypes.MicroPdf417` seleciona a versão micro da simbologia.  
- A contagem de colunas pode ser entre 1 e 4; escolher 4 produz o layout mais denso, ainda legível.

## Etapa 5: Gerar um código de barras Micro PDF417 compatível com GS1

Os prefixos GS1 adicionam identificadores padronizados (por exemplo, GTIN, número de lote) aos dados do código de barras. Aspose permite incorporá-los diretamente.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Por que funciona:**  
Os Identificadores de Aplicação GS1 (AIs) são colocados entre parênteses. Aspose os analisa e adiciona a formatação apropriada exigida pelos scanners GS1.

## Etapa 6: Gerar um código de barras Macro PDF417 com metadados completos

Macro PDF417 permite dividir um grande conjunto de dados em vários códigos de barras vinculados. Você pode incorporar metadados ao nível de arquivo, como ID do arquivo, contagem de segmentos, timestamps e strings personalizadas.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Por que funciona:**  
Cada propriedade `MacroPdf417*` mapeia para um segmento específico da especificação do código de barras macro. Definir esses valores garante que um scanner possa reconstruir o arquivo original a partir de múltiplas imagens de código de barras.
