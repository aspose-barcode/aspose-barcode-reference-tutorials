# Como gerar código de barras em C# com Aspose.BarCode e adicionar metadados

Se você precisa **gerar código de barras em C#** para um sistema de logística ou inventário, este guia mostra uma solução completa, pronta para produção. Você verá como criar um código de barras Macro PDF417, anexar metadados ricos e definir um timestamp preciso — tudo com a biblioteca Aspose.BarCode.

O tutorial cobre tudo, desde a instalação do pacote NuGet até a gravação da imagem PNG final. Ao final, você poderá gerar um código de barras que transporta identificadores de arquivo, informações de segmento e campos personalizados, pronto para scanners downstream que suportam Macro PDF417.

## Pré‑requisitos

Antes de começar, certifique‑se de que você tem:

* .NET 6.0 SDK ou posterior (o código também funciona com .NET Framework 4.7.2+)
* Visual Studio 2022 ou qualquer IDE C# de sua preferência
* Uma licença ativa do Aspose.BarCode (a versão de avaliação gratuita funciona para desenvolvimento)
* Familiaridade básica com a sintaxe C#

> **Dica profissional:** Se você usa um pipeline CI/CD, adicione a referência ao pacote Aspose.BarCode no seu arquivo de projeto para que as compilações permaneçam reproduzíveis.

## Etapa 1: Instalar Aspose.BarCode

Abra um terminal na pasta do seu projeto e execute:

```bash
dotnet add package Aspose.BarCode
```

O comando obtém a versão estável mais recente (atualmente 24.9). Após a restauração terminar, você pode referenciar a biblioteca nos seus arquivos de código.

## Etapa 2: Criar um novo projeto de console C# (opcional)

Se preferir começar do zero, crie um aplicativo de console:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

O arquivo `Program.cs` hospedará o código de geração do código de barras mostrado adiante.

## Etapa 3: Configurar o gerador de código de barras

O núcleo do processo é a classe `BarcodeGenerator`. Você a instancia com o valor desejado do enum `EncodeTypes` e o texto que deseja codificar.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Por que cada linha importa

* **EncodeTypes.MacroPdf417** indica ao Aspose que deve produzir um código PDF417 que pode ser dividido em segmentos. Isso é essencial para cargas úteis grandes que excedem a capacidade de um único símbolo.
* **XDimension.Pixels** controla a densidade visual. Um valor de 2 produz uma imagem nítida na maioria das telas e impressoras sem inflar o tamanho do arquivo.
* **Propriedades MacroPdf417*** incorporam os metadados que scanners downstream leem como campos separados (ID do arquivo, ID do segmento, etc.). Esta é a parte “como adicionar metadados” do tutorial.
* **MacroPdf417TimeStamp** demonstra “como definir timestamp”. A instância `DateTime` pode ser qualquer horário UTC; usar UTC evita ambiguidades de fuso horário quando o código de barras viaja entre regiões.
* **MacroPdf417Terminator** define como a sequência macro termina. `Set` é a escolha mais comum porque sinaliza o segmento final ao leitor.
* **Save(..., BarCodeImageFormat.Png)** grava uma imagem sem perdas que preserva os detalhes finos necessários para a leitura confiável.

## Etapa 4: Verificar o código de barras gerado

Execute o programa:

```bash
dotnet run
```

Você deverá ver a saída no console:

```
Barcode saved to ExtPDF417Meta.png
```

Abra `ExtPDF417Meta.png` em qualquer visualizador de imagens. A figura exibirá um símbolo PDF417 compacto com o texto **Åspóse.Barcóde©** e os campos macro incorporados. Escanear a imagem com um leitor compatível com PDF417 (ou um aplicativo móvel que suporte Macro PDF417) retornará o texto original mais os valores de metadados que você definiu.

### Características visuais esperadas

* Barras verticais escuras e uniformemente espaçadas
* Uma zona silenciosa (margem) adicionada automaticamente pelo Aspose
* Nenhuma distorção, pois o `XDimension` de 2 pixels corresponde à resolução nativa do PNG

## Etapa 5: Variações comuns e casos de borda

### 5.1 Manipulação de caracteres especiais

O texto de exemplo contém caracteres Unicode (`Å`, `ó`, `©`). Aspose.BarCode os codifica usando UTF‑8 por padrão, de modo que aparecem corretamente no código de barras. Se precisar de outra codificação (por exemplo, ISO‑8859‑1), defina:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Identificadores de arquivo grandes

`MacroPdf417FileID` aceita um inteiro de 32 bits. Para valores maiores que `int.MaxValue`, divida o identificador em vários campos ou use um GUID armazenado como string em `MacroPdf417FileName`.

### 5.3 Ajustando o número de colunas

Aumentar `Pdf417.Columns` reduz a altura do código de barras, mas alarga cada linha. Se o código precisar caber em uma etiqueta estreita, diminua a contagem de colunas e aumente automaticamente a contagem de linhas.

### 5.4 Salvando em outros formatos

Aspose suporta BMP, JPEG, TIFF e SVG. Substitua `BarCodeImageFormat.Png` pelo valor enum desejado, por exemplo, `BarCodeImageFormat.Svg` para um gráfico vetorial escalável.

## Etapa 6: Integrar o código de barras em um fluxo de trabalho maior

Depois de ter o arquivo PNG, você pode:

* Incorporá‑lo em uma fatura PDF usando Aspose.PDF.
* Anexá‑lo a um e‑mail como comprovante de entrega.
* Armazenar os bytes da imagem em um banco de dados para recuperação posterior.

A seguir, um trecho rápido que converte o PNG em um array de bytes para armazenamento:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Perguntas frequentes

**P: Isso funciona no .NET Core?**  
R: Sim. A mesma API funciona no .NET Core, .NET 5+ e .NET Framework. Basta referenciar o pacote NuGet apropriado.

**P: E se eu precisar gerar um PDF417 sem macro?**  
R: Use `EncodeTypes.Pdf417` em vez de `EncodeTypes.MacroPdf417`. As propriedades específicas de macro serão ignoradas.

**P: Posso adicionar pares chave/valor personalizados além dos campos incorporados?**  
R: Aspose.BarCode não expõe campos de usuário arbitrários para Macro PDF417. Se precisar de dados extras, codifique‑os na carga útil de texto principal ou troque para um QR code, que suporta “structured append”.
