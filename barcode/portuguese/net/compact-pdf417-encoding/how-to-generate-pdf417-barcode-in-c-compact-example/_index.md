# Como gerar código de barras PDF417 em C# – exemplo compacto

Se você precisa **gerar código de barras PDF417** em uma aplicação C#, este guia mostra uma solução completa, pronta‑para‑executar. Criaremos um código de barras PDF417 compacto, ajustaremos a largura do módulo, definiremos a contagem de colunas e salvaremos o resultado como uma imagem PNG — tudo com a biblioteca Aspose.BarCode .NET.

Gerar um código de barras PDF417 é comum quando se deseja codificar grandes quantidades de dados (por exemplo, URLs, cartões de contato ou IDs de inventário) em um formato bidimensional eficiente em espaço. Ao final deste tutorial você terá uma instância funcional de `BarcodeGenerator` que produz um código de barras compacto e de alta legibilidade, pronto para impressão ou exibição.

## Pré-requisitos

- .NET 6.0 ou superior (o código também funciona com .NET Framework 4.8)
- Visual Studio 2022 (ou qualquer IDE C#)
- Pacote NuGet Aspose.BarCode for .NET (`Install-Package Aspose.BarCode`)
- Familiaridade básica com a sintaxe C#

Nenhuma configuração adicional é necessária; o exemplo roda como um aplicativo de console.

## Passo 1: Criar um gerador de código de barras PDF417

O primeiro passo é instanciar `BarcodeGenerator` com o enum `EncodeTypes.Pdf417` e o texto que você deseja codificar.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Por que isso importa:** `EncodeTypes.Pdf417` indica à biblioteca que deve usar a simbologia PDF417, enquanto o segundo argumento define a carga de dados. Você pode substituir `"Compact example"` por qualquer string de até 1 800 caracteres.

## Passo 2: Definir a largura do módulo (dimensão X) em pixels

A dimensão X define a largura de um único módulo do código de barras (o menor quadrado preto ou branco). Um valor de pixel menor gera um código de barras mais compacto.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Por que isso importa:** Um valor de `2` pixels cria uma aparência compacta sem sacrificar a confiabilidade da leitura na maioria dos scanners modernos. Ajuste o valor se precisar de módulos maiores para impressão de baixa resolução.

## Passo 3: Especificar o número de colunas

PDF417 permite controlar o número de colunas, o que influencia a proporção do código de barras.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Por que isso importa:** Menos colunas tornam o código de barras mais alto, enquanto mais colunas o achatam. Três colunas funcionam bem para um layout compacto em orientação retrato.

## Passo 4: Habilitar o modo compacto truncando o código de barras

O modo compacto remove linhas de preenchimento desnecessárias, tornando o código de barras menor enquanto preserva os dados codificados.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Por que isso importa:** A truncagem é ideal quando o espaço na tela é limitado (por exemplo, apps móveis ou etiquetas pequenas). O código de barras permanece totalmente legível porque o algoritmo de codificação ajusta automaticamente os níveis de correção de erro.

## Passo 5: Salvar o código de barras como imagem PNG

Por fim, grave o código de barras gerado em um arquivo. PNG preserva qualidade sem perdas, essencial para scanners de código de barras.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Executar o programa cria `CompactPdf417.png` no diretório de trabalho do executável. A imagem se parece com isto:

![Código de barras PDF417 compacto gerado](CompactPdf417.png "Código de barras PDF417 compacto gerado")

**Saída esperada:** Um código de barras PDF417 de 2 pixels de largura, três colunas, que codifica o texto “Compact example”. Escanear o PNG com um scanner padrão deve retornar a string original.

## Variações comuns e casos de borda

| Situação | Como ajustar o código |
|-----------|------------------------|
| **Dados mais longos ( > 500 caracteres )** | Aumente `Columns` para 5‑7 para evitar que o código de barras fique muito alto. |
| **Impressão de alta resolução** | Defina `XDimension.Pixels` para 3 ou 4 para módulos maiores. |
| **Formato de imagem diferente** | Substitua `BarCodeImageFormat.Png` por `Jpeg` ou `Bmp`, conforme necessário. |
| **Incorporar o código de barras em um PDF** | Use `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` em vez de PNG. |

**Dica profissional:** Sempre teste o código de barras gerado no hardware de scanner alvo. Alguns scanners de baixo custo têm dificuldade com dimensões X muito pequenas; se encontrar erros de leitura, aumente o valor de pixel em um passo.

## Exemplo completo e executável

Abaixo está o programa completo que você pode copiar‑colar em um novo projeto de console. Nenhum arquivo adicional é necessário.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Compile e execute o programa (`dotnet run` se usar a CLI do .NET). Após a execução, abra `CompactPdf417.png` para verificar o resultado visual.

## Conclusão

Agora você sabe **como gerar código de barras PDF417** em C# com um layout compacto, dimensão X personalizada e configurações de colunas. O exemplo demonstra os passos essenciais: instanciar `BarcodeGenerator`, configurar `XDimension` e `Columns`, habilitar `Truncate` para modo compacto e, finalmente, salvar a imagem.

A partir daqui você pode explorar recursos adicionais, como nível de correção de erro, cores personalizadas ou incorporação direta do código de barras em PDFs. Experimente diferentes `EncodeTypes` se precisar de outras simbologias (por exemplo, QR, Code128) e integre o mesmo padrão de configuração de parâmetros.

Bom desenvolvimento, e que seus códigos de barras sempre sejam lidos na primeira tentativa!
