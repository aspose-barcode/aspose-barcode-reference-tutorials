# Criar barcode PNG em Python – Guia Completo

Já precisou **criar barcode PNG** mas não tinha certeza de qual biblioteca ou configurações usar? Você não está sozinho. Em muitos sistemas de inventário ou checkout, o primeiro passo é transformar dados brutos em uma imagem PNG nítida que os scanners adoram.  

Neste tutorial, vamos percorrer **como gerar databar**, como **ajustar a altura do barcode**, e até o truque para **alterar parâmetros do barcode** em tempo real — tudo usando **barcode com dados de exemplo** que você pode copiar‑colar diretamente no seu projeto.  

## O que você aprenderá

- Configurar a biblioteca Aspose.BarCode (ou similar) em Python.  
- **Create barcode PNG** arquivos com diferentes alturas em apenas algumas linhas de código.  
- **How to change barcode** propriedades como tamanho do módulo e altura da barra.  
- Usar um valor realista de GTIN‑14 como **barcode with sample data**.  
- Dicas para solucionar problemas comuns, como imagens borradas ou codificação incorreta.

Nenhuma experiência prévia com geração de barcode é necessária — apenas um interpretador Python básico e a capacidade de instalar um pacote pip.

## Pré-requisitos

- Python 3.8+ instalado na sua máquina.  
- Acesso à internet para instalar o pacote `aspose-barcode` (ou qualquer biblioteca compatível).  
- Uma pasta gravável onde os arquivos PNG serão salvos (substitua `YOUR_DIRECTORY` no script).  

Se você já tem isso, ótimo — vamos mergulhar.

## Criar barcode PNG – Configurando o Gerador

Primeiro de tudo: precisamos de um objeto gerador que saiba que estamos lidando com um barcode **DataBar Omnidirectional**. O código abaixo importa as classes necessárias, cria o gerador com um **barcode with sample data**, e define um tamanho de módulo modesto.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Por que isso importa:** O `EncodeTypes.DATABAR_OMNIDIRECTIONAL` indica ao motor para produzir um **DataBar** que pode ser lido de qualquer direção, perfeito para prateleiras de varejo. Definir `x_dimension` mantém as barras nítidas, enquanto `bar_height` controla o tamanho visual do código.

## Como gerar Databar com Dados de Exemplo

Agora que o gerador está pronto, vamos **create barcode PNG** arquivos. O primeiro salvamento usa uma altura de 30 pixels, que costuma ser suficiente para pré‑visualizações na tela.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Executar o script até este ponto produzirá um arquivo PNG que se parece com um barcode compacto e de alto contraste. Abra-o em qualquer visualizador de imagens para verificar se as barras estão nítidas e os dados GTIN‑14 estão codificados.

## Ajustar a Altura do Barcode (Como Alterar o Barcode)

Às vezes você precisa de um barcode mais alto para etiquetas maiores ou impressão de alta resolução. É aqui que **adjust barcode height** entra em ação. Alterar a altura é tão simples quanto atualizar a propriedade `BarHeight` e salvar novamente.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Como funciona:** O gerador reutiliza os mesmos dados e tamanho de módulo; apenas a dimensão vertical muda. Isso evita recriar todo o objeto e demonstra **how to change barcode** configurações dinamicamente.

## Script Completo – Solução Única

Abaixo está o script completo e executável que combina todas as etapas. Copie, cole e execute — ele deve funcionar imediatamente após você instalar o pacote.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Saída Esperada

Executar o script gerará dois arquivos:

- `DatabarOmni30.png` – barcode DataBar Omnidirectional com 30 px de altura.  
- `DatabarOmni60.png` – versão com 60 px de altura do mesmo barcode.

Ambas as imagens estão no formato PNG, sem perdas, e prontas para serem incorporadas em PDFs, páginas HTML ou impressas diretamente em etiquetas.

## Armadilhas Comuns & Dicas Profissionais

- **Pixel vs. DPI:** Arquivos PNG são baseados em pixels. Se você precisar de um tamanho de impressão específico, calcule `BarHeight` com base no DPI (ex.: 300 dpi → 30 px ≈ 0.1 in).  
- **Incorrect encoding:** Certifique-se de que a string de dados segue o formato do Identificador de Aplicação GS1 (`(01)` para GTIN‑14). Parênteses ausentes podem fazer a biblioteca recair para um barcode numérico simples.  
- **File paths:** Use strings brutas (`r"..."`) ou barras duplas invertidas no Windows para evitar dores de cabeça com caracteres de escape.  
- **Performance:** Se você estiver gerando milhares de barcodes, instancie o gerador uma única vez e modifique apenas `BarHeight` ou a string de dados entre as gravações. Isso reduz o consumo de memória.
