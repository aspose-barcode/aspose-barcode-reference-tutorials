# Como criar código de barras RM4SCC e gerar código de barras Planet em C#

Se você precisar **criar código de barras RM4SCC** para aplicações postais, este guia mostra as etapas exatas. Você também aprenderá como **gerar código de barras Planet** com alturas automáticas e fixas, de modo que o mesmo código funcione para qualquer simbologia postal.

O tutorial cobre tudo o que é necessário para produzir imagens PNG que atendam aos padrões postais. Nenhuma ferramenta externa é necessária além da biblioteca Aspose.BarCode for .NET. Ao final, você poderá gerar códigos de barras programaticamente e controlar suas dimensões com precisão.

## Pré-requisitos

* .NET 6.0 ou posterior instalado
* Visual Studio 2022 (ou qualquer IDE C#)
* Pacote NuGet Aspose.BarCode for .NET  
  `Install-Package Aspose.BarCode`
* Permissão de escrita no diretório de saída

Esses itens permitem compilar e executar o código de exemplo sem configuração adicional.

## Etapa 1: Inicializar o gerador de código de barras para RM4SCC

A primeira operação cria uma instância de `BarcodeGenerator` configurada para a simbologia RM4SCC. Este objeto contém todas as configurações da imagem do código de barras.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Por que isso importa** – `EncodeTypes.RM4SCC` indica ao Aspose que deve usar o formato postal RM4SCC, enquanto a string de dados `"123456"` representa o código postal que você deseja codificar.

## Etapa 2: Definir a largura do módulo (dimensão X)

A largura do módulo controla o tamanho da barra fina. Um valor comum para códigos de barras postais é 4 pixels.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Explicação** – A dimensão X influencia a legibilidade geral do código de barras. Escolher 4 px corresponde à maioria dos scanners postais.

## Etapa 3: Salvar com altura de barra automática

Quando você omite um valor de altura, o Aspose calcula a altura ideal automaticamente com base nas regras da simbologia.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Resultado** – O PNG gerado (`PostalRM4SCCBarHeightNone.png`) contém um código de barras RM4SCC com tamanho correto, pronto para impressão.

## Etapa 4: Criar um código de barras Planet com altura automática

O mesmo padrão funciona para a simbologia Planet. Comece inicializando o gerador com `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Por que reutilizar o código** – Tanto RM4SCC quanto Planet compartilham a mesma estrutura de parâmetros, permitindo trocar de simbologia alterando apenas o valor de `EncodeTypes`.

## Etapa 5: Definir uma altura de barra fixa para RM4SCC

Alguns serviços postais exigem uma altura de barra específica (por exemplo, 100 px). Você pode definir isso explicitamente antes de salvar.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Dica** – Definir `BarHeight.Pixels` substitui o cálculo automático, dando a você controle total sobre o tamanho visual.

## Etapa 6: Definir uma altura de barra fixa para Planet

Aplique a mesma técnica de altura fixa a um código de barras Planet.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Resultado** – Tanto `PostalRM4SCCBarHeight100Pixels.png` quanto `PostalPlanetBarHeight100Pixels.png` contêm códigos de barras com altura de barra consistente de 100 px, atendendo às especificações postais rigorosas.

## Código-fonte completo

Abaixo está o programa completo e executável que abrange os quatro exemplos. Copie-o para um novo projeto de console e ajuste o caminho de saída conforme necessário.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Saída esperada** – Após executar o programa, o diretório especificado contém quatro arquivos PNG:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC com altura automática
* `PostalPlanetBarHeightNone.png` – Planet com altura automática
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC com altura de 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet com altura de 100 px

Abra qualquer arquivo para verificar que as barras estão nítidas, a largura do módulo é 4 px e a altura corresponde à configuração escolhida.

## Perguntas comuns e casos extremos

| Pergunta | Resposta |
|----------|----------|
| **Posso usar outros formatos de imagem?** | Sim. Substitua `BarCodeImageFormat.Png` por `Jpeg`, `Bmp` ou `Gif` conforme necessário. |
| **E se a string de dados for mais longa?** | O gerador ajusta automaticamente o número de barras. Certifique‑se de que os dados estejam dentro dos limites de comprimento da simbologia (RM4SCC ≤ 6 dígitos, Planet ≤ 6 dígitos). |
| **Como mudar a cor da barra?** | Defina `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` antes de chamar `Save`. |
| **O DPI é importante para impressão?** | Você pode definir `rm4sccAuto.Parameters.ImageResolution.DpiX` e `DpiY` para corresponder à resolução da sua impressora. |
