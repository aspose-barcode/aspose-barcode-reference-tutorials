# Como salvar imagens de código de barras em C# usando a API BarcodeGenerator

Se você precisa **como salvar código de barras** arquivos de uma aplicação .NET, este guia mostra os passos exatos. Você verá um **exemplo completo de gerador de código de barras** que cria um código de barras DataBar Stacked Omnidirectional, ajusta sua proporção e salva dois arquivos PNG.

Salvar imagens de código de barras é uma necessidade comum ao construir sistemas de inventário, terminais de ponto de venda ou fluxos de trabalho de rotulagem automatizada. Ao final deste tutorial você poderá gerar código C# de código de barras que produz imagens confiáveis prontas para impressão ou exibição.

## Pré-requisitos

Antes de começar, certifique‑se de que você tem:

- .NET 6.0 SDK ou posterior instalado  
- Visual Studio 2022 (ou qualquer IDE compatível com C#)  
- O pacote **Aspose.BarCode for .NET** NuGet (o código usa `Aspose.BarCode.Generation`)  

Você pode adicionar o pacote com o seguinte comando:

```bash
dotnet add package Aspose.BarCode
```

## Etapa 1: Configurar um projeto de console C# mínimo

Crie um novo projeto de console e faça referência à biblioteca:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Abra `Program.cs`. O arquivo conterá o método `Main` onde colocaremos a lógica de **gerar código de barras em C#**.

## Etapa 2: Inicializar o BarcodeGenerator para um código de barras DataBar Stacked Omnidirectional

A primeira tarefa em qualquer fluxo de **criar código de barras databar** é instanciar `BarcodeGenerator` com o `EncodeType` correto. O construtor recebe a simbologia do código de barras e a string de dados.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

O valor `EncodeTypes.DatabarStackedOmniDirectional` indica à biblioteca que ela deve produzir um **código de barras databar** que pode ser escaneado de qualquer direção.

## Etapa 3: Configurar a dimensão X (largura do módulo)

A dimensão X controla a menor largura de barra em pixels. Definir um valor baixo mantém o código de barras compacto, preservando a legibilidade.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Etapa 4: **Como ajustar a proporção** – primeiro valor (15)

Os códigos de barras DataBar expõem uma propriedade `AspectRatio` que influencia a relação altura‑largura. Uma proporção maior gera um código de barras mais alto, o que pode melhorar a confiabilidade da leitura em certas impressoras.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Etapa 5: **Como salvar código de barras** – primeira imagem (proporção 15)

Agora realmente **como salvar código de barras** em um arquivo. O método `Save` recebe um caminho de arquivo e um formato de imagem. Neste exemplo armazenamos um arquivo PNG.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Dica:** O diretório do executável é o local de gravação padrão. Use um caminho absoluto se precisar de uma pasta específica.

## Etapa 6: **Como ajustar a proporção** – segundo valor (30)

Para demonstrar flexibilidade, altere a proporção e salve uma segunda imagem. Isso mostra como os mesmos dados codificados podem ser renderizados com diferentes proporções visuais.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Executar o programa produz dois arquivos PNG:

- `DatabarAspectRatio15.png` – código de barras com altura moderada  
- `DatabarAspectRatio30.png` – código de barras com altura maior para ambientes de leitura desafiadores  

Ambos os arquivos estão prontos para serem carregados em controles de UI, impressos em etiquetas ou transmitidos via API.

### Saída esperada

Ao abrir as imagens geradas, você deverá ver um código de barras DataBar Stacked Omnidirectional que codifica o valor GTIN‑14 `12345678901231`. A diferença visual entre os dois arquivos está apenas na altura, confirmando que **como ajustar a proporção** funciona como esperado.

## Etapa 7: Código-fonte completo para referência

Abaixo está o programa completo e executável. Copie‑o para `Program.cs`, compile e execute.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Perguntas comuns e tratamento de casos extremos

### E se a pasta de destino não existir?

`Save` lança uma `DirectoryNotFoundException`. Crie a pasta primeiro:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Como alterar o formato da imagem?

Substitua `BarCodeImageFormat.Png` por `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` ou `BarCodeImageFormat.Tiff` dependendo dos requisitos posteriores.

### Posso gerar vários códigos de barras em um loop?

Sim. Instancie um novo `BarcodeGenerator` para cada string de dados ou reutilize a mesma instância após atualizar a propriedade `CodeText`:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### O **como salvar código de barras** funciona em plataformas não‑Windows?

Aspose.BarCode é multiplataforma. O mesmo código funciona no Linux e macOS, desde que o runtime .NET esteja presente.
