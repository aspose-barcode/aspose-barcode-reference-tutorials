# Como criar um código de barras Planet PNG com Python

Se você precisa **criar um planet barcode PNG**, este tutorial orienta você por todo o processo usando Python. Você também aprenderá **como gerar um planet barcode** passo a passo, configurar sua aparência e salvar o resultado como uma imagem PNG de alta qualidade.

Gerar um código de barras Planet é comum em automação postal, rastreamento de inventário e sistemas logísticos. Ao final deste guia você terá um script autônomo que produz um arquivo PNG pronto para uso e entenderá como adaptar o código para diferentes tamanhos ou formatos de imagem.

## Pré-requisitos

Antes de começar, certifique‑se de que você tem:

* Python 3.8 ou superior instalado.  
* Acesso ao pacote `aspose-barcode` (ou qualquer biblioteca compatível que forneça as classes `BarcodeGenerator`, `EncodeTypes` e `BarCodeImageFormat`).  
* Permissão de gravação no diretório onde você deseja armazenar o arquivo PNG.

Você pode instalar a biblioteca necessária com pip:

```bash
pip install aspose-barcode
```

> **Dica profissional:** Use um ambiente virtual para manter as dependências isoladas de outros projetos.

## Criar planet barcode PNG – walkthrough completo do código

O script a seguir demonstra cada passo necessário para gerar um Planet barcode PNG com barras vazias (não preenchidas). Copie o código para um arquivo chamado `planet_barcode.py` e execute‑o com `python planet_barcode.py`.

```python
# planet_barcode.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Initialize a Planet barcode generator with the data to encode
# The data "123456" is a typical numeric payload for postal services.
generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

# Step 2: Set the width of each bar (X dimension) to 4 pixels.
# Adjusting the X dimension changes the overall size and readability.
generator.parameters.barcode.x_dimension.pixels = 4

# Step 3: Configure the barcode to use empty (unfilled) bars.
# When `filled_bars` is False, the dark bars become transparent,
# which is useful for overlaying the barcode on colored backgrounds.
generator.parameters.barcode.filled_bars = False

# Step 4: Save the generated barcode as a PNG image.
# The output path can be absolute or relative; ensure the folder exists.
output_path = "output/PostalPlanetEmptyBars.png"
generator.save(output_path, BarCodeImageFormat.PNG)

print(f"Planet barcode PNG saved to: {output_path}")
```

### O que cada linha faz

| Linha | Explicação |
|------|-------------|
| `from aspose.barcode import ...` | Importa as classes necessárias para criar e configurar o código de barras. |
| `BarcodeGenerator(EncodeTypes.Planet, "123456")` | Instancia um gerador para a simbologia **Planet** usando a string numérica `"123456"`. |
| `x_dimension.pixels = 4` | Define a largura da barra em 4 px; valores maiores produzem um código de barras maior, enquanto valores menores reduzem o tamanho do arquivo. |
| `filled_bars = False` | Alterna o código de barras para usar **barras vazias**, tornando os módulos escuros transparentes. |
| `save(..., BarCodeImageFormat.PNG)` | Grava o código de barras em um arquivo PNG, preservando a qualidade sem perdas. |
| `print(...)` | Confirma a criação bem‑sucedida no console. |

## Como gerar planet barcode com configurações personalizadas

Embora o script básico cubra a maioria dos casos de uso, pode ser necessário ajustar o código de barras para requisitos específicos:

1. **Comprimentos de dados diferentes** – O Planet barcode aceita até 12 caracteres numéricos. Substitua `"123456"` por qualquer string numérica válida dentro desse limite.  
2. **Formatos de imagem alternativos** – Troque `BarCodeImageFormat.PNG` por `BarCodeImageFormat.JPEG` ou `BarCodeImageFormat.BMP` para atender a pipelines de processamento posteriores.  
3. **Alterando a dimensão X** – Valores maiores (por exemplo, `8`) criam um código de barras de maior resolução, útil para impressão em etiquetas grandes.  
4. **Cores de fundo** – Se desejar um fundo colorido, defina `generator.parameters.barcode.back_color` antes de salvar.

Exemplo com cor de fundo personalizada:

```python
from aspose.barcode import Color

generator.parameters.barcode.back_color = Color.get_yellow()
generator.save("output/PlanetYellowBackground.png", BarCodeImageFormat.PNG)
```

## Armadilhas comuns e como evitá‑las

| Problema | Razão | Correção |
|----------|-------|----------|
| **FileNotFoundError** ao salvar | O diretório de destino não existe. | Crie o diretório previamente (`os.makedirs("output", exist_ok=True)`). |
| **Invalid data length** | O Planet barcode aceita apenas dados numéricos de até 12 caracteres. | Valide a string de entrada antes de criar o gerador. |
| **Transparent bars not visible** | Alguns visualizadores ignoram transparência em um canvas branco. | Coloque o código de barras sobre um fundo não branco ou exporte como PNG com canal alfa. |

## Verificando a saída

Depois de executar o script, abra `PostalPlanetEmptyBars.png` com qualquer visualizador de imagens. Você deverá ver uma série de barras verticais onde os módulos escuros são transparentes, deixando apenas o contorno do código de barras. Para confirmar que o código de barras pode ser lido, use um aplicativo de scanner móvel que suporte a simbologia Planet.

Se a imagem aparecer em branco, verifique:

* O parâmetro `filled_bars` está definido como `False`.  
* A dimensão X não está definida como zero.  
* O caminho de saída aponta para uma pasta existente.
