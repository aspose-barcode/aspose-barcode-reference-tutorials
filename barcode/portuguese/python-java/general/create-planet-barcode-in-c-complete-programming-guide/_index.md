# Criar código de barras planetário em C# – guia completo de programação

Se você precisa **criar código de barras planetário** em C#, este guia mostra exatamente como fazer isso. Você também descobrirá **como definir as dimensões do código de barras** para que as barras sejam renderizadas com a largura exata que você necessita.

Gerar códigos de barras Planet é comum quando você trabalha com serviços postais ou sistemas logísticos. O código abaixo cobre tanto a versão padrão de barras preenchidas quanto o estilo opcional de barras vazias, além de um exemplo rápido para o formato RM4SCC. Ao final deste tutorial você terá um trecho reutilizável que pode ser inserido em qualquer projeto .NET.

## Pré‑requisitos

Antes de começar, certifique‑se de que você tem:

* .NET 6.0 ou superior instalado (a API também funciona com .NET Framework 4.6+)
* O pacote NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`) adicionado ao seu projeto
* Um caminho de pasta gravável onde os arquivos PNG serão salvos
* Familiaridade básica com a sintaxe C# e Visual Studio (ou qualquer IDE)

> **Dica profissional:** Use um caminho absoluto ou `Path.Combine(Environment.CurrentDirectory, "output")` para evitar problemas de permissão ao salvar imagens.

## Etapa 1 – Inicializar um gerador de código de barras Planet (barras preenchidas)

O primeiro passo é criar uma instância de `BarcodeGenerator` para a simbologia Planet. Por padrão, o gerador produz **barras preenchidas**.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

O enum `EncodeTypes.Planet` indica ao Aspose.BarCode que deve usar o formato Planet, enquanto `"123456"` é a carga de dados que será codificada.

## Etapa 2 – Como definir as dimensões do código de barras para tamanho consistente

Para controlar a largura de cada barra, ajuste a **dimensão X**. Esta é a forma principal de **definir as dimensões do código de barras** e garante que o código caiba no tamanho da sua etiqueta.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

A propriedade `Pixels` define a largura da barra em pixels de tela. Valores comuns são 2 – 5 pixels para etiquetas de correspondência padrão; aumente o valor para impressões maiores.

## Etapa 3 – Salvar o código de barras Planet preenchido como PNG

Agora grave a imagem no disco. PNG preserva bordas nítidas, o que é ideal para a leitura.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Substitua `YOUR_DIRECTORY` pelo caminho que você preparou anteriormente. Após executar este código você verá um arquivo semelhante à imagem abaixo.

## Etapa 4 – Criar um código de barras Planet com barras vazias (não preenchidas)

Se o seu serviço postal exigir que as barras sejam **vazias**, você precisa alternar a flag `FilledBars` após inicializar o gerador.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

O construtor é idêntico; a diferença está na próxima etapa de configuração.

## Etapa 5 – Como definir as dimensões do código de barras e tornar as barras vazias

Novamente, defina a dimensão X para manter a consistência visual e, em seguida, desative as barras preenchidas.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

A propriedade `FilledBars = false` é o que realmente altera o estilo de renderização. Manter a mesma dimensão X garante que o código de barras de barras vazias alinhe perfeitamente com a versão preenchida.

## Etapa 6 – Salvar o código de barras Planet vazio

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Agora você terá dois arquivos PNG: um com barras sólidas e outro com barras ocos, ambos compartilhando as mesmas dimensões.

## Etapa 7 – (Opcional) Gerar um código de barras RM4SCC para comparação

RM4SCC é outra simbologia postal que usa o mesmo estilo padrão de barras preenchidas. As etapas espelham o exemplo Planet, demonstrando que **como definir as dimensões do código de barras** funciona em diferentes formatos.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Executar estas três etapas produz `PostalRM4SCCFilledBars.png`, que você pode comparar lado a lado com os resultados do Planet.

## Por que a dimensão X importa

A dimensão X determina a **largura mínima imprimível** de cada barra. Se você a definir muito baixa, o código de barras pode ficar borrado em impressoras de baixa resolução, causando falhas na leitura. Por outro lado, uma dimensão X muito grande pode exceder as dimensões da etiqueta e desperdiçar espaço. Ao definir explicitamente **como definir as dimensões do código de barras**, você obtém controle determinístico sobre o tamanho final da imagem, essencial para fluxos de trabalho de envio automatizado.

## Armadilhas comuns e como evitá‑las

| Problema | Causa | Solução |
|----------|-------|---------|
| O código de barras aparece esticado | Dimensão X definida em pontos em vez de pixels | Sempre use a propriedade `Pixels` para controle pixel‑perfect |
| As barras vazias ainda parecem preenchidas | `FilledBars` não definido como `false` após mudar a dimensão X | Defina `FilledBars = false` *depois* de ajustar a dimensão X |
| Arquivo salvo está em branco | Diretório de saída não existe ou falta permissão de gravação | Garanta que o diretório exista (`Directory.CreateDirectory`) e que seu app tenha direitos suficientes |
| Imagem fica borrada na impressão | PNG de baixa DPI salvo a partir de monitor de alta resolução | Use `BarCodeImageFormat.Png` (sem perdas) e considere a propriedade `Resolution` se necessário |

## Exemplo completo, executável

Copie todo o bloco abaixo para um novo projeto de console (`dotnet new console`) e execute. O programa cria três arquivos PNG na pasta `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Saída esperada:** três arquivos PNG—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` e `PostalRM4SCCFilledBars.png`—todos com barras de 4 pixels de largura, prontos para impressão ou processamento adicional.

## Conclusão

Agora você sabe como **criar código de barras planetário** em C# e como **definir precisamente as dimensões do código de barras** para estilos de barra preenchida e vazia. O mesmo padrão se aplica a outras simbologias, como RM4SCC, oferecendo uma base flexível para qualquer necessidade de código de barras postal.

Em seguida, você pode explorar:

* Adicionar texto legível ao humano abaixo do código de barras (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* Alterar cores das barras com `Parameters.Barcode.BarColor`
* Gerar códigos de barras em formatos vetoriais (SVG, EPS) para impressão escalável

Sinta‑se à vontade para experimentar diferentes valores de dimensão X, cadeias de dados e formatos de saída para adequar ao seu fluxo de trabalho específico. Boa codificação!
