# Como preencher código de barras em C# usando Aspose.BarCode

Se você precisa **preencher código de barras** em uma aplicação .NET, este tutorial mostra o processo completo. Você irá gerar um código de barras postal Planet com barras sólidas e, em seguida, criar uma versão de barras vazias do mesmo código, tudo com uma única alteração de linha de código.

O guia cobre tudo que você precisa saber: configuração do projeto, ajuste da X‑dimension, alternância entre barras preenchidas e vazias, e como verificar os arquivos PNG gerados. Nenhuma documentação externa é necessária — basta copiar o código, executá‑lo e você verá o resultado.

## Pré-requisitos

* .NET 6.0 SDK ou posterior instalado  
* Um ambiente de desenvolvimento como Visual Studio 2022 ou VS Code  
* O pacote NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

Esses itens constituem a base mínima para a parte **barcode generator c#** do tutorial.

## Como preencher código de barras – configurar o projeto

1. Crie um novo projeto de console:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Adicione o pacote Aspose.BarCode:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Abra o arquivo `Program.cs` gerado e substitua seu conteúdo pelo exemplo completo mostrado mais adiante neste artigo.

O projeto agora contém tudo que é necessário para **gerar código de barras postal**.

## Gerar código de barras postal com barras sólidas

O primeiro passo é criar um código de barras Planet que usa barras preenchidas (sólidas). Planet é a simbologia usada por muitos serviços postais para classificação.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Por que estas linhas são importantes**

* `EncodeTypes.Planet` informa ao gerador qual simbologia usar; Planet é o padrão para códigos de barras postais.  
* `XDimension.Pixels = 4` aumenta a largura do módulo, tornando o código de barras mais fácil de escanear e visualmente mais claro quando impresso.  
* `Save` grava a imagem no disco no formato PNG, um formato sem perdas adequado para processamento posterior.

Executar este bloco produz **PostalPlanetFilledBars.png**, uma imagem com barras sólidas que cumpre as especificações postais.

## Criar código de barras vazio usando a simbologia Planet

Às vezes, um sistema postal espera que as barras estejam vazias (não preenchidas) enquanto os espaços permanecem sólidos. Alternar para esse modo requer apenas uma mudança de propriedade.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Por que isso funciona**

Definir `FilledBars = false` indica ao renderizador que inverta o estilo visual: as barras tornam‑se transparentes (vazias) e o fundo torna‑se opaco. Isso é exatamente o oposto do comportamento padrão demonstrado anteriormente, permitindo que você **crie código de barras vazio** imagens sem alterar os dados codificados.

## Exemplo completo e executável

Abaixo está o programa completo que combina as duas seções. Copie‑o para `Program.cs`, substitua `YOUR_DIRECTORY/` por um caminho de pasta real e execute `dotnet run`.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Saída esperada

Após a execução você encontrará dois arquivos PNG na pasta especificada:

| Nome do arquivo               | Descrição visual |
|-------------------------------|-------------------|
| `PostalPlanetFilledBars.png`  | Barras são pretas sólidas sobre fundo branco |
| `PostalPlanetEmptyBars.png`   | Barras são transparentes (brancas) sobre fundo preto |

Ambas as imagens codificam a mesma sequência numérica `"123456"` e compartilham a mesma X‑dimension, garantindo que sejam intercambiáveis do ponto de vista de validação de dados.

## Perguntas comuns e casos extremos

**E se a pasta de saída não existir?**  
O método `Save` lança uma `DirectoryNotFoundException`. Crie a pasta antecipadamente ou envolva as chamadas em um bloco `try / catch` que crie o diretório se necessário:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Posso usar um formato de imagem diferente?**  
Sim. Substitua `BarCodeImageFormat.Png` por `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` ou qualquer formato suportado pelo Aspose.BarCode.

**A X‑dimension afeta a legibilidade pelo scanner?**  
Aumentar a largura em pixels torna as barras mais largas, o que pode melhorar a legibilidade em scanners de baixa resolução. Contudo, valores muito altos podem exceder a área imprimível. Valores típicos variam de 2 a 6 pixels para impressão a 300 dpi.

**A simbologia `EncodeTypes.Planet` é a única opção postal?**  
Não. Aspose.BarCode também suporta `EncodeTypes.Postnet` e `EncodeTypes.USPSIntelligentMail`. A mesma propriedade `FilledBars` funciona com esses tipos também.

Ajustando a X‑dimension você controla a clareza visual, e uma única troca de propriedade alterna entre barras preenchidas e vazias sem alterar os dados codificados.
