# Tutorial completo de gerador de código de barras para criar um código Planet em Python

Se você precisa de um **tutorial de gerador de código de barras** que o guie na criação de um código Planet, este guia fornece uma solução pronta‑para‑executar. Você aprenderá a criar um código Planet, definir a largura das barras, configurar barras vazias e salvar o resultado como imagem PNG — tudo em poucos passos concisos.

Este tutorial cobre tudo o que é necessário para gerar um código Planet usando a biblioteca Aspose.BarCode para Python. Ao final do guia, você terá um arquivo PNG que pode ser usado em aplicações postais, ambientes de teste ou qualquer sistema que aceite símbolos Planet.

## O que você precisará

Antes de começar, certifique‑se de que possui o seguinte:

* Python 3.8 ou mais recente
* Pacote `aspose-barcode` (instale com `pip install aspose-barcode`)
* Permissão de escrita no diretório onde o arquivo PNG será salvo

Nenhuma ferramenta externa adicional é necessária.

## Tutorial completo de gerador de código de barras: criando um código Planet

As seções a seguir dividem o processo em quatro passos claros. Cada passo explica **por que** a configuração é importante, não apenas **o que** digitar.

### Passo 1: Criar um código Planet

```python
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: instantiate the generator with the Planet symbology and data
barcode_generator = BarcodeGenerator(EncodeTypes.Planet, "123456")
```

*Por que este passo?*  
`EncodeTypes.Planet` indica à biblioteca que deve usar a simbologia Planet, que foi projetada para serviços postais. A string `"123456"` representa os dados numéricos que serão codificados. Usar um objeto gerador dedicado permite modificar parâmetros antes de renderizar a imagem.

### Passo 2: Definir a dimensão X (largura da barra)

```python
# Step 2: define the width of each bar (X dimension) in pixels
barcode_generator.parameters.barcode.x_dimension.pixels = 4
```

*Por que este passo?*  
A dimensão X controla a largura física de cada barra. Um valor de 4 pixels gera um código de barras que é facilmente legível pela maioria dos scanners, mantendo o tamanho da imagem modesto. Ajuste o valor se precisar de uma pegada visual maior ou menor.

### Passo 3: Configurar barras vazias (não preenchidas)

```python
# Step 3: configure the barcode to use empty (unfilled) bars
barcode_generator.parameters.barcode.filled_bars = False
```

*Por que este passo?*  
Códigos Planet podem ser renderizados com barras sólidas ou vazias. Definir `filled_bars` como `False` produz o estilo “barras vazias” frequentemente exigido por normas postais. Essa opção é útil quando a cor de fundo deve permanecer visível.

### Passo 4: Salvar o código de barras como imagem PNG

```python
# Step 4: save the generated barcode as a PNG file
output_path = "YOUR_DIRECTORY/PostalPlanetEmptyBars.png"
barcode_generator.save(output_path, BarCodeImageFormat.Png)
print(f"Barcode saved to {output_path}")
```

*Por que este passo?*  
`BarCodeImageFormat.Png` cria uma imagem sem perdas que preserva as bordas nítidas das barras. O método `save` grava o arquivo no disco, tornando‑o disponível para processamento posterior ou inspeção manual.

## Exemplo completo executável

Juntando os quatro passos, você obtém um script único que pode ser executado sem modificações (exceto o diretório de saída).

```python
# barcode_generator_tutorial.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_planet_barcode(data: str, output_file: str, x_dim: int = 4, filled: bool = False):
    """
    Generates a Planet barcode with the specified settings.

    Args:
        data: Numeric string to encode (e.g., "123456").
        output_file: Full path where the PNG image will be saved.
        x_dim: Width of each bar in pixels; default is 4.
        filled: When False, renders empty bars; when True, renders solid bars.
    """
    generator = BarcodeGenerator(EncodeTypes.Planet, data)
    generator.parameters.barcode.x_dimension.pixels = x_dim
    generator.parameters.barcode.filled_bars = filled
    generator.save(output_file, BarCodeImageFormat.Png)

if __name__ == "__main__":
    # Adjust the path to a writable location on your machine
    save_path = "PostalPlanetEmptyBars.png"
    create_planet_barcode("123456", save_path)
    print(f"Planet barcode created at {save_path}")
```

### Saída esperada

Ao executar o script, será gerado um arquivo chamado **PostalPlanetEmptyBars.png**. A imagem exibe um código Planet composto por barras vazias (não preenchidas) que codificam a string numérica `123456`. Ler o PNG com um leitor compatível devolve os dados originais.

## Como criar código Planet – configurações alternativas

Você pode precisar de um estilo visual diferente ou de um payload de dados distinto. As variações a seguir são comuns:

| Variação | Alteração no código | Resultado |
|-----------|---------------------|-----------|
| Barras sólidas | `filled_bars = True` | As barras são totalmente preenchidas, útil para fundos de baixo contraste |
| Barras maiores | `x_dimension.pixels = 6` | Aumenta o tamanho geral do código de barras para impressão em alta resolução |
| Comprimento de dados personalizado | Passe uma string diferente para `BarcodeGenerator` | Planet aceita até 6 caracteres numéricos; strings mais longas geram exceção |

Essas adaptações ilustram como **criar código Planet** que atendam a requisitos específicos.

## Armadilhas comuns e dicas

* **Formato dos dados** – A simbologia Planet aceita apenas caracteres numéricos (0‑9) e um comprimento máximo de seis. Fornecer caracteres não numéricos ou uma string mais longa aciona um erro de validação.
* **Permissões de diretório** – Certifique‑se de que o diretório em `output_path` exista e que o processo Python tenha permissão de escrita. Caso contrário, `save` lança um `IOError`.
* **Versão da biblioteca** – O exemplo visa Aspose.BarCode 23.9+. Versões anteriores podem usar nomes de propriedades diferentes (por exemplo, `x_dimension` em vez de `x_dimension.pixels`). Consulte as notas de versão se encontrar erros de atributo.
