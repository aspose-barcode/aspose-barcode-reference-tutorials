# Como gerar imagem de código de barras em C# com DataBar Stacked Omni‑Directional

Se você precisa **gerar imagem de código de barras** em uma aplicação .NET, este tutorial mostra os passos exatos. Você verá como criar um código de barras DataBar Stacked Omni‑Directional, ajustar sua proporção e exportar o resultado como arquivos PNG.

Gerar códigos de barras é uma necessidade comum para sistemas de inventário, terminais de ponto de venda no varejo e rastreamento logístico. Nas seções a seguir, cobriremos tudo o que você precisa — desde o pacote NuGet necessário até a verificação final da imagem — para que você possa integrar a criação de códigos de barras em qualquer projeto C# hoje.

## Pré‑requisitos

Antes de começar, certifique‑se de que você tem:

* .NET 6.0 ou superior (o código funciona com .NET Core e .NET Framework)
* Visual Studio 2022 ou qualquer IDE C# de sua preferência
* O pacote NuGet **Aspose.BarCode for .NET** (instale com `dotnet add package Aspose.BarCode`)
* Permissão de gravação na pasta onde os arquivos PNG serão salvos

Esses pré‑requisitos garantem que o exemplo seja executado sem configuração adicional.

## Etapa 1: Configurar a pasta de saída

A primeira coisa que você precisa é um diretório onde os arquivos PNG gerados serão gravados. Usar um caminho absoluto ou relativo funciona, mas certifique‑se de que a pasta exista antes de chamar `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Criar a pasta programaticamente evita *FileNotFoundException* quando o método `Save` tenta gravar a imagem.

## Etapa 2: Criar um gerador de código de barras DataBar Stacked Omni‑Directional

A classe **BarcodeGenerator** é o ponto de entrada para todos os tipos de código de barras. Aqui especificamos `EncodeTypes.DatabarStackedOmniDirectional` e a string de dados que queremos codificar.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Por que isso importa*: O enum `EncodeTypes` informa à biblioteca qual simbologia renderizar. Usar a variante Omni‑Directional garante que o código de barras possa ser escaneado a partir de qualquer orientação — um requisito para muitos scanners de armazém.

## Etapa 3: Configurar parâmetros comuns do código de barras

Um código de barras legível precisa de uma dimensão X sensata (a largura da barra mais estreita). Definir `Pixels` para 2 oferece um bom equilíbrio entre tamanho e clareza para a maioria das resoluções de tela.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Você pode ajustar `Pixels` mais tarde se precisar de uma imagem maior ou menor; a biblioteca escala automaticamente o restante do código de barras.

## Etapa 4: Gerar a primeira imagem com proporção 15

A **proporção** controla a relação altura‑largura dos códigos de barras DataBar. Uma proporção de 15 é o padrão típico para etiquetas de varejo.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Após esta chamada, você encontrará `DatabarAspectRatio15.png` na pasta de saída. A imagem é um PNG sem perdas, adequado para processamento adicional ou impressão.

## Etapa 5: Alterar a proporção para 30 e exportar uma segunda imagem

Às vezes, um código de barras mais alto é necessário — por exemplo, quando a altura da etiqueta é limitada. Alterar a proporção para 30 produz um visual mais compacto, preservando a integridade dos dados.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Agora você tem dois arquivos PNG que ilustram como os mesmos dados ficam com diferentes proporções. Essa comparação lado a lado ajuda a decidir qual variante se adapta melhor ao layout da sua etiqueta.

## Exemplo completo, executável

Abaixo está o programa completo que você pode copiar, colar e executar. Ele inclui todas as diretivas `using`, tratamento de erros e comentários que explicam cada parte do processo.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Saída esperada** (console):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Abra os dois arquivos PNG em qualquer visualizador de imagens. Você verá o mesmo GTIN codificado, mas a segunda imagem é mais alta devido à maior proporção.

## Dicas avançadas e armadilhas comuns

| Situação | Recomendação |
|-----------|----------------|
| **Exibições de baixa resolução** | Aumente `XDimension.Pixels` para 3 ou 4 para manter as barras nítidas. |
| **Impressão em papel térmico** | Use `BarCodeImageFormat.Tiff` para maior fidelidade e defina `Resolution.DpiX/DpiY` para 300. |
| **Dados dinâmicos** | Reutilize a mesma instância de `BarcodeGenerator` e atualize apenas `generator.CodeText` antes de cada `Save`. Isso evita alocação desnecessária de objetos. |
| **GTIN inválido** | A biblioteca lança `ArgumentException` se os dados não estiverem em conformidade com os padrões GS1. Valide seus dados antes de passá‑los ao gerador. |
