# 如何使用 Aspose.BarCode for .NET 產生 DataMatrix 條碼

## DataMatrix 條碼是什麼？
DataMatrix 條碼是一種二維的方形或矩形矩陣，由黑白格子組成，最多可儲存 2,335 個字母數字字元。它廣泛應用於製造、物流與醫療領域，用於標記小型物品，因即使部分受損仍能被讀取。

## 為什麼使用 Aspose.BarCode for .NET？

## 如何在 .NET 中產生 DataMatrix 條碼？

使用 `EncodeTypes.DataMatrix` 類型載入 `BarcodeGenerator`，設定欲使用的版本與 ECC，然後呼叫 `Save` 寫入影像檔。這個單行模式適用於任何選擇的版本，並會自動處理模組大小、靜止區與影像渲染。

## 匯入命名空間

`BarcodeGenerator` 是 Aspose.BarCode 用於建立條碼影像的核心類別。  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

`Aspose.BarCode.Generation` 命名空間提供 `BarcodeGenerator` 類別的存取，該類別是產生條碼影像的主要類別。

現在，我們將範例拆解為多個步驟。

## 步驟 1：設定目錄路徑

先定義要儲存產生的 DataMatrix 條碼的目錄路徑。

```csharp
string path = "Your Directory Path";
```

將 `"Your Directory Path"` 替換為實際想要儲存條碼影像的路徑。

## 步驟 2：初始化條碼產生器

建立 `BarcodeGenerator` 類別的實例，並將條碼類型指定為 `DataMatrix`。您也可以提供要編碼的資料。

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` 是建立與渲染條碼符號的主要類別。

## 步驟 3：設定條碼屬性

您可以自訂 DataMatrix 條碼的各種屬性，例如尺寸與 ECC（Error Correction Code）類型。以下範例將 X‑dimension 設為 4 像素，並選擇 ECC200：

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` 設定每個模組的像素大小，`DataMatrixEcc` 則選擇錯誤更正層級。

## 步驟 4：設定 DataMatrix 版本並儲存

您可以透過設定列數與行數來指定 DataMatrix 版本。設定完版本後，儲存條碼影像。

例如，使用 ECC200 建立 22 列 22 行的 DataMatrix 條碼：

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

同理，您可以透過變更版本與 ECC 類型產生不同參數的條碼。

## 步驟 5：為其他版本重複上述步驟

您可以重複步驟 4 產生其他 DataMatrix 版本。例如，使用 ECC200 建立 12 列 64 行的條碼：

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## 步驟 6：切換 ECC 類型

若想將 ECC 類型改為 Ecc140，只需更新 ECC 屬性：

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## 步驟 7：產生不同版本與 ECC 的條碼

對其他 DataMatrix 版本與 ECC 類型重複步驟 4，並以唯一檔名儲存每個條碼。

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

現在您已學會如何使用 Aspose.BarCode for .NET 產生 DataMatrix 條碼，能輕鬆將此功能整合至您的 .NET 應用程式。

## 常見問題與除錯技巧

- **版本尺寸不正確** – DataMatrix 版本有固定的列/行配對。提供不匹配的組合（例如 10 × 20）會拋出 `ArgumentException`。請務必使用 API 文件中列出的受支援組合。  
- **缺少授權** – 試用模式下產生的影像會帶有浮水印。請在建立產生器前以 `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` 套用有效授權，以移除浮水印。`License` 類別會載入授權檔案以啟用產品。  
- **影像尺寸過大** – 若需要高解析度輸出，可增加 `XDimension` 屬性；函式庫會按比例縮放影像而不失去可讀性。
