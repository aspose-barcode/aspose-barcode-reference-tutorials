# 如何在 C# 中使用 Aspose.BarCode 產生條碼並加入中繼資料

如果您需要在物流或庫存系統中 **在 C# 中產生條碼**，本指南將為您展示一個完整、可投入生產的解決方案。您將看到如何建立 Macro PDF417 條碼、附加豐富的中繼資料，並設定精確的時間戳記——全部使用 Aspose.BarCode 函式庫。

本教學涵蓋從安裝 NuGet 套件到儲存最終 PNG 圖片的全部步驟。完成後，您即可產生一個攜帶檔案識別碼、段落資訊與自訂欄位的條碼，供支援 Macro PDF417 的下游掃描器使用。

## 前置條件

* .NET 6.0 SDK 或更新版本（此程式碼亦相容於 .NET Framework 4.7.2 以上）
* Visual Studio 2022 或您偏好的任何 C# IDE
* 有效的 Aspose.BarCode 授權（免費試用版可用於開發）
* 基本的 C# 語法熟悉度

> **專業提示：** 若您使用 CI/CD 流程，請在專案檔中加入 Aspose.BarCode 套件參考，以確保建置可重現。

## 步驟 1：安裝 Aspose.BarCode

在專案資料夾中開啟終端機並執行：

```bash
dotnet add package Aspose.BarCode
```

此指令會取得最新的穩定版（目前為 24.9）。還原完成後，即可在原始碼檔案中引用此函式庫。

## 步驟 2：建立新的 C# 主控台專案（可選）

如果您想從頭開始，請建立一個主控台應用程式：

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs` 檔案將承載稍後示範的條碼產生程式碼。

## 步驟 3：設定條碼產生器

此流程的核心是 `BarcodeGenerator` 類別。您需要以欲使用的 `EncodeTypes` 列舉值以及要編碼的文字來建立實例。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### 為何每一行都很重要

* **EncodeTypes.MacroPdf417** 告訴 Aspose 產生可分割為多段的 PDF417 條碼。這對於超過單一符號容量的大型資料負載至關重要。
* **XDimension.Pixels** 控制視覺密度。設定為 2 可在大多數螢幕與印表機上產生清晰影像，同時不會增加檔案大小。
* **MacroPdf417* properties** 嵌入下游掃描器會以獨立欄位讀取的中繼資料（檔案 ID、段落 ID 等）。這即是教學中「如何加入中繼資料」的部分。
* **MacroPdf417TimeStamp** 示範「如何設定時間戳記」。`DateTime` 例項可以是任何 UTC 時間；使用 UTC 可避免條碼跨區域傳遞時的時區歧義。
* **MacroPdf417Terminator** 定義宏序列的結束方式。`Set` 為最常見的選擇，因為它向讀取器表示最後一段。
* **Save(..., BarCodeImageFormat.Png)** 產生無失真的影像，保留可靠掃描所需的細節。

## 步驟 4：驗證產生的條碼

執行程式：

```bash
dotnet run
```

您應該會看到以下主控台輸出：

```
Barcode saved to ExtPDF417Meta.png
```

在任何影像檢視器中開啟 `ExtPDF417Meta.png`。圖片會顯示一個緊湊的 PDF417 符號，內含文字 **Åspóse.Barcóde©** 以及嵌入的宏欄位。使用相容 PDF417 的掃描器（或支援 Macro PDF417 的手機應用程式）掃描此影像，即可回傳原始文字與您設定的中繼資料值。

### 預期的視覺特徵

* 深色且間距均勻的垂直條紋
* Aspose 自動加入的靜區（邊距）
* 無失真，因為 `XDimension` 為 2 像素正好符合 PNG 的原始解析度

## 步驟 5：常見變體與邊緣案例

### 5.1 處理特殊字元

範例文字包含 Unicode 字元（`Å`、`ó`、`©`）。Aspose.BarCode 預設使用 UTF‑8 編碼，因而在條碼中正確顯示。若需其他編碼（例如 ISO‑8859‑1），請設定：

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 大型檔案識別碼

`MacroPdf417FileID` 接受 32 位元整數。若值大於 `int.MaxValue`，請將識別碼分割至多個欄位，或使用以字串形式儲存於 `MacroPdf417FileName` 的 GUID。

### 5.3 調整欄位數量

提升 `Pdf417.Columns` 會降低條碼高度，但會使每列變寬。若條碼需適配窄標籤，請降低欄位數並自動增加列數。

### 5.4 以其他格式儲存

Aspose 支援 BMP、JPEG、TIFF 與 SVG。將 `BarCodeImageFormat.Png` 替換為所需的列舉值，例如 `BarCodeImageFormat.Svg` 以取得可縮放向量圖形。

## 常見問題

**Q: 這在 .NET Core 上可用嗎？**  
A: 可以。相同的 API 可在 .NET Core、.NET 5+ 與 .NET Framework 上使用。只需引用對應的 NuGet 套件即可。

**Q: 如果需要產生非宏式 PDF417 該怎麼辦？**  
A: 使用 `EncodeTypes.Pdf417` 取代 `EncodeTypes.MacroPdf417`。宏專屬的屬性將被忽略。

**Q: 我可以在內建欄位之外加入自訂鍵/值對嗎？**  
A: Aspose.BarCode 並未為 Macro PDF417 開放任意使用者欄位。若需額外資料，請將其編碼於主要文字負載中，或改用支援結構化附加的 QR Code。
