# 在 C# 中使用緊湊設定產生 PDF417 條碼

如果您需要在 .NET 應用程式中 **generate PDF417 barcode**，本教學將示範如何使用 Aspose.Barcode for .NET 完成。本文將一步步說明如何建立產生器、設定欄位數、X‑dimension，以及啟用緊湊模式，讓最終的符號盡可能小。

產生 PDF417 條碼在需要為票證、身分證或運送標籤編碼大量資料時相當常見。本教學涵蓋完整工作流程——從安裝函式庫到儲存最終 PNG——您只要直接 copy‑paste 程式碼到自己的專案，即可立即執行。

## 產生 PDF417 條碼的前置條件

開始之前，請確保您已具備：

* 已安裝 .NET 6.0（或更新版本）。  
* Visual Studio 2022 或任何支援 C# 專案的 IDE。  
* **Aspose.Barcode for .NET** 的 NuGet 授權（免費試用版足以學習）。  

您可以使用以下指令加入函式庫：

```bash
dotnet add package Aspose.BarCode
```

> **Pro tip:** 使用 `--version` 參數鎖定已知的穩定版本，例如 `dotnet add package Aspose.BarCode --version 23.12`。

## 建立 PDF417 條碼產生器

以下程式碼建立一個已預先設定為 PDF417 符號的 `BarcodeGenerator` 實例。文字 `"Åspóse.Barcóde©"` 含有 Unicode 字元，用以示範產生器能直接處理非 ASCII 輸入。

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### 為何這很重要
`EncodeTypes.Pdf417` 告訴 Aspose.Barcode 您想要 **PDF417 barcode**，這是一種堆疊式線性符號，最多可儲存 1 850 個字元。使用帶有文字參數的建構子可省去之後呼叫 `SetCodeText` 的步驟。

## 設定條碼 XDimension（模組大小）

模組大小（亦稱 X‑dimension）決定每根條的寬度。較小的像素會產生更密集的影像，而較大的像素則提升低解析度印表機上的可讀性。

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### 為何需要調整 XDimension
`2` 像素的設定在螢幕顯示與大多數辦公室印表機上都表現良好。若需更高解析度的列印，可提高此數值；若想要更緊湊的條碼（例如類似 QR 的外觀），則可降低，但絕不可低於 `1` 像素，否則影像將無法辨識。

## 設定 PDF417 符號的欄位數

PDF417 允許您自行決定條碼的欄位（垂直堆疊）數量。欄位較少時條碼較高，欄位較多時條碼較寬。

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### 何時調整欄位數
三個欄位會產生一個緊湊、近乎方形的符號，適合放在標準身分證上。若字串非常長，您可以增加欄位數，以保持高度在可接受範圍內。

## 啟用緊湊模式（截斷）

緊湊模式會自動移除符號中未使用的列，縮小整體尺寸。當編碼資料未填滿整個矩陣時，此功能特別有用。

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### 緊湊 PDF417 條碼的好處
將 `Truncate` 設為 `true` 後，產生器會計算儲存資料所需的最少列數，從而減少墨水使用量與掃描時間。大多數掃描器皆能安全讀取，因為 PDF417 規範已定義此截斷演算法。

## 將產生的條碼儲存為影像

最後，將條碼寫入 PNG 檔案。PNG 具備無損品質，適合之後列印或嵌入 PDF 中使用。

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### 預期輸出
執行程式後會在指定資料夾產生 `CompactPdf417.png`。該影像包含一個 **compact PDF417 barcode**，其編碼字串為 `"Åspóse.Barcóde©"`，使用三個欄位、2 像素 X‑dimension，且已套用截斷。您可以使用任何條碼掃描應用程式或 Aspose.Barcode 線上示範驗證結果。

## 常見變化與邊緣案例

| 情境 | 調整方式 |
|-----------|------------|
| **資料過長（> 1500 個字元）** | 增加 `Columns` 或手動設定 `Rows`（`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`）。 |
| **在低 DPI 印表機上列印** | 將 `XDimension.Pixels` 提升至 3 或 4，以避免像素化。 |
| **需要透明背景** | 使用 `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`。 |
| **嵌入 PDF 中** | 儲存為 `BarCodeImageFormat.Pdf`，或透過 `pdf417Generator.GenerateBarCodeImage()` 取得 `Image` 物件。 |

## 完整可執行範例

以下是您可以直接貼到新 Console 專案的完整程式碼，無需其他檔案。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

在專案資料夾執行 `dotnet run`。執行完畢後，開啟 `CompactPdf417.png` 即可看到產生的條碼。
