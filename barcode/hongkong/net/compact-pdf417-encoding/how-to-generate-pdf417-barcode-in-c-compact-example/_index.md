# 如何在 C# 中產生 PDF417 條碼 – 緊湊範例

如果您需要在 C# 應用程式中**產生 PDF417 條碼**，本指南將為您展示一個完整、可直接執行的解決方案。我們將建立一個緊湊的 PDF417 條碼、調整模組寬度、設定欄位數，並將結果儲存為 PNG 圖片——全部使用 Aspose.BarCode .NET 函式庫。

在需要以節省空間的二維格式編碼大量資料（例如 URL、聯絡卡或庫存編號）時，產生 PDF417 條碼是常見的做法。完成本教學後，您將擁有一個可運作的 `BarcodeGenerator` 實例，能產生緊湊且高可讀性的條碼，適合列印或顯示。

## 前置條件

- .NET 6.0 或更新版本（此程式碼亦相容 .NET Framework 4.8）
- Visual Studio 2022（或任何 C# IDE）
- Aspose.BarCode for .NET NuGet 套件（`Install-Package Aspose.BarCode`）
- 基本熟悉 C# 語法

不需要額外的設定；此範例以主控台應用程式執行。

## 步驟 1：建立 PDF417 條碼產生器

第一步是使用 `EncodeTypes.Pdf417` 列舉以及您想要編碼的文字來實例化 `BarcodeGenerator`。

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**為什麼這很重要：** `EncodeTypes.Pdf417` 告訴函式庫使用 PDF417 符號，而第二個參數則設定資料內容。您可以將 `"Compact example"` 替換為長度最高 1 800 個字元的任意字串。

## 步驟 2：設定模組寬度（X‑dimension）為像素

X‑dimension 定義單一條碼模組（最小的黑或白方格）的寬度。較小的像素值會產生更緊密的條碼。

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**為什麼這很重要：** `2` 像素的數值可在大多數現代掃描器上保持掃描可靠性，同時呈現緊湊外觀。如需在低解析度列印時使用較大的模組，請調整此數值。

## 步驟 3：指定欄位數量

PDF417 允許您控制欄位數量，這會影響條碼的長寬比。

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**為什麼這很重要：** 欄位較少會使條碼變高，欄位較多則會使其變寬。三欄位在緊湊的直向版面配置中表現良好。

## 步驟 4：透過截斷條碼啟用緊湊模式

緊湊模式會移除不必要的填充列，使條碼尺寸變小，同時保留編碼資料。

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**為什麼這很重要：** 當螢幕空間受限（例如行動應用程式或小尺寸標籤）時，截斷非常適合。條碼仍保持完全可讀，因為編碼演算法會自動調整錯誤更正等級。

## 步驟 5：將條碼儲存為 PNG 圖片

最後，將產生的條碼寫入檔案。PNG 保留無損品質，對條碼掃描器而言至關重要。

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

執行程式後會在可執行檔的工作目錄中產生 `CompactPdf417.png`。圖像如下所示：

![產生的緊湊 PDF417 條碼](CompactPdf417.png "產生的緊湊 PDF417 條碼")

**預期輸出：** 一個寬度為 2 像素、三欄位的 PDF417 條碼，編碼文字為 “Compact example”。使用標準條碼掃描器掃描此 PNG 應返回原始字串。

## 常見變化與邊緣情況

| 情況 | 如何調整程式碼 |
|-----------|------------------------|
| **較長資料（> 500 個字元）** | Increase `Columns` to 5‑7 to keep the barcode from becoming too tall. |
| **高解析度列印** | Set `XDimension.Pixels` to 3 or 4 for larger modules. |
| **不同的影像格式** | Replace `BarCodeImageFormat.Png` with `Jpeg` or `Bmp` as needed. |
| **將條碼嵌入 PDF** | Use `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` instead of PNG. |

**小技巧：** 始終在目標掃描硬體上測試產生的條碼。某些低成本掃描器在極小的 X‑dimension 下會有困難；若遇到讀取錯誤，請將像素值提升一步。

## 完整、可執行範例

以下是完整的程式碼，您可以直接複製貼上到新的主控台專案中。無需其他檔案。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

編譯並執行程式（若使用 .NET CLI，執行 `dotnet run`）。執行完畢後，開啟 `CompactPdf417.png` 以驗證視覺結果。

## 結論

您現在已了解如何在 C# 中**產生 PDF417 條碼**，使用緊湊版面、客製化 X‑dimension 與欄位設定。此範例示範了關鍵步驟：實例化 `BarcodeGenerator`、設定 `XDimension` 與 `Columns`、啟用 `Truncate` 以進入緊湊模式，最後儲存圖像。

接下來，您可以探索其他功能，例如錯誤更正等級、客製化顏色，或直接將條碼嵌入 PDF。若需要其他符號（例如 QR、Code128），可嘗試不同的 `EncodeTypes`，並套用相同的參數設定模式。
