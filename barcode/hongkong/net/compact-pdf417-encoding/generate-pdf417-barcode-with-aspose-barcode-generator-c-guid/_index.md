# 使用 Aspose Barcode Generator 產生 PDF417 條碼 – C# 指南

如果您需要在 .NET 專案中 **產生 PDF417 條碼**，本教學將會完整示範如何使用 **Aspose Barcode Generator**。您將看到一個完整且可執行的範例，該範例會建立緊湊的 PDF417 符號、調整其大小，並將結果儲存為 PNG 檔案。

產生 PDF417 條碼在需要將大量資料（例如 URL、聯絡資訊或庫存記錄）編碼成單一可掃描影像時相當常見。本指南涵蓋從安裝函式庫到微調 **how to set PDF417** 選項以取得緊湊輸出的全部步驟。

## 您將學習到

* 在 C# 專案中安裝並引用 Aspose.BarCode 函式庫。  
* 使用 **aspose barcode generator** 從任意文字建立 PDF417 符號。  
* 套用 **how to set PDF417** 參數 — 模組大小、欄位數量與緊湊模式。  
* 將條碼儲存為 PNG 圖片並驗證結果。  

**先決條件**

* .NET 6.0 SDK 或更新版本（程式碼亦相容 .NET Core 3.1 與 .NET Framework 4.7+）。  
* 具備 C# 主控台應用程式的基本知識。  
* 有效的 Aspose.BarCode 授權（免費評估版可用於開發）。

## 步驟 1：產生 PDF417 條碼 – 建立產生器

第一步是以目標文字與 PDF417 符號化方式實例化產生器。此步驟直接回應 **how to generate pdf417** 的問題。

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Create a BarcodeGenerator for PDF417 with the data you want to encode.
            // The EncodeTypes enum selects the symbology; Pdf417 is the target type.
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");
```

**為何這很重要：**  
`EncodeTypes.Pdf417` 告訴函式庫使用 PDF417 演算法，支援最多 1,850 個字元。建構子同時接受原始資料字串；任何 Unicode 字元（含重音）皆會自動處理。

## 步驟 2：設定 PDF417 參數 – 自訂大小與版面

PDF417 條碼可以以多種形狀呈現。調整 **how to set pdf417** 選項可讓您建立適合小標籤或行動裝置螢幕的緊湊符號。

```csharp
            // -----------------------------------------------------------------
            // Step 2: Set visual parameters for the barcode
            // -----------------------------------------------------------------

            // Module size – each tiny square (pixel) of the barcode.
            // Smaller values produce a tighter image; 2 pixels is a good default.
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Number of columns – controls the width of the barcode.
            // Fewer columns make the symbol taller; 3 columns yields a compact shape.
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode – removes unnecessary quiet zones and reduces height.
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;
```

**各設定說明**

| 參數 | 效果 | 使用時機 |
|-----------|--------|-------------|
| `XDimension.Pixels` | 控制單一模組的寬度。較低的數值會縮小條碼，但可能影響低解析度裝置的掃描可讀性。 | 在螢幕顯示時使用 `2`–`4`；列印標籤時則增大。 |
| `Pdf417.Columns` | 決定符號包含多少資料欄位。欄位較少會產生較高且較窄的條碼。 | 緊湊版面選擇 `3`–`5`；較寬條碼則使用更高的值。 |
| `Pdf417.Truncate` | 開啟「緊湊模式」，會移除外部安靜區並降低整體高度。 | 適用於空間受限的 UI 元素。 |

這三個設定共同回應 **how to set pdf417** 的需求，讓您能細緻控制最終圖像。

## 步驟 3：儲存條碼影像 – 匯出為 PNG

設定完產生器後，您需要將條碼寫入檔案。`Save` 方法支援多種格式；PNG 保持無損品質，且適用於 Web 與桌面情境。

```csharp
            // -----------------------------------------------------------------
            // Step 3: Save the generated barcode as a PNG image
            // -----------------------------------------------------------------

            // Replace YOUR_DIRECTORY with an actual folder on your machine.
            string outputPath = @"C:\Barcodes\CompactPdf417.png";

            // BarCodeImageFormat.Png tells Aspose to write a PNG file.
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            // Inform the user that the process succeeded.
            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**您應該會看到**

執行程式會在指定資料夾產生 `CompactPdf417.png`。該影像包含一個密集的 PDF417 符號，編碼字串 `Åspóse.Barcóde©`。大多數條碼掃描器與行動應用程式（例如 ZXing、Scandit）皆可在不需額外設定的情況下讀取此影像。

## 完整原始碼 – 可直接複製貼上

以下為完整程式碼，包含 `using` 指令與 `Main` 方法。您可以直接將其貼入新的主控台專案並立即執行。

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Step 1: Create the generator (how to generate pdf417)
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");

            // Step 2: Set PDF417 options (how to set pdf417)
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;   // module size
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;    // number of columns
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact mode

            // Step 3: Save as PNG
            string outputPath = @"C:\Barcodes\CompactPdf417.png";
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**執行程式碼**

1. 開啟終端機並建立新主控台專案：  
   `dotnet new console -n Pdf417Demo`  
2. 加入 Aspose.BarCode NuGet 套件：  
   `dotnet add package Aspose.BarCode`  
3. 將產生的 `Program.cs` 替換為上述程式碼。  
4. 編譯並執行：  
   `dotnet run`  

您應會看到確認訊息，且在您指定的位置找到 PNG 檔案。

## 常見陷阱與最佳實踐提示

* **授權過期** – 評估版在 30 天後會加上浮水印。請提前註冊授權以免意外。  
* **目錄權限** – 確認目標資料夾已存在且程式具有寫入權限；否則 `Save` 會拋出 `UnauthorizedAccessException`。  
* **掃描器相容性** – 若掃描器無法讀取緊湊條碼，請將 `XDimension.Pixels` 提升至 `4` 或將 `Truncate = false`。  
* **Unicode 處理** – Aspose.BarCode 完全支援 UTF‑8，您可直接編碼任何 Unicode 字串，無需額外步驟。  
* **效能** – 在迴圈中產生大量條碼時，重複使用單一 `BarcodeGenerator` 實例並僅在迭代間更新 `CodeText` 可提升效能。
