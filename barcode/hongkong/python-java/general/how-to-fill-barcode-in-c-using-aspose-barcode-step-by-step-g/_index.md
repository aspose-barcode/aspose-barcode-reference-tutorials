# 如何在 C# 中使用 Aspose.BarCode 填充條碼

如果您需要在 .NET 應用程式中 **填充條碼**，本教學將展示完整流程。您將產生一個使用實心條的郵政 Planet 條碼，然後建立相同條碼的空條版本，只需更改一行程式碼。

本指南涵蓋您需要了解的全部內容：專案設定、X‑dimension 調整、在實心與空白條之間切換，以及如何驗證產生的 PNG 檔案。無需外部文件說明——只要複製程式碼、執行，即可看到結果。

## 先決條件

在開始之前，請確保您已具備：

* .NET 6.0 SDK 或更新版本已安裝  
* 開發環境，例如 Visual Studio 2022 或 VS Code  
* **Aspose.BarCode for .NET** NuGet 套件 (`Aspose.BarCode`)  

這些項目構成本教學中 **barcode generator c#** 部分的最小基礎。

## 如何填充條碼 – 設定專案

1. 建立一個新的主控台專案：

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. 新增 Aspose.BarCode 套件：

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. 開啟產生的 `Program.cs` 檔案，將其內容取代為本文稍後示範的完整範例。

現在的專案已包含產生 **generate postal barcode** 圖片所需的全部內容。

## 產生實心條的郵政條碼

第一步是建立使用實心條的 Planet 條碼。Planet 是許多郵政服務用於分揀的符號系統。

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**為什麼這些程式碼很重要**

* `EncodeTypes.Planet` 告訴產生器使用哪種符號系統；Planet 是郵政條碼的標準。  
* `XDimension.Pixels = 4` 增加模組寬度，使條碼更易於掃描，列印時視覺上也更清晰。  
* `Save` 以 PNG 格式將影像寫入磁碟，PNG 為無損格式，適合後續處理。

執行此區塊會產生 **PostalPlanetFilledBars.png**，一張符合郵政規範的實心條圖像。

## 使用 Planet 符號建立空條條碼

有時郵政系統要求條碼的條為空（未填滿），而空格保持實心。只需變更一個屬性即可切換至此模式。

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**為什麼這樣會起作用**

設定 `FilledBars = false` 會指示渲染器反轉視覺樣式：條變為透明（空白），背景則變為不透明。這正好與前述的預設行為相反，讓您可以 **create empty barcode** 圖片而不必更改編碼資料。

## 完整、可執行的範例

以下是結合上述兩個部分的完整程式。將它複製到 `Program.cs`，將 `YOUR_DIRECTORY/` 替換為實際的資料夾路徑，然後執行 `dotnet run`。

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### 預期輸出

執行後，您會在指定的資料夾中找到兩個 PNG 檔案：

| 檔案名稱                     | 視覺說明 |
|-------------------------------|--------------------|
| `PostalPlanetFilledBars.png`  | 條碼為實心黑色，背景為白色 |
| `PostalPlanetEmptyBars.png`   | 條碼為透明（白色），背景為黑色 |

兩張影像皆編碼相同的數字字串 `"123456"`，且使用相同的 X‑dimension，確保在資料驗證層面上可互換。

## 常見問題與邊緣情況

**如果輸出資料夾不存在會怎樣？**  
`Save` 方法會拋出 `DirectoryNotFoundException`。請事先建立資料夾，或將呼叫包在 `try / catch` 區塊中，必要時自動建立目錄：

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**我可以使用其他影像格式嗎？**  
可以。將 `BarCodeImageFormat.Png` 替換為 `BarCodeImageFormat.Jpeg`、`BarCodeImageFormat.Bmp`，或任何 Aspose.BarCode 支援的格式。

**X‑dimension 會影響掃描器的可讀性嗎？**  
增加像素寬度會使條碼變寬，對低解析度掃描器的可讀性有提升。但過大的值可能超出可列印範圍。一般列印於 300 dpi 時，常見值介於 2 至 6 像素之間。

**`EncodeTypes.Planet` 符號是唯一的郵政選項嗎？**  
不是。Aspose.BarCode 亦支援 `EncodeTypes.Postnet` 與 `EncodeTypes.USPSIntelligentMail`。相同的 `FilledBars` 屬性同樣適用於這些類型。

## 結論

您現在已了解如何使用 Aspose.BarCode 函式庫在 C# 中 **填充條碼** 圖片，如何 **產生郵政條碼** 變體，以及如何使用 Planet 符號 **建立空條條碼** 版本。透過調整 X‑dimension 可控制視覺清晰度，而僅透過單一屬性切換即可在實心與空白條之間切換，且不需更改編碼資料。

接下來，您可以探索其他功能，例如加入可讀文字、變更顏色，或將條碼嵌入 PDF 文件。所有這些延伸功能皆建立在本指南示範的 **barcode generator c#** 基礎之上。
