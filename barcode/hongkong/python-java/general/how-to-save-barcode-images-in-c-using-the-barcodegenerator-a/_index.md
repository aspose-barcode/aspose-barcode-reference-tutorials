# 如何在 C# 中使用 BarcodeGenerator API 保存條碼圖像

如果您需要從 .NET 應用程式 **how to save barcode** 檔案，本指南將展示完整步驟。您將看到一個完整的 **barcode generator example**，它會建立 DataBar Stacked Omnidirectional 條碼、調整其長寬比，並儲存兩個 PNG 檔案。

在建構庫存系統、銷售點終端或自動標籤工作流程時，儲存條碼圖像是一項常見需求。完成本教學後，您將能產生 barcode C# 程式碼，產出可直接列印或顯示的可靠圖像。

## 前置條件

- .NET 6.0 SDK 或更新版本已安裝  
- Visual Studio 2022（或任何相容 C# 的 IDE）  
- **Aspose.BarCode for .NET** NuGet 套件（程式碼使用 `Aspose.BarCode.Generation`）  

您可以使用以下指令加入套件：

```bash
dotnet add package Aspose.BarCode
```

## 步驟 1：建立最小的 C# 主控台專案

建立新的主控台專案並參考此函式庫：

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

開啟 `Program.cs`。此檔案將包含 `Main` 方法，我們將在此放入 **generate barcode C#** 邏輯。

## 步驟 2：為 DataBar Stacked Omnidirectional 條碼初始化 BarcodeGenerator

在任何 **create databar barcode** 工作流程中的第一步是以正確的 `EncodeType` 實例化 `BarcodeGenerator`。建構函式會接受條碼符號與資料字串。

以下為程式碼：

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

`EncodeTypes.DatabarStackedOmniDirectional` 值告訴函式庫產生一個 **create databar barcode**，可從任何方向掃描。

## 步驟 3：設定 X‑dimension（模組寬度）

X‑dimension 控制最小條寬（以像素為單位）。將其設定為較低的值可保持條碼緊湊，同時維持可讀性。

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## 步驟 4：**How to adjust aspect ratio** – 第一個值 (15)

DataBar 條碼提供 `AspectRatio` 屬性，會影響高度與寬度的比例。較高的比例會產生較高的條碼，這可提升某些印表機的掃描可靠度。

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## 步驟 5：**How to save barcode** – 第一張影像（長寬比 15）

現在我們實際執行 **how to save barcode** 到檔案。`Save` 方法接受檔案路徑與影像格式。在此範例中我們儲存為 PNG 檔案。

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **提示：** 可執行檔所在目錄是預設寫入位置。如需特定資料夾，請使用絕對路徑。

## 步驟 6：**How to adjust aspect ratio** – 第二個值 (30)

為示範彈性，我們變更長寬比並儲存第二張影像。這說明相同的編碼資料可以不同的視覺比例呈現。

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

執行程式會產生兩個 PNG 檔案：

- `DatabarAspectRatio15.png` – 條碼高度適中  
- `DatabarAspectRatio30.png` – 條碼高度較高，適用於掃描環境較嚴苛的情況  

兩個檔案皆可載入 UI 控制項、列印於標籤，或透過 API 傳送。

### 預期輸出

開啟產生的圖像時，您應該會看到一個 DataBar Stacked Omnidirectional 條碼，編碼的 GTIN‑14 值為 `12345678901231`。兩個檔案的視覺差異僅在於高度，證實 **how to adjust aspect ratio** 如預期運作。

## 步驟 7：完整原始碼供參考

以下為完整且可執行的程式。將其複製到 `Program.cs`，編譯並執行。

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## 常見問題與邊緣案例處理

### 若目標資料夾不存在該怎麼辦？

`Save` 會拋出 `DirectoryNotFoundException`。請先建立該目錄：

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### 如何變更影像格式？

將 `BarCodeImageFormat.Png` 替換為 `BarCodeImageFormat.Jpeg`、`BarCodeImageFormat.Bmp` 或 `BarCodeImageFormat.Tiff`，視下游需求而定。

### 我可以在迴圈中產生多個條碼嗎？

可以。為每個資料字串實例化新的 `BarcodeGenerator`，或在更新 `CodeText` 屬性後重複使用同一個實例：

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### **how to save barcode** 在非 Windows 平台上能運作嗎？

Aspose.BarCode 為跨平台套件。只要安裝 .NET 執行環境，相同程式碼即可在 Linux 與 macOS 上執行。
