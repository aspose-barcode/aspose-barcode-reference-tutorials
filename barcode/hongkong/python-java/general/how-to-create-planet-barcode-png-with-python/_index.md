# 如何使用 Python 建立 planet barcode PNG

如果您需要 **建立 planet barcode PNG**，本教學將逐步說明使用 Python 完成整個流程。您亦會學習 **如何產生 planet barcode** 的步驟、設定外觀，並將結果儲存為高品質的 PNG 圖片。

在郵務自動化、庫存追蹤及物流系統中，產生 Planet 條碼相當常見。完成本指南後，您將擁有一個獨立的腳本，可產生可直接使用的 PNG 檔案，並了解如何為不同尺寸或影像格式調整程式碼。

## 前置條件

* 已安裝 Python 3.8 或更新版本。
* 可取得 `aspose-barcode` 套件（或任何提供 `BarcodeGenerator`、`EncodeTypes` 與 `BarCodeImageFormat` 類別的相容函式庫）。
* 具有寫入欲儲存 PNG 檔案之目錄的權限。

您可以使用 pip 安裝所需的函式庫：

```bash
pip install aspose-barcode
```

> **小技巧：** 使用虛擬環境可將相依套件與其他專案隔離。

## 建立 planet barcode PNG – 完整程式碼說明

以下腳本示範產生帶有空白（未填充）條紋的 Planet barcode PNG 所需的每一步。將程式碼複製到名為 `planet_barcode.py` 的檔案中，並以 `python planet_barcode.py` 執行。

```python
# planet_barcode.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Initialize a Planet barcode generator with the data to encode
# The data "123456" is a typical numeric payload for postal services.
generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

# Step 2: Set the width of each bar (X dimension) to 4 pixels.
# Adjusting the X dimension changes the overall size and readability.
generator.parameters.barcode.x_dimension.pixels = 4

# Step 3: Configure the barcode to use empty (unfilled) bars.
# When `filled_bars` is False, the dark bars become transparent,
# which is useful for overlaying the barcode on colored backgrounds.
generator.parameters.barcode.filled_bars = False

# Step 4: Save the generated barcode as a PNG image.
# The output path can be absolute or relative; ensure the folder exists.
output_path = "output/PostalPlanetEmptyBars.png"
generator.save(output_path, BarCodeImageFormat.PNG)

print(f"Planet barcode PNG saved to: {output_path}")
```

### 各行說明

| Line | 說明 |
|------|------|
| `from aspose.barcode import ...` | 匯入建立與設定條碼所需的類別。 |
| `BarcodeGenerator(EncodeTypes.Planet, "123456")` | 使用數字字串 `"123456"` 建立 **Planet** 符號的產生器實例。 |
| `x_dimension.pixels = 4` | 設定條紋寬度為 4 px；較大的數值會產生較大的條碼，較小的數值則可減少檔案大小。 |
| `filled_bars = False` | 將條碼切換為使用 **empty bars**，使深色模組變為透明。 |
| `save(..., BarCodeImageFormat.PNG)` | 將條碼寫入 PNG 檔案，保留無損品質。 |
| `print(...)` | 在主控台確認成功建立。 |

## 如何使用自訂設定產生 planet barcode

雖然基本腳本已涵蓋大多數使用情境，但您可能需要針對特定需求調整條碼：

1. **不同的資料長度** – Planet 條碼支援最多 12 個數字字元。將 `"123456"` 更改為該範圍內的任何有效數字字串。
2. **其他影像格式** – 將 `BarCodeImageFormat.PNG` 替換為 `BarCodeImageFormat.JPEG` 或 `BarCodeImageFormat.BMP`，以符合後續處理流程。
3. **變更 X 維度** – 較大的數值（例如 `8`）會產生更高解析度的條碼，對於在大型標籤上列印很有幫助。
4. **背景顏色** – 若需彩色背景，請在儲存前設定 `generator.parameters.barcode.back_color`。

以下為自訂背景顏色的範例：

```python
from aspose.barcode import Color

generator.parameters.barcode.back_color = Color.get_yellow()
generator.save("output/PlanetYellowBackground.png", BarCodeImageFormat.PNG)
```

## 常見陷阱與避免方法

| 問題 | 原因 | 解決方案 |
|------|------|----------|
| **FileNotFoundError** 在儲存時 | 目標目錄不存在。 | 事先建立目錄（`os.makedirs("output", exist_ok=True)`）。 |
| **Invalid data length** | Planet 條碼僅接受最多 12 個數字字元。 | 在建立產生器前驗證輸入字串。 |
| **Transparent bars not visible** | 某些檢視器會忽略白色畫布上的透明度。 | 將條碼放置於非白色背景，或以具 alpha 通道的 PNG 匯出。 |

## 驗證輸出結果

執行腳本後，使用任何影像檢視器開啟 `PostalPlanetEmptyBars.png`。您應該會看到垂直條紋，深色模組為透明，只留下條碼的輪廓。若要確認條碼可被掃描，請使用支援 Planet 符號的手機條碼掃描應用程式。

若影像顯示為空白，請再次檢查：

* `filled_bars` 旗標已設定為 `False`。
* X 維度未被設定為零。
* 輸出路徑指向已存在的資料夾。
