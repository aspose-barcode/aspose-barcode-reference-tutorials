# 在 C# 中建立 Planet 條碼 – 完整程式指南

如果你需要在 C# 中 **建立 Planet 條碼**，本指南會精確說明如何操作。你亦會了解 **如何設定條碼尺寸**，以確保條碼的條寬符合你的需求。

在處理郵務服務或物流系統時，產生 Planet 條碼是相當常見的需求。以下程式碼同時示範預設的實心條版本與可選的空心條樣式，並提供 RM4SCC 格式的快速範例。完成本教學後，你將擁有一段可重複使用的程式碼片段，能直接放入任何 .NET 專案中。

## 前置條件

在開始之前，請確保你已具備：

* 已安裝 .NET 6.0 或更新版本（此 API 亦相容 .NET Framework 4.6+）
* 專案已加入 **Aspose.BarCode for .NET** NuGet 套件 (`Aspose.BarCode`)
* 可寫入的資料夾路徑，用於儲存 PNG 檔案
* 具備基本的 C# 語法與 Visual Studio（或其他 IDE）使用經驗

> **專業提示：** 使用絕對路徑或 `Path.Combine(Environment.CurrentDirectory, "output")` 以避免儲存影像時的權限問題。

## 步驟 1 – 初始化 Planet 條碼產生器（實心條）

第一步是為 Planet 符號建立 `BarcodeGenerator` 實例。預設情況下產生器會產生 **實心** 條。

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

`EncodeTypes.Planet` 列舉告訴 Aspose.BarCode 使用 Planet 格式，而 `"123456"` 則是要編碼的資料內容。

## 步驟 2 – 如何設定條碼尺寸以確保尺寸一致

若要控制每條的寬度，請調整 **X‑dimension**。這是 **設定條碼尺寸** 的主要方式，能確保條碼符合標籤尺寸。

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

`Pixels` 屬性以螢幕像素定義條寬。一般郵寄標籤常用 2 – 5 像素；若需較大印刷可提高此數值。

## 步驟 3 – 將實心 Planet 條碼儲存為 PNG

將影像寫入磁碟。PNG 可保留銳利邊緣，最適合掃描使用。

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

將 `YOUR_DIRECTORY` 替換為先前準備好的路徑。執行程式後，你會看到與下圖類似的檔案。

![Planet barcode with filled bars](planet_filled.png "Planet barcode with filled bars – created by C# code")

## 步驟 4 – 建立具有空心條的 Planet 條碼

若郵務單位要求條碼為 **空心**，則需在初始化產生器後切換 `FilledBars` 旗標。

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

建構子保持相同；差異在於接下來的設定步驟。

## 步驟 5 – 如何設定條碼尺寸並使條碼為空心

同樣先設定 X‑dimension 以保持視覺一致性，然後關閉實心條。

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

`FilledBars = false` 屬性才是真正改變繪製樣式的關鍵。保持相同的 X‑dimension 可讓空心條碼與實心版本完美對齊。

## 步驟 6 – 儲存空心 Planet 條碼

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

此時你會得到兩個 PNG 檔案：一個實心條，另一個空心條，兩者尺寸相同。

## 步驟 7 – （可選）產生 RM4SCC 條碼作為比較

RM4SCC 是另一種郵務符號，同樣使用預設的實心條樣式。步驟與 Planet 範例相同，說明 **如何設定條碼尺寸** 可跨格式使用。

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

執行上述三個步驟後會產生 `PostalRM4SCCFilledBars.png`，可與 Planet 輸出並排比較。

## 為何 X‑dimension 重要

X‑dimension 決定每條的 **最小可列印寬度**。若設定過低，條碼在低解析度印表機上可能模糊，導致掃描失敗。相反，若設定過大，則可能超出標籤尺寸並浪費空間。透過明確的 **如何設定條碼尺寸**，即可對最終影像大小取得確定性的控制，這對自動化郵寄工作流程至關重要。

## 常見陷阱與避免方式

| 問題 | 原因 | 解決方式 |
|-------|-------|-----|
| 條碼顯示被拉長 | X‑dimension 使用點 (points) 而非像素 | 永遠使用 `Pixels` 屬性以取得像素級控制 |
| 空心條仍顯示為實心 | 在調整 X‑dimension 後未將 `FilledBars` 設為 `false` | 在調整 X‑dimension **之後** 設定 `FilledBars = false` |
| 儲存的檔案為空白 | 輸出目錄不存在或缺乏寫入權限 | 確認目錄已建立 (`Directory.CreateDirectory`) 且應用程式具備足夠權限 |
| 印刷時影像模糊 | 從高解析度螢幕直接儲存低 DPI PNG | 使用 `BarCodeImageFormat.Png`（無損）並視需要設定 `Resolution` 屬性 |

## 完整、可執行的範例

將下方程式碼完整複製到新的主控台專案（`dotnet new console`）中，然後執行。程式會在 `output` 資料夾產生三個 PNG 檔案。

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**預期結果：** 產生三個 PNG 檔案 — `PostalPlanetFilledBars.png`、`PostalPlanetEmptyBars.png`、`PostalRM4SCCFilledBars.png` — 每條寬度為 4 像素，隨時可列印或進一步處理。

## 結論

現在你已掌握如何在 C# 中 **建立 Planet 條碼**，以及如何精確 **設定條碼尺寸** 以支援實心與空心條樣式。同樣的模式也適用於其他符號，例如 RM4SCC，為任何郵務條碼需求提供彈性基礎。

* 產生向量格式（SVG、EPS）以利可縮放列印

歡迎自行嘗試不同的 X‑dimension、資料字串與輸出格式，以符合你的工作流程。祝程式開發順利！
