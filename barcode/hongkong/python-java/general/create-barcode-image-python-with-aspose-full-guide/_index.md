# 使用 Aspose 建立條碼影像（Python）完整教學

如果您需要 **建立條碼影像（Python）**，Aspose.Barcode 提供簡潔的 API，免除猜測的麻煩。本教學將帶您一步步產生 Planet 條碼、調整尺寸，並將結果儲存為 PNG 檔案——全部只需幾行 Python 程式碼。

您還會學會 **自訂條碼尺寸**、了解 X‑dimension 為何影響掃描器的可靠性，以及將產生的影像放置於專案結構的適當位置。除了 Aspose.Barcode 套件外，無需其他外部工具。

## 需要的環境

在開始之前，請確保您已具備：

- 已安裝 Python 3.8 或更新版本  
- 透過 [pip](https://pypi.org/project/aspose-barcode/) 安裝 Aspose.Barcode for Python (`pip install aspose-barcode`)  
- 具有寫入 PNG 檔案之目錄的寫入權限  

上述前置條件可確保程式碼在執行時不會因權限或相容性問題而失敗。

## 使用 Aspose.Barcode 建立條碼影像（Python）

第一步是匯入必要的類別，並實例化 `BarcodeGenerator`。此產生器同時保存條碼類型與要編碼的資料。

```python
# Import Aspose.Barcode classes
from asposebarcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Initialize a generator for a Planet barcode with the data "123456"
barcode_generator = BarcodeGenerator(EncodeTypes.Planet, "123456")
```

*為什麼這很重要：*  
`EncodeTypes.Planet` 告訴 Aspose 使用 Planet 符號系統，這是郵件應用的理想選擇。資料字串 `"123456"` 會成為條碼的可讀文字部分。

## 產生 Planet 條碼

產生器準備好後，您即可立即在記憶體中建立條碼影像。然而，在大多數實務情境下，需要調整尺寸以符合印刷標準。

```python
# Generate the barcode image (in memory) – no file written yet
image = barcode_generator.generate_barcode_image()
```

呼叫 `generate_barcode_image()` 會回傳 `byte[]`，您可以直接串流至 Web 回應；但在本教學中，我們會在自訂尺寸後將其儲存至磁碟。

## 自訂條碼尺寸

有兩個參數會控制條碼的視覺大小：

1. **X‑dimension** – 最窄條（模組）的寬度。  
2. **Bar height** – 條的整體高度。

使用 `set_pixels` 輔助方法時，兩者皆以像素為單位。

```python
# Access the parameter object
params = barcode_generator.parameters

# Set the X‑dimension to 4 pixels (makes each module 4 px wide)
params.barcode.x_dimension.set_pixels(4)

# Force a bar height of 100 pixels for better readability
params.barcode.bar_height.set_pixels(100)
```

*小技巧：* 較大的 X‑dimension 能提升低解析度印表機的可讀性，而較高的 bar height 則有助掃描器將條碼與周圍圖形區分開來。

## 儲存條碼為 PNG

最後，將自訂好的條碼寫入 PNG 檔案。`save` 方法會自動處理格式轉換。

```python
# Define the output path – change YOUR_DIRECTORY to your desired folder
output_path = "YOUR_DIRECTORY/PostalPlanetBarHeight100.png"

# Save the barcode as a PNG image
barcode_generator.save(output_path, BarCodeImageFormat.Png)
```

腳本執行完畢後，`PostalPlanetBarHeight100.png` 會包含一個符合指定尺寸的清晰 Planet 條碼。

![Barcode image generated by Aspose showing a Planet barcode](/images/planet-barcode.png){: .center-image alt="Aspose 產生的 Planet 條碼影像"}

*預期輸出：* PNG 會顯示編碼為 “123456” 的 Planet 條碼。條寬為 4 px，條高為 100 px，預設背景為透明。

## 完整腳本 – 產生條碼（Aspose 完整範例）

以下是結合所有步驟的完整可執行腳本。將其複製到名為 `generate_planet_barcode.py` 的檔案中，然後以 `python generate_planet_barcode.py` 執行。

```python
# generate_planet_barcode.py
# Complete example: create barcode image python with Aspose.Barcode

from asposebarcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def main():
    # 1️⃣ Initialize generator for Planet barcode
    generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

    # 2️⃣ Customize size: X‑dimension = 4 px, bar height = 100 px
    params = generator.parameters
    params.barcode.x_dimension.set_pixels(4)
    params.barcode.bar_height.set_pixels(100)

    # 3️⃣ Save as PNG
    output_file = "output/PostalPlanetBarHeight100.png"
    generator.save(output_file, BarCodeImageFormat.Png)
    print(f"Barcode saved to {output_file}")

if __name__ == "__main__":
    main()
```

執行腳本後會印出：

```
Barcode saved to output/PostalPlanetBarHeight100.png
```

您可以使用任何影像檢視器開啟 PNG，以驗證條碼外觀。

## 常見問題與邊緣案例

| 問題 | 解答 |
|----------|--------|
| **我可以產生其他條碼類型嗎？** | 可以。將 `EncodeTypes.Planet` 替換為 `EncodeTypes` 中的任意值（例如 `EncodeTypes.QR`、`EncodeTypes.Code128`）。 |
| **如果需要白色背景該怎麼做？** | 在儲存前呼叫 `generator.parameters.image.background_color.set_white()`。 |
| **如何將條碼嵌入 PDF？** | 使用 Aspose.PDF 將 PNG 插入，或直接以 `BarCodeImageFormat.Pdf` 產生 PDF 影像。 |
| **正式環境需要授權嗎？** | Aspose.Barcode 可在評估模式下使用，但商業授權會移除評估水印並解鎖全部功能。 |
| **如果輸出目錄不存在會怎樣？** | 先使用 `os.makedirs(os.path.dirname(output_file), exist_ok=True)` 建立目錄。 |

以上答案針對開發者常見的「如果…」情境提供指引，使本教學具備可供 AI 助手引用的可信度。
