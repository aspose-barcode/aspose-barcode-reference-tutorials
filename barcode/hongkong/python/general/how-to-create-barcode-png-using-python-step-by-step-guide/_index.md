# 如何使用 Python 建立條碼 PNG – 步驟說明指南

如果你需要從任意字串 **建立條碼 PNG** 檔案，本教學提供一個即時可執行的解決方案。你將會看到如何產生 Code 128 條碼、將文字轉換為條碼影像，並將結果儲存為 PNG 檔案——只需幾行 Python 程式碼。

本指南涵蓋從安裝所需函式庫到為不同使用情境自訂輸出的所有資訊。完成後，你將能在任何 Python 專案中嵌入條碼產生功能，而不必額外搜尋文件。

## 你將學會

* 安裝支援 Code 128 的 **barcode generator python** 套件。
* 使用 `BarCodeGenerator` 從文字字串 **產生 code 128 條碼**。
* 使用 `save` 將結果儲存為高品質 PNG。
* 調整影像尺寸、前景/背景顏色，並處理常見錯誤。
* 驗證 PNG 是否正確產生。

### 前置條件

| 需求 | 原因 |
|------|------|
| Python 3.8+ | 現代語法與型別提示 |
| Internet access (for `pip install`) | 下載套件 |
| Write permission to a folder | 儲存產生的 PNG |

不需要任何外部服務；所有操作皆在本機執行。

## 步驟 1：安裝條碼函式庫

將文字轉換為條碼的最直接方式是使用 **Aspose.BarCode for Python via .NET** 套件，它內建支援 Code 128。

```bash
pip install aspose-barcode
```

> **專業提示：** 若你在虛擬環境中工作，請先啟動該環境再執行指令，以保持相依性隔離。

## 步驟 2：匯入所需類別

安裝完成後，匯入核心類別。匯入語句簡潔，讓程式碼易於閱讀。

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` 建立條碼影像。
* `EncodeTypes` 提供支援的條碼類型列舉，包含 `CODE_128`。

## 步驟 3：定義要編碼的文字

選擇任意字母數字字串。Code 128 能表示完整的 ASCII 集合，並不限於數字。

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

若輸入包含不支援的字元，產生器會拋出 `ValueError`。若預期使用者提供資料，請將指派包在 `try` 區塊中。

## 步驟 4：為 Code 128 建立條碼產生器

以欲使用的條碼類型與先前定義的文字實例化 `BarCodeGenerator`。這是 **如何產生條碼** 影像的核心。

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

為什麼選擇 Code 128？它密度高且能編碼完整的 ASCII 範圍，非常適合庫存系統、運送標籤與票證等應用。

## 步驟 5：（可選）自訂外觀

在儲存之前，你可以微調條碼。以下選項相當常見：

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

這些設定會影響最終 **create barcode png** 輸出，但不會改變編碼資料。

## 步驟 6：將條碼儲存為 PNG 檔案

最後，將影像寫入磁碟。`save` 方法會自動偵測檔案副檔名，傳入 `.png` 即會產生 PNG 影像。

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

若目標目錄不存在，Python 會拋出 `FileNotFoundError`。請事先建立目錄，或使用 `os.makedirs` 並設定 `exist_ok=True`。

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### 預期輸出

執行腳本後，你會在 `output` 資料夾中找到 `extended_barcode.png`。開啟檔案即可看到清晰的 Code 128 條碼，編碼內容為 `1234567890`。

## 步驟 7：驗證條碼（快速檢查）

你可以使用相同的函式庫讀回 PNG，確認編碼值與原始文字相符。

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

執行此區塊會印出：

```
Verification succeeded: 1234567890
```

若斷言失敗，請再次檢查 `barcode_text` 以及任何自訂參數。

## 常見變形與邊緣情況

| 情況 | 調整 |
|------|------|
| **Longer text (> 20 characters)** | 增加 `image_width` 以避免截斷。 |
| **Need a transparent background** | 在儲存前將 `back_color = "Transparent"` 設為透明。 |
| **Generate multiple barcodes in a loop** | 將步驟 3‑6 包在 `for` 迴圈中，於每次迭代更改 `barcode_text`。 |
| **Save as JPEG instead of PNG** | 將檔案副檔名改為 `.jpg`；函式庫會自動處理格式。 |
| **Running on a headless server** | 此函式庫不需要 GUI，適用於 CI 流程。 |

## 完整腳本供快速複製貼上

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

將腳本儲存為 `generate_barcode.py` 後執行：

```bash
python generate_barcode.py
```

你會看到確認訊息，且在 `output` 資料夾中產生新的 PNG 檔案。
