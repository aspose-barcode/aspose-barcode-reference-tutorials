# Hur man fyller i streckkod i C# med Aspose.BarCode

Om du behöver **fylla i streckkod** i en .NET-applikation visar den här handledningen hela processen. Du kommer att generera en post‑Planet‑streckkod med solida staplar, och sedan skapa en version med tomma staplar av samma streckkod, allt med en enda kodradändring.

Guiden täcker allt du behöver veta: projektuppsättning, justering av X‑dimension, växling mellan fyllda och tomma staplar, och hur du verifierar de genererade PNG‑filerna. Ingen extern dokumentation krävs – kopiera bara koden, kör den, så ser du resultatet.

## Förutsättningar

Innan du börjar, se till att du har:

* .NET 6.0 SDK eller senare installerat  
* En utvecklingsmiljö som Visual Studio 2022 eller VS Code  
* NuGet‑paketet **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

Dessa komponenter utgör den minsta grundnivån för **barcode generator c#**‑delen av handledningen.

## Hur man fyller i streckkod – sätt upp projektet

1. Skapa ett nytt konsolprojekt:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Lägg till Aspose.BarCode‑paketet:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Öppna den genererade filen `Program.cs` och ersätt dess innehåll med det fullständiga exemplet som visas senare i den här artikeln.

Projektet innehåller nu allt som krävs för att **generera poststreckkod**‑bilder.

## Generera post‑Planet‑streckkod med solida staplar

Det första steget är att skapa en Planet‑streckkod som använder fyllda (solida) staplar. Planet är den symbolik som många posttjänster använder för sortering.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Varför dessa rader är viktiga**

* `EncodeTypes.Planet` talar om för generatorn vilken symbolik som ska användas; Planet är standarden för poststreckkoder.  
* `XDimension.Pixels = 4` ökar modulbredden, vilket gör streckkoden lättare att skanna och visuellt tydligare vid utskrift.  
* `Save` skriver bilden till disk i PNG-format, ett förlustfritt format som är lämpligt för vidare bearbetning.

Att köra detta block skapar **PostalPlanetFilledBars.png**, en bild med solida staplar som uppfyller postens specifikationer.

## Skapa tom streckkod med Planet‑symbolik

Ibland förväntar sig ett postsystem att staplarna ska vara tomma (oifyllda) medan mellanrummen förblir solida. Att växla till det läget kräver bara en egendomsändring.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Varför detta fungerar**

Genom att sätta `FilledBars = false` instrueras renderaren att invertera den visuella stilen: staplar blir transparenta (tomma) och bakgrunden blir ogenomskinlig. Detta är exakt motsatsen till standardbeteendet som demonstrerades tidigare, vilket låter dig **skapa tomma streckkod**‑bilder utan att ändra den kodade datan.

## Fullt, körbart exempel

Nedan är det kompletta programmet som kombinerar de två sektionerna. Kopiera det till `Program.cs`, ersätt `YOUR_DIRECTORY/` med en riktig sökväg till en mapp, och kör `dotnet run`.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Förväntad utdata

Efter körning hittar du två PNG‑filer i den angivna mappen:

| Filnamn                       | Visuell beskrivning |
|-------------------------------|---------------------|
| `PostalPlanetFilledBars.png`  | Staplarna är svarta och solida på en vit bakgrund |
| `PostalPlanetEmptyBars.png`   | Staplarna är transparenta (vita) på en svart bakgrund |

Båda bilderna kodar samma numeriska sträng `"123456"` och har samma X‑dimension, vilket säkerställer att de är utbytbara ur ett datavalideringsperspektiv.

## Vanliga frågor och kantfall

**Vad händer om målmappen inte finns?**  
`Save`‑metoden kastar ett `DirectoryNotFoundException`. Skapa mappen i förväg eller omslut anropen i ett `try / catch`‑block som skapar katalogen vid behov:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Kan jag använda ett annat bildformat?**  
Ja. Ersätt `BarCodeImageFormat.Png` med `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` eller något annat format som stöds av Aspose.BarCode.

**Påverkar X‑dimension läsbarheten för skannern?**  
Att öka pixelbredden gör staplarna bredare, vilket kan förbättra läsbarheten på lågupplösta skannrar. Dock kan mycket stora värden överskrida det utskrivbara området. Vanliga värden ligger mellan 2 och 6 pixlar för 300 dpi‑utskrift.

**Är `EncodeTypes.Planet`‑symboliken det enda postalternativet?**  
Nej. Aspose.BarCode stöder också `EncodeTypes.Postnet` och `EncodeTypes.USPSIntelligentMail`. Samma `FilledBars`‑egenskap fungerar även med dessa typer.
