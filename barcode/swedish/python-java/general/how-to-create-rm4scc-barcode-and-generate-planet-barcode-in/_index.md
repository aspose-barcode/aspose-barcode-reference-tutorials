# Hur man skapar RM4SCC‑streckkod och genererar planet‑streckkod i C#

Om du behöver **skapa RM4SCC‑streckkod** för postapplikationer visar den här guiden de exakta stegen. Du får också lära dig hur du **genererar planet‑streckkod** med både automatisk och fast höjd, så att samma kod fungerar för alla post‑symbologier.

Tutorialen täcker allt som krävs för att producera PNG‑bilder som uppfyller poststandarder. Inga externa verktyg behövs förutom Aspose.BarCode for .NET‑biblioteket. När du är klar kan du generera streckkoder programatiskt och kontrollera deras dimensioner exakt.

## Förutsättningar

Innan du börjar, se till att du har:

* .NET 6.0 eller senare installerat
* Visual Studio 2022 (eller någon C#‑IDE)
* Aspose.BarCode for .NET NuGet‑paket  
  `Install-Package Aspose.BarCode`
* Skrivbehörighet till utmatningskatalogen

Dessa komponenter låter dig kompilera och köra exempel‑koden utan ytterligare konfiguration.

## Steg 1: Initiera streckkodsgeneratorn för RM4SCC

Den första operationen skapar en `BarcodeGenerator`‑instans konfigurerad för RM4SCC‑symbologin. Detta objekt innehåller alla inställningar för streckkodsbilden.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Varför detta är viktigt** – `EncodeTypes.RM4SCC` talar om för Aspose att använda post‑RM4SCC‑formatet, medan data‑strängen `"123456"` representerar postnumret du vill koda.

## Steg 2: Ställ in modulbredden (X‑dimension)

Modulbredden styr tjockleken på den tunna stapeln. Ett vanligt värde för post‑streckkoder är 4 pixlar.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Förklaring** – X‑dimensionen påverkar streckkodens läsbarhet. Att välja 4 px matchar de flesta postskannrar.

## Steg 3: Spara med automatisk stapelhöjd

När du utelämnar ett höjd‑värde beräknar Aspose den optimala höjden automatiskt enligt symbologins regler.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Resultat** – Den genererade PNG‑filen (`PostalRM4SCCBarHeightNone.png`) innehåller en korrekt dimensionerad RM4SCC‑streckkod klar för utskrift.

## Steg 4: Skapa en Planet‑streckkod med automatisk höjd

Samma mönster fungerar för Planet‑symbologin. Börja med att initiera generatorn med `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Varför återanvända koden** – Både RM4SCC och Planet delar samma parameterstruktur, så du kan byta symbologi genom att bara ändra `EncodeTypes`‑värdet.

## Steg 5: Definiera en fast stapelhöjd för RM4SCC

Vissa posttjänster kräver en specifik stapelhöjd (t.ex. 100 px). Du kan ange detta explicit innan du sparar.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Tips** – Att sätta `BarHeight.Pixels` åsidosätter den automatiska beräkningen och ger dig full kontroll över den visuella storleken.

## Steg 6: Definiera en fast stapelhöjd för Planet

Applicera samma fast‑höjd‑teknik på en Planet‑streckkod.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Resultat** – Både `PostalRM4SCCBarHeight100Pixels.png` och `PostalPlanetBarHeight100Pixels.png` innehåller streckkoder med en konsekvent 100 px stapelhöjd, vilket uppfyller strikta post‑specifikationer.

## Komplett källkod

Nedan finns hela, körbara programmet som omfattar alla fyra exemplen. Kopiera det till ett nytt konsolprojekt och justera utmatningssökvägen efter behov.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Förväntat resultat** – Efter att programmet har körts finns fyra PNG‑filer i den angivna katalogen:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC med automatisk höjd
* `PostalPlanetBarHeightNone.png` – Planet med automatisk höjd
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC med 100 px höjd
* `PostalPlanetBarHeight100Pixels.png` – Planet med 100 px höjd

Öppna någon av filerna för att verifiera att staplarna är skarpa, modulbredden är 4 px och höjden matchar den valda inställningen.

## Vanliga frågor och kantfall

| Fråga | Svar |
|----------|--------|
| **Kan jag använda andra bildformat?** | Ja. Byt ut `BarCodeImageFormat.Png` mot `Jpeg`, `Bmp` eller `Gif` efter behov. |
| **Vad händer om data‑strängen är längre?** | Generatorn justerar automatiskt antalet staplar. Säkerställ att data följer symbologins längdgränser (RM4SCC ≤ 6 siffror, Planet ≤ 6 siffror). |
| **Hur ändrar jag stapelfärgen?** | Sätt `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` innan du anropar `Save`. |
| **Är DPI viktigt för utskrift?** | Du kan sätta `rm4sccAuto.Parameters.ImageResolution.DpiX` och `DpiY` för att matcha din skrivarens upplösning. |
