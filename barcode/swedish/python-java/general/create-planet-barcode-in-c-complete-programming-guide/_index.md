# Skapa planet-streckkod i C# – komplett programmeringsguide

Om du behöver **skapa planet-streckkod** i C#, visar den här guiden exakt hur du gör det. Du kommer också att upptäcka **hur du ställer in streckkodsdimensioner** så att staplarna renderas med exakt den bredd du kräver.

Att generera Planet‑streckkoder är vanligt när du arbetar med posttjänster eller logistiksystem. Koden nedan täcker både standardversionen med fyllda staplar och den valfria stilen med tomma staplar, samt ett snabbt exempel för RM4SCC‑formatet. I slutet av den här handledningen har du ett återanvändbart kodsnutt som du kan lägga in i vilket .NET‑projekt som helst.

## Förutsättningar

Innan du börjar, se till att du har:

* .NET 6.0 eller senare installerat (API:et fungerar även med .NET Framework 4.6+).
* NuGet‑paketet **Aspose.BarCode for .NET** (`Aspose.BarCode`) har lagts till i ditt projekt.
* En skrivbar mappväg där PNG‑filerna ska sparas.
* Grundläggande kunskap om C#‑syntax och Visual Studio (eller någon IDE).

> **Proffstips:** Använd en absolut sökväg eller `Path.Combine(Environment.CurrentDirectory, "output")` för att undvika behörighetsproblem när du sparar bilder.

## Steg 1 – Initiera en Planet‑streckkodsgenerator (fyllda staplar)

Det första steget är att skapa en `BarcodeGenerator`‑instans för Planet‑symbologi. Som standard producerar generatorn **fyllda** staplar.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

`EncodeTypes.Planet`‑enumerationen talar om för Aspose.BarCode att använda Planet‑formatet, medan `"123456"` är data‑payloaden som ska kodas.

## Steg 2 – Hur du ställer in streckkodsdimensioner för konsekvent storlek

För att kontrollera bredden på varje stapel, justera **X‑dimensionen**. Detta är det primära sättet att **ställa in streckkodsdimensioner** och säkerställer att streckkoden passar din etikettstorlek.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

`Pixels`‑egenskapen definierar stapelbredden i skärm‑pixlar. Vanliga värden är 2 – 5 pixlar för standardpostetiketter; öka värdet för större utskrifter.

## Steg 3 – Spara den fyllda Planet‑streckkoden som PNG

Skriv nu bilden till disk. PNG bevarar skarpa kanter, vilket är idealiskt för skanning.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Byt ut `YOUR_DIRECTORY` mot den sökväg du förberedde tidigare. Efter att ha kört koden kommer du att se en fil som liknar bilden nedan.

## Steg 4 – Skapa en Planet‑streckkod med tomma (ofyllda) staplar

Om din posttjänst kräver att staplarna är **tomma**, måste du växla `FilledBars`‑flaggan efter att generatorn har initierats.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Konstruktorn är identisk; skillnaden ligger i nästa konfigurationssteg.

## Steg 5 – Hur du ställer in streckkodsdimensioner och gör staplarna tomma

Återigen, sätt X‑dimensionen för visuell konsistens, och inaktivera sedan fyllda staplar.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

`FilledBars = false`‑egenskapen är det som faktiskt ändrar renderingsstilen. Att behålla samma X‑dimension säkerställer att den tomma‑stapelsstreckkoden alignerar perfekt med den fyllda versionen.

## Steg 6 – Spara den tomma Planet‑streckkoden

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Du har nu två PNG‑filer: en med solida staplar och en med ihåliga staplar, båda med samma dimensioner.

## Steg 7 – (Valfritt) Generera en RM4SCC‑streckkod för jämförelse

RM4SCC är en annan post‑symbologi som använder samma standardstil med fyllda staplar. Stegen speglar Planet‑exemplet och visar att **hur du ställer in streckkodsdimensioner** fungerar över format.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

När du kör dessa tre steg skapas `PostalRM4SCCFilledBars.png`, som du kan jämföra sida‑vid‑sida med Planet‑resultaten.

## Varför X‑dimensionen är viktig

X‑dimensionen bestämmer den **minsta utskrivbara bredden** för varje stapel. Om du sätter den för lågt kan streckkoden bli suddig på lågupplösta skrivare, vilket leder till skanningsfel. Omvänt kan en för stor X‑dimension överskrida etikettens mått och slösa utrymme. Genom att explicit **ställa in streckkodsdimensioner** får du deterministisk kontroll över den slutliga bildstorleken, vilket är avgörande för automatiserade postarbetsflöden.

## Vanliga fallgropar och hur du undviker dem

| Problem | Orsak | Lösning |
|-------|-------|-----|
| Streckkoden ser utdragen ut | X‑dimension satt i punkter istället för pixlar | Använd alltid `Pixels`‑egenskapen för pixel‑perfekt kontroll |
| Tomma staplar ser fortfarande fyllda ut | `FilledBars` är inte satt till `false` efter X‑dimension‑ändring | Sätt `FilledBars = false` *efter* att ha justerat X‑dimensionen |
| Sparad fil är tom | Utdatamappen finns inte eller saknar skrivbehörighet | Säkerställ att mappen finns (`Directory.CreateDirectory`) och att ditt program körs med tillräckliga rättigheter |
| Bilden är suddig vid utskrift | Låg DPI PNG sparad från en högupplöst skärm | Använd `BarCodeImageFormat.Png` (förlustfri) och överväg `Resolution`‑egenskapen om behövs |

## Fullt, körbart exempel

Kopiera hela blocket nedan till ett nytt konsolprojekt (`dotnet new console`) och kör det. Programmet skapar tre PNG‑filer i `output`‑mappen.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Förväntat resultat:** tre PNG‑filer — `PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` och `PostalRM4SCCFilledBars.png` — med 4‑pixel breda staplar, redo för utskrift eller vidare bearbetning.

## Slutsats

Du vet nu hur du **skapar planet-streckkod** i C# och exakt **hur du ställer in streckkodsdimensioner** för både fyllda och tomma stapelstilar. Samma mönster gäller för andra symbologier som RM4SCC, vilket ger dig en flexibel grund för alla post‑streckkodskrav.

Nästa steg kan vara att utforska:

* Lägga till mänskligt läsbar text under streckkoden (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* Ändra stapelfärger med `Parameters.Barcode.BarColor`
* Generera streckkoder i vektorformat (SVG, EPS) för skalbar utskrift

Känn dig fri att experimentera med olika X‑dimension‑värden, datasträngar och utdataformat för att passa ditt specifika arbetsflöde. Lycka till med kodningen!
