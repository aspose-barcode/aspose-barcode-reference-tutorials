# Hur man sparar streckkodsbilder i C# med BarcodeGenerator API

Om du behöver **how to save barcode** filer från en .NET-applikation, visar den här guiden de exakta stegen. Du kommer att se ett komplett **barcode generator example** som skapar en DataBar Stacked Omnidirectional streckkod, justerar dess bildförhållande och sparar två PNG-filer.

Att spara streckkodsbilder är ett vanligt krav när man bygger lagersystem, kassaterminaler eller automatiserade märkningsarbetsflöden. I slutet av den här handledningen kan du generera barcode C#-kod som producerar pålitliga bilder redo för utskrift eller visning.

## Förutsättningar

- .NET 6.0 SDK eller senare installerat  
- Visual Studio 2022 (eller någon C#‑kompatibel IDE)  
- **Aspose.BarCode for .NET** NuGet‑paketet (koden använder `Aspose.BarCode.Generation`)  

Du kan lägga till paketet med följande kommando:

```bash
dotnet add package Aspose.BarCode
```

## Steg 1: Skapa ett minimalt C#-konsolprojekt

Skapa ett nytt konsolprojekt och referera biblioteket:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Öppna `Program.cs`. Filen kommer att innehålla `Main`‑metoden där vi placerar **generate barcode C#**‑logiken.

## Steg 2: Initiera BarcodeGenerator för en DataBar Stacked Omnidirectional streckkod

Den första uppgiften i varje **create databar barcode**‑arbetsflöde är att instansiera `BarcodeGenerator` med rätt `EncodeType`. Konstruktorn tar emot streckkodssymbologin och datasträngen.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

`EncodeTypes.DatabarStackedOmniDirectional`‑värdet talar om för biblioteket att producera en **create databar barcode** som kan läsas från vilken riktning som helst.

## Steg 3: Konfigurera X‑dimensionen (modulbredd)

X‑dimensionen styr den minsta stapelbredden i pixlar. Att sätta den till ett lågt värde håller streckkoden kompakt samtidigt som läsbarheten bevaras.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Steg 4: **How to adjust aspect ratio** – första värdet (15)

DataBar‑streckkoder har en `AspectRatio`‑egenskap som påverkar förhållandet mellan höjd och bredd. Ett högre förhållande ger en högre streckkod, vilket kan förbättra läsbarheten på vissa skrivare.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Steg 5: **How to save barcode** – första bilden (aspect ratio 15)

Nu sparar vi faktiskt **how to save barcode** till en fil. `Save`‑metoden tar en filsökväg och ett bildformat. I det här exemplet lagrar vi en PNG‑fil.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Tips:** Katalogen för den körbara filen är standardplatsen för skrivning. Använd en absolut sökväg om du behöver en specifik mapp.

## Steg 6: **How to adjust aspect ratio** – andra värdet (30)

För att demonstrera flexibilitet, ändra bildförhållandet och spara en andra bild. Detta visar hur samma kodade data kan renderas med olika visuella proportioner.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Kör programmet skapar två PNG‑filer:

- `DatabarAspectRatio15.png` – streckkod med måttlig höjd  
- `DatabarAspectRatio30.png` – streckkod med högre höjd för krävande skanningsmiljöer  

Båda filerna är redo att laddas in i UI‑kontroller, skrivas ut på etiketter eller överföras via API.

### Förväntad output

När du öppnar de genererade bilderna bör du se en DataBar Stacked Omnidirectional streckkod som kodar GTIN‑14‑värdet `12345678901231`. Den visuella skillnaden mellan de två filerna är enbart höjden, vilket bekräftar att **how to adjust aspect ratio** fungerar som avsett.

## Steg 7: Fullständig källkod för referens

Nedan är det kompletta, körbara programmet. Kopiera det till `Program.cs`, bygg och kör.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Vanliga frågor och hantering av kantfall

### Vad händer om målmappen inte finns?

`Save` kastar ett `DirectoryNotFoundException`. Skapa katalogen först:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Hur ändrar man bildformat?

Byt ut `BarCodeImageFormat.Png` mot `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` eller `BarCodeImageFormat.Tiff` beroende på efterföljande krav.

### Kan jag generera flera streckkoder i en loop?

Ja. Instansiera en ny `BarcodeGenerator` för varje datasträng eller återanvänd samma instans efter att ha uppdaterat `CodeText`‑egenskapen:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### Fungerar **how to save barcode** på icke‑Windows‑plattformar?

Aspose.BarCode är plattformsoberoende. Samma kod körs på Linux och macOS så länge .NET‑runtime finns.
