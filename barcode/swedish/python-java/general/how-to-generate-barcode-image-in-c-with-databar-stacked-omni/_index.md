# Hur man genererar streckkodsbild i C# med DataBar Stacked Omni‑Directional

Om du behöver **hur man genererar streckkodsbild** i en .NET‑applikation, visar den här handledningen de exakta stegen. Du kommer att se hur du skapar en DataBar Stacked Omni‑Directional‑streckkod, justerar dess bildförhållande och exporterar resultatet som PNG‑filer.

Att generera streckkoder är ett vanligt krav för lagersystem, detaljhandels‑point‑of‑sale‑terminaler och logistikspårning. I följande avsnitt går vi igenom allt du behöver – från det nödvändiga NuGet‑paketet till den slutgiltiga bildverifieringen – så att du kan integrera streckkodsskapande i vilket C#‑projekt som helst redan idag.

## Förutsättningar

Innan du börjar, se till att du har:

* .NET 6.0 eller senare (koden fungerar med .NET Core och .NET Framework)
* Visual Studio 2022 eller någon annan C#‑IDE du föredrar
* **Aspose.BarCode for .NET**‑NuGet‑paketet (installera med `dotnet add package Aspose.BarCode`)
* Skrivrättigheter till den mapp där PNG‑filerna ska sparas

Dessa förutsättningar garanterar att exemplet körs utan ytterligare konfiguration.

## Steg 1: Skapa utdatamappen

Det första du behöver är en katalog där de genererade PNG‑filerna ska skrivas. Att använda en absolut eller relativ sökväg fungerar, men se till att mappen finns innan du anropar `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Att skapa mappen programatiskt förhindrar *FileNotFoundException* när `Save`‑metoden försöker skriva bilden.

## Steg 2: Skapa en DataBar Stacked Omni‑Directional‑streckkodsgenerator

Klassen **BarcodeGenerator** är ingångspunkten för alla streckkodstyper. Här specificerar vi `EncodeTypes.DatabarStackedOmniDirectional` och den datasträng vi vill koda.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Varför detta är viktigt*: `EncodeTypes`‑enumet talar om för biblioteket vilken symbologi som ska renderas. Att använda Omni‑Directional‑varianten säkerställer att streckkoden kan läsas från vilken orientering som helst – ett krav för många lager‑scanners.

## Steg 3: Konfigurera vanliga streckkodsegenskaper

En läsbar streckkod behöver en rimlig X‑dimension (bredden på den minsta stapeln). Att sätta `Pixels` till 2 ger en bra balans mellan storlek och tydlighet för de flesta skärmupplösningar.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Du kan justera `Pixels` senare om du behöver en större eller mindre bild; biblioteket skalar automatiskt resten av streckkoden.

## Steg 4: Generera den första bilden med bildförhållande 15

**Bildförhållandet** styr förhållandet mellan höjd och bredd för DataBar‑streckkoder. Ett bildförhållande på 15 är ett typiskt standardvärde för detaljhandels‑etiketter.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Efter detta anrop hittar du `DatabarAspectRatio15.png` i utdatamappen. Bilden är en förlustfri PNG, lämplig för vidare bearbetning eller utskrift.

## Steg 5: Ändra bildförhållandet till 30 och exportera en andra bild

Ibland krävs en högre streckkod – till exempel när etikettens höjd är begränsad. Att ändra bildförhållandet till 30 ger en mer kompakt visuell presentation samtidigt som dataintegriteten bevaras.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Nu har du två PNG‑filer som visar hur samma data ser ut med olika bildförhållanden. Denna sida‑vid‑sida‑jämförelse hjälper dig att avgöra vilken variant som passar din etikettlayout bäst.

## Fullt, körbart exempel

Nedan är det kompletta programmet som du kan kopiera, klistra in och köra. Det innehåller alla `using`‑direktiv, felhantering och kommentarer som förklarar varje del av processen.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Förväntad utdata** (konsol):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Öppna de två PNG‑filerna i någon bildvisare. Du kommer att se samma GTIN kodad, men den andra bilden är högre på grund av det högre bildförhållandet.

## Pro‑tips och vanliga fallgropar

| Situation | Rekommendation |
|-----------|----------------|
| **Låguppslösta skärmar** | Öka `XDimension.Pixels` till 3 eller 4 för att hålla staplarna skarpa. |
| **Utskrift på termisk papper** | Använd `BarCodeImageFormat.Tiff` för högre kvalitet och sätt `Resolution.DpiX/DpiY` till 300. |
| **Dynamisk data** | Återanvänd samma `BarcodeGenerator`‑instans och uppdatera bara `generator.CodeText` före varje `Save`. Detta undviker onödig objektallokering. |
| **Ogiltig GTIN** | Biblioteket kastar `ArgumentException` om datan inte följer GS1‑standarderna. Validera din data innan du skickar den till generatorn. |
