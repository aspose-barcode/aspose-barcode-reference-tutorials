# Skapa streckkod PNG i Python – Komplett guide

Har du någonsin behövt **create barcode PNG** men varit osäker på vilket bibliotek eller vilka inställningar du ska använda? Du är inte ensam. I många lager- eller kassasystem är första steget att omvandla rådata till en skarp PNG‑bild som skannrarna älskar.  

I den här handledningen går vi igenom **how to generate databar**, hur man **adjust barcode height**, och till och med tricket att **change barcode** parametrar i farten—allt medan vi använder **barcode with sample data** som du kan kopiera‑klistra rakt in i ditt projekt.  

## Vad du kommer att lära dig

- Installera Aspose.BarCode (eller liknande) biblioteket i Python.  
- **Create barcode PNG**-filer med olika höjder på bara några kodrader.  
- **How to change barcode**-egenskaper såsom modulstorlek och stapelhöjd.  
- Använd ett realistiskt GTIN‑14‑värde som **barcode with sample data**.  
- Tips för felsökning av vanliga fallgropar som suddiga bilder eller felaktig kodning.

## Förutsättningar

- Python 3.8+ installerat på din maskin.  
- Internetåtkomst för att installera `aspose-barcode`‑paketet (eller något kompatibelt bibliotek).  
- En skrivbar mapp där PNG‑filerna ska sparas (ersätt `YOUR_DIRECTORY` i skriptet).  

Om du redan har detta, toppen—låt oss dyka ner.

## Skapa streckkod PNG – Ställa in generatorn

Först och främst: vi behöver ett generator‑objekt som vet att vi arbetar med en **DataBar Omnidirectional**‑streckkod. Koden nedan importerar de nödvändiga klasserna, skapar generatorn med en **barcode with sample data**, och sätter en blygsam modulstorlek.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Varför detta är viktigt:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` talar om för motorn att producera en **DataBar** som kan läsas från vilken riktning som helst, perfekt för butikshyllor. Att sätta `x_dimension` håller staplarna skarpa, medan `bar_height` styr den visuella storleken på koden.

## Hur man genererar Databar med exempeldata

Nu när generatorn är klar kommer vi att **create barcode PNG**‑filer. Den första sparningen använder en höjd på 30 pixlar, vilket ofta är tillräckligt för förhandsvisning på skärmen.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Att köra skriptet fram till detta steg kommer att producera en PNG‑fil som ser ut som en kompakt, högkontrast‑streckkod. Öppna den i någon bildvisare för att verifiera att staplarna är skarpa och att GTIN‑14‑data är kodad.

## Justera stapelhöjd (How to Change Barcode)

Ibland behöver du en högre stapel för större etiketter eller högupplöst utskrift. Här kommer **adjust barcode height** in i bilden. Att ändra höjden är så enkelt som att uppdatera `BarHeight`‑egenskapen och spara igen.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Hur det fungerar:** Generatorn återanvänder samma data och modulstorlek; endast den vertikala dimensionen ändras. Detta undviker att återskapa hela objektet och demonstrerar **how to change barcode**‑inställningar dynamiskt.

## Fullt skript – En‑stopp‑lösning

Nedan är det kompletta, körbara skriptet som kombinerar alla stegen. Kopiera, klistra in och kör—det bör fungera direkt efter att du installerat paketet.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Förväntad output

Kör skriptet kommer att generera två filer:

- `DatabarOmni30.png` – 30 px hög DataBar Omnidirectional‑streckkod.  
- `DatabarOmni60.png` – 60 px hög version av samma streckkod.

Båda bilderna är i PNG‑format, förlustfria, och redo att bäddas in i PDF‑filer, HTML‑sidor eller skrivas ut direkt på etiketter.

## Vanliga fallgropar & pro‑tips

- **Pixel vs. DPI:** PNG‑filer är pixelbaserade. Om du behöver en specifik utskriftsstorlek, beräkna `BarHeight` baserat på DPI (t.ex. 300 dpi → 30 px ≈ 0.1 in).  
- **Incorrect encoding:** Se till att datasträngen följer GS1 Application Identifier‑formatet (`(01)` för GTIN‑14). Saknade parenteser kan få biblioteket att falla tillbaka till en ren numerisk streckkod.  
- **File paths:** Använd råsträngar (`r"..."`) eller dubbla bakstreck på Windows för att undvika problem med escape‑tecken.  
- **Performance:** Om du genererar tusentals streckkoder, skapa generatorn en gång och modifiera bara `BarHeight` eller datasträngen mellan sparningar. Detta minskar minnesanvändning.
