# Hur man genererar DataMatrix‑streckkoder med Aspose.BarCode för .NET

Om du behöver ett pålitligt sätt att bädda in maskinläsbara symboler i dina .NET‑applikationer, är **hur man genererar DataMatrix**‑streckkoder ett vanligt krav. Aspose.BarCode för .NET erbjuder ett fullt hanterat API som hanterar varje steg—från att välja rätt DataMatrix‑version till finjustering av felkorrigeringsnivåer—utan att kräva externa verktyg. I den här handledningen går vi igenom ett komplett exempel, förklarar varför varje inställning är viktig och visar hur du sparar resultatet som en PNG‑ eller JPEG‑bild.

## Snabba svar
- **Vilket bibliotek skapar DataMatrix‑streckkoder?** Aspose.BarCode för .NET.  
- **Hur många DataMatrix‑versioner stöds?** Alla 30 standardkvadratiska och rektangulära versioner (från 10×10 upp till 144×144 moduler).  
- **Vilka ECC‑typer kan jag använda?** ECC200 (standard) och ECC140.  
- **Behöver jag en licens för utveckling?** En gratis 30‑dagars provperiod fungerar för testning; en kommersiell licens krävs för produktion.  
- **Kan jag köra detta på .NET 6, .NET Core eller .NET Framework?** Ja—Aspose.BarCode stöder .NET Framework 4.5+, .NET Core 3.1+ och .NET 5/6+.

## Vad är en DataMatrix‑streckkod?
En DataMatrix‑streckkod är en tvådimensionell, kvadratisk eller rektangulär matris av svarta och vita celler som kan lagra upp till 2 335 alfanumeriska tecken. Den används i stor utsträckning inom tillverkning, logistik och sjukvård för märkning av små föremål eftersom den förblir läsbar även när den är delvis skadad.

## Varför använda Aspose.BarCode för .NET?
Aspose.BarCode stöder **50+ utdataformat** (inklusive PNG, JPEG, TIFF, SVG och PDF) och kan generera **alla 30 DataMatrix‑versioner** utan att ladda hela bilden i minnet, vilket gör att du kan skapa streckkoder i högkapacitets‑tjänster som bearbetar filer större än 100 MB.

- En utvecklingsmiljö med .NET‑stöd (Visual Studio 2022, Rider eller VS Code).

Nu ska vi utforska DataMatrix‑versionerna och hur man genererar dem med Aspose.BarCode för .NET.

## Hur man genererar DataMatrix‑streckkoder i .NET?

Läs in `BarcodeGenerator` med typen `EncodeTypes.DataMatrix`, ange önskad version och ECC, och anropa sedan `Save` för att skriva bildfilen. Detta enkla‑radsmönster fungerar för vilken version du än väljer och hanterar automatiskt modulstorlek, tysta zoner och bildrendering.

## Importera namnrymder

`BarcodeGenerator` är Aspose.BarCode:s kärnklass för att skapa streckkods‑bilder.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

`Aspose.BarCode.Generation`‑namnrymden ger åtkomst till `BarcodeGenerator`‑klassen, som är den primära klassen som används för att generera streckkods‑bilder.

Nu ska vi dela upp exemplet i flera steg.

## Steg 1: ange din katalogsökväg

Börja med att definiera katalogsökvägen där du vill spara de genererade DataMatrix‑streckkoderna.

```csharp
string path = "Your Directory Path";
```

Ersätt `"Your Directory Path"` med den faktiska sökvägen där du vill spara streckkods‑bilderna.

## Steg 2: initiera streckkodsgeneratorn

Skapa en instans av `BarcodeGenerator`‑klassen och ange streckkodstypen som `DataMatrix`. Du kan också ange den data du vill koda i streckkoden.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` är huvudklassen som skapar och renderar streckkodssymboler.

## Steg 3: konfigurera streckkodsegenskaper

Du kan anpassa olika egenskaper för DataMatrix‑streckkoden, såsom dess dimensioner och ECC‑typ (Error Correction Code). Här är ett exempel på att sätta X‑dimensionen till 4 pixlar och välja ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` anger storleken på varje modul i pixlar, och `DataMatrixEcc` väljer felkorrigeringsnivån.

## Steg 4: ange DataMatrix‑version och spara

Du kan ange DataMatrix‑versionen genom att sätta antalet rader och kolumner. Efter att ha konfigurerat versionen, spara streckkodsbilden.

Till exempel, för att skapa en DataMatrix‑streckkod med 22 rader och 22 kolumner med ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

På liknande sätt kan du generera en streckkod med olika parametrar genom att ändra versionen och ECC‑typen efter behov.

## Steg 5: upprepa för andra versioner

Du kan upprepa Steg 4 för andra DataMatrix‑versioner. Till exempel, för att skapa en streckkod med 12 rader och 64 kolumner med ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Steg 6: byt ECC‑typer

Om du vill ändra ECC‑typen till Ecc140 kan du göra det genom att uppdatera ECC‑egenskapen:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Steg 7: generera streckkoder med olika versioner och ECC

Upprepa Steg 4 för andra DataMatrix‑versioner och ECC‑typer, och spara varje streckkod med ett unikt filnamn.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

Nu när du har lärt dig hur man genererar DataMatrix‑streckkoder med Aspose.BarCode för .NET, kan du enkelt integrera denna funktionalitet i dina .NET‑applikationer.

## Vanliga fallgropar och felsökningstips

- **Felaktiga versionsdimensioner** – DataMatrix‑versioner har fasta rad/kolumn‑par. Att ange ett felaktigt par (t.ex. 10 × 20) kommer att kasta ett `ArgumentException`. Använd alltid en av de stödda kombinationerna som listas i API‑dokumentationen.  
- **Saknad licens** – I provläge innehåller de genererade bilderna ett vattenstämpel. Applicera en giltig licens med `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` innan du skapar generatorn för att ta bort vattenstämpeln. `License`‑klassen läser in en licensfil för att aktivera produkten.  
- **Stor bildstorlek** – Om du behöver högupplöst utdata, öka `XDimension`‑egenskapen; biblioteket skalar bilden proportionellt utan att förlora läsbarhet.
