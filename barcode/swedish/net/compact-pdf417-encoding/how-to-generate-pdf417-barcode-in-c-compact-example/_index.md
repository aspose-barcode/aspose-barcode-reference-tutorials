# Hur man genererar PDF417‑streckkod i C# – kompakt exempel

Om du behöver **generera PDF417‑streckkod** i en C#‑applikation visar den här guiden en komplett, färdig‑att‑köra lösning. Vi skapar en kompakt PDF417‑streckkod, justerar modulbredden, definierar antalet kolumner och sparar resultatet som en PNG‑bild – allt med Aspose.BarCode .NET‑biblioteket.

Att generera en PDF417‑streckkod är vanligt när du vill koda stora mängder data (t.ex. URL‑er, kontaktkort eller lager‑ID:n) i ett utrymmeseffektivt två‑dimensionellt format. I slutet av den här tutorialen har du en fungerande `BarcodeGenerator`‑instans som producerar en kompakt, högläslig streckkod redo för utskrift eller visning.

## Förutsättningar

- .NET 6.0 eller senare (koden fungerar också med .NET Framework 4.8)
- Visual Studio 2022 (eller någon annan C#‑IDE)
- Aspose.BarCode for .NET NuGet‑paket (`Install-Package Aspose.BarCode`)
- Grundläggande kunskap om C#‑syntax

Ingen extra konfiguration krävs; exemplet körs som en konsolapp.

## Steg 1: Skapa en PDF417‑streckkodsgenerator

Det första steget är att instansiera `BarcodeGenerator` med enum‑värdet `EncodeTypes.Pdf417` och den text du vill koda.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Varför detta är viktigt:** `EncodeTypes.Pdf417` talar om för biblioteket att använda PDF417‑symbologi, medan det andra argumentet anger datainnehållet. Du kan ersätta `"Compact example"` med vilken sträng som helst upp till 1 800 tecken.

## Steg 2: Ställ in modulbredden (X‑dimension) i pixlar

X‑dimensionen definierar bredden på en enskild streckkodmodul (den minsta svarta eller vita fyrkanten). Ett mindre pixelvärde ger en tätare streckkod.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Varför detta är viktigt:** Ett värde på `2` pixlar skapar ett kompakt utseende utan att offra skanningspålitlighet på de flesta moderna skannrar. Justera värdet om du behöver större moduler för lågupplöst utskrift.

## Steg 3: Ange antalet kolumner

PDF417 låter dig styra antalet kolumner, vilket påverkar streckkodens bildförhållande.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Varför detta är viktigt:** Färre kolumner gör streckkoden högre, medan fler kolumner gör den plattare. Tre kolumner fungerar bra för en kompakt, stående layout.

## Steg 4: Aktivera kompakt läge genom att trunkera streckkoden

Kompakt läge tar bort onödiga padding‑rader, vilket gör streckkoden mindre samtidigt som den kodade datan bevaras.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Varför detta är viktigt:** Trunkering är idealiskt när skärmutrymmet är begränsat (t.ex. mobila appar eller små etiketter). Streckkoden förblir fullt läsbar eftersom kodningsalgoritmen automatiskt justerar felkorrigeringsnivåerna.

## Steg 5: Spara streckkoden som en PNG‑bild

Till sist skriver du den genererade streckkoden till en fil. PNG bevarar förlustfri kvalitet, vilket är viktigt för streckkodsläsare.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

När programmet körs skapas `CompactPdf417.png` i den körbara filens arbetskatalog. Bilden ser ut så här:

![Genererad kompakt PDF417‑streckkod](CompactPdf417.png "Genererad kompakt PDF417‑streckkod")

**Förväntat resultat:** En 2‑pixel‑bred, tre‑kolumnig PDF417‑streckkod som kodar texten “Compact example”. Att skanna PNG‑filen med en standardstreckkodsläsare bör returnera den ursprungliga strängen.

## Vanliga variationer och kantfall

| Situation | Hur du justerar koden |
|-----------|------------------------|
| **Längre data ( > 500 tecken )** | Öka `Columns` till 5‑7 för att undvika att streckkoden blir för hög. |
| **Utskrift med hög upplösning** | Sätt `XDimension.Pixels` till 3 eller 4 för större moduler. |
| **Annat bildformat** | Ersätt `BarCodeImageFormat.Png` med `Jpeg` eller `Bmp` efter behov. |
| **Bädda in streckkoden i en PDF** | Använd `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` istället för PNG. |

**Proffstips:** Testa alltid den genererade streckkoden på den avsedda skannrarutrustningen. Vissa billigare skannrar har problem med mycket små X‑dimensioner; om du får läsfel, öka pixelvärdet med ett steg.

## Fullt, körbart exempel

Nedan är hela programmet som du kan kopiera‑klistra in i ett nytt konsolprojekt. Inga ytterligare filer behövs.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Kompilera och kör programmet (`dotnet run` om du använder .NET‑CLI). Efter körning, öppna `CompactPdf417.png` för att verifiera det visuella resultatet.

## Slutsats

Du vet nu **hur man genererar PDF417‑streckkod** i C# med en kompakt layout, anpassad X‑dimension och kolumninställningar. Exemplet visar de väsentliga stegen: instansiera `BarcodeGenerator`, konfigurera `XDimension` och `Columns`, aktivera `Truncate` för kompakt läge och slutligen spara bilden.

Härifrån kan du utforska ytterligare funktioner som felkorrigeringsnivå, egna färger eller att bädda in streckkoden direkt i PDF‑filer. Experimentera med olika `EncodeTypes` om du behöver andra symbologier (t.ex. QR, Code128) och integrera samma konfigurationsmönster i dina projekt.

Lycka till med kodandet, och må dina streckkoder alltid skannas på första försöket!
