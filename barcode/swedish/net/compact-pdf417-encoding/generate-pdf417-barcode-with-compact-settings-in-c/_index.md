# Generera PDF417-streckkod med kompakta inställningar i C#

Om du behöver **generera PDF417-streckkod** i en .NET‑applikation visar den här guiden hur du gör det med Aspose.Barcode för .NET. Vi går igenom hur du skapar generatorn, konfigurerar kolumner, X‑dimension och aktiverar kompakt läge så att den resulterande symbolen blir så liten som möjligt.

Att generera en PDF417‑streckkod är vanligt när du måste koda stora mängder data för biljetter, ID‑kort eller fraktsedlar. Denna handledning täcker hela arbetsflödet – från installation av biblioteket till sparande av den slutgiltiga PNG‑filen – så att du kan kopiera‑klistra koden i ditt eget projekt och köra den direkt.

## Förutsättningar för att generera PDF417-streckkod

Innan du börjar, se till att du har:

* .NET 6.0 (eller senare) installerat.  
* Visual Studio 2022 eller någon IDE som stödjer C#‑projekt.  
* En NuGet‑licens för **Aspose.Barcode för .NET** (gratis provversion fungerar för lärande).  

Du kan lägga till biblioteket med följande kommando:

```bash
dotnet add package Aspose.BarCode
```

> **Proffstips:** Använd flaggan `--version` för att låsa en känd stabil version, t.ex. `dotnet add package Aspose.BarCode --version 23.12`.

## Skapa en PDF417‑streckkodsgenerator

Det första kodblocket skapar en `BarcodeGenerator`‑instans som är förkonfigurerad för PDF417‑symbologi. Texten `"Åspóse.Barcóde©"` innehåller Unicode‑tecken för att demonstrera att generatorn hanterar icke‑ASCII‑indata direkt.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Varför detta är viktigt
`EncodeTypes.Pdf417` talar om för Aspose.Barcode att du vill ha en **PDF417‑streckkod**, vilket är en staplad linjär symbologi som kan lagra upp till 1 850 tecken. Att använda konstruktorn med textargumentet sparar ett senare anrop till `SetCodeText`.

## Ställ in streckkodens XDimension (modulstorlek)

Modulstorleken, även kallad X‑dimension, bestämmer hur bred varje enskild stapel är. Mindre pixlar ger en tätare bild, medan större pixlar förbättrar läsbarheten på lågrealistiska skrivare.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### Varför du bör justera XDimension
Ett värde på `2` pixlar fungerar bra för skärmvisning och de flesta kontorsskrivare. Om du behöver en högupplöst utskrift, öka värdet; om du vill ha en kompakt streckkod (t.ex. för ett QR‑liknande utseende), sänk det – men aldrig under `1` pixel, annars blir bilden oläslig.

## Ställ in antalet kolumner för PDF417‑symbolen

PDF417 låter dig välja hur många kolumner (vertikala staplar) streckkoden ska ha. Färre kolumner gör streckkoden högre; fler kolumner gör den bredare.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### När du bör ändra kolumnantalet
Tre kolumner ger en kompakt, nästan kvadratisk symbol som passar bra på vanliga ID‑kort. Om du har en mycket lång sträng kan du öka kolumnantalet för att hålla höjden rimlig.

## Aktivera kompakt läge (trunkering)

Kompakt läge tar automatiskt bort oanvända rader från symbolen och minskar dess totala storlek. Detta är särskilt användbart när den kodade datan inte fyller hela matrisen.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Fördelar med kompakt PDF417‑streckkod
När `Truncate` är `true` beräknar generatorn det minsta antalet rader som krävs för att lagra dina data, vilket minskar bläckförbrukning och skanningstid. Det är säkert för de flesta skannrar eftersom PDF417‑specifikationen definierar trunkeringsalgoritmen.

## Spara den genererade streckkoden som en bild

Till sist skriver vi streckkoden till en PNG‑fil. PNG bevarar förlustfri kvalitet, vilket gör den idealisk för senare utskrift eller inbäddning i PDF‑filer.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Förväntat resultat
När programmet körs skapas `CompactPdf417.png` i den angivna mappen. Bilden innehåller en **kompakt PDF417‑streckkod** som kodar strängen `"Åspóse.Barcóde©"` med tre kolumner, en 2‑pixel X‑dimension och trunkering aktiverad. Du kan verifiera resultatet med vilken streckkodsläsarapp som helst eller med den kostnadsfria Aspose.Barcode‑online‑demot.

## Vanliga variationer och kantfall

| Situation | Justering |
|-----------|-----------|
| **Mycket lång data (> 1500 tecken)** | Öka `Columns` eller sätt `Rows` manuellt (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Utskrift på en låg‑dpi‑skrivare** | Höj `XDimension.Pixels` till 3 eller 4 för att undvika pixelering. |
| **Behöver transparent bakgrund** | Använd `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **Inbäddning i en PDF** | Spara som `BarCodeImageFormat.Pdf` eller hämta `Image`‑objektet via `pdf417Generator.GenerateBarCodeImage()`. |

## Fullt, körbart exempel

Nedan är hela programmet som du kan kopiera in i ett nytt konsolprojekt. Inga ytterligare filer behövs.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Kör `dotnet run` från projektmappen. Efter körning, öppna `CompactPdf417.png` för att se den genererade streckkoden.

## Slutsats

Du vet nu hur du **genererar PDF417‑streckkod** i C# med full kontroll över kolumner, X‑dimension och kompakt läge. Genom att justera `barcode XDimension pixels`, `set PDF417 columns` och aktivera `compact PDF417 barcode`‑trunkering kan du producera en streckkod som exakt matchar storlekskraven i din applikation.

Nästa steg du kan utforska:

* Koda större datamängder och experimentera med parametern `Rows`.

* Kombinera streckkoden med andra Aspose‑komponenter, såsom **Aspose.PDF**, för att bädda in bilden direkt i en PDF‑rapport.

Lycka till med kodandet, och känn dig fri att justera inställningarna så att de passar just din skannermiljö!
