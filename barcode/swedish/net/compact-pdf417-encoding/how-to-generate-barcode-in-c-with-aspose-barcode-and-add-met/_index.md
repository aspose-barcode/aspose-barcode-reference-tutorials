# Hur man genererar streckkod i C# med Aspose.BarCode och lägger till metadata

Om du behöver **generera streckkod i C#** för ett logistik- eller lagersystem, visar den här guiden en komplett, produktionsklar lösning. Du kommer att se hur du skapar en Macro PDF417‑streckkod, bifogar rik metadata och ställer in en exakt tidsstämpel — allt med Aspose.BarCode‑biblioteket.

Guiden täcker allt från att installera NuGet‑paketet till att spara den slutgiltiga PNG‑bilden. När du är klar kan du generera en streckkod som bär filidentifierare, segmentinformation och anpassade fält, redo för downstream‑skannrar som stödjer Macro PDF417.

## Förutsättningar

Innan du börjar, se till att du har:

* .NET 6.0 SDK eller senare (koden fungerar också med .NET Framework 4.7.2+)
* Visual Studio 2022 eller någon annan C#‑IDE du föredrar
* En aktiv Aspose.BarCode‑licens (gratis provversion fungerar för utveckling)
* Grundläggande kunskap om C#‑syntax

> **Pro tip:** Om du använder en CI/CD‑pipeline, lägg till Aspose.BarCode‑paketreferensen i din projektfil så att byggen förblir reproducerbara.

## Steg 1: Installera Aspose.BarCode

Öppna en terminal i din projektmapp och kör:

```bash
dotnet add package Aspose.BarCode
```

Kommandot hämtar den senaste stabila versionen (för närvarande 24.9). När återställningen är klar kan du referera biblioteket i dina källfiler.

## Steg 2: Skapa ett nytt C#‑konsolprojekt (valfritt)

Om du föredrar en ny start, skapa en konsolapp:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs`‑filen kommer att innehålla koden för streckkodsgenerering som visas senare.

## Steg 3: Ställ in streckkodsgeneratorn

Kärnan i processen är klassen `BarcodeGenerator`. Du instansierar den med önskat `EncodeTypes`‑enum‑värde och den text du vill koda.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Varför varje rad är viktig

* **EncodeTypes.MacroPdf417** talar om för Aspose att producera en PDF417‑streckkod som kan delas upp i segment. Detta är nödvändigt för stora nyttolaster som överskrider en enskild symbols kapacitet.
* **XDimension.Pixels** styr den visuella densiteten. Ett värde på 2 ger en klar bild på de flesta skärmar och skrivare utan att öka filstorleken.
* **MacroPdf417*‑egenskaper** bäddar in metadata som downstream‑skannrar läser som separata fält (fil‑ID, segment‑ID osv.). Detta är delen i handledningen som visar “hur man lägger till metadata”.
* **MacroPdf417TimeStamp** demonstrerar “hur man ställer in tidsstämpel”. `DateTime`‑instansen kan vara vilken UTC‑tid som helst; att använda UTC undviker tidszonsambiguitet när streckkoden färdas över regioner.
* **MacroPdf417Terminator** definierar hur makrosequensen avslutas. `Set` är det vanligaste valet eftersom det signalerar det sista segmentet till läsaren.
* **Save(..., BarCodeImageFormat.Png)** skriver en förlustfri bild som bevarar de fina detaljer som krävs för pålitlig skanning.

## Steg 4: Verifiera den genererade streckkoden

Kör programmet:

```bash
dotnet run
```

Du bör se konsolutdata:

```
Barcode saved to ExtPDF417Meta.png
```

Öppna `ExtPDF417Meta.png` i någon bildvisare. Bilden visar en kompakt PDF417‑symbol med texten **Åspóse.Barcóde©** och de inbäddade makrofälten. Att skanna bilden med en PDF417‑kompatibel skanner (eller en mobilapp som stödjer Macro PDF417) returnerar den ursprungliga texten plus de metadata‑värden du angav.

### Förväntade visuella egenskaper

* Mörka, jämnt fördelade vertikala staplar
* En tyst zon (marginal) som automatiskt läggs till av Aspose
* Ingen förvrängning, eftersom `XDimension` på 2 pixlar matchar PNG‑filens inbyggda upplösning

## Steg 5: Vanliga variationer och kantfall

### 5.1 Hantera specialtecken

Exempeltexten innehåller Unicode‑tecken (`Å`, `ó`, `©`). Aspose.BarCode kodar dem med UTF‑8 som standard, så de visas korrekt i streckkoden. Om du behöver en annan kodning (t.ex. ISO‑8859‑1), ange:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Stora filidentifierare

`MacroPdf417FileID` accepterar ett 32‑bit‑heltal. För värden som är större än `int.MaxValue`, dela identifieraren över flera fält eller använd ett GUID lagrat som en sträng i `MacroPdf417FileName`.

### 5.3 Justera antalet kolumner

Att öka `Pdf417.Columns` minskar streckkodens höjd men breddar varje rad. Om streckkoden måste passa på en smal etikett, sänk kolumnantalet och låt radantalet öka automatiskt.

### 5.4 Spara i andra format

Aspose stödjer BMP, JPEG, TIFF och SVG. Byt ut `BarCodeImageFormat.Png` mot önskat enum‑värde, t.ex. `BarCodeImageFormat.Svg` för en skalbar vektorgrafik.

## Steg 6: Integrera streckkoden i ett större arbetsflöde

När du har PNG‑filen kan du:

* Bädda in den i en PDF‑faktura med Aspose.PDF.
* Bifoga den till ett e‑postmeddelande som ett leveransbevis.
* Lagra bild‑bytarna i en databas för senare hämtning.

Nedan är ett snabbt kodexempel som konverterar PNG‑filen till en byte‑array för lagring:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Vanliga frågor

**Q: Fungerar detta på .NET Core?**  
A: Ja. samma API fungerar på .NET Core, .NET 5+ och .NET Framework. Referera bara rätt NuGet‑paket.

**Q: Vad händer om jag behöver generera en icke‑macro PDF417?**  
A: Använd `EncodeTypes.Pdf417` istället för `EncodeTypes.MacroPdf417`. De makrospecifika egenskaperna kommer att ignoreras.

**Q: Kan jag lägga till egna nyckel/värde‑par utöver de inbyggda fälten?**  
A: Aspose.BarCode exponerar inte godtyckliga användarfält för Macro PDF417. Om du behöver extra data, koda dem i huvudtextens nyttolast eller byt till en QR‑kod, som stödjer strukturerad append.
