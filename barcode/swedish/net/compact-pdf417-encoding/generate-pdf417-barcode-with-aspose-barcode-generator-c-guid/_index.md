# Generera PDF417-streckkod med Aspose Barcode Generator – C#-guide

Om du behöver **generera PDF417 barcode** i ett .NET‑projekt, visar den här handledningen exakt hur du gör det med **Aspose Barcode Generator**. Du får se ett komplett, körbart exempel som skapar en kompakt PDF417‑symbol, anpassar dess storlek och sparar resultatet som en PNG‑fil.

Att generera en PDF417‑streckkod är vanligt när du måste koda stora mängder data—såsom URL:er, kontaktinformation eller lagerposter—till en enda skanningsbar bild. Denna guide täcker allt från installation av biblioteket till finjustering av **how to set PDF417**‑alternativen för en kompakt utskrift.

## Vad du kommer att lära dig

* Installera och referera Aspose.BarCode‑biblioteket i ett C#‑projekt.  
* Använd **aspose barcode generator** för att skapa en PDF417‑symbol från godtycklig text.  
* Tillämpa **how to set PDF417**‑parametrarna — modulstorlek, kolumnantal och kompakt läge.  
* Spara streckkoden som en PNG‑bild och verifiera resultatet.  

**Förutsättningar**

* .NET 6.0 SDK eller senare (koden fungerar också med .NET Core 3.1 och .NET Framework 4.7+).  
* Grundläggande kunskap om C#‑konsolapplikationer.  
* En giltig Aspose.BarCode‑licens (den kostnadsfria utvärderingen fungerar för utveckling).

## Steg 1: Generera PDF417‑streckkod – skapa generatorn

Den första uppgiften är att instansiera generatorn med önskad text och PDF417‑symbologi. Detta steg svarar direkt på frågan **how to generate pdf417**.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Create a BarcodeGenerator for PDF417 with the data you want to encode.
            // The EncodeTypes enum selects the symbology; Pdf417 is the target type.
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");
```

**Varför detta är viktigt:**  
`EncodeTypes.Pdf417` talar om för biblioteket att använda PDF417‑algoritmen, som stödjer upp till 1 850 tecken. Konstruktorn accepterar också den råa datasträngen; alla Unicode‑tecken (inklusive accenter) hanteras automatiskt.

## Steg 2: How to set PDF417‑parametrar – anpassa storlek och layout

En PDF417‑streckkod kan renderas i många former. Genom att justera **how to set pdf417**‑alternativen kan du skapa en kompakt symbol som passar på en liten etikett eller en mobilskärm.

```csharp
            // -----------------------------------------------------------------
            // Step 2: Set visual parameters for the barcode
            // -----------------------------------------------------------------

            // Module size – each tiny square (pixel) of the barcode.
            // Smaller values produce a tighter image; 2 pixels is a good default.
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Number of columns – controls the width of the barcode.
            // Fewer columns make the symbol taller; 3 columns yields a compact shape.
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode – removes unnecessary quiet zones and reduces height.
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Förklaring av varje inställning**

| Parameter | Effekt | När den ska användas |
|-----------|--------|----------------------|
| `XDimension.Pixels` | Styr bredden på en enskild modul. Lägre värden minskar streckkoden men kan påverka skannerns läsbarhet på lågupplösta enheter. | Använd `2`–`4` för skärmvisning; öka för utskrivna etiketter. |
| `Pdf417.Columns` | Bestämmer hur många datakolumner symbolen innehåller. Färre kolumner ger en högre, smalare streckkod. | Välj `3`–`5` för kompakta layouter; högre värden för bredare streckkoder. |
| `Pdf417.Truncate` | Aktiverar “kompakt läge” som tar bort den yttre tysta zonen och minskar totalhöjden. | Idealiskt för UI‑element där utrymmet är begränsat. |

Dessa tre inställningar tillsammans svarar på **how to set pdf417**‑delen av uppgiften och ger dig fin‑granulär kontroll över den slutliga bilden.

## Steg 3: Spara streckkodsbilden – exportera som PNG

Efter att ha konfigurerat generatorn måste du skriva streckkoden till en fil. `Save`‑metoden stöder många format; PNG bevarar förlustfri kvalitet och fungerar bra för både webb‑ och skrivbords­scenarier.

```csharp
            // -----------------------------------------------------------------
            // Step 3: Save the generated barcode as a PNG image
            // -----------------------------------------------------------------

            // Replace YOUR_DIRECTORY with an actual folder on your machine.
            string outputPath = @"C:\Barcodes\CompactPdf417.png";

            // BarCodeImageFormat.Png tells Aspose to write a PNG file.
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            // Inform the user that the process succeeded.
            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**Vad du bör se**

När programmet körs skapas `CompactPdf417.png` i den angivna mappen. Bilden innehåller en tät PDF417‑symbol som kodar strängen `Åspóse.Barcóde©`. De flesta streckkodsläsare och mobilappar (t.ex. ZXing, Scandit) kan läsa denna bild utan ytterligare konfiguration.

## Fullständig källkod – en enda, kopiera‑och‑klistra‑klar fil

Nedan är det kompletta programmet, inklusive `using`‑direktiven och `Main`‑metoden. Du kan kopiera detta till ett nytt konsolprojekt och köra det omedelbart.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Step 1: Create the generator (how to generate pdf417)
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");

            // Step 2: Set PDF417 options (how to set pdf417)
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;   // module size
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;    // number of columns
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact mode

            // Step 3: Save as PNG
            string outputPath = @"C:\Barcodes\CompactPdf417.png";
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**Kör koden**

1. Öppna en terminal och skapa ett nytt konsolprojekt:  
   `dotnet new console -n Pdf417Demo`  
2. Lägg till Aspose.BarCode‑NuGet‑paketet:  
   `dotnet add package Aspose.BarCode`  
3. Ersätt den genererade `Program.cs` med koden ovan.  
4. Bygg och kör:  
   `dotnet run`  

Du bör se bekräftelsemeddelandet och hitta PNG‑filen på den plats du angav.

## Vanliga fallgropar och bästa praxis‑tips

* **Licensutgång** – Utvärderingsversionen lägger till ett vattenmärke efter 30 dagar. Registrera en licens tidigt för att undvika överraskningar.  
* **Mappbehörigheter** – Säkerställ att målmappen finns och att processen har skrivbehörighet; annars kastar `Save` ett `UnauthorizedAccessException`.  
* **Skanningskompatibilitet** – Om en skanner misslyckas med att läsa den kompakta streckkoden, öka `XDimension.Pixels` till `4` eller sätt `Truncate = false`.  
* **Unicode‑hantering** – Aspose.BarCode stödjer fullt ut UTF‑8; du kan koda vilken Unicode‑sträng som helst utan extra steg.  
* **Prestanda** – Att generera många streckkoder i en loop gynnas av att återanvända en enda `BarcodeGenerator`‑instans och bara uppdatera `CodeText` mellan iterationer.
