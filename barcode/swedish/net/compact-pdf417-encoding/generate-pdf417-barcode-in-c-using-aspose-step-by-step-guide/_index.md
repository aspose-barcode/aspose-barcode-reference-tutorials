# Generera PDF417‑streckkod i C# med Aspose – steg‑för‑steg‑guide

Om du behöver **generera PDF417‑streckkod** i en .NET‑applikation visar den här guiden exakt hur du gör. Du får se ett komplett, färdigt‑att‑köra‑exempel som skapar grundläggande, kompakt, Micro, GS1‑Micro och Macro PDF417‑streckkoder med Aspose.BarCode för .NET.

Att generera en PDF417‑streckkod är ett vanligt krav för fraktetiketter, transportdokument och lagersystem. I slutet av den här handledningen kommer du att kunna **generera PDF417‑streckkod**‑bilder, förstå de viktigaste parametrarna och anpassa koden för dina egna datapaket.

## Prerequisites

- .NET 6.0 SDK eller senare (koden fungerar också med .NET Framework 4.7+)
- Visual Studio 2022 eller någon C#‑IDE
- Aspose.BarCode för .NET NuGet‑paket (`Aspose.BarCode`) installerat
- Grundläggande kunskap om C#‑syntax

> **Pro tip:** Använd den kostnadsfria evalueringslicensen från Aspose för att undvika körningsrestriktioner under testning.

## Step 1: Set up the project and import namespaces

Skapa ett nytt konsolprojekt och lägg till Aspose.BarCode‑paketet:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Öppna sedan `Program.cs` och lägg till de nödvändiga `using`‑direktiven:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Dessa namnrymder ger dig åtkomst till klassen `BarcodeGenerator` och uppräkningen `EncodeTypes` som behövs för att **generera streckkod med C#**.

## Step 2: Generate a basic PDF417 barcode

Den enklaste PDF417‑streckkoden använder standardinställningar förutom X‑dimensionen (modulbredd) och antalet kolumner. Genom att justera dessa värden styr du den totala storleken och läsbarheten.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Varför det fungerar:**  
- `EncodeTypes.Pdf417` talar om för Aspose att använda PDF417‑symbologin.  
- `XDimension.Pixels` definierar den minsta stapelbredden; ett värde på 2 håller bilden liten utan att offra skanningsförmåga.  
- `Pdf417.Columns` bestämmer hur många datakolumner streckkoden innehåller; tre kolumner ger ett balanserat bildförhållande.

## Step 3: Generate a compact (truncated) PDF417 barcode

Kompakt läge tar bort stoppmönstret och minskar den totala höjden, vilket är användbart för etiketter med begränsat utrymme.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Varför det fungerar:**  
Genom att sätta `Pdf417.Truncate = true` aktiveras trunkerat läge, vilket utelämnar det högra stoppmönstret och minskar streckkodens höjd samtidigt som dataintegriteten bevaras.

## Step 4: Generate a Micro PDF417 barcode

Micro PDF417 är en mindre variant som stödjer 1‑4 kolumner. Den är idealisk för applikationer där utrymmet är begränsat, såsom små produktetiketter.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Varför det fungerar:**  
- `EncodeTypes.MicroPdf417` väljer mikro‑versionen av symbologin.  
- Kolumnantalet kan vara mellan 1 och 4; att välja 4 ger den tätaste layouten samtidigt som den förblir skannbar.

## Step 5: Generate a GS1‑compliant Micro PDF417 barcode

GS1‑prefix lägger till standardiserade identifierare (t.ex. GTIN, batch‑nummer) till streckkodens data. Aspose låter dig bädda in dessa direkt.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Varför det fungerar:**  
GS1‑applikationsidentifierare (AIs) placeras i parenteser. Aspose tolkar dem och lägger till den formattering som krävs av GS1‑skannrar.

## Step 6: Generate a Macro PDF417 barcode with full metadata

Macro PDF417 låter dig dela ett stort datapaket över flera länkade streckkoder. Du kan bädda in fil‑nivåmetadata såsom fil‑ID, segmentantal, tidsstämplar och anpassade strängar.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Varför det fungerar:**  
Varje `MacroPdf417*`‑egenskap motsvarar ett specifikt segment i macro‑streckkodsspecifikationen. Genom att sätta dessa värden säkerställer du att en skanner kan återskapa den ursprungliga filen från flera streckkodsbilder.
