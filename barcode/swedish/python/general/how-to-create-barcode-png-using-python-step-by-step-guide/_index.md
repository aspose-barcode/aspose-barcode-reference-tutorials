# Hur man skapar barcode PNG med Python – steg‑för‑steg guide

Om du behöver **skapa barcode PNG**‑filer från godtyckliga strängar, ger den här handledningen en färdig‑att‑köra lösning. Du kommer att se exakt hur du genererar en Code 128‑streckkod, konverterar text till en streckkodsbild och sparar resultatet som en PNG‑fil – allt med några få rader Python.

Guiden täcker allt du behöver veta, från att installera det nödvändiga biblioteket till att anpassa utdata för olika användningsfall. När du är klar kan du bädda in barcode‑generering i vilket Python‑projekt som helst utan att behöva söka efter ytterligare dokumentation.

## Vad du kommer att lära dig

* Installera paketet **barcode generator python** som stödjer Code 128.
* Använd `BarCodeGenerator` för att **generera code 128 barcode** från en textsträng.
* Spara resultatet som en högkvalitativ PNG med `save`.
* Justera bildstorlek, förgrunds‑/bakgrundsfärger och hantera vanliga fel.
* Verifiera att PNG‑filen skapades korrekt.

### Förutsättningar

| Krav | Orsak |
|------|-------|
| Python 3.8+ | Modern syntax och typindikeringar |
| Internet access (for `pip install`) | För att ladda ner biblioteket |
| Write permission to a folder | För att lagra den genererade PNG‑filen |

Inga externa tjänster krävs; allt körs lokalt.

## Steg 1: Installera barcode‑biblioteket

Det enklaste sättet att **konvertera text till barcode** i Python är att använda paketet **Aspose.BarCode for Python via .NET**, som stödjer Code 128 direkt.

```bash
pip install aspose-barcode
```

> **Proffstips:** Om du arbetar i en virtuell miljö, aktivera den innan du kör kommandot för att hålla beroenden isolerade.

## Steg 2: Importera de klasser du behöver

Efter installation, importera de centrala klasserna. Import‑satserna är korta, vilket gör koden lätt att läsa.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` skapar streckkodsbilden.
* `EncodeTypes` tillhandahåller en uppräkning av stödjade symbologier, inklusive `CODE_128`.

## Steg 3: Definiera den text du vill koda

Välj en godtycklig alfanumerisk sträng. Code 128 kan representera hela ASCII‑uppsättningen, så du är inte begränsad till siffror.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Om inmatningen innehåller tecken som inte stöds, kastar generatorn ett `ValueError`. Omge tilldelningen med ett `try`‑block om du förväntar dig användargenererad data.

## Steg 4: Skapa barcode‑generatorn för Code 128

Instansiera `BarCodeGenerator` med den önskade symbologin och den text du definierade. Detta är kärnan i **hur man genererar barcode**‑bilder i Python.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Varför Code 128? Det erbjuder hög densitet och kan koda hela ASCII‑intervallet, vilket gör det idealiskt för lagerhanteringssystem, fraktetiketter och biljetter.

## Steg 5: (Valfritt) Anpassa utseendet

Du kan finjustera streckkoden innan du sparar den. Följande alternativ är vanliga:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Dessa inställningar påverkar den slutgiltiga **create barcode png**‑utmatningen utan att ändra den kodade datan.

## Steg 6: Spara streckkoden som en PNG‑fil

Slutligen skriver du bilden till disk. `save`‑metoden upptäcker automatiskt filändelsen, så att ange `.png` skapar en PNG‑bild.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Om målkatalogen inte finns, kastar Python ett `FileNotFoundError`. Skapa katalogen i förväg eller använd `os.makedirs` med `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### Förväntad utdata

Efter att skriptet har körts hittar du `extended_barcode.png` i `output`‑mappen. När du öppnar filen ser du en skarp Code 128‑streckkod som kodar `1234567890`.

![Generated barcode PNG created with Python](generated_barcode.png "create barcode png example")

## Steg 7: Verifiera streckkoden (snabb kontroll)

Du kan läsa PNG‑filen igen med samma bibliotek för att bekräfta att det kodade värdet matchar den ursprungliga texten.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Kör detta block så skrivs följande ut:

```
Verification succeeded: 1234567890
```

Om påståendet misslyckas, dubbelkolla `barcode_text` och eventuella anpassade parametrar du har satt.

## Vanliga variationer och kantfall

| Situation | Anpassning |
|-----------|------------|
| **Längre text (> 20 tecken)** | Öka `image_width` för att undvika trunkering. |
| **Behöver en transparent bakgrund** | Sätt `back_color = "Transparent"` innan du sparar. |
| **Generera flera streckkoder i en loop** | Omge steg 3‑6 i en `for`‑loop och ändra `barcode_text` för varje iteration. |
| **Spara som JPEG istället för PNG** | Ändra filändelsen till `.jpg`; biblioteket hanterar formatet automatiskt. |
| **Kör på en huvudlös server** | Biblioteket kräver ingen GUI, vilket gör det säkert för CI‑pipelines. |

## Fullt skript för snabb kopiera‑och‑klistra

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Spara skriptet som `generate_barcode.py` och kör:

```bash
python generate_barcode.py
```

Du kommer att se bekräftelsemeddelandena och en ny PNG‑fil i `output`‑mappen.

Du vet nu hur du **skapar barcode PNG**‑filer i Python, från att installera paketet **barcode generator python** till att anpassa utseendet och verifiera resultatet. Känn dig fri att experimentera med färgscheman, storlekar och batch‑behandling – ditt nya barcode‑skapande arbetsflöde är redo för produktion. Happy coding!
