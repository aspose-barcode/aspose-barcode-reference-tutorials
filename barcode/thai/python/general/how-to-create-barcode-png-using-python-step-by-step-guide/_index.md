# วิธีสร้าง barcode PNG ด้วย Python – คู่มือขั้นตอนโดยละเอียด

หากคุณต้องการ **สร้างไฟล์ barcode PNG** จากสตริงใด ๆ คำแนะนำนี้จะให้วิธีแก้ที่พร้อมใช้งาน คุณจะได้เห็นขั้นตอนการสร้าง barcode Code 128, แปลงข้อความเป็นภาพ barcode, และบันทึกผลลัพธ์เป็นไฟล์ PNG—ทั้งหมดด้วยไม่กี่บรรทัดของ Python

คู่มือนี้ครอบคลุมทุกสิ่งที่คุณต้องรู้ ตั้งแต่การติดตั้งไลบรารีที่จำเป็นจนถึงการปรับแต่งผลลัพธ์สำหรับกรณีการใช้งานต่าง ๆ เมื่อจบคุณจะสามารถฝังการสร้าง barcode ลงในโปรเจกต์ Python ใด ๆ ได้โดยไม่ต้องค้นหาเอกสารเพิ่มเติม

## สิ่งที่คุณจะได้เรียนรู้

* ติดตั้งแพ็กเกจ **barcode generator python** ที่รองรับ Code 128
* ใช้ `BarCodeGenerator` เพื่อ **สร้าง barcode code 128** จากสตริงข้อความ
* บันทึกผลลัพธ์เป็น PNG คุณภาพสูงด้วย `save`
* ปรับขนาดภาพ, สีพื้นหน้า/พื้นหลัง, และจัดการข้อผิดพลาดทั่วไป
* ตรวจสอบว่า PNG ถูกสร้างอย่างถูกต้อง

### ข้อกำหนดเบื้องต้น

| Requirement | Reason |
|-------------|--------|
| Python 3.8+ | Modern syntax and type hints |
| Internet access (for `pip install`) | To download the library |
| Write permission to a folder | To store the generated PNG |

ไม่ต้องใช้บริการภายนอก; ทุกอย่างทำงานบนเครื่องของคุณ

## ขั้นตอนที่ 1: ติดตั้งไลบรารี barcode

วิธีที่ง่ายที่สุดในการ **แปลงข้อความเป็น barcode** ใน Python คือใช้แพ็กเกจ **Aspose.BarCode for Python via .NET** ซึ่งรองรับ Code 128 โดยอัตโนมัติ

```bash
pip install aspose-barcode
```

> **Pro tip:** หากคุณทำงานใน virtual environment ให้เปิดใช้งานก่อนรันคำสั่งเพื่อแยกการพึ่งพาออกจากกัน

## ขั้นตอนที่ 2: นำเข้าคลาสที่ต้องการ

หลังจากติดตั้งแล้ว ให้นำเข้าคลาสหลัก คำสั่ง import สั้นและอ่านง่าย

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` สร้างภาพ barcode
* `EncodeTypes` ให้รายการ enumeration ของ symbology ที่รองรับ รวมถึง `CODE_128`

## ขั้นตอนที่ 3: กำหนดข้อความที่ต้องการเข้ารหัส

เลือกสตริงอัลฟานูเมอริกใดก็ได้ Code 128 สามารถแทนค่าชุด ASCII ทั้งหมดได้ ดังนั้นคุณไม่จำกัดเฉพาะตัวเลข

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

หากอินพุตมีอักขระที่ไม่รองรับ ตัวสร้างจะโยน `ValueError` ให้ใส่โค้ดใน `try` block หากคาดว่าจะรับข้อมูลจากผู้ใช้

## ขั้นตอนที่ 4: สร้าง barcode generator สำหรับ Code 128

สร้างอินสแตนซ์ `BarCodeGenerator` ด้วย symbology ที่ต้องการและข้อความที่กำหนด นี่คือหัวใจของ **วิธีสร้าง barcode** ใน Python

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

ทำไมต้อง Code 128? มันให้ความหนาแน่นสูงและสามารถเข้ารหัสชุด ASCII ทั้งหมด เหมาะสำหรับระบบสินค้าคงคลัง, ป้ายจัดส่ง, และตั๋วต่าง ๆ

## ขั้นตอนที่ 5: (ทางเลือก) ปรับแต่งลักษณะการแสดงผล

คุณสามารถปรับแต่ง barcode ก่อนบันทึกได้ ตัวเลือกต่อไปนี้เป็นที่นิยม

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

การตั้งค่าเหล่านี้มีผลต่อผลลัพธ์ **create barcode png** สุดท้ายโดยไม่กระทบข้อมูลที่เข้ารหัส

## ขั้นตอนที่ 6: บันทึก barcode เป็นไฟล์ PNG

สุดท้าย ให้เขียนภาพลงดิสก์ เมธอด `save` จะตรวจจับนามสกุลไฟล์โดยอัตโนมัติ ดังนั้นการใส่ `.png` จะสร้างไฟล์ PNG

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

หากโฟลเดอร์เป้าหมายไม่มีอยู่ Python จะโยน `FileNotFoundError` ให้สร้างโฟลเดอร์ล่วงหน้าหรือใช้ `os.makedirs` พร้อม `exist_ok=True`

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### ผลลัพธ์ที่คาดหวัง

หลังจากรันสคริปต์ คุณจะพบไฟล์ `extended_barcode.png` ในโฟลเดอร์ `output` เปิดไฟล์จะเห็น barcode Code 128 ชัดเจนที่เข้ารหัส `1234567890`

![Generated barcode PNG created with Python](generated_barcode.png "create barcode png example")

## ขั้นตอนที่ 7: ตรวจสอบ barcode (ตรวจสอบอย่างเร็ว)

คุณสามารถอ่าน PNG กลับมาโดยใช้ไลบรารีเดียวกันเพื่อยืนยันว่าค่าที่เข้ารหัสตรงกับข้อความต้นฉบับ

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

การรันบล็อกนี้จะแสดงผล:

```
Verification succeeded: 1234567890
```

หากการตรวจสอบล้มเหลว ให้ตรวจสอบ `barcode_text` และพารามิเตอร์ที่คุณตั้งค่า

## ความแปรผันทั่วไปและกรณีขอบ

| Situation | Adjustment |
|-----------|------------|
| **Longer text (> 20 characters)** | Increase `image_width` to avoid truncation. |
| **Need a transparent background** | Set `back_color = "Transparent"` before saving. |
| **Generate multiple barcodes in a loop** | Wrap steps 3‑6 in a `for` loop, changing `barcode_text` each iteration. |
| **Save as JPEG instead of PNG** | Change the file extension to `.jpg`; the library handles the format automatically. |
| **Running on a headless server** | The library does not require a GUI, making it safe for CI pipelines. |

## สคริปต์เต็มสำหรับคัดลอก‑วางอย่างรวดเร็ว

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

บันทึกสคริปต์เป็น `generate_barcode.py` แล้วรัน:

```bash
python generate_barcode.py
```

คุณจะเห็นข้อความยืนยันและไฟล์ PNG ใหม่ในโฟลเดอร์ `output`
