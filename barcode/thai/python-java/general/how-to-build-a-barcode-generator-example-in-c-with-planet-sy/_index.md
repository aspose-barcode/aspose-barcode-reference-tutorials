# ตัวอย่างการสร้าง Barcode ด้วย C# – สร้าง Planet barcode และสร้างภาพ barcode

หากคุณต้องการ **ตัวอย่างการสร้าง barcode** ด้วย C# คู่มือนี้จะแสดงให้คุณเห็นอย่างชัดเจนว่าการสร้าง Planet barcode และสร้างภาพ barcode ด้วย C# ทำได้อย่างไรในเพียงไม่กี่บรรทัดของโค้ด คุณจะได้เห็นโซลูชันที่พร้อมรันเต็มรูปแบบที่สามารถนำไปใส่ในโปรเจกต์ .NET ใดก็ได้

Planet barcode ถูกใช้โดยบริการไปรษณีย์เพื่อเข้ารหัสข้อมูลเส้นทาง ในตอนท้ายของบทเรียนนี้คุณจะเข้าใจว่าทำไมไลบรารีจึงกำหนดความสูงของ barcode อัตโนมัติ วิธีควบคุมมิติ X และวิธีบันทึกผลลัพธ์เป็นไฟล์ PNG ไม่ต้องใช้เครื่องมือภายนอก—เพียงแค่แพ็กเกจ Aspose.BarCode for .NET และสภาพแวดล้อมการพัฒนา .NET

## ข้อกำหนดเบื้องต้น

ก่อนเริ่มทำตามขั้นตอน ให้ตรวจสอบว่าคุณมี:

* .NET 6.0 SDK หรือใหม่กว่า  
* Visual Studio 2022 (หรือ IDE ใดก็ได้ที่รองรับ .NET)  
* แพ็กเกจ **Aspose.BarCode for .NET** จาก NuGet (`Aspose.BarCode`)  

คุณสามารถติดตั้งแพ็กเกจได้จากบรรทัดคำสั่ง:

```bash
dotnet add package Aspose.BarCode
```

## ขั้นตอนที่ 1: เริ่มต้นตัวสร้าง barcode สำหรับการเข้ารหัส Planet

ขั้นตอนแรกใน **ตัวอย่างการสร้าง barcode** ใด ๆ คือการสร้างอินสแตนซ์ `BarcodeGenerator` และระบุประเภทการเข้ารหัส สำหรับ Planet barcode คุณใช้ `EncodeTypes.Planet` พร้อมส่งสตริงข้อมูลที่ต้องการเข้ารหัส

```csharp
using Aspose.BarCode.Generation;

// Create a Planet barcode generator with the data to encode
BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

**เหตุผลที่สำคัญ:** enum `EncodeTypes.Planet` บอกไลบรารีให้ใช้สัญลักษณ์ Planet ซึ่งมีรูปแบบโมดูลคงที่ตามมาตรฐานไปรษณีย์ การใส่ข้อมูล (`"123456"` ในตัวอย่างนี้) ทำให้ barcode มีรหัสเส้นทางเชิงตัวเลขที่ถูกต้อง

## ขั้นตอนที่ 2: ตั้งค่ามิติ X (ความกว้างโมดูล) เป็นพิกเซล

มิติ X ควบคุมความกว้างของแต่ละโมดูล (บาร์ที่เล็กที่สุด) การปรับค่านี้จะเปลี่ยนขนาดโดยรวมของ barcode โดยไม่กระทบต่อความอ่านได้

```csharp
// Set the X dimension (module width) to 4 pixels
generator.Parameters.Barcode.XDimension.Pixels = 4;
```

**เหตุผลที่สำคัญ:** มิติ X ที่ใหญ่ขึ้นทำให้ barcode มีขนาดใหญ่ขึ้น ซึ่งอาจเป็นประโยชน์เมื่อพิมพ์บนซองจดหมายขนาดใหญ่ ไลบรารีจะปรับสเกลความสูงอัตโนมัติเพื่อรักษาอัตราส่วนที่ถูกต้องสำหรับ Planet barcode

## ขั้นตอนที่ 3: บันทึกภาพ barcode ลงดิสก์

สุดท้าย คุณบันทึกภาพที่สร้างขึ้น ไลบรารีจะคำนวณความสูงที่เหมาะสมโดยอัตโนมัติ ดังนั้นคุณเพียงระบุเส้นทางและรูปแบบไฟล์เท่านั้น

```csharp
using Aspose.BarCode;

// Define the output file path
string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";

// Save the barcode as a PNG image
generator.Save(outputFile, BarCodeImageFormat.Png);
```

**เหตุผลที่สำคัญ:** การบันทึกเป็น PNG จะรักษาขอบที่คมของ barcode ซึ่งจำเป็นต่อการสแกนที่เชื่อถือได้ เมธอด `Save` ยังรองรับรูปแบบอื่น (JPEG, BMP, TIFF) หากคุณต้องการเอาต์พุตรูปแบบอื่น

### ผลลัพธ์ที่คาดหวัง

หลังจากรันโค้ด คุณจะพบไฟล์ชื่อ **PlanetAutoHeight.png** ใน `C:\Barcodes` ภาพจะคล้ายกับภาพตัวอย่างด้านล่าง (ข้อความแทน: *ตัวอย่างการสร้าง barcode แสดง Planet barcode*).

![Planet barcode generated by the C# example](/images/planet-barcode-example.png){alt="ตัวอย่างการสร้าง barcode แสดง Planet barcode"}

## ขั้นตอนที่ 4: ตัวเลือก – ปรับสีพื้นหน้าและพื้นหลัง

หากแอปพลิเคชันของคุณต้องการสไตล์ภาพที่แตกต่าง คุณสามารถเปลี่ยนสีของ barcode ก่อนบันทึกได้

```csharp
// Set foreground (bars) to dark blue and background to light gray
generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

// Save the customized image
generator.Save(@"C:\Barcodes\PlanetCustomColors.png", BarCodeImageFormat.Png);
```

**เคล็ดลับ:** ควรทดสอบ barcode ที่ปรับสีแล้วด้วยสแกนเนอร์จริงเพื่อยืนยันว่าการเปลี่ยนสีไม่ส่งผลต่อการอ่าน

## ขั้นตอนที่ 5: การจัดการข้อผิดพลาดและการตรวจสอบความถูกต้อง

ไลบรารี Aspose.BarCode จะโยน `ArgumentException` หากข้อมูลไม่เป็นไปตามข้อกำหนดของสัญลักษณ์ Planet (เช่น มีอักขระที่ไม่ใช่ตัวเลข) ให้ห่อโค้ดการสร้างในบล็อก try‑catch เพื่อให้ฟีดแบ็กที่ชัดเจน

```csharp
try
{
    BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "ABC123");
    generator.Save(@"C:\Barcodes\InvalidPlanet.png", BarCodeImageFormat.Png);
}
catch (ArgumentException ex)
{
    Console.WriteLine($"Invalid data for Planet barcode: {ex.Message}");
}
```

**เหตุผลที่สำคัญ:** Planet barcode ยอมรับเฉพาะข้อมูลเชิงตัวเลขที่มีความยาวตามที่กำหนด การตรวจสอบล่วงหน้าช่วยป้องกันการล้มเหลวขณะรันและประหยัดเวลาในการทดสอบการผสานรวม

## ตัวอย่างเต็มที่สามารถรันได้

การรวมทุกขั้นตอนเข้าด้วยกันจะได้โปรแกรมที่เป็นอิสระซึ่งคุณสามารถคัดลอก วาง และรันได้ทันที

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;
using Aspose.BarCode;

class Program
{
    static void Main()
    {
        // Step 1: Initialize the generator with Planet encoding
        BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");

        // Step 2: Set the X dimension (module width) to 4 pixels
        generator.Parameters.Barcode.XDimension.Pixels = 4;

        // Optional: customize colors (comment out if not needed)
        // generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
        // generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

        // Step 3: Save the barcode image
        string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";
        generator.Save(outputFile, BarCodeImageFormat.Png);

        Console.WriteLine($"Planet barcode saved to {outputFile}");
    }
}
```

คอมไพล์และรันโปรแกรม:

```bash
dotnet run
```

คุณจะเห็นข้อความในคอนโซลยืนยันตำแหน่งไฟล์ และไฟล์ PNG จะมี Planet barcode ที่สร้างขึ้น

## ความแปรผันทั่วไปและกรณีขอบ

| ความแปรผัน | วิธีการทำ | เมื่อควรใช้ |
|-----------|-----------|------------|
| **ความยาวข้อมูลต่างกัน** | เปลี่ยนอาร์กิวเมนต์ที่สองใน `new BarcodeGenerator(EncodeTypes.Planet, "987654321")` | บริการไปรษณีย์ที่ต้องการหมายเลขเส้นทางยาวกว่า |
| **ความละเอียดสูงขึ้น** | ตั้งค่า `generator.Parameters.ImageResolution = 300;` ก่อน `Save` | พิมพ์บนเครื่องพิมพ์ที่มี DPI สูง |
| **รูปแบบภาพต่างกัน** | ใช้ `BarCodeImageFormat.Jpeg` หรือ `BarCodeImageFormat.Tiff` | เมื่อ PNG ไม่เหมาะกับกระบวนการทำงานของคุณ |
| **ชื่อไฟล์ไดนามิก** | `string outputFile = Path.Combine(folder, $"Planet_{DateTime.Now:yyyyMMdd_HHmmss}.png");` | การประมวลผลเป็นชุดของหลาย barcode |

## เคล็ดลับขั้นสูงสำหรับตัวอย่างการสร้าง barcode ที่มั่นคง

* **ใช้ซ้ำอินสแตนซ์ generator** เมื่อสร้างหลาย barcode ด้วยการตั้งค่าเดียวกัน; เพียงเปลี่ยน `EncodeTypes` หรือสตริงข้อมูลเพื่อเพิ่มประสิทธิภาพ  
* **ตรวจสอบความถูกต้องของอินพุต** ก่อนส่งให้ `BarcodeGenerator` regex ง่าย ๆ เช่น `^\d{6,9}$` จะทำให้ข้อมูลสอดคล้องกับข้อกำหนดของ Planet  
* **ปล่อยทรัพยากร** หากคุณสร้างภาพหลายพันภาพในบริการที่ทำงานต่อเนื่อง `BarcodeGenerator` implements `IDisposable` ดังนั้นให้ห่อด้วยบล็อก `using` เมื่อเหมาะสม  

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, data))
{
    // configure and save...
}
```

## สรุป

**ตัวอย่างการสร้าง barcode** นี้แสดงให้เห็นวิธี **สร้าง Planet barcode** และ **สร้างภาพ barcode ด้วย C#** ด้วย Aspose.BarCode for .NET คุณได้เรียนรู้วิธีเริ่มต้น generator, ตั้งค่ามิติ X, ปรับสีตามต้องการ, จัดการข้อผิดพลาดการตรวจสอบ, และบันทึกผลเป็นไฟล์ PNG พร้อมโค้ดเต็มที่ให้คุณนำไปผสานการสร้าง Planet barcode ในแอปพลิเคชัน C# ใดก็ได้ทันที
