# สร้างบาร์โค้ด Planet ด้วย C# – คู่มือการเขียนโปรแกรมแบบครบถ้วน

หากคุณต้องการ **สร้างบาร์โค้ด planet** ด้วย C# คู่มือนี้จะแสดงขั้นตอนที่ต้องทำอย่างละเอียด คุณยังจะได้เรียนรู้ **วิธีตั้งค่าขนาดบาร์โค้ด** เพื่อให้แถบมีความกว้างตามที่ต้องการอย่างแม่นยำ

การสร้างบาร์โค้ด Planet เป็นเรื่องปกติเมื่อทำงานกับบริการไปรษณีย์หรือระบบโลจิสติกส์ โค้ดด้านล่างครอบคลุมทั้งเวอร์ชันแถบเต็ม (filled‑bar) เริ่มต้นและสไตล์แถบว่าง (empty‑bar) ทางเลือก พร้อมตัวอย่างสั้น ๆ สำหรับรูปแบบ RM4SCC เมื่อจบบทเรียนนี้คุณจะมีสแนปช็อตที่นำกลับไปใช้ใหม่ได้ในโปรเจกต์ .NET ใด ๆ

## ข้อกำหนดเบื้องต้น

ก่อนเริ่มทำงาน ตรวจสอบให้แน่ใจว่าคุณมี:

* .NET 6.0 หรือใหม่กว่า (API นี้ทำงานกับ .NET Framework 4.6+ ด้วย)
* แพคเกจ NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`) ที่เพิ่มเข้าในโปรเจกต์ของคุณ
* โฟลเดอร์ที่สามารถเขียนไฟล์ PNG ได้
* ความคุ้นเคยพื้นฐานกับไวยากรณ์ C# และ Visual Studio (หรือ IDE ใดก็ได้)

> **เคล็ดลับ:** ใช้เส้นทางแบบ absolute หรือ `Path.Combine(Environment.CurrentDirectory, "output")` เพื่อหลีกเลี่ยงปัญหาการอนุญาตเมื่อบันทึกภาพ

## ขั้นตอนที่ 1 – เริ่มต้นตัวสร้างบาร์โค้ด Planet (แถบเต็ม)

ขั้นตอนแรกคือการสร้างอินสแตนซ์ `BarcodeGenerator` สำหรับสัญลักษณ์ Planet โดยค่าเริ่มต้นจะสร้าง **แถบเต็ม**  

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

ค่า enum `EncodeTypes.Planet` บอก Aspose.BarCode ให้ใช้รูปแบบ Planet ส่วน `"123456"` คือข้อมูลที่ต้องเข้ารหัส

## ขั้นตอนที่ 2 – วิธีตั้งค่าขนาดบาร์โค้ดเพื่อให้ได้ขนาดสม่ำเสมอ

เพื่อควบคุมความกว้างของแต่ละแถบ ให้ปรับ **X‑dimension** นี่เป็นวิธีหลักในการ **ตั้งค่าขนาดบาร์โค้ด** และทำให้บาร์โค้ดพอดีกับขนาดฉลากของคุณ  

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

คุณสมบัติ `Pixels` กำหนดความกว้างของแถบเป็นพิกเซลบนหน้าจอ ค่าที่นิยมใช้คือ 2 – 5 พิกเซลสำหรับฉลากไปรษณีย์มาตรฐาน; เพิ่มค่าเพื่อพิมพ์ขนาดใหญ่ขึ้น

## ขั้นตอนที่ 3 – บันทึกบาร์โค้ด Planet แถบเต็มเป็น PNG

ต่อไปให้เขียนภาพลงดิสก์ PNG จะรักษาความคมของขอบ ซึ่งเหมาะกับการสแกน  

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

แทนที่ `YOUR_DIRECTORY` ด้วยเส้นทางที่คุณเตรียมไว้ก่อนหน้า หลังจากรันโค้ดนี้คุณจะเห็นไฟล์ที่คล้ายกับภาพด้านล่าง  

![บาร์โค้ด Planet พร้อมแถบเต็ม](planet_filled.png "บาร์โค้ด Planet พร้อมแถบเต็ม – สร้างโดยโค้ด C#")

*Alt text:* **บาร์โค้ด Planet พร้อมแถบเต็มที่สร้างโดยโค้ด C#** (matches `og_image_alt`).

## ขั้นตอนที่ 4 – สร้างบาร์โค้ด Planet ด้วยแถบว่าง (unfilled)

หากบริการไปรษณีย์ของคุณต้องการให้แถบเป็น **ว่าง** ให้สลับค่าสถานะ `FilledBars` หลังจากสร้างอินสแตนซ์  

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

คอนสตรัคเตอร์ยังคงเหมือนเดิม; ความแตกต่างอยู่ที่ขั้นตอนการตั้งค่าถัดไป

## ขั้นตอนที่ 5 – วิธีตั้งค่าขนาดบาร์โค้ดและทำให้แถบเป็นว่าง

เช่นเดิม ให้ตั้งค่า X‑dimension เพื่อความสอดคล้องด้านภาพ แล้วปิดการใช้แถบเต็ม  

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

คุณสมบัติ `FilledBars = false` คือสิ่งที่ทำให้สไตล์การเรนเดอร์เปลี่ยนเป็นแถว่าง การใช้ X‑dimension เดียวกันทำให้บาร์โค้ดแถว่างตรงกับเวอร์ชันแถบเต็มอย่างพอดี

## ขั้นตอนที่ 6 – บันทึกบาร์โค้ด Planet แถว่าง  

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

ตอนนี้คุณจะมีไฟล์ PNG สองไฟล์: หนึ่งไฟล์แถบเต็มและอีกไฟล์แถว่าง ทั้งสองใช้ขนาดเดียวกัน

## ขั้นตอนที่ 7 – (ทางเลือก) สร้างบาร์โค้ด RM4SCC เพื่อเปรียบเทียบ

RM4SCC เป็นสัญลักษณ์ไปรษณีย์อีกแบบหนึ่งที่ใช้สไตล์แถบเต็มแบบเริ่มต้น ขั้นตอนคล้ายกับตัวอย่าง Planet แสดงให้เห็นว่า **วิธีตั้งค่าขนาดบาร์โค้ด** ทำงานได้กับหลายรูปแบบ  

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

การรันสามขั้นตอนนี้จะสร้างไฟล์ `PostalRM4SCCFilledBars.png` ซึ่งคุณสามารถเปรียบเทียบเคียงกับผลลัพธ์จาก Planet ได้

## ทำไม X‑dimension ถึงสำคัญ

X‑dimension กำหนด **ความกว้างขั้นต่ำที่พิมพ์ได้** ของแต่ละแถบ หากตั้งค่านี้ต่ำเกินไป บาร์โค้ดอาจเบลอบนเครื่องพิมพ์ความละเอียดต่ำ ทำให้สแกนล้มเหลว ในทางกลับกัน X‑dimension ที่ใหญ่เกินไปอาจทำให้บาร์โค้ดเกินขนาดฉลากและเสียพื้นที่ ด้วยการ **ตั้งค่าขนาดบาร์โค้ด** อย่างชัดเจน คุณจะได้การควบคุมขนาดภาพสุดท้ายอย่างแน่นอน ซึ่งจำเป็นต่อกระบวนการไปรษณีย์อัตโนมัติ

## ข้อผิดพลาดทั่วไปและวิธีหลีกเลี่ยง

| ปัญหา | สาเหตุ | วิธีแก้ |
|-------|-------|-----|
| บาร์โค้ดดูบิดเบี้ยว | ตั้งค่า X‑dimension เป็นหน่วย points แทนพิกเซล | ใช้คุณสมบัติ `Pixels` เสมอเพื่อควบคุมพิกเซลอย่างแม่นยำ |
| แถบว่างยังดูเหมือนแถบเต็ม | ไม่ได้ตั้งค่า `FilledBars` เป็น `false` หลังจากเปลี่ยน X‑dimension | ตั้งค่า `FilledBars = false` *หลังจาก* ปรับ X‑dimension |
| ไฟล์ที่บันทึกเป็นไฟล์เปล่า | โฟลเดอร์ปลายทางไม่มีอยู่หรือไม่มีสิทธิ์เขียน | ตรวจสอบให้โฟลเดอร์มี (`Directory.CreateDirectory`) และแอปทำงานด้วยสิทธิ์ที่เพียงพอ |
| ภาพเบลอบนการพิมพ์ | PNG ที่บันทึกจากหน้าจอความละเอียดสูง | ใช้ `BarCodeImageFormat.Png` (lossless) และพิจารณาคุณสมบัติ `Resolution` หากจำเป็น |

## ตัวอย่างเต็มที่สามารถรันได้

คัดลอกบล็อกทั้งหมดด้านล่างไปยังโปรเจกต์คอนโซลใหม่ (`dotnet new console`) แล้วรัน โปรแกรมจะสร้างไฟล์ PNG สามไฟล์ในโฟลเดอร์ `output`  

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**ผลลัพธ์ที่คาดหวัง:** ไฟล์ PNG สามไฟล์—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png`, และ `PostalRM4SCCFilledBars.png`—แต่ละไฟล์มีแถบกว้าง 4 พิกเซล พร้อมพิมพ์หรือประมวลผลต่อไป

## สรุป

คุณได้เรียนรู้วิธี **สร้างบาร์โค้ด planet** ด้วย C# และวิธี **ตั้งค่าขนาดบาร์โค้ด** อย่างแม่นยำสำหรับสไตล์แถบเต็มและแถว่าง รูปแบบเดียวกันนี้ใช้ได้กับสัญลักษณ์อื่น ๆ เช่น RM4SCC ทำให้คุณมีพื้นฐานที่ยืดหยุ่นสำหรับความต้องการบาร์โค้ดไปรษณีย์ใด ๆ

ต่อไปคุณอาจสำรวจ:

* เพิ่มข้อความที่อ่านได้มนุษย์ใต้บาร์โค้ด (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* เปลี่ยนสีแถบด้วย `Parameters.Barcode.BarColor`
* สร้างบาร์โค้ดในรูปแบบเวกเตอร์ (SVG, EPS) เพื่อการพิมพ์ที่ปรับขนาดได้

ลองปรับค่า X‑dimension, สตริงข้อมูล, และรูปแบบการบันทึกต่าง ๆ เพื่อให้เข้ากับกระบวนการทำงานของคุณเอง ขอให้สนุกกับการเขียนโค้ด!
