# วิธีบันทึกภาพบาร์โค้ดใน C# ด้วย BarcodeGenerator API

หากคุณต้องการ **how to save barcode** ไฟล์จากแอปพลิเคชัน .NET คู่มือนี้จะแสดงขั้นตอนที่ชัดเจน คุณจะได้เห็น **barcode generator example** ที่สมบูรณ์ซึ่งสร้างบาร์โค้ด DataBar Stacked Omnidirectional ปรับอัตราส่วนภาพ และบันทึกเป็นไฟล์ PNG สองไฟล์

การบันทึกภาพบาร์โค้ดเป็นความต้องการทั่วไปเมื่อสร้างระบบสินค้าคงคลัง, เทอร์มินัลจุดขาย, หรือกระบวนการติดฉลากอัตโนมัติ เมื่อจบบทเรียนนี้คุณจะสามารถสร้างโค้ด C# สำหรับบาร์โค้ดที่สร้างภาพที่เชื่อถือได้พร้อมสำหรับการพิมพ์หรือแสดงผล

## ข้อกำหนดเบื้องต้น

- .NET 6.0 SDK หรือรุ่นที่ใหม่กว่า ติดตั้งแล้ว  
- Visual Studio 2022 (หรือ IDE ที่รองรับ C# ใด ๆ)  
- แพคเกจ NuGet **Aspose.BarCode for .NET** (โค้ดใช้ `Aspose.BarCode.Generation`)  

คุณสามารถเพิ่มแพคเกจด้วยคำสั่งต่อไปนี้:

```bash
dotnet add package Aspose.BarCode
```

## ขั้นตอนที่ 1: ตั้งค่าโครงการคอนโซล C# ขั้นพื้นฐาน

สร้างโครงการคอนโซลใหม่และอ้างอิงไลบรารี:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

เปิดไฟล์ `Program.cs` ไฟล์นี้จะมีเมธอด `Main` ที่เราจะใส่ตรรกะ **generate barcode C#** 

## ขั้นตอนที่ 2: เริ่มต้น BarcodeGenerator สำหรับบาร์โค้ด DataBar Stacked Omnidirectional

งานแรกในกระบวนการ **create databar barcode** ใด ๆ คือการสร้างอินสแตนซ์ของ `BarcodeGenerator` ด้วย `EncodeType` ที่ถูกต้อง ตัวสร้างรับสัญลักษณ์บาร์โค้ดและสตริงข้อมูล

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

`EncodeTypes.DatabarStackedOmniDirectional` บอกไลบรารีให้สร้าง **create databar barcode** ที่สามารถสแกนจากทุกทิศทาง

## ขั้นตอนที่ 3: ตั้งค่า X‑dimension (ความกว้างโมดูล)

X‑dimension ควบคุมความกว้างบาร์ที่เล็กที่สุดเป็นพิกเซล การตั้งค่าต่ำทำให้บาร์โค้ดกระชับพร้อมคงความอ่านได้

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## ขั้นตอนที่ 4: **How to adjust aspect ratio** – ค่าแรก (15)

บาร์โค้ด DataBar มีคุณสมบัติ `AspectRatio` ที่ส่งผลต่อความสัมพันธ์ระหว่างความสูงและความกว้าง อัตราส่วนที่สูงกว่าจะทำให้บาร์โค้ดสูงขึ้น ซึ่งอาจเพิ่มความน่าเชื่อถือในการสแกนบนเครื่องพิมพ์บางรุ่น

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## ขั้นตอนที่ 5: **How to save barcode** – ภาพแรก (aspect ratio 15)

ตอนนี้เราจะ **how to save barcode** ลงไฟล์จริง ๆ เมธอด `Save` รับพาธไฟล์และรูปแบบภาพ ในตัวอย่างนี้เราบันทึกเป็นไฟล์ PNG

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Tip:** โฟลเดอร์ของไฟล์ executable เป็นตำแหน่งเขียนเริ่มต้น ใช้พาธแบบเต็มหากต้องการโฟลเดอร์เฉพาะ

## ขั้นตอนที่ 6: **How to adjust aspect ratio** – ค่าอื่น (30)

เพื่อแสดงความยืดหยุ่น ให้เปลี่ยนอัตราส่วนภาพและบันทึกภาพที่สอง ซึ่งแสดงให้เห็นว่าข้อมูลที่เข้ารหัสเดียวกันสามารถแสดงด้วยสัดส่วนภาพที่ต่างกัน

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

การรันโปรแกรมจะสร้างไฟล์ PNG สองไฟล์:

- `DatabarAspectRatio15.png` – บาร์โค้ดที่มีความสูงปานกลาง  
- `DatabarAspectRatio30.png` – บาร์โค้ดที่มีความสูงมากขึ้นสำหรับสภาพแวดล้อมการสแกนที่ท้าทาย  

ไฟล์ทั้งสองพร้อมที่จะโหลดเข้าสู่คอนโทรล UI, พิมพ์บนฉลาก, หรือส่งผ่าน API

### ผลลัพธ์ที่คาดหวัง

เมื่อคุณเปิดภาพที่สร้างขึ้น คุณควรเห็นบาร์โค้ด DataBar Stacked Omnidirectional ที่เข้ารหัสค่า GTIN‑14 `12345678901231` ความแตกต่างด้านภาพระหว่างไฟล์สองไฟล์เป็นเพียงความสูงเท่านั้น ซึ่งยืนยันว่า **how to adjust aspect ratio** ทำงานตามที่คาด

## ขั้นตอนที่ 7: โค้ดต้นฉบับเต็มสำหรับอ้างอิง

ด้านล่างเป็นโปรแกรมที่สมบูรณ์และสามารถรันได้ คัดลอกไปยัง `Program.cs`, คอมไพล์และรัน

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## คำถามทั่วไปและการจัดการกรณีขอบ

### ถ้าโฟลเดอร์เป้าหมายไม่มีอยู่?

`Save` จะโยน `DirectoryNotFoundException` สร้างโฟลเดอร์ก่อน:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### วิธีเปลี่ยนรูปแบบภาพ?

แทนที่ `BarCodeImageFormat.Png` ด้วย `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` หรือ `BarCodeImageFormat.Tiff` ตามความต้องการของระบบต่อไป

### สามารถสร้างบาร์โค้ดหลายรายการในลูปได้หรือไม่?

ได้ คุณสามารถสร้าง `BarcodeGenerator` ใหม่สำหรับแต่ละสตริงข้อมูล หรือใช้อินสแตนซ์เดียวกันโดยอัปเดตคุณสมบัติ `CodeText` :

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

Aspose.BarCode รองรับหลายแพลตฟอร์ม โค้ดเดียวกันทำงานบน Linux และ macOS ตราบใดที่มี .NET runtime
