# วิธีสร้างบาร์โค้ด RM4SCC และสร้างบาร์โค้ด Planet ด้วย C#

หากคุณต้องการ **สร้างบาร์โค้ด RM4SCC** สำหรับการใช้งานไปรษณีย์ คำแนะนำนี้จะแสดงขั้นตอนที่แม่นยำให้คุณได้เห็น นอกจากนี้คุณยังจะได้เรียนรู้วิธี **สร้างบาร์โค้ด Planet** ด้วยความสูงอัตโนมัติและความสูงคงที่ ทำให้โค้ดเดียวกันใช้งานได้กับสัญลักษณ์ไปรษณีย์ใด ๆ

บทเรียนนี้ครอบคลุมทุกอย่างที่จำเป็นสำหรับการสร้างภาพ PNG ที่เป็นไปตามมาตรฐานไปรษณีย์ ไม่ต้องใช้เครื่องมือภายนอกนอกจากไลบรารี Aspose.BarCode for .NET เพียงอย่างเดียว เมื่อเสร็จสิ้นคุณจะสามารถสร้างบาร์โค้ดโดยโปรแกรมและควบคุมขนาดได้อย่างแม่นยำ

## ข้อกำหนดเบื้องต้น

ก่อนเริ่มทำงาน ตรวจสอบให้แน่ใจว่าคุณมี:

* .NET 6.0 หรือใหม่กว่า
* Visual Studio 2022 (หรือ IDE สำหรับ C# ใดก็ได้)
* แพคเกจ NuGet Aspose.BarCode for .NET  
  `Install-Package Aspose.BarCode`
* สิทธิ์การเขียนในโฟลเดอร์ปลายทาง

สิ่งเหล่านี้จะทำให้คุณสามารถคอมไพล์และรันโค้ดตัวอย่างได้โดยไม่ต้องตั้งค่าเพิ่มเติม

## ขั้นตอนที่ 1: เริ่มต้นตัวสร้างบาร์โค้ดสำหรับ RM4SCC

การดำเนินการแรกจะสร้างอินสแตนซ์ `BarcodeGenerator` ที่กำหนดให้ใช้สัญลักษณ์ RM4SCC วัตถุนี้จะเก็บการตั้งค่าทั้งหมดสำหรับภาพบาร์โค้ด

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**ทำไมจึงสำคัญ** – `EncodeTypes.RM4SCC` บอกให้ Aspose ใช้รูปแบบ RM4SCC ของไปรษณีย์ ส่วนสตริงข้อมูล `"123456"` แทนรหัสไปรษณีย์ที่คุณต้องการเข้ารหัส

## ขั้นตอนที่ 2: ตั้งค่าความกว้างโมดูล (X‑dimension)

ความกว้างโมดูลกำหนดขนาดของบาร์แคบ ค่าโดยทั่วไปสำหรับบาร์โค้ดไปรษณีย์คือ 4 พิกเซล

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**คำอธิบาย** – X‑dimension มีผลต่อความอ่านง่ายของบาร์โค้ดทั้งหมด การเลือก 4 px จะสอดคล้องกับเครื่องสแกนไปรษณีย์ส่วนใหญ่

## ขั้นตอนที่ 3: บันทึกด้วยความสูงบาร์อัตโนมัติ

เมื่อคุณไม่ระบุค่าความสูง Aspose จะคำนวณความสูงที่เหมาะสมโดยอัตโนมัติตามกฎของสัญลักษณ์

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**ผลลัพธ์** – PNG ที่สร้าง (`PostalRM4SCCBarHeightNone.png`) มีบาร์โค้ด RM4SCC ขนาดที่ถูกต้องพร้อมพิมพ์

## ขั้นตอนที่ 4: สร้างบาร์โค้ด Planet ด้วยความสูงอัตโนมัติ

รูปแบบเดียวกันใช้ได้กับสัญลักษณ์ Planet เริ่มต้นด้วยการสร้างตัวสร้างโดยใช้ `EncodeTypes.Planet`

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**ทำไมต้องใช้โค้ดเดียวกัน** – ทั้ง RM4SCC และ Planet ใช้โครงสร้างพารามิเตอร์เดียวกัน คุณจึงสามารถสลับสัญลักษณ์ได้โดยเปลี่ยนค่า `EncodeTypes` เพียงอย่างเดียว

## ขั้นตอนที่ 5: กำหนดความสูงบาร์คงที่สำหรับ RM4SCC

บางบริการไปรษณีย์ต้องการความสูงบาร์ที่เฉพาะเจาะจง (เช่น 100 px) คุณสามารถตั้งค่าได้โดยตรงก่อนบันทึก

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**เคล็ดลับ** – การตั้งค่า `BarHeight.Pixels` จะทับการคำนวณอัตโนมัติ ให้คุณควบคุมขนาดภาพได้เต็มที่

## ขั้นตอนที่ 6: กำหนดความสูงบาร์คงที่สำหรับ Planet

ใช้เทคนิคเดียวกันกับบาร์โค้ด Planet

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**ผลลัพธ์** – ทั้งไฟล์ `PostalRM4SCCBarHeight100Pixels.png` และ `PostalPlanetBarHeight100Pixels.png` มีบาร์โค้ดที่ความสูง 100 px สม่ำเสมอ ตรงตามข้อกำหนดไปรษณีย์ที่เข้มงวด

## โค้ดต้นฉบับทั้งหมด

ด้านล่างเป็นโปรแกรมเต็มรูปแบบที่สามารถรันได้ ซึ่งรวมตัวอย่างสี่กรณีไว้ในไฟล์เดียว คัดลอกไปยังโปรเจกต์คอนโซลใหม่และปรับเส้นทางออกตามต้องการ

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**ผลลัพธ์ที่คาดหวัง** – หลังจากรันโปรแกรม โฟลเดอร์ที่ระบุจะมีไฟล์ PNG สี่ไฟล์:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC ความสูงอัตโนมัติ
* `PostalPlanetBarHeightNone.png` – Planet ความสูงอัตโนมัติ
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC ความสูง 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet ความสูง 100 px

เปิดไฟล์ใดไฟล์หนึ่งเพื่อยืนยันว่าบาร์คมชัด ความกว้างโมดูลเป็น 4 px และความสูงตรงกับการตั้งค่าที่เลือก

## คำถามทั่วไปและกรณีขอบ

| Question | Answer |
|----------|--------|
| **Can I use other image formats?** | Yes. Replace `BarCodeImageFormat.Png` with `Jpeg`, `Bmp`, or `Gif` as needed. |
| **What if the data string is longer?** | The generator automatically adjusts the number of bars. Ensure the data complies with the symbology’s length limits (RM4SCC ≤ 6 digits, Planet ≤ 6 digits). |
| **How do I change bar color?** | Set `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` before calling `Save`. |
| **Is DPI important for printing?** | You can set `rm4sccAuto.Parameters.ImageResolution.DpiX` and `DpiY` to match your printer’s resolution. |
