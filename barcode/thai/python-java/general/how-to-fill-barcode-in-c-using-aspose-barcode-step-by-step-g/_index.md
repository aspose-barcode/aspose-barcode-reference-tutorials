# วิธีเติมบาร์โค้ดใน C# ด้วย Aspose.BarCode

หากคุณต้องการ **วิธีเติมบาร์โค้ด** ในแอปพลิเคชัน .NET นี้ การสอนนี้จะแสดงกระบวนการทั้งหมด คุณจะสร้างบาร์โค้ด Planet สำหรับไปรษณีย์ที่มีบาร์เต็ม (solid) แล้วสร้างเวอร์ชันบาร์ว่างของบาร์โค้ดเดียวกัน ทั้งหมดนี้ด้วยการเปลี่ยนแค่บรรทัดเดียวของโค้ด

คู่มือครอบคลุมทุกอย่างที่คุณต้องรู้: การตั้งค่าโปรเจกต์, การปรับ X‑dimension, การสลับระหว่างบาร์เต็มและบาร์ว่าง, และวิธีตรวจสอบไฟล์ PNG ที่สร้างขึ้น ไม่จำเป็นต้องอ้างอิงเอกสารภายนอก—เพียงคัดลอกโค้ด, รันมัน, แล้วคุณจะเห็นผลลัพธ์

## ข้อกำหนดเบื้องต้น

ก่อนเริ่ม, โปรดตรวจสอบว่าคุณมี:

* .NET 6.0 SDK หรือรุ่นที่ใหม่กว่า ติดตั้งแล้ว  
* สภาพแวดล้อมการพัฒนา เช่น Visual Studio 2022 หรือ VS Code  
* แพคเกจ NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

รายการเหล่านี้เป็นพื้นฐานขั้นต่ำสำหรับส่วน **barcode generator c#** ของบทเรียนนี้

## วิธีเติมบาร์โค้ด – ตั้งค่าโปรเจกต์

1. สร้างโปรเจกต์คอนโซลใหม่:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. เพิ่มแพคเกจ Aspose.BarCode:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. เปิดไฟล์ `Program.cs` ที่สร้างขึ้นและแทนที่เนื้อหาด้วยตัวอย่างเต็มที่แสดงต่อไปในบทความนี้

โปรเจกต์ตอนนี้มีทุกอย่างที่จำเป็นเพื่อ **generate postal barcode** รูปภาพแล้ว

## สร้างบาร์โค้ดไปรษณีย์ด้วยบาร์เต็ม

ขั้นตอนแรกคือการสร้างบาร์โค้ด Planet ที่ใช้บาร์เต็ม (solid) Planet เป็นสัญลักษณ์ที่หลายบริการไปรษณีย์ใช้สำหรับการจัดเรียง

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**ทำไมบรรทัดเหล่านี้ถึงสำคัญ**

* `EncodeTypes.Planet` บอกให้ตัวสร้างทราบว่าจะใช้สัญลักษณ์ใด; Planet เป็นมาตรฐานสำหรับบาร์โค้ดไปรษณีย์  
* `XDimension.Pixels = 4` เพิ่มความกว้างของโมดูล ทำให้บาร์โค้ดสแกนง่ายขึ้นและมองเห็นชัดเจนเมื่อพิมพ์  
* `Save` บันทึกรูปภาพลงดิสก์ในรูปแบบ PNG ซึ่งเป็นรูปแบบ loss‑less ที่เหมาะกับการประมวลผลต่อไป  

การรันบล็อกนี้จะสร้าง **PostalPlanetFilledBars.png**, ภาพที่มีบาร์เต็มสีดำตามข้อกำหนดของไปรษณีย์

## สร้างบาร์โค้ดว่างโดยใช้สัญลักษณ์ Planet

บางระบบไปรษณีย์ต้องการให้บาร์เป็นแบบว่าง (unfilled) ขณะที่ช่องว่างคงเป็นสีทึบ การสลับไปยังโหมดนั้นต้องเปลี่ยนคุณสมบัติเพียงหนึ่งค่า

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**ทำไมวิธีนี้ถึงได้ผล**

การตั้งค่า `FilledBars = false` บอกให้ตัวเรนเดอร์กลับสไตล์ภาพ: บาร์จะเป็นโปร่งใส (ว่าง) และพื้นหลังจะเป็นสีทึบ นี่คือการทำตรงข้ามกับพฤติกรรมเริ่มต้นที่แสดงไว้ก่อนหน้า ทำให้คุณ **create empty barcode** ได้โดยไม่ต้องเปลี่ยนข้อมูลที่เข้ารหัส

## ตัวอย่างเต็มที่สามารถรันได้

ด้านล่างเป็นโปรแกรมทั้งหมดที่รวมสองส่วนเข้าด้วยกัน คัดลอกลงใน `Program.cs`, แทนที่ `YOUR_DIRECTORY/` ด้วยเส้นทางโฟลเดอร์จริง, แล้วรัน `dotnet run`

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### ผลลัพธ์ที่คาดหวัง

หลังจากรันคุณจะพบไฟล์ PNG สองไฟล์ในโฟลเดอร์ที่ระบุ:

| ชื่อไฟล์                     | คำอธิบายภาพ |
|-------------------------------|--------------------|
| `PostalPlanetFilledBars.png`  | บาร์เป็นสีดำทึบบนพื้นหลังสีขาว |
| `PostalPlanetEmptyBars.png`   | บาร์เป็นแบบโปร่งใส (สีขาว) บนพื้นหลังสีดำ |

ทั้งสองภาพเข้ารหัสสตริงตัวเลขเดียวกัน `"123456"` และใช้ X‑dimension เดียวกัน ทำให้สามารถสลับใช้กันได้จากมุมมองการตรวจสอบข้อมูล

## คำถามทั่วไปและกรณีขอบ

**ถ้าโฟลเดอร์ปลายทางไม่มีอยู่?**  
เมธอด `Save` จะโยน `DirectoryNotFoundException` ให้สร้างโฟลเดอร์ล่วงหน้าหรือห่อการเรียกในบล็อก `try / catch` ที่สร้างโฟลเดอร์หากจำเป็น:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**ฉันสามารถใช้รูปแบบภาพอื่นได้หรือไม่?**  
ได้. แทนที่ `BarCodeImageFormat.Png` ด้วย `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` หรือรูปแบบใด ๆ ที่ Aspose.BarCode รองรับ

**X‑dimension มีผลต่อการอ่านของสแกนเนอร์หรือไม่?**  
การเพิ่มความกว้างเป็นพิกเซลทำให้บาร์กว้างขึ้น ซึ่งอาจช่วยให้สแกนเนอร์ความละเอียดต่ำอ่านได้ดีขึ้น อย่างไรก็ตาม ค่าใหญ่เกินไปอาจทำให้เกินพื้นที่พิมพ์ ค่าที่นิยมอยู่ระหว่าง 2‑6 พิกเซลสำหรับการพิมพ์ที่ 300 dpi

**สัญลักษณ์ `EncodeTypes.Planet` เป็นตัวเลือกไปรษณีย์เดียวหรือไม่?**  
ไม่. Aspose.BarCode ยังรองรับ `EncodeTypes.Postnet` และ `EncodeTypes.USPSIntelligentMail` คุณสมบัติ `FilledBars` ทำงานกับประเภทเหล่านี้เช่นกัน

## สรุป

คุณได้เรียนรู้ **วิธีเติมบาร์โค้ด** ใน C# ด้วยไลบรารี Aspose.BarCode, วิธี **generate postal barcode** แบบต่าง ๆ, และวิธี **create empty barcode** ด้วยสัญลักษณ์ Planet การปรับ X‑dimension จะควบคุมความคมชัดของภาพ, และการสลับคุณสมบัติเดียวจะเปลี่ยนระหว่างบาร์เต็มและบาร์ว่างโดยไม่ต้องแก้ไขข้อมูลที่เข้ารหัส

จากจุดนี้คุณสามารถสำรวจฟีเจอร์เพิ่มเติม เช่น การเพิ่มข้อความที่อ่านได้โดยมนุษย์, การเปลี่ยนสี, หรือการฝังบาร์โค้ดลงในเอกสาร PDF ทั้งหมดนี้ต่อยอดจากพื้นฐาน **barcode generator c#** ที่แสดงในคู่มือนี้
