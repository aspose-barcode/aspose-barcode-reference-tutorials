# สร้างไฟล์ PNG ของบาร์โค้ดใน Python – คู่มือฉบับเต็ม

เคยต้องการ **create barcode PNG** แต่ไม่แน่ใจว่าจะใช้ไลบรารีหรือการตั้งค่าแบบไหนหรือไม่? คุณไม่ได้เป็นคนเดียว ในระบบสินค้าคงคลังหรือระบบชำระเงินหลายระบบ ขั้นตอนแรกคือการแปลงข้อมูลดิบให้เป็นภาพ PNG คมชัดที่เครื่องสแกนชื่นชอบ  

ในบทแนะนำนี้ เราจะอธิบาย **how to generate databar**, วิธี **adjust barcode height**, และแม้กระทั่งเคล็ดลับการ **change barcode** พารามิเตอร์แบบเรียลไทม์—ทั้งหมดนี้โดยใช้ **barcode with sample data** ที่คุณสามารถคัดลอก‑วางตรงลงในโปรเจคของคุณ  

## สิ่งที่คุณจะได้เรียนรู้

- ตั้งค่าไลบรารี Aspose.BarCode (หรือไลบรารีที่คล้ายกัน) ใน Python.  
- **Create barcode PNG** files with different heights in just a few lines of code.  
- คุณสมบัติ **How to change barcode** เช่น ขนาดโมดูลและความสูงของบาร์  
- ใช้ค่า GTIN‑14 ที่สมจริงเป็น **barcode with sample data**.  
- เคล็ดลับการแก้ไขปัญหาที่พบบ่อย เช่น ภาพเบลอหรือการเข้ารหัสที่ไม่ถูกต้อง  

ไม่จำเป็นต้องมีประสบการณ์ก่อนหน้าในการสร้างบาร์โค้ด—เพียงแค่ Python interpreter เบื้องต้นและความสามารถในการติดตั้งแพคเกจ pip  

## ข้อกำหนดเบื้องต้น

- ติดตั้ง Python 3.8+ บนเครื่องของคุณ  
- เข้าถึงอินเทอร์เน็ตเพื่อทำการติดตั้งแพคเกจ `aspose-barcode` (หรือไลบรารีที่เข้ากันได้)  
- โฟลเดอร์ที่สามารถเขียนไฟล์ PNG ได้ (แทนที่ `YOUR_DIRECTORY` ในสคริปต์)  

หากคุณมีทั้งหมดนี้แล้ว เยี่ยม—มาเริ่มกันเลย  

## สร้างไฟล์ PNG ของบาร์โค้ด – การตั้งค่า Generator

สิ่งแรกที่ต้องทำคือ เราต้องการอ็อบเจ็กต์ generator ที่รู้ว่าเรากำลังทำงานกับบาร์โค้ด **DataBar Omnidirectional** โค้ดด้านล่างจะนำเข้าคลาสที่จำเป็น, สร้าง generator ด้วย **barcode with sample data**, และตั้งค่าขนาดโมดูลที่เหมาะสม  

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Why this matters:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` บอกให้เอนจินสร้าง **DataBar** ที่สามารถอ่านได้จากทุกทิศทาง เหมาะอย่างยิ่งสำหรับชั้นวางสินค้า การตั้งค่า `x_dimension` ทำให้บาร์คมชัด ส่วน `bar_height` ควบคุมขนาดภาพของโค้ด  

## วิธีการสร้าง Databar ด้วยข้อมูลตัวอย่าง

เมื่อ generator พร้อมแล้ว เราจะ **create barcode PNG** ไฟล์แรกใช้ความสูง 30 พิกเซล ซึ่งมักเพียงพอสำหรับการแสดงตัวอย่างบนหน้าจอ  

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

การรันสคริปต์จนถึงจุดนี้จะสร้างไฟล์ PNG ที่ดูเหมือนบาร์โค้ดขนาดกะทัดรัดและคอนทราสต์สูง เปิดไฟล์ในโปรแกรมดูรูปใดก็ได้เพื่อยืนยันว่าบาร์คมชัดและข้อมูล GTIN‑14 ถูกเข้ารหัส  

## ปรับความสูงของบาร์โค้ด (How to Change Barcode)

บางครั้งคุณอาจต้องการบาร์โค้ดที่สูงขึ้นสำหรับป้ายขนาดใหญ่หรือการพิมพ์ความละเอียดสูง นี่คือจุดที่ **adjust barcode height** มีบทบาท การเปลี่ยนความสูงทำได้ง่ายโดยการอัปเดตคุณสมบัติ `BarHeight` แล้วบันทึกอีกครั้ง  

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**How it works:** generator ใช้ข้อมูลและขนาดโมดูลเดิม; เพียงเปลี่ยนมิติแนวตั้งเท่านั้น ซึ่งช่วยหลีกเลี่ยงการสร้างอ็อบเจ็กต์ใหม่ทั้งหมดและแสดงให้เห็น **how to change barcode** การตั้งค่าแบบไดนามิก  

## สคริปต์เต็ม – โซลูชันครบวงจร

ด้านล่างเป็นสคริปต์ที่สมบูรณ์และสามารถรันได้ซึ่งรวมทุกขั้นตอนไว้ด้วยกัน คัดลอก วาง และรัน—ควรทำงานได้ทันทีหลังจากคุณติดตั้งแพคเกจ  

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### ผลลัพธ์ที่คาดหวัง

การรันสคริปต์จะสร้างไฟล์สองไฟล์:

- `DatabarOmni30.png` – บาร์โค้ด DataBar Omnidirectional สูง 30 px.  
- `DatabarOmni60.png` – เวอร์ชันสูง 60 px ของบาร์โค้ดเดียวกัน.  

ทั้งสองภาพเป็นรูปแบบ PNG ไม่สูญเสียข้อมูล และพร้อมสำหรับการฝังใน PDF, หน้า HTML หรือการพิมพ์โดยตรงบนป้าย  

## ข้อผิดพลาดทั่วไป & เคล็ดลับระดับมืออาชีพ

- **Pixel vs. DPI:** ไฟล์ PNG มีหน่วยเป็นพิกเซล หากต้องการขนาดการพิมพ์ที่เฉพาะเจาะจง ให้คำนวณ `BarHeight` ตาม DPI (เช่น 300 dpi → 30 px ≈ 0.1 in).  
- **Incorrect encoding:** ตรวจสอบให้แน่ใจว่าสตริงข้อมูลเป็นไปตามรูปแบบ GS1 Application Identifier (`(01)` สำหรับ GTIN‑14) การขาดวงเล็บอาจทำให้ไลบรารีกลับไปใช้บาร์โค้ดตัวเลขธรรมดา  
- **File paths:** ใช้ raw strings (`r"..."`) หรือ backslash คู่บน Windows เพื่อหลีกเลี่ยงปัญหา escape‑character  
- **Performance:** หากคุณสร้างบาร์โค้ดหลายพันรายการ ให้สร้าง generator ครั้งเดียวและแก้ไขเฉพาะ `BarHeight` หรือสตริงข้อมูลระหว่างการบันทึก เพื่อลดการใช้หน่วยความจำ
