# วิธีสร้างภาพบาร์โค้ดใน C# ด้วย DataBar Stacked Omni‑Directional

หากคุณต้องการ **วิธีสร้างภาพบาร์โค้ด** ในแอปพลิเคชัน .NET นี้ บทแนะนำนี้จะแสดงขั้นตอนที่แน่นอน คุณจะได้เห็นวิธีสร้างบาร์โค้ด DataBar Stacked Omni‑Directional ปรับอัตราส่วนภาพ และส่งออกผลลัพธ์เป็นไฟล์ PNG

การสร้างบาร์โค้ดเป็นความต้องการทั่วไปสำหรับระบบสินค้าคงคลัง, จุดขาย (POS) ของร้านค้า, และการติดตามโลจิสติกส์ ในส่วนต่อไปนี้ เราจะครอบคลุมทุกอย่างที่คุณต้องการ — ตั้งแต่แพคเกจ NuGet ที่จำเป็นจนถึงการตรวจสอบภาพขั้นสุดท้าย — เพื่อให้คุณสามารถรวมการสร้างบาร์โค้ดเข้าไปในโปรเจกต์ C# ใดก็ได้วันนี้

## ข้อกำหนดเบื้องต้น

* .NET 6.0 หรือใหม่กว่า (โค้ดทำงานได้กับ .NET Core และ .NET Framework)
* Visual Studio 2022 หรือ IDE สำหรับ C# ที่คุณชอบ
* แพคเกจ NuGet **Aspose.BarCode for .NET** (ติดตั้งด้วย `dotnet add package Aspose.BarCode`)
* สิทธิ์การเขียนในโฟลเดอร์ที่ไฟล์ PNG จะถูกบันทึก

ข้อกำหนดเหล่านี้รับประกันว่าโค้ดตัวอย่างจะทำงานโดยไม่มีการตั้งค่าเพิ่มเติม

## ขั้นตอนที่ 1: ตั้งค่าโฟลเดอร์ผลลัพธ์

สิ่งแรกที่คุณต้องการคือไดเรกทอรีที่ไฟล์ PNG ที่สร้างขึ้นจะถูกเขียนลงไป การใช้พาธแบบเต็มหรือแบบสัมพันธ์ก็ได้ แต่ต้องแน่ใจว่าโฟลเดอร์มีอยู่ก่อนที่คุณจะเรียก `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

การสร้างโฟลเดอร์โดยโปรแกรมจะป้องกัน *FileNotFoundException* เมื่อเมธอด `Save` พยายามเขียนภาพ

## ขั้นตอนที่ 2: สร้างตัวสร้างบาร์โค้ด DataBar Stacked Omni‑Directional

คลาส **BarcodeGenerator** เป็นจุดเริ่มต้นสำหรับทุกประเภทของบาร์โค้ด ที่นี่เรากำหนด `EncodeTypes.DatabarStackedOmniDirectional` และสตริงข้อมูลที่ต้องการเข้ารหัส

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*ทำไมเรื่องนี้สำคัญ*: enum `EncodeTypes` บอกไลบรารีว่าจะเรนเดอร์สัญลักษณ์ใด การใช้รูปแบบ Omni‑Directional ทำให้บาร์โค้ดสามารถสแกนได้จากทุกทิศทาง — เป็นข้อกำหนดสำหรับสแกนเนอร์ในคลังสินค้าจำนวนมาก

## ขั้นตอนที่ 3: ตั้งค่าพารามิเตอร์บาร์โค้ดทั่วไป

บาร์โค้ดที่อ่านได้ต้องการ X‑dimension ที่เหมาะสม (ความกว้างของบาร์ที่เล็กที่สุด) การตั้งค่า `Pixels` เป็น 2 จะให้สมดุลที่ดีระหว่างขนาดและความคมชัดสำหรับความละเอียดหน้าจอส่วนใหญ่

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

คุณสามารถปรับค่า `Pixels` ภายหลังได้หากต้องการภาพที่ใหญ่หรือเล็กกว่า; ไลบรารีจะปรับสเกลส่วนที่เหลือของบาร์โค้ดโดยอัตโนมัติ

## ขั้นตอนที่ 4: สร้างภาพแรกด้วยอัตราส่วน 15

**อัตราส่วน** ควบคุมความสัมพันธ์ระหว่างความสูงและความกว้างของบาร์โค้ด DataBar อัตราส่วน 15 เป็นค่าเริ่มต้นทั่วไปสำหรับป้ายสินค้าในร้านค้า

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

หลังจากเรียกเมธอดนี้ คุณจะพบไฟล์ `DatabarAspectRatio15.png` ในโฟลเดอร์ผลลัพธ์ ภาพเป็น PNG แบบไม่มีการสูญเสียคุณภาพ เหมาะสำหรับการประมวลผลต่อหรือการพิมพ์

## ขั้นตอนที่ 5: เปลี่ยนอัตราส่วนเป็น 30 และส่งออกภาพที่สอง

บางครั้งต้องการบาร์โค้ดที่สูงกว่า — เช่น เมื่อความสูงของป้ายจำกัด การเปลี่ยนอัตราส่วนเป็น 30 จะให้ภาพที่กระชับมากขึ้นในขณะที่ยังคงความสมบูรณ์ของข้อมูล

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

ตอนนี้คุณมีไฟล์ PNG สองไฟล์ที่แสดงให้เห็นว่าข้อมูลเดียวกันดูอย่างไรเมื่อเปลี่ยนอัตราส่วนต่างกัน การเปรียบเทียบแบบข้างเคียงนี้ช่วยให้คุณตัดสินใจว่าแบบไหนเหมาะกับการจัดวางป้ายของคุณที่สุด

## ตัวอย่างเต็มที่สามารถรันได้

ด้านล่างเป็นโปรแกรมเต็มที่คุณสามารถคัดลอก วาง และรันได้ รวมถึงคำสั่ง `using` ทั้งหมด การจัดการข้อผิดพลาด และคอมเมนต์ที่อธิบายแต่ละส่วนของกระบวนการ

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**ผลลัพธ์ที่คาดหวัง** (คอนโซล):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

เปิดไฟล์ PNG สองไฟล์ในโปรแกรมดูภาพใดก็ได้ คุณจะเห็น GTIN เดียวกันที่เข้ารหัสไว้ แต่ภาพที่สองจะสูงกว่าเนื่องจากอัตราส่วนที่สูงกว่า

## เคล็ดลับมืออาชีพและข้อผิดพลาดทั่วไป

| Situation | Recommendation |
|-----------|----------------|
| **Low‑resolution displays** | Increase `XDimension.Pixels` to 3 or 4 to keep the bars crisp. |
| **หน้าจอความละเอียดต่ำ** | เพิ่มค่า `XDimension.Pixels` เป็น 3 หรือ 4 เพื่อให้บาร์คมชัด. |
| **Printing on thermal paper** | Use `BarCodeImageFormat.Tiff` for higher fidelity and set `Resolution.DpiX/DpiY` to 300. |
| **การพิมพ์บนกระดาษความร้อน** | ใช้ `BarCodeImageFormat.Tiff` เพื่อความละเอียดสูงขึ้นและตั้งค่า `Resolution.DpiX/DpiY` เป็น 300. |
| **Dynamic data** | Re‑use the same `BarcodeGenerator` instance and only update `generator.CodeText` before each `Save`. This avoids unnecessary object allocation. |
| **ข้อมูลแบบไดนามิก** | ใช้ instance ของ `BarcodeGenerator` เดียวกันซ้ำและอัปเดต `generator.CodeText` ก่อนแต่ละการ `Save` เท่านั้น ซึ่งจะหลีกเลี่ยงการสร้างอ็อบเจ็กต์ที่ไม่จำเป็น. |
| **Invalid GTIN** | The library throws `ArgumentException` if the data does not conform to GS1 standards. Validate your data before passing it to the generator. |
| **GTIN ไม่ถูกต้อง** | ไลบรารีจะโยน `ArgumentException` หากข้อมูลไม่สอดคล้องกับมาตรฐาน GS1 ตรวจสอบข้อมูลของคุณก่อนส่งให้ตัวสร้าง. |

## สรุป

ตอนนี้คุณรู้แล้ว **วิธีสร้างภาพบาร์โค้ด** ใน C# ด้วย Aspose.BarCode วิธีควบคุมอัตราส่วนของ DataBar Stacked Omni‑Directional และวิธีส่งออกผลลัพธ์เป็นไฟล์ PNG ตัวอย่างครบวงจรนี้ครอบคลุมการติดตั้ง การกำหนดค่า และการจัดการข้อผิดพลาด ให้คุณมีพื้นฐานที่มั่นคงสำหรับฟีเจอร์ที่เกี่ยวกับบาร์โค้ดใด ๆ

ต่อไปคุณอาจสำรวจ:

* **การสร้างบาร์โค้ดด้วย C#** สำหรับสัญลักษณ์อื่น ๆ เช่น QR, Code 128, หรือ PDF417.
* **การฝังบาร์โค้ดในเอกสาร PDF** ด้วย Aspose.PDF.
* **การประมวลผลเป็นชุด** ของหลายสตริงข้อมูลและบันทึกเป็น PDF หน้าหลายหน้าไฟล์เดียว.

คุณสามารถทดลองใช้ `EncodeTypes` ต่าง ๆ รูปแบบภาพ และการตั้งค่าความละเอียดเพื่อให้ตรงกับความต้องการของโครงการของคุณได้เลย ขอให้สนุกกับการเขียนโค้ด!
