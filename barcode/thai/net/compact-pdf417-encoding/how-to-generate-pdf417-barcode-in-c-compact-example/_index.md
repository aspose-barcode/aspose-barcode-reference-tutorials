# วิธีสร้างบาร์โค้ด PDF417 ใน C# – ตัวอย่างแบบกะทัดรัด

หากคุณต้องการ **สร้างบาร์โค้ด PDF417** ในแอปพลิเคชัน C# คู่มือนี้จะแสดงวิธีแก้ไขที่สมบูรณ์และพร้อมใช้งาน เราจะสร้างบาร์โค้ด PDF417 แบบกะทัดรัด ปรับความกว้างของโมดูล กำหนดจำนวนคอลัมน์ และบันทึกผลลัพธ์เป็นภาพ PNG — ทั้งหมดนี้ด้วยไลบรารี Aspose.BarCode .NET

การสร้างบาร์โค้ด PDF417 เป็นเรื่องทั่วไปเมื่อคุณต้องการเข้ารหัสข้อมูลจำนวนมาก (เช่น URL, การ์ดติดต่อ, หรือรหัสสินค้าคงคลัง) ในรูปแบบสองมิติที่ใช้พื้นที่อย่างมีประสิทธิภาพ เมื่อจบบทเรียนนี้คุณจะมีอ็อบเจ็กต์ `BarcodeGenerator` ที่ทำงานได้ซึ่งสร้างบาร์โค้ดแบบกะทัดรัดและอ่านง่าย พร้อมสำหรับการพิมพ์หรือแสดงผล

## ข้อกำหนดเบื้องต้น

- .NET 6.0 หรือใหม่กว่า (โค้ดนี้ยังทำงานได้กับ .NET Framework 4.8)
- Visual Studio 2022 (หรือ IDE สำหรับ C# ใดก็ได้)
- แพคเกจ NuGet Aspose.BarCode for .NET (`Install-Package Aspose.BarCode`)
- ความคุ้นเคยพื้นฐานกับไวยากรณ์ C#

ไม่ต้องกำหนดค่าพิเศษเพิ่มเติม; ตัวอย่างนี้ทำงานเป็นแอปคอนโซล

## ขั้นตอนที่ 1: สร้างตัวสร้างบาร์โค้ด PDF417

ขั้นตอนแรกคือการสร้างอ็อบเจ็กต์ `BarcodeGenerator` ด้วยค่า enum `EncodeTypes.Pdf417` และข้อความที่คุณต้องการเข้ารหัส

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**ทำไมจึงสำคัญ:** `EncodeTypes.Pdf417` บอกไลบรารีให้ใช้สัญลักษณ์ PDF417 ส่วนอาร์กิวเมนต์ที่สองกำหนดข้อมูลที่ต้องการเข้ารหัส คุณสามารถเปลี่ยน `"Compact example"` เป็นสตริงใดก็ได้สูงสุด 1 800 ตัวอักษร

## ขั้นตอนที่ 2: ตั้งค่าความกว้างของโมดูล (X‑dimension) เป็นพิกเซล

X‑dimension กำหนดความกว้างของโมดูลบาร์โค้ดหนึ่งหน่วย (สี่เหลี่ยมสีดำหรือสีขาวที่เล็กที่สุด) ค่าพิกเซลที่เล็กลงจะทำให้บาร์โค้ดกระชับขึ้น

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**ทำไมจึงสำคัญ:** ค่า `2` พิกเซลให้ลักษณะกะทัดรัดโดยไม่ลดทอนความน่าเชื่อถือของการสแกนบนสแกนเนอร์สมัยใหม่ส่วนใหญ่ ปรับค่าตามต้องการหากต้องการโมดูลใหญ่ขึ้นสำหรับการพิมพ์ความละเอียดต่ำ

## ขั้นตอนที่ 3: ระบุจำนวนคอลัมน์

PDF417 ให้คุณควบคุมจำนวนคอลัมน์ ซึ่งส่งผลต่ออัตราส่วนของบาร์โค้ด

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**ทำไมจึงสำคัญ:** คอลัมน์น้อยทำให้บาร์โค้ดสูงขึ้น ส่วนคอลัมน์มากทำให้บาร์โค้ดแบนลง คอลัมน์สามคอลัมน์ทำงานได้ดีสำหรับการจัดวางแบบแนวตั้งกะทัดรัด

## ขั้นตอนที่ 4: เปิดโหมดกะทัดรัดโดยการตัดบาร์โค้ด

โหมดกะทัดรัดจะลบแถวเติมที่ไม่จำเป็น ทำให้บาร์โค้ดมีขนาดเล็กลงในขณะที่ยังคงข้อมูลที่เข้ารหัสไว้

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**ทำไมจึงสำคัญ:** การตัดบาร์โค้ดเหมาะเมื่อพื้นที่หน้าจอจำกัด (เช่น แอปมือถือหรือป้ายเล็ก) บาร์โค้ดยังคงอ่านได้เต็มที่เนื่องจากอัลกอริทึมการเข้ารหัสปรับระดับการแก้ไขข้อผิดพลาดโดยอัตโนมัติ

## ขั้นตอนที่ 5: บันทึกบาร์โค้ดเป็นภาพ PNG

สุดท้ายให้เขียนบาร์โค้ดที่สร้างขึ้นลงไฟล์ PNG คงคุณภาพแบบไม่มีการสูญเสีย ซึ่งสำคัญต่อสแกนเนอร์บาร์โค้ด

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

การรันโปรแกรมจะสร้างไฟล์ `CompactPdf417.png` ในไดเรกทอรีทำงานของไฟล์ปฏิบัติการ รูปภาพจะเป็นดังนี้:

![บาร์โค้ด PDF417 แบบกะทัดรัดที่สร้างขึ้น](CompactPdf417.png "บาร์โค้ด PDF417 แบบกะทัดรัดที่สร้างขึ้น")

**ผลลัพธ์ที่คาดหวัง:** บาร์โค้ด PDF417 ความกว้าง 2 พิกเซล มีสามคอลัมน์ ซึ่งเข้ารหัสข้อความ “Compact example”. การสแกนไฟล์ PNG ด้วยสแกนเนอร์บาร์โค้ดมาตรฐานควรคืนค่าข้อความเดิม

## ความแปรผันทั่วไปและกรณีขอบ

| สถานการณ์ | วิธีปรับโค้ด |
|-----------|------------------------|
| **ข้อมูลยาวกว่า ( > 500 ตัวอักษร )** | เพิ่ม `Columns` เป็น 5‑7 เพื่อป้องกันบาร์โค้ดสูงเกินไป |
| **การพิมพ์ความละเอียดสูง** | ตั้งค่า `XDimension.Pixels` เป็น 3 หรือ 4 เพื่อให้โมดูลใหญ่ขึ้น |
| **รูปแบบภาพที่แตกต่าง** | แทนที่ `BarCodeImageFormat.Png` ด้วย `Jpeg` หรือ `Bmp` ตามต้องการ |
| **ฝังบาร์โค้ดใน PDF** | ใช้ `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` แทน PNG |

**เคล็ดลับ:** ควรทดสอบบาร์โค้ดที่สร้างบนฮาร์ดแวร์สแกนเนอร์เป้าหมายเสมอ สแกนเนอร์ราคาถูกบางรุ่นอาจมีปัญหากับ X‑dimension ที่เล็กมาก; หากพบข้อผิดพลาดในการอ่าน ให้เพิ่มค่าพิกเซลหนึ่งขั้น

## ตัวอย่างเต็มที่สามารถรันได้

ด้านล่างเป็นโปรแกรมเต็มที่คุณสามารถคัดลอกและวางลงในโปรเจกต์คอนโซลใหม่ได้ ไม่ต้องมีไฟล์เพิ่มเติม

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

คอมไพล์และรันโปรแกรม (`dotnet run` หากคุณใช้ .NET CLI) หลังจากทำงานเสร็จ ให้เปิดไฟล์ `CompactPdf417.png` เพื่อตรวจสอบผลลัพธ์ภาพ

## สรุป

ตอนนี้คุณรู้ **วิธีสร้างบาร์โค้ด PDF417** ใน C# ด้วยการจัดวางแบบกะทัดรัด การกำหนด X‑dimension และการตั้งค่าคอลัมน์ ตัวอย่างนี้แสดงขั้นตอนสำคัญ: สร้างอ็อบเจ็กต์ `BarcodeGenerator`, ตั้งค่า `XDimension` และ `Columns`, เปิดใช้งาน `Truncate` เพื่อโหมดกะทัดรัด และสุดท้ายบันทึกภาพ

จากนี้คุณสามารถสำรวจคุณลักษณะเพิ่มเติมเช่นระดับการแก้ไขข้อผิดพลาด, สีที่กำหนดเอง, หรือฝังบาร์โค้ดโดยตรงใน PDF ทดลองใช้ `EncodeTypes` ต่าง ๆ หากคุณต้องการสัญลักษณ์อื่น (เช่น QR, Code128) และนำรูปแบบการกำหนดพารามิเตอร์นี้ไปใช้

ขอให้เขียนโค้ดอย่างสนุกสนานและบาร์โค้ดของคุณสแกนได้สำเร็จตั้งแต่ครั้งแรก!
