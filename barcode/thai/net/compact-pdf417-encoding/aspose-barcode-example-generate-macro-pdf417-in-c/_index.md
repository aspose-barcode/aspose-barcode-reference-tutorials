## PDF417 barcode คืออะไร?
PDF417 barcode คือสัญลักษณ์เชิงเส้นแบบซ้อนกันที่สามารถเข้ารหัสข้อมูลได้ประมาณ 1 KB ต่อสัญลักษณ์และรองรับเมตาดาต้า macro แบบเลือกใช้สำหรับไฟล์หลายส่วน มันประกอบด้วยหลายแถวของรูปแบบเชิงเส้นซ้อนกัน ทำให้มีความจุข้อมูลสูงในขณะที่ยังอ่านได้โดยสแกนเนอร์ 2‑D มาตรฐาน รูปแบบนี้ยังรวมระดับการแก้ไขข้อผิดพลาดเพื่อเพิ่มความน่าเชื่อถือ และฟีเจอร์ macro แบบเลือกใช้ช่วยแบ่งไฟล์ขนาดใหญ่เป็นหลายบาร์โค้ดพร้อมเมตาดาต้าที่ช่วยในการประกอบไฟล์กลับมา

## วิธีสร้างบาร์โค้ด PDF417 ใน C#?

`BarcodeGenerator` คือคลาสหลักสำหรับสร้างภาพบาร์โค้ด.  
`EncodeTypes.MacroPdf417` เลือกสัญลักษณ์ Macro PDF417 สำหรับการสร้างบาร์โค้ด.  
`Save` เขียนบาร์โค้ดที่สร้างออกเป็นไฟล์ภาพ.

โหลด `BarcodeGenerator` ด้วยค่า enum `EncodeTypes.MacroPdf417` และข้อความเป้าหมายของคุณ จากนั้นเรียก `Save` – นั่นคือกระบวนการสร้างครบถ้วนในสามบรรทัด ตัวสร้างจัดการ Unicode โดยอัตโนมัติ และคำสั่ง `using` รับประกันว่าทรัพยากรที่ไม่ได้จัดการจะถูกปล่อยหลังจากบันทึกภาพแล้ว.

### ขั้นตอนที่ 1: สร้างอินสแตนซ์ของ barcode generator ใน C#

`BarcodeGenerator` class สร้างและกำหนดค่าภาพบาร์โค้ด.  

สร้างอินสแตนซ์ของ `BarcodeGenerator` ด้วยค่า enum `EncodeTypes.MacroPdf417` และข้อความที่คุณต้องการเข้ารหัส ข้อความสามารถมีอักขระ Unicode ซึ่งไลบรารีจะจัดการโดยอัตโนมัติ.

```csharp
using Aspose.BarCode.Generation;
using System;

using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
{
    // Subsequent steps are performed inside this using block.
```

*ทำไมจึงสำคัญ*: `EncodeTypes.MacroPdf417` บอกให้เอนจินสร้างสัญลักษณ์ Macro PDF417 ซึ่งรองรับข้อมูลแบบแบ่งส่วนและเมตาดาต้าระดับไฟล์เพิ่มเติม คำสั่ง `using` รับประกันว่าทรัพยากรที่ไม่ได้จัดการจะถูกปล่อยหลังจากบันทึกภาพ.

### ขั้นตอนที่ 2: กำหนดลักษณะพื้นฐานของบาร์โค้ด

`XDimension.Pixels` กำหนดขนาดของแต่ละโมดูลของบาร์โค้ดเป็นพิกเซล.

บาร์โค้ด Macro PDF417 ประกอบด้วยโมดูลสี่เหลี่ยม การควบคุมขนาดโมดูลและจำนวนคอลัมน์มีผลต่อความอ่านง่ายและขนาดไฟล์.

```csharp
    // Pixel size of a single module (X dimension)
    generator.Parameters.Barcode.XDimension.Pixels = 2;

    // Number of columns in the symbol; fewer columns produce a taller barcode
    generator.Parameters.Barcode.Pdf417.Columns = 5;
```

*ทำไมจึงสำคัญ*: `XDimension.Pixels` กำหนดความหนาแน่นของภาพ; ค่า 2 pixels ทำงานได้ดีสำหรับการแสดงบนหน้าจอพร้อมขนาดภาพที่เล็ก ปรับจำนวนคอลัมน์ให้เหมาะกับข้อจำกัดการจัดวางของคุณ — คอลัมน์มากขึ้นทำให้บาร์โค้ดกว้างและสั้นลง.

### ขั้นตอนที่ 3: ตั้งค่าเมตาดาต้าเฉพาะของ Macro PDF417

`MacroPdf417FileID` ระบุไฟล์ที่ส่วนบาร์โค้ดทั้งหมดเป็นส่วนหนึ่งของมัน.

Macro PDF417 ขยายรูปแบบ PDF417 มาตรฐานด้วยฟิลด์ที่ทำให้สามารถสร้างไฟล์ขนาดใหญ่จากหลายส่วนของบาร์โค้ดได้ ฟิลด์แต่ละอันเป็นตัวเลือก แต่การตั้งค่าจะสาธิตความสามารถเต็มของ API.

```csharp
    // Unique identifier for the entire file
    generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;

    // Identifier of the current segment (zero‑based)
    generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;

    // Total number of segments that compose the file
    generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;

    // Logical name of the source file
    generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

    // 16‑bit CCITT checksum for error detection
    generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234;

    // Approximate size of the original file in bytes
    generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400000;

    // Timestamp when the file was generated
    generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);

    // Optional address fields for routing information
    generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

    // Terminator indicates that this is the last segment
    generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;
```

*ทำไมจึงสำคัญ*:  
- `MacroPdf417FileID` เชื่อมโยงส่วนทั้งหมดที่เป็นของไฟล์ตรรกะเดียวกัน.  
- `MacroPdf417SegmentID` และ `MacroPdf417SegmentsCount` ทำให้ตัวถอดรหัสสามารถจัดลำดับส่วนย่อยได้อย่างถูกต้อง.  
- `MacroPdf417Checksum` ให้การตรวจสอบความสมบูรณ์อย่างรวดเร็วโดยไม่ต้องถอดรหัสข้อมูลทั้งหมด.  
- `MacroPdf417FileSize` และ `MacroPdf417TimeStamp` ให้ระบบต่อไปตรวจสอบว่าไฟล์ที่ประกอบกลับมาตรงกับไฟล์ต้นฉบับ.  
- `MacroPdf417Addressee` / `MacroPdf417Sender` มีประโยชน์ในสถานการณ์โลจิสติกส์หรือการแลกเปลี่ยนเอกสาร.  
- การตั้งค่า `MacroPdf417Terminator` เป็น `Set` ทำเครื่องหมายบาร์โค้ดนี้เป็นส่วนสุดท้าย ซึ่งทำให้ขั้นตอนการประกอบไฟล์ง่ายขึ้น.

### ขั้นตอนที่ 4: บันทึกภาพบาร์โค้ดที่สร้าง

`Save` เขียนภาพบาร์โค้ดไปยังเส้นทางไฟล์ที่ระบุ.

สุดท้าย เขียนบาร์โค้ดเป็นไฟล์ PNG คุณสามารถเลือกฟอร์แมตที่รองรับใดก็ได้ (`Png`, `Jpeg`, `Bmp`, `Gif`, `Tiff`).

```csharp
    // Save the barcode image to the specified path
    generator.Save("YOUR_DIRECTORY/ExtPDF417Meta.png", BarCodeImageFormat.Png);
}
```

*ทำไมจึงสำคัญ*: PNG รักษาข้อมูลพิกเซลแบบ lossless ทำให้สแกนเนอร์อ่านรูปแบบโมดูลที่คุณกำหนดได้อย่างแม่นยำ การเปลี่ยนฟอร์แมตอาจส่งผลต่อคุณภาพภาพและขนาดไฟล์.

#### ผลลัพธ์ที่คาดหวัง

การรันโปรแกรมเต็มจะสร้างไฟล์ชื่อ **ExtPDF417Meta.png** การเปิดภาพจะแสดงบาร์โค้ด Macro PDF417 รูปสี่เหลี่ยมผืนผ้าที่เข้ารหัสข้อความ “Åspóse.Barcóde©” และความหนาแน่นของภาพตรงกับค่า X dimension 2‑pixel ที่คุณตั้งค่า การสแกนภาพด้วยเครื่องอ่านที่รองรับ PDF417 จะคืนค่าฟิลด์เมตาดาต้าทั้งหมดที่กำหนดในขั้นตอนที่ 3.

## ตัวอย่างทำงานเต็ม

คัดลอกโค้ดด้านล่างไปยังโปรเจกต์คอนโซลใหม่ (`dotnet new console`) และแทนที่ `YOUR_DIRECTORY` ด้วยเส้นทางแบบ absolute หรือ relative ที่มีอยู่บนเครื่องของคุณ.

```csharp
using Aspose.BarCode.Generation;
using System;

namespace MacroPdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Step 1: Create a barcode generator for Macro PDF417 with the desired text
            using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
            {
                // Step 2: Define the basic barcode appearance
                generator.Parameters.Barcode.XDimension.Pixels = 2;          // pixel size of a single module
                generator.Parameters.Barcode.Pdf417.Columns = 5;           // number of columns in the symbol

                // Step 3: Set Macro PDF417 specific metadata
                generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
                generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
                generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
                generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
                generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 example
                generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400000;
                generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
                generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
                generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
                generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

                // Step 4: Save the generated barcode image
                generator.Save("YOUR_DIRECTORY/ExtPDF417Meta.png", BarCodeImageFormat.Png);
            }

            Console.WriteLine("Macro PDF417 barcode generated successfully.");
        }
    }
}
```

เรียกโปรแกรม (`dotnet run`). หลังจากทำงานเสร็จ ตรวจสอบว่าไฟล์ PNG ปรากฏที่ตำแหน่งที่คุณระบุ ใช้แอปอ่านบาร์โค้ดใดก็ได้ที่รองรับ Macro PDF417 เพื่อยืนยันว่าเมตาดาต้าถูกฝังอย่างถูกต้อง.

## ความแปรผันทั่วไปและกรณีขอบ

- **รูปแบบภาพที่แตกต่าง**: แทนที่ `BarCodeImageFormat.Png` ด้วย `Jpeg`, `Bmp`, หรือ `Tiff` หากระบบต่อไปของคุณต้องการรูปแบบอื่น.  
- **การเปลี่ยนขนาดโมดูล**: ค่าที่ใหญ่กว่าใน `XDimension.Pixels` ช่วยเพิ่มความน่าเชื่อถือของการสแกนบนสแกนเนอร์ความละเอียดต่ำแต่ทำให้ขนาดภาพเพิ่มขึ้น.  
- **หลายส่วน**: เพื่อสร้างไฟล์หลายส่วน ให้สร้างบาร์โค้ดชุดหนึ่ง เพิ่มค่า `MacroPdf417SegmentID` สำหรับแต่ละส่วน และคงค่า `MacroPdf417FileID` คงที่ ส่วนสุดท้ายเท่านั้นควรตั้งค่า `MacroPdf417Terminator`.  
- **การสนับสนุน Unicode**: ตัวสร้างจะเข้ารหัสอักขระ Unicode โดยอัตโนมัติ; ตรวจสอบให้แน่ใจว่าสตริงต้นฉบับของคุณใช้การเข้ารหัส UTF-8 หากอ่านจากไฟล์ภายนอก.  
- **การจัดการข้อผิดพลาด**: ห่อบล็อก `using` ด้วย try‑catch เพื่อจับ `BarCodeException` สำหรับพารามิเตอร์ที่ไม่ถูกต้อง (เช่น จำนวนคอลัมน์อยู่นอกช่วง).

## เคล็ดลับระดับมืออาชีพ

- **ประสิทธิภาพ**: ใช้ `BarcodeGenerator` อินสแตนซ์เดียวซ้ำเมื่อสร้างบาร์โค้ดหลายรายการด้วยการตั้งค่าเดียวกัน; เพียงเปลี่ยนคุณสมบัติ `CodeText` ระหว่างการบันทึก.  
- **การประมาณขนาดไฟล์**: ฟิลด์ `MacroPdf417FileSize` ควรตรงกับจำนวนไบต์ของข้อมูลต้นฉบับ; ความไม่ตรงกันอาจทำให้การตรวจสอบต่อไปล้มเหลว.  
- **การทดสอบ**: ตรวจสอบบาร์โค้ดที่สร้างด้วยตัวถอดรหัสในตัวของ Aspose (`BarCodeReader`) และสแกนเนอร์ของบุคคลที่สามเพื่อให้แน่ใจว่าระหว่างระบบทำงานร่วมกันได้.
