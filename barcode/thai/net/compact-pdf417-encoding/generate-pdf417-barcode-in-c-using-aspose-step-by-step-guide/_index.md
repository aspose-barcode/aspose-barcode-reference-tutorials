# สร้างบาร์โค้ด PDF417 ด้วย C# โดยใช้ Aspose – คู่มือขั้นตอน‑ต่อ​ขั้นตอน

หากคุณต้องการ **สร้างบาร์โค้ด PDF417** ในแอปพลิเคชัน .NET คู่มือนี้จะแสดงวิธีทำอย่างละเอียด คุณจะได้เห็นตัวอย่างที่พร้อม‑รันทั้งหมดซึ่งสร้างบาร์โค้ด PDF417 แบบพื้นฐาน, แบบคอมแพค, Micro, GS1‑Micro, และ Macro ด้วย Aspose.BarCode for .NET

การสร้างบาร์โค้ด PDF417 เป็นความต้องการทั่วไปสำหรับป้ายจัดส่ง, เอกสารขนส่ง, และระบบสินค้าคงคลัง เมื่อจบบทเรียนนี้คุณจะสามารถ **สร้างภาพบาร์โค้ด PDF417** ได้ เข้าใจพารามิเตอร์สำคัญ และปรับโค้ดให้เหมาะกับข้อมูลของคุณเอง

## Prerequisites

- .NET 6.0 SDK หรือใหม่กว่า (โค้ดนี้ยังทำงานกับ .NET Framework 4.7+)
- Visual Studio 2022 หรือ IDE สำหรับ C# ใดก็ได้
- แพคเกจ NuGet Aspose.BarCode for .NET (`Aspose.BarCode`) ที่ติดตั้งแล้ว
- ความคุ้นเคยพื้นฐานกับไวยากรณ์ C#

> **Pro tip:** ใช้ไลเซนส์ทดลองฟรีจาก Aspose เพื่อหลีกเลี่ยงข้อจำกัดระหว่างรันขณะทดสอบ

## Step 1: Set up the project and import namespaces

สร้างโปรเจกต์คอนโซลใหม่และเพิ่มแพคเกจ Aspose.BarCode:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

จากนั้นเปิด `Program.cs` แล้วเพิ่ม `using` directives ที่จำเป็น:

```csharp
using System;
using Aspose.BarCode.Generation;
```

เนมสเปซเหล่านี้ทำให้คุณเข้าถึงคลาส `BarcodeGenerator` และ enumeration `EncodeTypes` ที่ต้องใช้เพื่อ **generate barcode using C#**.

## Step 2: Generate a basic PDF417 barcode

บาร์โค้ด PDF417 ที่ง่ายที่สุดใช้ค่าตั้งต้น ยกเว้น X‑dimension (ความกว้างโมดูล) และจำนวนคอลัมน์ การปรับค่าทั้งสองจะควบคุมขนาดและความอ่านได้โดยรวม

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Why it works:**  
- `EncodeTypes.Pdf417` บอก Aspose ให้ใช้สัญลักษณ์ PDF417  
- `XDimension.Pixels` กำหนดความกว้างบาร์ที่เล็กที่สุด; ค่า 2 ทำให้ภาพเล็กโดยไม่เสียการสแกน  
- `Pdf417.Columns` กำหนดจำนวนคอลัมน์ข้อมูลของบาร์โค้ด; 3 คอลัมน์ให้สัดส่วนที่สมดุล

## Step 3: Generate a compact (truncated) PDF417 barcode

โหมดคอมแพคลบรูปแบบหยุดและลดความสูงโดยรวม ซึ่งเหมาะกับป้ายที่มีพื้นที่จำกัด

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Why it works:**  
การตั้งค่า `Pdf417.Truncate = true` เปิดโหมดตัดส่วนท้าย ซึ่งละเว้นรูปแบบหยุดด้านขวาและลดความสูงของบาร์โค้ดโดยยังคงความสมบูรณ์ของข้อมูล

## Step 4: Generate a Micro PDF417 barcode

Micro PDF417 เป็นรูปแบบที่เล็กกว่า รองรับคอลัมน์ 1‑4 เหมาะสำหรับแอปพลิเคชันที่ต้องการพื้นที่น้อย เช่น ป้ายสินค้าเล็ก

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Why it works:**  
- `EncodeTypes.MicroPdf417` เลือกเวอร์ชัน micro ของสัญลักษณ์  
- จำนวนคอลัมน์สามารถอยู่ระหว่าง 1 ถึง 4; การเลือก 4 จะให้การจัดวางที่หนาแน่นที่สุดพร้อมยังสแกนได้

## Step 5: Generate a GS1‑compliant Micro PDF417 barcode

คำนำหน้า GS1 เพิ่มตัวระบุมาตรฐาน (เช่น GTIN, หมายเลขล็อต) ลงในข้อมูลบาร์โค้ด Aspose ให้คุณฝังข้อมูลเหล่านี้โดยตรง

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Why it works:**  
GS1 Application Identifiers (AIs) จะถูกใส่ในวงเล็บ. Aspose จะทำการพาร์สและเพิ่มรูปแบบที่สแกนเนอร์ GS1 ต้องการโดยอัตโนมัติ

## Step 6: Generate a Macro PDF417 barcode with full metadata

Macro PDF417 ช่วยให้คุณแบ่งข้อมูลขนาดใหญ่เป็นหลายบาร์โค้ดที่เชื่อมโยงกัน คุณสามารถฝังเมทาดาต้าระดับไฟล์ เช่น ไฟล์ ID, จำนวนเซกเมนต์, เวลา, และสตริงกำหนดเอง

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Why it works:**  
แต่ละคุณสมบัติ `MacroPdf417*` จะแมปกับส่วนเฉพาะของสเปคบาร์โค้ด macro การตั้งค่าค่าต่าง ๆ นี้ทำให้สแกนเนอร์สามารถประกอบไฟล์ต้นฉบับจากหลายภาพบาร์โค้ดได้
