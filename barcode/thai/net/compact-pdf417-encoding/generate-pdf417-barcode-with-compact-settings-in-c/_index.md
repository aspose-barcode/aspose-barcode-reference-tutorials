# สร้างบาร์โค้ด PDF417 ด้วยการตั้งค่าแบบคอมแพคท์ใน C#

หากคุณต้องการ **สร้างบาร์โค้ด PDF417** ในแอปพลิเคชัน .NET คู่มือนี้จะแสดงวิธีทำด้วย Aspose.Barcode for .NET เราจะอธิบายขั้นตอนการสร้างตัวสร้าง (generator) การกำหนดค่าคอลัมน์, X‑dimension, และการเปิดใช้งานโหมดคอมแพคท์ เพื่อให้สัญลักษณ์ที่ได้มีขนาดเล็กที่สุดเท่าที่จะเป็นไปได้

การสร้างบาร์โค้ด PDF417 เป็นเรื่องปกติเมื่อคุณต้องเข้ารหัสข้อมูลจำนวนมากสำหรับตั๋ว, บัตรประจำตัว, หรือป้ายกำกับการจัดส่ง บทเรียนนี้ครอบคลุมกระบวนการทำงานทั้งหมด — ตั้งแต่การติดตั้งไลบรารีจนถึงการบันทึกไฟล์ PNG สุดท้าย — เพื่อให้คุณสามารถคัดลอก‑วางโค้ดลงในโปรเจกต์ของคุณและรันได้ทันที

## ข้อกำหนดเบื้องต้นสำหรับการสร้างบาร์โค้ด PDF417

ก่อนเริ่มทำงาน ให้ตรวจสอบว่าคุณมี:

* .NET 6.0 (หรือใหม่กว่า) ติดตั้งอยู่  
* Visual Studio 2022 หรือ IDE ใด ๆ ที่รองรับโปรเจกต์ C#  
* ไลเซนส์ NuGet สำหรับ **Aspose.Barcode for .NET** (รุ่นทดลองฟรีใช้งานเพื่อการเรียนรู้ได้)

คุณสามารถเพิ่มไลบรารีด้วยคำสั่งต่อไปนี้:

```bash
dotnet add package Aspose.BarCode
```

> **เคล็ดลับ:** ใช้แฟล็ก `--version` เพื่อติดตั้งเวอร์ชันที่มั่นคงที่รู้จัก เช่น `dotnet add package Aspose.BarCode --version 23.12`

## สร้างตัวสร้างบาร์โค้ด PDF417

บล็อกโค้ดแรกนี้สร้างอินสแตนซ์ `BarcodeGenerator` ที่กำหนดค่าล่วงหน้าสำหรับสัญลักษณ์ PDF417 ข้อความ `"Åspóse.Barcóde©"` มีอักขระ Unicode เพื่อแสดงว่าตัวสร้างสามารถจัดการอินพุตที่ไม่ใช่ ASCII ได้โดยอัตโนมัติ

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### ทำไมจึงสำคัญ
`EncodeTypes.Pdf417` บอก Aspose.Barcode ว่าคุณต้องการ **บาร์โค้ด PDF417** ซึ่งเป็นสัญลักษณ์เชิงเส้นแบบซ้อนกันที่สามารถเก็บข้อมูลได้สูงสุดถึง 1 850 ตัวอักษร การใช้คอนสตรัคเตอร์พร้อมอาร์กิวเมนต์ข้อความช่วยให้คุณไม่ต้องเรียก `SetCodeText` ภายหลัง

## ตั้งค่า XDimension ของบาร์โค้ด (ขนาดโมดูล)

ขนาดโมดูล หรือที่เรียกว่า X‑dimension กำหนดความกว้างของบาร์แต่ละบาร์ พิกเซลที่เล็กลงจะทำให้ภาพหนาแน่นขึ้น ในขณะที่พิกเซลที่ใหญ่ขึ้นจะทำให้การอ่านบนเครื่องพิมพ์ความละเอียดต่ำง่ายขึ้น

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### ทำไมคุณควรปรับ XDimension
ค่าที่ `2` พิกเซลทำงานได้ดีสำหรับการแสดงผลบนหน้าจอและเครื่องพิมพ์สำนักงานส่วนใหญ่ หากต้องการพิมพ์ความละเอียดสูงขึ้น ให้เพิ่มค่า; หากต้องการบาร์โค้ดที่กระชับกว่า (เช่นลักษณะคล้าย QR) ให้ลดค่า — แต่ห้ามต่ำกว่า `1` พิกเซล มิฉะนั้นภาพจะอ่านไม่ได้

## ตั้งค่าจำนวนคอลัมน์สำหรับสัญลักษณ์ PDF417

PDF417 ให้คุณเลือกจำนวนคอลัมน์ (กองแนวตั้ง) ของบาร์โค้ด คอลัมน์น้อยทำให้บาร์โค้ดสูงขึ้น; คอลัมน์มากทำให้บาร์โค้ดกว้างขึ้น

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### เมื่อใดควรเปลี่ยนจำนวนคอลัมน์
สามคอลัมน์ให้สัญลักษณ์ที่คอมแพคท์และเกือบเป็นสี่เหลี่ยมจัตุรัส ซึ่งเหมาะกับบัตรประจำตัวมาตรฐาน หากคุณมีสตริงที่ยาวมาก คุณอาจเพิ่มจำนวนคอลัมน์เพื่อให้ความสูงอยู่ในระดับที่รับได้

## เปิดใช้งานโหมดคอมแพคท์ (การตัดส่วนที่ไม่ใช้)

โหมดคอมแพคท์จะลบแถวที่ไม่ได้ใช้จากสัญลักษณ์โดยอัตโนมัติ ทำให้ขนาดโดยรวมลดลง ซึ่งมีประโยชน์มากเมื่อข้อมูลที่เข้ารหัสไม่เต็มเมทริกซ์

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### ประโยชน์ของบาร์โค้ด PDF417 แบบคอมแพคท์
เมื่อ `Truncate` เป็น `true` ตัวสร้างจะคำนวณจำนวนแถวขั้นต่ำที่ต้องการเพื่อเก็บข้อมูลของคุณ ซึ่งช่วยลดการใช้หมึกและเวลาการสแกน ปลอดภัยต่อสแกนเนอร์ส่วนใหญ่เนื่องจากสเปค PDF417 กำหนดอัลกอริทึมการตัดส่วนไว้แล้ว

## บันทึกบาร์โค้ดที่สร้างเป็นภาพ

สุดท้าย ให้เขียนบาร์โค้ดลงไฟล์ PNG PNG ให้คุณภาพแบบไม่มีการสูญเสีย ทำให้เหมาะสำหรับการพิมพ์ต่อหรือฝังใน PDF

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### ผลลัพธ์ที่คาดหวัง
การรันโปรแกรมจะสร้างไฟล์ `CompactPdf417.png` ในโฟลเดอร์ที่ระบุ ภาพนี้มี **บาร์โค้ด PDF417 แบบคอมแพคท์** ที่เข้ารหัสสตริง `"Åspóse.Barcóde©"` ด้วยสามคอลัมน์, X‑dimension 2 พิกเซล, และเปิดใช้งานการตัดส่วน คุณสามารถตรวจสอบผลลัพธ์ด้วยแอปสแกนบาร์โค้ดใด ๆ หรือเดโมออนไลน์ของ Aspose.Barcode ฟรี

## การปรับเปลี่ยนทั่วไปและกรณีขอบ

| สถานการณ์ | การปรับเปลี่ยน |
|-----------|------------|
| **ข้อมูลยาวมาก (> 1500 ตัวอักษร)** | เพิ่ม `Columns` หรือกำหนด `Rows` ด้วยตนเอง (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **พิมพ์บนเครื่องพิมพ์ความละเอียดต่ำ** | เพิ่ม `XDimension.Pixels` เป็น 3 หรือ 4 เพื่อหลีกเลี่ยงการเป็นพิกเซล. |
| **ต้องการพื้นหลังโปร่งใส** | ใช้ `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **ฝังใน PDF** | บันทึกเป็น `BarCodeImageFormat.Pdf` หรือดึงอ็อบเจ็กต์ `Image` ผ่าน `pdf417Generator.GenerateBarCodeImage()`. |

## ตัวอย่างเต็มที่สามารถรันได้

ด้านล่างเป็นโปรแกรมสมบูรณ์ที่คุณสามารถคัดลอกไปใส่ในโปรเจกต์คอนโซลใหม่ ไม่ต้องมีไฟล์เพิ่มเติมใด ๆ

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

รัน `dotnet run` จากโฟลเดอร์โปรเจกต์ หลังจากทำงานเสร็จ เปิด `CompactPdf417.png` เพื่อดูบาร์โค้ดที่สร้างขึ้น
