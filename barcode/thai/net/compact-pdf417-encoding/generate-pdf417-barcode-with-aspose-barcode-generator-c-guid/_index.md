# สร้างบาร์โค้ด PDF417 ด้วย Aspose Barcode Generator – คู่มือ C#

หากคุณต้องการ **สร้างบาร์โค้ด PDF417** ในโครงการ .NET คู่มือนี้จะแสดงวิธีทำโดยใช้ **Aspose Barcode Generator** อย่างละเอียด คุณจะได้เห็นตัวอย่างที่ทำงานได้เต็มรูปแบบซึ่งสร้างสัญลักษณ์ PDF417 แบบกะทัดรัด ปรับขนาดตามต้องการ และบันทึกผลลัพธ์เป็นไฟล์ PNG

การสร้างบาร์โค้ด PDF417 เป็นเรื่องทั่วไปเมื่อคุณต้องเข้ารหัสข้อมูลจำนวนมาก—เช่น URL, ข้อมูลติดต่อ, หรือบันทึกสินค้าคงคลัง—เป็นภาพเดียวที่สแกนได้ คู่มือนี้ครอบคลุมตั้งแต่การติดตั้งไลบรารีจนถึงการปรับ **วิธีตั้งค่า PDF417** เพื่อให้ได้ผลลัพธ์แบบกะทัดรัด

## สิ่งที่คุณจะได้เรียน

* ติดตั้งและอ้างอิงไลบรารี Aspose.BarCode ในโครงการ C#  
* ใช้ **aspose barcode generator** เพื่อสร้างสัญลักษณ์ PDF417 จากข้อความใด ๆ  
* ปรับ **วิธีตั้งค่า PDF417** — ขนาดโมดูล, จำนวนคอลัมน์, และโหมดกะทัดรัด  
* บันทึกบาร์โค้ดเป็นภาพ PNG และตรวจสอบผลลัพธ์  

**ข้อกำหนดเบื้องต้น**

* .NET 6.0 SDK หรือใหม่กว่า (โค้ดนี้ยังทำงานกับ .NET Core 3.1 และ .NET Framework 4.7+)  
* ความคุ้นเคยพื้นฐานกับแอปพลิเคชันคอนโซล C#  
* ใบอนุญาต Aspose.BarCode ที่ถูกต้อง (รุ่นทดลองฟรีใช้ได้สำหรับการพัฒนา)

## ขั้นตอนที่ 1: สร้างบาร์โค้ด PDF417 – สร้างตัวสร้าง

งานแรกคือสร้างอินสแตนซ์ของตัวสร้างด้วยข้อความที่ต้องการและสัญลักษณ์ PDF417 ขั้นตอนนี้ตอบคำถาม **วิธีสร้าง pdf417** โดยตรง

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Create a BarcodeGenerator for PDF417 with the data you want to encode.
            // The EncodeTypes enum selects the symbology; Pdf417 is the target type.
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");
```

**ทำไมจึงสำคัญ:**  
`EncodeTypes.Pdf417` บอกไลบรารีให้ใช้อัลกอริทึม PDF417 ซึ่งรองรับได้สูงสุด 1,850 ตัวอักษร ตัวสร้างยังรับสตริงข้อมูลดิบ; ตัวอักษร Unicode (รวมถึงสำเนียง) จะถูกจัดการโดยอัตโนมัติ

## ขั้นตอนที่ 2: วิธีตั้งค่า PDF417 – ปรับขนาดและเค้าโครง

บาร์โค้ด PDF417 สามารถเรนเดอร์ในหลายรูปแบบ การปรับ **วิธีตั้งค่า pdf417** จะช่วยให้คุณสร้างสัญลักษณ์กะทัดรัดที่พอดีกับป้ายเล็กหรือหน้าจอมือถือ

```csharp
            // -----------------------------------------------------------------
            // Step 2: Set visual parameters for the barcode
            // -----------------------------------------------------------------

            // Module size – each tiny square (pixel) of the barcode.
            // Smaller values produce a tighter image; 2 pixels is a good default.
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Number of columns – controls the width of the barcode.
            // Fewer columns make the symbol taller; 3 columns yields a compact shape.
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode – removes unnecessary quiet zones and reduces height.
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;
```

**คำอธิบายของแต่ละการตั้งค่า**

| พารามิเตอร์ | ผลกระทบ | เมื่อใดควรใช้ |
|-------------|----------|----------------|
| `XDimension.Pixels` | ควบคุมความกว้างของโมดูลเดียว ค่าเล็กลงจะทำให้บาร์โค้ดสั้นลงแต่อาจทำให้เครื่องสแกนอ่านยากบนอุปกรณ์ความละเอียดต่ำ | ใช้ค่า `2`–`4` สำหรับการแสดงบนหน้าจอ; เพิ่มค่าสำหรับป้ายพิมพ์ |
| `Pdf417.Columns` | กำหนดจำนวนคอลัมน์ข้อมูลของสัญลักษณ์ คอลัมน์น้อยจะทำให้บาร์โค้ดสูงและแคบ | เลือก `3`–`5` สำหรับเลย์เอาต์กะทัดรัด; ค่ามากขึ้นสำหรับบาร์โค้ดกว้าง |
| `Pdf417.Truncate` | เปิด “โหมดกะทัดรัด” ซึ่งลบโซนเงียบด้านนอกและลดความสูงโดยรวม | เหมาะกับ UI ที่มีพื้นที่จำกัด |

การตั้งค่าเหล่านี้สามอย่างร่วมกันตอบส่วน **วิธีตั้งค่า pdf417** ของงาน ให้คุณควบคุมภาพสุดท้ายได้อย่างละเอียด

## ขั้นตอนที่ 3: บันทึกภาพบาร์โค้ด – ส่งออกเป็น PNG

หลังจากกำหนดค่าตัวสร้างแล้ว คุณต้องเขียนบาร์โค้ดลงไฟล์ วิธี `Save` รองรับหลายรูปแบบ; PNG ให้คุณภาพ lossless และเหมาะกับเว็บและเดสก์ท็อป

```csharp
            // -----------------------------------------------------------------
            // Step 3: Save the generated barcode as a PNG image
            // -----------------------------------------------------------------

            // Replace YOUR_DIRECTORY with an actual folder on your machine.
            string outputPath = @"C:\Barcodes\CompactPdf417.png";

            // BarCodeImageFormat.Png tells Aspose to write a PNG file.
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            // Inform the user that the process succeeded.
            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**สิ่งที่คุณควรเห็น**

เมื่อรันโปรแกรมจะสร้างไฟล์ `CompactPdf417.png` ในโฟลเดอร์ที่ระบุ ภาพนี้มีสัญลักษณ์ PDF417 หนาแน่นที่เข้ารหัสสตริง `Åspóse.Barcóde©` เครื่องสแกนบาร์โค้ดและแอปมือถือส่วนใหญ่ (เช่น ZXing, Scandit) สามารถอ่านภาพนี้ได้โดยไม่ต้องตั้งค่าเพิ่มเติม

## โค้ดเต็ม – ไฟล์เดียวพร้อมคัดลอกใช้

ด้านล่างเป็นโปรแกรมครบชุด รวมถึง `using` directives และเมธอด `Main` คุณสามารถคัดลอกไปยังโปรเจกต์คอนโซลใหม่และรันได้ทันที

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Step 1: Create the generator (how to generate pdf417)
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");

            // Step 2: Set PDF417 options (how to set pdf417)
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;   // module size
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;    // number of columns
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact mode

            // Step 3: Save as PNG
            string outputPath = @"C:\Barcodes\CompactPdf417.png";
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**การรันโค้ด**

1. เปิดเทอร์มินัลและสร้างโปรเจกต์คอนโซลใหม่:  
   `dotnet new console -n Pdf417Demo`  
2. เพิ่มแพ็กเกจ NuGet ของ Aspose.BarCode:  
   `dotnet add package Aspose.BarCode`  
3. แทนที่ไฟล์ `Program.cs` ที่สร้างขึ้นด้วยโค้ดด้านบน  
4. คอมไพล์และรัน:  
   `dotnet run`  

คุณควรเห็นข้อความยืนยันและพบไฟล์ PNG ที่ตำแหน่งที่ระบุไว้

## ข้อผิดพลาดทั่วไปและเคล็ดลับปฏิบัติที่ดีที่สุด

* **ใบอนุญาตหมดอายุ** – รุ่นทดลองจะใส่ลายน้ำหลังจาก 30 วัน ควรลงทะเบียนใบอนุญาตตั้งแต่ต้นเพื่อหลีกเลี่ยงปัญหา  
* **สิทธิ์โฟลเดอร์** – ตรวจสอบให้โฟลเดอร์เป้าหมายมีอยู่และกระบวนการมีสิทธิ์เขียน; หากไม่เช่นนั้น `Save` จะโยน `UnauthorizedAccessException`  
* **ความเข้ากันได้ของสแกนเนอร์** – หากสแกนเนอร์อ่านบาร์โค้ดกะทัดรัดไม่ได้ ให้เพิ่ม `XDimension.Pixels` เป็น `4` หรือตั้งค่า `Truncate = false`  
* **การจัดการ Unicode** – Aspose.BarCode รองรับ UTF‑8 อย่างเต็มที่; คุณสามารถเข้ารหัสสตริง Unicode ใดก็ได้โดยไม่ต้องทำขั้นตอนเพิ่มเติม  
* **ประสิทธิภาพ** – การสร้างบาร์โค้ดหลาย ๆ ตัวในลูปจะได้ประโยชน์จากการใช้อินสแตนซ์ `BarcodeGenerator` เพียงตัวเดียวและอัปเดต `CodeText` ระหว่างรอบ
