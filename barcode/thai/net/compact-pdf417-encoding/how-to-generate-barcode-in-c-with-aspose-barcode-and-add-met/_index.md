# วิธีสร้างบาร์โค้ดใน C# ด้วย Aspose.BarCode และเพิ่มเมตาดาต้า

หากคุณต้องการ **สร้างบาร์โค้ดใน C#** สำหรับระบบโลจิสติกส์หรือระบบสินค้าคงคลัง คู่มือนี้จะแสดงวิธีแก้ไขที่สมบูรณ์และพร้อมใช้งานในระดับการผลิต คุณจะได้เห็นวิธีสร้างบาร์โค้ด Macro PDF417 แนบเมตาดาต้าที่ครบถ้วน และตั้งค่า timestamp ที่แม่นยำ—ทั้งหมดด้วยไลบรารี Aspose.BarCode

บทแนะนำนี้ครอบคลุมทุกอย่างตั้งแต่การติดตั้งแพ็กเกจ NuGet ไปจนถึงการบันทึกภาพ PNG สุดท้าย เมื่อจบคุณจะสามารถสร้างบาร์โค้ดที่บรรจุตัวระบุไฟล์ ข้อมูลเซกเมนต์ และฟิลด์ที่กำหนดเอง พร้อมให้สแกนเนอร์ที่รองรับ Macro PDF417 ใช้งานได้

## Prerequisites

ก่อนเริ่มทำงาน โปรดตรวจสอบว่าคุณมี:

* .NET 6.0 SDK หรือใหม่กว่า (โค้ดนี้ยังทำงานกับ .NET Framework 4.7.2+ ด้วย)
* Visual Studio 2022 หรือ IDE C# ใด ๆ ที่คุณชอบ
* ใบอนุญาต Aspose.BarCode ที่ใช้งานได้ (รุ่นทดลองฟรีใช้สำหรับการพัฒนา)
* ความคุ้นเคยพื้นฐานกับไวยากรณ์ C#

> **Pro tip:** หากคุณใช้ pipeline CI/CD ให้เพิ่มการอ้างอิงแพ็กเกจ Aspose.BarCode ในไฟล์โครงการของคุณเพื่อให้การสร้างซ้ำได้อย่างสม่ำเสมอ

## Step 1: Install Aspose.BarCode

เปิดเทอร์มินัลในโฟลเดอร์โครงการของคุณและรัน:

```bash
dotnet add package Aspose.BarCode
```

คำสั่งนี้จะดึงเวอร์ชันเสถียรล่าสุด (ขณะนี้คือ 24.9) หลังจากการกู้คืนเสร็จสิ้น คุณสามารถอ้างอิงไลบรารีในไฟล์ซอร์สของคุณได้

## Step 2: Create a new C# console project (optional)

หากต้องการเริ่มต้นใหม่ ให้สร้างแอปคอนโซล:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

ไฟล์ `Program.cs` จะเป็นที่เก็บโค้ดการสร้างบาร์โค้ดที่จะแสดงต่อไป

## Step 3: Set up the barcode generator

หัวใจของกระบวนการคือคลาส `BarcodeGenerator` คุณจะสร้างอินสแตนซ์โดยระบุค่า `EncodeTypes` ที่ต้องการและข้อความที่ต้องการเข้ารหัส

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Why each line matters

* **EncodeTypes.MacroPdf417** บอก Aspose ให้สร้างบาร์โค้ด PDF417 ที่สามารถแยกเป็นเซกเมนต์ได้ ซึ่งจำเป็นสำหรับข้อมูลขนาดใหญ่ที่เกินความจุของสัญลักษณ์เดียว
* **XDimension.Pixels** ควบคุมความหนาแน่นของภาพ ค่า 2 ให้ภาพที่คมชัดบนหน้าจอและเครื่องพิมพ์ส่วนใหญ่โดยไม่ทำให้ไฟล์ใหญ่เกินไป
* **MacroPdf417* properties** ฝังเมตาดาต้าที่สแกนเนอร์อ่านเป็นฟิลด์แยก (ไฟล์ ID, เซกเมนต์ ID ฯลฯ) นี่คือส่วน “วิธีเพิ่มเมตาดาต้า” ของบทแนะนำ
* **MacroPdf417TimeStamp** แสดง “วิธีตั้งค่า timestamp” ตัวแปร `DateTime` สามารถเป็นเวลา UTC ใด ๆ ก็ได้; การใช้ UTC ช่วยหลีกเลี่ยงความสับสนของโซนเวลาเมื่อบาร์โค้ดเดินทางข้ามภูมิภาค
* **MacroPdf417Terminator** กำหนดวิธีการสิ้นสุดลำดับแมโคร `Set` เป็นตัวเลือกที่ใช้บ่อยที่สุดเพราะสื่อสารว่าเป็นเซกเมนต์สุดท้ายให้กับรีดเดอร์
* **Save(..., BarCodeImageFormat.Png)** บันทึกเป็นภาพแบบ lossless ที่รักษารายละเอียดสำคัญสำหรับการสแกนที่เชื่อถือได้

### Expected visual characteristics

* แถบสีดำแนวตั้งที่หนาและห่างกันอย่างสม่ำเสมอ
* Quiet zone (ขอบว่าง) ที่เพิ่มโดยอัตโนมัติโดย Aspose
* ไม่มีการบิดเบือน เนื่องจาก `XDimension` ที่ 2 พิกเซลตรงกับความละเอียดดั้งเดิมของ PNG

## Step 5: Common variations and edge cases

### 5.1 Handling special characters

ข้อความตัวอย่างมีอักขระ Unicode (`Å`, `ó`, `©`) Aspose.BarCode จะเข้ารหัสด้วย UTF‑8 เป็นค่าเริ่มต้น ทำให้แสดงผลถูกต้องในบาร์โค้ด หากต้องการการเข้ารหัสอื่น (เช่น ISO‑8859‑1) ให้ตั้งค่า:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Large file identifiers

`MacroPdf417FileID` รองรับจำนวนเต็ม 32‑bit หากค่ามากกว่า `int.MaxValue` ให้แยกตัวระบุออกเป็นหลายฟิลด์หรือใช้ GUID ที่เก็บเป็นสตริงใน `MacroPdf417FileName`

### 5.3 Adjusting the number of columns

การเพิ่มค่า `Pdf417.Columns` จะลดความสูงของบาร์โค้ดแต่ทำให้แต่ละแถวกว้างขึ้น หากบาร์โค้ดต้องพอดีกับป้ายแคบ ให้ลดจำนวนคอลัมน์และระบบจะเพิ่มจำนวนแถวโดยอัตโนมัติ

### 5.4 Saving in other formats

Aspose รองรับ BMP, JPEG, TIFF, และ SVG แทนที่ `BarCodeImageFormat.Png` ด้วยค่า enum ที่ต้องการ เช่น `BarCodeImageFormat.Svg` สำหรับกราฟิกเวกเตอร์ที่ปรับขนาดได้

## Frequently asked questions

**Q: Does this work on .NET Core?**  
A: Yes. The same API works on .NET Core, .NET 5+, and .NET Framework. Just reference the appropriate NuGet package.

**Q: What if I need to generate a non‑macro PDF417?**  
A: Use `EncodeTypes.Pdf417` instead of `EncodeTypes.MacroPdf417`. The macro‑specific properties will be ignored.

**Q: Can I add custom key/value pairs beyond the built‑in fields?**  
A: Aspose.BarCode does not expose arbitrary user fields for Macro PDF417. If you need extra data, encode it in the main text payload or switch to a QR code, which supports structured append.
