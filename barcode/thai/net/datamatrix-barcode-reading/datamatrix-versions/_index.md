# วิธีสร้างบาร์โค้ด DataMatrix ด้วย Aspose.BarCode สำหรับ .NET

หากคุณต้องการวิธีที่เชื่อถือได้ในการฝังสัญลักษณ์ที่เครื่องอ่านได้ในแอปพลิเคชัน .NET ของคุณ, **วิธีสร้าง DataMatrix** เป็นความต้องการที่พบบ่อย Aspose.BarCode สำหรับ .NET มี API ที่จัดการทั้งหมด—from การเลือกเวอร์ชัน DataMatrix ที่เหมาะสมจนถึงการปรับระดับการแก้ไขข้อผิดพลาด—โดยไม่ต้องใช้เครื่องมือภายนอก ในบทแนะนำนี้เราจะเดินผ่านตัวอย่างเต็มรูปแบบ, อธิบายว่าการตั้งค่าแต่ละอย่างสำคัญอย่างไร, และแสดงวิธีบันทึกผลลัพธ์เป็นภาพ PNG หรือ JPEG

## คำตอบสั้น
- **ไลบรารีใดสร้างบาร์โค้ด DataMatrix?** Aspose.BarCode สำหรับ .NET.  
- **รองรับเวอร์ชัน DataMatrix กี่เวอร์ชัน?** ทั้ง 30 เวอร์ชันมาตรฐานแบบสี่เหลี่ยมจัตุรัสและสี่เหลี่ยมผืนผ้า (ตั้งแต่ 10×10 ถึง 144×144 โมดูล).  
- **ประเภท ECC ที่ฉันสามารถใช้ได้มีอะไรบ้าง?** ECC200 (ค่าเริ่มต้น) และ ECC140.  
- **ต้องการไลเซนส์สำหรับการพัฒนาหรือไม่?** รุ่นทดลองฟรี 30 วันใช้ได้สำหรับการทดสอบ; ต้องมีไลเซนส์เชิงพาณิชย์สำหรับการใช้งานจริง.  
- **ฉันสามารถรันบน .NET 6, .NET Core หรือ .NET Framework ได้หรือไม่?** ใช่—Aspose.BarCode รองรับ .NET Framework 4.5+, .NET Core 3.1+, และ .NET 5/6+.

## DataMatrix barcode คืออะไร
DataMatrix barcode คือรหัสสองมิติรูปแบบสี่เหลี่ยมจัตุรัสหรือสี่เหลี่ยมผืนผ้าที่ประกอบด้วยเซลล์สีดำและสีขาว สามารถเก็บข้อมูลอักขระได้สูงสุด 2,335 ตัวอักษรแบบอัลฟานูเมอริก มักใช้ในอุตสาหกรรมการผลิต, โลจิสติกส์, และสุขภาพสำหรับการทำเครื่องหมายสินค้าขนาดเล็ก เนื่องจากยังอ่านได้แม้ส่วนหนึ่งของสัญลักษณ์จะเสียหาย

## ทำไมต้องใช้ Aspose.BarCode สำหรับ .NET
Aspose.BarCode รองรับ **รูปแบบผลลัพธ์กว่า 50 แบบ** (รวมถึง PNG, JPEG, TIFF, SVG, และ PDF) และสามารถสร้าง **เวอร์ชัน DataMatrix ทั้ง 30** ได้โดยไม่ต้องโหลดภาพทั้งหมดเข้าสู่หน่วยความจำ ทำให้คุณสร้างบาร์โค้ดในบริการที่ต้องประมวลผลไฟล์ขนาดใหญ่กว่า 100 MB ได้อย่างมีประสิทธิภาพ

## วิธีสร้างบาร์โค้ด DataMatrix ใน .NET?

โหลด `BarcodeGenerator` ด้วยประเภท `EncodeTypes.DataMatrix`, ตั้งค่าเวอร์ชันและ ECC ที่ต้องการ, แล้วเรียก `Save` เพื่อบันทึกไฟล์ภาพ รูปแบบบรรทัดเดียวนี้ทำงานได้กับเวอร์ชันใดก็ได้ที่คุณเลือกและจัดการขนาดโมดูล, โซนเงียบ, และการเรนเดอร์ภาพโดยอัตโนมัติ

## นำเข้า namespace

`BarcodeGenerator` เป็นคลาสหลักของ Aspose.BarCode สำหรับสร้างภาพบาร์โค้ด.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

Namespace `Aspose.BarCode.Generation` ให้เข้าถึงคลาส `BarcodeGenerator`, ซึ่งเป็นคลาสหลักที่ใช้ในการสร้างภาพบาร์โค้ด

## ขั้นตอนที่ 1: ตั้งค่าเส้นทางไดเรกทอรีของคุณ

กำหนดเส้นทางไดเรกทอรีที่คุณต้องการบันทึกบาร์โค้ด DataMatrix ที่สร้างขึ้น

```csharp
string path = "Your Directory Path";
```

แทนที่ `"Your Directory Path"` ด้วยเส้นทางจริงที่คุณต้องการบันทึกภาพบาร์โค้ด

## ขั้นตอนที่ 2: เริ่มต้นตัวสร้างบาร์โค้ด

สร้างอินสแตนซ์ของคลาส `BarcodeGenerator` และระบุประเภทบาร์โค้ดเป็น `DataMatrix`. คุณยังสามารถระบุข้อมูลที่ต้องการเข้ารหัสในบาร์โค้ดได้อีกด้วย

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` เป็นคลาสหลักที่สร้างและเรนเดอร์สัญลักษณ์บาร์โค้ด

## ขั้นตอนที่ 3: กำหนดคุณสมบัติบาร์โค้ด

คุณสามารถปรับแต่งคุณสมบัติต่าง ๆ ของบาร์โค้ด DataMatrix เช่น มิติและประเภท ECC (Error Correction Code). ตัวอย่างต่อไปนี้ตั้งค่า X‑dimension เป็น 4 พิกเซลและเลือก ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` กำหนดขนาดของแต่ละโมดูลเป็นพิกเซล, ส่วน `DataMatrixEcc` เลือกระดับการแก้ไขข้อผิดพลาด

## ขั้นตอนที่ 4: ตั้งค่าเวอร์ชัน DataMatrix และบันทึก

คุณสามารถระบุเวอร์ชัน DataMatrix โดยตั้งค่าจำนวนแถวและคอลัมน์ หลังจากกำหนดเวอร์ชันแล้วให้บันทึกภาพบาร์โค้ด

ตัวอย่างเช่น การสร้างบาร์โค้ด DataMatrix ที่มี 22 แถวและ 22 คอลัมน์โดยใช้ ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

เช่นเดียวกัน, คุณสามารถสร้างบาร์โค้ดด้วยพารามิเตอร์ต่าง ๆ โดยเปลี่ยนเวอร์ชันและประเภท ECC ตามต้องการ

## ขั้นตอนที่ 5: ทำซ้ำสำหรับเวอร์ชันอื่น ๆ

คุณสามารถทำซ้ำขั้นตอนที่ 4 สำหรับเวอร์ชัน DataMatrix อื่น ๆ ตัวอย่างเช่น การสร้างบาร์โค้ดที่มี 12 แถวและ 64 คอลัมน์โดยใช้ ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## ขั้นตอนที่ 6: สลับประเภท ECC

หากต้องการเปลี่ยนประเภท ECC เป็น Ecc140, สามารถทำได้โดยอัปเดตคุณสมบัติ ECC:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## ขั้นตอนที่ 7: สร้างบาร์โค้ดด้วยเวอร์ชันและ ECC ที่แตกต่างกัน

ทำซ้ำขั้นตอนที่ 4 สำหรับเวอร์ชัน DataMatrix และประเภท ECC อื่น ๆ, บันทึกแต่ละบาร์โค้ดด้วยชื่อไฟล์ที่ไม่ซ้ำกัน

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

ตอนนี้คุณได้เรียนรู้วิธีสร้างบาร์โค้ด DataMatrix ด้วย Aspose.BarCode สำหรับ .NET แล้ว, คุณสามารถผสานฟังก์ชันนี้เข้าไปในแอปพลิเคชัน .NET ของคุณได้อย่างง่ายดาย

## ข้อผิดพลาดทั่วไปและเคล็ดลับการแก้ไขปัญหา

- **Incorrect version dimensions** – เวอร์ชัน DataMatrix มีคู่แถว/คอลัมน์ที่กำหนดไว้ล่วงหน้า การใส่คู่ที่ไม่ตรงกัน (เช่น 10 × 20) จะทำให้เกิด `ArgumentException`. ควรใช้คู่ที่รองรับตามที่ระบุในเอกสาร API.  
- **Missing license** – ในโหมดทดลองภาพที่สร้างจะมีลายน้ำ ใช้ไลเซนส์ที่ถูกต้องด้วย `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` ก่อนสร้างตัวสร้างเพื่อเอาลายน้ำออก คลาส `License` จะโหลดไฟล์ไลเซนส์เพื่อเปิดใช้งานผลิตภัณฑ์.  
- **Large image size** – หากต้องการผลลัพธ์ความละเอียดสูง ให้เพิ่มคุณสมบัติ `XDimension`; ไลบรารีจะสเกลภาพอย่างสัดส่วนโดยไม่สูญเสียความอ่านได้.
