# Jak utworzyć plik PNG z kodem kreskowym w Pythonie – przewodnik krok po kroku

Jeśli potrzebujesz **utworzyć plik PNG z kodem kreskowym** z dowolnych ciągów znaków, ten tutorial dostarcza gotowe rozwiązanie. Zobaczysz dokładnie, jak wygenerować kod kreskowy Code 128, przekształcić tekst w obraz kodu kreskowego i zapisać wynik jako plik PNG — wszystko przy użyciu kilku linii Pythona.

Poradnik obejmuje wszystko, co musisz wiedzieć, od instalacji wymaganego pakietu po dostosowanie wyjścia do różnych scenariuszy. Po zakończeniu będziesz mógł wbudować generowanie kodów kreskowych w dowolny projekt Pythona bez konieczności szukania dodatkowej dokumentacji.

## Czego się nauczysz

* Zainstalujesz pakiet **barcode generator python**, który obsługuje Code 128.
* Użyjesz `BarCodeGenerator`, aby **wygenerować kod kreskowy 128** z ciągu tekstowego.
* Zapiszesz wynik jako wysokiej jakości PNG przy pomocy `save`.
* Dostosujesz rozmiar obrazu, kolory pierwszego planu/tła oraz obsłużysz typowe błędy.
* Zweryfikujesz, że plik PNG został utworzony poprawnie.

### Wymagania wstępne

| Wymaganie | Powód |
|-----------|-------|
| Python 3.8+ | Nowoczesna składnia i wskazówki typów |
| Dostęp do Internetu (do `pip install`) | Aby pobrać bibliotekę |
| Uprawnienia do zapisu w folderze | Aby przechowywać wygenerowany PNG |

Żadne zewnętrzne usługi nie są wymagane; wszystko działa lokalnie.

## Krok 1: Zainstaluj bibliotekę do kodów kreskowych

Najprostszym sposobem na **konwersję tekstu na kod kreskowy** w Pythonie jest użycie pakietu **Aspose.BarCode for Python via .NET**, który obsługuje Code 128 od razu.

```bash
pip install aspose-barcode
```

> **Wskazówka:** Jeśli pracujesz w wirtualnym środowisku, aktywuj je przed uruchomieniem polecenia, aby utrzymać zależności odizolowane.

## Krok 2: Zaimportuj potrzebne klasy

Po instalacji zaimportuj klasy podstawowe. Instrukcje importu są krótkie, co ułatwia czytelność kodu.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` tworzy obraz kodu kreskowego.
* `EncodeTypes` udostępnia wyliczenie obsługiwanych symbologii, w tym `CODE_128`.

## Krok 3: Zdefiniuj tekst do zakodowania

Wybierz dowolny ciąg alfanumeryczny. Code 128 może reprezentować pełny zestaw ASCII, więc nie jesteś ograniczony do samych liczb.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Jeśli wejście zawiera nieobsługiwane znaki, generator zgłosi `ValueError`. Owiń przypisanie w blok `try`, jeśli spodziewasz się danych podawanych przez użytkownika.

## Krok 4: Utwórz generator kodu kreskowego dla Code 128

Zainicjuj `BarCodeGenerator` z wybraną symbologią i wcześniej zdefiniowanym tekstem. To jest sedno **tworzenia kodu kreskowego** w Pythonie.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

Dlaczego Code 128? Oferuje wysoką gęstość i może kodować pełny zakres ASCII, co czyni go idealnym dla systemów inwentaryzacji, etykiet wysyłkowych i biletów.

## Krok 5: (Opcjonalnie) Dostosuj wygląd

Możesz precyzyjnie dostroić kod kreskowy przed jego zapisaniem. Poniższe opcje są najczęściej używane:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Ustawienia te wpływają na ostateczny **create barcode png** bez zmiany zakodowanych danych.

## Krok 6: Zapisz kod kreskowy jako plik PNG

Na koniec zapisz obraz na dysku. Metoda `save` automatycznie wykrywa rozszerzenie pliku, więc podanie `.png` tworzy obraz PNG.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Jeśli docelowy katalog nie istnieje, Python zgłosi `FileNotFoundError`. Utwórz katalog wcześniej lub użyj `os.makedirs` z `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### Oczekiwany wynik

Po uruchomieniu skryptu znajdziesz plik `extended_barcode.png` w folderze `output`. Otwierając go, zobaczysz wyraźny kod kreskowy Code 128, który koduje `1234567890`.

![Wygenerowany kod kreskowy PNG utworzony w Pythonie](generated_barcode.png "przykład create barcode png")

## Krok 7: Zweryfikuj kod kreskowy (szybka kontrola)

Możesz odczytać PNG ponownie przy użyciu tej samej biblioteki, aby potwierdzić, że zakodowana wartość odpowiada pierwotnemu tekstowi.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Uruchomienie tego bloku wypisuje:

```
Verification succeeded: 1234567890
```

Jeśli asercja nie powiedzie się, sprawdź ponownie `barcode_text` oraz wszelkie niestandardowe parametry, które ustawiłeś.

## Typowe warianty i przypadki brzegowe

| Sytuacja | Dostosowanie |
|----------|--------------|
| **Dłuższy tekst (> 20 znaków)** | Zwiększ `image_width`, aby uniknąć obcięcia. |
| **Potrzeba przezroczystego tła** | Ustaw `back_color = "Transparent"` przed zapisem. |
| **Generowanie wielu kodów kreskowych w pętli** | Owiń kroki 3‑6 w pętlę `for`, zmieniając `barcode_text` w każdej iteracji. |
| **Zapis jako JPEG zamiast PNG** | Zmień rozszerzenie pliku na `.jpg`; biblioteka automatycznie obsłuży format. |
| **Uruchamianie na serwerze bez interfejsu graficznego** | Biblioteka nie wymaga GUI, co czyni ją bezpieczną dla potoków CI. |

## Pełny skrypt do szybkiego kopiowania

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Zapisz skrypt jako `generate_barcode.py` i uruchom:

```bash
python generate_barcode.py
```

Zobaczysz komunikaty potwierdzające oraz nowy plik PNG w folderze `output`.

Ten sam schemat działa dla dowolnych danych Code 128, umożliwiając wbudowanie tworzenia kodów kreskowych w systemy inwentaryzacji, usługi internetowe czy automatyczne generatory raportów.

* Połącz PNG z bibliotekami generującymi PDF (np. `ReportLab`) w celu tworzenia drukowalnych etykiet.

Śmiało eksperymentuj z schematami kolorów, rozmiarami i przetwarzaniem wsadowym — Twój nowy proces tworzenia kodów kreskowych jest gotowy do produkcji. Miłego kodowania!
