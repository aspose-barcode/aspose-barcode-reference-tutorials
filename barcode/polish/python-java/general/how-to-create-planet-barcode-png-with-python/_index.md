# Jak stworzyć kod kreskowy Planet w formacie PNG przy użyciu Pythona

Jeśli potrzebujesz **utworzyć kod kreskowy Planet w formacie PNG**, ten tutorial przeprowadzi Cię przez cały proces przy użyciu Pythona. Dowiesz się także **jak generować kod kreskowy Planet** krok po kroku, skonfigurować jego wygląd i zapisać wynik jako wysokiej jakości obraz PNG.

Generowanie kodu kreskowego Planet jest powszechne w automatyzacji pocztowej, śledzeniu zapasów i systemach logistycznych. Po zakończeniu tego przewodnika będziesz mieć samodzielny skrypt, który tworzy gotowy do użycia plik PNG, oraz zrozumiesz, jak dostosować kod do różnych rozmiarów lub formatów obrazu.

## Prerequisites

Before you start, make sure you have:

* Python 3.8 lub nowszy zainstalowany.
* Dostęp do pakietu `aspose-barcode` (lub dowolnej kompatybilnej biblioteki, która udostępnia klasy `BarcodeGenerator`, `EncodeTypes` i `BarCodeImageFormat`).
* Uprawnienia do zapisu w katalogu, w którym chcesz przechowywać plik PNG.

You can install the required library with pip:

```bash
pip install aspose-barcode
```

> **Wskazówka:** Użyj wirtualnego środowiska, aby utrzymać zależności odizolowane od innych projektów.

## Tworzenie kodu kreskowego Planet w formacie PNG – pełny przegląd kodu

The following script demonstrates every step required to generate a Planet barcode PNG with empty (unfilled) bars. Copy the code into a file named `planet_barcode.py` and run it with `python planet_barcode.py`.

```python
# planet_barcode.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Initialize a Planet barcode generator with the data to encode
# The data "123456" is a typical numeric payload for postal services.
generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

# Step 2: Set the width of each bar (X dimension) to 4 pixels.
# Adjusting the X dimension changes the overall size and readability.
generator.parameters.barcode.x_dimension.pixels = 4

# Step 3: Configure the barcode to use empty (unfilled) bars.
# When `filled_bars` is False, the dark bars become transparent,
# which is useful for overlaying the barcode on colored backgrounds.
generator.parameters.barcode.filled_bars = False

# Step 4: Save the generated barcode as a PNG image.
# The output path can be absolute or relative; ensure the folder exists.
output_path = "output/PostalPlanetEmptyBars.png"
generator.save(output_path, BarCodeImageFormat.PNG)

print(f"Planet barcode PNG saved to: {output_path}")
```

### Co robi każda linia

| Linia | Wyjaśnienie |
|------|-------------|
| `from aspose.barcode import ...` | Importuje klasy potrzebne do stworzenia i skonfigurowania kodu kreskowego. |
| `BarcodeGenerator(EncodeTypes.Planet, "123456")` | Tworzy generator dla symbolu **Planet** używając ciągu numerycznego `"123456"`. |
| `x_dimension.pixels = 4` | Ustawia szerokość kreski na 4 px; większe wartości tworzą większy kod kreskowy, mniejsze zmniejszają rozmiar pliku. |
| `filled_bars = False` | Przełącza kod kreskowy na użycie **pustych kresek**, co sprawia, że ciemne moduły są przezroczyste. |
| `save(..., BarCodeImageFormat.PNG)` | Zapisuje kod kreskowy do pliku PNG, zachowując jakość bezstratną. |
| `print(...)` | Potwierdza pomyślne utworzenie w konsoli. |

## Jak generować kod kreskowy Planet z własnymi ustawieniami

While the basic script covers most use‑cases, you may need to adjust the barcode for specific requirements:

1. **Różne długości danych** – Kody kreskowe Planet obsługują do 12 znaków numerycznych. Zmień `"123456"` na dowolny prawidłowy ciąg numeryczny w tym zakresie.
2. **Alternatywne formaty obrazu** – Zastąp `BarCodeImageFormat.PNG` przez `BarCodeImageFormat.JPEG` lub `BarCodeImageFormat.BMP`, aby dopasować do kolejnych etapów przetwarzania.
3. **Zmiana wymiaru X** – Większe wartości (np. `8`) tworzą kod kreskowy o wyższej rozdzielczości, co jest przydatne przy drukowaniu na dużych etykietach.
4. **Kolory tła** – Jeśli chcesz kolorowe tło, ustaw `generator.parameters.barcode.back_color` przed zapisem.

Example with a custom background color:

```python
from aspose.barcode import Color

generator.parameters.barcode.back_color = Color.get_yellow()
generator.save("output/PlanetYellowBackground.png", BarCodeImageFormat.PNG)
```

## Częste pułapki i jak ich unikać

| Problem | Przyczyna | Rozwiązanie |
|-------|--------|-----|
| **FileNotFoundError** przy zapisywaniu | Docelowy katalog nie istnieje. | Utwórz katalog wcześniej (`os.makedirs("output", exist_ok=True)`). |
| **Nieprawidłowa długość danych** | Kod kreskowy Planet akceptuje wyłącznie dane numeryczne do 12 znaków. | Zweryfikuj ciąg wejściowy przed utworzeniem generatora. |
| **Przezroczyste kreski niewidoczne** | Niektóre przeglądarki ignorują przezroczystość na białym tle. | Umieść kod kreskowy na tle innym niż białe lub wyeksportuj jako PNG z kanałem alfa. |

## Weryfikacja wyniku

After running the script, open `PostalPlanetEmptyBars.png` with any image viewer. You should see a series of vertical bars where the dark modules are transparent, leaving only the outline of the barcode. To confirm that the barcode is scannable, use a mobile barcode scanner app that supports the Planet symbology.

If the image appears blank, double‑check:

* Flaga `filled_bars` jest ustawiona na `False`.
* Wymiar X nie jest ustawiony na zero.
* Ścieżka wyjściowa wskazuje istniejący folder.
