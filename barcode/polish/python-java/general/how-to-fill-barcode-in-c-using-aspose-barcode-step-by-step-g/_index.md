# Jak wypełnić kod kreskowy w C# przy użyciu Aspose.BarCode

Jeśli potrzebujesz **jak wypełnić kod kreskowy** w aplikacji .NET, ten tutorial pokazuje kompletny proces. Wygenerujesz pocztowy kod kreskowy Planet z pełnymi paskami, a następnie utworzysz wersję tego samego kodu z pustymi paskami, wszystko przy zmianie jednej linii kodu.

Poradnik obejmuje wszystko, co musisz wiedzieć: konfigurację projektu, dostrajanie X‑dimension, przełączanie między pełnymi a pustymi paskami oraz sposób weryfikacji wygenerowanych plików PNG. Nie wymaga dodatkowej dokumentacji — po prostu skopiuj kod, uruchom go i zobaczysz wynik.

## Wymagania wstępne

* .NET 6.0 SDK lub nowszy zainstalowany  
* Środowisko programistyczne, takie jak Visual Studio 2022 lub VS Code  
* Pakiet NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

Te elementy stanowią minimalną bazę dla części **barcode generator c#** tego tutorialu.

## Jak wypełnić kod kreskowy – konfiguracja projektu

1. Utwórz nowy projekt konsolowy:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Dodaj pakiet Aspose.BarCode:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Otwórz wygenerowany plik `Program.cs` i zamień jego zawartość na pełny przykład pokazany później w tym artykule.

Projekt zawiera teraz wszystko, co potrzebne do **generate postal barcode** obrazów.

## Generowanie pocztowego kodu kreskowego z pełnymi paskami

Pierwszym krokiem jest stworzenie kodu kreskowego Planet, który używa wypełnionych (solidnych) pasków. Planet jest symboliką używaną przez wiele usług pocztowych do sortowania.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Dlaczego te linie są ważne**

* `EncodeTypes.Planet` informuje generator, której symboliki użyć; Planet jest standardem dla pocztowych kodów kreskowych.  
* `XDimension.Pixels = 4` zwiększa szerokość modułu, co ułatwia skanowanie kodu i sprawia, że jest on wizualnie czytelniejszy po wydrukowaniu.  
* `Save` zapisuje obraz na dysku w formacie PNG, formacie bezstratnym odpowiednim do dalszego przetwarzania.  

Uruchomienie tego bloku generuje **PostalPlanetFilledBars.png**, obraz z pełnymi paskami, który spełnia specyfikacje pocztowe.

## Tworzenie pustego kodu kreskowego przy użyciu symboliki Planet

Czasami system pocztowy oczekuje, że paski będą puste (nie wypełnione), podczas gdy przestrzenie pozostaną solidne. Przełączenie na ten tryb wymaga zmiany tylko jednej właściwości.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Dlaczego to działa**

Ustawienie `FilledBars = false` informuje renderer, aby odwrócił styl wizualny: paski stają się przezroczyste (puste), a tło nieprzezroczyste. To jest dokładny przeciwieństwo domyślnego zachowania pokazanego wcześniej, pozwalając Ci **create empty barcode** obrazy bez zmiany zakodowanych danych.

## Pełny, uruchamialny przykład

Poniżej znajduje się kompletny program łączący oba sekcje. Skopiuj go do `Program.cs`, zamień `YOUR_DIRECTORY/` na rzeczywistą ścieżkę folderu i uruchom `dotnet run`.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Oczekiwany wynik

Po wykonaniu znajdziesz dwa pliki PNG w określonym folderze:

| Nazwa pliku                     | Opis wizualny |
|-------------------------------|--------------------|
| `PostalPlanetFilledBars.png`  | Paski są czarne i pełne na białym tle |
| `PostalPlanetEmptyBars.png`   | Paski są przezroczyste (białe) na czarnym tle |

Oba obrazy kodują ten sam ciąg liczbowy `"123456"` i mają tę samą X‑dimension, co zapewnia ich wymienność z perspektywy walidacji danych.

## Częste pytania i przypadki brzegowe

**Co zrobić, jeśli folder wyjściowy nie istnieje?**  
Metoda `Save` rzuca `DirectoryNotFoundException`. Utwórz folder wcześniej lub otocz wywołania w blok `try / catch`, który w razie potrzeby utworzy katalog:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Czy mogę użyć innego formatu obrazu?**  
Tak. Zamień `BarCodeImageFormat.Png` na `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` lub dowolny format obsługiwany przez Aspose.BarCode.

**Czy X‑dimension wpływa na czytelność skanera?**  
Zwiększenie szerokości w pikselach powoduje szersze paski, co może poprawić czytelność na skanerach o niskiej rozdzielczości. Jednak bardzo duże wartości mogą przekroczyć obszar drukowalny. Typowe wartości mieszczą się w przedziale od 2 do 6 pikseli przy druku 300 dpi.

**Czy symbologia `EncodeTypes.Planet` jest jedyną opcją pocztową?**  
Nie. Aspose.BarCode obsługuje także `EncodeTypes.Postnet` i `EncodeTypes.USPSIntelligentMail`. Ta sama właściwość `FilledBars` działa również z tymi typami.

Dostosowując X‑dimension kontrolujesz klarowność wizualną, a jednorazowa zmiana właściwości przełącza między pełnymi a pustymi paskami bez zmiany zakodowanych danych.
