# Przykład generatora kodów kreskowych w C# – generowanie kodu Planet i tworzenie obrazu kodu kreskowego

Jeśli potrzebujesz **przykładu generatora kodów kreskowych** w C#, ten przewodnik pokaże Ci dokładnie, jak wygenerować kod Planet i stworzyć obraz kodu kreskowego w C# w zaledwie kilku linijkach kodu. Zobaczysz kompletną, gotową do uruchomienia rozwiązanie, które możesz wstawić do dowolnego projektu .NET.

Kod Planet jest używany przez usługi pocztowe do kodowania informacji o trasie. Po zakończeniu tego samouczka zrozumiesz, dlaczego biblioteka automatycznie określa wysokość kodu kreskowego, jak kontrolować wymiar X oraz jak zapisać wynik jako plik PNG. Nie są wymagane żadne zewnętrzne narzędzia — wystarczy pakiet Aspose.BarCode for .NET oraz środowisko programistyczne .NET.

## Wymagania wstępne

Przed rozpoczęciem upewnij się, że masz:

* .NET 6.0 SDK lub nowszy zainstalowany  
* Visual Studio 2022 (lub dowolne IDE obsługujące .NET)  
* Pakiet **Aspose.BarCode for .NET** NuGet (`Aspose.BarCode`)  

Możesz zainstalować pakiet z wiersza poleceń:

```bash
dotnet add package Aspose.BarCode
```

## Krok 1: Inicjalizacja generatora kodów kreskowych dla kodowania Planet

Pierwszy krok w każdym **przykładzie generatora kodów kreskowych** polega na utworzeniu instancji `BarcodeGenerator` i określeniu typu kodowania. Dla kodu Planet używasz `EncodeTypes.Planet` i przekazujesz ciąg danych, który chcesz zakodować.

```csharp
using Aspose.BarCode.Generation;

// Create a Planet barcode generator with the data to encode
BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

**Dlaczego to ważne:** Enum `EncodeTypes.Planet` informuje bibliotekę, że ma używać symboliki Planet, która ma stały wzorzec modułów wymagany przez standardy pocztowe. Podanie danych (`"123456"` w tym przypadku) zapewnia, że kod kreskowy zawiera prawidłowy numeryczny kod trasy.

## Krok 2: Konfiguracja wymiaru X (szerokość modułu) w pikselach

Wymiar X kontroluje szerokość każdego pojedynczego modułu (najmniejszego paska). Dostosowanie go zmienia ogólny rozmiar kodu kreskowego bez wpływu na czytelność.

```csharp
// Set the X dimension (module width) to 4 pixels
generator.Parameters.Barcode.XDimension.Pixels = 4;
```

**Dlaczego to ważne:** Większy wymiar X powoduje większy kod kreskowy, co może być przydatne przy drukowaniu na dużych kopertach. Biblioteka automatycznie skaluje wysokość, aby zachować prawidłowy współczynnik proporcji dla kodów Planet.

## Krok 3: Zapis obrazu kodu kreskowego na dysku

Na koniec zapisujesz wygenerowany obraz. Biblioteka określa optymalną wysokość, więc musisz podać jedynie ścieżkę wyjściową i format.

```csharp
using Aspose.BarCode;

// Define the output file path
string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";

// Save the barcode as a PNG image
generator.Save(outputFile, BarCodeImageFormat.Png);
```

**Dlaczego to ważne:** Zapis w formacie PNG zachowuje ostre krawędzie kodu kreskowego, co jest niezbędne do niezawodnego skanowania. Metoda `Save` obsługuje także inne formaty (JPEG, BMP, TIFF), jeśli potrzebujesz innego wyjścia.

### Oczekiwany wynik

Po uruchomieniu kodu znajdziesz plik o nazwie **PlanetAutoHeight.png** w `C:\Barcodes`. Obraz będzie wyglądał podobnie do ilustracji poniżej (tekst alternatywny: *przykład generatora kodów kreskowych pokazujący kod Planet*).

## Krok 4: Opcjonalnie – dostosowanie kolorów pierwszego planu i tła

Jeśli Twoja aplikacja wymaga innego stylu wizualnego, możesz zmienić kolory kodu kreskowego przed zapisem.

```csharp
// Set foreground (bars) to dark blue and background to light gray
generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

// Save the customized image
generator.Save(@"C:\Barcodes\PlanetCustomColors.png", BarCodeImageFormat.Png);
```

**Wskazówka:** Zawsze testuj dostosowany kod kreskowy rzeczywistym skanerem, aby potwierdzić, że zmiana kolorów nie wpływa na czytelność.

## Krok 5: Obsługa błędów i walidacja

Biblioteka Aspose.BarCode rzuca `ArgumentException`, jeśli dane nie spełniają wymagań symboliki Planet (np. znaki nienumeryczne). Owiń kod generujący w blok try‑catch, aby zapewnić czytelny komunikat.

```csharp
try
{
    BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "ABC123");
    generator.Save(@"C:\Barcodes\InvalidPlanet.png", BarCodeImageFormat.Png);
}
catch (ArgumentException ex)
{
    Console.WriteLine($"Invalid data for Planet barcode: {ex.Message}");
}
```

**Dlaczego to ważne:** Kody Planet akceptują wyłącznie dane numeryczne o określonych długościach. Prawidłowa walidacja zapobiega awariom w czasie wykonywania i oszczędza czas podczas testów integracyjnych.

## Pełny, gotowy do uruchomienia przykład

Połączenie wszystkich kroków daje Ci samodzielny program, który możesz skopiować, wkleić i uruchomić.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;
using Aspose.BarCode;

class Program
{
    static void Main()
    {
        // Step 1: Initialize the generator with Planet encoding
        BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, "123456");

        // Step 2: Set the X dimension (module width) to 4 pixels
        generator.Parameters.Barcode.XDimension.Pixels = 4;

        // Optional: customize colors (comment out if not needed)
        // generator.Parameters.Barcode.BarColor = System.Drawing.Color.DarkBlue;
        // generator.Parameters.Barcode.BackgroundColor = System.Drawing.Color.LightGray;

        // Step 3: Save the barcode image
        string outputFile = @"C:\Barcodes\PlanetAutoHeight.png";
        generator.Save(outputFile, BarCodeImageFormat.Png);

        Console.WriteLine($"Planet barcode saved to {outputFile}");
    }
}
```

Kompiluj i uruchom program:

```bash
dotnet run
```

Powinieneś zobaczyć komunikat w konsoli potwierdzający lokalizację pliku, a plik PNG będzie zawierał wygenerowany kod Planet.

## Typowe warianty i przypadki brzegowe

| Wariant | Jak zaimplementować | Kiedy używać |
|-----------|------------------|------------|
| **Różna długość danych** | Zmieniamy drugi argument w `new BarcodeGenerator(EncodeTypes.Planet, "987654321")` | Usługi pocztowe wymagające dłuższych numerów tras |
| **Wyższa rozdzielczość** | Ustaw `generator.Parameters.ImageResolution = 300;` przed `Save` | Drukowanie na drukarkach o wysokiej rozdzielczości (dpi) |
| **Inny format obrazu** | Użyj `BarCodeImageFormat.Jpeg` lub `BarCodeImageFormat.Tiff` | Gdy PNG nie jest odpowiedni dla Twojego przepływu pracy |
| **Dynamiczna nazwa pliku** | `string outputFile = Path.Combine(folder, $"Planet_{DateTime.Now:yyyyMMdd_HHmmss}.png");` | Przetwarzanie wsadowe wielu kodów kreskowych |

## Profesjonalne wskazówki dla solidnego przykładu generatora kodów kreskowych

* **Ponowne użycie instancji generatora** przy tworzeniu wielu kodów kreskowych o tych samych ustawieniach; zmieniaj jedynie `EncodeTypes` lub ciąg danych, aby poprawić wydajność.  
* **Waliduj dane wejściowe** przed przekazaniem ich do `BarcodeGenerator`. Proste wyrażenie regularne takie jak `^\d{6,9}$` zapewnia, że dane spełniają wymagania Planet.  
* **Zwalniaj zasoby** jeśli generujesz tysiące obrazów w długotrwale działającej usłudze. `BarcodeGenerator` implementuje `IDisposable`, więc owiń go w blok `using`, gdy ma to sens.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.Planet, data))
{
    // configure and save...
}
```
