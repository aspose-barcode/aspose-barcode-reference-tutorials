# Jak wygenerować obraz kodu kreskowego w C# z DataBar Stacked Omni‑Directional

Jeśli potrzebujesz **jak wygenerować obraz kodu kreskowego** w aplikacji .NET, ten tutorial pokazuje dokładne kroki. Zobaczysz, jak stworzyć kod kreskowy DataBar Stacked Omni‑Directional, dostosować jego współczynnik proporcji i wyeksportować wynik jako pliki PNG.

Generowanie kodów kreskowych jest powszechnym wymogiem dla systemów inwentaryzacji, terminali sprzedaży detalicznej oraz śledzenia logistycznego. W kolejnych sekcjach omówimy wszystko, czego potrzebujesz — od wymaganego pakietu NuGet po ostateczną weryfikację obrazu — abyś mógł zintegrować tworzenie kodów kreskowych w dowolnym projekcie C# już dziś.

## Prerequisites

Before you start, make sure you have:

* .NET 6.0 lub nowszy (kod działa z .NET Core i .NET Framework)
* Visual Studio 2022 lub dowolne IDE C#, które preferujesz
* Pakiet NuGet **Aspose.BarCode for .NET** (zainstaluj przy pomocy `dotnet add package Aspose.BarCode`)
* Uprawnienia do zapisu w folderze, w którym będą zapisywane pliki PNG

These prerequisites guarantee that the sample runs without additional configuration.

## Step 1: Set up the output folder

The first thing you need is a directory where the generated PNG files will be written. Using an absolute or relative path works, but ensure the folder exists before you call `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Creating the folder programmatically prevents *FileNotFoundException* when the `Save` method tries to write the image.

## Step 2: Create a DataBar Stacked Omni‑Directional barcode generator

The **BarcodeGenerator** class is the entry point for all barcode types. Here we specify `EncodeTypes.DatabarStackedOmniDirectional` and the data string we want to encode.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Dlaczego to ważne*: Enum `EncodeTypes` informuje bibliotekę, którą symbologię ma renderować. Użycie wariantu Omni‑Directional zapewnia, że kod kreskowy może być odczytany z dowolnej orientacji — wymóg wielu skanerów magazynowych.

## Step 3: Configure common barcode parameters

A readable barcode needs a sensible X‑dimension (the width of the smallest bar). Setting `Pixels` to 2 gives a good balance between size and clarity for most screen resolutions.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

You can adjust `Pixels` later if you need a larger or smaller image; the library automatically scales the rest of the barcode.

## Step 4: Generate the first image with aspect ratio 15

**Współczynnik proporcji** controls the height‑to‑width relationship of DataBar barcodes. An aspect ratio of 15 is a typical default for retail labels.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

After this call, you’ll find `DatabarAspectRatio15.png` in the output folder. The image is a lossless PNG, suitable for further processing or printing.

## Step 5: Change the aspect ratio to 30 and export a second image

Sometimes a taller barcode is required—for example, when the label height is limited. Changing the aspect ratio to 30 produces a more compact visual while preserving data integrity.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Now you have two PNG files that illustrate how the same data looks with different aspect ratios. This side‑by‑side comparison helps you decide which variant fits your label layout best.

## Full, runnable example

Below is the complete program that you can copy, paste, and run. It includes all `using` directives, error handling, and comments that explain each part of the process.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Oczekiwany wynik** (konsola):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Open the two PNG files in any image viewer. You’ll see the same GTIN encoded, but the second image is taller because of the higher aspect ratio.

## Pro tips and common pitfalls

| Sytuacja | Zalecenie |
|-----------|----------------|
| **Ekrany o niskiej rozdzielczości** | Zwiększ `XDimension.Pixels` do 3 lub 4, aby słupki pozostały ostre. |
| **Druk na papierze termicznym** | Użyj `BarCodeImageFormat.Tiff` dla wyższej jakości i ustaw `Resolution.DpiX/DpiY` na 300. |
| **Dane dynamiczne** | Ponownie użyj tej samej instancji `BarcodeGenerator` i aktualizuj jedynie `generator.CodeText` przed każdym `Save`. Zapobiega to niepotrzebnemu przydzielaniu obiektów. |
| **Nieprawidłowy GTIN** | Biblioteka zgłasza `ArgumentException`, jeśli dane nie spełniają standardów GS1. Zweryfikuj swoje dane przed przekazaniem ich do generatora. |
