# Utwórz kod kreskowy Planet w C# – kompletny przewodnik programistyczny

Jeśli potrzebujesz **utworzyć kod kreskowy planet** w C#, ten przewodnik pokaże Ci dokładnie, jak to zrobić. Odkryjesz także **jak ustawić wymiary kodu kreskowego**, aby paski miały dokładnie taką szerokość, jaką potrzebujesz.

Generowanie kodów kreskowych Planet jest powszechne, gdy pracujesz z usługami pocztowymi lub systemami logistycznymi. Poniższy kod obejmuje zarówno domyślną wersję z wypełnionymi paskami, jak i opcjonalny styl z pustymi paskami, a także szybki przykład formatu RM4SCC. Po zakończeniu tego samouczka będziesz mieć wielokrotnego użytku fragment, który możesz wkleić do dowolnego projektu .NET.

## Wymagania wstępne

Zanim rozpoczniesz, upewnij się, że masz:

* .NET 6.0 lub nowszy zainstalowany (API działa również z .NET Framework 4.6+)
* Pakiet NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`) dodany do projektu
* Ścieżkę do zapisu, w której można zapisywać pliki PNG
* Podstawową znajomość składni C# oraz Visual Studio (lub dowolnego IDE)

> **Pro tip:** Użyj ścieżki bezwzględnej lub `Path.Combine(Environment.CurrentDirectory, "output")`, aby uniknąć problemów z uprawnieniami przy zapisywaniu obrazów.

## Krok 1 – Zainicjuj generator kodu kreskowego Planet (wypełnione paski)

Pierwszym krokiem jest utworzenie instancji `BarcodeGenerator` dla symbologii Planet. Domyślnie generator tworzy **wypełnione** paski.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Enum `EncodeTypes.Planet` informuje Aspose.BarCode, że ma używać formatu Planet, a `"123456"` to ładunek danych, który zostanie zakodowany.

## Krok 2 – Jak ustawić wymiary kodu kreskowego dla spójnego rozmiaru

Aby kontrolować szerokość każdego paska, dostosuj **X‑dimension**. To podstawowy sposób **ustawiania wymiarów kodu kreskowego** i zapewnia, że kod zmieści się na etykiecie.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

Właściwość `Pixels` definiuje szerokość paska w pikselach ekranu. Typowe wartości to 2 – 5 pikseli dla standardowych etykiet pocztowych; zwiększ wartość dla większych wydruków.

## Krok 3 – Zapisz wypełniony kod kreskowy Planet jako PNG

Teraz zapisz obraz na dysku. PNG zachowuje ostre krawędzie, co jest idealne do skanowania.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Zastąp `YOUR_DIRECTORY` ścieżką przygotowaną wcześniej. Po uruchomieniu tego kodu zobaczysz plik podobny do obrazu poniżej.

## Krok 4 – Utwórz kod kreskowy Planet z pustymi (niewypełnionymi) paskami

Jeśli Twój operator pocztowy wymaga **pustych** pasków, musisz przełączyć flagę `FilledBars` po zainicjowaniu generatora.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Konstruktor jest identyczny; różnica pojawia się w następnym kroku konfiguracji.

## Krok 5 – Jak ustawić wymiary kodu kreskowego i zrobić paski puste

Ponownie ustaw X‑dimension dla spójności wizualnej, a następnie wyłącz wypełnione paski.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

Właściwość `FilledBars = false` to właśnie to, co zmienia styl renderowania. Zachowanie tej samej X‑dimension zapewnia, że kod kreskowy z pustymi paskami idealnie wyrównuje się z wersją wypełnioną.

## Krok 6 – Zapisz pusty kod kreskowy Planet

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Teraz będziesz mieć dwa pliki PNG: jeden z solidnymi paskami i jeden z pustymi paskami, oba o tych samych wymiarach.

## Krok 7 – (Opcjonalnie) Wygeneruj kod kreskowy RM4SCC dla porównania

RM4SCC to inna symbologia pocztowa, która używa tego samego domyślnego stylu wypełnionych pasków. Kroki są analogiczne do przykładu Planet, co pokazuje, że **jak ustawić wymiary kodu kreskowego** działa w różnych formatach.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Wykonanie tych trzech kroków tworzy plik `PostalRM4SCCFilledBars.png`, który możesz porównać obok wyników Planet.

## Dlaczego X‑dimension ma znaczenie

X‑dimension określa **minimalną drukowaną szerokość** każdego paska. Jeśli ustawisz ją zbyt nisko, kod kreskowy może rozmywać się na drukarkach o niskiej rozdzielczości, co prowadzi do niepowodzeń skanowania. Z kolei zbyt duża X‑dimension może przekroczyć wymiary etykiety i zmarnować miejsce. Dzięki wyraźnemu **jak ustawić wymiary kodu kreskowego** zyskujesz deterministyczną kontrolę nad ostatecznym rozmiarem obrazu, co jest niezbędne w zautomatyzowanych procesach wysyłkowych.

## Typowe pułapki i jak ich unikać

| Problem | Przyczyna | Rozwiązanie |
|-------|-------|-----|
| Kod kreskowy wygląda na rozciągnięty | X‑dimension ustawiona w punktach zamiast w pikselach | Zawsze używaj właściwości `Pixels` dla kontroli w pikselach |
| Puste paski nadal wyglądają na wypełnione | `FilledBars` nie ustawiono na `false` po zmianie X‑dimension | Ustaw `FilledBars = false` *po* dostosowaniu X‑dimension |
| Zapisany plik jest pusty | Katalog wyjściowy nie istnieje lub brak uprawnień do zapisu | Upewnij się, że katalog istnieje (`Directory.CreateDirectory`) i aplikacja ma odpowiednie prawa |
| Obraz jest rozmazany przy druku | PNG o niskim DPI zapisany z monitora o wysokiej rozdzielczości | Użyj `BarCodeImageFormat.Png` (bezstratny) i rozważ właściwość `Resolution`, jeśli potrzebne |

## Pełny, gotowy do uruchomienia przykład

Skopiuj cały blok poniżej do nowego projektu konsolowego (`dotnet new console`) i uruchom go. Program tworzy trzy pliki PNG w folderze `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Oczekiwany wynik:** trzy pliki PNG — `PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` oraz `PostalRM4SCCFilledBars.png` — każdy z paskami o szerokości 4 piksele, gotowe do druku lub dalszego przetwarzania.

## Podsumowanie

Teraz wiesz, jak **utworzyć kod kreskowy planet** w C# oraz precyzyjnie **ustawić wymiary kodu kreskowego** zarówno dla stylu wypełnionego, jak i pustego. Ten sam wzorzec działa dla innych symbologii, takich jak RM4SCC, dając Ci elastyczną bazę dla każdego wymogu kodów kreskowych pocztowych.

Następnie możesz rozważyć:

* Dodanie tekstu czytelnego dla człowieka pod kodem kreskowym (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* Zmianę kolorów pasków przy użyciu `Parameters.Barcode.BarColor`
* Generowanie kodów kreskowych w formatach wektorowych (SVG, EPS) dla skalowalnego druku

Śmiało eksperymentuj z różnymi wartościami X‑dimension, ciągami danych i formatami wyjściowymi, aby dopasować je do swojego konkretnego przepływu pracy. Powodzenia w kodowaniu!
