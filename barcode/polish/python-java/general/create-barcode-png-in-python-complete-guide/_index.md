# Utwórz barcode PNG w Pythonie – Kompletny przewodnik

Czy kiedykolwiek potrzebowałeś **create barcode PNG**, ale nie byłeś pewien, której biblioteki lub ustawień użyć? Nie jesteś sam. W wielu systemach inwentaryzacji lub kas pierwszym krokiem jest przekształcenie surowych danych w wyraźny obraz PNG, który skanery uwielbiają.

## Utwórz barcode PNG – Konfiguracja generatora

Na początek potrzebujemy obiektu generatora, który wie, że pracujemy z kodem **DataBar Omnidirectional**. Poniższy kod importuje niezbędne klasy, tworzy generator z **barcode with sample data** i ustawia umiarkowany rozmiar modułu.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Dlaczego to ważne:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` instruuje silnik, aby wygenerował **DataBar**, który może być odczytany z dowolnego kierunku, idealny dla półek detalicznych. Ustawienie `x_dimension` utrzymuje paski ostre, natomiast `bar_height` kontroluje wizualny rozmiar kodu.

## Jak wygenerować Databar z przykładowymi danymi

Teraz, gdy generator jest gotowy, **create barcode PNG** pliki. Pierwsze zapisanie używa wysokości 30 pikseli, co często wystarcza do podglądu na ekranie.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Uruchomienie skryptu do tego momentu wygeneruje plik PNG wyglądający jak kompaktowy, wysokokontrastowy kod kreskowy. Otwórz go w dowolnym przeglądarce obrazów, aby sprawdzić, że paski są ostre, a dane GTIN‑14 są zakodowane.

## Dostosuj wysokość kodu kreskowego (How to Change Barcode)

Czasami potrzebny jest wyższy kod kreskowy dla większych etykiet lub druku o wyższej rozdzielczości. W tym miejscu wkracza **adjust barcode height**. Zmiana wysokości jest tak prosta, jak aktualizacja właściwości `BarHeight` i ponowne zapisanie.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Jak to działa:** Generator ponownie używa tych samych danych i rozmiaru modułu; zmienia się tylko wymiar pionowy. To unika ponownego tworzenia całego obiektu i pokazuje **how to change barcode** ustawienia dynamicznie.

## Pełny skrypt – Kompleksowe rozwiązanie

Poniżej znajduje się kompletny, gotowy do uruchomienia skrypt, który łączy wszystkie kroki. Skopiuj, wklej i uruchom — powinien działać od razu po zainstalowaniu pakietu.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Oczekiwany wynik

Uruchomienie skryptu wygeneruje dwa pliki:

- `DatabarOmni30.png` – 30 px wysoki kod DataBar Omnidirectional.  
- `DatabarOmni60.png` – 60 px wysoka wersja tego samego kodu.

Oba obrazy są w formacie PNG, bezstratnym, i gotowe do osadzenia w PDF‑ach, stronach HTML lub bezpośredniego druku na etykietach.

## Częste pułapki i profesjonalne wskazówki

- **Pixel vs. DPI:** Pliki PNG są oparte na pikselach. Jeśli potrzebujesz konkretnego rozmiaru druku, oblicz `BarHeight` na podstawie DPI (np. 300 dpi → 30 px ≈ 0.1 in).  
- **Incorrect encoding:** Upewnij się, że ciąg danych spełnia format identyfikatora aplikacji GS1 (`(01)` dla GTIN‑14). Brak nawiasów może spowodować, że biblioteka przełączy się na zwykły numeryczny kod kreskowy.  
- **File paths:** Używaj surowych łańcuchów (`r"..."`) lub podwójnych backslashy w Windows, aby uniknąć problemów z znakami ucieczki.  
- **Performance:** Jeśli generujesz tysiące kodów, utwórz generator raz i modyfikuj jedynie `BarHeight` lub ciąg danych pomiędzy zapisami. To zmniejsza obciążenie pamięci.
