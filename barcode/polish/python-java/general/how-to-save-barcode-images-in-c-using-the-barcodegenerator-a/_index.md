# Jak zapisywać obrazy kodów kreskowych w C# przy użyciu API BarcodeGenerator

Jeśli potrzebujesz **how to save barcode** plików z aplikacji .NET, ten przewodnik pokazuje dokładne kroki. Zobaczysz kompletny **barcode generator example**, który tworzy kod kreskowy DataBar Stacked Omnidirectional, dostosowuje jego współczynnik proporcji i zapisuje dwa pliki PNG.

Zapisywanie obrazów kodów kreskowych jest powszechnym wymogiem przy budowaniu systemów inwentaryzacji, terminali punktu sprzedaży lub zautomatyzowanych procesów etykietowania. Po zakończeniu tego samouczka będziesz mógł generować kod C# dla kodów kreskowych, który tworzy niezawodne obrazy gotowe do druku lub wyświetlenia.

## Wymagania wstępne

Zanim rozpoczniesz, upewnij się, że masz:

- .NET 6.0 SDK lub nowszy zainstalowany  
- Visual Studio 2022 (lub dowolne IDE kompatybilne z C#)  
- Pakiet NuGet **Aspose.BarCode for .NET** (kod używa `Aspose.BarCode.Generation`)  

Możesz dodać pakiet za pomocą następującego polecenia:

```bash
dotnet add package Aspose.BarCode
```

## Krok 1: Utwórz minimalny projekt konsolowy C#

Utwórz nowy projekt konsolowy i odwołaj się do biblioteki:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Otwórz `Program.cs`. Plik będzie zawierał metodę `Main`, w której umieścimy logikę **generate barcode C#**.

## Krok 2: Zainicjalizuj BarcodeGenerator dla kodu DataBar Stacked Omnidirectional

Pierwszym zadaniem w każdym przepływie **create databar barcode** jest utworzenie instancji `BarcodeGenerator` z odpowiednim `EncodeType`. Konstruktor przyjmuje symbologię kodu kreskowego oraz ciąg danych.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

Wartość `EncodeTypes.DatabarStackedOmniDirectional` informuje bibliotekę, aby wygenerowała **create databar barcode**, który może być skanowany z dowolnego kierunku.

## Krok 3: Skonfiguruj wymiar X (szerokość modułu)

Wymiar X kontroluje najmniejszą szerokość kreski w pikselach. Ustawienie niskiej wartości utrzymuje kod kreskowy kompaktowy, zachowując jednocześnie czytelność.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Krok 4: **How to adjust aspect ratio** – pierwsza wartość (15)

Kody DataBar udostępniają właściwość `AspectRatio`, która wpływa na stosunek wysokości do szerokości. Wyższy współczynnik daje wyższy kod kreskowy, co może poprawić niezawodność skanowania na niektórych drukarkach.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Krok 5: **How to save barcode** – pierwszy obraz (współczynnik 15)

Teraz faktycznie **how to save barcode** do pliku. Metoda `Save` przyjmuje ścieżkę pliku oraz format obrazu. W tym przykładzie zapisujemy plik PNG.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Wskazówka:** Katalog wykonywalnego pliku jest domyślną lokalizacją zapisu. Użyj ścieżki bezwzględnej, jeśli potrzebujesz konkretnego folderu.

## Krok 6: **How to adjust aspect ratio** – druga wartość (30)

Aby pokazać elastyczność, zmień współczynnik proporcji i zapisz drugi obraz. To pokazuje, jak te same zakodowane dane mogą być renderowane z różnymi proporcjami wizualnymi.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Uruchomienie programu generuje dwa pliki PNG:

- `DatabarAspectRatio15.png` – kod kreskowy o umiarkowanej wysokości  
- `DatabarAspectRatio30.png` – kod kreskowy o większej wysokości dla trudnych warunków skanowania  

Oba pliki są gotowe do załadowania do kontrolek UI, wydrukowania na etykietach lub przesłania przez API.

### Oczekiwany wynik

Po otwarciu wygenerowanych obrazów powinieneś zobaczyć kod DataBar Stacked Omnidirectional, który koduje wartość GTIN‑14 `12345678901231`. Różnica wizualna między dwoma plikami polega wyłącznie na wysokości, co potwierdza, że **how to adjust aspect ratio** działa zgodnie z zamierzeniami.

## Krok 7: Pełny kod źródłowy do odniesienia

Poniżej znajduje się kompletny, gotowy do uruchomienia program. Skopiuj go do `Program.cs`, zbuduj i uruchom.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Częste pytania i obsługa przypadków brzegowych

### Co zrobić, jeśli docelowy folder nie istnieje?

`Save` zgłasza `DirectoryNotFoundException`. Najpierw utwórz katalog:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### Jak zmienić format obrazu?

Zastąp `BarCodeImageFormat.Png` przez `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` lub `BarCodeImageFormat.Tiff` w zależności od wymagań downstream.

### Czy mogę generować wiele kodów kreskowych w pętli?

Tak. Utwórz nowy `BarcodeGenerator` dla każdego ciągu danych lub ponownie użyj tej samej instancji po zaktualizowaniu właściwości `CodeText`:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### Czy **how to save barcode** działa na platformach nie‑Windowsowych?

Aspose.BarCode jest wieloplatformowy. Ten sam kod działa na Linuksie i macOS, o ile dostępny jest środowisko uruchomieniowe .NET.
