# Jak utworzyć kod kreskowy RM4SCC i wygenerować kod kreskowy Planet w C#

Jeśli potrzebujesz **utworzyć kod kreskowy RM4SCC** do zastosowań pocztowych, ten przewodnik pokaże Ci dokładne kroki. Dowiesz się także, jak **generować kod kreskowy Planet** zarówno z automatyczną, jak i stałą wysokością, tak aby ten sam kod działał dla dowolnej symbologii pocztowej.

Samouczek obejmuje wszystko, co potrzebne do tworzenia obrazów PNG spełniających standardy pocztowe. Nie są potrzebne żadne zewnętrzne narzędzia poza biblioteką Aspose.BarCode for .NET. Po zakończeniu będziesz mógł generować kody kreskowe programowo i precyzyjnie kontrolować ich wymiary.

## Wymagania wstępne

Przed rozpoczęciem upewnij się, że masz:

* .NET 6.0 lub nowszy zainstalowany
* Visual Studio 2022 (lub dowolne IDE C#)
* Pakiet NuGet Aspose.BarCode for .NET  
  `Install-Package Aspose.BarCode`
* Uprawnienia zapisu do katalogu wyjściowego

Te elementy pozwalają kompilować i uruchamiać przykładowy kod bez dodatkowej konfiguracji.

## Krok 1: Zainicjalizuj generator kodów kreskowych dla RM4SCC

Pierwsza operacja tworzy instancję `BarcodeGenerator` skonfigurowaną dla symbologii RM4SCC. Ten obiekt przechowuje wszystkie ustawienia obrazu kodu kreskowego.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Dlaczego to ważne** – `EncodeTypes.RM4SCC` informuje Aspose, aby używał pocztowego formatu RM4SCC, a ciąg danych `"123456"` reprezentuje kod pocztowy, który chcesz zakodować.

## Krok 2: Ustaw szerokość modułu (wymiar X)

Szerokość modułu kontroluje rozmiar cienkiej kreski. Typowa wartość dla kodów kreskowych pocztowych to 4 piksele.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Wyjaśnienie** – Wymiar X wpływa na ogólną czytelność kodu kreskowego. Wybranie 4 px odpowiada większości skanerów pocztowych.

## Krok 3: Zapisz z automatyczną wysokością kreski

Gdy pomijasz wartość wysokości, Aspose automatycznie oblicza optymalną wysokość na podstawie reguł symbologii.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Wynik** – Wygenerowany PNG (`PostalRM4SCCBarHeightNone.png`) zawiera prawidłowo wymiarowany kod kreskowy RM4SCC gotowy do druku.

## Krok 4: Utwórz kod kreskowy Planet z automatyczną wysokością

Ten sam wzorzec działa dla symbologii Planet. Rozpocznij od zainicjalizowania generatora przy użyciu `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Dlaczego ponownie używać kodu** – Zarówno RM4SCC, jak i Planet mają tę samą strukturę parametrów, więc możesz przełączać symbologie, zmieniając jedynie wartość `EncodeTypes`.

## Krok 5: Zdefiniuj stałą wysokość kreski dla RM4SCC

Niektóre usługi pocztowe wymagają określonej wysokości kreski (np. 100 px). Możesz ustawić to wyraźnie przed zapisem.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Wskazówka** – Ustawienie `BarHeight.Pixels` nadpisuje automatyczne obliczenia, dając pełną kontrolę nad rozmiarem wizualnym.

## Krok 6: Zdefiniuj stałą wysokość kreski dla Planet

Zastosuj tę samą technikę stałej wysokości do kodu kreskowego Planet.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Wynik** – Zarówno `PostalRM4SCCBarHeight100Pixels.png`, jak i `PostalPlanetBarHeight100Pixels.png` zawierają kody kreskowe o jednolitej wysokości kreski 100 px, spełniając rygorystyczne specyfikacje pocztowe.

## Pełny kod źródłowy

Poniżej znajduje się pełny, działający program obejmujący wszystkie cztery przykłady. Skopiuj go do nowego projektu konsolowego i w razie potrzeby dostosuj ścieżkę wyjściową.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Oczekiwany wynik** – Po uruchomieniu programu, wskazany katalog zawiera cztery pliki PNG:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC z automatyczną wysokością
* `PostalPlanetBarHeightNone.png` – Planet z automatyczną wysokością
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC z wysokością 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet z wysokością 100 px

Otwórz dowolny plik, aby zweryfikować, że kreski są ostre, szerokość modułu wynosi 4 px, a wysokość odpowiada wybranemu ustawieniu.

## Częste pytania i przypadki brzegowe

| Pytanie | Odpowiedź |
|----------|--------|
| **Czy mogę używać innych formatów obrazu?** | Tak. Zastąp `BarCodeImageFormat.Png` przez `Jpeg`, `Bmp` lub `Gif` w zależności od potrzeb. |
| **Co jeśli ciąg danych jest dłuższy?** | Generator automatycznie dostosowuje liczbę kresek. Upewnij się, że dane spełniają limity długości symbologii (RM4SCC ≤ 6 cyfr, Planet ≤ 6 cyfr). |
| **Jak zmienić kolor kreski?** | Ustaw `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` przed wywołaniem `Save`. |
| **Czy DPI jest ważne przy drukowaniu?** | Możesz ustawić `rm4sccAuto.Parameters.ImageResolution.DpiX` i `DpiY`, aby dopasować je do rozdzielczości Twojej drukarki. |
