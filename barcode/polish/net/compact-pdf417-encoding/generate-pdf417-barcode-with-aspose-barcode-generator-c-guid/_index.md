# Generowanie kodu kreskowego PDF417 przy użyciu Aspose Barcode Generator – przewodnik C# guide

Jeśli potrzebujesz **generować kod kreskowy PDF417** w projekcie .NET, ten samouczek pokaże Ci dokładnie, jak to zrobić przy użyciu **Aspose Barcode Generator**. Zobaczysz kompletny, gotowy do uruchomienia przykład, który tworzy kompaktowy symbol PDF417, dostosowuje jego rozmiar i zapisuje wynik jako plik PNG.

Generowanie kodu kreskowego PDF417 jest powszechne, gdy trzeba zakodować duże ilości danych — takich jak adresy URL, informacje kontaktowe czy rekordy inwentaryzacyjne — w jednym, skanowalnym obrazie. Ten przewodnik obejmuje wszystko, od instalacji biblioteki po dostosowanie **how to set PDF417** opcji dla kompaktowego wyniku.

## Czego się nauczysz

* Zainstaluj i odwołaj się do biblioteki Aspose.BarCode w projekcie C#.
* Użyj **aspose barcode generator**, aby utworzyć symbol PDF417 z dowolnego tekstu.
* Zastosuj parametry **how to set PDF417** — rozmiar modułu, liczbę kolumn i tryb kompaktowy.
* Zapisz kod kreskowy jako obraz PNG i zweryfikuj wynik.  

**Wymagania wstępne**

* .NET 6.0 SDK lub nowszy (kod działa również z .NET Core 3.1 i .NET Framework 4.7+).  
* Podstawowa znajomość aplikacji konsolowych C#.  
* Ważna licencja Aspose.BarCode (darmowa wersja ewaluacyjna działa w środowisku deweloperskim).

## Krok 1: Generowanie kodu kreskowego PDF417 – utworzenie generatora

Pierwszym zadaniem jest utworzenie instancji generatora z żądanym tekstem i symboliką PDF417. Ten krok bezpośrednio odpowiada na pytanie **how to generate pdf417**.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Create a BarcodeGenerator for PDF417 with the data you want to encode.
            // The EncodeTypes enum selects the symbology; Pdf417 is the target type.
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");
```

**Dlaczego to jest ważne:**  
`EncodeTypes.Pdf417` informuje bibliotekę, aby użyła algorytmu PDF417, który obsługuje do 1 850 znaków. Konstruktor przyjmuje również surowy ciąg danych; wszystkie znaki Unicode (w tym akcenty) są obsługiwane automatycznie.

## Krok 2: Jak ustawić parametry PDF417 – dostosowanie rozmiaru i układu

Kod kreskowy PDF417 może być renderowany w wielu kształtach. Dostosowanie opcji **how to set pdf417** pozwala stworzyć kompaktowy symbol, który zmieści się na małej etykiecie lub ekranie mobilnym.

```csharp
            // -----------------------------------------------------------------
            // Step 2: Set visual parameters for the barcode
            // -----------------------------------------------------------------

            // Module size – each tiny square (pixel) of the barcode.
            // Smaller values produce a tighter image; 2 pixels is a good default.
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Number of columns – controls the width of the barcode.
            // Fewer columns make the symbol taller; 3 columns yields a compact shape.
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode – removes unnecessary quiet zones and reduces height.
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Wyjaśnienie każdego ustawienia**

| Parametr | Efekt | Kiedy używać |
|----------|-------|--------------|
| `XDimension.Pixels` | Kontroluje szerokość pojedynczego modułu. Niższe wartości zmniejszają kod kreskowy, ale mogą wpływać na czytelność skanera na urządzeniach o niskiej rozdzielczości. | Użyj `2`–`4` do wyświetlania na ekranie; zwiększ dla drukowanych etykiet. |
| `Pdf417.Columns` | Określa liczbę kolumn danych w symbolu. Mniej kolumn daje wyższy, węższy kod kreskowy. | Wybierz `3`–`5` dla kompaktowych układów; wyższe wartości dla szerszych kodów. |
| `Pdf417.Truncate` | Włącza „tryb kompaktowy”, który usuwa zewnętrzną strefę ciszy i zmniejsza całkowitą wysokość. | Idealny dla elementów UI, gdzie miejsce jest ograniczone. |

Te trzy ustawienia razem odpowiadają na część zadania **how to set pdf417**, dając precyzyjną kontrolę nad ostatecznym obrazem.

## Krok 3: Zapisz obraz kodu kreskowego – eksport jako PNG

Po skonfigurowaniu generatora musisz zapisać kod kreskowy do pliku. Metoda `Save` obsługuje wiele formatów; PNG zachowuje jakość bezstratną i dobrze sprawdza się zarówno w scenariuszach internetowych, jak i desktopowych.

```csharp
            // -----------------------------------------------------------------
            // Step 3: Save the generated barcode as a PNG image
            // -----------------------------------------------------------------

            // Replace YOUR_DIRECTORY with an actual folder on your machine.
            string outputPath = @"C:\Barcodes\CompactPdf417.png";

            // BarCodeImageFormat.Png tells Aspose to write a PNG file.
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            // Inform the user that the process succeeded.
            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**Co powinieneś zobaczyć**

Uruchomienie programu tworzy `CompactPdf417.png` w określonym folderze. Obraz zawiera gęsty symbol PDF417, który koduje ciąg `Åspóse.Barcóde©`. Większość skanerów kodów kreskowych i aplikacji mobilnych (np. ZXing, Scandit) może odczytać ten obraz bez dodatkowej konfiguracji.

## Pełny kod źródłowy – pojedynczy plik gotowy do skopiowania

Poniżej znajduje się kompletny program, w tym dyrektywy `using` oraz metoda `Main`. Możesz skopiować go do nowego projektu konsolowego i od razu uruchomić.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main(string[] args)
        {
            // Step 1: Create the generator (how to generate pdf417)
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417, "Åspóse.Barcóde©");

            // Step 2: Set PDF417 options (how to set pdf417)
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;   // module size
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;    // number of columns
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact mode

            // Step 3: Save as PNG
            string outputPath = @"C:\Barcodes\CompactPdf417.png";
            pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode saved to: {outputPath}");
        }
    }
}
```

**Uruchamianie kodu**

1. Otwórz terminal i utwórz nowy projekt konsolowy:  
   `dotnet new console -n Pdf417Demo`  
2. Dodaj pakiet NuGet Aspose.BarCode:  
   `dotnet add package Aspose.BarCode`  
3. Zastąp wygenerowany plik `Program.cs` kodem powyżej.  
4. Zbuduj i uruchom:  
   `dotnet run`  

Powinieneś zobaczyć komunikat potwierdzający i znaleźć plik PNG w określonym miejscu.

## Częste pułapki i wskazówki najlepszych praktyk

* **Wygaśnięcie licencji** – Wersja ewaluacyjna dodaje znak wodny po 30 dniach. Zarejestruj licencję wcześnie, aby uniknąć niespodzianek.  
* **Uprawnienia katalogu** – Upewnij się, że docelowy folder istnieje i proces ma dostęp do zapisu; w przeciwnym razie `Save` zgłosi `UnauthorizedAccessException`.  
* **Kompatybilność skanera** – Jeśli skaner nie odczytuje kompaktowego kodu, zwiększ `XDimension.Pixels` do `4` lub ustaw `Truncate = false`.  
* **Obsługa Unicode** – Aspose.BarCode w pełni obsługuje UTF‑8; możesz kodować dowolny ciąg Unicode bez dodatkowych kroków.  
* **Wydajność** – Generowanie wielu kodów w pętli korzysta z ponownego użycia jednej instancji `BarcodeGenerator` i jedynie aktualizowania `CodeText` pomiędzy iteracjami.
