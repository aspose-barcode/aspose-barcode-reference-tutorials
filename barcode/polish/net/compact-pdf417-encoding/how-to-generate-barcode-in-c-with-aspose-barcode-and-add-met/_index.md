# Jak generować kod kreskowy w C# przy użyciu Aspose.BarCode i dodać metadane

Jeśli potrzebujesz **generować kod kreskowy w C#** dla systemu logistycznego lub inwentaryzacji, ten przewodnik pokaże Ci kompletną, gotową do produkcji rozwiązanie. Zobaczysz, jak stworzyć kod Macro PDF417, dołączyć bogate metadane i ustawić precyzyjny znacznik czasu — wszystko przy użyciu biblioteki Aspose.BarCode.

Poradnik obejmuje wszystko, od instalacji pakietu NuGet po zapisanie finalnego obrazu PNG. Po zakończeniu będziesz mógł generować kod kreskowy, który przenosi identyfikatory plików, informacje o segmentach oraz pola niestandardowe, gotowy dla skanerów obsługujących Macro PDF417.

## Prerequisites

Zanim rozpoczniesz, upewnij się, że masz:

* .NET 6.0 SDK lub nowszy (kod działa także z .NET Framework 4.7.2+)
* Visual Studio 2022 lub dowolne IDE C#, które preferujesz
* Aktywna licencja Aspose.BarCode (bezpłatna wersja próbna działa w środowisku deweloperskim)
* Podstawowa znajomość składni C#

> **Wskazówka:** Jeśli używasz potoku CI/CD, dodaj odwołanie do pakietu Aspose.BarCode w pliku projektu, aby kompilacje były powtarzalne.

## Step 1: Install Aspose.BarCode

Otwórz terminal w folderze projektu i uruchom:

```bash
dotnet add package Aspose.BarCode
```

Polecenie pobiera najnowszą stabilną wersję (obecnie 24.9). Po zakończeniu przywracania możesz odwoływać się do biblioteki w swoich plikach źródłowych.

## Step 2: Create a new C# console project (optional)

Jeśli wolisz rozpocząć od nowa, utwórz aplikację konsolową:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Plik `Program.cs` będzie zawierał kod generujący kod kreskowy pokazany później.

## Step 3: Set up the barcode generator

Rdzeniem procesu jest klasa `BarcodeGenerator`. Tworzysz jej instancję, podając żądany enum `EncodeTypes` oraz tekst, który chcesz zakodować.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Dlaczego każdy wiersz ma znaczenie

* **EncodeTypes.MacroPdf417** informuje Aspose, aby wygenerował kod PDF417, który może być podzielony na segmenty. Jest to niezbędne przy dużych ładunkach, które przekraczają pojemność jednego symbolu.
* **XDimension.Pixels** kontroluje gęstość wizualną. Wartość 2 tworzy wyraźny obraz na większości ekranów i drukarek, nie zwiększając rozmiaru pliku.
* **MacroPdf417* properties** osadzają metadane, które skanery odczytują jako oddzielne pola (ID pliku, ID segmentu itp.). To część „jak dodać metadane” w tym poradniku.
* **MacroPdf417TimeStamp** pokazuje „jak ustawić znacznik czasu”. Instancja `DateTime` może być dowolnym czasem UTC; użycie UTC eliminuje niejasności stref czasowych, gdy kod podróżuje między regionami.
* **MacroPdf417Terminator** definiuje, jak kończy się sekwencja makro. `Set` jest najczęściej wybieraną opcją, ponieważ sygnalizuje ostatni segment czytnikowi.
* **Save(..., BarCodeImageFormat.Png)** zapisuje obraz bezstratny, zachowując drobne szczegóły niezbędne do niezawodnego skanowania.

Zeskanowanie obrazu skanerem kompatybilnym z PDF417 (lub aplikacją mobilną obsługującą Macro PDF417) zwróci oryginalny tekst oraz wartości metadanych, które ustawiłeś.

* Strefa ciszy (margines) automatycznie dodana przez Aspose

## Step 5: Common variations and edge cases

### 5.1 Handling special characters

Przykładowy tekst zawiera znaki Unicode (`Å`, `ó`, `©`). Aspose.BarCode koduje je domyślnie w UTF‑8, więc wyświetlają się poprawnie w kodzie kreskowym. Jeśli potrzebujesz innego kodowania (np. ISO‑8859‑1), ustaw:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Large file identifiers

`MacroPdf417FileID` przyjmuje 32‑bitową liczbę całkowitą. Dla wartości większych niż `int.MaxValue` podziel identyfikator na kilka pól lub użyj GUID‑a przechowywanego jako ciąg w `MacroPdf417FileName`.

### 5.3 Adjusting the number of columns

Zwiększenie `Pdf417.Columns` zmniejsza wysokość kodu, ale poszerza każdy wiersz. Jeśli kod musi zmieścić się na wąskiej etykiecie, obniż liczbę kolumn, a liczba wierszy zwiększy się automatycznie.

### 5.4 Saving in other formats

Aspose obsługuje BMP, JPEG, TIFF i SVG. Zamień `BarCodeImageFormat.Png` na żądaną wartość enum, np. `BarCodeImageFormat.Svg` dla grafiki wektorowej skalowalnej.

## Frequently asked questions

**Q:** Czy to działa na .NET Core?  
**A:** Tak. Ten sam API działa na .NET Core, .NET 5+ i .NET Framework. Po prostu odwołaj się do odpowiedniego pakietu NuGet.

**Q:** Co zrobić, jeśli potrzebuję wygenerować PDF417 bez makra?  
**A:** Użyj `EncodeTypes.Pdf417` zamiast `EncodeTypes.MacroPdf417`. Właściwości specyficzne dla makra zostaną zignorowane.

**Q:** Czy mogę dodać własne pary klucz/wartość poza wbudowanymi polami?  
**A:** Aspose.BarCode nie udostępnia dowolnych pól użytkownika dla Macro PDF417. Jeśli potrzebujesz dodatkowych danych, zakoduj je w głównym ładunku tekstowym lub przejdź na kod QR, który obsługuje strukturalny dołączanie.
