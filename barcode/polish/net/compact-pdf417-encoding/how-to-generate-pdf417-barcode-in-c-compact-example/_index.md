# Jak wygenerować kod kreskowy PDF417 w C# – przykład kompaktowy

Jeśli potrzebujesz **generować kod kreskowy PDF417** w aplikacji C#, ten przewodnik pokaże Ci kompletną, gotową do uruchomienia rozwiązanie. Utworzymy kompaktowy kod PDF417, dostosujemy szerokość modułu, określimy liczbę kolumn i zapisujemy wynik jako obraz PNG — wszystko przy użyciu biblioteki Aspose.BarCode .NET.

Generowanie kodu PDF417 jest powszechne, gdy chcesz zakodować duże ilości danych (np. URL‑e, wizytówki lub identyfikatory inwentarza) w oszczędnym pod względem miejsca dwuwymiarowym formacie. Po zakończeniu tego samouczka będziesz mieć działającą instancję `BarcodeGenerator`, która generuje kompaktowy, wysoko czytelny kod gotowy do druku lub wyświetlenia.

## Prerequisites

- .NET 6.0 lub nowszy (kod działa również z .NET Framework 4.8)
- Visual Studio 2022 (lub dowolne IDE C#)
- Pakiet NuGet Aspose.BarCode for .NET (`Install-Package Aspose.BarCode`)
- Podstawowa znajomość składni C#

Nie wymagana jest dodatkowa konfiguracja; przykład działa jako aplikacja konsolowa.

## Step 1: Create a PDF417 barcode generator

Pierwszy krok to utworzenie instancji `BarcodeGenerator` z enumem `EncodeTypes.Pdf417` oraz tekstem, który chcesz zakodować.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Dlaczego to ważne:** `EncodeTypes.Pdf417` informuje bibliotekę, aby użyła symboliki PDF417, a drugi argument ustawia ładunek danych. Możesz zamienić `"Compact example"` na dowolny ciąg znaków do 1 800 znaków.

## Step 2: Set the module width (X‑dimension) in pixels

Ustaw szerokość modułu (wymiar X) w pikselach

Wymiar X definiuje szerokość pojedynczego modułu kodu (najmniejszego czarnego lub białego kwadratu). Mniejsza wartość w pikselach daje bardziej zwartą strukturę kodu.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Dlaczego to ważne:** Wartość `2` piksele tworzy kompaktowy wygląd bez utraty niezawodności skanowania na większości nowoczesnych skanerów. Dostosuj wartość, jeśli potrzebujesz większych modułów przy drukowaniu o niskiej rozdzielczości.

## Step 3: Specify the number of columns

Określ liczbę kolumn

PDF417 pozwala kontrolować liczbę kolumn, co wpływa na proporcje kodu.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Dlaczego to ważne:** Mniej kolumn sprawia, że kod jest wyższy, a więcej kolumn go spłaszcza. Trzy kolumny dobrze sprawdzają się w kompaktowym układzie pionowym.

## Step 4: Enable compact mode by truncating the barcode

Włącz tryb kompaktowy przez przycięcie kodu

Tryb kompaktowy usuwa niepotrzebne wiersze wypełnienia, co zmniejsza rozmiar kodu przy zachowaniu zakodowanych danych.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Dlaczego to ważne:** Przycięcie jest idealne, gdy przestrzeń ekranu jest ograniczona (np. aplikacje mobilne lub małe etykiety). Kod pozostaje w pełni czytelny, ponieważ algorytm kodowania automatycznie dostosowuje poziomy korekcji błędów.

## Step 5: Save the barcode as a PNG image

Zapisz kod jako obraz PNG

Na koniec zapisujemy wygenerowany kod do pliku. PNG zachowuje jakość bezstratną, co jest kluczowe dla skanerów kodów kreskowych.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Uruchomienie programu tworzy `CompactPdf417.png` w katalogu roboczym aplikacji. Obraz wygląda następująco:

![Generated compact PDF417 barcode](CompactPdf417.png "Generated compact PDF417 barcode")

**Oczekiwany wynik:** Kod PDF417 o szerokości 2 piksele i trzech kolumnach, który koduje tekst “Compact example”. Skanowanie pliku PNG standardowym skanerem kodów kreskowych powinno zwrócić oryginalny ciąg.

## Common variations and edge cases

| Sytuacja | Jak dostosować kod |
|-----------|--------------------|
| **Dłuższe dane ( > 500 znaków )** | Zwiększ `Columns` do 5‑7, aby kod nie stał się zbyt wysoki. |
| **Druk o wyższej rozdzielczości** | Ustaw `XDimension.Pixels` na 3 lub 4, aby uzyskać większe moduły. |
| **Inny format obrazu** | Zamień `BarCodeImageFormat.Png` na `Jpeg` lub `Bmp` w razie potrzeby. |
| **Osadzenie kodu w pliku PDF** | Użyj `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` zamiast PNG. |

**Pro tip:** Zawsze testuj wygenerowany kod na docelowym sprzęcie skanującym. Niektóre tanie skanery mają problemy z bardzo małymi wymiarami X; jeśli napotkasz błędy odczytu, zwiększ wartość pikseli o jeden krok.

## Full, runnable example

Pełny, gotowy do uruchomienia przykład

Poniżej znajduje się kompletny program, który możesz skopiować i wkleić do nowego projektu konsolowego. Nie są wymagane dodatkowe pliki.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Skompiluj i uruchom program (`dotnet run`, jeśli używasz .NET CLI). Po wykonaniu otwórz `CompactPdf417.png`, aby zweryfikować wynik wizualny.

## Conclusion

Teraz wiesz **jak generować kod kreskowy PDF417** w C# z kompaktowym układem, niestandardowym wymiarem X i ustawieniami kolumn. Przykład demonstruje niezbędne kroki: utworzenie `BarcodeGenerator`, skonfigurowanie `XDimension` i `Columns`, włączenie `Truncate` dla trybu kompaktowego oraz zapisanie obrazu.

Od tego momentu możesz odkrywać dodatkowe funkcje, takie jak poziom korekcji błędów, niestandardowe kolory lub osadzanie kodu bezpośrednio w plikach PDF. Eksperymentuj z różnymi `EncodeTypes`, jeśli potrzebujesz innych symbolik (np. QR, Code128) i zastosuj ten sam wzorzec konfiguracji parametrów.

Miłego kodowania i niech Twoje kody zawsze skanują się za pierwszym razem!
