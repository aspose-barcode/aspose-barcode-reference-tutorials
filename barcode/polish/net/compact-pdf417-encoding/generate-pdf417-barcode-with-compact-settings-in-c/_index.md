# Generowanie kodu kreskowego PDF417 z ustawieniami kompaktowymi w C#

Jeśli potrzebujesz **generować kod kreskowy PDF417** w aplikacji .NET, ten przewodnik pokaże Ci, jak to zrobić przy użyciu Aspose.Barcode for .NET. Przejdziemy przez tworzenie generatora, konfigurowanie kolumn, wymiaru X oraz włączenie trybu kompaktowego, aby uzyskany symbol był jak najmniejszy.

Generowanie kodu kreskowego PDF417 jest powszechne, gdy trzeba zakodować duże ilości danych na bilety, identyfikatory lub etykiety wysyłkowe. Ten samouczek obejmuje cały proces — od instalacji biblioteki po zapisanie finalnego pliku PNG — dzięki czemu możesz skopiować‑wkleić kod do własnego projektu i uruchomić go od razu.

## Wymagania wstępne do generowania kodu kreskowego PDF417

* .NET 6.0 (lub nowszy) zainstalowany.  
* Visual Studio 2022 lub dowolne IDE obsługujące projekty C#.  
* Licencja NuGet dla **Aspose.Barcode for .NET** (bezpłatna wersja próbna wystarczy do nauki).  

Możesz dodać bibliotekę przy użyciu następującego polecenia:

```bash
dotnet add package Aspose.BarCode
```

> **Wskazówka:** Użyj flagi `--version`, aby przypiąć znaną stabilną wersję, np. `dotnet add package Aspose.BarCode --version 23.12`.

## Utwórz generator kodu kreskowego PDF417

Pierwszy blok kodu tworzy instancję `BarcodeGenerator`, która jest wstępnie skonfigurowana dla symbologii PDF417. Tekst `"Åspóse.Barcóde©"` zawiera znaki Unicode, aby pokazać, że generator obsługuje dane nie‑ASCII od razu.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Dlaczego to jest ważne
`EncodeTypes.Pdf417` informuje Aspose.Barcode, że chcesz **kod kreskowy PDF417**, który jest układaną symbologią liniową zdolną do przechowywania do 1 850 znaków. Użycie konstruktora z argumentem tekstowym oszczędza późniejsze wywołanie `SetCodeText`.

## Ustaw XDimension kodu kreskowego (rozmiar modułu)

Rozmiar modułu, znany również jako wymiar X, określa szerokość każdego pojedynczego paska. Mniejsze piksele tworzą gęstszy obraz, podczas gdy większe piksele poprawiają czytelność na drukarkach o niskiej rozdzielczości.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### Dlaczego warto dostosować XDimension
Wartość `2` piksele dobrze sprawdza się przy wyświetlaniu na ekranie i na większości drukarek biurowych. Jeśli potrzebujesz wydruku o wyższej rozdzielczości, zwiększ tę wartość; jeśli potrzebujesz bardziej zwarty kod (np. w stylu QR), zmniejsz ją — ale nigdy nie poniżej `1` piksela, w przeciwnym razie obraz stanie się nieczytelny.

## Ustaw liczbę kolumn dla symbolu PDF417

PDF417 pozwala wybrać, ile kolumn (pionowych stosów) będzie miał kod kreskowy. Mniej kolumn powoduje, że kod jest wyższy; więcej kolumn sprawia, że jest szerszy.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### Kiedy zmienić liczbę kolumn
Trzy kolumny tworzą kompaktowy, prawie kwadratowy symbol, który dobrze pasuje do standardowych kart identyfikacyjnych. Jeśli masz bardzo długi ciąg, możesz zwiększyć liczbę kolumn, aby utrzymać wysokość w rozsądnych granicach.

## Włącz tryb kompaktowy (obcinanie)

Tryb kompaktowy automatycznie usuwa nieużywane wiersze z symbolu, zmniejszając jego całkowity rozmiar. Jest to szczególnie przydatne, gdy zakodowane dane nie wypełniają całej macierzy.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Korzyści z kompaktowego kodu PDF417
Gdy `Truncate` jest ustawione na `true`, generator oblicza minimalną liczbę wierszy potrzebną do przechowywania danych, co zmniejsza zużycie tuszu i czas skanowania. Jest to bezpieczne dla większości skanerów, ponieważ specyfikacja PDF417 definiuje algorytm obcinania.

## Zapisz wygenerowany kod kreskowy jako obraz

Na koniec zapisz kod kreskowy do pliku PNG. PNG zachowuje jakość bezstratną, co czyni go idealnym do późniejszego drukowania lub osadzania w plikach PDF.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Oczekiwany wynik
Uruchomienie programu tworzy plik `CompactPdf417.png` w określonym folderze. Obraz zawiera **kompaktowy kod PDF417**, który koduje ciąg `"Åspóse.Barcóde©"` z trzema kolumnami, wymiarem X wynoszącym 2 piksele oraz zastosowanym obcięciem. Możesz zweryfikować wynik przy pomocy dowolnej aplikacji skanującej kody kreskowe lub darmowej demonstracji online Aspose.Barcode.

## Typowe warianty i przypadki brzegowe

| Situation | Adjustment |
|-----------|------------|
| **Bardzo długie dane (> 1500 znaków)** | Zwiększ `Columns` lub ustaw `Rows` ręcznie (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Drukowanie na drukarce o niskiej rozdzielczości (low‑dpi)** | Podnieś `XDimension.Pixels` do 3 lub 4, aby uniknąć pikselizacji. |
| **Potrzeba przezroczystego tła** | Użyj `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **Osadzanie w PDF** | Zapisz jako `BarCodeImageFormat.Pdf` lub uzyskaj obiekt `Image` za pomocą `pdf417Generator.GenerateBarCodeImage()`. |

## Pełny, gotowy do uruchomienia przykład

Poniżej znajduje się kompletny program, który możesz skopiować do nowego projektu konsolowego. Nie są wymagane dodatkowe pliki.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Uruchom `dotnet run` z katalogu projektu. Po wykonaniu otwórz `CompactPdf417.png`, aby zobaczyć wygenerowany kod kreskowy.

Dostosowując `barcode XDimension pixels`, `set PDF417 columns` i włączając obcinanie `compact PDF417 barcode`, możesz uzyskać kod kreskowy, który spełnia dokładne ograniczenia rozmiaru Twojej aplikacji.

Możliwe dalsze kroki:

* Połącz kod kreskowy z innymi komponentami Aspose, takimi jak **Aspose.PDF**, aby osadzić obraz bezpośrednio w raporcie PDF.
