# Generowanie kodu kreskowego PDF417 w C# przy użyciu Aspose – przewodnik krok po kroku

Jeśli potrzebujesz **generować kod kreskowy PDF417** w aplikacji .NET, ten przewodnik pokaże Ci dokładnie, jak to zrobić. Zobaczysz kompletny, gotowy do uruchomienia przykład, który tworzy podstawowe, kompaktowe, Micro, GS1‑Micro i Macro kody PDF417 przy użyciu Aspose.BarCode dla .NET.

Generowanie kodu kreskowego PDF417 jest powszechnym wymogiem dla etykiet wysyłkowych, dokumentów transportowych i systemów inwentaryzacji. Po zakończeniu tego samouczka będziesz w stanie **generować obrazy kodu PDF417**, zrozumieć kluczowe parametry i dostosować kod do własnych danych.

## Wymagania wstępne

- .NET 6.0 SDK lub nowszy (kod działa również z .NET Framework 4.7+)
- Visual Studio 2022 lub dowolne IDE C#
- Pakiet NuGet Aspose.BarCode dla .NET (`Aspose.BarCode`) zainstalowany
- Podstawowa znajomość składni C#

> **Wskazówka:** Użyj darmowej licencji ewaluacyjnej od Aspose, aby uniknąć ograniczeń w czasie wykonywania podczas testów.

## Krok 1: Skonfiguruj projekt i zaimportuj przestrzenie nazw

Create a new console project and add the Aspose.BarCode package:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Następnie otwórz `Program.cs` i dodaj wymagane dyrektywy `using`:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Te przestrzenie nazw dają dostęp do klasy `BarcodeGenerator` oraz wyliczenia `EncodeTypes` potrzebnych do **generowania kodu kreskowego przy użyciu C#**.

## Krok 2: Wygeneruj podstawowy kod PDF417

Najprostszy kod PDF417 używa ustawień domyślnych, z wyjątkiem wymiaru X (szerokość modułu) oraz liczby kolumn. Dostosowanie tych wartości kontroluje ogólny rozmiar i czytelność.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Dlaczego to działa:**  
- `EncodeTypes.Pdf417` informuje Aspose, aby użył symbologii PDF417.  
- `XDimension.Pixels` definiuje najmniejszą szerokość kreski; wartość 2 utrzymuje obraz mały bez utraty możliwości skanowania.  
- `Pdf417.Columns` określa, ile kolumn danych zawiera kod kreskowy; trzy kolumny dają zrównoważony stosunek wymiarów.

## Krok 3: Wygeneruj kompaktowy (skrócony) kod PDF417

Tryb kompaktowy usuwa wzorzec stop i zmniejsza całkowitą wysokość, co jest przydatne przy etykietach o ograniczonej przestrzeni.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Dlaczego to działa:**  
Ustawienie `Pdf417.Truncate = true` aktywuje tryb skrócony, który pomija prawostronny wzorzec stop i zmniejsza wysokość kodu kreskowego, zachowując integralność danych.

## Krok 4: Wygeneruj Micro PDF417

Micro PDF417 to mniejsza odmiana, która obsługuje 1‑4 kolumny. Jest idealna dla zastosowań, gdzie przestrzeń jest cenna, np. małe etykiety produktów.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Dlaczego to działa:**  
- `EncodeTypes.MicroPdf417` wybiera mikro wersję symbologii.  
- Liczba kolumn może wynosić od 1 do 4; wybór 4 daje najgęstszy układ przy zachowaniu możliwości skanowania.

## Krok 5: Wygeneruj zgodny z GS1 Micro PDF417

Prefiksy GS1 dodają standardowe identyfikatory (np. GTIN, numer partii) do danych kodu kreskowego. Aspose pozwala osadzić je bezpośrednio.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Dlaczego to działa:**  
Identyfikatory aplikacji GS1 (AIs) są umieszczane w nawiasach. Aspose je parsuje i dodaje odpowiednie formatowanie wymagane przez skanery GS1.

## Krok 6: Wygeneruj Macro PDF417 z pełnymi metadanymi

Macro PDF417 pozwala podzielić duży ładunek danych na wiele powiązanych kodów kreskowych. Możesz osadzić metadane na poziomie pliku, takie jak ID pliku, liczba segmentów, znaczniki czasu i własne ciągi znaków.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Dlaczego to działa:**  
Każda właściwość `MacroPdf417*` odpowiada konkretnemu segmentowi specyfikacji makro kodu kreskowego. Ustawienie tych wartości zapewnia, że skaner może odtworzyć oryginalny plik z wielu obrazów kodów kreskowych.
