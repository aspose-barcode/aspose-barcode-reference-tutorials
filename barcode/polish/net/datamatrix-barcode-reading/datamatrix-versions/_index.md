# Jak generować kody kreskowe DataMatrix przy użyciu Aspose.BarCode dla .NET

Jeśli potrzebujesz niezawodnego sposobu na osadzanie symboli odczytywanych maszynowo w swoich aplikacjach .NET, **jak generować DataMatrix** jest powszechnym wymaganiem. Aspose.BarCode dla .NET oferuje w pełni zarządzane API, które obsługuje każdy krok — od wyboru odpowiedniej wersji DataMatrix po precyzyjne dostosowanie poziomów korekcji błędów — bez konieczności używania zewnętrznych narzędzi. W tym samouczku przeprowadzimy Cię przez kompletny przykład, wyjaśnimy, dlaczego każde ustawienie ma znaczenie, i pokażemy, jak zapisać wynik jako obraz PNG lub JPEG.

## Szybkie odpowiedzi
- **Jaka biblioteka tworzy kody DataMatrix?** Aspose.BarCode for .NET.  
- **Ile wersji DataMatrix jest obsługiwanych?** Wszystkie 30 standardowych wersji kwadratowych i prostokątnych (od 10×10 do 144×144 modułów).  
- **Jakie typy ECC mogę używać?** ECC200 (domyślnie) i ECC140.  
- **Czy potrzebuję licencji do rozwoju?** Darmowa 30‑dniowa wersja próbna działa do testów; wymagana jest licencja komercyjna w produkcji.  
- **Czy mogę uruchomić to na .NET 6, .NET Core lub .NET Framework?** Tak — Aspose.BarCode obsługuje .NET Framework 4.5+, .NET Core 3.1+ oraz .NET 5/6+.

## Co to jest kod kreskowy DataMatrix?
Kod DataMatrix to dwuwymiarowa, kwadratowa lub prostokątna macierz czarnych i białych komórek, która może przechowywać do 2 335 znaków alfanumerycznych. Jest szeroko stosowany w przemyśle, logistyce i opiece zdrowotnej do znakowania małych przedmiotów, ponieważ pozostaje czytelny nawet po częściowym uszkodzeniu.

## Dlaczego warto używać Aspose.BarCode dla .NET?
Aspose.BarCode obsługuje **ponad 50 formatów wyjściowych** (w tym PNG, JPEG, TIFF, SVG i PDF) i może generować **wszystkie 30 wersji DataMatrix** bez ładowania całego obrazu do pamięci, co pozwala tworzyć kody kreskowe w usługach o wysokiej przepustowości przetwarzających pliki większe niż 100 MB.

Teraz przyjrzyjmy się wersjom DataMatrix i sposobom ich generowania przy użyciu Aspose.BarCode dla .NET.

## Jak generować kody DataMatrix w .NET?

Załaduj `BarcodeGenerator` z typem `EncodeTypes.DataMatrix`, ustaw żądaną wersję i ECC, a następnie wywołaj `Save`, aby zapisać plik obrazu. Ten jednowierszowy wzorzec działa dla dowolnej wybranej wersji i automatycznie obsługuje rozmiarowanie modułów, strefy ciszy oraz renderowanie obrazu.

## Importowanie przestrzeni nazw

`BarcodeGenerator` jest podstawową klasą Aspose.BarCode służącą do tworzenia obrazów kodów kreskowych.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

Przestrzeń nazw `Aspose.BarCode.Generation` zapewnia dostęp do klasy `BarcodeGenerator`, która jest główną klasą używaną do generowania obrazów kodów kreskowych.

Teraz rozbijmy przykład na kilka kroków.

## Krok 1: ustaw ścieżkę katalogu

Zacznij od określenia ścieżki katalogu, w którym chcesz zapisywać wygenerowane kody DataMatrix.

```csharp
string path = "Your Directory Path";
```

Zastąp `"Your Directory Path"` rzeczywistą ścieżką, w której chcesz zapisywać obrazy kodów.

## Krok 2: zainicjuj generator kodów kreskowych

Utwórz instancję klasy `BarcodeGenerator` i określ typ kodu kreskowego jako `DataMatrix`. Możesz także podać dane, które chcesz zakodować w kodzie.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` jest główną klasą, która tworzy i renderuje symbole kodów kreskowych.

## Krok 3: skonfiguruj właściwości kodu kreskowego

Możesz dostosować różne właściwości kodu DataMatrix, takie jak jego wymiary i typ ECC (Error Correction Code). Oto przykład ustawienia wymiaru X na 4 piksele i wyboru ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` ustawia rozmiar każdego modułu w pikselach, a `DataMatrixEcc` wybiera poziom korekcji błędów.

## Krok 4: ustaw wersję DataMatrix i zapisz

Możesz określić wersję DataMatrix, ustawiając liczbę wierszy i kolumn. Po skonfigurowaniu wersji zapisz obraz kodu.

Na przykład, aby utworzyć kod DataMatrix z 22 wierszami i 22 kolumnami przy użyciu ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

Podobnie możesz wygenerować kod z innymi parametrami, zmieniając wersję i typ ECC w razie potrzeby.

## Krok 5: powtórz dla innych wersji

Możesz powtórzyć Krok 4 dla innych wersji DataMatrix. Na przykład, aby utworzyć kod z 12 wierszami i 64 kolumnami przy użyciu ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Krok 6: zmień typy ECC

Jeśli chcesz zmienić typ ECC na Ecc140, możesz to zrobić, aktualizując właściwość ECC:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Krok 7: generuj kody kreskowe z różnymi wersjami i ECC

Powtórz Krok 4 dla innych wersji DataMatrix i typów ECC, zapisując każdy kod pod unikalną nazwą pliku.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

Teraz, gdy nauczyłeś się generować kody DataMatrix przy użyciu Aspose.BarCode dla .NET, możesz łatwo zintegrować tę funkcjonalność ze swoimi aplikacjami .NET.

## Typowe pułapki i wskazówki rozwiązywania problemów

- **Nieprawidłowe wymiary wersji** – Wersje DataMatrix mają stałe pary wiersz/kolumna. Podanie niepasującej pary (np. 10 × 20) spowoduje wyrzucenie `ArgumentException`. Zawsze używaj jednej z obsługiwanych kombinacji wymienionych w dokumentacji API.  
- **Brak licencji** – W trybie próbnym wygenerowane obrazy zawierają znak wodny. Zastosuj ważną licencję przy pomocy `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` przed utworzeniem generatora, aby usunąć znak wodny. Klasa `License` ładuje plik licencji w celu aktywacji produktu.  
- **Duży rozmiar obrazu** – Jeśli potrzebujesz wyjścia o wysokiej rozdzielczości, zwiększ właściwość `XDimension`; biblioteka skaluje obraz proporcjonalnie, nie tracąc czytelności.
