# Barcode‑PNG in Python erstellen – Komplettanleitung

Haben Sie jemals **barcode PNG erstellen** müssen, waren sich aber nicht sicher, welche Bibliothek oder Einstellungen zu verwenden sind? Sie sind nicht allein. In vielen Inventar‑ oder Kassensystemen ist der erste Schritt, Rohdaten in ein klares PNG‑Bild zu verwandeln, das Scanner lieben.  

In diesem Tutorial führen wir Sie durch **how to generate databar**, zeigen, wie Sie **adjust barcode height** vornehmen können, und sogar den Trick, **change barcode**‑Parameter zur Laufzeit zu ändern – und das alles mit **barcode with sample data**, das Sie direkt in Ihr Projekt kopieren‑und‑einfügen können.  

## What You’ll Learn

- Tipps zur Fehlersuche bei häufigen Problemen wie unscharfen Bildern oder falscher Kodierung.

Vorkenntnisse in der Barcode‑Erstellung sind nicht nötig – nur ein einfacher Python‑Interpreter und die Möglichkeit, ein pip‑Package zu installieren.

## Create barcode PNG – Setting Up the Generator

Zuerst benötigen wir ein Generator‑Objekt, das weiß, dass wir einen **DataBar Omnidirectional**‑Barcode erzeugen wollen. Der untenstehende Code importiert die notwendigen Klassen, erstellt den Generator mit einem **barcode with sample data** und setzt eine moderate Modulgröße.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Why this matters:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` weist die Engine an, einen **DataBar** zu erzeugen, der aus jeder Richtung lesbar ist – ideal für Regale im Einzelhandel. Das Setzen von `x_dimension` sorgt für scharfe Balken, während `bar_height` die visuelle Größe des Codes bestimmt.

## How to Generate Databar with Sample Data

Jetzt, wo der Generator bereit ist, **create barcode PNG**‑Dateien erzeugen. Der erste Save verwendet eine Höhe von 30 Pixel, was oft für Bildschirm‑Vorschauen ausreicht.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Das Ausführen des Skripts bis zu diesem Punkt erzeugt eine PNG‑Datei, die wie ein kompakter, hochkontrastierter Barcode aussieht. Öffnen Sie sie in einem Bildbetrachter, um zu prüfen, dass die Balken scharf sind und die GTIN‑14‑Daten korrekt kodiert wurden.

## Adjust Barcode Height (How to Change Barcode)

Manchmal benötigen Sie einen höheren Barcode für größere Etiketten oder hochauflösenden Druck. Hier kommt **adjust barcode height** ins Spiel. Die Höhe zu ändern ist so einfach wie das Aktualisieren der Eigenschaft `BarHeight` und ein erneutes Speichern.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**How it works:** Der Generator verwendet dieselben Daten und dieselbe Modulgröße; nur die vertikale Dimension ändert sich. Das vermeidet das Neuerstellen des gesamten Objekts und demonstriert **how to change barcode**‑Einstellungen dynamisch.

## Full Script – One‑Stop Solution

Unten finden Sie das vollständige, ausführbare Skript, das alle Schritte kombiniert. Kopieren, einfügen und ausführen – es sollte nach der Paketinstallation sofort funktionieren.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Expected Output

Das Ausführen des Skripts erzeugt zwei Dateien:

- `DatabarOmni30.png` – 30 px hoher DataBar Omnidirectional‑Barcode.  
- `DatabarOmni60.png` – 60 px hohe Version desselben Barcodes.

Beide Bilder sind im PNG‑Format, verlustfrei, und bereit, in PDFs, HTML‑Seiten eingebettet oder direkt auf Etiketten gedruckt zu werden.

## Common Pitfalls & Pro Tips

- **Pixel vs. DPI:** PNG‑Dateien basieren auf Pixeln. Wenn Sie eine bestimmte Druckgröße benötigen, berechnen Sie `BarHeight` basierend auf DPI (z. B. 300 dpi → 30 px ≈ 0,1 in).  
- **Incorrect encoding:** Stellen Sie sicher, dass die Datenzeichenfolge dem GS1‑Application‑Identifier‑Format entspricht (`(01)` für GTIN‑14). Fehlende Klammern können dazu führen, dass die Bibliothek zu einem reinen numerischen Barcode zurückfällt.  
- **File paths:** Verwenden Sie rohe Strings (`r"..."`) oder doppelte Backslashes unter Windows, um Escape‑Zeichen‑Probleme zu vermeiden.  
- **Performance:** Wenn Sie Tausende von Barcodes erzeugen, instanziieren Sie den Generator einmal und ändern nur `BarHeight` oder die Datenzeichenfolge zwischen den Saves. Das reduziert den Speicherverbrauch.
