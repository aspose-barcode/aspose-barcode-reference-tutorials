# Wie man ein Planet‑Barcode‑PNG mit Python erstellt

Wenn Sie ein **Planet‑Barcode‑PNG erstellen** müssen, führt Sie dieses Tutorial durch den gesamten Prozess mit Python. Sie lernen außerdem **wie man einen Planet‑Barcode** Schritt für Schritt erzeugt, sein Aussehen konfiguriert und das Ergebnis als hochqualitatives PNG‑Bild speichert.

Das Erzeugen eines Planet‑Barcodes ist in der Postautomatisierung, Bestandsverfolgung und Logistik üblich. Am Ende dieses Leitfadens besitzen Sie ein eigenständiges Skript, das eine einsatzbereite PNG‑Datei erzeugt, und Sie verstehen, wie Sie den Code für unterschiedliche Größen oder Bildformate anpassen können.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie:

* Python 3.8 oder neuer installiert haben.
* Zugriff auf das `aspose-barcode`‑Paket (oder eine kompatible Bibliothek, die die Klassen `BarcodeGenerator`, `EncodeTypes` und `BarCodeImageFormat` bereitstellt).
* Schreibrechte für das Verzeichnis, in dem Sie die PNG‑Datei speichern möchten.

Sie können die benötigte Bibliothek mit pip installieren:

```bash
pip install aspose-barcode
```

> **Pro‑Tipp:** Verwenden Sie ein virtuelles Umfeld, um Abhängigkeiten von anderen Projekten zu isolieren.

## Planet‑Barcode‑PNG erstellen – vollständiger Code‑Durchlauf

Das folgende Skript demonstriert jeden Schritt, der nötig ist, um ein Planet‑Barcode‑PNG mit leeren (nicht ausgefüllten) Balken zu erzeugen. Kopieren Sie den Code in eine Datei namens `planet_barcode.py` und führen Sie sie mit `python planet_barcode.py` aus.

```python
# planet_barcode.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Initialize a Planet barcode generator with the data to encode
# The data "123456" is a typical numeric payload for postal services.
generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

# Step 2: Set the width of each bar (X dimension) to 4 pixels.
# Adjusting the X dimension changes the overall size and readability.
generator.parameters.barcode.x_dimension.pixels = 4

# Step 3: Configure the barcode to use empty (unfilled) bars.
# When `filled_bars` is False, the dark bars become transparent,
# which is useful for overlaying the barcode on colored backgrounds.
generator.parameters.barcode.filled_bars = False

# Step 4: Save the generated barcode as a PNG image.
# The output path can be absolute or relative; ensure the folder exists.
output_path = "output/PostalPlanetEmptyBars.png"
generator.save(output_path, BarCodeImageFormat.PNG)

print(f"Planet barcode PNG saved to: {output_path}")
```

### Was jede Zeile macht

| Zeile | Erklärung |
|------|-------------|
| `from aspose.barcode import ...` | Importiert die Klassen, die zum Erstellen und Konfigurieren des Barcodes benötigt werden. |
| `BarcodeGenerator(EncodeTypes.Planet, "123456")` | Instanziiert einen Generator für die **Planet**‑Symbologie mit dem numerischen String `"123456"`. |
| `x_dimension.pixels = 4` | Setzt die Balkenbreite auf 4 px; höhere Werte erzeugen einen größeren Barcode, niedrigere Werte reduzieren die Dateigröße. |
| `filled_bars = False` | Schaltet den Barcode auf **leere Balken**, wodurch die dunklen Module transparent werden. |
| `save(..., BarCodeImageFormat.PNG)` | Schreibt den Barcode in eine PNG‑Datei und bewahrt die verlustfreie Qualität. |
| `print(...)` | Bestätigt die erfolgreiche Erstellung in der Konsole. |

## Wie man einen Planet‑Barcode mit benutzerdefinierten Einstellungen generiert

Während das Grundskript die meisten Anwendungsfälle abdeckt, müssen Sie den Barcode möglicherweise für spezielle Anforderungen anpassen:

1. **Unterschiedliche Datenlängen** – Planet‑Barcodes unterstützen bis zu 12 numerische Zeichen. Ändern Sie `"123456"` zu einem beliebigen gültigen numerischen String innerhalb dieser Grenze.
2. **Alternative Bildformate** – Ersetzen Sie `BarCodeImageFormat.PNG` durch `BarCodeImageFormat.JPEG` oder `BarCodeImageFormat.BMP`, um sie an nachgelagerte Verarbeitungspipelines anzupassen.
3. **Ändern der X‑Dimension** – Größere Werte (z. B. `8`) erzeugen einen hochauflösenden Barcode, was beim Druck auf großen Etiketten hilfreich ist.
4. **Hintergrundfarben** – Wenn Sie einen farbigen Hintergrund wünschen, setzen Sie `generator.parameters.barcode.back_color` vor dem Speichern.

Beispiel mit einer benutzerdefinierten Hintergrundfarbe:

```python
from aspose.barcode import Color

generator.parameters.barcode.back_color = Color.get_yellow()
generator.save("output/PlanetYellowBackground.png", BarCodeImageFormat.PNG)
```

## Häufige Stolperfallen und wie man sie vermeidet

| Problem | Ursache | Lösung |
|-------|--------|-----|
| **FileNotFoundError** beim Speichern | Das Zielverzeichnis existiert nicht. | Erstellen Sie das Verzeichnis vorher (`os.makedirs("output", exist_ok=True)`). |
| **Ungültige Datenlänge** | Planet‑Barcode akzeptiert nur numerische Daten bis zu 12 Zeichen. | Validieren Sie den Eingabestring, bevor Sie den Generator erstellen. |
| **Transparente Balken nicht sichtbar** | Einige Viewer ignorieren Transparenz auf einer weißen Leinwand. | Platzieren Sie den Barcode auf einem nicht‑weißen Hintergrund oder exportieren Sie als PNG mit Alphakanal. |

## Überprüfung der Ausgabe

Nach dem Ausführen des Skripts öffnen Sie `PostalPlanetEmptyBars.png` mit einem beliebigen Bildbetrachter. Sie sollten eine Reihe vertikaler Balken sehen, bei denen die dunklen Module transparent sind und nur die Kontur des Barcodes sichtbar bleibt. Um zu bestätigen, dass der Barcode lesbar ist, verwenden Sie eine mobile Barcode‑Scanner‑App, die die Planet‑Symbologie unterstützt.

Falls das Bild leer erscheint, prüfen Sie:

* Das Flag `filled_bars` ist auf `False` gesetzt.
* Die X‑Dimension ist nicht auf Null gesetzt.
* Der Ausgabepfad verweist auf einen existierenden Ordner.
