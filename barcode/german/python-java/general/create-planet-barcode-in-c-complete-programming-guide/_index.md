# Erstellen eines Planet-Barcodes in C# – vollständige Programmieranleitung

Wenn Sie in C# **einen Planet-Barcode erstellen** müssen, zeigt Ihnen dieser Leitfaden genau, wie das geht. Außerdem erfahren Sie **wie Sie die Barcode‑Abmessungen festlegen**, sodass die Striche exakt die gewünschte Breite haben.

Das Erzeugen von Planet‑Barcodes ist üblich, wenn Sie mit Postdiensten oder Logistiksystemen arbeiten. Der untenstehende Code deckt sowohl die standardmäßige gefüllte‑Bar‑Version als auch den optionalen leeren‑Bar‑Stil ab und enthält ein kurzes Beispiel für das RM4SCC‑Format. Am Ende dieses Tutorials verfügen Sie über ein wiederverwendbares Snippet, das Sie in jedes .NET‑Projekt einbinden können.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

* .NET 6.0 oder höher installiert (die API funktioniert auch mit .NET Framework 4.6+).
* Das NuGet‑Paket **Aspose.BarCode for .NET** (`Aspose.BarCode`) zu Ihrem Projekt hinzugefügt.
* Ein beschreibbarer Ordnerpfad, in dem die PNG‑Dateien gespeichert werden.
* Grundlegende Kenntnisse der C#‑Syntax und von Visual Studio (oder einer anderen IDE).

> **Pro‑Tipp:** Verwenden Sie einen absoluten Pfad oder `Path.Combine(Environment.CurrentDirectory, "output")`, um Berechtigungsprobleme beim Speichern von Bildern zu vermeiden.

## Schritt 1 – Initialisieren eines Planet‑Barcode‑Generators (gefüllte Balken)

Der erste Schritt besteht darin, eine `BarcodeGenerator`‑Instanz für die Planet‑Symbologie zu erstellen. Standardmäßig erzeugt der Generator **gefüllte** Balken.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Das Enum `EncodeTypes.Planet` weist Aspose.BarCode an, das Planet‑Format zu verwenden, während `"123456"` die zu kodierenden Daten darstellt.

## Schritt 2 – Wie Sie die Barcode‑Abmessungen für konsistente Größen festlegen

Um die Breite jedes Balkens zu steuern, passen Sie die **X‑Dimension** an. Dies ist die primäre Methode, um **Barcode‑Abmessungen festzulegen**, und sorgt dafür, dass der Barcode in Ihre Etikettengröße passt.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

Die Eigenschaft `Pixels` definiert die Balkenbreite in Bildschirm‑Pixeln. Übliche Werte liegen bei 2 – 5 Pixeln für Standard‑Versandetiketten; erhöhen Sie den Wert für größere Drucke.

## Schritt 3 – Speichern des gefüllten Planet‑Barcodes als PNG

Jetzt schreiben Sie das Bild auf die Festplatte. PNG bewahrt scharfe Kanten, was ideal zum Scannen ist.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Ersetzen Sie `YOUR_DIRECTORY` durch den Pfad, den Sie zuvor vorbereitet haben. Nach dem Ausführen dieses Codes sehen Sie eine Datei, die dem Bild unten ähnelt.

## Schritt 4 – Erstellen eines Planet‑Barcodes mit leeren (nicht gefüllten) Balken

Wenn Ihr Postdienst verlangt, dass die Balken **leer** sein sollen, müssen Sie nach der Initialisierung des Generators das `FilledBars`‑Flag umschalten.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

Der Konstruktor ist identisch; der Unterschied liegt im nächsten Konfigurationsschritt.

## Schritt 5 – Wie Sie die Barcode‑Abmessungen festlegen und die Balken leer machen

Setzen Sie erneut die X‑Dimension für visuelle Konsistenz und deaktivieren Sie dann gefüllte Balken.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

Die Eigenschaft `FilledBars = false` ist das, was den Renderstil tatsächlich ändert. Die Beibehaltung derselben X‑Dimension stellt sicher, dass der leere‑Bar‑Barcode perfekt mit der gefüllten Version ausgerichtet ist.

## Schritt 6 – Speichern des leeren Planet‑Barcodes

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Sie haben jetzt zwei PNG‑Dateien: eine mit soliden Balken und eine mit hohlen Balken, beide mit denselben Abmessungen.

## Schritt 7 – (Optional) Erzeugen eines RM4SCC‑Barcodes zum Vergleich

RM4SCC ist eine weitere Post‑Symbologie, die denselben standardmäßigen gefüllten‑Bar‑Stil verwendet. Die Schritte spiegeln das Planet‑Beispiel wider und zeigen, dass **wie man Barcode‑Abmessungen festlegt** formatübergreifend funktioniert.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Durch das Ausführen dieser drei Schritte entsteht `PostalRM4SCCFilledBars.png`, das Sie nebeneinander mit den Planet‑Ausgaben vergleichen können.

## Warum die X‑Dimension wichtig ist

Die X‑Dimension bestimmt die **mindeste druckbare Breite** jedes Balkens. Wenn Sie sie zu niedrig einstellen, kann der Barcode auf Niedrigauflösungs‑Druckern verschwimmen, was zu Scan‑Fehlern führt. Umgekehrt kann eine zu große X‑Dimension die Etikettengröße überschreiten und Platz verschwenden. Indem Sie explizit **wie Sie Barcode‑Abmessungen festlegen**, erhalten Sie eine deterministische Kontrolle über die endgültige Bildgröße, was für automatisierte Versand‑Workflows unerlässlich ist.

## Häufige Fallstricke und wie man sie vermeidet

| Problem | Ursache | Lösung |
|---------|---------|--------|
| Barcode erscheint gestreckt | X‑Dimension in Punkten statt in Pixeln eingestellt | Verwenden Sie stets die `Pixels`‑Eigenschaft für pixelgenaue Kontrolle |
| Leere Balken sehen immer noch gefüllt aus | `FilledBars` nicht auf `false` gesetzt nach Änderung der X‑Dimension | `FilledBars = false` *nach* Anpassen der X‑Dimension setzen |
| Gespeicherte Datei ist leer | Ausgabeverzeichnis existiert nicht oder hat keine Schreibberechtigung | Stellen Sie sicher, dass das Verzeichnis existiert (`Directory.CreateDirectory`) und Ihre Anwendung mit ausreichenden Rechten läuft |
| Bild ist beim Druck unscharf | PNG mit niedriger DPI von einem hochauflösenden Monitor gespeichert | `BarCodeImageFormat.Png` (verlustfrei) verwenden und ggf. die `Resolution`‑Eigenschaft berücksichtigen |

## Vollständiges, ausführbares Beispiel

Kopieren Sie den gesamten Block unten in ein neues Konsolenprojekt (`dotnet new console`) und führen Sie es aus. Das Programm erstellt drei PNG‑Dateien im Ordner `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Erwartete Ausgabe:** drei PNG‑Dateien – `PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` und `PostalRM4SCCFilledBars.png` – jeweils mit 4‑Pixel‑breiten Balken, bereit zum Drucken oder zur Weiterverarbeitung.

## Fazit

Sie wissen jetzt, wie Sie in C# **einen Planet‑Barcode erstellen** und genau **wie Sie Barcode‑Abmessungen festlegen** für sowohl gefüllte als auch leere Balkenstile. Das gleiche Muster gilt für andere Symbologien wie RM4SCC und bietet Ihnen eine flexible Grundlage für jede postalische Barcode‑Anforderung.

Als Nächstes könnten Sie erkunden:

* Hinzufügen von menschenlesbarem Text unterhalb des Barcodes (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* Ändern der Balkenfarben mit `Parameters.Barcode.BarColor`
* Erzeugen von Barcodes in Vektorformaten (SVG, EPS) für skalierbaren Druck

Fühlen Sie sich frei, mit verschiedenen X‑Dimension‑Werten, Datenzeichenketten und Ausgabeformaten zu experimentieren, um Ihren spezifischen Workflow zu unterstützen. Viel Spaß beim Coden!
