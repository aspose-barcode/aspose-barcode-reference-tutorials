# Wie man ein Barcode‑Bild in C# mit DataBar Stacked Omni‑Directional erzeugt

Wenn Sie **wie man ein Barcode‑Bild erzeugt** in einer .NET‑Anwendung benötigen, zeigt dieses Tutorial die genauen Schritte. Sie sehen, wie man einen DataBar Stacked Omni‑Directional‑Barcode erstellt, das Seitenverhältnis anpasst und das Ergebnis als PNG‑Dateien exportiert.

Das Erzeugen von Barcodes ist eine gängige Anforderung für Inventursysteme, Einzelhandels‑POS‑Terminals und Logistik‑Tracking. In den folgenden Abschnitten behandeln wir alles, was Sie benötigen – vom erforderlichen NuGet‑Paket bis zur abschließenden Bild‑Verifizierung – sodass Sie die Barcode‑Erstellung noch heute in jedes C#‑Projekt integrieren können.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

* .NET 6.0 oder höher (der Code funktioniert mit .NET Core und .NET Framework)
* Visual Studio 2022 oder eine beliebige C#‑IDE Ihrer Wahl
* Das **Aspose.BarCode for .NET** NuGet‑Paket (installieren mit `dotnet add package Aspose.BarCode`)
* Schreibrechte für den Ordner, in dem die PNG‑Dateien gespeichert werden

Diese Voraussetzungen garantieren, dass das Beispiel ohne zusätzliche Konfiguration ausgeführt wird.

## Schritt 1: Ausgabeverzeichnis einrichten

Das erste, was Sie benötigen, ist ein Verzeichnis, in das die erzeugten PNG‑Dateien geschrieben werden. Sowohl ein absoluter als auch ein relativer Pfad funktionieren, aber stellen Sie sicher, dass der Ordner existiert, bevor Sie `Save` aufrufen.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Das programmgesteuerte Erstellen des Ordners verhindert *FileNotFoundException*, wenn die `Save`‑Methode versucht, das Bild zu schreiben.

## Schritt 2: Einen DataBar Stacked Omni‑Directional Barcode‑Generator erstellen

Die **BarcodeGenerator**‑Klasse ist der Einstiegspunkt für alle Barcode‑Typen. Hier geben wir `EncodeTypes.DatabarStackedOmniDirectional` und die Datenzeichenfolge an, die wir codieren wollen.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Warum das wichtig ist*: Das `EncodeTypes`‑Enum teilt der Bibliothek mit, welche Symbolik gerendert werden soll. Die Verwendung der Omni‑Directional‑Variante stellt sicher, dass der Barcode aus jeder Orientierung gescannt werden kann – eine Anforderung vieler Lager‑Scanner.

## Schritt 3: Gemeinsame Barcode‑Parameter konfigurieren

Ein lesbarer Barcode benötigt eine sinnvolle X‑Dimension (die Breite des kleinsten Strichs). Das Setzen von `Pixels` auf 2 bietet für die meisten Bildschirmauflösungen ein gutes Gleichgewicht zwischen Größe und Klarheit.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Sie können `Pixels` später anpassen, wenn Sie ein größeres oder kleineres Bild benötigen; die Bibliothek skaliert den Rest des Barcodes automatisch.

## Schritt 4: Das erste Bild mit Seitenverhältnis 15 erzeugen

Das **Seitenverhältnis** steuert das Höhen‑zu‑Breiten‑Verhältnis von DataBar‑Barcodes. Ein Seitenverhältnis von 15 ist ein typischer Standard für Einzelhandels‑Etiketten.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Nach diesem Aufruf finden Sie `DatabarAspectRatio15.png` im Ausgabeverzeichnis. Das Bild ist ein verlustfreies PNG, geeignet für weitere Verarbeitung oder den Druck.

## Schritt 5: Das Seitenverhältnis auf 30 ändern und ein zweites Bild exportieren

Manchmal wird ein höherer Barcode benötigt – zum Beispiel, wenn die Etikettenhöhe begrenzt ist. Das Ändern des Seitenverhältnisses auf 30 erzeugt ein kompakteres Bild, während die Datenintegrität erhalten bleibt.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Jetzt haben Sie zwei PNG‑Dateien, die zeigen, wie dieselben Daten bei unterschiedlichen Seitenverhältnissen aussehen. Dieser Nebeneinander‑Vergleich hilft Ihnen, die Variante zu wählen, die am besten zu Ihrem Etikettenlayout passt.

## Vollständiges, ausführbares Beispiel

Unten finden Sie das komplette Programm, das Sie kopieren, einfügen und ausführen können. Es enthält alle `using`‑Direktiven, Fehlerbehandlung und Kommentare, die jeden Teil des Prozesses erklären.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Erwartete Ausgabe** (Konsole):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Öffnen Sie die beiden PNG‑Dateien in einem beliebigen Bildbetrachter. Sie sehen dieselbe GTIN codiert, aber das zweite Bild ist höher, weil das Seitenverhältnis größer ist.

## Profi‑Tipps und häufige Stolperfallen

| Situation                     | Empfehlung                                                                                                   |
|-------------------------------|--------------------------------------------------------------------------------------------------------------|
| **Niedrigauflösende Anzeigen** | Erhöhen Sie `XDimension.Pixels` auf 3 oder 4, um die Striche scharf zu halten.                               |
| **Drucken auf Thermopapier**   | Verwenden Sie `BarCodeImageFormat.Tiff` für höhere Bildtreue und setzen Sie `Resolution.DpiX/DpiY` auf 300. |
| **Dynamische Daten**           | Nutzen Sie dieselbe `BarcodeGenerator`‑Instanz und aktualisieren Sie nur `generator.CodeText` vor jedem `Save`. Das vermeidet unnötige Objektallokationen. |
| **Ungültige GTIN**             | Die Bibliothek wirft `ArgumentException`, wenn die Daten nicht den GS1‑Standards entsprechen. Validieren Sie Ihre Daten, bevor Sie sie an den Generator übergeben. |
