# Wie man Barcodes in C# mit Aspose.BarCode füllt

Wenn Sie **wie man Barcodes füllt** in einer .NET-Anwendung benötigen, zeigt dieses Tutorial den vollständigen Prozess. Sie werden einen postalischen Planet‑Barcode mit durchgezogenen Balken erzeugen und dann eine leere‑Balken‑Version desselben Barcodes erstellen, alles mit einer einzigen Code‑Zeile Änderung.

Der Leitfaden deckt alles ab, was Sie wissen müssen: Projekt‑Setup, X‑Dimension‑Feinabstimmung, Umschalten zwischen gefüllten und leeren Balken und wie Sie die erzeugten PNG‑Dateien überprüfen. Keine externe Dokumentation ist nötig – einfach den Code kopieren, ausführen und das Ergebnis sehen.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

* .NET 6.0 SDK oder später installiert  
* Eine Entwicklungsumgebung wie Visual Studio 2022 oder VS Code  
* Das **Aspose.BarCode for .NET** NuGet‑Paket (`Aspose.BarCode`)  

Diese Elemente bilden die minimale Basis für den **barcode generator c#**‑Teil des Tutorials.

## Wie man Barcodes füllt – Projekt einrichten

1. Erstellen Sie ein neues Konsolenprojekt:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Fügen Sie das Aspose.BarCode‑Paket hinzu:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Öffnen Sie die erzeugte Datei `Program.cs` und ersetzen Sie deren Inhalt durch das vollständige Beispiel, das später in diesem Artikel gezeigt wird.

Das Projekt enthält nun alles, was nötig ist, um **postalische Barcodes** zu erzeugen.

## Postal‑Barcode mit durchgezogenen Balken erzeugen

Der erste Schritt besteht darin, einen Planet‑Barcode zu erstellen, der gefüllte (durchgezogene) Balken verwendet. Planet ist die Symbologie, die von vielen Postdiensten zum Sortieren verwendet wird.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Warum diese Zeilen wichtig sind**

* `EncodeTypes.Planet` gibt dem Generator an, welche Symbologie verwendet werden soll; Planet ist der Standard für postalische Barcodes.  
* `XDimension.Pixels = 4` erhöht die Modulbreite, wodurch der Barcode leichter zu scannen und beim Druck optisch klarer ist.  
* `Save` schreibt das Bild im PNG‑Format auf die Festplatte, ein verlustfreies Format, das für die Weiterverarbeitung geeignet ist.

Das Ausführen dieses Blocks erzeugt **PostalPlanetFilledBars.png**, ein Bild mit durchgezogenen Balken, das den Postvorschriften entspricht.

## Leeren Barcode mit Planet‑Symbologie erstellen

Manchmal erwartet ein Postsystem, dass die Balken leer (ungefüllt) sind, während die Zwischenräume solide bleiben. Der Wechsel in diesen Modus erfordert nur eine Eigenschaftsänderung.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Warum das funktioniert**

Durch Setzen von `FilledBars = false` wird dem Renderer mitgeteilt, den visuellen Stil zu invertieren: Balken werden transparent (leer) und der Hintergrund undurchsichtig. Das ist das genaue Gegenteil des zuvor gezeigten Standardverhaltens und ermöglicht es Ihnen, **leere Barcodes** zu erzeugen, ohne die kodierten Daten zu ändern.

## Vollständiges, ausführbares Beispiel

Unten finden Sie das komplette Programm, das beide Abschnitte kombiniert. Kopieren Sie es in `Program.cs`, ersetzen Sie `YOUR_DIRECTORY/` durch einen echten Ordnerpfad und führen Sie `dotnet run` aus.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Erwartete Ausgabe

Nach der Ausführung finden Sie zwei PNG‑Dateien im angegebenen Ordner:

| File name                     | Visuelle Beschreibung |
|-------------------------------|-----------------------|
| `PostalPlanetFilledBars.png`  | Balken sind schwarz durchgezogen auf weißem Hintergrund |
| `PostalPlanetEmptyBars.png`   | Balken sind transparent (weiß) auf schwarzem Hintergrund |

Beide Bilder kodieren dieselbe numerische Zeichenkette `"123456"` und teilen die gleiche X‑Dimension, sodass sie aus Sicht der Datenvalidierung austauschbar sind.

## Häufige Fragen und Sonderfälle

**Was ist, wenn der Ausgabepfad nicht existiert?**  
Die `Save`‑Methode wirft eine `DirectoryNotFoundException`. Erstellen Sie den Ordner vorher oder wickeln Sie die Aufrufe in einen `try / catch`‑Block, der das Verzeichnis bei Bedarf erzeugt:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**Kann ich ein anderes Bildformat verwenden?**  
Ja. Ersetzen Sie `BarCodeImageFormat.Png` durch `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` oder ein beliebiges von Aspose.BarCode unterstütztes Format.

**Beeinflusst die X‑Dimension die Lesbarkeit durch Scanner?**  
Eine größere Pixelbreite macht die Balken breiter, was die Lesbarkeit bei Low‑Resolution‑Scannern verbessern kann. Sehr große Werte können jedoch den druckbaren Bereich überschreiten. Typische Werte liegen bei 2 bis 6 Pixeln für 300 dpi‑Druck.

**Ist die `EncodeTypes.Planet`‑Symbologie die einzige postalische Option?**  
Nein. Aspose.BarCode unterstützt außerdem `EncodeTypes.Postnet` und `EncodeTypes.USPSIntelligentMail`. Die gleiche `FilledBars`‑Eigenschaft funktioniert auch mit diesen Typen.
