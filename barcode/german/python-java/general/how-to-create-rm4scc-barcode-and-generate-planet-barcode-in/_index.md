# Wie man einen RM4SCC-Barcode erstellt und einen Planet-Barcode in C# generiert

Wenn Sie einen **RM4SCC-Barcode** für Postanwendungen erstellen müssen, zeigt Ihnen dieser Leitfaden die genauen Schritte. Sie lernen außerdem, wie Sie einen **Planet-Barcode** mit automatischer und fester Höhe erzeugen, sodass derselbe Code für jede postale Symbolik funktioniert.

Der Leitfaden behandelt alles, was nötig ist, um PNG‑Bilder zu erzeugen, die den Poststandards entsprechen. Keine externen Werkzeuge sind erforderlich, außer der Aspose.BarCode for .NET‑Bibliothek. Am Ende können Sie Barcodes programmgesteuert erzeugen und ihre Abmessungen präzise steuern.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

* .NET 6.0 oder höher installiert
* Visual Studio 2022 (oder jede C#‑IDE)
* Aspose.BarCode für .NET NuGet‑Paket  
  `Install-Package Aspose.BarCode`
* Schreibberechtigung für das Ausgabeverzeichnis

Diese Elemente ermöglichen es Ihnen, den Beispielcode zu kompilieren und auszuführen, ohne zusätzliche Konfiguration.

## Schritt 1: Initialisieren des Barcode-Generators für RM4SCC

Der erste Vorgang erstellt eine `BarcodeGenerator`‑Instanz, die für die RM4SCC‑Symbolik konfiguriert ist. Dieses Objekt enthält alle Einstellungen für das Barcode‑Bild.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Warum das wichtig ist** – `EncodeTypes.RM4SCC` weist Aspose an, das postalische RM4SCC‑Format zu verwenden, während die Datenzeichenkette `"123456"` die Postleitzahl darstellt, die Sie codieren möchten.

## Schritt 2: Festlegen der Modulbreite (X‑Dimension)

Die Modulbreite steuert die Größe des dünnen Balkens. Ein gängiger Wert für Post‑Barcodes ist 4 Pixel.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Erklärung** – Die X‑Dimension beeinflusst die Lesbarkeit des Barcodes insgesamt. Die Wahl von 4 px entspricht den meisten Postscannern.

## Schritt 3: Speichern mit automatischer Balkenhöhe

Wenn Sie keinen Höhenwert angeben, berechnet Aspose die optimale Höhe automatisch basierend auf den Symbolik‑Regeln.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Ergebnis** – Das erzeugte PNG (`PostalRM4SCCBarHeightNone.png`) enthält einen korrekt dimensionierten RM4SCC‑Barcode, der druckbereit ist.

## Schritt 4: Erstellen eines Planet‑Barcodes mit automatischer Höhe

Dasselbe Muster funktioniert für die Planet‑Symbolik. Beginnen Sie damit, den Generator mit `EncodeTypes.Planet` zu initialisieren.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Warum den Code wiederverwenden** – Sowohl RM4SCC als auch Planet verwenden dieselbe Parameterstruktur, sodass Sie die Symbolik nur durch Ändern des `EncodeTypes`‑Werts umschalten können.

## Schritt 5: Festlegen einer festen Balkenhöhe für RM4SCC

Einige Postdienste verlangen eine spezifische Balkenhöhe (z. B. 100 px). Sie können diese vor dem Speichern explizit festlegen.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Tipp** – Das Setzen von `BarHeight.Pixels` überschreibt die automatische Berechnung und gibt Ihnen die volle Kontrolle über die visuelle Größe.

## Schritt 6: Festlegen einer festen Balkenhöhe für Planet

Wenden Sie dieselbe Fest‑Höhen‑Technik auf einen Planet‑Barcode an.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Ergebnis** – Sowohl `PostalRM4SCCBarHeight100Pixels.png` als auch `PostalPlanetBarHeight100Pixels.png` enthalten Barcodes mit einer einheitlichen 100 px Balkenhöhe, die strenge Postvorgaben erfüllt.

## Vollständiger Quellcode

Unten finden Sie das vollständige, ausführbare Programm, das alle vier Beispiele umfasst. Kopieren Sie es in ein neues Konsolenprojekt und passen Sie den Ausgabepfad nach Bedarf an.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Erwartete Ausgabe** – Nach dem Ausführen des Programms enthält das angegebene Verzeichnis vier PNG‑Dateien:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC mit automatischer Höhe
* `PostalPlanetBarHeightNone.png` – Planet mit automatischer Höhe
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC mit 100 px Höhe
* `PostalPlanetBarHeight100Pixels.png` – Planet mit 100 px Höhe

Öffnen Sie eine beliebige Datei, um zu überprüfen, dass die Balken scharf sind, die Modulbreite 4 px beträgt und die Höhe der gewählten Einstellung entspricht.

## Häufige Fragen und Sonderfälle

| Frage | Antwort |
|----------|--------|
| **Can I use other image formats?** | Yes. Replace `BarCodeImageFormat.Png` with `Jpeg`, `Bmp`, or `Gif` as needed. |
| **What if the data string is longer?** | The generator automatically adjusts the number of bars. Ensure the data complies with the symbology’s length limits (RM4SCC ≤ 6 digits, Planet ≤ 6 digits). |
| **How do I change bar color?** | Set `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` before calling `Save`. |
| **Is DPI important for printing?** | You can set `rm4sccAuto.Parameters.ImageResolution.DpiX` and `DpiY` to match your printer’s resolution. |
