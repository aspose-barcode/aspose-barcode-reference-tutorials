# Wie man PDF417-Barcode in C# generiert – kompaktes Beispiel

Wenn Sie **PDF417-Barcode** in einer C#‑Anwendung generieren müssen, zeigt Ihnen diese Anleitung eine vollständige, sofort lauffähige Lösung. Wir erstellen einen kompakten PDF417‑Barcode, passen die Modulbreite an, definieren die Spaltenanzahl und speichern das Ergebnis als PNG‑Bild – alles mit der Aspose.BarCode .NET‑Bibliothek.

Das Generieren eines PDF417‑Barcodes ist üblich, wenn Sie große Datenmengen (z. B. URLs, Visitenkarten oder Inventar‑IDs) in einem platzsparenden zweidimensionalen Format codieren möchten. Am Ende dieses Tutorials verfügen Sie über eine funktionierende `BarcodeGenerator`‑Instanz, die einen kompakten, gut lesbaren Barcode erzeugt, der zum Drucken oder Anzeigen bereit ist.

## Voraussetzungen

- .NET 6.0 oder höher (der Code funktioniert auch mit .NET Framework 4.8)
- Visual Studio 2022 (oder jede C#‑IDE)
- Aspose.BarCode für .NET NuGet‑Paket (`Install-Package Aspose.BarCode`)
- Grundlegende Kenntnisse der C#‑Syntax

Keine zusätzliche Konfiguration ist erforderlich; das Beispiel läuft als Konsolenanwendung.

## Schritt 1: PDF417‑Barcode‑Generator erstellen

Der erste Schritt besteht darin, `BarcodeGenerator` mit dem Enum `EncodeTypes.Pdf417` und dem zu codierenden Text zu instanziieren.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Warum das wichtig ist:** `EncodeTypes.Pdf417` weist die Bibliothek an, die PDF417‑Symbologie zu verwenden, während das zweite Argument die Datenlast festlegt. Sie können `"Compact example"` durch jede Zeichenkette bis zu 1 800 Zeichen ersetzen.

## Schritt 2: Modulbreite (X‑Dimension) in Pixeln festlegen

Die X‑Dimension definiert die Breite eines einzelnen Barcode‑Moduls (das kleinste schwarze oder weiße Quadrat). Ein kleinerer Pixelwert erzeugt einen dichteren Barcode.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Warum das wichtig ist:** Ein Wert von `2` Pixeln erzeugt ein kompaktes Erscheinungsbild, ohne die Scan‑Zuverlässigkeit auf den meisten modernen Scannern zu beeinträchtigen. Passen Sie den Wert an, wenn Sie für den Niedrigauflösungsdruck größere Module benötigen.

## Schritt 3: Anzahl der Spalten festlegen

PDF417 ermöglicht die Steuerung der Spaltenanzahl, was das Seitenverhältnis des Barcodes beeinflusst.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Warum das wichtig ist:** Weniger Spalten machen den Barcode höher, während mehr Spalten ihn flacher machen. Drei Spalten eignen sich gut für ein kompaktes, hochformatiges Layout.

## Schritt 4: Kompaktmodus aktivieren, indem der Barcode gekürzt wird

Der Kompaktmodus entfernt unnötige Auffüllungszeilen, wodurch der Barcode kleiner wird, während die codierten Daten erhalten bleiben.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Warum das wichtig ist:** Kürzen ist ideal, wenn der Bildschirmplatz begrenzt ist (z. B. mobile Apps oder kleine Etiketten). Der Barcode bleibt vollständig lesbar, da der Codierungsalgorithmus die Fehlerkorrektur‑Stufen automatisch anpasst.

## Schritt 5: Barcode als PNG‑Bild speichern

Zum Schluss schreiben Sie den erzeugten Barcode in eine Datei. PNG bewahrt verlustfreie Qualität, was für Barcodescanner entscheidend ist.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Das Ausführen des Programms erzeugt `CompactPdf417.png` im Arbeitsverzeichnis der ausführbaren Datei. Das Bild sieht folgendermaßen aus:

![Generated compact PDF417 barcode](CompactPdf417.png "Generated compact PDF417 barcode")

**Erwartete Ausgabe:** Ein 2‑Pixel‑breiter, dreispaltiger PDF417‑Barcode, der den Text „Compact example“ codiert. Das Scannen des PNGs mit einem Standard‑Barcode‑Scanner sollte die ursprüngliche Zeichenkette zurückgeben.

## Häufige Variationen und Sonderfälle

| Situation | Wie man den Code anpasst |
|-----------|--------------------------|
| **Längere Daten ( > 500 Zeichen )** | Erhöhen Sie `Columns` auf 5‑7, um zu verhindern, dass der Barcode zu hoch wird. |
| **Druck mit höherer Auflösung** | Setzen Sie `XDimension.Pixels` auf 3 oder 4 für größere Module. |
| **Anderes Bildformat** | Ersetzen Sie `BarCodeImageFormat.Png` durch `Jpeg` oder `Bmp`, je nach Bedarf. |
| **Barcode in ein PDF einbetten** | Verwenden Sie `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` anstelle von PNG. |

**Profi‑Tipp:** Testen Sie den erzeugten Barcode stets auf der Ziel‑Scanner‑Hardware. Einige günstige Scanner haben Probleme mit sehr kleinen X‑Dimensionen; wenn Sie Lesefehler feststellen, erhöhen Sie den Pixelwert um einen Schritt.

## Vollständiges, ausführbares Beispiel

Unten finden Sie das vollständige Programm, das Sie in ein neues Konsolenprojekt kopieren‑und‑einfügen können. Es werden keine zusätzlichen Dateien benötigt.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Kompilieren und führen Sie das Programm aus (`dotnet run`, wenn Sie die .NET‑CLI verwenden). Nach der Ausführung öffnen Sie `CompactPdf417.png`, um das visuelle Ergebnis zu überprüfen.

## Fazit

Sie wissen jetzt, **wie man PDF417‑Barcode** in C# mit einem kompakten Layout, benutzerdefinierter X‑Dimension und Spalteneinstellungen generiert. Das Beispiel zeigt die wesentlichen Schritte: `BarcodeGenerator` instanziieren, `XDimension` und `Columns` konfigurieren, `Truncate` für den Kompaktmodus aktivieren und schließlich das Bild speichern.

Ab hier können Sie weitere Funktionen wie Fehlerkorrektur‑Level, benutzerdefinierte Farben oder das direkte Einbetten des Barcodes in PDFs erkunden. Experimentieren Sie mit verschiedenen `EncodeTypes`, wenn Sie andere Symbologien benötigen (z. B. QR, Code128) und integrieren Sie dasselbe Muster der Parameterkonfiguration.
