# PDF417‑Barcode in C# mit Aspose – Schritt‑für‑Schritt‑Anleitung

Wenn Sie in einer .NET‑Anwendung **PDF417‑Barcode generieren** müssen, zeigt Ihnen diese Anleitung genau, wie es geht. Sie sehen ein vollständiges, sofort ausführbares Beispiel, das grundlegende, kompakte, Micro, GS1‑Micro und Macro PDF417‑Barcodes mit Aspose.BarCode für .NET erstellt.

Das Generieren eines PDF417‑Barcodes ist eine häufige Anforderung für Versandetiketten, Transportdokumente und Bestandsverwaltungssysteme. Am Ende dieses Tutorials können Sie **PDF417‑Barcode‑Bilder generieren**, die wichtigsten Parameter verstehen und den Code an Ihre eigenen Daten‑Payloads anpassen.

## Voraussetzungen

- .NET 6.0 SDK oder neuer (der Code funktioniert auch mit .NET Framework 4.7+)
- Visual Studio 2022 oder jede andere C#‑IDE
- Aspose.BarCode für .NET NuGet‑Paket (`Aspose.BarCode`) installiert
- Grundlegende Kenntnisse der C#‑Syntax

> **Profi‑Tipp:** Verwenden Sie die kostenlose Evaluierungslizenz von Aspose, um Laufzeitbeschränkungen während des Tests zu vermeiden.

## Schritt 1: Projekt einrichten und Namespaces importieren

Erstellen Sie ein neues Konsolen‑Projekt und fügen Sie das Aspose.BarCode‑Paket hinzu:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Öffnen Sie anschließend `Program.cs` und fügen Sie die erforderlichen `using`‑Direktiven hinzu:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Diese Namespaces geben Ihnen Zugriff auf die Klasse `BarcodeGenerator` und die Aufzählung `EncodeTypes`, die zum **Barcode‑Generieren mit C#** benötigt werden.

## Schritt 2: Einen einfachen PDF417‑Barcode generieren

Der einfachste PDF417‑Barcode verwendet die Standardeinstellungen, außer der X‑Dimension (Modulbreite) und der Anzahl der Spalten. Das Anpassen dieser Werte steuert die Gesamtabmessungen und Lesbarkeit.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Warum das funktioniert:**  
- `EncodeTypes.Pdf417` weist Aspose an, die PDF417‑Symbologie zu verwenden.  
- `XDimension.Pixels` definiert die kleinste Balkenbreite; ein Wert von 2 hält das Bild klein, ohne die Scanbarkeit zu beeinträchtigen.  
- `Pdf417.Columns` legt fest, wie viele Datenspalten der Barcode enthält; drei Spalten ergeben ein ausgewogenes Seitenverhältnis.

## Schritt 3: Einen kompakten (abgeschnittenen) PDF417‑Barcode generieren

Der kompakte Modus entfernt das Stop‑Muster und reduziert die Gesamthöhe, was für platzbeschränkte Etiketten nützlich ist.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Warum das funktioniert:**  
Durch Setzen von `Pdf417.Truncate = true` wird der abgeschnittene Modus aktiviert, der das rechte Stop‑Muster weglässt und die Barcode‑Höhe reduziert, während die Datenintegrität erhalten bleibt.

## Schritt 4: Einen Micro PDF417‑Barcode generieren

Micro PDF417 ist eine kleinere Variante, die 1‑4 Spalten unterstützt. Sie ist ideal für Anwendungen, bei denen der Platz knapp ist, z. B. kleine Produktetiketten.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Warum das funktioniert:**  
- `EncodeTypes.MicroPdf417` wählt die Mikro‑Version der Symbologie.  
- Die Spaltenzahl kann zwischen 1 und 4 liegen; die Wahl von 4 ergibt das dichteste Layout und bleibt dennoch scanbar.

## Schritt 5: Einen GS1‑konformen Micro PDF417‑Barcode generieren

GS1‑Präfixe fügen standardisierte Kennungen (z. B. GTIN, Chargennummer) zu den Barcode‑Daten hinzu. Aspose ermöglicht das direkte Einbetten dieser Informationen.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Warum das funktioniert:**  
GS1‑Anwendungskennzeichen (AIs) werden in Klammern gesetzt. Aspose analysiert sie und fügt die für GS1‑Scanner erforderliche Formatierung hinzu.

## Schritt 6: Einen Macro PDF417‑Barcode mit vollständigen Metadaten generieren

Macro PDF417 erlaubt es, ein großes Daten‑Payload auf mehrere verknüpfte Barcodes zu verteilen. Sie können datei‑bezogene Metadaten wie Datei‑ID, Segment‑Anzahl, Zeitstempel und benutzerdefinierte Zeichenketten einbetten.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Warum das funktioniert:**  
Jede `MacroPdf417*`‑Eigenschaft entspricht einem spezifischen Segment der Macro‑Barcode‑Spezifikation. Durch das Setzen dieser Werte kann ein Scanner die ursprüngliche Datei aus mehreren Barcode‑Bildern rekonstruieren.
