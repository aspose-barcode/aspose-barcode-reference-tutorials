# Wie man Barcode in C# mit Aspose.BarCode generiert und Metadaten hinzufügt

Wenn Sie **Barcode in C#** für ein Logistik‑ oder Inventarsystem benötigen, zeigt Ihnen dieser Leitfaden eine vollständige, produktionsreife Lösung. Sie sehen, wie man einen Macro PDF417‑Barcode erstellt, umfangreiche Metadaten anhängt und einen genauen Zeitstempel setzt – alles mit der Aspose.BarCode‑Bibliothek.

Das Tutorial deckt alles ab, von der Installation des NuGet‑Pakets bis zum Speichern des finalen PNG‑Bildes. Am Ende können Sie einen Barcode erzeugen, der Dateikennungen, Segmentinformationen und benutzerdefinierte Felder enthält und bereit für nachgelagerte Scanner ist, die Macro PDF417 unterstützen.

## Voraussetzungen

* .NET 6.0 SDK oder neuer (der Code funktioniert auch mit .NET Framework 4.7.2+)
* Visual Studio 2022 oder jede C#‑IDE Ihrer Wahl
* Eine aktive Aspose.BarCode‑Lizenz (die kostenlose Testversion funktioniert für die Entwicklung)
* Grundlegende Vertrautheit mit C#‑Syntax

> **Pro Tipp:** Wenn Sie eine CI/CD‑Pipeline verwenden, fügen Sie den Aspose.BarCode‑Paketverweis in Ihrer Projektdatei hinzu, damit Builds reproduzierbar bleiben.

## Schritt 1: Aspose.BarCode installieren

Öffnen Sie ein Terminal in Ihrem Projektordner und führen Sie aus:

```bash
dotnet add package Aspose.BarCode
```

Der Befehl lädt die neueste stabile Version (derzeit 24.9). Nachdem das Wiederherstellen abgeschlossen ist, können Sie die Bibliothek in Ihren Quellcodedateien referenzieren.

## Schritt 2: Ein neues C#‑Konsolenprojekt erstellen (optional)

Wenn Sie einen frischen Start bevorzugen, erstellen Sie eine Konsolenanwendung:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Die Datei `Program.cs` wird den später gezeigten Barcode‑Generierungscode enthalten.

## Schritt 3: Den Barcode‑Generator einrichten

Der Kern des Prozesses ist die Klasse `BarcodeGenerator`. Sie instanziieren sie mit dem gewünschten `EncodeTypes`‑Enum‑Wert und dem Text, den Sie codieren möchten.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Warum jede Zeile wichtig ist

* **EncodeTypes.MacroPdf417** teilt Aspose mit, einen PDF417‑Barcode zu erzeugen, der in Segmente aufgeteilt werden kann. Das ist entscheidend für große Nutzdaten, die die Kapazität eines einzelnen Symbols überschreiten.
* **XDimension.Pixels** steuert die visuelle Dichte. Ein Wert von 2 erzeugt ein klares Bild auf den meisten Bildschirmen und Druckern, ohne die Dateigröße zu vergrößern.
* **MacroPdf417\***‑Eigenschaften betten die Metadaten ein, die nachgelagerte Scanner als separate Felder (Datei‑ID, Segment‑ID usw.) auslesen. Das ist der Teil des Tutorials, der erklärt, **wie man Metadaten hinzufügt**.
* **MacroPdf417TimeStamp** demonstriert, **wie man einen Zeitstempel setzt**. Die `DateTime`‑Instanz kann jede UTC‑Zeit sein; die Verwendung von UTC vermeidet Zeitzonen‑Mehrdeutigkeiten, wenn der Barcode über Regionen hinweg transportiert wird.
* **MacroPdf417Terminator** definiert, wie die Makrosequenz endet. `Set` ist die gängigste Wahl, da sie dem Leser das letzte Segment signalisiert.
* **Save(..., BarCodeImageFormat.Png)** schreibt ein verlustfreies Bild, das die feinen Details bewahrt, die für zuverlässiges Scannen erforderlich sind.

## Schritt 4: Den erzeugten Barcode überprüfen

Führen Sie das Programm aus:

```bash
dotnet run
```

Sie sollten die Konsolenausgabe sehen:

```
Barcode saved to ExtPDF417Meta.png
```

Öffnen Sie `ExtPDF417Meta.png` in einem beliebigen Bildbetrachter. Das Bild zeigt ein kompaktes PDF417‑Symbol mit dem Text **Åspóse.Barcóde©** und den eingebetteten Makrofeldern. Das Scannen des Bildes mit einem PDF417‑kompatiblen Scanner (oder einer mobilen App, die Macro PDF417 unterstützt) liefert den ursprünglichen Text plus die von Ihnen gesetzten Metadatenwerte.

### Erwartete visuelle Merkmale

* Dunkle, gleichmäßig abgestandene vertikale Balken
* Eine Ruhezone (Rand), die automatisch von Aspose hinzugefügt wird
* Keine Verzerrung, da die `XDimension` von 2 Pixeln der nativen Auflösung des PNG entspricht

## Schritt 5: Häufige Variationen und Randfälle

### 5.1 Umgang mit Sonderzeichen

Der Beispieltext enthält Unicode‑Zeichen (`Å`, `ó`, `©`). Aspose.BarCode codiert sie standardmäßig mit UTF‑8, sodass sie im Barcode korrekt erscheinen. Wenn Sie eine andere Kodierung benötigen (z. B. ISO‑8859‑1), setzen Sie:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Große Dateikennungen

`MacroPdf417FileID` akzeptiert einen 32‑Bit‑Integer. Für Werte, die größer als `int.MaxValue` sind, teilen Sie die Kennung auf mehrere Felder auf oder verwenden Sie einen GUID, der als Zeichenkette in `MacroPdf417FileName` gespeichert wird.

### 5.3 Anpassen der Spaltenanzahl

Ein Erhöhen von `Pdf417.Columns` reduziert die Barcode‑Höhe, verbreitert jedoch jede Zeile. Wenn der Barcode auf ein schmales Etikett passen muss, reduzieren Sie die Spaltenzahl und erhöhen Sie die Zeilenanzahl automatisch.

### 5.4 Speichern in anderen Formaten

Aspose unterstützt BMP, JPEG, TIFF und SVG. Ersetzen Sie `BarCodeImageFormat.Png` durch den gewünschten Enum‑Wert, z. B. `BarCodeImageFormat.Svg` für eine skalierbare Vektorgrafik.

## Häufig gestellte Fragen

**F: Funktioniert das auf .NET Core?**  
A: Ja. Die gleiche API funktioniert auf .NET Core, .NET 5+ und .NET Framework. Referenzieren Sie einfach das passende NuGet‑Paket.

**F: Was ist, wenn ich ein nicht‑Macro PDF417 erzeugen muss?**  
A: Verwenden Sie `EncodeTypes.Pdf417` anstelle von `EncodeTypes.MacroPdf417`. Die macro‑spezifischen Eigenschaften werden ignoriert.

**F: Kann ich benutzerdefinierte Schlüssel‑/Wert‑Paare über die integrierten Felder hinaus hinzufügen?**  
A: Aspose.BarCode stellt keine beliebigen Benutzerfelder für Macro PDF417 bereit. Wenn Sie zusätzliche Daten benötigen, codieren Sie sie im Haupt‑Text‑Payload oder wechseln Sie zu einem QR‑Code, der Structured Append unterstützt.
