# PDF417-Barcode mit kompakten Einstellungen in C# generieren

Wenn Sie in einer .NET‑Anwendung **PDF417‑Barcode generieren** müssen, zeigt Ihnen dieses Handbuch, wie Sie dies mit Aspose.Barcode für .NET erledigen. Wir führen Sie durch das Erstellen des Generators, das Konfigurieren von Spalten, X‑Dimension und das Aktivieren des kompakten Modus, sodass das resultierende Symbol so klein wie möglich wird.

Das Generieren eines PDF417‑Barcodes ist üblich, wenn Sie große Datenmengen für Tickets, Ausweise oder Versandetiketten codieren müssen. Dieses Tutorial deckt den gesamten Arbeitsablauf ab – von der Installation der Bibliothek bis zum Speichern des finalen PNG – sodass Sie den Code einfach in Ihr eigenes Projekt kopieren und sofort ausführen können.

## Voraussetzungen für das Generieren eines PDF417‑Barcodes

* .NET 6.0 (oder neuer) installiert.  
* Visual Studio 2022 oder eine beliebige IDE, die C#‑Projekte unterstützt.  
* Eine NuGet‑Lizenz für **Aspose.Barcode for .NET** (die kostenlose Testversion eignet sich zum Lernen).  

Sie können die Bibliothek mit dem folgenden Befehl hinzufügen:

```bash
dotnet add package Aspose.BarCode
```

> **Profi‑Tipp:** Verwenden Sie das Flag `--version`, um eine bekannte stabile Version festzulegen, z. B. `dotnet add package Aspose.BarCode --version 23.12`.

## Einen PDF417‑Barcode‑Generator erstellen

Der erste Code‑Block erstellt eine `BarcodeGenerator`‑Instanz, die bereits für die PDF417‑Symbologie vorkonfiguriert ist. Der Text `"Åspóse.Barcóde©"` enthält Unicode‑Zeichen, um zu zeigen, dass der Generator nicht‑ASCII‑Eingaben sofort verarbeitet.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Warum das wichtig ist
`EncodeTypes.Pdf417` teilt Aspose.Barcode mit, dass Sie einen **PDF417‑Barcode** wünschen, eine gestapelte lineare Symbologie, die bis zu 1 850 Zeichen speichern kann. Die Verwendung des Konstruktors mit dem Text‑Argument erspart Ihnen einen späteren Aufruf von `SetCodeText`.

## XDimension des Barcodes festlegen (Modulgröße)

Die Modulgröße, auch X‑Dimension genannt, bestimmt, wie breit jeder einzelne Strich ist. Kleinere Pixel erzeugen ein dichteres Bild, während größere Pixel die Lesbarkeit auf Niedrigauflösungs‑Druckern verbessern.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### Warum Sie die XDimension anpassen sollten
Ein Wert von `2` Pixeln funktioniert gut für die Anzeige auf Bildschirmen und die meisten Büro‑Drucker. Wenn Sie einen höherauflösenden Druck benötigen, erhöhen Sie den Wert; wenn Sie einen kompakteren Barcode benötigen (z. B. für ein QR‑ähnliches Aussehen), reduzieren Sie ihn – jedoch niemals unter `1` Pixel, da das Bild sonst unlesbar wird.

## Anzahl der Spalten für das PDF417‑Symbol festlegen

PDF417 ermöglicht es Ihnen, zu wählen, wie viele Spalten (vertikale Stapel) der Barcode haben soll. Weniger Spalten machen den Barcode höher; mehr Spalten machen ihn breiter.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### Wann Sie die Spaltenanzahl ändern sollten
Drei Spalten erzeugen ein kompaktes, fast quadratisches Symbol, das gut auf Standard‑Ausweiskarten passt. Bei einem sehr langen String können Sie die Spaltenanzahl erhöhen, um die Höhe im Rahmen zu halten.

## Kompaktmodus aktivieren (Trunkierung)

Der Kompaktmodus entfernt automatisch ungenutzte Zeilen aus dem Symbol und verkleinert so die Gesamtabmessungen. Das ist besonders nützlich, wenn die codierten Daten nicht die gesamte Matrix ausfüllen.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Vorteile eines kompakten PDF417‑Barcodes
Wenn `Truncate` auf `true` gesetzt ist, berechnet der Generator die minimale Anzahl von Zeilen, die zum Speichern Ihrer Daten erforderlich ist, was den Tintenverbrauch und die Scanzeit reduziert. Es ist für die meisten Scanner sicher, da die PDF417‑Spezifikation den Trunkierungs‑Algorithmus definiert.

## Den generierten Barcode als Bild speichern

Zum Schluss schreiben Sie den Barcode in eine PNG‑Datei. PNG bewahrt verlustfreie Qualität und ist daher ideal für späteres Drucken oder Einbetten in PDFs.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Erwartete Ausgabe
Beim Ausführen des Programms wird `CompactPdf417.png` im angegebenen Ordner erstellt. Das Bild enthält einen **kompakten PDF417‑Barcode**, der den String `"Åspóse.Barcóde©"` mit drei Spalten, einer 2‑Pixel‑X‑Dimension und angewandter Trunkierung codiert. Sie können das Ergebnis mit jeder Barcode‑Scanner‑App oder der kostenlosen Aspose.Barcode‑Online‑Demo überprüfen.

## Häufige Variationen und Sonderfälle

| Situation | Anpassung |
|-----------|------------|
| **Sehr lange Daten (> 1500 Zeichen)** | Erhöhen Sie `Columns` oder setzen Sie `Rows` manuell (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Drucken auf einem Low‑DPI‑Drucker** | Erhöhen Sie `XDimension.Pixels` auf 3 oder 4, um Pixelbildung zu vermeiden. |
| **Transparenter Hintergrund benötigt** | Verwenden Sie `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **Einbetten in ein PDF** | Speichern Sie als `BarCodeImageFormat.Pdf` oder erhalten Sie das `Image`‑Objekt über `pdf417Generator.GenerateBarCodeImage()`. |

## Vollständiges, ausführbares Beispiel

Unten finden Sie das vollständige Programm, das Sie in ein neues Konsolenprojekt kopieren können. Es werden keine zusätzlichen Dateien benötigt.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Führen Sie `dotnet run` im Projektordner aus. Nach der Ausführung öffnen Sie `CompactPdf417.png`, um den generierten Barcode zu sehen.

## Fazit

Sie wissen jetzt, wie Sie in C# **PDF417‑Barcodes generieren** können, mit voller Kontrolle über Spalten, X‑Dimension und Kompaktmodus. Durch Anpassen der `barcode XDimension pixels`, `set PDF417 columns` und Aktivieren der `compact PDF417 barcode`‑Trunkierung können Sie einen Barcode erzeugen, der exakt den Größenanforderungen Ihrer Anwendung entspricht.

Nächste Schritte, die Sie erkunden könnten:

* Größere Datensätze codieren und mit dem Parameter `Rows` experimentieren.  
* Wechseln Sie das Ausgabeformat zu `BarCodeImageFormat.Svg` für skalierbare Webgrafiken.  
* Kombinieren Sie den Barcode mit anderen Aspose‑Komponenten, wie **Aspose.PDF**, um das Bild direkt in einen PDF‑Bericht einzubetten.  

Viel Spaß beim Programmieren und passen Sie die Einstellungen gerne an Ihre spezifische Scan‑Umgebung an!
