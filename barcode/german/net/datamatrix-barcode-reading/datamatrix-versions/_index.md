# Wie man DataMatrix‑Barcodes mit Aspose.BarCode für .NET erzeugt

Wenn Sie eine zuverlässige Methode benötigen, maschinenlesbare Symbole in Ihre .NET‑Anwendungen einzubetten, ist **wie man DataMatrix‑Barcodes erzeugt** ein häufiges Anliegen. Aspose.BarCode für .NET bietet eine vollständig verwaltete API, die jeden Schritt übernimmt – von der Auswahl der richtigen DataMatrix‑Version bis zur Feinabstimmung der Fehlerkorrektur‑Level – ohne externe Werkzeuge zu benötigen. In diesem Tutorial führen wir Sie durch ein vollständiges Beispiel, erklären, warum jede Einstellung wichtig ist, und zeigen Ihnen, wie Sie das Ergebnis als PNG‑ oder JPEG‑Bild speichern.

## Schnelle Antworten
- **Welche Bibliothek erzeugt DataMatrix‑Barcodes?** Aspose.BarCode für .NET.  
- **Wie viele DataMatrix‑Versionen werden unterstützt?** Alle 30 Standard‑Quadrat‑ und Rechteck‑Versionen (von 10×10 bis 144×144 Modulen).  
- **Welche ECC‑Typen kann ich verwenden?** ECC200 (Standard) und ECC140.  
- **Benötige ich eine Lizenz für die Entwicklung?** Eine kostenlose 30‑Tage‑Testversion funktioniert für Tests; für die Produktion ist eine kommerzielle Lizenz erforderlich.  
- **Kann ich das auf .NET 6, .NET Core oder .NET Framework ausführen?** Ja – Aspose.BarCode unterstützt .NET Framework 4.5+, .NET Core 3.1+ und .NET 5/6+.

## Was ist ein DataMatrix‑Barcode?
Ein DataMatrix‑Barcode ist eine zweidimensionale, quadratische oder rechteckige Matrix aus schwarzen und weißen Zellen, die bis zu 2 335 alphanumerische Zeichen speichern kann. Er wird in der Fertigung, Logistik und im Gesundheitswesen häufig verwendet, um kleine Gegenstände zu kennzeichnen, da er selbst bei teilweiser Beschädigung lesbar bleibt.

## Warum Aspose.BarCode für .NET verwenden?
Aspose.BarCode unterstützt **50+ Ausgabeformate** (einschließlich PNG, JPEG, TIFF, SVG und PDF) und kann **alle 30 DataMatrix‑Versionen** erzeugen, ohne das gesamte Bild in den Speicher zu laden. Das ermöglicht das Erzeugen von Barcodes in Hochdurchsatz‑Diensten, die Dateien größer als 100 MB verarbeiten.

## Wie man DataMatrix‑Barcodes in .NET erzeugt

Laden Sie den `BarcodeGenerator` mit dem Typ `EncodeTypes.DataMatrix`, setzen Sie die gewünschte Version und den ECC und rufen Sie dann `Save` auf, um die Bilddatei zu schreiben. Dieses Einzeiler‑Muster funktioniert für jede gewählte Version und behandelt automatisch die Modulgröße, Ruhebereiche und Bildrendering.

## Namespaces importieren

`BarcodeGenerator` ist die Kernklasse von Aspose.BarCode zum Erzeugen von Barcode‑Bildern.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

Der Namespace `Aspose.BarCode.Generation` stellt Zugriff auf die Klasse `BarcodeGenerator` bereit, die die primäre Klasse zum Erzeugen von Barcode‑Bildern ist.

Jetzt zerlegen wir das Beispiel in mehrere Schritte.

## Schritt 1: Verzeichnis‑Pfad festlegen

Beginnen Sie damit, den Verzeichnis‑Pfad zu definieren, in dem Sie die erzeugten DataMatrix‑Barcodes speichern möchten.

```csharp
string path = "Your Directory Path";
```

Ersetzen Sie `"Your Directory Path"` durch den tatsächlichen Pfad, in dem Sie die Barcode‑Bilder speichern möchten.

## Schritt 2: Barcode‑Generator initialisieren

Erstellen Sie eine Instanz der Klasse `BarcodeGenerator` und geben Sie den Barcode‑Typ als `DataMatrix` an. Sie können außerdem die zu codierenden Daten angeben.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` ist die Hauptklasse, die Barcode‑Symbole erstellt und rendert.

## Schritt 3: Barcode‑Eigenschaften konfigurieren

Sie können verschiedene Eigenschaften des DataMatrix‑Barcodes anpassen, z. B. seine Abmessungen und den ECC‑Typ (Error Correction Code). Hier ein Beispiel, das die X‑Dimension auf 4 Pixel setzt und ECC200 wählt:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` legt die Größe jedes Moduls in Pixeln fest, und `DataMatrixEcc` wählt das Fehlerkorrektur‑Level.

## Schritt 4: DataMatrix‑Version festlegen und speichern

Sie können die DataMatrix‑Version festlegen, indem Sie die Anzahl der Zeilen und Spalten setzen. Nach der Konfiguration der Version speichern Sie das Barcode‑Bild.

Beispiel: Einen DataMatrix‑Barcode mit 22 Zeilen und 22 Spalten unter Verwendung von ECC200 erzeugen:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

Analog können Sie einen Barcode mit anderen Parametern erzeugen, indem Sie die Version und den ECC‑Typ nach Bedarf ändern.

## Schritt 5: Für andere Versionen wiederholen

Sie können Schritt 4 für andere DataMatrix‑Versionen wiederholen. Beispiel: Einen Barcode mit 12 Zeilen und 64 Spalten unter Verwendung von ECC200 erzeugen:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Schritt 6: ECC‑Typen wechseln

Wenn Sie den ECC‑Typ zu Ecc140 ändern möchten, können Sie dies tun, indem Sie die ECC‑Eigenschaft aktualisieren:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Schritt 7: Barcodes mit verschiedenen Versionen und ECC erzeugen

Wiederholen Sie Schritt 4 für andere DataMatrix‑Versionen und ECC‑Typen und speichern Sie jeden Barcode unter einem eindeutigen Dateinamen.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

Nachdem Sie nun gelernt haben, wie man DataMatrix‑Barcodes mit Aspose.BarCode für .NET erzeugt, können Sie diese Funktionalität einfach in Ihre .NET‑Anwendungen integrieren.

## Häufige Fallstricke und Fehlerbehebungstipps

- **Falsche Versionsabmessungen** – DataMatrix‑Versionen haben feste Zeilen/Spalten‑Paare. Die Angabe eines nicht passenden Paares (z. B. 10 × 20) löst eine `ArgumentException` aus. Verwenden Sie stets eine der unterstützten Kombinationen aus der API‑Dokumentation.  
- **Fehlende Lizenz** – Im Testmodus enthalten die erzeugten Bilder ein Wasserzeichen. Wenden Sie vor der Erstellung des Generators eine gültige Lizenz an mit `License license = new License(); license.SetLicense("Aspose.BarCode.lic");`, um das Wasserzeichen zu entfernen. Die Klasse `License` lädt eine Lizenzdatei, um das Produkt zu aktivieren.  
- **Große Bildgröße** – Wenn Sie eine hochauflösende Ausgabe benötigen, erhöhen Sie die Eigenschaft `XDimension`; die Bibliothek skaliert das Bild proportional, ohne die Lesbarkeit zu verlieren.
