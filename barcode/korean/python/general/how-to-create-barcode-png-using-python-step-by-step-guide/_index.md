# Python을 사용하여 바코드 PNG 만들기 – 단계별 가이드

임의의 문자열에서 **barcode PNG** 파일을 생성해야 한다면, 이 튜토리얼은 바로 실행할 수 있는 솔루션을 제공합니다. Code 128 바코드를 생성하고, 텍스트를 바코드 이미지로 변환하며, 결과를 PNG 파일로 저장하는 방법을 정확히 보여줍니다—모두 몇 줄의 Python 코드만으로 가능합니다.

이 가이드는 필요한 라이브러리 설치부터 다양한 사용 사례에 맞춘 출력 커스터마이징까지 알아야 할 모든 내용을 다룹니다. 끝까지 읽으면 추가 문서를 찾지 않고도 어떤 Python 프로젝트에든 바코드 생성을 삽입할 수 있게 됩니다.

## 배울 내용

* Code 128을 지원하는 **barcode generator python** 패키지를 설치합니다.
* `BarCodeGenerator`를 사용하여 텍스트 문자열에서 **code 128 barcode**를 생성합니다.
* `save`를 사용해 결과를 고품질 PNG로 저장합니다.
* 이미지 크기, 전경/배경 색상을 조정하고 일반적인 오류를 처리합니다.
* PNG가 올바르게 생성되었는지 확인합니다.

### 사전 요구 사항

| 요구 사항 | 이유 |
|-------------|--------|
| Python 3.8+ | 최신 구문 및 타입 힌트 |
| Internet access (for `pip install`) | 라이브러리를 다운로드하기 위해 |
| Write permission to a folder | 생성된 PNG를 저장하기 위해 |

외부 서비스가 필요하지 않으며, 모든 작업이 로컬에서 실행됩니다.

## 1단계: 바코드 라이브러리 설치

Python에서 **텍스트를 바코드로 변환**하는 가장 간단한 방법은 **Aspose.BarCode for Python via .NET** 패키지를 사용하는 것으로, 기본적으로 Code 128을 지원합니다.

```bash
pip install aspose-barcode
```

> **Pro tip:** 가상 환경에서 작업한다면, 명령을 실행하기 전에 환경을 활성화하여 종속성을 격리하세요.

## 2단계: 필요한 클래스 가져오기

설치 후, 핵심 클래스를 가져옵니다. import 문이 짧아 코드가 읽기 쉽습니다.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator`는 바코드 이미지를 생성합니다.
* `EncodeTypes`는 `CODE_128`을 포함한 지원되는 심볼리지를 열거합니다.

## 3단계: 인코딩할 텍스트 정의

알파벳과 숫자를 조합한 문자열을 선택하세요. Code 128은 전체 ASCII 세트를 표현할 수 있어 숫자에만 제한되지 않습니다.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

입력에 지원되지 않는 문자가 포함되면, 제너레이터가 `ValueError`를 발생시킵니다. 사용자 제공 데이터를 예상한다면 할당을 `try` 블록으로 감싸세요.

## 4단계: Code 128용 바코드 제너레이터 생성

원하는 심볼리와 정의한 텍스트를 사용해 `BarCodeGenerator`를 인스턴스화합니다. 이것이 Python에서 **바코드 생성 방법**의 핵심입니다.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

왜 Code 128인가요? 높은 밀도를 제공하고 전체 ASCII 범위를 인코딩할 수 있어 재고 시스템, 배송 라벨, 티켓 발행 등에 이상적입니다.

## 5단계: (선택) 외관 커스터마이징

바코드를 저장하기 전에 세밀하게 조정할 수 있습니다. 다음 옵션이 일반적입니다.

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

이 설정들은 인코딩된 데이터를 변경하지 않고 최종 **create barcode png** 출력에 영향을 줍니다.

## 6단계: 바코드를 PNG 파일로 저장

마지막으로 이미지를 디스크에 씁니다. `save` 메서드는 파일 확장자를 자동으로 감지하므로 `.png`를 지정하면 PNG 이미지가 생성됩니다.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

대상 디렉터리가 존재하지 않으면 Python이 `FileNotFoundError`를 발생시킵니다. 미리 디렉터리를 만들거나 `exist_ok=True` 옵션을 사용해 `os.makedirs`를 이용하세요.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### 예상 출력

스크립트를 실행하면 `output` 폴더에 `extended_barcode.png`가 생성됩니다. 파일을 열면 `1234567890`을 인코딩한 선명한 Code 128 바코드가 표시됩니다.

## 7단계: 바코드 검증 (간단한 확인)

같은 라이브러리를 사용해 PNG를 다시 읽어 인코딩된 값이 원본 텍스트와 일치하는지 확인할 수 있습니다.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

이 블록을 실행하면 다음이 출력됩니다:

```
Verification succeeded: 1234567890
```

assertion이 실패하면 `barcode_text`와 설정한 커스텀 매개변수를 다시 확인하세요.

## 일반적인 변형 및 엣지 케이스

| 상황 | 조정 |
|-----------|------------|
| **길이가 긴 텍스트 (> 20자)** | `image_width`를 늘려 잘림을 방지합니다. |
| **투명 배경이 필요함** | 저장하기 전에 `back_color = "Transparent"`로 설정합니다. |
| **루프에서 여러 바코드 생성** | `for` 루프로 3‑6 단계를 감싸고 각 반복마다 `barcode_text`를 변경합니다. |
| **PNG 대신 JPEG로 저장** | 파일 확장자를 `.jpg`로 바꾸면 라이브러리가 자동으로 포맷을 처리합니다. |
| **헤드리스 서버에서 실행** | 라이브러리는 GUI가 필요 없으므로 CI 파이프라인에 안전합니다. |

## 빠른 복사를 위한 전체 스크립트

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

`generate_barcode.py`라는 파일명으로 저장하고 실행합니다:

```bash
python generate_barcode.py
```

확인 메시지와 `output` 폴더에 새 PNG 파일이 생성된 것을 볼 수 있습니다.
