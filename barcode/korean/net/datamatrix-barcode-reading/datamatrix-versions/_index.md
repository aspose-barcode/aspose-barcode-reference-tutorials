# Aspose.BarCode for .NET을 사용하여 DataMatrix 바코드 생성 방법

.NET 애플리케이션에 기계 판독 가능한 심볼을 삽입하는 신뢰할 수 있는 방법이 필요하다면, **DataMatrix 바코드 생성**은 일반적인 요구 사항입니다. Aspose.BarCode for .NET은 전체 과정을 처리하는 완전 관리형 API를 제공하며, 올바른 DataMatrix 버전을 선택하고 오류 정정 수준을 미세 조정하는 모든 단계를 외부 도구 없이 수행합니다. 이 튜토리얼에서는 전체 예제를 단계별로 살펴보고 각 설정이 왜 중요한지 설명하며, 결과를 PNG 또는 JPEG 이미지로 저장하는 방법을 보여드립니다.

## 빠른 답변
- **DataMatrix 바코드를 생성하는 라이브러리는 무엇인가요?** Aspose.BarCode for .NET.  
- **지원되는 DataMatrix 버전은 몇 개인가요?** 10×10부터 144×144 모듈까지 총 30개의 표준 정사각형 및 직사각형 버전 모두 지원합니다.  
- **어떤 ECC 유형을 사용할 수 있나요?** ECC200(기본) 및 ECC140.  
- **개발용 라이선스가 필요합니까?** 테스트용으로는 30일 무료 체험판이 작동하며, 상용 환경에서는 상업용 라이선스가 필요합니다.  
- **.NET 6, .NET Core 또는 .NET Framework에서 실행할 수 있나요?** 예—Aspose.BarCode는 .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6+을 지원합니다.

## DataMatrix 바코드란?
DataMatrix 바코드는 흑백 셀로 구성된 2차원 정사각형 또는 직사각형 매트릭스로, 최대 2,335개의 영문자 및 숫자를 저장할 수 있습니다. 제조, 물류, 의료 분야에서 작은 품목에 표시하기에 널리 사용되며, 부분적으로 손상되어도 판독이 가능합니다.

## 왜 Aspose.BarCode for .NET을 사용해야 하나요?
Aspose.BarCode는 **50개 이상의 출력 형식**(PNG, JPEG, TIFF, SVG, PDF 등)을 지원하고, 전체 이미지를 메모리에 로드하지 않고도 **모든 30개의 DataMatrix 버전**을 생성할 수 있어 100 MB 이상의 대용량 파일을 처리하는 고처리량 서비스에서도 바코드를 효율적으로 만들 수 있습니다.

## .NET에서 DataMatrix 바코드를 생성하는 방법

`BarcodeGenerator`를 `EncodeTypes.DataMatrix` 유형으로 로드하고, 원하는 버전과 ECC를 설정한 뒤 `Save`를 호출하여 이미지 파일을 저장합니다. 이 한 줄 패턴은 선택한 모든 버전에 대해 작동하며 모듈 크기, 여백 영역 및 이미지 렌더링을 자동으로 처리합니다.

## 네임스페이스 가져오기

`BarcodeGenerator`는 바코드 이미지를 생성하기 위한 Aspose.BarCode의 핵심 클래스입니다.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

`Aspose.BarCode.Generation` 네임스페이스는 `BarcodeGenerator` 클래스를 제공하며, 이는 바코드 이미지를 생성하는 주요 클래스입니다.

이제 예제를 여러 단계로 나누어 살펴보겠습니다.

## 단계 1: 디렉터리 경로 설정

생성된 DataMatrix 바코드를 저장할 디렉터리 경로를 정의합니다.

```csharp
string path = "Your Directory Path";
```

`"Your Directory Path"`를 실제 바코드 이미지를 저장하려는 경로로 바꾸세요.

## 단계 2: 바코드 생성기 초기화

`BarcodeGenerator` 클래스의 인스턴스를 만들고 바코드 유형을 `DataMatrix`로 지정합니다. 또한 바코드에 인코딩할 데이터를 제공할 수 있습니다.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator`는 바코드 심볼을 생성하고 렌더링하는 주요 클래스입니다.

## 단계 3: 바코드 속성 구성

DataMatrix 바코드의 차원 및 ECC(오류 정정 코드) 유형과 같은 다양한 속성을 사용자 정의할 수 있습니다. 아래 예시는 X‑dimension을 4픽셀로 설정하고 ECC200을 선택하는 방법을 보여줍니다.

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension`은 각 모듈의 픽셀 크기를 설정하고, `DataMatrixEcc`는 오류 정정 수준을 선택합니다.

## 단계 4: DataMatrix 버전 설정 및 저장

행과 열 수를 지정하여 DataMatrix 버전을 설정할 수 있습니다. 버전을 구성한 후 바코드 이미지를 저장합니다.

예를 들어 ECC200을 사용하여 22행 22열의 DataMatrix 바코드를 만들려면:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

필요에 따라 버전 및 ECC 유형을 변경하여 다른 매개변수로 바코드를 생성할 수도 있습니다.

## 단계 5: 다른 버전으로 반복

다른 DataMatrix 버전에 대해 단계 4를 반복할 수 있습니다. 예를 들어 ECC200을 사용하여 12행 64열의 바코드를 만들려면:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## 단계 6: ECC 유형 전환

ECC 유형을 Ecc140으로 변경하려면 ECC 속성을 업데이트하면 됩니다:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## 단계 7: 다양한 버전 및 ECC로 바코드 생성

다른 DataMatrix 버전 및 ECC 유형에 대해 단계 4를 반복하고, 각 바코드를 고유한 파일 이름으로 저장합니다.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

이제 Aspose.BarCode for .NET을 사용하여 DataMatrix 바코드를 생성하는 방법을 배웠으므로, 이 기능을 .NET 애플리케이션에 쉽게 통합할 수 있습니다.

## 일반적인 함정 및 문제 해결 팁

- **잘못된 버전 차원** – DataMatrix 버전은 고정된 행/열 쌍을 가집니다. 일치하지 않는 쌍(예: 10 × 20)을 제공하면 `ArgumentException`이 발생합니다. API 문서에 나열된 지원 조합 중 하나를 항상 사용하세요.  
- **라이선스 누락** – 체험판 모드에서는 생성된 이미지에 워터마크가 삽입됩니다. 워터마크를 제거하려면 `License license = new License(); license.SetLicense("Aspose.BarCode.lic");`와 같이 유효한 라이선스를 적용한 후 생성기를 만들세요. `License` 클래스는 제품을 활성화하기 위해 라이선스 파일을 로드합니다.  
- **이미지 크기 과다** – 고해상도 출력이 필요하면 `XDimension` 속성을 늘리세요. 라이브러리는 가독성을 잃지 않으면서 이미지를 비례적으로 확대합니다.
