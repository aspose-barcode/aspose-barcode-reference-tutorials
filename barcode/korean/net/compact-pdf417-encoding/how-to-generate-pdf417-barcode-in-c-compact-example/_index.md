# C#에서 PDF417 바코드 생성하기 – 컴팩트 예제

C# 애플리케이션에서 **PDF417 바코드**를 생성해야 할 경우, 이 가이드는 완전하고 바로 실행 가능한 솔루션을 보여줍니다. Aspose.BarCode .NET 라이브러리를 사용해 컴팩트 PDF417 바코드를 만들고, 모듈 너비를 조정하고, 열 개수를 정의한 뒤, 결과를 PNG 이미지로 저장하는 전체 과정을 다룹니다.

PDF417 바코드 생성은 대량의 데이터(예: URL, 연락처 카드, 재고 ID 등)를 공간 효율적인 2차원 형식으로 인코딩하고자 할 때 일반적입니다. 이 튜토리얼을 마치면 인쇄 또는 디스플레이용으로 바로 사용할 수 있는, 컴팩트하고 가독성이 높은 바코드를 생성하는 `BarcodeGenerator` 인스턴스를 갖게 됩니다.

## Prerequisites

- .NET 6.0 이상 (코드는 .NET Framework 4.8에서도 동작)
- Visual Studio 2022 (또는 기타 C# IDE)
- Aspose.BarCode for .NET NuGet 패키지 (`Install-Package Aspose.BarCode`)
- C# 문법에 대한 기본 지식

추가 설정은 필요하지 않으며, 예제는 콘솔 앱으로 실행됩니다.

## Step 1: Create a PDF417 barcode generator

첫 번째 단계는 `EncodeTypes.Pdf417` 열거형과 인코딩할 텍스트를 사용해 `BarcodeGenerator`를 인스턴스화하는 것입니다.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**왜 중요한가:** `EncodeTypes.Pdf417`은 라이브러리에게 PDF417 심볼을 사용하도록 지시하고, 두 번째 인자는 데이터 페이로드를 설정합니다. `"Compact example"`을 최대 1 800자까지의 문자열로 교체할 수 있습니다.

## Step 2: Set the module width (X‑dimension) in pixels

X‑dimension은 단일 바코드 모듈(가장 작은 검은색 또는 흰색 사각형)의 너비를 정의합니다. 픽셀 값이 작을수록 바코드가 더 촘촘해집니다.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**왜 중요한가:** `2` 픽셀 값은 대부분의 최신 스캐너에서 스캔 신뢰성을 유지하면서 컴팩트한 외관을 제공합니다. 저해상도 인쇄가 필요하면 값을 늘리세요.

## Step 3: Specify the number of columns

PDF417은 열 개수를 제어할 수 있으며, 이는 바코드의 종횡비에 영향을 줍니다.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**왜 중요한가:** 열이 적을수록 바코드가 높아지고, 열이 많을수록 평평해집니다. 세 개의 열은 컴팩트하고 세로 방향 레이아웃에 적합합니다.

## Step 4: Enable compact mode by truncating the barcode

컴팩트 모드는 불필요한 패딩 행을 제거해 바코드를 작게 만들면서도 인코딩된 데이터를 유지합니다.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**왜 중요한가:** 트렁케이션은 화면 공간이 제한된 경우(예: 모바일 앱이나 작은 라벨) 이상적입니다. 인코딩 알고리즘이 자동으로 오류 정정 수준을 조정하므로 바코드는 여전히 완전하게 읽을 수 있습니다.

## Step 5: Save the barcode as a PNG image

마지막으로 생성된 바코드를 파일에 저장합니다. PNG는 무손실 품질을 유지하므로 바코드 스캐너에 필수적입니다.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

프로그램을 실행하면 실행 파일의 작업 디렉터리에 `CompactPdf417.png`가 생성됩니다. 이미지 예시는 다음과 같습니다:

![Generated compact PDF417 barcode](CompactPdf417.png "Generated compact PDF417 barcode")

**예상 출력:** 2픽셀 너비, 세 열로 구성된 PDF417 바코드이며, 텍스트 “Compact example”을 인코딩합니다. 표준 바코드 스캐너로 PNG를 스캔하면 원본 문자열이 반환됩니다.

## Common variations and edge cases

| Situation | How to adjust the code |
|-----------|------------------------|
| **Longer data ( > 500 characters )** | 바코드가 너무 높아지는 것을 방지하려면 `Columns`를 5‑7로 늘립니다. |
| **Higher‑resolution printing** | 더 큰 모듈을 위해 `XDimension.Pixels`를 3 또는 4로 설정합니다. |
| **Different image format** | 필요에 따라 `BarCodeImageFormat.Png`를 `Jpeg` 또는 `Bmp`로 교체합니다. |
| **Embedding the barcode in a PDF** | PNG 대신 `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)`를 사용합니다. |

**Pro tip:** 생성된 바코드를 대상 스캐너 하드웨어에서 항상 테스트하세요. 일부 저가형 스캐너는 매우 작은 X‑dimension에서 읽기 오류가 발생할 수 있으니, 오류가 발생하면 픽셀 값을 한 단계씩 늘려 보세요.

## Full, runnable example

아래는 새 콘솔 프로젝트에 복사‑붙여넣기 할 수 있는 전체 프로그램입니다. 추가 파일은 필요하지 않습니다.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

프로그램을 컴파일하고 실행합니다(`dotnet run`을 사용해도 됩니다). 실행 후 `CompactPdf417.png`를 열어 시각적 결과를 확인하세요.

## Conclusion

이제 C#에서 컴팩트 레이아웃, 사용자 정의 X‑dimension 및 열 설정을 활용해 **PDF417 바코드**를 생성하는 방법을 알게 되었습니다. 예제는 핵심 단계들을 보여줍니다: `BarcodeGenerator` 인스턴스화, `XDimension` 및 `Columns` 설정, 컴팩트 모드를 위한 `Truncate` 활성화, 그리고 이미지 저장. 

이후에는 오류 정정 수준, 사용자 정의 색상, 바코드를 PDF에 직접 삽입하는 기능 등을 탐색해 볼 수 있습니다. 다른 심볼이 필요하면 `EncodeTypes`를 교체해 QR, Code128 등 다양한 심볼을 구현하고, 동일한 파라미터 구성 패턴을 적용해 보세요.

코딩을 즐기시고, 바코드가 항상 첫 번째 시도에서 스캔되길 바랍니다!
