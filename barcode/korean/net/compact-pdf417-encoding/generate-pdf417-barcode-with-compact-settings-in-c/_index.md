# C#에서 컴팩트 설정으로 PDF417 바코드 생성

.NET 애플리케이션에서 **PDF417 바코드 생성**이 필요하다면, 이 가이드는 Aspose.Barcode for .NET을 사용하여 수행하는 방법을 보여줍니다. 생성기 만들기, 열 구성, X‑dimension 설정, 그리고 컴팩트 모드 활성화를 단계별로 안내하여 결과 심볼을 가능한 작게 만들 수 있습니다.

PDF417 바코드 생성은 티켓, ID, 혹은 배송 라벨과 같이 대량의 데이터를 인코딩해야 할 때 흔히 사용됩니다. 이 튜토리얼은 라이브러리 설치부터 최종 PNG 저장까지 전체 워크플로를 다루므로, 코드를 복사‑붙여넣기만 하면 바로 프로젝트에서 실행할 수 있습니다.

## PDF417 바코드 생성을 위한 사전 요구 사항

시작하기 전에 다음이 설치되어 있는지 확인하십시오:

* .NET 6.0 (또는 그 이후 버전)  
* Visual Studio 2022 또는 C# 프로젝트를 지원하는 IDE  
* **Aspose.Barcode for .NET**에 대한 NuGet 라이선스 (무료 체험판으로 학습 가능)  

다음 명령으로 라이브러리를 추가할 수 있습니다:

```bash
dotnet add package Aspose.BarCode
```

> **전문가 팁:** `--version` 플래그를 사용해 안정된 특정 버전을 지정하세요. 예: `dotnet add package Aspose.BarCode --version 23.12`.

## PDF417 바코드 생성기 만들기

첫 번째 코드 블록은 PDF417 심볼을 미리 구성한 `BarcodeGenerator` 인스턴스를 생성합니다. 텍스트 `"Åspóse.Barcóde©"`는 Unicode 문자를 포함하고 있어, 생성기가 비ASCII 입력을 바로 처리함을 보여줍니다.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### 왜 중요한가
`EncodeTypes.Pdf417`은 Aspose.Barcode에 **PDF417 바코드**를 원한다는 것을 알려줍니다. PDF417은 최대 1 850자를 저장할 수 있는 스택형 선형 심볼입니다. 텍스트 인수를 사용한 생성자 호출은 이후 `SetCodeText` 호출을 생략하게 해 줍니다.

## 바코드 XDimension(모듈 크기) 설정

모듈 크기, 즉 X‑dimension은 각 개별 바의 너비를 결정합니다. 픽셀 수가 작을수록 이미지가 조밀해지고, 픽셀 수가 클수록 저해상도 프린터에서 가독성이 향상됩니다.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### XDimension을 조정해야 하는 이유
`2` 픽셀 값은 화면 표시와 대부분의 사무용 프린터에 적합합니다. 고해상도 인쇄가 필요하면 값을 늘리고, QR‑같은 촘촘한 바코드가 필요하면 값을 낮추세요—단, `1` 픽셀 이하로 낮추면 이미지가 읽히지 않게 됩니다.

## PDF417 심볼의 열 수 설정

PDF417은 바코드가 가질 열(수직 스택) 수를 선택할 수 있게 해 줍니다. 열이 적으면 바코드가 높아지고, 열이 많으면 가로로 넓어집니다.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### 열 수를 바꿔야 할 때
세 개의 열은 컴팩트하고 거의 정사각형에 가까운 심볼을 만들며, 표준 ID 카드에 잘 맞습니다. 문자열이 매우 길 경우, 높이를 적절히 유지하기 위해 열 수를 늘릴 수 있습니다.

## 컴팩트 모드(축소) 활성화

컴팩트 모드는 사용되지 않은 행을 자동으로 제거해 전체 크기를 줄입니다. 인코딩된 데이터가 전체 매트릭스를 채우지 않을 때 특히 유용합니다.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### 컴팩트 PDF417 바코드의 장점
`Truncate`가 `true`이면, 생성기는 데이터를 저장하는 데 필요한 최소 행 수를 계산해 잉크 사용량과 스캔 시간을 감소시킵니다. PDF417 사양에 정의된 축소 알고리즘을 따르므로 대부분의 스캐너와 호환됩니다.

## 생성된 바코드를 이미지로 저장

마지막으로 바코드를 PNG 파일로 저장합니다. PNG는 무손실 품질을 유지하므로 인쇄하거나 PDF에 삽입할 때 이상적입니다.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### 예상 출력
프로그램을 실행하면 지정된 폴더에 `CompactPdf417.png`가 생성됩니다. 이 이미지에는 세 개의 열, 2‑픽셀 X‑dimension, 그리고 축소가 적용된 **컴팩트 PDF417 바코드**가 포함되어 있으며, 문자열 `"Åspóse.Barcóde©"`를 인코딩합니다. 바코드 스캐너 앱이나 무료 Aspose.Barcode 온라인 데모로 결과를 확인할 수 있습니다.

## 일반적인 변형 및 엣지 케이스

| 상황 | 조정 방법 |
|-----------|------------|
| **매우 긴 데이터 (> 1500자)** | `Columns`를 늘리거나 `Rows`를 수동으로 설정 (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **저해상도 프린터에 인쇄** | 픽셀화를 방지하기 위해 `XDimension.Pixels`를 3 또는 4로 높이세요. |
| **투명 배경 필요** | `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })` 사용. |
| **PDF에 삽입** | `BarCodeImageFormat.Pdf`로 저장하거나 `pdf417Generator.GenerateBarCodeImage()`를 통해 `Image` 객체를 얻으세요. |

## 전체 실행 가능한 예제

아래는 새 콘솔 프로젝트에 복사해 넣을 수 있는 완전한 프로그램입니다. 추가 파일은 필요하지 않습니다.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

프로젝트 폴더에서 `dotnet run`을 실행하세요. 실행이 끝난 뒤 `CompactPdf417.png`를 열어 생성된 바코드를 확인합니다.
