# C#에서 Aspose.BarCode를 사용하여 바코드 생성 및 메타데이터 추가 방법

물류 또는 재고 시스템을 위해 **C#에서 바코드 생성**이 필요하다면, 이 가이드는 완전하고 프로덕션 수준의 솔루션을 보여줍니다. Macro PDF417 바코드를 생성하고, 풍부한 메타데이터를 첨부하며, 정확한 타임스탬프를 설정하는 방법을 Aspose.BarCode 라이브러리를 사용해 확인할 수 있습니다.

이 튜토리얼은 NuGet 패키지 설치부터 최종 PNG 이미지 저장까지 모든 과정을 다룹니다. 끝까지 따라 하면 파일 식별자, 세그먼트 정보, 사용자 정의 필드를 포함하는 바코드를 생성할 수 있으며, Macro PDF417를 지원하는 하위 스캐너에서 바로 사용할 수 있습니다.

## 전제 조건

* .NET 6.0 SDK 또는 그 이상 (코드는 .NET Framework 4.7.2+에서도 작동합니다)
* Visual Studio 2022 또는 선호하는 C# IDE
* 활성화된 Aspose.BarCode 라이선스 (무료 체험판으로 개발 가능)
* C# 구문에 대한 기본적인 이해

> **Pro tip:** CI/CD 파이프라인을 사용하는 경우, 프로젝트 파일에 Aspose.BarCode 패키지 참조를 추가하면 빌드가 재현 가능하게 유지됩니다.

## 단계 1: Aspose.BarCode 설치

프로젝트 폴더에서 터미널을 열고 다음을 실행합니다:

```bash
dotnet add package Aspose.BarCode
```

이 명령은 최신 안정 버전(현재 24.9)을 가져옵니다. 복원이 완료되면 소스 파일에서 라이브러리를 참조할 수 있습니다.

## 단계 2: 새 C# 콘솔 프로젝트 만들기 (선택 사항)

새로 시작하고 싶다면 콘솔 앱을 생성합니다:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs` 파일에 나중에 보여줄 바코드 생성 코드를 넣게 됩니다.

## 단계 3: 바코드 생성기 설정

프로세스의 핵심은 `BarcodeGenerator` 클래스입니다. 원하는 `EncodeTypes` 열거형 값과 인코딩할 텍스트를 사용해 인스턴스를 생성합니다.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### 각 라인이 중요한 이유

* **EncodeTypes.MacroPdf417**는 Aspose에게 세그먼트로 분할 가능한 PDF417 바코드를 생성하도록 지시합니다. 이는 단일 심볼 용량을 초과하는 대용량 페이로드에 필수적입니다.
* **XDimension.Pixels**는 시각적 밀도를 제어합니다. 값이 2이면 대부분의 화면과 프린터에서 파일 크기를 크게 늘리지 않고 선명한 이미지를 제공합니다.
* **MacroPdf417* properties**는 하위 스캐너가 별도 필드(파일 ID, 세그먼트 ID 등)로 읽는 메타데이터를 삽입합니다. 이것이 튜토리얼에서 “메타데이터 추가 방법”에 해당합니다.
* **MacroPdf417TimeStamp**는 “타임스탬프 설정 방법”을 보여줍니다. `DateTime` 인스턴스는 任意의 UTC 시간을 사용할 수 있으며, UTC를 사용하면 바코드가 지역을 넘어 이동할 때 시계열 모호성을 피할 수 있습니다.
* **MacroPdf417Terminator**는 매크로 시퀀스 종료 방식을 정의합니다. `Set`은 최종 세그먼트를 리더에게 알리는 가장 일반적인 선택입니다.
* **Save(..., BarCodeImageFormat.Png)**은 손실 없는 이미지를 저장해 신뢰할 수 있는 스캔에 필요한 세부 정보를 보존합니다.

## 단계 4: 생성된 바코드 확인

프로그램을 실행합니다:

```bash
dotnet run
```

콘솔에 다음과 같은 출력이 표시됩니다:

```
Barcode saved to ExtPDF417Meta.png
```

`ExtPDF417Meta.png` 파일을 이미지 뷰어에서 엽니다. 사진에는 텍스트 **Åspóse.Barcóde©**와 삽입된 매크로 필드가 포함된 컴팩트 PDF417 심볼이 표시됩니다. PDF417‑호환 스캐너(또는 Macro PDF417를 지원하는 모바일 앱)로 이미지를 스캔하면 원본 텍스트와 설정한 메타데이터 값이 반환됩니다.

### 예상 시각적 특성

* 어두운, 균일하게 간격이 잡힌 수직 바
* Aspose가 자동으로 추가한 조용한 영역(여백)
* `XDimension`이 2 픽셀이라 PNG의 기본 해상도와 일치하므로 왜곡 없음

## 단계 5: 일반적인 변형 및 엣지 케이스

### 5.1 특수 문자 처리

샘플 텍스트에는 유니코드 문자(`Å`, `ó`, `©`)가 포함되어 있습니다. Aspose.BarCode는 기본적으로 UTF‑8로 인코딩하므로 바코드에 올바르게 표시됩니다. 다른 인코딩이 필요하면(예: ISO‑8859‑1) 다음과 같이 설정합니다:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 큰 파일 식별자

`MacroPdf417FileID`는 32‑비트 정수를 허용합니다. `int.MaxValue`보다 큰 값은 여러 필드에 나누어 저장하거나 `MacroPdf417FileName`에 문자열 형태의 GUID를 사용하세요.

### 5.3 열 수 조정

`Pdf417.Columns` 값을 늘리면 바코드 높이는 감소하지만 각 행이 넓어집니다. 라벨이 좁을 경우 열 수를 줄이고 행 수를 자동으로 늘리세요.

### 5.4 다른 형식으로 저장

Aspose는 BMP, JPEG, TIFF, SVG를 지원합니다. `BarCodeImageFormat.Png`를 원하는 열거형 값으로 교체하면 됩니다. 예: 확장 가능한 벡터 그래픽을 원한다면 `BarCodeImageFormat.Svg`를 사용합니다.

## 단계 6: 바코드를 더 큰 워크플로에 통합

PNG 파일을 확보하면 다음과 같이 활용할 수 있습니다:

* Aspose.PDF를 사용해 PDF 청구서에 삽입
* 배송 증명으로 이메일에 첨부
* 이미지 바이트를 데이터베이스에 저장해 나중에 조회

다음은 PNG를 바이트 배열로 변환해 저장하는 간단한 코드 스니펫입니다:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## 자주 묻는 질문

**Q: Does this work on .NET Core?**  
A: Yes. The same API works on .NET Core, .NET 5+, and .NET Framework. Just reference the appropriate NuGet package.

**Q: What if I need to generate a non‑macro PDF417?**  
A: Use `EncodeTypes.Pdf417` instead of `EncodeTypes.MacroPdf417`. The macro‑specific properties will be ignored.

**Q: Can I add custom key/value pairs beyond the built‑in fields?**  
A: Aspose.BarCode does not expose arbitrary user fields for Macro PDF417. If you need extra data, encode it in the main text payload or switch to a QR code, which supports structured append.
