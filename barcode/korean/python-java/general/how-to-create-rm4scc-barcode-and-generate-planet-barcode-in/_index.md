# C#에서 RM4SCC 바코드 생성 및 플래닛 바코드 생성 방법

우편용 **RM4SCC 바코드**를 생성해야 하는 경우, 이 가이드는 정확한 단계를 보여줍니다. 또한 자동 높이와 고정 높이 모두를 사용하여 **플래닛 바코드**를 생성하는 방법을 배울 수 있으므로 동일한 코드가 모든 우편 심볼로지에 적용됩니다.

이 튜토리얼은 우편 표준을 충족하는 PNG 이미지를 만들기 위해 필요한 모든 내용을 다룹니다. Aspose.BarCode for .NET 라이브러리 외에 별도의 외부 도구가 필요하지 않습니다. 끝까지 진행하면 프로그래밍 방식으로 바코드를 생성하고 크기를 정확히 제어할 수 있습니다.

## Prerequisites

시작하기 전에 다음이 설치되어 있는지 확인하세요:

* .NET 6.0 이상
* Visual Studio 2022 (또는 기타 C# IDE)
* Aspose.BarCode for .NET NuGet 패키지  
  `Install-Package Aspose.BarCode`
* 출력 디렉터리에 대한 쓰기 권한

이 항목들은 추가 설정 없이 샘플 코드를 컴파일하고 실행할 수 있게 해줍니다.

## Step 1: Initialize the barcode generator for RM4SCC

첫 번째 작업은 RM4SCC 심볼로지를 사용하도록 구성된 `BarcodeGenerator` 인스턴스를 생성합니다. 이 객체는 바코드 이미지에 대한 모든 설정을 보관합니다.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**왜 중요한가** – `EncodeTypes.RM4SCC`는 Aspose에 우편용 RM4SCC 형식을 사용하도록 지시하고, 데이터 문자열 `"123456"`은 인코딩하려는 우편 번호를 나타냅니다.

## Step 2: Set the module width (X‑dimension)

모듈 너비는 얇은 바의 크기를 제어합니다. 우편 바코드에 일반적으로 사용되는 값은 4 픽셀입니다.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**설명** – X‑dimension은 전체 바코드 가독성에 영향을 줍니다. 4 px를 선택하면 대부분의 우편 스캐너와 일치합니다.

## Step 3: Save with automatic bar height

높이 값을 지정하지 않으면 Aspose가 심볼로지 규칙에 따라 최적의 높이를 자동으로 계산합니다.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**결과** – 생성된 PNG(`PostalRM4SCCBarHeightNone.png`)는 인쇄 준비가 된 올바른 크기의 RM4SCC 바코드를 포함합니다.

## Step 4: Create a Planet barcode with automatic height

같은 패턴이 플래닛 심볼로지에도 적용됩니다. `EncodeTypes.Planet`으로 생성기를 초기화합니다.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**코드를 재사용하는 이유** – RM4SCC와 Planet은 동일한 매개변수 구조를 공유하므로 `EncodeTypes` 값만 변경하면 심볼로지를 전환할 수 있습니다.

## Step 5: Define a fixed bar height for RM4SCC

일부 우편 서비스에서는 특정 바 높이(예: 100 px)를 요구합니다. 저장하기 전에 이를 명시적으로 설정할 수 있습니다.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**팁** – `BarHeight.Pixels`를 설정하면 자동 계산을 무시하고 시각적 크기를 완전히 제어할 수 있습니다.

## Step 6: Define a fixed bar height for Planet

플래닛 바코드에도 동일한 고정 높이 기법을 적용합니다.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**결과** – `PostalRM4SCCBarHeight100Pixels.png`와 `PostalPlanetBarHeight100Pixels.png` 모두 일관된 100 px 바 높이를 가진 바코드를 포함하여 엄격한 우편 사양을 만족합니다.

## Complete source code

아래는 네 가지 예제를 모두 포함하는 전체 실행 가능한 프로그램입니다. 새 콘솔 프로젝트에 복사하고 출력 경로를 필요에 맞게 조정하세요.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**예상 출력** – 프로그램을 실행하면 지정된 디렉터리에 네 개의 PNG 파일이 생성됩니다:

* `PostalRM4SCCBarHeightNone.png` – 자동 높이 적용된 RM4SCC
* `PostalPlanetBarHeightNone.png` – 자동 높이 적용된 Planet
* `PostalRM4SCCBarHeight100Pixels.png` – 100 px 높이 적용된 RM4SCC
* `PostalPlanetBarHeight100Pixels.png` – 100 px 높이 적용된 Planet

파일을 열어 바가 선명하고, 모듈 너비가 4 px이며, 높이가 설정한 값과 일치하는지 확인하세요.

## Common questions and edge cases

| Question | Answer |
|----------|--------|
| **Can I use other image formats?** | 예. `BarCodeImageFormat.Png`를 `Jpeg`, `Bmp`, 또는 `Gif`로 교체하면 됩니다. |
| **What if the data string is longer?** | 생성기는 자동으로 바의 수를 조정합니다. 데이터가 심볼로지의 길이 제한을 충족하는지 확인하세요 (RM4SCC ≤ 6 digits, Planet ≤ 6 digits). |
| **How do I change bar color?** | 저장하기 전에 `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;`를 설정합니다. |
| **Is DPI important for printing?** | `rm4sccAuto.Parameters.ImageResolution.DpiX`와 `DpiY`를 프린터 해상도에 맞게 설정할 수 있습니다. |
