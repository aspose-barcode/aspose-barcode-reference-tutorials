# C#에서 BarcodeGenerator API를 사용하여 바코드 이미지 저장하기

.NET 애플리케이션에서 **바코드 저장 방법**이 필요하다면, 이 가이드는 정확한 단계를 보여줍니다. DataBar Stacked Omnidirectional 바코드를 생성하고, 종횡비를 조정한 뒤 두 개의 PNG 파일을 저장하는 **바코드 생성기 예제**를 전체적으로 확인할 수 있습니다.

바코드 이미지를 저장하는 것은 재고 관리 시스템, POS 단말기, 자동 라벨링 워크플로우 등을 구축할 때 흔히 요구되는 작업입니다. 이 튜토리얼을 마치면 인쇄 또는 표시용으로 바로 사용할 수 있는 신뢰성 높은 이미지를 생성하는 C# 코드를 만들 수 있습니다.

## Prerequisites

시작하기 전에 다음이 설치되어 있는지 확인하세요:

- .NET 6.0 SDK 이상  
- Visual Studio 2022 (또는 C#을 지원하는 IDE)  
- **Aspose.BarCode for .NET** NuGet 패키지 (`Aspose.BarCode.Generation` 사용)  

다음 명령으로 패키지를 추가할 수 있습니다:

```bash
dotnet add package Aspose.BarCode
```

## Step 1: 최소 C# 콘솔 프로젝트 설정하기

새 콘솔 프로젝트를 만들고 라이브러리를 참조합니다:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

`Program.cs`를 엽니다. 이 파일에 **바코드 생성 C#** 로직을 넣을 `Main` 메서드가 포함됩니다.

## Step 2: DataBar Stacked Omnidirectional 바코드용 BarcodeGenerator 초기화

어떤 **데이터바 바코드 생성** 워크플로우든 첫 번째 작업은 올바른 `EncodeType`으로 `BarcodeGenerator`를 인스턴스화하는 것입니다. 생성자는 바코드 심볼과 데이터 문자열을 받습니다.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

`EncodeTypes.DatabarStackedOmniDirectional` 값은 라이브러리에게 어느 방향에서든 스캔 가능한 **데이터바 바코드 생성**을 하도록 지시합니다.

## Step 3: X‑dimension(모듈 폭) 설정하기

X‑dimension은 픽셀 단위의 최소 바 폭을 제어합니다. 낮은 값을 설정하면 바코드가 컴팩트해지면서도 가독성을 유지합니다.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Step 4: **종횡비 조정 방법** – 첫 번째 값 (15)

DataBar 바코드는 `AspectRatio` 속성을 제공하며, 이는 높이‑대‑너비 비율에 영향을 줍니다. 비율이 높을수록 바코드가 더 높아져 특정 프린터에서 스캔 신뢰성을 향상시킬 수 있습니다.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Step 5: **바코드 저장 방법** – 첫 번째 이미지 (종횡비 15)

이제 실제로 **바코드 저장 방법**을 파일에 적용합니다. `Save` 메서드는 파일 경로와 이미지 포맷을 받습니다. 여기서는 PNG 파일을 저장합니다.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Tip:** 실행 파일이 위치한 디렉터리가 기본 쓰기 위치입니다. 특정 폴더가 필요하면 절대 경로를 사용하세요.

## Step 6: **종횡비 조정 방법** – 두 번째 값 (30)

유연성을 보여주기 위해 종횡비를 변경하고 두 번째 이미지를 저장합니다. 이렇게 하면 동일한 데이터가 다른 시각적 비율로 렌더링되는 것을 확인할 수 있습니다.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

프로그램을 실행하면 두 개의 PNG 파일이 생성됩니다:

- `DatabarAspectRatio15.png` – 중간 높이의 바코드  
- `DatabarAspectRatio30.png` – 스캔이 어려운 환경을 위한 높은 바코드  

두 파일 모두 UI 컨트롤에 로드하거나 라벨에 인쇄하거나 API를 통해 전송할 준비가 되어 있습니다.

### Expected output

생성된 이미지를 열면 GTIN‑14 값 `12345678901231`을 인코딩한 DataBar Stacked Omnidirectional 바코드를 확인할 수 있습니다. 두 파일의 시각적 차이는 오직 높이만 다르며, **종횡비 조정 방법**이 정상적으로 작동함을 보여줍니다.

## Step 7: 참고용 전체 소스 코드

아래는 완전하고 실행 가능한 프로그램 전체입니다. `Program.cs`에 복사하고 빌드·실행하세요.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Common questions and edge‑case handling

### 대상 폴더가 존재하지 않을 경우는?

`Save`는 `DirectoryNotFoundException`을 발생시킵니다. 먼저 디렉터리를 생성하세요:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### 이미지 포맷을 변경하려면?

`BarCodeImageFormat.Png`를 `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp`, `BarCodeImageFormat.Tiff` 등으로 교체하면 됩니다.

### 루프에서 여러 바코드를 생성할 수 있나요?

가능합니다. 각 데이터 문자열마다 새 `BarcodeGenerator`를 인스턴스화하거나, `CodeText` 속성을 업데이트해 동일 인스턴스를 재사용하세요:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### **바코드 저장 방법**이 비 Windows 플랫폼에서도 동작하나요?

Aspose.BarCode는 크로스‑플랫폼입니다. .NET 런타임만 있으면 Linux와 macOS에서도 동일 코드를 실행할 수 있습니다.
