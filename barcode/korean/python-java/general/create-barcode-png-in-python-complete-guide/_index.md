# Python에서 바코드 PNG 만들기 – 완전 가이드

바코드 PNG를 **생성**해야 했지만 어떤 라이브러리나 설정을 사용해야 할지 몰랐던 적이 있나요? 당신만 그런 것이 아닙니다. 많은 재고 관리나 결제 시스템에서 첫 번째 단계는 원시 데이터를 스캐너가 좋아하는 선명한 PNG 이미지로 변환하는 것입니다.  

이 튜토리얼에서는 **databar 생성 방법**, **바코드 높이 조정** 방법, 그리고 **바코드** 매개변수를 실시간으로 변경하는 요령까지 살펴보겠습니다—모두 **샘플 데이터가 포함된 바코드**를 사용하여 프로젝트에 바로 복사‑붙여넣기 할 수 있습니다.  

## 배울 내용

- Python에서 Aspose.BarCode(또는 유사) 라이브러리를 설정합니다.  
- 몇 줄의 코드만으로 다양한 높이의 **barcode PNG** 파일을 **생성**합니다.  
- **바코드** 속성(예: 모듈 크기 및 바 높이) **변경 방법**.  
- 실제 GTIN‑14 값을 **샘플 데이터가 포함된 바코드**로 사용합니다.  
- 흐릿한 이미지나 인코딩 오류와 같은 일반적인 문제를 해결하기 위한 팁.  

바코드 생성에 대한 사전 경험은 필요하지 않습니다—기본 Python 인터프리터와 pip 패키지를 설치할 수 있는 능력만 있으면 됩니다.

## 사전 요구 사항

- 머신에 Python 3.8+이 설치되어 있어야 합니다.  
- `aspose-barcode` 패키지(또는 호환 라이브러리)를 설치하기 위한 인터넷 연결이 필요합니다.  
- PNG 파일이 저장될 쓰기 가능한 폴더(`스크립트에서 `YOUR_DIRECTORY`를 교체하세요).  

이미 준비가 되었다면, 좋습니다—시작해봅시다.

## 바코드 PNG 만들기 – 생성기 설정

우선, **DataBar Omnidirectional** 바코드를 다룬다는 것을 인식하는 생성기 객체가 필요합니다. 아래 코드는 필요한 클래스를 가져오고, **샘플 데이터가 포함된 바코드**로 생성기를 만들며, 적당한 모듈 크기를 설정합니다.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**왜 중요한가:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL`은 엔진에게 어느 방향에서든 읽을 수 있는 **DataBar**를 생성하도록 지시합니다. 이는 소매 진열대에 최적입니다. `x_dimension`을 설정하면 바가 선명하게 유지되고, `bar_height`는 코드의 시각적 크기를 제어합니다.

## 샘플 데이터로 Databar 생성하기

생성기가 준비되었으니, **barcode PNG** 파일을 **생성**합니다. 첫 번째 저장은 30픽셀 높이를 사용하며, 이는 화면 미리보기용으로 충분한 경우가 많습니다.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

스크립트를 여기까지 실행하면 컴팩트하고 고대비인 바코드처럼 보이는 PNG 파일이 생성됩니다. 이미지 뷰어에서 열어 바가 선명하고 GTIN‑14 데이터가 인코딩되었는지 확인하세요.

## 바코드 높이 조정 (How to Change Barcode)

때때로 더 큰 라벨이나 고해상도 인쇄를 위해 더 높은 바코드가 필요합니다. 여기서 **바코드 높이 조정**이 필요합니다. 높이를 변경하는 것은 `BarHeight` 속성을 업데이트하고 다시 저장하는 것만큼 간단합니다.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**작동 방식:** 생성기는 동일한 데이터와 모듈 크기를 재사용하고, 수직 차원만 변경합니다. 이는 전체 객체를 다시 만들 필요가 없으며 **바코드 변경 방법**을 동적으로 보여줍니다.

## 전체 스크립트 – 원스톱 솔루션

아래는 모든 단계를 결합한 완전한 실행 가능한 스크립트입니다. 복사‑붙여넣기 후 실행하면, 패키지를 설치한 뒤 바로 작동합니다.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### 예상 출력

스크립트를 실행하면 두 개의 파일이 생성됩니다:

- `DatabarOmni30.png` – 30 px 높이의 DataBar Omnidirectional 바코드.  
- `DatabarOmni60.png` – 동일 바코드의 60 px 높이 버전.

두 이미지는 PNG 형식이며 손실이 없고, PDF, HTML 페이지에 삽입하거나 라벨에 직접 인쇄할 준비가 되어 있습니다.

## 일반적인 함정 및 전문가 팁

- **픽셀 vs. DPI:** PNG 파일은 픽셀 기반입니다. 특정 인쇄 크기가 필요하면 DPI를 기준으로 `BarHeight`를 계산하세요(예: 300 dpi → 30 px ≈ 0.1 인치).  
- **잘못된 인코딩:** 데이터 문자열이 GS1 애플리케이션 식별자 형식(`GTIN‑14`의 경우 `(01)`)을 따르는지 확인하세요. 괄호가 누락되면 라이브러리가 일반 숫자 바코드로 대체될 수 있습니다.  
- **파일 경로:** Windows에서는 원시 문자열(`r"..."`)이나 이중 백슬래시를 사용해 이스케이프 문자 문제를 피하세요.  
- **성능:** 수천 개의 바코드를 생성한다면 생성기를 한 번만 인스턴스화하고 저장 사이에 `BarHeight` 또는 데이터 문자열만 수정하세요. 이렇게 하면 메모리 사용량을 줄일 수 있습니다.
