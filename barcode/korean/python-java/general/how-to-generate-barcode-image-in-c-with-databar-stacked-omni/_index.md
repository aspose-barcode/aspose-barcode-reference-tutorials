# C#에서 DataBar Stacked Omni‑Directional 바코드 이미지 생성 방법

.NET 애플리케이션에서 **바코드 이미지 생성 방법**이 필요하다면, 이 튜토리얼은 정확한 단계들을 보여줍니다. DataBar Stacked Omni‑Directional 바코드를 생성하고, 종횡비를 조정하며, 결과를 PNG 파일로 내보내는 방법을 확인할 수 있습니다.

바코드 생성은 재고 관리 시스템, 소매점 POS 단말기, 물류 추적 등에서 흔히 요구되는 기능입니다. 아래 섹션에서는 필요한 NuGet 패키지부터 최종 이미지 검증까지 모든 과정을 다루므로, 오늘 바로 C# 프로젝트에 바코드 생성을 통합할 수 있습니다.

## 사전 요구 사항

시작하기 전에 다음이 준비되어 있는지 확인하세요:

* .NET 6.0 이상 (.NET Core 및 .NET Framework에서도 동작)
* Visual Studio 2022 또는 선호하는 C# IDE
* **Aspose.BarCode for .NET** NuGet 패키지 (`dotnet add package Aspose.BarCode` 명령으로 설치)
* PNG 파일을 저장할 폴더에 대한 쓰기 권한

이 사전 요구 사항을 충족하면 추가 설정 없이 샘플을 실행할 수 있습니다.

## 1단계: 출력 폴더 설정

먼저 생성된 PNG 파일을 기록할 디렉터리가 필요합니다. 절대 경로나 상대 경로 모두 사용할 수 있지만, `Save`를 호출하기 전에 폴더가 존재하는지 확인하세요.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

프로그램matically 폴더를 생성하면 `Save` 메서드가 이미지를 쓰려 할 때 발생할 수 있는 *FileNotFoundException*을 방지할 수 있습니다.

## 2단계: DataBar Stacked Omni‑Directional 바코드 생성기 만들기

**BarcodeGenerator** 클래스는 모든 바코드 유형의 진입점입니다. 여기서는 `EncodeTypes.DatabarStackedOmniDirectional`와 인코딩할 데이터 문자열을 지정합니다.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*왜 중요한가*: `EncodeTypes` 열거형은 라이브러리에 어떤 심볼을 렌더링할지 알려줍니다. Omni‑Directional 변형을 사용하면 바코드를 어떤 방향에서도 스캔할 수 있어, 많은 창고 스캐너의 요구 사항을 만족합니다.

## 3단계: 일반 바코드 매개변수 구성

읽기 쉬운 바코드를 만들려면 적절한 X‑dimension(가장 작은 바의 너비)이 필요합니다. `Pixels`를 2로 설정하면 대부분의 화면 해상도에서 크기와 선명도 사이의 좋은 균형을 얻을 수 있습니다.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

이미지가 더 크거나 작아야 할 경우 `Pixels` 값을 나중에 조정하면 됩니다. 라이브러리가 나머지 바코드 요소를 자동으로 스케일링합니다.

## 4단계: 종횡비 15로 첫 번째 이미지 생성

**aspect ratio**는 DataBar 바코드의 높이‑대‑너비 비율을 제어합니다. 종횡비 15는 소매 라벨에서 일반적으로 사용되는 기본값입니다.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

이 호출이 끝나면 출력 폴더에 `DatabarAspectRatio15.png` 파일이 생성됩니다. 이 이미지는 무손실 PNG 형식으로, 추가 처리나 인쇄에 적합합니다.

## 5단계: 종횡비를 30으로 변경하고 두 번째 이미지 내보내기

라벨 높이가 제한된 경우처럼 더 높은 바코드가 필요할 때가 있습니다. 종횡비를 30으로 변경하면 데이터 무결성을 유지하면서 시각적으로 더 컴팩트한 바코드를 얻을 수 있습니다.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

이제 두 개의 PNG 파일이 생성되어 동일한 데이터가 다른 종횡비에서 어떻게 보이는지 보여줍니다. 이 나란히 비교를 통해 라벨 레이아웃에 가장 적합한 변형을 선택할 수 있습니다.

## 전체 실행 가능한 예제

아래는 복사·붙여넣기만 하면 바로 실행할 수 있는 전체 프로그램입니다. 모든 `using` 지시문, 오류 처리, 각 단계에 대한 설명 주석이 포함되어 있습니다.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**예상 출력** (콘솔):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

두 PNG 파일을 이미지 뷰어에서 열어 보세요. 동일한 GTIN이 인코딩되어 있지만, 두 번째 이미지는 종횡비가 높아져 더 길게 표시됩니다.

## 전문가 팁 및 일반적인 함정

| 상황 | 권장 사항 |
|-----------|----------------|
| **저해상도 디스플레이** | `XDimension.Pixels`를 3 또는 4로 늘려 바가 선명하게 보이도록 합니다. |
| **열전지(thermal) 용지 인쇄** | `BarCodeImageFormat.Tiff`를 사용해 품질을 높이고 `Resolution.DpiX/DpiY`를 300으로 설정합니다. |
| **동적 데이터** | 동일한 `BarcodeGenerator` 인스턴스를 재사용하고 `generator.CodeText`만 각 `Save` 전에 업데이트합니다. 불필요한 객체 할당을 방지할 수 있습니다. |
| **잘못된 GTIN** | 데이터가 GS1 표준에 맞지 않으면 라이브러리가 `ArgumentException`을 발생시킵니다. 생성기에 전달하기 전에 데이터를 검증하세요. |
