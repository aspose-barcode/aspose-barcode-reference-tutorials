# C#에서 플래닛 바코드 생성 – 완전 프로그래밍 가이드

C#에서 **플래닛 바코드 생성**이 필요하다면, 이 가이드는 정확한 방법을 보여줍니다. 또한 **바코드 크기 설정 방법**을 알아보게 되어 바가 원하는 정확한 너비로 렌더링됩니다.

우편 서비스나 물류 시스템을 다룰 때 플래닛 바코드 생성은 흔히 사용됩니다. 아래 코드는 기본 채워진 바 버전과 선택적인 빈 바 스타일을 모두 다루며, RM4SCC 형식에 대한 간단한 예제도 포함합니다. 이 튜토리얼을 마치면 .NET 프로젝트 어디에든 삽입할 수 있는 재사용 가능한 스니펫을 얻게 됩니다.

## 전제 조건

시작하기 전에 다음이 준비되어 있는지 확인하세요:

* .NET 6.0 이상이 설치됨 (.NET Framework 4.6+에서도 API가 작동합니다)
* 프로젝트에 **Aspose.BarCode for .NET** NuGet 패키지(`Aspose.BarCode`)가 추가됨
* PNG 파일을 저장할 수 있는 쓰기 가능한 폴더 경로
* C# 구문 및 Visual Studio(또는 기타 IDE)에 대한 기본적인 이해

> **Pro tip:** 절대 경로나 `Path.Combine(Environment.CurrentDirectory, "output")`을 사용하면 이미지 저장 시 권한 문제를 피할 수 있습니다.

## Step 1 – Initialize a Planet barcode generator (filled bars)

첫 번째 단계는 플래닛 심볼을 위한 `BarcodeGenerator` 인스턴스를 만드는 것입니다. 기본적으로 생성기는 **채워진** 바를 생성합니다.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

`EncodeTypes.Planet` 열거형은 Aspose.BarCode에 플래닛 형식을 사용하도록 지시하고, `"123456"`은 인코딩될 데이터 페이로드입니다.

## Step 2 – How to set barcode dimensions for consistent sizing

각 바의 너비를 제어하려면 **X‑dimension**을 조정합니다. 이는 **바코드 크기 설정**의 주요 방법이며 바코드가 라벨 크기에 맞도록 보장합니다.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

`Pixels` 속성은 화면 픽셀 단위의 바 너비를 정의합니다. 일반적인 값은 표준 우편 라벨에 2 – 5 픽셀이며, 더 큰 인쇄물에는 값을 늘립니다.

## Step 3 – Save the filled Planet barcode as PNG

이제 이미지를 디스크에 기록합니다. PNG는 선명한 가장자리를 유지하므로 스캔에 이상적입니다.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

`YOUR_DIRECTORY`를 앞서 준비한 경로로 교체하세요. 코드를 실행하면 아래 이미지와 유사한 파일이 생성됩니다.

## Step 4 – Create a Planet barcode with empty (unfilled) bars

우편 서비스에서 바가 **빈** 상태여야 한다면, 생성기를 초기화한 뒤 `FilledBars` 플래그를 전환해야 합니다.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

생성자는 동일하지만 차이는 다음 설정 단계에 있습니다.

## Step 5 – How to set barcode dimensions and make bars empty

다시 한 번 시각적 일관성을 위해 X‑dimension을 설정하고, 채워진 바를 비활성화합니다.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

`FilledBars = false` 속성이 실제로 렌더링 스타일을 변경합니다. 동일한 X‑dimension을 유지하면 빈 바 바코드가 채워진 버전과 완벽히 정렬됩니다.

## Step 6 – Save the empty Planet barcode

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

이제 두 개의 PNG 파일이 생성됩니다: 하나는 실선 바, 다른 하나는 빈 바이며 두 파일 모두 동일한 차원을 공유합니다.

## Step 7 – (Optional) Generate an RM4SCC barcode for comparison

RM4SCC는 동일한 기본 채워진 바 스타일을 사용하는 또 다른 우편 심볼입니다. 단계는 플래닛 예제와 동일하며, **바코드 크기 설정 방법**이 형식 전반에 적용됨을 보여줍니다.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

이 세 단계를 실행하면 `PostalRM4SCCFilledBars.png`가 생성되며, 플래닛 출력물과 나란히 비교할 수 있습니다.

## Why X‑dimension matters

X‑dimension은 각 바의 **최소 인쇄 너비**를 결정합니다. 너무 낮게 설정하면 저해상도 프린터에서 바코드가 흐려져 스캔 실패가 발생할 수 있습니다. 반대로 X‑dimension이 너무 크면 라벨 크기를 초과하고 공간을 낭비합니다. **바코드 크기 설정 방법**을 명시적으로 지정하면 최종 이미지 크기에 대한 결정적인 제어가 가능해져 자동 우편 워크플로에 필수적입니다.

## Common pitfalls and how to avoid them

| Issue | Cause | Fix |
|-------|-------|-----|
| 바코드가 늘어남 | X‑dimension을 픽셀이 아닌 포인트로 설정 | 픽셀‑완벽 제어를 위해 항상 `Pixels` 속성을 사용 |
| 빈 바가 여전히 채워진 것처럼 보임 | `FilledBars`를 X‑dimension 변경 후 `false`로 설정하지 않음 | X‑dimension 조정 *후에* `FilledBars = false`를 설정 |
| 저장된 파일이 비어 있음 | 출력 디렉터리가 없거나 쓰기 권한이 없음 | 디렉터리가 존재하는지 확인(`Directory.CreateDirectory`)하고 애플리케이션이 충분한 권한으로 실행되는지 확인 |
| 인쇄 시 이미지가 흐림 | 고해상도 모니터에서 낮은 DPI PNG 저장 | `BarCodeImageFormat.Png`(무손실) 사용 및 필요 시 `Resolution` 속성 고려 |

## Full, runnable example

아래 전체 블록을 새 콘솔 프로젝트(`dotnet new console`)에 복사하고 실행하세요. 프로그램은 `output` 폴더에 세 개의 PNG 파일을 생성합니다.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Expected output:** 세 개의 PNG 파일—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png`, `PostalRM4SCCFilledBars.png`—각각 4‑픽셀 너비 바를 가지고 있어 인쇄 또는 추가 처리에 바로 사용할 수 있습니다.

## Conclusion

이제 C#에서 **플래닛 바코드 생성** 방법과 채워진 바와 빈 바 스타일 모두에 대해 정확히 **바코드 크기 설정 방법**을 알게 되었습니다. 동일한 패턴을 RM4SCC와 같은 다른 심볼에도 적용할 수 있어 모든 우편‑바코드 요구 사항에 유연한 기반을 제공합니다.

다음과 같은 항목을 탐색해 볼 수 있습니다:

* 바코드 아래에 인간이 읽을 수 있는 텍스트 추가 (`BarcodeGenerator.Parameters.Barcode.CodeText`)
* `Parameters.Barcode.BarColor`를 사용해 바 색상 변경
* 벡터 형식(SVG, EPS)으로 바코드 생성하여 확장 가능한 인쇄 구현

다양한 X‑dimension 값, 데이터 문자열, 출력 형식을 실험해 보면서 워크플로에 맞게 최적화하세요. 즐거운 코딩 되세요!
