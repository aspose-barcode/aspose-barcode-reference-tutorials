# Generar código de barras PDF417 con configuración compacta en C#

Si necesita **generar código de barras PDF417** en una aplicación .NET, esta guía le muestra cómo hacerlo con Aspose.Barcode para .NET. Recorreremos la creación del generador, la configuración de columnas, la X‑dimensión y la activación del modo compacto para que el símbolo resultante sea lo más pequeño posible.

Generar un código de barras PDF417 es común cuando tiene que codificar grandes cantidades de datos para boletos, identificaciones o etiquetas de envío. Este tutorial cubre todo el flujo de trabajo, desde la instalación de la biblioteca hasta el guardado del PNG final, para que pueda copiar‑pegar el código en su propio proyecto y ejecutarlo de inmediato.

## Requisitos previos para generar código de barras PDF417

Antes de comenzar, asegúrese de tener:

* .NET 6.0 (o posterior) instalado.  
* Visual Studio 2022 o cualquier IDE que soporte proyectos C#.  
* Una licencia NuGet para **Aspose.Barcode for .NET** (la prueba gratuita sirve para aprender).  

Puede agregar la biblioteca con el siguiente comando:

```bash
dotnet add package Aspose.BarCode
```

> **Consejo profesional:** Use la bandera `--version` para fijar una versión estable conocida, por ejemplo, `dotnet add package Aspose.BarCode --version 23.12`.

## Crear un generador de código de barras PDF417

El primer bloque de código crea una instancia de `BarcodeGenerator` que está pre‑configurada para la simbología PDF417. El texto `"Åspóse.Barcóde©"` contiene caracteres Unicode para demostrar que el generador maneja entradas no ASCII de forma nativa.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        BarcodeGenerator pdf417Generator = new BarcodeGenerator(
            EncodeTypes.Pdf417,          // PDF417 symbology
            "Åspóse.Barcóde©");          // Data to encode
```

### Por qué es importante
`EncodeTypes.Pdf417` indica a Aspose.Barcode que desea un **código de barras PDF417**, que es una simbología lineal apilada capaz de almacenar hasta 1 850 caracteres. Usar el constructor con el argumento de texto le ahorra una llamada posterior a `SetCodeText`.

## Establecer la XDimension del código de barras (tamaño del módulo)

El tamaño del módulo, también conocido como X‑dimensión, determina cuán ancha es cada barra individual. Los píxeles más pequeños producen una imagen más densa, mientras que los píxeles más grandes mejoran la legibilidad en impresoras de baja resolución.

```csharp
        // Step 2: Define the module size (X‑dimension) in pixels
        pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2; // barcode XDimension pixels
```

### Por qué debe ajustar la XDimension
Un valor de `2` píxeles funciona bien para visualización en pantalla y la mayoría de impresoras de oficina. Si necesita una impresión de mayor resolución, aumente el valor; si necesita un código de barras más estrecho (por ejemplo, con apariencia similar a un QR), disminúyalo, pero nunca por debajo de `1` píxel, de lo contrario la imagen será ilegible.

## Establecer el número de columnas para el símbolo PDF417

PDF417 le permite elegir cuántas columnas (pilas verticales) tendrá el código de barras. Menos columnas hacen que el código sea más alto; más columnas lo hacen más ancho.

```csharp
        // Step 3: Set the number of columns for the PDF417 symbol
        pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3; // set PDF417 columns
```

### Cuándo cambiar el recuento de columnas
Tres columnas producen un símbolo compacto, casi cuadrado, que encaja bien en tarjetas de identificación estándar. Si tiene una cadena muy larga, podría aumentar el recuento de columnas para mantener una altura razonable.

## Habilitar modo compacto (truncamiento)

El modo compacto elimina automáticamente filas no utilizadas del símbolo, reduciendo su tamaño total. Esto es especialmente útil cuando los datos codificados no llenan la matriz completa.

```csharp
        // Step 4: Enable compact mode to truncate the symbol when possible
        pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true; // compact PDF417 barcode
```

### Beneficios del código de barras PDF417 compacto
Cuando `Truncate` es `true`, el generador calcula el número mínimo de filas necesario para almacenar sus datos, lo que reduce el consumo de tinta y el tiempo de escaneo. Es seguro para la mayoría de los escáneres porque la especificación PDF417 define el algoritmo de truncamiento.

## Guardar el código de barras generado como una imagen

Finalmente, escriba el código de barras en un archivo PNG. PNG conserva la calidad sin pérdidas, lo que lo hace ideal para impresión posterior o incrustación en PDFs.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        string outputPath = @"YOUR_DIRECTORY\CompactPdf417.png";
        pdf417Generator.Save(outputPath, BarCodeImageFormat.Png);
    }
}
```

### Resultado esperado
Ejecutar el programa crea `CompactPdf417.png` en la carpeta especificada. La imagen contiene un **código de barras PDF417 compacto** que codifica la cadena `"Åspóse.Barcóde©"` con tres columnas, una X‑dimension de 2 píxeles y truncamiento aplicado. Puede verificar el resultado con cualquier aplicación escáner de códigos de barras o con la demo en línea gratuita de Aspose.Barcode.

## Variaciones comunes y casos límite

| Situación | Ajuste |
|-----------|--------|
| **Datos muy largos (> 1500 caracteres)** | Aumente `Columns` o establezca `Rows` manualmente (`pdf417Generator.Parameters.Barcode.Pdf417.Rows = 30`). |
| **Impresión en una impresora de baja resolución (dpi)** | Aumente `XDimension.Pixels` a 3 o 4 para evitar la pixelación. |
| **Necesita un fondo transparente** | Utilice `pdf417Generator.Save(outputPath, BarCodeImageFormat.Png, new ImageOptions { BackgroundColor = Color.Transparent })`. |
| **Incrustar en un PDF** | Guarde como `BarCodeImageFormat.Pdf` o obtenga el objeto `Image` mediante `pdf417Generator.GenerateBarCodeImage()`. |

## Ejemplo completo y ejecutable

A continuación se muestra el programa completo que puede copiar en un nuevo proyecto de consola. No se requieren archivos adicionales.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with Unicode text
            BarcodeGenerator pdf417Generator = new BarcodeGenerator(
                EncodeTypes.Pdf417,
                "Åspóse.Barcóde©");

            // Set module size – this is the barcode XDimension pixels
            pdf417Generator.Parameters.Barcode.XDimension.Pixels = 2;

            // Choose a compact layout – set PDF417 columns
            pdf417Generator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable truncation for a smaller, compact PDF417 barcode
            pdf417Generator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save as PNG (you can also use JPG, BMP, or PDF formats)
            string outputFile = @"CompactPdf417.png";
            pdf417Generator.Save(outputFile, BarCodeImageFormat.Png);

            Console.WriteLine($"PDF417 barcode generated and saved to {outputFile}");
        }
    }
}
```

Ejecute `dotnet run` desde la carpeta del proyecto. Después de la ejecución, abra `CompactPdf417.png` para ver el código de barras generado.

## Conclusión

Ahora sabe cómo **generar código de barras PDF417** en C# con control total sobre columnas, X‑dimensión y modo compacto. Ajustando los píxeles de `barcode XDimension`, `set PDF417 columns` y habilitando la truncación `compact PDF417 barcode`, puede producir un código de barras que se ajuste a las restricciones de tamaño exactas de su aplicación.

Próximos pasos que podría explorar:

* Codifique conjuntos de datos más grandes y experimente con el parámetro `Rows`.  
* Cambie el formato de salida a `BarCodeImageFormat.Svg` para gráficos web escalables.  
* Combine el código de barras con otros componentes de Aspose, como **Aspose.PDF**, para incrustar la imagen directamente en un informe PDF.

¡Feliz codificación, y siéntase libre de ajustar la configuración para que coincida con su entorno de escaneo específico!
