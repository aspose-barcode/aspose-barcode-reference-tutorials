# Cómo generar código de barras en C# con Aspose.BarCode y agregar metadatos

Si necesitas **generar código de barras en C#** para un sistema logístico o de inventario, esta guía te muestra una solución completa y lista para producción. Verás cómo crear un código de barras Macro PDF417, adjuntar metadatos enriquecidos y establecer una marca de tiempo precisa, todo con la biblioteca Aspose.BarCode.

El tutorial cubre todo, desde la instalación del paquete NuGet hasta el guardado de la imagen PNG final. Al terminar, podrás generar un código de barras que lleva identificadores de archivo, información de segmento y campos personalizados, listo para escáneres posteriores que soporten Macro PDF417.

## Requisitos previos

Antes de comenzar, asegúrate de tener:

* .NET 6.0 SDK o posterior (el código también funciona con .NET Framework 4.7.2+)
* Visual Studio 2022 o cualquier IDE de C# que prefieras
* Una licencia activa de Aspose.BarCode (la prueba gratuita funciona para desarrollo)
* Familiaridad básica con la sintaxis de C#

> **Consejo profesional:** Si utilizas una canalización CI/CD, agrega la referencia al paquete Aspose.BarCode en tu archivo de proyecto para que las compilaciones sean reproducibles.

## Paso 1: Instalar Aspose.BarCode

Abre una terminal en la carpeta de tu proyecto y ejecuta:

```bash
dotnet add package Aspose.BarCode
```

El comando descarga la última versión estable (actualmente 24.9). Cuando finalice la restauración, podrás referenciar la biblioteca en tus archivos fuente.

## Paso 2: Crear un nuevo proyecto de consola C# (opcional)

Si prefieres comenzar desde cero, crea una aplicación de consola:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

El archivo `Program.cs` alojará el código de generación de código de barras que se muestra más adelante.

## Paso 3: Configurar el generador de códigos de barras

El núcleo del proceso es la clase `BarcodeGenerator`. La instancias con el valor deseado del enumerado `EncodeTypes` y el texto que deseas codificar.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 3.1: Create a Macro PDF417 generator with sample text
        using (BarcodeGenerator generator = new BarcodeGenerator(
                   EncodeTypes.MacroPdf417, "Åspóse.Barcóde©"))
        {
            // Step 3.2: Configure basic appearance (module width, column count)
            generator.Parameters.Barcode.XDimension.Pixels = 2;   // 2‑pixel modules
            generator.Parameters.Barcode.Pdf417.Columns = 5;    // compact layout

            // Step 3.3: Add Macro PDF417 metadata (how to add metadata)
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
            generator.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";

            // Step 3.4: Set a checksum for data integrity
            generator.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16

            // Step 3.5: Provide file size and custom fields
            generator.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000; // bytes
            generator.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
            generator.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";

            // Step 3.6: How to set timestamp (ISO‑like date for the barcode)
            generator.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp =
                new DateTime(2019, 11, 1, 14, 30, 0, DateTimeKind.Utc);

            // Step 3.7: Choose the terminator that signals the end of the macro sequence
            generator.Parameters.Barcode.Pdf417.MacroPdf417Terminator = 
                Pdf417MacroTerminator.Set;

            // Step 3.8: Save the barcode image (PNG format)
            string outputPath = "ExtPDF417Meta.png";
            generator.Save(outputPath, BarCodeImageFormat.Png);

            Console.WriteLine($"Barcode saved to {outputPath}");
        }
    }
}
```

### Por qué cada línea es importante

* **EncodeTypes.MacroPdf417** indica a Aspose que produzca un código de barras PDF417 que puede dividirse en segmentos. Esto es esencial para cargas útiles grandes que superan la capacidad de un solo símbolo.
* **XDimension.Pixels** controla la densidad visual. Un valor de 2 produce una imagen clara en la mayoría de pantallas e impresoras sin inflar el tamaño del archivo.
* **MacroPdf417* properties** incrustan los metadatos que los escáneres posteriores leen como campos separados (ID de archivo, ID de segmento, etc.). Esta es la parte del tutorial que muestra “cómo agregar metadatos”.
* **MacroPdf417TimeStamp** demuestra “cómo establecer la marca de tiempo”. La instancia `DateTime` puede ser cualquier hora UTC; usar UTC evita ambigüedades de zona horaria cuando el código de barras viaja entre regiones.
* **MacroPdf417Terminator** define cómo termina la secuencia macro. `Set` es la opción más común porque señala el segmento final al lector.
* **Save(..., BarCodeImageFormat.Png)** escribe una imagen sin pérdida que conserva los detalles finos necesarios para un escaneo fiable.

## Paso 4: Verificar el código de barras generado

Ejecuta el programa:

```bash
dotnet run
```

Deberías ver la salida en la consola:

```
Barcode saved to ExtPDF417Meta.png
```

Abre `ExtPDF417Meta.png` en cualquier visor de imágenes. La foto mostrará un símbolo PDF417 compacto con el texto **Åspóse.Barcóde©** y los campos macro incrustados. Escanear la imagen con un escáner compatible con PDF417 (o una aplicación móvil que soporte Macro PDF417) devolverá el texto original más los valores de metadatos que configuraste.

### Características visuales esperadas

* Barras verticales oscuras y uniformemente espaciadas
* Una zona silenciosa (margen) añadida automáticamente por Aspose
* Sin distorsión, porque la `XDimension` de 2 píxeles coincide con la resolución nativa del PNG

## Paso 5: Variaciones comunes y casos límite

### 5.1 Manejo de caracteres especiales

El texto de ejemplo contiene caracteres Unicode (`Å`, `ó`, `©`). Aspose.BarCode los codifica usando UTF‑8 por defecto, por lo que aparecen correctamente en el código de barras. Si necesitas una codificación diferente (p. ej., ISO‑8859‑1), establece:

```csharp
generator.Parameters.Barcode.Pdf417.TextEncoding = System.Text.Encoding.GetEncoding("iso-8859-1");
```

### 5.2 Identificadores de archivo grandes

`MacroPdf417FileID` acepta un entero de 32 bits. Para valores mayores que `int.MaxValue`, divide el identificador en varios campos o usa un GUID almacenado como cadena en `MacroPdf417FileName`.

### 5.3 Ajustar el número de columnas

Incrementar `Pdf417.Columns` reduce la altura del código de barras pero ensancha cada fila. Si el código debe caber en una etiqueta estrecha, disminuye el recuento de columnas y aumenta automáticamente el número de filas.

### 5.4 Guardar en otros formatos

Aspose soporta BMP, JPEG, TIFF y SVG. Reemplaza `BarCodeImageFormat.Png` por el valor de enumerado deseado, por ejemplo, `BarCodeImageFormat.Svg` para un gráfico vectorial escalable.

## Paso 6: Integrar el código de barras en un flujo de trabajo más amplio

Una vez que tengas el archivo PNG, puedes:

* Incrustarlo en una factura PDF usando Aspose.PDF.
* Adjuntarlo a un correo electrónico como prueba de entrega.
* Almacenar los bytes de la imagen en una base de datos para su recuperación posterior.

A continuación, un fragmento rápido que convierte el PNG a un arreglo de bytes para su almacenamiento:

```csharp
byte[] barcodeBytes = System.IO.File.ReadAllBytes("ExtPDF417Meta.png");
// Example: save to SQL Server varbinary(max) column
```

## Preguntas frecuentes

**P: ¿Esto funciona en .NET Core?**  
R: Sí. La misma API funciona en .NET Core, .NET 5+ y .NET Framework. Sólo hay que referenciar el paquete NuGet apropiado.

**P: ¿Qué pasa si necesito generar un PDF417 sin macro?**  
R: Usa `EncodeTypes.Pdf417` en lugar de `EncodeTypes.MacroPdf417`. Las propiedades específicas de macro serán ignoradas.

**P: ¿Puedo agregar pares clave/valor personalizados más allá de los campos incorporados?**  
R: Aspose.BarCode no expone campos de usuario arbitrarios para Macro PDF417. Si necesitas datos extra, codifícalos en la carga útil de texto principal o cambia a un código QR, que soporta “structured append”.
