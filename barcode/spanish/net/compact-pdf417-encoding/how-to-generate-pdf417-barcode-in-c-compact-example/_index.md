# Cómo generar un código de barras PDF417 en C# – ejemplo compacto

Si necesitas **generar un código de barras PDF417** en una aplicación C#, esta guía te muestra una solución completa y lista para ejecutar. Crearemos un código de barras PDF417 compacto, ajustaremos el ancho del módulo, definiremos la cantidad de columnas y guardaremos el resultado como una imagen PNG, todo con la biblioteca Aspose.BarCode .NET.

Generar un código de barras PDF417 es común cuando deseas codificar grandes cantidades de datos (p. ej., URLs, tarjetas de contacto o IDs de inventario) en un formato bidimensional eficiente en espacio. Al final de este tutorial tendrás una instancia funcional de `BarcodeGenerator` que produce un código de barras compacto y de alta legibilidad, listo para imprimir o mostrar.

## Requisitos previos

- .NET 6.0 o posterior (el código también funciona con .NET Framework 4.8)
- Visual Studio 2022 (o cualquier IDE de C#)
- Paquete NuGet Aspose.BarCode for .NET (`Install-Package Aspose.BarCode`)
- Familiaridad básica con la sintaxis de C#

No se requiere configuración adicional; el ejemplo se ejecuta como una aplicación de consola.

## Paso 1: Crear un generador de código de barras PDF417

El primer paso es instanciar `BarcodeGenerator` con el enumerado `EncodeTypes.Pdf417` y el texto que deseas codificar.

```csharp
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a PDF417 barcode generator with the desired text
        var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");
```

**Por qué es importante:** `EncodeTypes.Pdf417` indica a la biblioteca que use la simbología PDF417, mientras que el segundo argumento establece la carga de datos. Puedes reemplazar `"Compact example"` por cualquier cadena de hasta 1 800 caracteres.

## Paso 2: Establecer el ancho del módulo (dimensión X) en píxeles

La dimensión X define el ancho de un solo módulo del código de barras (el cuadrado negro o blanco más pequeño). Un valor de píxel menor produce un código de barras más estrecho.

```csharp
        // Step 2: Set the module width (X‑dimension) in pixels
        barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;
```

**Por qué es importante:** Un valor de `2` píxeles crea una apariencia compacta sin sacrificar la fiabilidad de escaneo en la mayoría de los escáneres modernos. Ajusta el valor si necesitas módulos más grandes para impresiones de baja resolución.

## Paso 3: Especificar el número de columnas

PDF417 permite controlar la cantidad de columnas, lo que influye en la relación de aspecto del código de barras.

```csharp
        // Step 3: Specify the number of columns for the PDF417 code
        barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;
```

**Por qué es importante:** Menos columnas hacen que el código de barras sea más alto, mientras que más columnas lo aplanan. Tres columnas funcionan bien para un diseño compacto en orientación vertical.

## Paso 4: Habilitar el modo compacto truncando el código de barras

El modo compacto elimina filas de relleno innecesarias, reduciendo el tamaño del código de barras sin perder los datos codificados.

```csharp
        // Step 4: Enable compact mode by truncating the barcode
        barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;
```

**Por qué es importante:** La truncación es ideal cuando el espacio en pantalla es limitado (p. ej., aplicaciones móviles o etiquetas pequeñas). El código de barras sigue siendo totalmente legible porque el algoritmo de codificación ajusta automáticamente los niveles de corrección de errores.

## Paso 5: Guardar el código de barras como imagen PNG

Finalmente, escribe el código de barras generado en un archivo. PNG conserva la calidad sin pérdidas, lo cual es esencial para los escáneres de códigos de barras.

```csharp
        // Step 5: Save the generated barcode as a PNG image
        barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);
    }
}
```

Ejecutar el programa crea `CompactPdf417.png` en el directorio de trabajo del ejecutable. La imagen se ve así:

**Salida esperada:** Un código de barras PDF417 de 2 píxeles de ancho, con tres columnas, que codifica el texto “Compact example”. Escanear el PNG con un escáner de códigos de barras estándar debería devolver la cadena original.

## Variaciones comunes y casos límite

| Situación | Cómo ajustar el código |
|-----------|------------------------|
| **Datos más extensos ( > 500 caracteres )** | Incrementa `Columns` a 5‑7 para evitar que el código de barras quede demasiado alto. |
| **Impresión de alta resolución** | Establece `XDimension.Pixels` a 3 o 4 para módulos más grandes. |
| **Formato de imagen diferente** | Reemplaza `BarCodeImageFormat.Png` por `Jpeg` o `Bmp` según sea necesario. |
| **Incorporar el código de barras en un PDF** | Usa `barcodeGenerator.Save("output.pdf", BarCodeImageFormat.Pdf)` en lugar de PNG. |

**Consejo profesional:** Siempre prueba el código de barras generado en el hardware de escáner objetivo. Algunos escáneres de bajo costo tienen dificultades con dimensiones X muy pequeñas; si encuentras errores de lectura, aumenta el valor de píxeles en un paso.

## Ejemplo completo y ejecutable

A continuación tienes el programa completo que puedes copiar y pegar en un nuevo proyecto de consola. No se requieren archivos adicionales.

```csharp
using System;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

namespace Pdf417Demo
{
    class Program
    {
        static void Main()
        {
            // Create a PDF417 barcode generator with the desired text
            var barcodeGenerator = new BarcodeGenerator(EncodeTypes.Pdf417, "Compact example");

            // Set the module width (X‑dimension) in pixels
            barcodeGenerator.Parameters.Barcode.XDimension.Pixels = 2;

            // Specify the number of columns for the PDF417 code
            barcodeGenerator.Parameters.Barcode.Pdf417.Columns = 3;

            // Enable compact mode by truncating the barcode
            barcodeGenerator.Parameters.Barcode.Pdf417.Truncate = true;

            // Save the generated barcode as a PNG image
            barcodeGenerator.Save("CompactPdf417.png", BarCodeImageFormat.Png);

            Console.WriteLine("PDF417 barcode generated successfully: CompactPdf417.png");
        }
    }
}
```

Compila y ejecuta el programa (`dotnet run` si usas la CLI de .NET). Después de la ejecución, abre `CompactPdf417.png` para verificar el resultado visual.

## Conclusión

Ahora sabes **cómo generar un código de barras PDF417** en C# con un diseño compacto, dimensión X personalizada y configuración de columnas. El ejemplo muestra los pasos esenciales: instanciar `BarcodeGenerator`, configurar `XDimension` y `Columns`, habilitar `Truncate` para el modo compacto y, finalmente, guardar la imagen.

A partir de aquí puedes explorar características adicionales como el nivel de corrección de errores, colores personalizados o la incorporación directa del código de barras en PDFs. Experimenta con diferentes `EncodeTypes` si necesitas otras simbologías (p. ej., QR, Code128) e integra el mismo patrón de configuración de parámetros.

¡Feliz codificación, y que tus códigos de barras siempre se lean en el primer intento!
