# Generar código de barras PDF417 en C# usando Aspose – guía paso a paso

Si necesitas **generar código de barras PDF417** en una aplicación .NET, esta guía te muestra exactamente cómo. Verás un ejemplo completo, listo‑para‑ejecutar, que crea códigos de barras PDF417 básicos, compactos, Micro, GS1‑Micro y Macro con Aspose.BarCode para .NET.

Generar un código de barras PDF417 es un requisito común para etiquetas de envío, documentos de transporte y sistemas de inventario. Al final de este tutorial podrás **generar imágenes de código de barras PDF417**, comprender los parámetros clave y adaptar el código a tus propias cargas de datos.

## Requisitos previos

- SDK .NET 6.0 o posterior (el código también funciona con .NET Framework 4.7+)
- Visual Studio 2022 o cualquier IDE de C#
- Paquete NuGet Aspose.BarCode para .NET (`Aspose.BarCode`) instalado
- Familiaridad básica con la sintaxis de C#

> **Consejo profesional:** Usa la licencia de evaluación gratuita de Aspose para evitar restricciones en tiempo de ejecución durante las pruebas.

## Paso 1: Configurar el proyecto e importar espacios de nombres

Crea un nuevo proyecto de consola y agrega el paquete Aspose.BarCode:

```bash
dotnet new console -n Pdf417Demo
cd Pdf417Demo
dotnet add package Aspose.BarCode
```

Luego abre `Program.cs` y agrega las directivas `using` requeridas:

```csharp
using System;
using Aspose.BarCode.Generation;
```

Estos espacios de nombres te dan acceso a la clase `BarcodeGenerator` y a la enumeración `EncodeTypes` necesarias para **generar códigos de barras usando C#**.

## Paso 2: Generar un código de barras PDF417 básico

El código de barras PDF417 más simple usa la configuración predeterminada, excepto por la X‑dimensión (ancho del módulo) y el número de columnas. Ajustar estos valores controla el tamaño general y la legibilidad.

```csharp
// Step 2: Basic PDF417
var basicPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    // Set module width to 2 pixels for a compact image
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 3 }
        }
    }
};

basicPdf417.Save("Pdf417Basic.png", BarCodeImageFormat.Png);
Console.WriteLine("Basic PDF417 saved as Pdf417Basic.png");
```

**Por qué funciona:**  
- `EncodeTypes.Pdf417` indica a Aspose que use la simbología PDF417.  
- `XDimension.Pixels` define el ancho de barra más pequeño; un valor de 2 mantiene la imagen pequeña sin sacrificar la capacidad de escaneo.  
- `Pdf417.Columns` determina cuántas columnas de datos contiene el código de barras; tres columnas proporcionan una proporción equilibrada.

## Paso 3: Generar un código de barras PDF417 compacto (truncado)

El modo compacto elimina el patrón de parada y reduce la altura total, lo que es útil para etiquetas con espacio limitado.

```csharp
// Step 3: Compact PDF417 (truncated mode)
var compactPdf417 = new BarcodeGenerator(EncodeTypes.Pdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = {
                Columns = 3,
                Truncate = true          // Enable compact mode
            }
        }
    }
};

compactPdf417.Save("CompactPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Compact PDF417 saved as CompactPdf417.png");
```

**Por qué funciona:**  
Establecer `Pdf417.Truncate = true` activa el modo truncado, que omite el patrón de parada derecho y reduce la altura del código de barras mientras preserva la integridad de los datos.

## Paso 4: Generar un código de barras Micro PDF417

Micro PDF417 es una variante más pequeña que admite de 1 a 4 columnas. Es ideal para aplicaciones donde el espacio es limitado, como etiquetas de productos pequeñas.

```csharp
// Step 4: Micro PDF417
var microPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417, "Sample text")
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }   // 1‑4 columns allowed for Micro PDF417
        }
    }
};

microPdf417.Save("MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("Micro PDF417 saved as MicroPdf417.png");
```

**Por qué funciona:**  
- `EncodeTypes.MicroPdf417` selecciona la versión micro de la simbología.  
- El número de columnas puede estar entre 1 y 4; elegir 4 produce el diseño más denso mientras sigue siendo escaneable.

## Paso 5: Generar un código de barras Micro PDF417 compatible con GS1

Los prefijos GS1 añaden identificadores estandarizados (p. ej., GTIN, número de lote) a los datos del código de barras. Aspose te permite incrustarlos directamente.

```csharp
// Step 5: GS1‑Micro PDF417
var gs1MicroPdf417 = new BarcodeGenerator(EncodeTypes.MicroPdf417,
    "(01)12345678901231(10)ABC123")   // (01) = GTIN, (10) = batch/lot
{
    Parameters = {
        Barcode = {
            XDimension = { Pixels = 2 },
            Pdf417 = { Columns = 4 }
        }
    }
};

gs1MicroPdf417.Save("Gs1MicroPdf417.png", BarCodeImageFormat.Png);
Console.WriteLine("GS1‑Micro PDF417 saved as Gs1MicroPdf417.png");
```

**Por qué funciona:**  
Los Identificadores de Aplicación GS1 (AIs) se colocan entre paréntesis. Aspose los interpreta y agrega el formato apropiado requerido por los escáneres GS1.

## Paso 6: Generar un código de barras Macro PDF417 con metadatos completos

Macro PDF417 permite dividir una gran carga de datos en varios códigos de barras vinculados. Puedes incrustar metadatos a nivel de archivo como ID de archivo, recuento de segmentos, marcas de tiempo y cadenas personalizadas.

```csharp
// Step 6: Macro PDF417 with metadata
using (var macroPdf417 = new BarcodeGenerator(EncodeTypes.MacroPdf417, "Sample text"))
{
    macroPdf417.Parameters.Barcode.XDimension.Pixels = 2;
    macroPdf417.Parameters.Barcode.Pdf417.Columns = 5;

    // ---- macro metadata ----
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileID = 12345678;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentID = 12;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417SegmentsCount = 20;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileName = "file01";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Checksum = 1234; // CCITT‑16 CRC
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417FileSize = 400_000;
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417TimeStamp = new DateTime(2019, 11, 1);
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Addressee = "street";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Sender = "aspose";
    macroPdf417.Parameters.Barcode.Pdf417.MacroPdf417Terminator = Pdf417MacroTerminator.Set;

    macroPdf417.Save("MacroPdf417.png", BarCodeImageFormat.Png);
    Console.WriteLine("Macro PDF417 saved as MacroPdf417.png");
}
```

**Por qué funciona:**  
Cada propiedad `MacroPdf417*` se asigna a un segmento específico de la especificación del código de barras macro. Configurar estos valores garantiza que un escáner pueda reconstruir el archivo original a partir de múltiples imágenes de códigos de barras.
