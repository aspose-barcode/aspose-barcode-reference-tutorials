# Cómo generar códigos de barras DataMatrix con Aspose.BarCode para .NET

Si necesita una forma fiable de incrustar símbolos legibles por máquina en sus aplicaciones .NET, **cómo generar DataMatrix** es un requisito común. Aspose.BarCode para .NET ofrece una API totalmente administrada que maneja cada paso, desde elegir la versión correcta de DataMatrix hasta ajustar finamente los niveles de corrección de errores, sin requerir herramientas externas. En este tutorial recorreremos un ejemplo completo, explicaremos por qué cada configuración es importante y le mostraremos cómo guardar el resultado como una imagen PNG o JPEG.

## Respuestas rápidas
- **¿Qué biblioteca crea códigos de barras DataMatrix?** Aspose.BarCode para .NET.  
- **¿Cuántas versiones de DataMatrix son compatibles?** Todas las 30 versiones estándar cuadradas y rectangulares (de 10×10 hasta 144×144 módulos).  
- **¿Qué tipos de ECC puedo usar?** ECC200 (predeterminado) y ECC140.  
- **¿Necesito una licencia para desarrollo?** Una prueba gratuita de 30 días funciona para pruebas; se requiere una licencia comercial para producción.  
- **¿Puedo ejecutar esto en .NET 6, .NET Core o .NET Framework?** Sí—Aspose.BarCode soporta .NET Framework 4.5+, .NET Core 3.1+ y .NET 5/6+.

## ¿Qué es un código de barras DataMatrix?
Un código de barras DataMatrix es una matriz bidimensional, cuadrada o rectangular, de celdas negras y blancas que puede almacenar hasta 2 335 caracteres alfanuméricos. Se utiliza ampliamente en la fabricación, la logística y la atención sanitaria para marcar artículos pequeños porque sigue siendo legible incluso cuando está parcialmente dañado.

## ¿Por qué usar Aspose.BarCode para .NET?
Aspose.BarCode soporta **más de 50 formatos de salida** (incluidos PNG, JPEG, TIFF, SVG y PDF) y puede generar **las 30 versiones de DataMatrix** sin cargar la imagen completa en memoria, lo que le permite crear códigos de barras en servicios de alto rendimiento que procesan archivos de más de 100 MB.

## Requisitos previos

Antes de sumergirnos en el código, asegúrese de que tiene los siguientes requisitos previos:
- Un entorno de desarrollo con soporte .NET (Visual Studio 2022, Rider o VS Code).  
- Una copia de Aspose.BarCode para .NET, que puede descargar desde la **página de descarga de Aspose.BarCode .NET**: [Aspose.BarCode .NET download page](https://releases.aspose.com/barcode/net/).  
- Conocimientos básicos de C# y del framework .NET.

Ahora, exploremos las versiones de DataMatrix y cómo generarlas usando Aspose.BarCode para .NET.

## Cómo generar códigos de barras DataMatrix en .NET?

Cargue el `BarcodeGenerator` con el tipo `EncodeTypes.DataMatrix`, establezca la versión y el ECC deseados, y luego llame a `Save` para escribir el archivo de imagen. Este patrón de una sola línea funciona para cualquier versión que elija y maneja automáticamente el dimensionado de módulos, las zonas silenciosas y la renderización de la imagen.

## Importar espacios de nombres

`BarcodeGenerator` es la clase principal de Aspose.BarCode para crear imágenes de códigos de barras.  
```csharp
using Aspose.BarCode.Generation;
```
```csharp
using Aspose.BarCode.Generation;
```

El espacio de nombres `Aspose.BarCode.Generation` proporciona acceso a la clase `BarcodeGenerator`, que es la clase principal utilizada para generar imágenes de códigos de barras.

Ahora, desglosaremos el ejemplo en varios pasos.

## Paso 1: configurar la ruta del directorio

Comience definiendo la ruta del directorio donde desea guardar los códigos de barras DataMatrix generados.

```csharp
string path = "Your Directory Path";
```

Reemplace `"Your Directory Path"` con la ruta real donde desea guardar las imágenes del código de barras.

## Paso 2: inicializar el generador de códigos de barras

Cree una instancia de la clase `BarcodeGenerator` y especifique el tipo de código de barras como `DataMatrix`. También puede proporcionar los datos que desea codificar dentro del código de barras.

```csharp
using (BarcodeGenerator generator = new BarcodeGenerator(EncodeTypes.DataMatrix, "Åspóse.Barcóde©"))
{
    // Code for generating barcodes goes here
}
```

`BarcodeGenerator` es la clase principal que crea y renderiza símbolos de códigos de barras.

## Paso 3: configurar las propiedades del código de barras

Puede personalizar varias propiedades del código de barras DataMatrix, como sus dimensiones y el tipo de ECC (Error Correction Code). Aquí hay un ejemplo de cómo establecer la dimensión X a 4 píxeles y elegir ECC200:

```csharp
generator.Parameters.Barcode.XDimension.Pixels = 4;
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc200;
```

`XDimension` establece el tamaño de cada módulo en píxeles, y `DataMatrixEcc` selecciona el nivel de corrección de errores.

## Paso 4: establecer la versión DataMatrix y guardar

Puede especificar la versión de DataMatrix estableciendo el número de filas y columnas. Después de configurar la versión, guarde la imagen del código de barras.

Por ejemplo, para crear un código de barras DataMatrix con 22 filas y 22 columnas usando ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC200_22x22;
generator.Save($"{path}DataMatrixRows22Columns22Ecc200.png", BarCodeImageFormat.Png);
```

De manera similar, puede generar un código de barras con diferentes parámetros cambiando la versión y el tipo de ECC según sea necesario.

## Paso 5: repetir para otras versiones

Puede repetir el Paso 4 para otras versiones de DataMatrix. Por ejemplo, para crear un código de barras con 12 filas y 64 columnas usando ECC200:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.DMRE_12x64;
generator.Save($"{path}DataMatrixRows12Columns64Ecc200.png", BarCodeImageFormat.Png);
```

## Paso 6: cambiar los tipos de ECC

Si desea cambiar el tipo de ECC a Ecc140, puede hacerlo actualizando la propiedad ECC:

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixEcc = DataMatrixEccType.Ecc140;
```

## Paso 7: generar códigos de barras con diferentes versiones y ECC

Repita el Paso 4 para otras versiones de DataMatrix y tipos de ECC, guardando cada código de barras con un nombre de archivo único.

```csharp
generator.Parameters.Barcode.DataMatrix.DataMatrixVersion = DataMatrixVersion.ECC000_140_29x29;
generator.Save($"{path}DataMatrixRows29Columns29Ecc140.png", BarCodeImageFormat.Png);
```

Ahora que ha aprendido cómo generar códigos de barras DataMatrix usando Aspose.BarCode para .NET, puede integrar fácilmente esta funcionalidad en sus aplicaciones .NET.

## Problemas comunes y consejos de solución

- **Dimensiones de versión incorrectas** – Las versiones de DataMatrix tienen pares de filas/columnas fijos. Proporcionar un par no coincidente (p. ej., 10 × 20) generará una `ArgumentException`. Siempre use una de las combinaciones compatibles listadas en la documentación de la API.  
- **Licencia faltante** – En modo de prueba, las imágenes generadas contienen una marca de agua. Aplique una licencia válida con `License license = new License(); license.SetLicense("Aspose.BarCode.lic");` antes de crear el generador para eliminar la marca de agua. La clase `License` carga un archivo de licencia para activar el producto.  
- **Tamaño de imagen grande** – Si necesita una salida de alta resolución, aumente la propiedad `XDimension`; la biblioteca escala la imagen proporcionalmente sin perder legibilidad.
