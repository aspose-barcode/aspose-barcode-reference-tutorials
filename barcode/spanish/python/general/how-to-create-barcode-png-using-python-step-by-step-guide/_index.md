# Cómo crear un archivo PNG de código de barras usando Python – guía paso a paso

Si necesitas **crear archivos PNG de código de barras** a partir de cadenas arbitrarias, este tutorial te ofrece una solución lista para ejecutar. Verás exactamente cómo generar un código de barras Code 128, convertir texto en una imagen de código de barras y guardar el resultado como un archivo PNG, todo con unas pocas líneas de Python.

La guía cubre todo lo que necesitas saber, desde la instalación de la biblioteca requerida hasta la personalización de la salida para diferentes casos de uso. Al final, podrás integrar la generación de códigos de barras en cualquier proyecto Python sin buscar documentación adicional.

## Lo que aprenderás

* Instalar el paquete **barcode generator python** que soporta Code 128.
* Usar `BarCodeGenerator` para **generar código 128 barcode** a partir de una cadena de texto.
* Guardar el resultado como un PNG de alta calidad con `save`.
* Ajustar el tamaño de la imagen, colores de primer plano/fondo y manejar errores comunes.
* Verificar que el PNG se haya creado correctamente.

### Requisitos previos

| Requisito | Motivo |
|-------------|--------|
| Python 3.8+ | Sintaxis moderna y anotaciones de tipo |
| Acceso a Internet (para `pip install`) | Para descargar la biblioteca |
| Permiso de escritura en una carpeta | Para almacenar el PNG generado |

No se requieren servicios externos; todo se ejecuta localmente.

## Paso 1: Instalar la biblioteca de códigos de barras

La forma más directa de **convertir texto a código de barras** en Python es usar el paquete **Aspose.BarCode for Python via .NET**, que soporta Code 128 de forma nativa.

```bash
pip install aspose-barcode
```

> **Consejo profesional:** Si trabajas en un entorno virtual, actívalo antes de ejecutar el comando para mantener las dependencias aisladas.

## Paso 2: Importar las clases que necesitas

Después de la instalación, importa las clases principales. Las sentencias de importación son breves, lo que facilita la lectura del código.

```python
from aspose.barcode import BarCodeGenerator, EncodeTypes
```

* `BarCodeGenerator` crea la imagen del código de barras.
* `EncodeTypes` proporciona una enumeración de las simbologías compatibles, incluido `CODE_128`.

## Paso 3: Definir el texto que deseas codificar

Elige cualquier cadena alfanumérica. Code 128 puede representar todo el conjunto ASCII, por lo que no estás limitado a números.

```python
# Step 3: Define the text to encode in the barcode
barcode_text = "1234567890"
```

Si la entrada contiene caracteres no compatibles, el generador lanza un `ValueError`. Envuelve la asignación en un bloque `try` si esperas datos proporcionados por el usuario.

## Paso 4: Crear el generador de código de barras para Code 128

Instancia `BarCodeGenerator` con la simbología deseada y el texto que definiste. Este es el núcleo de **cómo generar códigos de barras** en Python.

```python
# Step 4: Create a barcode generator for Code 128 symbology
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)
```

¿Por qué Code 128? Ofrece alta densidad y puede codificar todo el rango ASCII, lo que lo hace ideal para sistemas de inventario, etiquetas de envío y tickets.

## Paso 5: (Opcional) Personalizar la apariencia

Puedes afinar el código de barras antes de guardarlo. Las siguientes opciones son comunes:

```python
# Optional: set image resolution and colors
generator.parameters.image_height = 100          # pixels
generator.parameters.image_width = 300           # pixels
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"
```

Estos ajustes afectan la salida final de **create barcode png** sin alterar los datos codificados.

## Paso 6: Guardar el código de barras como archivo PNG

Finalmente, escribe la imagen en disco. El método `save` detecta automáticamente la extensión del archivo, por lo que pasar `.png` crea una imagen PNG.

```python
# Step 6: Save the generated barcode as an image file
output_path = "output/extended_barcode.png"
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")
```

Si el directorio de destino no existe, Python lanza un `FileNotFoundError`. Crea el directorio previamente o usa `os.makedirs` con `exist_ok=True`.

```python
import os
os.makedirs(os.path.dirname(output_path), exist_ok=True)
```

### Salida esperada

Después de ejecutar el script, encontrarás `extended_barcode.png` en la carpeta `output`. Al abrir el archivo verás un código de barras Code 128 nítido que codifica `1234567890`.

![Generated barcode PNG created with Python](generated_barcode.png "ejemplo de create barcode png")

## Paso 7: Verificar el código de barras (comprobación rápida)

Puedes leer el PNG nuevamente con la misma biblioteca para confirmar que el valor codificado coincide con el texto original.

```python
from aspose.barcode import BarCodeReader, DecodeType

with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Ejecutar este bloque imprime:

```
Verification succeeded: 1234567890
```

Si la aserción falla, verifica `barcode_text` y cualquier parámetro personalizado que hayas establecido.

## Variaciones comunes y casos límite

| Situación | Ajuste |
|-----------|------------|
| **Texto más largo (> 20 caracteres)** | Incrementa `image_width` para evitar truncamiento. |
| **Necesitas un fondo transparente** | Establece `back_color = "Transparent"` antes de guardar. |
| **Generar múltiples códigos de barras en un bucle** | Envuelve los pasos 3‑6 en un `for` loop, cambiando `barcode_text` en cada iteración. |
| **Guardar como JPEG en lugar de PNG** | Cambia la extensión del archivo a `.jpg`; la biblioteca maneja el formato automáticamente. |
| **Ejecutar en un servidor sin interfaz gráfica** | La biblioteca no requiere GUI, lo que la hace segura para pipelines CI. |

## Script completo para copiar y pegar rápidamente

```python
import os
from aspose.barcode import BarCodeGenerator, EncodeTypes, BarCodeReader, DecodeType

# ---------- Configuration ----------
output_dir = "output"
output_file = "extended_barcode.png"
barcode_text = "1234567890"

# Ensure the output directory exists
os.makedirs(output_dir, exist_ok=True)
output_path = os.path.join(output_dir, output_file)

# ---------- Generate barcode ----------
generator = BarCodeGenerator(EncodeTypes.CODE_128, barcode_text)

# Optional appearance tweaks
generator.parameters.image_height = 100
generator.parameters.image_width = 300
generator.parameters.back_color = "White"
generator.parameters.fore_color = "Black"

# Save as PNG
generator.save(output_path)
print(f"Barcode PNG saved to {output_path}")

# ---------- Verify the result ----------
with BarCodeReader(output_path, DecodeType.CODE_128) as reader:
    if reader.read():
        decoded = reader.get_code_text()
        assert decoded == barcode_text, "Decoded value does not match original"
        print(f"Verification succeeded: {decoded}")
    else:
        print("No barcode detected in the image.")
```

Guarda el script como `generate_barcode.py` y ejecútalo:

```bash
python generate_barcode.py
```

Verás los mensajes de confirmación y un nuevo archivo PNG en la carpeta `output`.
