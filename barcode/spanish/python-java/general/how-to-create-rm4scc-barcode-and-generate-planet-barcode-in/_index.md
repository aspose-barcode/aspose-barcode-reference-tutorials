# Cómo crear un código de barras RM4SCC y generar código de barras Planet en C#

Si necesita **crear un código de barras RM4SCC** para aplicaciones postales, esta guía le muestra los pasos exactos. También aprenderá cómo **generar un código de barras Planet** con alturas automáticas y fijas, de modo que el mismo código funcione para cualquier simbología postal.

El tutorial cubre todo lo necesario para producir imágenes PNG que cumplan con los estándares postales. No se requieren herramientas externas más allá de la biblioteca Aspose.BarCode for .NET. Al final, podrá generar códigos de barras programáticamente y controlar sus dimensiones con precisión.

## Requisitos previos

Antes de comenzar, asegúrese de tener:

* .NET 6.0 o posterior instalado
* Visual Studio 2022 (o cualquier IDE de C#)
* Paquete NuGet Aspose.BarCode for .NET  
  `Install-Package Aspose.BarCode`
* Permiso de escritura en el directorio de salida

Estos elementos le permiten compilar y ejecutar el código de ejemplo sin configuración adicional.

## Paso 1: Inicializar el generador de códigos de barras para RM4SCC

La primera operación crea una instancia de `BarcodeGenerator` configurada para la simbología RM4SCC. Este objeto contiene todas las configuraciones para la imagen del código de barras.

```csharp
using Aspose.BarCode.Generation;

// Create a generator for the RM4SCC symbology
BarcodeGenerator rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
```

**Por qué es importante** – `EncodeTypes.RM4SCC` indica a Aspose que use el formato postal RM4SCC, mientras que la cadena de datos `"123456"` representa el código postal que desea codificar.

## Paso 2: Establecer el ancho del módulo (dimensión X)

El ancho del módulo controla el tamaño de la barra fina. Un valor común para los códigos de barras postales es 4 píxeles.

```csharp
// Set the module width (X‑dimension) in pixels
rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
```

**Explicación** – La dimensión X influye en la legibilidad general del código de barras. Elegir 4 px coincide con la mayoría de los escáneres postales.

## Paso 3: Guardar con altura de barra automática

Cuando omite un valor de altura, Aspose calcula automáticamente la altura óptima según las reglas de la simbología.

```csharp
// Save the image – the bar height is calculated automatically
rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);
```

**Resultado** – El PNG generado (`PostalRM4SCCBarHeightNone.png`) contiene un código de barras RM4SCC con el tamaño correcto listo para imprimir.

## Paso 4: Crear un código de barras Planet con altura automática

El mismo patrón funciona para la simbología Planet. Comience inicializando el generador con `EncodeTypes.Planet`.

```csharp
// Create a generator for the Planet symbology
BarcodeGenerator planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set the module width
planetAuto.Parameters.Barcode.XDimension.Pixels = 4;

// Save the image – height is calculated automatically
planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);
```

**Por qué reutilizar el código** – Tanto RM4SCC como Planet comparten la misma estructura de parámetros, por lo que puede cambiar de simbología modificando solo el valor de `EncodeTypes`.

## Paso 5: Definir una altura de barra fija para RM4SCC

Algunos servicios postales requieren una altura de barra específica (p. ej., 100 px). Puede establecerla explícitamente antes de guardar.

```csharp
// Create a generator for RM4SCC with fixed height
BarcodeGenerator rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Set module width
rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Consejo** – Establecer `BarHeight.Pixels` anula el cálculo automático, dándole control total sobre el tamaño visual.

## Paso 6: Definir una altura de barra fija para Planet

Aplique la misma técnica de altura fija a un código de barras Planet.

```csharp
// Create a generator for Planet with fixed height
BarcodeGenerator planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Set module width
planetFixed.Parameters.Barcode.XDimension.Pixels = 4;

// Define a fixed bar height of 100 pixels
planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;

// Save the image with the specified height
planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);
```

**Resultado** – Tanto `PostalRM4SCCBarHeight100Pixels.png` como `PostalPlanetBarHeight100Pixels.png` contienen códigos de barras con una altura de barra constante de 100 px, cumpliendo con especificaciones postales estrictas.

## Código fuente completo

A continuación se muestra el programa completo y ejecutable que abarca los cuatro ejemplos. Cópielo en un nuevo proyecto de consola y ajuste la ruta de salida según sea necesario.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Automatic height – RM4SCC
        var rm4sccAuto = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccAuto.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccAuto.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeightNone.png", BarCodeImageFormat.Png);

        // Automatic height – Planet
        var planetAuto = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetAuto.Parameters.Barcode.XDimension.Pixels = 4;
        planetAuto.Save("YOUR_DIRECTORY/PostalPlanetBarHeightNone.png", BarCodeImageFormat.Png);

        // Fixed height – RM4SCC
        var rm4sccFixed = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4sccFixed.Parameters.Barcode.XDimension.Pixels = 4;
        rm4sccFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        rm4sccFixed.Save("YOUR_DIRECTORY/PostalRM4SCCBarHeight100Pixels.png", BarCodeImageFormat.Png);

        // Fixed height – Planet
        var planetFixed = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFixed.Parameters.Barcode.XDimension.Pixels = 4;
        planetFixed.Parameters.Barcode.BarHeight.Pixels = 100;
        planetFixed.Save("YOUR_DIRECTORY/PostalPlanetBarHeight100Pixels.png", BarCodeImageFormat.Png);

        Console.WriteLine("All barcodes generated successfully.");
    }
}
```

**Salida esperada** – Después de ejecutar el programa, el directorio especificado contiene cuatro archivos PNG:

* `PostalRM4SCCBarHeightNone.png` – RM4SCC con altura automática
* `PostalPlanetBarHeightNone.png` – Planet con altura automática
* `PostalRM4SCCBarHeight100Pixels.png` – RM4SCC con altura de 100 px
* `PostalPlanetBarHeight100Pixels.png` – Planet con altura de 100 px

Abra cualquier archivo para verificar que las barras sean nítidas, el ancho del módulo sea de 4 px y la altura coincida con la configuración elegida.

## Preguntas frecuentes y casos límite

| Pregunta | Respuesta |
|----------|-----------|
| **¿Puedo usar otros formatos de imagen?** | Sí. Reemplace `BarCodeImageFormat.Png` por `Jpeg`, `Bmp` o `Gif` según sea necesario. |
| **¿Qué ocurre si la cadena de datos es más larga?** | El generador ajusta automáticamente el número de barras. Asegúrese de que los datos cumplan con los límites de longitud de la simbología (RM4SCC ≤ 6 dígitos, Planet ≤ 6 dígitos). |
| **¿Cómo cambio el color de la barra?** | Establezca `rm4sccAuto.Parameters.Barcode.BarColor = Color.Blue;` antes de llamar a `Save`. |
| **¿Es importante el DPI para la impresión?** | Puede establecer `rm4sccAuto.Parameters.ImageResolution.DpiX` y `DpiY` para que coincidan con la resolución de su impresora. |
