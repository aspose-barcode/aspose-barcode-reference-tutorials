# Cómo crear un código de barras Planet PNG con Python

Si necesitas **crear un código de barras Planet PNG**, este tutorial te guía a través del proceso completo usando Python. También aprenderás **cómo generar un código de barras Planet** paso a paso, configurar su apariencia y guardar el resultado como una imagen PNG de alta calidad.

Generar un código de barras Planet es común en la automatización postal, el seguimiento de inventario y los sistemas logísticos. Al final de esta guía tendrás un script autónomo que produce un archivo PNG listo para usar, y comprenderás cómo adaptar el código para diferentes tamaños o formatos de imagen.

## Requisitos previos

* Python 3.8 o superior instalado.
* Acceso al paquete `aspose-barcode` (o cualquier biblioteca compatible que proporcione las clases `BarcodeGenerator`, `EncodeTypes` y `BarCodeImageFormat`).
* Permiso de escritura en el directorio donde deseas almacenar el archivo PNG.

Puedes instalar la biblioteca requerida con pip:

```bash
pip install aspose-barcode
```

> **Consejo profesional:** Usa un entorno virtual para mantener las dependencias aisladas de otros proyectos.

## Crear código de barras Planet PNG – recorrido completo del código

El siguiente script muestra cada paso necesario para generar un código de barras Planet PNG con barras vacías (sin rellenar). Copia el código en un archivo llamado `planet_barcode.py` y ejecútalo con `python planet_barcode.py`.

```python
# planet_barcode.py
from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Initialize a Planet barcode generator with the data to encode
# The data "123456" is a typical numeric payload for postal services.
generator = BarcodeGenerator(EncodeTypes.Planet, "123456")

# Step 2: Set the width of each bar (X dimension) to 4 pixels.
# Adjusting the X dimension changes the overall size and readability.
generator.parameters.barcode.x_dimension.pixels = 4

# Step 3: Configure the barcode to use empty (unfilled) bars.
# When `filled_bars` is False, the dark bars become transparent,
# which is useful for overlaying the barcode on colored backgrounds.
generator.parameters.barcode.filled_bars = False

# Step 4: Save the generated barcode as a PNG image.
# The output path can be absolute or relative; ensure the folder exists.
output_path = "output/PostalPlanetEmptyBars.png"
generator.save(output_path, BarCodeImageFormat.PNG)

print(f"Planet barcode PNG saved to: {output_path}")
```

### Qué hace cada línea

| Línea | Explicación |
|------|-------------|
| `from aspose.barcode import ...` | Importa las clases necesarias para crear y configurar el código de barras. |
| `BarcodeGenerator(EncodeTypes.Planet, "123456")` | Instancia un generador para la simbología **Planet** usando la cadena numérica `"123456"`. |
| `x_dimension.pixels = 4` | Establece el ancho de la barra a 4 px; valores mayores generan un código de barras más grande, mientras que valores menores reducen el tamaño del archivo. |
| `filled_bars = False` | Cambia el código de barras para usar **barras vacías**, haciendo que los módulos oscuros sean transparentes. |
| `save(..., BarCodeImageFormat.PNG)` | Escribe el código de barras en un archivo PNG, preservando la calidad sin pérdida. |
| `print(...)` | Confirma la creación exitosa en la consola. |

## Cómo generar un código de barras Planet con configuraciones personalizadas

Aunque el script básico cubre la mayoría de los casos de uso, puede que necesites ajustar el código de barras para requisitos específicos:

1. **Longitudes de datos diferentes** – Los códigos de barras Planet admiten hasta 12 caracteres numéricos. Cambia `"123456"` por cualquier cadena numérica válida dentro de ese rango.
2. **Formatos de imagen alternativos** – Reemplaza `BarCodeImageFormat.PNG` por `BarCodeImageFormat.JPEG` o `BarCodeImageFormat.BMP` para adaptarse a las canalizaciones de procesamiento posteriores.
3. **Cambiar la dimensión X** – Valores mayores (p.ej., `8`) crean un código de barras de mayor resolución, lo cual es útil para imprimir en etiquetas grandes.
4. **Colores de fondo** – Si deseas un fondo coloreado, establece `generator.parameters.barcode.back_color` antes de guardar.

Ejemplo con un color de fondo personalizado:

```python
from aspose.barcode import Color

generator.parameters.barcode.back_color = Color.get_yellow()
generator.save("output/PlanetYellowBackground.png", BarCodeImageFormat.PNG)
```

## Errores comunes y cómo evitarlos

| Problema | Razón | Solución |
|----------|-------|----------|
| **FileNotFoundError** al guardar | El directorio de destino no existe. | Crea el directorio previamente (`os.makedirs("output", exist_ok=True)`). |
| **Longitud de datos inválida** | El código de barras Planet solo acepta datos numéricos de hasta 12 caracteres. | Valida la cadena de entrada antes de crear el generador. |
| **Barras transparentes no visibles** | Algunos visores ignoran la transparencia en un lienzo blanco. | Coloca el código de barras sobre un fondo no blanco o exporta como PNG con canal alfa. |

## Verificando la salida

Después de ejecutar el script, abre `PostalPlanetEmptyBars.png` con cualquier visor de imágenes. Deberías ver una serie de barras verticales donde los módulos oscuros son transparentes, dejando solo el contorno del código de barras. Para confirmar que el código de barras es escaneable, usa una aplicación móvil de escáner de códigos de barras que admita la simbología Planet.

Si la imagen aparece en blanco, verifica:

* La bandera `filled_bars` está establecida en `False`.
* La dimensión X no está establecida en cero.
* La ruta de salida apunta a una carpeta existente.
