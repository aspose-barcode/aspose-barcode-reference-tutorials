# Cómo generar una imagen de código de barras en C# con DataBar Stacked Omni‑Directional

Si necesitas **cómo generar una imagen de código de barras** en una aplicación .NET, este tutorial muestra los pasos exactos. Verás cómo crear un código de barras DataBar Stacked Omni‑Directional, ajustar su relación de aspecto y exportar el resultado como archivos PNG.

Generar códigos de barras es un requisito común para sistemas de inventario, terminales de punto de venta y seguimiento logístico. En las siguientes secciones cubriremos todo lo que necesitas, desde el paquete NuGet requerido hasta la verificación final de la imagen, para que puedas integrar la creación de códigos de barras en cualquier proyecto C# hoy mismo.

## Requisitos previos

Antes de comenzar, asegúrate de tener:

* .NET 6.0 o posterior (el código funciona con .NET Core y .NET Framework)
* Visual Studio 2022 o cualquier IDE de C# que prefieras
* El paquete NuGet **Aspose.BarCode for .NET** (instálalo con `dotnet add package Aspose.BarCode`)
* Permiso de escritura en la carpeta donde se guardarán los archivos PNG

Estos requisitos garantizan que el ejemplo se ejecute sin configuración adicional.

## Paso 1: Configurar la carpeta de salida

Lo primero que necesitas es un directorio donde se escribirán los archivos PNG generados. Funciona usar una ruta absoluta o relativa, pero asegúrate de que la carpeta exista antes de llamar a `Save`.

```csharp
// Step 1: Define the output folder
string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");

// Create the folder if it doesn't exist
Directory.CreateDirectory(outputFolder);
```

Crear la carpeta programáticamente evita *FileNotFoundException* cuando el método `Save` intenta escribir la imagen.

## Paso 2: Crear un generador de código de barras DataBar Stacked Omni‑Directional

La clase **BarcodeGenerator** es el punto de entrada para todos los tipos de códigos de barras. Aquí especificamos `EncodeTypes.DatabarStackedOmniDirectional` y la cadena de datos que queremos codificar.

```csharp
// Step 2: Initialise the generator with the desired barcode type and data
BarcodeGenerator generator = new BarcodeGenerator(
    EncodeTypes.DatabarStackedOmniDirectional,
    "(01)12345678901231"); // GS1 Application Identifier 01 + 14‑digit GTIN
```

*Por qué es importante*: El enum `EncodeTypes` indica a la biblioteca qué simbología renderizar. Usar la variante Omni‑Directional asegura que el código de barras pueda escanearse desde cualquier orientación, un requisito para muchos escáneres de almacén.

## Paso 3: Configurar parámetros comunes del código de barras

Un código de barras legible necesita una dimensión X razonable (el ancho de la barra más pequeña). Establecer `Pixels` a 2 brinda un buen equilibrio entre tamaño y claridad para la mayoría de resoluciones de pantalla.

```csharp
// Step 3: Set common barcode parameters (pixel size of the X‑dimension)
generator.Parameters.Barcode.XDimension.Pixels = 2;
```

Puedes ajustar `Pixels` más adelante si necesitas una imagen más grande o más pequeña; la biblioteca escala automáticamente el resto del código de barras.

## Paso 4: Generar la primera imagen con relación de aspecto 15

La **relación de aspecto** controla la relación altura‑ancho de los códigos de barras DataBar. Una relación de aspecto de 15 es el valor predeterminado típico para etiquetas de venta al por menor.

```csharp
// Step 4: Configure aspect ratio 15 and save the image
generator.Parameters.Barcode.DataBar.AspectRatio = 15;
generator.Save($"{outputFolder}/DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

Después de esta llamada, encontrarás `DatabarAspectRatio15.png` en la carpeta de salida. La imagen es un PNG sin pérdida, adecuado para procesamiento adicional o impresión.

## Paso 5: Cambiar la relación de aspecto a 30 y exportar una segunda imagen

A veces se requiere un código de barras más alto, por ejemplo, cuando la altura de la etiqueta es limitada. Cambiar la relación de aspecto a 30 produce una visual más compacta mientras preserva la integridad de los datos.

```csharp
// Step 5: Change aspect ratio to 30 and save the second image
generator.Parameters.Barcode.DataBar.AspectRatio = 30;
generator.Save($"{outputFolder}/DatabarAspectRatio30.png", BarCodeImageFormat.Png);
```

Ahora tienes dos archivos PNG que ilustran cómo se ve la misma información con diferentes relaciones de aspecto. Esta comparación lado a lado te ayuda a decidir qué variante se adapta mejor al diseño de tu etiqueta.

## Ejemplo completo y ejecutable

A continuación se muestra el programa completo que puedes copiar, pegar y ejecutar. Incluye todas las directivas `using`, manejo de errores y comentarios que explican cada parte del proceso.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        try
        {
            // 1️⃣ Define the output folder
            string outputFolder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
            Directory.CreateDirectory(outputFolder);

            // 2️⃣ Initialise the barcode generator (DataBar Stacked Omni‑Directional)
            BarcodeGenerator generator = new BarcodeGenerator(
                EncodeTypes.DatabarStackedOmniDirectional,
                "(01)12345678901231"); // GS1 GTIN

            // 3️⃣ Set common parameters – X‑dimension in pixels
            generator.Parameters.Barcode.XDimension.Pixels = 2;

            // 4️⃣ First image: aspect ratio 15
            generator.Parameters.Barcode.DataBar.AspectRatio = 15;
            string file15 = Path.Combine(outputFolder, "DatabarAspectRatio15.png");
            generator.Save(file15, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 15 to: {file15}");

            // 5️⃣ Second image: aspect ratio 30
            generator.Parameters.Barcode.DataBar.AspectRatio = 30;
            string file30 = Path.Combine(outputFolder, "DatabarAspectRatio30.png");
            generator.Save(file30, BarCodeImageFormat.Png);
            Console.WriteLine($"Saved barcode with aspect ratio 30 to: {file30}");
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"Error generating barcode: {ex.Message}");
        }
    }
}
```

**Salida esperada** (consola):

```
Saved barcode with aspect ratio 15 to: C:\YourPath\Barcodes\DatabarAspectRatio15.png
Saved barcode with aspect ratio 30 to: C:\YourPath\Barcodes\DatabarAspectRatio30.png
```

Abre los dos archivos PNG en cualquier visor de imágenes. Verás el mismo GTIN codificado, pero la segunda imagen es más alta debido a la mayor relación de aspecto.

## Consejos profesionales y errores comunes

| Situación | Recomendación |
|-----------|----------------|
| **Pantallas de baja resolución** | Aumenta `XDimension.Pixels` a 3 o 4 para mantener las barras nítidas. |
| **Impresión en papel térmico** | Utiliza `BarCodeImageFormat.Tiff` para mayor fidelidad y establece `Resolution.DpiX/DpiY` a 300. |
| **Datos dinámicos** | Reutiliza la misma instancia de `BarcodeGenerator` y solo actualiza `generator.CodeText` antes de cada `Save`. Esto evita la asignación innecesaria de objetos. |
| **GTIN inválido** | La biblioteca lanza `ArgumentException` si los datos no cumplen con los estándares GS1. Valida tus datos antes de pasarlos al generador. |
