# Cómo guardar imágenes de códigos de barras en C# usando la API BarcodeGenerator

Si necesitas **cómo guardar códigos de barras** desde una aplicación .NET, esta guía muestra los pasos exactos. Verás un **ejemplo completo de generador de códigos de barras** que crea un código DataBar Stacked Omnidirectional, ajusta su relación de aspecto y guarda dos archivos PNG.

Guardar imágenes de códigos de barras es un requisito común al crear sistemas de inventario, terminales punto de venta o flujos de trabajo de etiquetado automatizado. Al final de este tutorial podrás generar código C# que produce imágenes fiables listas para imprimir o mostrar.

## Requisitos previos

Antes de comenzar, asegúrate de tener:

- SDK de .NET 6.0 o posterior instalado  
- Visual Studio 2022 (o cualquier IDE compatible con C#)  
- El paquete NuGet **Aspose.BarCode for .NET** (el código usa `Aspose.BarCode.Generation`)  

Puedes añadir el paquete con el siguiente comando:

```bash
dotnet add package Aspose.BarCode
```

## Paso 1: Configurar un proyecto de consola C# mínimo

Crea un nuevo proyecto de consola y referencia la biblioteca:

```bash
dotnet new console -n BarcodeDemo
cd BarcodeDemo
dotnet add package Aspose.BarCode
```

Abre `Program.cs`. El archivo contendrá el método `Main` donde colocaremos la lógica de **generar código de barras C#**.

## Paso 2: Inicializar BarcodeGenerator para un código DataBar Stacked Omnidirectional

La primera tarea en cualquier flujo de **crear código databar** es instanciar `BarcodeGenerator` con el `EncodeType` correcto. El constructor recibe la simbología del código de barras y la cadena de datos.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Initialize the generator for a DataBar Stacked Omnidirectional barcode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");   // Example GTIN-14 data
```

El valor `EncodeTypes.DatabarStackedOmniDirectional` indica a la biblioteca que produzca un **crear código databar** que pueda escanearse desde cualquier dirección.

## Paso 3: Configurar la dimensión X (ancho del módulo)

La dimensión X controla el ancho de barra más pequeño en píxeles. Establecerla a un valor bajo mantiene el código compacto sin perder legibilidad.

```csharp
        // Set the X‑dimension to 2 pixels (module width)
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;
```

## Paso 4: **Cómo ajustar la relación de aspecto** – primer valor (15)

Los códigos DataBar exponen una propiedad `AspectRatio` que influye en la relación altura‑ancho. Una relación mayor produce un código más alto, lo que puede mejorar la fiabilidad del escaneo en ciertas impresoras.

```csharp
        // Aspect ratio 15 – taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
```

## Paso 5: **Cómo guardar código de barras** – primera imagen (relación de aspecto 15)

Ahora realmente **cómo guardar código de barras** en un archivo. El método `Save` recibe una ruta de archivo y un formato de imagen. En este ejemplo guardamos un archivo PNG.

```csharp
        // Save the barcode with aspect ratio 15
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);
```

> **Consejo:** El directorio del ejecutable es la ubicación de escritura predeterminada. Usa una ruta absoluta si necesitas una carpeta específica.

## Paso 6: **Cómo ajustar la relación de aspecto** – segundo valor (30)

Para demostrar flexibilidad, cambia la relación de aspecto y guarda una segunda imagen. Esto muestra cómo los mismos datos codificados pueden renderizarse con diferentes proporciones visuales.

```csharp
        // Change aspect ratio to 30 – even taller barcode
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;

        // Save the barcode with aspect ratio 30
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

Ejecutar el programa produce dos archivos PNG:

- `DatabarAspectRatio15.png` – código con una altura moderada  
- `DatabarAspectRatio30.png` – código con una altura mayor para entornos de escaneo difíciles  

Ambos archivos están listos para cargarse en controles UI, imprimirse en etiquetas o enviarse mediante API.

### Resultado esperado

Al abrir las imágenes generadas, deberías ver un código DataBar Stacked Omnidirectional que codifica el valor GTIN‑14 `12345678901231`. La diferencia visual entre los dos archivos es únicamente la altura, confirmando que **cómo ajustar la relación de aspecto** funciona como se espera.

## Paso 7: Código fuente completo para referencia

A continuación se muestra el programa completo y ejecutable. Cópialo en `Program.cs`, compílalo y ejecútalo.

```csharp
using System;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Step 1: Create a DataBar Stacked Omnidirectional generator with the data to encode
        BarcodeGenerator barcodeGen = new BarcodeGenerator(
            EncodeTypes.DatabarStackedOmniDirectional,
            "(01)12345678901231");

        // Step 2: Set the X‑dimension (module width) in pixels
        barcodeGen.Parameters.Barcode.XDimension.Pixels = 2;

        // Step 3: Configure the aspect ratio to 15 and save the barcode image
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 15;
        barcodeGen.Save("DatabarAspectRatio15.png", BarCodeImageFormat.Png);

        // Step 4: Change the aspect ratio to 30 for the same barcode and save again
        barcodeGen.Parameters.Barcode.DataBar.AspectRatio = 30;
        barcodeGen.Save("DatabarAspectRatio30.png", BarCodeImageFormat.Png);
    }
}
```

## Preguntas frecuentes y manejo de casos límite

### ¿Qué pasa si la carpeta de destino no existe?

`Save` lanza una `DirectoryNotFoundException`. Crea la carpeta primero:

```csharp
string folder = Path.Combine(Environment.CurrentDirectory, "Barcodes");
Directory.CreateDirectory(folder);
barcodeGen.Save(Path.Combine(folder, "DatabarAspectRatio15.png"), BarCodeImageFormat.Png);
```

### ¿Cómo cambiar el formato de imagen?

Reemplaza `BarCodeImageFormat.Png` por `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` o `BarCodeImageFormat.Tiff` según los requisitos posteriores.

### ¿Puedo generar varios códigos de barras en un bucle?

Sí. Instancia un nuevo `BarcodeGenerator` para cada cadena de datos o reutiliza la misma instancia después de actualizar la propiedad `CodeText`:

```csharp
barcodeGen.CodeText = "(01)98765432109876";
barcodeGen.Save("AnotherBarcode.png", BarCodeImageFormat.Png);
```

### ¿Funciona **cómo guardar código de barras** en plataformas que no son Windows?

Aspose.BarCode es multiplataforma. El mismo código se ejecuta en Linux y macOS siempre que el runtime de .NET esté presente.
