# Crear código de barras planet en C# – guía completa de programación

Si necesitas **crear un código de barras planet** en C#, esta guía te muestra exactamente cómo hacerlo. También descubrirás **cómo establecer las dimensiones del código de barras** para que las barras se rendericen con el ancho exacto que requieres.

Generar códigos de barras Planet es común cuando trabajas con servicios postales o sistemas logísticos. El código a continuación cubre tanto la versión predeterminada de barras rellenas como el estilo opcional de barras vacías, además de un ejemplo rápido para el formato RM4SCC. Al final de este tutorial tendrás un fragmento reutilizable que podrás insertar en cualquier proyecto .NET.

## Prerrequisitos

Antes de comenzar, asegúrate de tener:

* .NET 6.0 o posterior instalado (la API también funciona con .NET Framework 4.6+)
* El paquete NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`) agregado a tu proyecto
* Una ruta de carpeta con permisos de escritura donde se guardarán los archivos PNG
* Familiaridad básica con la sintaxis de C# y Visual Studio (o cualquier IDE)

> **Consejo profesional:** Utiliza una ruta absoluta o `Path.Combine(Environment.CurrentDirectory, "output")` para evitar problemas de permisos al guardar imágenes.

## Paso 1 – Inicializar un generador de código de barras Planet (barras rellenas)

El primer paso es crear una instancia de `BarcodeGenerator` para la simbología Planet. Por defecto, el generador produce barras **rellenas**.

```csharp
// Step 1: Create a Planet barcode with the default (filled) bars
BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

El enum `EncodeTypes.Planet` indica a Aspose.BarCode que use el formato Planet, mientras que `"123456"` es la carga de datos que se codificará.

## Paso 2 – Cómo establecer las dimensiones del código de barras para un tamaño consistente

Para controlar el ancho de cada barra, ajusta la **X‑dimensión**. Esta es la forma principal de **establecer las dimensiones del código de barras** y garantiza que el código de barras se ajuste al tamaño de tu etiqueta.

```csharp
// Step 2: Set the X‑dimension (width of each bar) to 4 pixels
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
```

La propiedad `Pixels` define el ancho de la barra en píxeles de pantalla. Los valores comunes son 2 – 5 píxeles para etiquetas de correo estándar; aumenta el valor para impresiones más grandes.

## Paso 3 – Guardar el código de barras Planet relleno como PNG

Ahora escribe la imagen en disco. PNG conserva bordes nítidos, lo cual es ideal para escanear.

```csharp
// Step 3: Save the Planet barcode as a PNG image
planetFilled.Save("YOUR_DIRECTORY/PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

Reemplaza `YOUR_DIRECTORY` con la ruta que preparaste anteriormente. Después de ejecutar este código verás un archivo similar a la imagen a continuación.

## Paso 4 – Crear un código de barras Planet con barras vacías (no rellenas)

Si tu servicio postal requiere que las barras sean **vacías**, debes alternar la bandera `FilledBars` después de inicializar el generador.

```csharp
// Step 4: Create a Planet barcode with empty (unfilled) bars
BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
```

El constructor es idéntico; la diferencia está en el siguiente paso de configuración.

## Paso 5 – Cómo establecer las dimensiones del código de barras y hacer que las barras estén vacías

Nuevamente, establece la X‑dimensión para mantener la consistencia visual, luego desactiva las barras rellenas.

```csharp
// Step 5: Set the X‑dimension and specify that bars should be empty
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
planetEmpty.Parameters.Barcode.FilledBars = false;   // makes bars empty
```

La propiedad `FilledBars = false` es lo que realmente cambia el estilo de renderizado. Mantener la misma X‑dimensión asegura que el código de barras de barras vacías se alinee perfectamente con la versión rellena.

## Paso 6 – Guardar el código de barras Planet vacío

```csharp
// Step 6: Save the Planet barcode with empty bars as a PNG image
planetEmpty.Save("YOUR_DIRECTORY/PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

Ahora tendrás dos archivos PNG: uno con barras sólidas y otro con barras huecas, ambos compartiendo las mismas dimensiones.

## Paso 7 – (Opcional) Generar un código de barras RM4SCC para comparación

RM4SCC es otra simbología postal que utiliza el mismo estilo predeterminado de barras rellenas. Los pasos reflejan el ejemplo de Planet, demostrando que **cómo establecer las dimensiones del código de barras** funciona en varios formatos.

```csharp
// Step 7: Create an RM4SCC barcode (filled bars are the default)
BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");

// Step 8: Set the X‑dimension for consistency
rm4scc.Parameters.Barcode.XDimension.Pixels = 4;

// Step 9: Save the RM4SCC barcode as a PNG image
rm4scc.Save("YOUR_DIRECTORY/PostalRM4SCCFilledBars.png", BarCodeImageFormat.Png);
```

Ejecutar estos tres pasos produce `PostalRM4SCCFilledBars.png`, que puedes comparar lado a lado con los resultados de Planet.

## Por qué la X‑dimensión es importante

La X‑dimensión determina el **ancho imprimible mínimo** de cada barra. Si la configuras demasiado baja, el código de barras puede desenfocarse en impresoras de baja resolución, provocando fallos de escaneo. Por el contrario, una X‑dimensión demasiado grande puede exceder las dimensiones de la etiqueta y desperdiciar espacio. Al definir explícitamente **cómo establecer las dimensiones del código de barras**, obtienes un control determinista sobre el tamaño final de la imagen, lo cual es esencial para flujos de trabajo de envío automatizados.

## Problemas comunes y cómo evitarlos

| Problema | Causa | Solución |
|----------|-------|----------|
| El código de barras aparece estirado | X‑dimensión establecida en puntos en lugar de píxeles | Siempre usa la propiedad `Pixels` para un control perfecto de píxeles |
| Las barras vacías siguen pareciendo rellenas | `FilledBars` no se estableció en `false` después del cambio de X‑dimensión | Establece `FilledBars = false` *después* de ajustar la X‑dimensión |
| El archivo guardado está vacío | El directorio de salida no existe o carece de permisos de escritura | Asegúrate de que el directorio exista (`Directory.CreateDirectory`) y que tu aplicación se ejecute con los derechos suficientes |
| La imagen está borrosa al imprimir | PNG de baja DPI guardado desde un monitor de alta resolución | Usa `BarCodeImageFormat.Png` (sin pérdida) y considera la propiedad `Resolution` si es necesario |

## Ejemplo completo y ejecutable

Copia todo el bloque a continuación en un nuevo proyecto de consola (`dotnet new console`) y ejecútalo. El programa crea tres archivos PNG en la carpeta `output`.

```csharp
using System;
using System.IO;
using Aspose.BarCode;
using Aspose.BarCode.Generation;

class Program
{
    static void Main()
    {
        // Ensure output folder exists
        string outDir = Path.Combine(Environment.CurrentDirectory, "output");
        Directory.CreateDirectory(outDir);

        // ---------- Planet barcode – filled bars ----------
        BarcodeGenerator planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4; // set dimensions
        planetFilled.Save(Path.Combine(outDir, "PostalPlanetFilledBars.png"), BarCodeImageFormat.Png);

        // ---------- Planet barcode – empty bars ----------
        BarcodeGenerator planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4; // same dimensions
        planetEmpty.Parameters.Barcode.FilledBars = false;    // make bars empty
        planetEmpty.Save(Path.Combine(outDir, "PostalPlanetEmptyBars.png"), BarCodeImageFormat.Png);

        // ---------- RM4SCC barcode (filled bars) ----------
        BarcodeGenerator rm4scc = new BarcodeGenerator(EncodeTypes.RM4SCC, "123456");
        rm4scc.Parameters.Barcode.XDimension.Pixels = 4; // consistent size
        rm4scc.Save(Path.Combine(outDir, "PostalRM4SCCFilledBars.png"), BarCodeImageFormat.Png);

        Console.WriteLine($"Barcodes generated in: {outDir}");
    }
}
```

**Salida esperada:** tres archivos PNG—`PostalPlanetFilledBars.png`, `PostalPlanetEmptyBars.png` y `PostalRM4SCCFilledBars.png`—cada uno con barras de 4 píxeles de ancho, listos para imprimir o procesar más.

## Conclusión

Ahora sabes cómo **crear un código de barras planet** en C# y, de manera precisa, **cómo establecer las dimensiones del código de barras** para estilos de barras rellenas y vacías. El mismo patrón se aplica a otras simbologías como RM4SCC, brindándote una base flexible para cualquier requerimiento de códigos de barras postales.

A continuación, podrías explorar:

* Añadir texto legible por humanos debajo del código de barras (`BarcodeGenerator.Parameters.Barcode.CodeText`)

* Generar códigos de barras en formatos vectoriales (SVG, EPS) para impresión escalable

Siéntete libre de experimentar con diferentes valores de X‑dimensión, cadenas de datos y formatos de salida para adaptarlos a tu flujo de trabajo específico. ¡Feliz codificación!
