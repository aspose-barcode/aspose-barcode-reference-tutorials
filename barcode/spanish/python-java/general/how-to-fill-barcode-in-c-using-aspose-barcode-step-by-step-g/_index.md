# Cómo rellenar códigos de barras en C# usando Aspose.BarCode

Si necesitas **cómo rellenar códigos de barras** en una aplicación .NET, este tutorial muestra el proceso completo. Generarás un código de barras postal Planet con barras sólidas y luego crearás una versión con barras vacías del mismo código, todo con un único cambio de línea de código.

La guía cubre todo lo que necesitas saber: configuración del proyecto, ajuste de la X‑dimension, cambio entre barras rellenas y vacías, y cómo verificar los archivos PNG generados. No se requiere documentación externa—simplemente copia el código, ejecútalo y verás el resultado.

## Requisitos previos

Antes de comenzar, asegúrate de tener:

* SDK de .NET 6.0 o posterior instalado  
* Un entorno de desarrollo como Visual Studio 2022 o VS Code  
* El paquete NuGet **Aspose.BarCode for .NET** (`Aspose.BarCode`)  

Estos elementos constituyen la línea base mínima para la parte **barcode generator c#** del tutorial.

## Cómo rellenar códigos de barras – configurar el proyecto

1. Crea un nuevo proyecto de consola:

   ```bash
   dotnet new console -n BarcodeDemo
   cd BarcodeDemo
   ```

2. Añade el paquete Aspose.BarCode:

   ```bash
   dotnet add package Aspose.BarCode
   ```

3. Abre el archivo `Program.cs` generado y reemplaza su contenido con el ejemplo completo que se muestra más adelante en este artículo.

El proyecto ahora contiene todo lo necesario para **generar códigos de barras postales** en imágenes.

## Generar código de barras postal con barras sólidas

El primer paso es crear un código de barras Planet que use barras rellenas (sólidas). Planet es la simbología utilizada por muchos servicios postales para la clasificación.

```csharp
// Step 1: Define the output folder
string outputFolder = "YOUR_DIRECTORY/";

// Step 2: Create a Planet barcode with the default solid (filled) bars
var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 3: Set the X‑dimension (module width) to 4 pixels for better visibility
planetFilled.Parameters.Barcode.XDimension.Pixels = 4;

// Step 4: Save the barcode image with filled bars as PNG
planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);
```

**Por qué estas líneas son importantes**

* `EncodeTypes.Planet` indica al generador qué simbología usar; Planet es el estándar para códigos de barras postales.  
* `XDimension.Pixels = 4` aumenta el ancho del módulo, facilitando la lectura del código y haciéndolo visualmente más claro al imprimir.  
* `Save` escribe la imagen en disco en formato PNG, un formato sin pérdida adecuado para procesamiento posterior.

Ejecutar este bloque produce **PostalPlanetFilledBars.png**, una imagen con barras sólidas que cumple con las especificaciones postales.

## Crear código de barras vacío usando la simbología Planet

A veces un sistema postal espera que las barras estén vacías (no rellenas) mientras los espacios permanecen sólidos. Cambiar a ese modo solo requiere modificar una propiedad.

```csharp
// Step 5: Create another Planet barcode that will use empty (unfilled) bars
var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");

// Step 6: Apply the same X‑dimension setting
planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;

// Step 7: Configure the barcode to render empty bars instead of solid ones
planetEmpty.Parameters.Barcode.FilledBars = false;

// Step 8: Save the barcode image with empty bars as PNG
planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
```

**Por qué funciona**

Establecer `FilledBars = false` indica al renderizador que invierta el estilo visual: las barras se vuelven transparentes (vacías) y el fondo opaco. Esto es exactamente lo opuesto al comportamiento predeterminado demostrado antes, permitiéndote **crear códigos de barras vacíos** sin cambiar los datos codificados.

## Ejemplo completo y ejecutable

A continuación se muestra el programa completo que combina ambas secciones. Cópialo en `Program.cs`, sustituye `YOUR_DIRECTORY/` por una ruta de carpeta real y ejecuta `dotnet run`.

```csharp
using Aspose.BarCode.Generation;
using System;

class Program
{
    static void Main()
    {
        // Define where the PNG files will be saved
        string outputFolder = "YOUR_DIRECTORY/";

        // -------------------------------------------------
        // Generate a filled (solid) Planet barcode
        // -------------------------------------------------
        var planetFilled = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetFilled.Parameters.Barcode.XDimension.Pixels = 4;
        planetFilled.Save($"{outputFolder}PostalPlanetFilledBars.png", BarCodeImageFormat.Png);

        // -------------------------------------------------
        // Generate an empty (unfilled) Planet barcode
        // -------------------------------------------------
        var planetEmpty = new BarcodeGenerator(EncodeTypes.Planet, "123456");
        planetEmpty.Parameters.Barcode.XDimension.Pixels = 4;
        planetEmpty.Parameters.Barcode.FilledBars = false;
        planetEmpty.Save($"{outputFolder}PostalPlanetEmptyBars.png", BarCodeImageFormat.Png);
    }
}
```

### Resultado esperado

Después de la ejecución encontrarás dos archivos PNG en la carpeta especificada:

| Nombre del archivo               | Descripción visual |
|----------------------------------|--------------------|
| `PostalPlanetFilledBars.png`    | Barras negras sólidas sobre fondo blanco |
| `PostalPlanetEmptyBars.png`     | Barras transparentes (blancas) sobre fondo negro |

Ambas imágenes codifican la misma cadena numérica `"123456"` y comparten la misma X‑dimension, garantizando que sean intercambiables desde la perspectiva de validación de datos.

## Preguntas frecuentes y casos límite

**¿Qué pasa si la carpeta de salida no existe?**  
El método `Save` lanza una `DirectoryNotFoundException`. Crea la carpeta previamente o envuelve las llamadas en un bloque `try / catch` que cree el directorio si es necesario:

```csharp
if (!System.IO.Directory.Exists(outputFolder))
    System.IO.Directory.CreateDirectory(outputFolder);
```

**¿Puedo usar otro formato de imagen?**  
Sí. Sustituye `BarCodeImageFormat.Png` por `BarCodeImageFormat.Jpeg`, `BarCodeImageFormat.Bmp` o cualquier formato soportado por Aspose.BarCode.

**¿Afecta la X‑dimension a la legibilidad del escáner?**  
Aumentar el ancho en píxeles hace que las barras sean más anchas, lo que puede mejorar la legibilidad en escáneres de baja resolución. Sin embargo, valores muy grandes pueden exceder el área imprimible. Los valores típicos oscilan entre 2 y 6 píxeles para impresiones a 300 dpi.

**¿La simbología `EncodeTypes.Planet` es la única opción postal?**  
No. Aspose.BarCode también soporta `EncodeTypes.Postnet` y `EncodeTypes.USPSIntelligentMail`. La propiedad `FilledBars` funciona con esos tipos también.

Al ajustar la X‑dimension controlas la claridad visual, y un único cambio de propiedad alterna entre barras rellenas y vacías sin modificar los datos codificados.
