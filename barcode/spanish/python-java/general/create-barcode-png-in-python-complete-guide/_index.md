# Crear barcode PNG en Python – Guía completa

¿Alguna vez necesitaste **create barcode PNG** pero no estabas seguro de qué biblioteca o configuración usar? No estás solo. En muchos sistemas de inventario o de pago, el primer paso es convertir datos sin procesar en una imagen PNG nítida que a los escáneres les encanta.  

En este tutorial recorreremos **how to generate databar**, cómo **adjust barcode height**, e incluso el truco para **change barcode** parámetros sobre la marcha—todo mientras usamos **barcode with sample data** que puedes copiar‑pegar directamente en tu proyecto.  

## Lo que aprenderás

- Configurar la biblioteca Aspose.BarCode (o similar) en Python.  
- **Create barcode PNG** archivos con diferentes alturas en solo unas pocas líneas de código.  
- **How to change barcode** propiedades como el tamaño del módulo y la altura de la barra.  
- Utilizar un valor realista GTIN‑14 como **barcode with sample data**.  
- Consejos para solucionar problemas comunes como imágenes borrosas o codificación incorrecta.

No se requiere experiencia previa en generación de códigos de barras—solo un intérprete básico de Python y la capacidad de instalar un paquete pip.

## Requisitos previos

- Python 3.8+ instalado en tu máquina.  
- Acceso a internet para instalar el paquete `aspose-barcode` (o cualquier biblioteca compatible).  
- Una carpeta con permisos de escritura donde se guardarán los archivos PNG (reemplaza `YOUR_DIRECTORY` en el script).  

Si ya los tienes, genial—¡vamos a sumergirnos!

## Crear barcode PNG – Configurando el Generador

Lo primero: necesitamos un objeto generador que sepa que estamos trabajando con un código de barras **DataBar Omnidirectional**. El código a continuación importa las clases necesarias, crea el generador con un **barcode with sample data**, y establece un tamaño de módulo modesto.

```python
# Install the library (run once):
# pip install aspose-barcode

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

# Step 1: Create a DataBar Omnidirectional generator with sample data
# The string "(01)12345678901231" is a GTIN‑14 wrapped in Application Identifier 01.
barcode_generator = BarcodeGenerator(
    EncodeTypes.DATABAR_OMNIDIRECTIONAL,
    "(01)12345678901231"
)

# Step 2: Set common barcode parameters (module size and initial height)
# XDimension defines the width of the narrowest bar; 2 pixels is a good default.
barcode_generator.parameters.barcode.x_dimension.pixels = 2
barcode_generator.parameters.barcode.bar_height.pixels = 30   # initial 30 px height
```

**Por qué es importante:** `EncodeTypes.DATABAR_OMNIDIRECTIONAL` indica al motor que produzca un **DataBar** que pueda leerse desde cualquier dirección, perfecto para estanterías minoristas. Configurar `x_dimension` mantiene las barras nítidas, mientras que `bar_height` controla el tamaño visual del código.

## Cómo generar Databar con datos de ejemplo

Ahora que el generador está listo, **crearemos barcode PNG** archivos. La primera guardada usa una altura de 30 píxeles, lo cual suele ser suficiente para vistas previas en pantalla.

```python
# Step 3: Save the barcode image at 30 px height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni30.png", BarCodeImageFormat.PNG)
print("30 px barcode saved as DatabarOmni30.png")
```

Ejecutar el script hasta este punto producirá un archivo PNG que se ve como un código de barras compacto y de alto contraste. Ábrelo en cualquier visor de imágenes para verificar que las barras son nítidas y que los datos GTIN‑14 están codificados.

## Ajustar la altura del barcode (Cómo cambiar barcode)

A veces necesitas un barcode más alto para etiquetas más grandes o impresión de mayor resolución. Aquí es donde **adjust barcode height** entra en juego. Cambiar la altura es tan simple como actualizar la propiedad `BarHeight` y guardar nuevamente.

```python
# Step 4: Increase the barcode height to 60 px
barcode_generator.parameters.barcode.bar_height.pixels = 60

# Step 5: Save the barcode image at the new height
barcode_generator.save(r"YOUR_DIRECTORY/DatabarOmni60.png", BarCodeImageFormat.PNG)
print("60 px barcode saved as DatabarOmni60.png")
```

**Cómo funciona:** El generador reutiliza los mismos datos y tamaño de módulo; solo cambia la dimensión vertical. Esto evita recrear todo el objeto y demuestra **how to change barcode** configuraciones de forma dinámica.

## Script completo – Solución todo en uno

A continuación se muestra el script completo y ejecutable que combina todos los pasos. Copia, pega y ejecuta—debería funcionar de inmediato después de instalar el paquete.

```python
# Full example: create two barcode PNG files with different heights

from aspose.barcode import BarcodeGenerator, EncodeTypes, BarCodeImageFormat

def create_databar_png(output_dir: str):
    # Initialize generator with sample GTIN‑14 data
    generator = BarcodeGenerator(
        EncodeTypes.DATABAR_OMNIDIRECTIONAL,
        "(01)12345678901231"
    )

    # Common settings
    generator.parameters.barcode.x_dimension.pixels = 2
    generator.parameters.barcode.bar_height.pixels = 30  # 30 px first version

    # Save first PNG (30 px)
    path30 = f"{output_dir}/DatabarOmni30.png"
    generator.save(path30, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (30 px): {path30}")

    # Change height – this is the “how to change barcode” part
    generator.parameters.barcode.bar_height.pixels = 60  # 60 px second version

    # Save second PNG (60 px)
    path60 = f"{output_dir}/DatabarOmni60.png"
    generator.save(path60, BarCodeImageFormat.PNG)
    print(f"Created barcode PNG (60 px): {path60}")

if __name__ == "__main__":
    # Replace with an actual folder you have write access to
    create_databar_png(r"YOUR_DIRECTORY")
```

### Resultado esperado

Ejecutar el script generará dos archivos:

- `DatabarOmni30.png` – código DataBar Omnidirectional de 30 px de altura.  
- `DatabarOmni60.png` – versión de 60 px de altura del mismo código.

Ambas imágenes están en formato PNG, sin pérdida, y listas para incrustarse en PDFs, páginas HTML o imprimirse directamente en etiquetas.

## Problemas comunes y consejos profesionales

- **Pixel vs. DPI:** Los archivos PNG se basan en píxeles. Si necesitas un tamaño de impresión específico, calcula `BarHeight` en función del DPI (p. ej., 300 dpi → 30 px ≈ 0.1 in).  
- **Incorrect encoding:** Asegúrate de que la cadena de datos siga el formato de Identificador de Aplicación GS1 (`(01)` para GTIN‑14). La falta de paréntesis puede hacer que la biblioteca recurra a un barcode numérico simple.  
- **File paths:** Usa cadenas crudas (`r"..."`) o dobles barras invertidas en Windows para evitar problemas con caracteres de escape.  
- **Performance:** Si estás generando miles de barcodes, instancia el generador una sola vez y solo modifica `BarHeight` o la cadena de datos entre guardados. Esto reduce el consumo de memoria.
